1. 머신러닝 — 컴퓨터가 데이터에서 스스로 배운다는 게 뭔 뜻인가​

머신러닝을 이해하는 출발점은 귀납적사고와 기계학습이에요. 귀납적 추론이란 "개별 사례를 많이 보고 일반적인 규칙을 뽑아내는" 사고방식인데, 기계학습이 딱 이 방식으로 작동해요. 데이터를 잔뜩 먹이면 스스로 패턴을 학습하는 거죠.

이렇게 학습을 마친 모델을 실제 서비스에 올리고 관리하는 전체 흐름을 기계학습 모델링과 ModelOps라고 불러요. 데이터 수집부터 모델 배포·모니터링까지 이어지는 파이프라인이 바로 머신러닝 파이프라인이에요. 데이터 전처리 → 특징 추출 → 학습 → 평가 → 배포 단계가 컨베이어벨트처럼 연결된 거예요.

그런데 머신러닝과 딥러닝 차이를 묻는 문제가 자주 나와요. 머신러닝은 사람이 특징(feature)을 직접 설계해서 넣어주는 반면, 딥러닝은 신경망이 특징 자체를 스스로 학습해요. 딥러닝이 머신러닝의 일종이지만 훨씬 더 강력하고 복잡한 구조예요.

모델이 잘 학습되려면 최적화가 필요해요. 머신러닝 최적화 알고리즘에는 경사하강법 계열이 많은데, 그 대표가 Gradient Descent Algorithm이에요. 손실 함수의 기울기를 따라 내려가면서 최솟값을 찾는 알고리즘이죠. 배치 경사하강법, 확률적 경사하강법(SGD), 미니배치 방식으로 나뉘어요.

주요 알고리즘들​

로지스틱 회귀분석(Logistic Regression)은 이름에 "회귀"가 붙어있지만 사실 분류 알고리즘이에요. 출력값을 0~1 사이로 압축하는 로짓 변환을 써서 확률로 만들어요. "이 메일이 스팸일 확률이 0.92다" 같은 식으로요.

SVM(Support Vector Machine)은 클래스 사이의 경계선(결정 경계)을 최대한 넓게 잡으려는 알고리즘이에요. 이 경계와 데이터 포인트 사이의 거리를 마진이라고 하는데, SVM 마진 분류에서 모든 데이터가 마진 밖에 있어야 한다는 조건이 Hard Margin, 약간의 오류를 허용하는 게 Soft Margin이에요. 현실 데이터는 노이즈가 있으니까 Soft Margin이 더 자주 쓰이죠.

의사결정나무 분석(Decision Tree Analysis)은 "이 값이 30 이상인가? → 예: 왼쪽, 아니오: 오른쪽" 식으로 조건을 트리 형태로 분기하는 알고리즘이에요. 의사결정나무(Decision Tree)에서 분기 기준을 정할 때 의사결정나무의 지니 지수/엔트로피 지수를 씁니다. 지니 지수와 엔트로피 모두 한 노드의 "불순도"를 측정하는 지표예요. 불순도가 낮아지는 방향으로 분기하는 거죠.

비슷한 예시 여러 개를 모아서 하나의 강력한 모델을 만드는 게 앙상블(Ensemble) 기법이에요. 대표적으로 두 가지 방식이 있는데, 앙상블 Bagging과 Boosting이에요. Bagging은 데이터를 복원 추출로 여러 번 샘플링해서 각각 모델을 만들고 결과를 투표로 합치는 방식이고, Boosting은 이전 모델이 틀린 데이터에 더 집중해서 모델을 순차적으로 개선해 나가는 방식이에요. Random Forest가 배깅의 대표 예인데, 복원 샘플링 기반으로 여러 의사결정나무를 만들고 다수결로 예측해요.

비슷한 데이터끼리 그룹을 짓는 게 군집분석(Cluster Analysis)이에요. 라벨 없이 데이터 구조를 파악하는 비지도학습의 핵심이죠. K-Means Clustering과 DBSCAN은 군집분석의 양대산맥인데, K-Means는 클러스터 수 K를 미리 정하고 중심점을 반복 이동시키는 방식이고, DBSCAN은 밀도 기반으로 모양이 불규칙한 클러스터도 찾아낼 수 있어요. K-Means/DBSCAN/SVM을 데이터 마이닝 기법으로 함께 묶어서 비교하는 문제도 나왔어요. 또 다른 군집 기법으로 군집분석 SOM(Self Organizing Map)이 있는데, 자기조직화지도라고도 해요. 고차원 데이터를 2차원 격자로 시각화하면서 군집화하는 신경망 기반 기법이에요.

연관규칙은 "기저귀를 사면 맥주도 산다" 같은 패턴을 데이터에서 찾는 기법이에요. 세 가지 지표가 핵심인데, 지지도(두 항목이 함께 등장하는 빈도), 신뢰도(A를 산 사람 중 B도 산 비율), 향상도(우연보다 얼마나 더 자주 함께 나타나는지)예요.

생물 진화 원리를 최적화에 적용한 게 유전 알고리즘(Genetic Algorithm)이에요. 해(解)를 유전자처럼 표현하고, 적자생존 방식으로 좋은 해를 점점 발전시켜 나가는 거죠. 선택 방법 중 하나가 룰렛 휠 선택이에요. 적합도에 비례해서 선택 확률을 부여하는 방식이죠.

강화학습에서 에이전트가 환경과 상호작용하면서 보상을 최대화하는 정책을 학습하는 기법이 Q-러닝(Q-Learning)이에요. 각 상태-행동 쌍에 Q값(기대 보상)을 부여하고, 반복적으로 업데이트해서 최적 정책을 찾아요.

통계적 모델로 음성인식과 자연어처리에 쓰이는 은닉 마르코프 모델(HMM)도 있어요. 관측할 수 없는 숨겨진 상태(은닉 상태)가 있고, 그 상태가 마르코프 과정을 따른다는 가정 하에 관측된 시퀀스를 모델링하는 거예요.

차원 축소​

데이터의 특징이 너무 많으면 계산이 복잡해지고 과적합도 생겨요. 이걸 줄이는 게 데이터 차원 축소예요. 다변량회귀분석/주성분분석(PCA)/다차원척도법이 대표적인 차원 축소 기법이에요. PCA는 분산을 최대로 보존하는 방향으로 새 축을 만들어서 차원을 줄이는 거고, 다차원척도법은 데이터 간 거리 관계를 유지하면서 저차원에 배치하는 거예요.

성능 평가​

학습이 끝났으면 모델이 잘 작동하는지 평가해야 해요. 머신러닝 성능지표의 기반이 되는 게 혼동행렬(Confusion Matrix)이에요. TP(진양성), TN(진음성), FP(위양성), FN(위음성) 네 칸으로 구성돼요. 여기서 F1 Score, 정밀도(Precision), 재현율(Recall)이 나와요. 정밀도는 "양성이라 예측한 것 중 실제 양성 비율", 재현율은 "실제 양성 중 양성으로 잡아낸 비율"이고, F1 Score는 둘의 조화평균이에요. PR곡선과 ROC곡선은 모델 성능을 시각화하는 곡선인데, PR곡선은 정밀도-재현율 트레이드오프를, ROC곡선은 TPR과 FPR의 관계를 보여줘요.

군집의 품질을 평가할 때는 실루엣 계수(Silhouette Coefficient)를 써요. 한 데이터 포인트가 자기 클러스터 안에서는 얼마나 가깝고, 다른 클러스터와는 얼마나 먼지를 -1~1 사이 값으로 표현하는 거예요.

과적합과 보안​

모델이 훈련 데이터에 지나치게 맞춰져서 새 데이터에는 성능이 떨어지는 현상이 과적합(Overfitting)이에요. 해결책으로는 데이터 증강, 정규화(L1/L2), 드롭아웃, 조기종료 등이 있어요.

머신러닝 모델에도 보안 위협이 있어요. 머신러닝 보안 취약점과 적대적 공격(Adversarial Attack)이 그거예요. 입력 데이터에 사람 눈에는 안 보이는 미세한 노이즈를 추가해서 모델을 오분류하게 만드는 거예요. 머신러닝 적대적 공격/생성형 AI 보안을 함께 묶어 출제하는 경우도 있어요.

2. 딥러닝 — 뇌를 흉내 낸 구조로 더 복잡한 문제를 푼다​

딥러닝의 출발점은 퍼셉트론(Perceptron), 활성화 함수예요. 퍼셉트론은 뉴런을 수학적으로 흉내 낸 구조인데, 입력값에 가중치를 곱해서 합산한 뒤 활성화 함수를 통과시켜요. 단층 퍼셉트론은 XOR 문제를 못 풀었는데, 이게 다층 구조로 발전하면서 딥러닝이 탄생한 거예요.

인공신경망/피드포워드/역전파/활성화함수는 딥러닝의 핵심 구성 요소예요. **피드포워드(Feed Forward)**는 입력층 → 은닉층 → 출력층 방향으로 정보가 앞으로만 흐르는 구조이고, **역전파(Backpropagation)**는 출력에서 발생한 오차를 뒤로 전파해서 각 층의 가중치를 업데이트하는 알고리즘이에요. Feed Forward 모델, CNN의 차이를 묻는 문제도 나왔는데, CNN은 이미지처럼 공간 구조가 있는 데이터를 위해 합성곱 연산을 추가한 구조예요.

딥러닝 모델을 구현할 때 많이 쓰는 프레임워크가 텐서플로(TensorFlow)예요. 구글이 만든 오픈소스 딥러닝 라이브러리로, 연산 그래프를 정의하고 GPU에서 병렬 처리하는 거죠.

모델 학습에는 수많은 설정값이 있어요. 딥러닝 파라미터/하이퍼파라미터를 구분해야 하는데, 파라미터는 학습으로 자동 조정되는 가중치·편향이고, 하이퍼파라미터는 학습률, 배치 크기, 에포크 수처럼 사람이 직접 설정하는 값이에요.

다양한 신경망 구조​

일반적인 CNN, RNN 너머로 다양한 신경망 구조가 있어요.

SNN(Spiking Neural Networks)은 실제 뇌처럼 스파이크(전기 신호) 패턴으로 정보를 전달하는 신경망이에요. 기존 인공신경망보다 에너지 효율이 높고 시간적 패턴 처리에 강해요.

GNN(Graph Neural Network)은 그래프 구조 데이터(소셜 네트워크, 분자 구조 등)를 처리하는 신경망이에요. 노드와 엣지 간의 관계를 학습하는 거죠.

딥뷰(DeepView)는 딥러닝 모델의 내부 작동을 시각적으로 분석하는 기술이에요. 고차원 표현 공간을 2차원으로 투영해서 모델이 데이터를 어떻게 분류하는지 직관적으로 보여줘요.

하드웨어와 인프라​

딥러닝의 발전을 이끈 건 알고리즘만이 아니에요. 하드웨어도 엄청나게 중요해요. GPU와 TPU 비교가 시험에 나오는데, GPU는 원래 그래픽 처리용이지만 행렬 연산에 강해서 딥러닝 학습에 활용되고, TPU는 구글이 딥러닝 연산만을 위해 설계한 전용 칩이에요.

대규모 신경망을 여러 GPU에서 동시에 학습시키는 기술이 멀티 GPU 훈련 기술이에요. 데이터 병렬화(같은 모델을 여러 GPU에 복사)와 모델 병렬화(모델을 여러 GPU에 쪼개서 배치)로 나뉘어요.

아예 뇌 구조를 반도체에 구현한 게 뉴로모픽 칩(Neuromorphic Chip)이에요. 뉴런과 시냅스를 하드웨어로 모방해서 기존 폰 노이만 구조 대비 에너지 소비를 획기적으로 줄이는 거예요.

클라우드 서버 없이 스마트폰·IoT 기기에서 직접 AI를 실행하는 게 온디바이스 AI예요. 데이터를 외부로 보내지 않으니 프라이버시 보호와 응답속도 측면에서 유리하죠.

3. 자연어처리/LLM — 언어를 이해하고 생성하는 AI​

자연어처리(NLP)는 컴퓨터가 인간의 언어를 이해하고 생성하는 기술이에요. 가장 기초적인 응용이 챗봇(Chatbot)이에요. 규칙 기반 챗봇에서 딥러닝 기반으로 진화했고, 지금은 LLM 기반의 대화형 AI가 대세예요. 인공지능 콜센터(딥러닝 적용)도 실용적인 예시인데, 인바운드(고객 문의 응대), 아웃바운드(발신 업무 자동화), 녹취 분석까지 딥러닝으로 처리해요.

자연어처리에서 중요한 개념들을 묶어서 설명하면, NER, Word Embedding, BERT, GPT-3가 핵심이에요. **NER(Named Entity Recognition)**은 텍스트에서 사람·장소·조직 같은 개체명을 찾는 기술이고, Word Embedding은 단어를 고차원 벡터로 표현해서 의미적 유사성을 포착하는 기법이에요. 자연어처리 임베딩(Embedding)은 AI가 텍스트를 수치로 변환하는 핵심 과정인데, 비슷한 의미의 단어는 벡터 공간에서 가까이 위치해요.

문서에서 단어의 중요도를 측정하는 TF-IDF도 자연어처리의 고전 기법이에요. 단어 빈도(TF)와 역문서 빈도(IDF)를 곱해서, 특정 문서에만 자주 등장하는 단어에 높은 가중치를 부여해요. 형태소 분석과 함께 써서 문서 가중치를 계산하는 거죠.

텍스트에서 감정이나 의견을 추출하는 게 오피니언 마이닝(Opinion Mining)이에요. 감성 분석이라고도 하는데, 리뷰나 SNS에서 "이 제품에 대해 긍정적인가, 부정적인가"를 파악하는 거죠.

트랜스포머와 LLM​

현대 자연어처리의 혁명은 트랜스포머(Transformer)와 MoE에서 왔어요. 트랜스포머는 어텐션 메커니즘으로 문장 안의 모든 단어 간 관계를 한 번에 포착하는 구조예요. **MoE(Mixture of Experts)**는 여러 전문가 네트워크를 두고 입력에 따라 적절한 전문가만 활성화하는 방식으로 대형 모델의 효율을 높이는 기법이에요.

PLM/LLM 훈련 과정을 보면, 먼저 대규모 코퍼스로 **사전 학습(Pre-training)**을 하고, 특정 태스크에 맞게 **파인튜닝(Fine-tuning)**하는 과정이에요. Pre-trained Language Model에서 GPT, BERT로 발전하고, 이제는 수천억 파라미터의 거대 언어 모델(LLM) 적용 시대가 됐죠. LLM을 도입할 때는 5가지 고려사항(데이터 보안, 환각, 비용, 지연, 정확도)과 5가지 아키텍처(RAG, 파인튜닝, 프롬프트 엔지니어링 등)를 따져봐야 해요.

이미지, 음성, 텍스트를 동시에 처리하는 Multimodal LLM도 있어요. 텍스트만 보던 LLM이 이제는 사진도 보고 소리도 들으면서 통합적으로 이해하는 거예요.

AI 능력을 범위로 나눠보면 AGI/ANI 비교가 중요해요. **ANI(Artificial Narrow Intelligence)**는 체스, 이미지 인식처럼 특정 분야에서만 뛰어난 특화 AI고, **AGI(Artificial General Intelligence)**는 인간처럼 모든 분야에서 일반적으로 사고할 수 있는 범용 AI예요. 현재 AI는 전부 ANI 수준이에요.

RAG, 프롬프트, 에이전트​

LLM의 지식을 최신 정보로 보완하는 기법이 RAG(Retrieval Augmented Generation)이에요. 검색 증강 생성이라고 하는데, LLM이 답변할 때 외부 지식베이스에서 관련 문서를 검색해서 맥락으로 제공하는 거예요. 모델 자체를 재학습시키지 않고도 최신 정보를 활용할 수 있어서 실용적이에요.

LLM에게 원하는 출력을 잘 뽑아내도록 입력을 설계하는 기술이 프롬프트 엔지니어링이에요. Few-shot, Chain-of-Thought, Role-based 같은 기술 요소들이 있고, 잘 설계하면 파인튜닝 없이도 성능을 크게 올릴 수 있어요.

LLM과 외부 도구, 데이터베이스를 연동하는 프레임워크가 LangChain 프레임워크와 LLM이에요. 설비 예지정비처럼 산업 현장에서 LLM을 활용하는 실용 사례에 쓰여요.

자연어로 SQL을 생성하는 TEXT2SQL도 있어요. 데이터베이스를 모르는 사용자도 "지난 달 매출이 가장 높은 상품 5개 알려줘"라고 입력하면 자동으로 SQL 쿼리로 변환되는 거예요.

AI가 스스로 계획을 세우고 도구를 사용하며 목표를 달성하는 에이전틱 AI(Agentic AI)도 주목받고 있어요. 단순히 질문에 답하는 게 아니라, 멀티스텝 작업을 자율적으로 수행하는 에이전트 기반 AI예요.

AI 모델과 외부 컨텍스트·도구를 연결하는 표준 프로토콜이 MCP(Model Context Protocol)예요. LLM이 다양한 외부 서비스나 데이터 소스에 일관된 방식으로 접근할 수 있게 해주는 인터페이스 규격이에요.

LLM 보안​

LLM이 강력해질수록 보안 위협도 커졌어요. OWASP LLM Top 10 보안위협은 LLM 애플리케이션에서 가장 주의해야 할 10가지 보안 위협 목록이에요. 그 중 대표가 프롬프트 인젝션(Prompt Injection)인데, 악의적인 입력으로 LLM의 원래 지시를 덮어써서 의도치 않은 동작을 유발하는 공격이에요.

모델 전도 공격(Model Inversion Attack)은 AI 모델에 여러 쿼리를 보내서 학습 데이터의 민감한 정보를 역으로 추출하는 공격 기법이에요. 개인정보가 모델에 학습됐다면 유출될 수 있는 거예요.

MCP 보안 취약점도 새로 등장한 이슈예요. MCP를 활용할 때 인증·권한 관리·입력 검증이 미흡하면 공격자가 악용할 수 있는 취약점이 생겨요.

생성형 AI 보안 가이드라인은 생성형 AI 사용 시 발생할 수 있는 보안 위협(환각, 데이터 유출, 편향 등)에 대한 대응 방안을 담은 가이드예요. 정부나 주요 기관에서 이런 가이드라인을 계속 발표하고 있어요. 초거대 AI 도입 가이드라인은 공공부문에서 대형 AI 모델을 안전하게 도입·운영하기 위한 공식 지침이에요.

4. 통계/분석 — AI 모델 뒤에 깔린 수학적 기반​

AI와 데이터 분석의 바탕에는 통계학이 있어요. 기술통계와 추론통계 비교가 기본인데, 기술통계는 수집한 데이터를 요약·정리하는 것(평균, 분산, 표준편차)이고, 추론통계는 표본으로 모집단의 특성을 추론하는 거예요.

확률 분포​

확률 분포를 알아야 통계 검정을 이해할 수 있어요. 정규분포 특징은 통계의 기본 중의 기본이에요. 평균을 중심으로 좌우 대칭이고, 평균·중앙값·최빈값이 모두 같아요.

베르누이 분포와 기하 분포는 이산 확률 분포예요. 베르누이 분포는 성공/실패 딱 하나의 시행, 기하 분포는 첫 번째 성공이 나올 때까지의 시행 횟수를 모델링해요.

이항 분포와 포아송 분포도 자주 비교돼요. 이항 분포는 n번 시행에서 성공 횟수, 포아송 분포는 단위 시간/공간에서 사건 발생 횟수를 다루는데, n이 크고 p가 작을 때 이항이 포아송에 수렴해요.

통계적 추정과 가설검정​

추정통계의 표본과 불편 추정량에서, 불편추정량(Unbiased Estimator)은 추정량의 기댓값이 모수와 일치하는 경우예요. 표본 분산 계산 시 n 대신 n-1로 나누는 이유가 여기 있어요.

점추정과 구간추정 비교도 중요해요. 점추정은 모수를 하나의 값으로 추정하고, 구간추정은 신뢰 구간(예: 95% 신뢰구간)으로 범위를 제시해요.

통계적 의사결정의 핵심이 통계적 가설 검정, p-value예요. **귀무가설(H0)**을 세우고, 데이터가 귀무가설과 얼마나 상반되는지 p-value로 측정해요. p-value가 유의수준보다 낮으면 귀무가설을 기각하는 거죠. 통계적 가설 검정 절차는 가설 설정 → 유의수준 선택 → 검정통계량 계산 → 기각역 결정 → 결론 도출 순서예요.

가설검정에서 발생할 수 있는 오류가 통계적 가설검정 1차오류/2차오류예요. 제1종 오류는 귀무가설이 참인데 기각하는 오류(False Positive)이고, 제2종 오류는 귀무가설이 거짓인데 기각하지 못하는 오류(False Negative)예요.

가설검정(정규분포, t-검정)과 가설검정(정규분포, 스마트팩토리 생산시간)은 실제 계산 문제로 출제돼요. 중심극한정리, t-검정, z-검정도 함께 나오는데, 중심극한정리는 "표본 크기가 커지면 표본 평균의 분포가 정규분포에 가까워진다"는 원리예요. 모분산을 알면 z-검정, 모르면 t-검정을 써요.

독립표본 t-검정, 대응표본 t-검정 비교도 출제돼요. 독립표본은 서로 다른 두 집단을 비교하고, 대응표본은 같은 집단을 두 번 측정(전후 비교)하는 거예요.

A/B 테스팅은 실험 설계의 기법인데, 두 버전(A, B)을 사용자에게 무작위 배정해서 어느 쪽이 더 효과적인지 통계적으로 검증해요.

회귀분석​

선형회귀모형 추론 가정 4가지는 선형성, 독립성, 등분산성, 정규성이에요. 이 가정들이 깨지면 회귀 결과를 신뢰할 수 없어요.

설명 변수들 사이에 강한 상관관계가 있으면 다중공선성(Multicollinearity) 문제가 생겨요. 회귀 계수 추정이 불안정해지고 해석이 어려워지죠. 등분산성과 다중공선성을 함께 묶어 회귀모형 오차 진단 항목으로 출제하기도 해요.

4가지 척도, 다중회귀/로지스틱회귀 비교에서 척도는 명목·서열·등간·비율 척도로 나뉘어요. 명목 척도(성별, 혈액형)는 범주만 구분하고, 비율 척도(키, 몸무게)는 절대적 영점과 비율이 모두 의미있어요.

측정 도구가 일관성 있는 결과를 내는지는 타당도(Validity)와 신뢰도(Reliability)로 평가해요. 타당도는 측정하려는 것을 실제로 측정하는지, 신뢰도는 반복 측정 시 일관성이 있는지예요.

시계열과 기타 기법​

시계열분석은 시간 순서로 나열된 데이터에서 패턴을 찾는 거예요. 정상성(평균·분산이 시간에 따라 일정), 자기상관, 이동평균, 그리고 이 개념들을 통합한 ARIMA 모형이 핵심이에요. 자기회귀모형/이동평균모형은 시계열 분석의 기본 구성 요소예요.

상관관계와 인과관계 비교는 빅데이터 분석에서 자주 나오는 함정이에요. 상관관계는 두 변수가 함께 변한다는 관측이고, 인과관계는 한 변수가 다른 변수를 실제로 유발한다는 더 강한 주장이에요. 상관이 있다고 인과가 있는 건 아니에요.

베이즈 정리는 조건부 확률의 핵심이에요. 새로운 증거를 보고 기존 믿음(사전 확률)을 업데이트하는 원리로, 나이브 베이즈 분류기처럼 AI에서도 많이 쓰여요.

베이지안 최적화는 하이퍼파라미터를 효율적으로 튜닝하는 기법이에요. 평가가 비싼 함수(모델 학습)의 최적값을 베이즈 이론으로 똑똑하게 탐색하는 거예요.

MCTS(Monte Carlo Tree Search)는 바둑 AI(알파고)로 유명해진 기법이에요. 트리 탐색에 몬테카를로 시뮬레이션을 결합해서 방대한 경우의 수 중 최선의 수를 찾아요.

아웃라이어(Outlier)는 다른 데이터들과 동떨어진 이상값이에요. 전역(전체 분포 기준), 맥락(시간·공간 맥락 기준), 군집(주변 데이터 기준) 세 유형이 있어요. 전처리 단계에서 아웃라이어를 제거하거나 변환해야 모델 성능이 올라가요.

5. 빅데이터 — 대규모 데이터를 어떻게 다룰 것인가​

빅데이터는 기존 도구로는 처리할 수 없을 정도로 대규모·고속·다양한 데이터예요. 패스트 데이터(Fast Data)는 빅데이터 중에서도 실시간 스트리밍 데이터를 강조하는 개념이에요. 즉각적인 의사결정이 필요한 IoT, 금융 거래 같은 분야에서 중요해요.

데이터 저장과 아키텍처​

대용량 데이터를 원시 형태로 모두 저장해두는 스토리지가 Data Lake예요. 정형·비정형·반정형 데이터를 모두 담을 수 있어서 유연해요. 반면 데이터 레이크를 제대로 관리하지 않으면 데이터 늪(Data Swamp)이 돼요. 메타데이터도 없고, 어디에 뭐가 있는지 아무도 모르는 상태예요. 그래서 데이터 카탈로그와 거버넌스가 필수예요.

로지컬 데이터웨어하우스(LDW)는 하둡 같은 분산 스토리지를 데이터웨어하우스처럼 쓸 수 있게 논리적으로 통합한 아키텍처예요.

빅데이터 처리 아키텍처의 양대 산맥이 빅데이터 프로세싱 아키텍처(람다/카파)예요. Lambda Architecture는 배치(Batch)와 스트림(Speed) 레이어를 모두 두는 이중 구조인데, 복잡하다는 단점이 있어요. Kappa Architecture는 스트림 처리로만 모든 걸 처리하는 단순한 구조예요. 실시간 일관성은 높지만 재처리 비용이 큰 게 트레이드오프예요.

빅데이터 분석 플랫폼 통합 아키텍처는 수집(Kafka 등) → 저장(HDFS, S3) → 처리(Spark, Flink) → 분석(SQL, ML) → 서빙 레이어로 이어지는 전체 파이프라인 구조예요. 빅데이터 플랫폼 아키텍처 설계에서는 인프라·데이터·입출력 구조를 어떻게 설계하는지가 핵심이에요.

데이터 마이닝​

데이터에서 숨겨진 패턴을 찾는 게 CRISP-DM(Cross Industry Standard Process for Data Mining)이에요. 데이터 마이닝 표준 프로세스로, 비즈니스 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 배포 단계로 진행돼요.

데이터 마이닝(정형/비정형/오피니언) 유형을 비교하면, 정형 데이터 마이닝은 DB의 구조화된 데이터를, 비정형 데이터 마이닝은 텍스트·이미지 같은 비구조화 데이터를, 오피니언 마이닝은 감성·의견 데이터를 분석해요. 비정형 데이터 마이닝/텍스트 마이닝/SNA는 각각 비정형 데이터 처리, 텍스트 패턴 분석, 소셜 네트워크 관계 분석을 다루는 기법이에요.

음성데이터 마이닝은 음성 신호에서 의미있는 정보를 추출하는 기술이에요. 콜센터 상담 분석, 회의 내용 추출 등에 활용돼요.

연관 규칙 분석 지표는 앞서 설명한 지지도·신뢰도·향상도예요. 데이터마이닝에서 연관 규칙을 평가하는 핵심 지표들이죠.

네트워크 중심성 분석은 소셜 네트워크에서 어떤 노드가 얼마나 중요한지 측정해요. 연결 중심성(연결 수), 매개 중심성(다른 노드 간 경로에서의 중간 역할), 인접 중심성(다른 노드까지의 평균 거리)으로 나눠요.

데이터사이언스와 MLOps​

데이터사이언스 영역/역량은 통계학, 프로그래밍, 도메인 지식이 교차하는 영역이에요. 데이터 엔지니어링, 분석, 모델링, 커뮤니케이션 능력이 모두 필요해요.

DSML 프로젝트/MLOps는 데이터사이언스와 머신러닝 프로젝트를 효율적으로 운영하는 방법론이에요. MLOps는 개발(Dev)과 운영(Ops)의 원칙을 ML에 적용한 것으로, 모델 학습·배포·모니터링·재학습을 자동화하는 파이프라인을 만드는 거예요.

메타휴리스틱스(Metaheuristics)는 유전 알고리즘(GA), 시뮬레이티드 어닐링(SA) 같은 근사 최적화 기법을 통칭해요. 정확한 최적해보다 충분히 좋은 해를 빠르게 찾는 전략이에요.

빅데이터가 제대로 쓰이고 있는지 감사하는 빅데이터 감리 가이드도 중요해요. 지능정보기술 감리실무 가이드에 따라 빅데이터 시스템의 품질·보안·운영을 점검하는 거예요.

빅데이터 분석도구 선택 원칙은 처리량, 지연 요구사항, 데이터 유형, 팀 역량, 비용을 종합적으로 고려해서 적합한 도구를 고르는 기준이에요.

가상계측(Virtual Metrology)은 빅데이터 기법을 반도체·제조 공정에 적용하는 기술이에요. 실제로 전수검사를 하지 않고도 센서 데이터를 분석해서 품질을 예측·관리하는 온라인 전수검사 효과를 내요.

6. AI 품질/운영 — 만든 AI를 믿을 수 있는가, 제대로 운영하는가​

AI가 확산되면서 "이 AI를 믿을 수 있나?"라는 질문이 더 중요해졌어요. 이 섹션은 AI의 품질, 윤리, 거버넌스를 다뤄요.

데이터 품질과 학습 데이터​

AI 모델의 품질은 학습 데이터 품질에 달려있어요. AI 학습용 데이터 품질관리와 AI 학습용 데이터셋 품질관리는 학습 데이터의 정확성·일관성·완전성·최신성을 보장하기 위한 가이드라인이에요.

학습 데이터를 만들 때 레이블(정답)을 붙이는 작업이 데이터 라벨링/어노테이션이에요. 이미지에 특화된 게 이미지 데이터 어노테이션인데, 분류(Classification), 경계 박스(Bounding Box), 세그멘테이션(Segmentation) 등 유형에 따라 기법이 달라요.

AI 신뢰성과 설명가능성​

AI가 왜 그런 결정을 내렸는지 설명하는 기술이 XAI(eXplainable AI)예요. 설명 가능한 인공지능이라고도 하는데, 블랙박스 AI의 결정을 인간이 이해할 수 있는 형태로 제공하는 거예요. LIME, SHAP 같은 기법이 있어요.

AI 모델이 학습 데이터의 편향을 그대로 흡수하면 머신러닝 편향(Bias)이 생겨요. 편향의 원인은 데이터 수집 편향, 알고리즘 설계 편향, 인간의 확증 편향 등 크게 3가지예요.

AI 신뢰성은 AI 시스템이 정확하고, 공정하고, 투명하고, 안전하게 작동하는지를 포괄하는 개념이에요. 핵심 속성으로 정확성, 견고성, 공정성, 설명가능성, 프라이버시, 안전성이 있어요. AI 신뢰성 검인증 제도(CAT)는 AI 시스템의 신뢰성을 공식적으로 검증하고 인증하는 제도예요.

인공지능 SW 품질보증 테스트에는 일반 소프트웨어와 다른 특수한 기법이 필요해요. 메타모픽 테스팅은 입력 변환과 출력 관계를 이용하고, 뉴런커버리지 테스트는 신경망의 활성화 비율을 측정하는 기법이에요.

딥페이크(Deepfake)는 딥러닝으로 사람의 얼굴·목소리를 합성하는 기술이에요. 딥페이크 대응방안은 탐지 알고리즘, 워터마킹, 법·제도적 규제가 함께 필요해요.

AI 운영 (ModelOps, MLOps)​

학습된 모델을 실제 서비스로 운영하는 게 모델옵스(ModelOps)예요. ModelOps는 AI 모델의 전체 생명주기(개발·배포·모니터링·재학습·폐기)를 체계적으로 관리하는 거예요. MLOps는 기계학습 운영화로, CI/CD 파이프라인에 모델 학습과 배포를 통합하는 거예요.

여러 기관이 데이터를 외부로 공유하지 않고 각자의 로컬 데이터로 모델을 학습시키는 방식이 연합학습(Federated Learning)이에요. 분산된 환경에서 AI를 학습하면서도 프라이버시를 보장할 수 있어요.

PET(Privacy Enhancing Technology)는 데이터의 프라이버시를 기술적으로 보호하는 방법들이에요. 동형암호(암호화된 채로 연산), 차분프라이버시(쿼리 결과에 노이즈 추가), 합성데이터(실제 데이터 특성을 모방한 가짜 데이터 생성)가 대표적인 PET 기술이에요.

AI 리스크와 거버넌스​

AI가 사회에 미치는 영향이 커지면서 리스크 관리와 거버넌스가 필수가 됐어요.

AI RMF(Risk Management Framework)는 NIST가 제시한 AI 위험관리 프레임워크예요. Govern(거버넌스), Map(위험 식별), Measure(측정), Manage(관리) 네 가지 기능으로 구성돼요. 범용 AI 위험관리 프레임워크는 GPT 같은 범용 AI 모델에 특화된 위험관리 체계예요.

AI 거버넌스는 AI의 개발·배포·사용 전 과정에서 책임·투명성·공정성을 확보하기 위한 정책과 제도예요.

AI 개인정보보호 자율점검표는 AI 시스템이 개인정보를 제대로 보호하는지 스스로 점검하는 체크리스트예요. 데이터 수집부터 처리·삭제까지 전 단계를 점검해요.

AI 윤리정책은 AI 개발·사용에서 지켜야 할 윤리 기준을 법·정책으로 정리한 것이에요. 인공지능 윤리기준 3대 원칙/10대 요건은 과기정통부가 발표한 기준인데, 3대 원칙은 인간성, 사회성, 기술성이고, 그 아래 10가지 핵심 요건이 있어요. 인공지능 윤리/거버넌스는 AI 윤리 기준과 거버넌스 모형을 함께 다루는 주제예요. AI 윤리기준/생성형 AI 역기능은 3대 원칙과 10대 핵심요건 위에서 생성형 AI가 만들어내는 역기능(허위정보, 저작권 침해, 딥페이크 등)에 대응하는 내용이에요.

AI 인공지능기본법은 2026년 시행 예정으로, AI의 개발·활용 전반에 대한 기본 원칙과 규제 체계를 담은 법률이에요. 생성형 AI 이용자 보호 가이드라인은 2025년에 발표된 가이드라인으로, 사용자가 생성형 AI를 안전하게 사용할 수 있도록 플랫폼과 서비스 제공자의 의무를 제시해요.

7. 데이터 시각화 — 데이터를 눈으로 보이게 하기​

숫자와 통계는 시각화를 통해서야 진짜 의미가 살아나요. 데이터 시각화(Data Visualization)는 데이터를 차트, 그래프, 지도 등 시각적 형태로 변환해서 인사이트를 빠르게 파악할 수 있게 해주는 거예요. 원리는 "데이터를 가장 직관적인 시각 채널(색상, 위치, 크기)에 매핑하는 것"이고, 절차는 데이터 준비 → 시각화 유형 선택 → 인코딩 → 렌더링 → 인터랙션 순이에요.

소프트웨어 Visualization은 SW 개발 품질관리를 위한 시각화 도구예요. 코드 의존성, 테스트 커버리지, 코드 복잡도 같은 지표를 시각화해서 개발팀이 빠르게 품질 이슈를 파악할 수 있게 해줘요.

빅데이터 시각화(Visualization)는 방대한 데이터를 다룰 때의 시각화를 말해요. 수백만 건의 데이터를 실시간으로 시각화하려면 Tableau, Power BI, D3.js 같은 전용 도구가 필요하고, 데이터 집계·샘플링·프로그레시브 렌더링 같은 최적화 기법도 써요.

8. 컴퓨터비전 — AI가 이미지와 영상을 이해하는 방법​

컴퓨터비전은 AI가 이미지와 영상을 이해하는 분야예요. 실생활 적용 사례부터 시작해서 핵심 기술로 들어가 볼게요.

영상감시시스템(Video Surveillance System)은 CCTV 등에서 영상을 분석해 보안을 강화하는 시스템이에요. 영상 전처리 → 객체 탐지 → 추적 → 이벤트 감지 단계로 동작해요. 지능형 CCTV 스마트 관제는 여기에 AI를 결합해서 단순 모니터링을 넘어 자동 이상 감지, 실시간 경보 발송까지 하는 스마트 관제 시스템이에요.

안면인식 결제 서비스는 생체인식 기반 결제 서비스예요. 얼굴을 촬영해서 등록된 사용자와 매칭하고 본인 확인 후 결제하는 시스템이에요. 편리하지만 개인정보 보호와 보안 이슈가 함께 따라와요.

핵심 모델​

EfficientNet과 EfficientDet은 구글이 개발한 효율적인 딥러닝 모델이에요. EfficientNet은 이미지 분류 모델이고, EfficientDet은 객체 탐지 모델이에요. 두 모델 모두 모델 크기와 정확도를 동시에 최적화하는 복합 스케일링(Compound Scaling) 기법을 써요. EfficientNet이 이미지에서 특징을 추출하면, EfficientDet은 그 특징을 바탕으로 "어디에 무엇이 있는지"까지 찾아내요.

이미지 데이터 어노테이션은 컴퓨터비전 모델 학습을 위해 이미지에 레이블을 붙이는 작업이에요. 분류 레이블(전체 이미지에 태그), 바운딩 박스(객체 위치), 세그멘테이션 마스크(픽셀 단위 구분)까지 정밀도에 따라 유형이 달라져요.

이렇게 보면 인공지능/데이터분석은 단순히 알고리즘 하나하나를 외우는 게 아니라, "데이터를 모으고 → 전처리하고 → 모델을 학습시키고 → 평가하고 → 서비스에 배포하고 → 윤리적으로 운영한다"는 큰 흐름 속에 모든 키워드가 연결되어 있어요. 머신러닝의 기초 알고리즘부터 LLM의 보안, AI 거버넌스까지 이 흐름을 머릿속에 그리면서 각 키워드의 자리를 잡아두면 훨씬 효율적으로 준비할 수 있을 거예요.
