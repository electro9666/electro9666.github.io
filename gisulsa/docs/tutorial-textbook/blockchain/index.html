블록체인 개념과 구조​

블록체인(Blockchain)은 거래 데이터를 블록(Block) 단위로 묶어 체인(Chain) 형태로 연결하고, 네트워크 참여자 모두가 복사본을 분산 보관하는 분산 원장 기술입니다. 각 블록은 이전 블록의 해시값(Hash), 타임스탬프(Timestamp), 거래 데이터(Transaction Data), 논스(Nonce)로 구성되며, 해시 체인을 통해 과거 데이터의 위·변조가 불가능합니다. 탈중앙화(Decentralization), 투명성(Transparency), 불변성(Immutability), 보안성(Security)이 핵심 특징입니다.

블록체인의 보안 위협으로는 51% 공격(51% Attack), 이클립스 공격(Eclipse Attack), 스마트 컨트랙트 취약점, 지갑 해킹 등이 있습니다. 보안 대응 방안으로는 합의 알고리즘 강화, 스마트 컨트랙트 감사(Audit), 다중 서명(Multi-Signature), 하드웨어 지갑 사용, 개인키 관리 강화 등이 있습니다. 데이터 저장 측면에서 블록체인은 파일·데이터베이스와 달리 변경 불가능하고 분산 저장된다는 점이 차별화됩니다.

합의 알고리즘 (PoW/PoS/PBFT)​

합의 알고리즘(Consensus Algorithm)은 분산된 참여자들이 블록의 유효성에 대해 동의하는 메커니즘으로, 블록체인의 신뢰성과 보안을 담보하는 핵심 기술입니다. PoW(Proof of Work, 작업 증명)는 비트코인이 채택한 방식으로, 참여자(채굴자)가 수학적 난제를 가장 먼저 해결한 노드가 블록을 생성하고 보상을 받습니다. 높은 보안성을 제공하지만 막대한 전력 소비와 확장성 한계가 단점입니다.

PoS(Proof of Stake, 지분 증명)는 보유 코인 지분에 비례하여 블록 생성 권한을 부여하는 방식으로, PoW 대비 에너지 효율이 높고 확장성이 우수합니다. 이더리움은 PoW에서 PoS로 전환(The Merge)하여 에너지 소비를 99% 이상 감소시켰습니다. PBFT(Practical Byzantine Fault Tolerance)는 프라이빗 블록체인에서 주로 사용되는 합의 알고리즘으로, 전체 노드의 2/3 이상이 동의하면 합의가 이루어지며 빠른 처리 속도와 높은 신뢰성을 제공합니다.

  • 113회 4교시 - 퍼블릭/프라이빗 블록체인 운영 방식 특징 비교

스마트 컨트랙트 (솔리디티/EVM)​

스마트 컨트랙트(Smart Contract)는 계약 조건을 코드로 블록체인에 기록하고, 조건이 충족되면 자동으로 계약이 실행되는 자동화 프로그램입니다. 중개자 없이 신뢰성 있는 거래를 가능하게 하며, 금융 거래, 부동산 거래, 공급망 관리, 투표 시스템 등 다양한 분야에 적용됩니다. 한번 배포된 스마트 컨트랙트는 수정이 불가능하므로 배포 전 철저한 보안 감사(Audit)가 필수입니다.

솔리디티(Solidity)는 이더리움 스마트 컨트랙트 개발을 위한 정적 타입 고급 프로그래밍 언어로, JavaScript와 유사한 문법을 가집니다. EVM(Ethereum Virtual Machine)은 이더리움 네트워크에서 스마트 컨트랙트를 실행하는 가상 머신으로, 플랫폼 독립적인 바이트코드 실행 환경을 제공합니다. 스마트 컨트랙트의 주요 취약점으로는 재진입 공격(Reentrancy Attack), 정수 오버플로우, 타임스탬프 의존성 등이 있으며 스마트 컨트랙트 감사를 통해 취약점을 사전에 발견·수정합니다.

관련 기출문제​

  • 118회 4교시 - 솔리디티(Solidity), EVM, DApp
  • 117회 2교시 - Smart Contract Audit

비트코인 (UTXO/마이닝)​

비트코인(Bitcoin)은 사토시 나카모토(Satoshi Nakamoto)가 2008년 제안한 최초의 암호화폐로, P2P 네트워크와 PoW 합의 알고리즘을 기반으로 중앙기관 없이 거래를 처리합니다. UTXO(Unspent Transaction Output, 미사용 트랜잭션 출력)는 비트코인의 거래 유효성 검사 모델로, 이더리움의 계좌잔고모델(Account Balance Model)과 달리 각 거래 출력값의 소비 여부로 잔액을 추적합니다. UTXO 기반에서 잔액 계산은 사용되지 않은 출력값의 합계로 산정됩니다.

마이닝(Mining, 채굴)은 PoW에서 참여자가 난이도 조정 해시 퍼즐(SHA-256)을 계산하여 유효한 블록을 생성하고 비트코인 보상과 거래 수수료를 받는 과정입니다. 비트코인 네트워크는 약 10분마다 새로운 블록이 생성되도록 난이도를 자동 조정하며, 반감기(Halving)마다 채굴 보상이 절반으로 줄어들어 총 공급량 2,100만 BTC로 제한됩니다. 트랜잭션 수수료(Transaction Fee)는 미확인 거래의 우선순위를 결정하며, 최소 수수료로 송금하려면 UTXO 조합을 최적화해야 합니다.

관련 기출문제​

  • 111회 1교시 - 블록체인 구성요소 중 마이닝(Mining)
  • 117회 3교시 - UTXO 개념과 최소 수수료 거래 방법

이더리움 (DApp)​

이더리움(Ethereum)은 비탈릭 부테린(Vitalik Buterin)이 2015년 출시한 스마트 컨트랙트 플랫폼으로, 단순 화폐 거래를 넘어 탈중앙화 애플리케이션(DApp) 개발 및 실행 환경을 제공합니다. 이더(Ether, ETH)는 이더리움 네트워크의 기본 화폐이며, 스마트 컨트랙트 실행 비용인 가스(Gas)를 지불하는 데 사용됩니다. ERC-20(대체 가능 토큰), ERC-721(NFT) 등의 표준을 통해 다양한 토큰 생태계가 구축되었습니다.

DApp(Decentralized Application)은 스마트 컨트랙트를 백엔드로 사용하고 블록체인 위에서 실행되는 탈중앙화 애플리케이션입니다. 프론트엔드는 일반 웹/앱과 유사하지만 백엔드 로직이 스마트 컨트랙트로 구현되어 투명성과 검열 저항성을 갖습니다. DeFi(분산 금융), NFT 마켓플레이스, DAO(분산 자율 조직) 등이 대표적인 DApp 형태입니다.

관련 기출문제​

  • 110회 4교시 - 이더리움의 개념과 특징, 가상화폐와 비교
  • 118회 4교시 - 솔리디티, EVM, DApp

하이퍼레저​

하이퍼레저(Hyperledger)는 리눅스 재단이 주도하는 오픈소스 블록체인 프레임워크 프로젝트로, 기업용(Enterprise) 블록체인 솔루션 구축을 목적으로 합니다. 하이퍼레저 패브릭(Hyperledger Fabric)은 프라이빗 블록체인 플랫폼으로, 허가된 참여자만 접근 가능하며 채널(Channel)을 통해 프라이버시를 보장합니다. 체인코드(Chaincode)는 하이퍼레저 패브릭의 스마트 컨트랙트로, Go, Java, Node.js 언어로 개발합니다.

하이퍼레저 패브릭의 주요 구성 요소는 피어(Peer), 오더러(Orderer), CA(Certificate Authority), 채널(Channel), 원장(Ledger)입니다. PBFT 기반의 합의 메커니즘을 사용하여 빠른 처리 속도와 최종성(Finality)을 보장합니다. 하이퍼레저는 공급망, 금융, 의료, 정부 등 다양한 산업에서 신뢰할 수 있는 비즈니스 네트워크 구축에 활용됩니다.

관련 기출문제​

  • 117회 1교시 - 하이퍼레저(Hyperledger)

퍼블릭/프라이빗 블록체인​

퍼블릭 블록체인(Public Blockchain)은 누구나 참여·열람·검증이 가능한 완전 개방형 블록체인입니다. 비트코인, 이더리움이 대표적이며, 탈중앙화 수준이 높고 검열 저항성이 강하지만 처리 속도가 느리고 에너지 소비가 큽니다. 트랜잭션 처리 속도, 확장성, 프라이버시 보호가 퍼블릭 블록체인의 주요 과제입니다.

프라이빗 블록체인(Private Blockchain)은 허가된 참여자만 접근 가능한 폐쇄형 블록체인으로, 하이퍼레저 패브릭이 대표적입니다. 빠른 처리 속도, 에너지 효율, 프라이버시 보호 면에서 우수하지만 중앙화 경향으로 탈중앙화 이점이 약합니다. 하이브리드 블록체인(Hybrid Blockchain)은 퍼블릭과 프라이빗의 장점을 결합한 형태로, 일부 데이터는 공개하고 민감 정보는 프라이빗 체인에서 관리합니다. 정보, 생성, 합의 주체, 규칙 변경, 거래 속도, 거래 확정 주체 등 6가지 관점에서 두 유형을 비교 이해하는 것이 중요합니다.

DID (분산 신원증명)​

DID(Decentralized Identity, 분산 신원증명)는 중앙화된 신원 관리 기관 없이 개인이 자신의 신원 정보를 직접 생성·관리·증명할 수 있는 자기 주권 신원(SSI: Self-Sovereign Identity) 기술입니다. 블록체인을 기반으로 DID 식별자와 DID 문서를 관리하며, 검증 가능한 자격증명(Verifiable Credential, VC)을 통해 신원을 증명합니다.

신원증명의 발전 단계는 중앙화 ID(Centralized) → 연합 ID(Federated) → 사용자 중심 ID(User-Centric) → 자기 주권 ID(Self-Sovereign) 순으로 진행되었습니다. DID의 주요 구성 요소는 홀더(Holder, 신원 보유자), 발급자(Issuer), 검증자(Verifier)의 3자 신뢰 모델입니다. 전자 여권, 운전면허증, 학력 증명, 금융 KYC(Know Your Customer) 등 다양한 신원 확인이 필요한 분야에 활용됩니다.

머클 트리​

머클 트리(Merkle Tree)는 해시 트리(Hash Tree)의 일종으로, 리프 노드(Leaf Node)에 개별 트랜잭션의 해시값을 저장하고, 상위 노드는 두 자식 노드의 해시값을 결합한 해시값을 저장하는 이진 트리 구조입니다. 루트 해시(Merkle Root)는 트리 내 모든 거래 데이터를 대표하며, 비트코인과 이더리움 블록 헤더에 포함됩니다.

머클 트리의 핵심 장점은 특정 거래의 포함 여부를 O(log n)의 복잡도로 검증할 수 있는 머클 증명(Merkle Proof)입니다. SPV(Simplified Payment Verification) 클라이언트는 전체 블록체인을 저장하지 않고 머클 증명만으로 거래의 유효성을 확인할 수 있어 경량 클라이언트 구현에 활용됩니다. 데이터 일부가 변조되면 머클 루트가 변경되어 즉시 감지가 가능하므로 데이터 무결성 검증 도구로 유용합니다.

관련 기출문제​

분산 원장 기술 (DLT)​

분산 원장 기술(DLT: Distributed Ledger Technology)은 거래 기록을 중앙 서버 없이 네트워크 참여자 모두가 분산하여 공유·관리하는 기술의 총칭입니다. 블록체인은 DLT의 한 형태로, 블록과 체인 구조를 사용하지만 DAG(Directed Acyclic Graph) 기반의 탱글(Tangle), 해시그래프(Hashgraph) 등 비블록체인 DLT도 존재합니다. DLT의 핵심 가치는 단일 실패 지점(SPOF) 제거, 투명성, 불변성, 탈중앙화입니다.

P2P 통신은 블록체인 네트워크의 기반으로, 퓨어 P2P(Pure P2P)는 중앙 서버 없이 모든 노드가 대등하게 통신하며, 하이브리드 P2P(Hybrid P2P)는 일부 중앙 서버를 두어 연결 효율을 높입니다. 비트코인과 이더리움은 퓨어 P2P 방식을 채택합니다. DLT는 금융 결제, 무역 금융, 토지 등기, 의료 기록, 공급망 투명성 확보 등 신뢰 기반의 거래가 필요한 모든 산업에 혁신적 변화를 가져오고 있습니다.
