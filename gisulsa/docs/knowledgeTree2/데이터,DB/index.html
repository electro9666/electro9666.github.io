데이터,DB

식별자# 08. 데이터/DB

1. 데이터 모델링​

1.1 데이터 모델링 기초​

1.1.1 모델링 개념​

  • Data Modeling: 모델링(Modeling)의 필요성과 Inside-out전략, 데이터 모델링의 개념 및 모델링 단계별 수행내용
  • 개념/논리/물리 데이터 모델
  • CRUD 매트릭스: CRUD 매트릭스(Matrix)

1.1.2 ERD​

  • ERD: 바커(Barker) 표기법으로 표현된 ERD, ERD(Entity Relationship Diagram)
  • 관계형 데이터 모델: 관계형 데이터 모델(Relational Data Model)
  • Entity / Attribute

1.2 관계와 식별자​

1.2.1 관계(Relationship)​

  • Cardinality: 데이터베이스 카디널리티(Database Cardinality)
  • 식별/비식별 관계: 식별(Identification)과 비식별(Non Identification)
  • Primary Key / Foreign Key

1.2.2 무결성(Integrity)​

  • 릴레이션 무결성 제약: 릴레이션 무결성 제약의 유형과 사례
  • 참조 무결성: 정보모델링의 참조 무결성
  • 데이터 무결성과 정합성: 데이터 무결성(Integrity)과 정합성(Consistency)의 차이

1.3 정규화​

1.3.1 정규화(Normalization)​

  • 정규화: 정규화(Normalization)의 의미와 효과, 관계형 데이터베이스의 정규화
  • 이상현상: 이상현상(Anomaly)
  • 함수적 종속성(Functional Dependency)
  • 1NF / 2NF / 3NF / BCNF
  • 제4정규형: 제4정규형
  • 제5정규형: 데이터베이스 제5정규형

1.3.2 반정규화(De-normalization)​

  • 반정규화: 반정규화 절차/유형/고려사항, 역정규화

2. 관계형 데이터베이스와 SQL​

2.1 DBMS 기초​

2.1.1 DBMS 개념​

  • 데이터 저장 방식 비교: 파일, 데이터베이스, 블록체인 비교
  • 오픈소스 DBMS: 오픈소스 DBMS 전환 배경/제약사항/마이그레이션 절차

2.2 SQL​

2.2.1 SQL 기본​

  • SQL: SQL(Structured Query Language), SNAME을 조회하는 SQL
  • DDL: 도메인과 테이블을 생성하는 DDL
  • JOIN: SQL에서 정의하는 JOIN의 유형과 JOIN 성능을 높이기 위한 기법

2.2.2 SQL 처리​

  • SQL 처리과정: DBMS에서의 SQL(Structured Query Language) 처리과정
  • Prepared Statement: Statement와 Prepared Statement 방식 비교
  • 동적 SQL: 동적 SQL 개념, 장점, 단점, 정적 SQL(Static SQL)과 동적 SQL(Dynamic SQL) 비교
  • TEXT2SQL: TEXT2SQL의 개념과 활용 사례

2.3 질의 최적화와 튜닝​

2.3.1 옵티마이저​

  • Optimizer: 데이터베이스 옵티마이저(Optimizer)
  • RBO/CBO: RBO(Rule Based Optimizer)와 CBO(Cost Based Optimizer) 비교
  • 실행계획(Execution Plan)
  • Hint: 힌트(Hint)의 유형

2.3.2 데이터베이스 튜닝​

  • DB 튜닝: 데이터베이스 튜닝(Tuning)의 개념과 목적, 설계 단계 튜닝 기법

2.4 인덱스​

2.4.1 인덱스 구조​

  • Index: 데이터베이스 인덱스(Index)
  • Clustered/Non-Clustered Index: 클러스터드 인덱스(Clustered Index)와 논클러스터드 인덱스(Non-Clustered Index) 비교
  • B-Tree / B+Tree
  • 해싱: 확장성 해싱(Extendible Hashing)기법

2.4.2 다차원·공간 인덱스​

  • 다차원 색인구조: 다차원 색인구조(Multidimensional Index Structure) 3가지, 다차원 색인구조(Multidimensional Index Structure)의 개념, 유형, 활용 사례
  • MBR: MBR(Minimum Bounding Region)
  • R-Tree: R트리, R+트리, R*트리 비교, 힐버트(Hilbert) R-tree
  • 공간 연산자: 공간 연산자(Spatial Operator)
  • 공간 데이터 표준: 인도어GML(Indoor Geography Markup Language)

3. 트랜잭션과 동시성 제어​

3.1 트랜잭션​

3.1.1 트랜잭션 개념​

  • ACID: 데이터베이스 트랜잭션(Transaction)의 특징
  • Commit / Rollback / Savepoint

3.1.2 격리 수준(Isolation Level)​

  • Isolation Level: 데이터베이스의 Isolation Level, 트랜잭션 격리 수준(Transaction Isolation Level) 4가지, 데이터베이스 트랜잭션 격리 수준(Transaction Isolation Level)
  • Dirty Read / Phantom Read: RDBMS의 Dirty Read와 Phantom Read, 격리 수준에 따라 발생할 수 있는 이상 현상
  • Phantom Conflict: 팬텀충돌(Phantom Conflict)

3.2 동시성 제어​

3.2.1 병행제어(Concurrency Control)​

  • 병행제어: DBMS 병행수행(Concurrency)제어의 3가지 문제와 해결방법, 데이터베이스의 병행제어(Concurrency Control) 기법의 종류, 데이터베이스 병행 제어 기법 및 필요성
  • Locking / 2PL(Two Phase Locking)
  • Timestamp Ordering
  • MVCC: 다중 버전 동시성 제어(MVCC : Multi Version Concurrency Control)

3.3 회복​

3.3.1 회복(Recovery) 기법​

  • REDO / UNDO
  • Checkpoint
  • 로그 기반 회복(Log-based Recovery)

4. NoSQL과 특수 데이터베이스​

4.1 NoSQL​

4.1.1 NoSQL 개념과 모델링​

  • NoSQL: NoSQL, NoSQL 특징, 데이터 모델링 패턴 및 데이터 모델링 절차, NoSQL의 3가지 구조, NoSQL유형과 모델링 절차
  • NoSQL 모델링 패턴: NoSQL 모델링 패턴 3가지 및 NoSQL 모델링 절차

4.1.2 NoSQL 유형​

  • Key-Value Store
  • Document DB: MongoDB의 개념 및 특징
  • Column Family: Column Family 데이터베이스
  • Graph DB: 그래프 데이터베이스(Graph Database)

4.2 특수 목적 데이터베이스​

4.2.1 인메모리 데이터베이스​

  • In-memory DB: 인메모리 데이터베이스(In-memory Database)

4.2.2 벡터 데이터베이스​

  • Vector Database: 벡터 데이터베이스(Vector Database)
  • HNSW: HNSW(Hierarchical Navigable Small World)
  • IVF: IVF(Inverted File Index)

5. 분산 데이터베이스​

5.1 분산/병렬 데이터베이스​

5.1.1 분산 데이터베이스 개념​

  • 병렬 DB와 분산 DB: 병렬 데이터베이스와 분산 데이터베이스 비교
  • 투명성: 분산 데이터베이스의 5가지 투명성, 분산 데이터베이스의 투명성
  • CAP/PACELC: CAP이론의 한계와 PACELC(Partition Availability Consistency Else Latency Consistency) 이론

5.2 분할과 샤딩​

5.2.1 데이터베이스 분할​

  • DB 분할: 데이터베이스 분할 단위
  • 수평/수직 분할: 수평분할과 수직분할
  • 샤딩: 데이터베이스 샤드(database shard), 데이터베이스 샤딩(Sharding)의 개념 및 분할방법
  • 파티셔닝: 샤딩과 파티셔닝(Partitioning)의 차이점

5.3 복제와 가용성​

5.3.1 데이터 복제(Replication)​

  • 복제 유형: 여러 서버에 데이터를 복제하는 경우의 복제 유형
  • DBMS 고가용성: 신뢰성 확보를 위한 고가용성(HA) 아키텍처 구성 방안

6. 데이터웨어하우스와 데이터 플랫폼​

6.1 데이터웨어하우스​

6.1.1 DW와 OLAP​

  • OLTP vs OLAP: 온라인 분석처리(OLAP)와 온라인 트랜잭션처리(OLTP) 비교
  • MOLAP: 다차원 온라인분석처리(MOLAP)의 설계방법과 다차원 데이터 큐브 설계
  • ROLAP / HOLAP
  • Data Mart / ODS

6.1.2 DW 모델링과 아키텍처​

  • Star Schema: 스타 스키마(Star Schema)
  • Snowflake Schema
  • LDW: 로지컬 데이터웨어하우스(LDW : Logical Data Warehouse)

6.2 데이터 레이크​

6.2.1 Data Lake​

  • Data Lake: Data Lake, 데이터 레이크(Data Lake)의 아키텍처
  • Data Swamp: 데이터 늪(Data Swamp), 데이터 스웜프(Data Swamp) 발생 원인과 방지 방안
  • Data Lakehouse / Data Mesh / Data Fabric

6.3 데이터 통합과 파이프라인​

6.3.1 데이터 통합(ETL)​

  • ETL / ELT / CDC
  • Backfill: 워크플로우 관리의 백필(Backfill)
  • 데이터 마이그레이션: 데이터 마이그레이션 검증 테스트 방법, 오픈소스 DBMS 전환 시 단계별 마이그레이션 절차

6.3.2 DataOps​

  • DataOps: 데이터옵스(DataOps)와 데브옵스(DevOps) 비교, 데이터옵스 아키텍처
  • Data Observability: 데이터 관측가능성(Data Observability)

7. 데이터 관리와 거버넌스​

7.1 데이터 아키텍처와 조직​

7.1.1 데이터 관리 조직​

  • DA/DBA: DA(Data Architect)와 DBA(Database Administrator)의 역할 비교
  • Data Steward / Data Owner

7.2 데이터 표준화​

7.2.1 표준화 체계​

  • 데이터 표준화: 데이터 표준화의 필요성과 기대효과
  • 테이블 정의서: 데이터베이스 표준화지침에서 정의하는 테이블 정의서
  • 공공데이터베이스 표준화: 공공데이터베이스 표준화 관리 매뉴얼의 예방적 품질관리

7.3 데이터 품질​

7.3.1 데이터 품질관리​

  • 품질관리 프레임워크: 데이터 품질관리 프레임워크, 데이터 구조관리, 데이터관리프로세스
  • 품질관리 정책: 정보 생명주기(Information Life Cycle) 단계별 데이터 품질 관리 활동
  • 품질관리 아키텍처/성숙도: 데이터 품질관리 아키텍처, 성숙도, 정형/비정형 데이터 품질기준
  • 데이터 프로파일링: 데이터 값(Value) 진단 프로파일링(Data Profiling)

7.3.2 AI 학습용 데이터 품질​

  • AI 학습용 데이터 품질관리: 인공지능 학습용 데이터 품질관리 모델과 지표, 학습용 데이터 셋의 품질확보를 위한 주요활동과 생애 주기별 품질관리, AI 학습용 데이터 품질관리 지표와 활동

7.4 데이터 거버넌스​

7.4.1 거버넌스 체계​

  • 데이터 거버넌스: 데이터 거버넌스, 데이터 거버넌스(Data Governance)의 개념 및 주요 기능, 데이터 주권 이슈와 데이터 거버넌스 전략
  • 메타데이터 / 데이터 카탈로그

7.4.2 마스터 데이터​

  • Master Data: 마스터 데이터(Master Data)의 개념과 필요성
  • MDM: 마스터 데이터 관리(Master Data Management)의 구성요소와 구축 시 고려사항

8. 데이터 활용과 가치​

8.1 오픈데이터​

8.1.1 개방 데이터​

  • Open Data: 오픈 데이터(Open Data)의 정의와 데이터 등급 5단계
  • LOD: LOD(Linked Open Data) 기술요소, LOD(Linked Open Data)

8.1.2 마이데이터​

  • MyData: 마이데이터(MyData) 산업

8.2 데이터 경제​

8.2.1 데이터 거래와 가치평가​

  • 데이터 거래소: 데이터 거래소
  • 데이터 가치평가: 데이터 가치평가의 모델 및 절차, 데이터 가치평가 및 데이터 자산화
  • 데이터 커머스: 데이터 커머스(Data Commerce)

8.3 데이터 법제도​

8.3.1 데이터 관련 법제도​

  • 데이터산업법: 데이터 산업진흥 및 이용에 관한 촉진법(데이터산업법)
  • 데이터 안심구역: 데이터 안심구역의 정의, 기능, 지정요건, 개인정보 안심구역과 데이터안심구역 비교
