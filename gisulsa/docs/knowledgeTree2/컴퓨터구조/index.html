02. 컴퓨터구조

1. 컴퓨터 시스템 개요​

1.1 컴퓨터 구조 기초​

1.1.1 기본 구조​

  • 폰 노이만(Von Neumann) 구조
  • 하버드(Harvard) 구조
  • 시스템 버스(주소/데이터/제어 버스)

1.2 데이터 표현​

1.2.1 수의 표현과 바이트 순서​

  • 보수 표현(1의 보수, 2의 보수)
  • 부동소수점 표현(IEEE 754)
  • 엔디언: 빅 엔디언, 리틀 엔디언 (126M)

2. 중앙처리장치(CPU)​

2.1 CPU 구조와 명령어​

2.1.1 CPU 구성 요소​

  • CPU: CPU (120M)
  • 레지스터(Register), ALU, 제어장치(Control Unit)
  • 명령어 사이클(인출-해석-실행)

2.1.2 명령어 집합 구조(ISA)​

  • RISC
  • CISC
  • 주소지정방식(Addressing Mode)

2.2 인터럽트​

2.2.1 인터럽트 처리​

  • 인터럽트 처리 우선순위: 인터럽트(Interrupt)의 처리 우선순위 (113M)
  • 인터럽트 벡터(Interrupt Vector)
  • 폴링(Polling)

2.3 파이프라이닝​

2.3.1 파이프라인 구조​

  • 파이프라인: 파이프라인(pipeline) 방식과 비파이프라인 방식 (113M)
  • 파이프라인 해저드(구조적/데이터/제어)
  • 분기 예측(Branch Prediction)
  • 비순차 실행(Out-of-Order Execution)
  • 슈퍼스칼라(Superscalar)

2.4 CPU 보안 취약점​

2.4.1 마이크로아키텍처 취약점​

  • 멜트다운: 멜트다운(Meltdown) (114M)
  • 스펙터: 스펙터(Spectre) (116M)
  • 부채널 공격(Side-Channel Attack)

3. 기억장치​

3.1 메모리 계층구조​

3.1.1 메모리 계층​

  • 메모리 계층구조(Memory Hierarchy)
  • 레지스터-캐시-주기억장치-보조기억장치
  • 지역성(Locality of Reference)

3.2 캐시 메모리​

3.2.1 캐시 구조와 정책​

  • 캐시 메모리: 캐시 메모리(Cache Memory) (137M)
  • 매핑 기법(직접/연관/집합연관)
  • 캐시 쓰기 정책: 캐시 쓰기 정책(Write Policy) (137M)
  • 캐시 일관성: 캐시 일관성(Cache Coherence) (137M)
  • 캐시 교체 알고리즘(LRU, FIFO)

3.3 주기억장치​

3.3.1 메모리 구성 기술​

  • 메모리 인터리빙: 메모리 인터리빙(Memory Interleaving) (128M)
  • HBM: 고대역 초고속 메모리(High Bandwidth Memory) (134M)
  • CXL: CXL(Compute Express Link) (136M)

3.3.2 메모리 반도체​

  • 메모리/비메모리 반도체: 메모리 반도체와 비메모리 반도체 비교 (129M)
  • DRAM/SRAM
  • 플래시 메모리(NAND/NOR)

4. 입출력과 저장장치​

4.1 입출력 방식​

4.1.1 I/O 제어 방식​

  • 프로그램 I/O(Programmed I/O)
  • 인터럽트 구동 I/O(Interrupt-driven I/O)
  • DMA(Direct Memory Access)
  • 채널(Channel) I/O

4.2 디스크와 RAID​

4.2.1 저장장치와 배열​

  • HDD/SSD
  • RAID: RAID 0, 1, 5, 6 (120M)

4.3 스토리지 아키텍처​

4.3.1 스토리지 연결 구조​

  • DAS/NAS/SAN: DAS(Direct Attached Storage), NAS(Network Attached Storage), SAN(Storage Area Network) (122M)
  • 스토리지 유형별 접근 방식: 블록 스토리지, 파일 스토리지, 오브젝트 스토리지의 데이터 접근 방식 (132M)
  • 스토리지 가상화: 스토리지 가상화(Storage Virtualization) 유형별 특징 (134M)

5. 병렬처리와 고성능 컴퓨팅​

5.1 병렬처리 구조​

5.1.1 병렬 컴퓨터 분류​

  • 플린(Flynn)의 분류(SISD/SIMD/MISD/MIMD)
  • 멀티코어/멀티프로세서
  • SMP/NUMA

5.1.2 상호연결망​

  • 상호연결망: 상호연결망(Interconnection Network)의 개념과 종류 (125M)
  • 토러스 구조: 토러스(Torus) 구조 (125M)
  • 메시(Mesh), 하이퍼큐브(Hypercube)

5.2 GPU와 AI 가속기​

5.2.1 GPU 컴퓨팅​

  • GPGPU: GPGPU(General Purpose Graphics Processing Units) (111M), GPGPU (120M)
  • 멀티 GPU: 멀티 GPU 기술의 개념과 장점 (134M)

5.2.2 AI 가속기​

  • GPU/TPU: GPU(Graphics Processing Unit)와 TPU(Tensor Processing Unit) (138M)
  • NPU(Neural Processing Unit)

6. 차세대·특수 컴퓨팅 하드웨어​

6.1 뉴로모픽·양자 컴퓨팅​

6.1.1 신개념 프로세서​

  • 뉴로모픽 칩: 뉴로모픽 칩(Neuromorphic Chip) (128M)
  • 큐비트: 큐비트(Qubit) (128M)

6.2 저전력 컴퓨팅​

6.2.1 에너지 제약 컴퓨팅​

  • 인터미턴트 컴퓨팅: 인터미턴트 컴퓨팅(Intermittent Computing) (134M)

6.3 하드웨어 보안 모듈​

6.3.1 신뢰 하드웨어​

  • TPM: TPM(Trusted Platform Module) (132M)
  • HSM(Hardware Security Module)
  • TEE(Trusted Execution Environment)
