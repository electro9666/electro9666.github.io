01. 자료구조

1. 자료구조 개요​

1.1 자료구조 분류​

1.1.1 선형/비선형 구조​

  • 추상 자료형(ADT)
  • 선형 자료구조: 선형 자료구조 (125M), 선형 구조(Linear Structure)의 개념 및 유형 (131M), 선형 자료 구조인 스택, 큐, 리스트 (132M)
  • 비선형 자료구조: 비선형 자료구조 (125M), 비선형 구조(Non-Linear Structure)의 개념 및 유형 (131M)

2. 선형 자료구조​

2.1 배열과 리스트​

2.1.1 배열(Array)​

  • 배열(Array)
  • 희소 행렬(Sparse Matrix)

2.1.2 연결 리스트(Linked List)​

  • 단순 연결 리스트(Singly Linked List)
  • 이중 연결 리스트(Doubly Linked List)
  • 원형 연결 리스트(Circular Linked List)
  • 다중 연결 리스트: 다중연결리스트(Multi-linked List) (114M)
  • 리스트 입출력 원리: 리스트의 자료 입출력 원리 (132M)

2.2 스택(Stack)​

2.2.1 스택 연산​

  • 스택 개념: 스택(Stack)의 개념 (122M), 스택 (132M)
  • Push/Pop, 스택 포인터(Top): 스택의 작동 알고리즘 (122M)
  • Overflow/Underflow: Overflow 처리, Underflow 처리 (122M)

2.2.2 스택 응용​

  • 수식 표기법(중위/후위 표기)
  • 재귀 호출과 스택

2.3 큐(Queue)​

2.3.1 큐 유형​

  • 선형 큐: 큐 (132M)
  • 원형 큐: 배열을 이용하여 큐(Queue)를 구성할 때의 단점과 해결 방법 (125M)
  • 덱(Deque)
  • 우선순위 큐: 우선순위 큐(Priority Queue) (114M)

2.3.2 큐 응용​

  • 대기행렬이론: 대기행렬이론(Queuing Theory) (116M), 대기행렬시스템(Queue System) (120M)
  • 메시지 큐잉: 메시지큐잉 (123M)

3. 비선형 자료구조​

3.1 트리(Tree)​

3.1.1 트리 기초​

  • 트리 용어(노드, 차수, 깊이, 레벨)
  • 이진 트리(Binary Tree)
  • 트리 순회(전위/중위/후위)

3.1.2 탐색 트리​

  • 이진 탐색 트리: 이진 탐색 트리 (137M), 이진 탐색 트리와 라우팅 테이블 탐색 알고리즘의 상관관계 (139M)
  • AVL 트리
  • 레드-블랙 트리
  • B-트리/B+트리

3.1.3 힙(Heap)​

  • Max-heap/Min-heap: Max-heap과 Min-heap (124M)

3.1.4 특수 트리​

  • 트라이(Trie)
  • 머클 트리: 머클트리(Merkle Tree) (119M)

3.2 그래프(Graph)​

3.2.1 그래프 기초​

  • 그래프 표현(인접행렬, 인접리스트)
  • 방향/무방향 그래프
  • 방향성 비순환 그래프: 방향성 비순환 그래프(Directed Acyclic Graph) (125M)

3.2.2 그래프 탐색과 정렬​

  • 깊이 우선 탐색(DFS)
  • 너비 우선 탐색(BFS)
  • 위상 정렬: 위상정렬(Topology Sort) (125M)

3.2.3 최소 신장 트리(MST)​

  • MST: MST(Minimum Spanning Tree) (117M)
  • 크루스칼 알고리즘: 크루스칼(Kruskal) 알고리즘 (117M)
  • 프림 알고리즘: 프림(Prim) 알고리즘 (117M)

3.2.4 최단 경로​

  • 최단경로 알고리즘: 최단경로 알고리즘의 유형 4가지 (123M)
  • 다익스트라(Dijkstra) 알고리즘
  • 벨만-포드(Bellman-Ford) 알고리즘
  • 플로이드-워셜(Floyd-Warshall) 알고리즘

4. 해싱(Hashing)​

4.1 해시 함수​

4.1.1 해시 함수 개념​

  • 해시 함수/해시값: 해쉬 알고리즘(Hash Algorithm) (116M), 해시값(HashValue)과 해시함수의 구분, 종류, 용도 (118M), 해쉬 알고리즘(Hash Algorithm)의 특성 및 종류 (120M)

4.2 충돌 해결​

4.2.1 충돌 해결 기법​

  • 체이닝(Chaining)
  • 개방 주소법(Open Addressing)
  • 확장성 해싱: 확장성 해싱(Extendible Hashing)기법 (135M), 충돌회피 기법 (135M)

5. 탐색과 색인 구조​

5.1 탐색 알고리즘​

5.1.1 기본 탐색​

  • 순차 탐색(Sequential Search)
  • 이진 탐색(Binary Search)
  • 보간 탐색(Interpolation Search)

5.2 다차원 색인 구조​

5.2.1 공간 색인​

  • 다차원 색인구조: 다차원 색인구조(Multidimensional Index Structure) 3가지 (124M), 다차원 색인구조(Multidimensional Index Structure)의 개념, 유형, 활용 사례 (134M)
  • MBR: MBR(Minimum Bounding Region) (111M)
  • R-트리 계열: R트리, R+트리, R*트리 (111M)
  • 힐버트 R-트리: 힐버트(Hilbert) R-tree (116M)
  • K-D 트리

5.2.2 벡터 검색 색인​

  • HNSW: HNSW(Hierarchical Navigable Small World) (137M)
  • IVF: IVF(Inverted File Index) (137M)

6. 정렬(Sorting)​

6.1 비교 기반 정렬​

6.1.1 단순 정렬​

  • 버블 정렬: 버블 정렬 (131M)
  • 삽입 정렬: 삽입 정렬 (131M)
  • 선택 정렬(Selection Sort)

6.1.2 고급 정렬​

  • 퀵 정렬: 퀵 정렬 (131M)
  • 병합 정렬(Merge Sort)
  • 힙 정렬(Heap Sort)
  • 트리 정렬: 트리정렬(Tree Sort) (129M)
  • 셸 정렬(Shell Sort)

6.2 비비교 정렬​

6.2.1 분포 기반 정렬​

  • 기수 정렬(Radix Sort)
  • 계수 정렬(Counting Sort)
  • 버킷 정렬(Bucket Sort)

7. 알고리즘​

7.1 알고리즘 복잡도​

7.1.1 복잡도 분석​

  • 시간 복잡도: 알고리즘의 복잡도 (134M)
  • O-표기법: O-Notation의 개념과 유형 및 유형별 연산시간의 차이 (134M)
  • 공간 복잡도
  • P/NP 문제

7.2 알고리즘 설계 기법​

7.2.1 주요 설계 기법​

  • 분할 정복(Divide and Conquer)
  • 동적 계획법(Dynamic Programming)
  • 탐욕 알고리즘(Greedy Algorithm)
  • 백트래킹(Backtracking)
  • 분기 한정(Branch and Bound)

7.3 탐색 기반 문제 해결​

7.3.1 상태 공간 탐색​

  • 균일비용탐색: 균일비용탐색(Uniform Cost Search) (114M)
  • A* 알고리즘: A* 알고리즘 (114M)
  • 몬테카를로 트리 탐색: MCTS(Monte Carlo Tree Search) (113M)

7.4 최적화 알고리즘​

7.4.1 진화 연산​

  • 유전 알고리즘: 유전 알고리즘(Genetic algorithm) (113M), 유전 알고리즘(Genetic Algorithm)의 개념 및 절차 (137M)
  • 룰렛 휠 선택: 룰렛 휠 선택(roulett wheel selection) (113M)

7.4.2 메타휴리스틱​

  • 메타휴리스틱스: 메타휴리스틱스(Metaheuristics) (126M)
  • 담금질 기법(Simulated Annealing)
  • 타부 탐색(Tabu Search)

7.5 계산 이론​

7.5.1 오토마타와 형식 언어​

  • 유한 오토마타: 유한 오토마타 (110M), 유한오토마타 (120M)
  • 정규식: 정규식(Regular Expression) (120M)
  • 튜링 머신(Turing Machine)
