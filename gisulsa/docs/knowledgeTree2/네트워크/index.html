04. 네트워크

1. 네트워크 기초​

1.1 네트워크 참조모델​

1.1.1 OSI 7계층​

  • OSI 7 Layer: OSI 7 Layer, OSI 7 Layer의 각 계층과 특징
  • 계층별 캡슐화/역캡슐화
  • 표현계층 인코딩: ASN.1(Abstract Syntax Notation One)

1.1.2 TCP/IP 모델​

  • TCP/IP 4계층 모델
  • 표준 프로토콜: 표준 프로토콜
  • 프로토콜 설계: 프로토콜 설계 시 고려 사항

1.2 통신 이론 및 교환방식​

1.2.1 정보 이론​

  • 정보이론: 정보이론(Information Theory)
  • 샤논의 정리: 샤논(Shannon)의 정리, 샤논-하틀리(shannon-Hartley)의 정리
  • 채널 용량, 대역폭

1.2.2 교환 방식​

  • 회선 교환(Circuit Switching)
  • 패킷 교환(Packet Switching): 교환방식
  • 프레임 릴레이: 프레임릴레이(Frame Relay)
  • ATM(Asynchronous Transfer Mode)

1.3 오류 제어 및 흐름 제어​

1.3.1 오류 제어​

  • 오류 제어: 오류 제어, 오류 제어(Error Control) 기술
  • 오류 검출: 오류 검출(Error Detection), CRC(Cyclic Redundancy Check)
  • 오류 정정: 오류 정정(Error Correction)
  • 해밍 코드(Hamming Code)
  • ARQ: 정지-대기(Stop-and-Wait) ARQ, Go-Back-N ARQ
  • Selective Repeat ARQ

1.3.2 흐름 제어​

  • Flow Control
  • Sliding Window: 슬라이딩 윈도우(Sliding Window) 기법
  • Stop and Wait

2. 전송 계층​

2.1 TCP​

2.1.1 연결 관리​

  • Three-way Handshake: 3-way handshake
  • Four-way Handshake: 4-way handshake
  • TCP 상태 천이(State Transition)

2.1.2 혼잡 제어​

  • Congestion Control: TCP 혼잡제어 메커니즘, 혼잡 제어
  • 혼잡 윈도우: 혼잡 윈도우 크기
  • 혼잡상황 감지/제어: 혼잡상황 감지, 혼잡상황 제어
  • Slow Start, AIMD
  • Fast Retransmit, Fast Recovery

2.2 UDP 및 기타 전송 프로토콜​

2.2.1 전송 프로토콜​

  • UDP(User Datagram Protocol)
  • SCTP: SCTP(Stream Control Transmission Protocol)
  • QUIC

2.3 소켓 통신​

2.3.1 Socket​

  • 소켓 통신: Socket 통신방식, 소켓(Socket) 통신
  • TCP Socket: TCP Socket, TCP 소켓
  • Web Socket: Web Socket, Web 소켓
  • Non-blocking I/O: 네트워크에서의 Non-blocking I/O

3. 응용 계층 프로토콜​

3.1 웹 프로토콜​

3.1.1 HTTP/HTTPS​

  • HTTP: HTTP의 취약점, HTTP 통신 방식
  • HTTPS: HTTPS의 특징
  • HTTP/2, HTTP/3

3.1.2 TLS​

  • TLS: TLS(Transport Layer Security)
  • TLS Handshake: 핸드셰이크(Handshake) 과정
  • TLS 1.3: TLS 1.2 보안 취약점과 TLS 1.3 개선 사항

3.1.3 실시간 웹 통신​

  • WebRTC: WebRTC(Web Real-Time Communication)

3.2 파일 전송 및 디렉토리 서비스​

3.2.1 파일 전송 프로토콜​

  • FTP: FTP(File Transfer Protocol)
  • FTPS: FTPS(FTP Secure)
  • SFTP: SFTP(SSH FTP)

3.2.2 디렉토리 서비스​

  • LDAP: 경량 디렉토리 액세스 프로토콜(LDAP: Lightweight Directory Access Protocol)

3.3 이름 해석 및 기타 프로토콜​

3.3.1 DNS​

  • DNS(Domain Name System)
  • DNSSEC
  • DNS Record(A, CNAME, MX)

3.3.2 기타 응용 프로토콜​

  • SMTP
  • SNMP
  • DHCP

4. IP 주소체계 및 라우팅​

4.1 IP 주소체계​

4.1.1 IPv4/IPv6​

  • IPv4 주소 클래스
  • IPv6 전환 기술(Dual Stack, Tunneling)
  • NAT/PAT

4.1.2 서브네팅​

  • 서브네팅: 서브네팅(subnetting), 서브네팅(Subnetting)
  • 슈퍼네팅: 수퍼네팅(supernetting), 슈퍼네팅(Supernetting)
  • 서브넷 마스크: 서브넷 마스크
  • VLSM: VLSM(Variable Length Subnet Mask)
  • CIDR(Classless Inter-Domain Routing)

4.2 라우팅​

4.2.1 라우팅 프로토콜​

  • IGP: IGP (Interior Gateway Protocol)
  • EGP: EGP (Exterior Gateway Protocol)
  • 거리벡터 라우팅: 거리벡터 라우팅(Distance Vector Rounting)
  • 링크 스테이트 라우팅(Link State Routing)
  • RIP: RIP(Routing Information Protocol)
  • OSPF: OSPF(Open Shortest Path First)
  • BGP(Border Gateway Protocol)

4.2.2 라우팅 테이블​

  • 라우팅 테이블 탐색: 라우팅 테이블 탐색 알고리즘
  • Longest Prefix Match
  • Static/Dynamic Routing

4.3 멀티캐스트​

4.3.1 Multicast​

  • Unicast/Broadcast/Multicast
  • IGMP(Internet Group Management Protocol)
  • PIM(Protocol Independent Multicast)

5. 네트워크 장비 및 네트워크 가상화​

5.1 스위칭 및 부하분산​

5.1.1 스위칭​

  • L2/L3 스위치
  • STP(Spanning Tree Protocol)
  • ARP(Address Resolution Protocol)

5.1.2 로드밸런싱 및 프록시​

  • 로드밸런싱: 로드밸런싱
  • L4/L7 로드밸런서
  • 리버스 프록시: 리버스 프록시(Reverse Proxy), 리버스 프록시, 리버스 프록시(Reverse Proxy)의 개념, 동작원리, 설정방법
  • CDN: 콘텐츠 전송 네트워크(Content Delivery Network)

5.2 가상 네트워크​

5.2.1 LAN 가상화​

  • VLAN: VLAN(Virtual LAN)
  • VXLAN: VXLAN(Virtual eXtensible LAN)

5.2.2 VPN 및 오버레이 네트워크​

  • VPN: VPN(Virtual Private Network), VPN(Virtual Private Network), VPN의 개념 및 특징
  • IPSec VPN: IPSec(Internet Protocol Security) VPN
  • SSL VPN: SSL(Secure Socket Layer) VPN
  • Tor: 익명 네트워크 TOR(The Onion Routing), Tor

5.3 SDN/NFV​

5.3.1 SDN​

  • SDN: 소프트웨어 정의 네트워크(SDN)
  • 제어 평면/데이터 평면: SDN 제어 평면
  • OpenFlow: 오픈플로우(OpenFlow) 프로토콜

5.3.2 NFV 및 지능형 네트워크​

  • NFV: NFV(Network Function Virtualization)
  • SD-WAN
  • IBN: IBN(Intent-Based Networking)

6. 무선 및 이동통신​

6.1 무선 LAN 및 근거리 무선통신​

6.1.1 무선 LAN​

  • Wi-Fi 7: Wi-Fi 7
  • IEEE 802.11bn: IEEE 802.11bn

6.1.2 근거리 무선통신​

  • NFC: NFC(Near Field Communication)
  • Bluetooth/BLE

6.1.3 무선 전송 기술​

  • SDR: SDR(Software Defined Radio)
  • FSO: 모바일 FSO(Free Space Optics) 통신
  • 다중접속 기술: 비직교 다중접속(NOMA, Non-Orthogonal Multiple Access)
  • OFDMA, MIMO

6.2 이동통신​

6.2.1 5G​

  • 5G: 5G 네트워크의 기술석 특징
  • 네트워크 슬라이싱: 5G 네트워크 슬라이싱(5G Nerwork Slicing)
  • 5G 특화망: 5G 특화망(지역 5G), 5G 특화망
  • 모바일 엣지 컴퓨팅: 모바일 엣지 컴퓨팅(Mobile Edge Computing)
  • eMBB, URLLC, mMTC

6.2.2 6G​

  • 6G: 6G 이동통신, 6G 이동통신기술
  • 위성-지상 통합망: 위성-상공-지상 통합형 무선 네트워크(Satelite-Aerial-Terrestrial Integrated Network, SATIN)
  • AI-Native Network: AI-Native Network
  • AI-RAN: AI-RAN
  • 네트워크 자율 관리: 자율 최적화, 디지털트윈 기반 네트워크 관리

6.2.3 이동통신 응용​

  • C-V2X: 차량∙사물 셀룰러 통신(Cellular Vehicle to Everything)
  • 실내 측위: IPS(Indoor Positioning System)

7. IoT 및 특수 목적 네트워크​

7.1 IoT 네트워크 프로토콜​

7.1.1 IoT 경량 프로토콜​

  • MQTT: MQTT, MQTT
  • CoAP: CoAP, CoAP
  • XMPP: XMPP
  • LwM2M: LwM2M

7.1.2 IoT 광역 네트워크​

  • LPWA: LPWA(Low Power Wide Area)
  • LoRa, NB-IoT
  • IoT 디바이스 식별체계: 객체식별자 기반 사물인터넷 디바이스 식별체계(TTAK.KO-06.0365/R1)

7.1.3 산업용 프로토콜​

  • MODBUS: MODBUS 프로토콜
  • OPC-UA

7.2 무선 센서 및 애드혹 네트워크​

7.2.1 무선 센서 네트워크​

  • WSN: 무선센서네트워크(WSN)
  • Itinerary Routing: 무선 센서 네트워크 구성방법 중 Itinerary Routing

7.2.2 애드혹 네트워크​

  • Ad-hoc: 애드혹(Ad-hoc) 네트워크
  • 경로제어 방식: 리액티브(Reactive)형 방법과 프로액티브(Proactive)방법

7.3 P2P 네트워크​

7.3.1 P2P​

  • P2P: P2P 통신
  • Hybrid P2P: 하이브리드 P2P(Hybrid P2P) 방식
  • Pure P2P: 퓨어 P2P(Pure P2P) 방식

8. 네트워크 성능 및 QoS​

8.1 QoS​

8.1.1 QoS 모델​

  • QoS: QoS(Quality of Service)
  • DiffServ: DiffServ
  • IntServ: IntServ
  • 큐잉 기법: WFQ(Weighted Fair Queuing)
  • Traffic Shaping/Policing

8.2 성능 분석​

8.2.1 대기행렬 이론​

  • 대기행렬이론: 대기행렬이론(Queuing Theory), 대기행렬시스템(Queue System)

8.2.2 성능 지표 및 최적화​

  • Throughput, Latency, Jitter, Packet Loss
  • 웹 성능 최적화: 웹 성능저하 요인, 웹 최적화 방안
  • Sprite: 스프라이트(Sprite)

8.3 데이터센터 네트워크​

8.3.1 DCN​

  • DCI: DCI(Data Center Interconnect) 기술
  • 저지연 기술: 저지연 기술과 스케일링 확보 기술
  • Spine-Leaf 구조

9.1.1 망중립성 정책​
