11. 정보보안

1. 정보보안 관리체계​

1.1 정보보안 개요​

1.1.1 정보보안 개념과 보안 위협​

  • 기밀성/무결성/가용성(CIA Triad)
  • 보안 공격 유형(가로채기/차단/변조/위조): 변조(Modification)와 위조(Fabrication) (127M)
  • 쉐도우 IT: 쉐도우 IT(Shadow IT) (114M)
  • 사이버전: 사이버전(Cyber Warfare) (111M)
  • 사이버 범죄: 컴퓨터(사이버) 범죄의 정의와 특징, 종류와 그 대응책 (123M)

1.1.2 정보보호 거버넌스와 조직​

  • 정보보호 거버넌스: 정보보호 거버넌스의 6대 원리, 핵심 프로세스 및 주요 구성요소 (114M)
  • 정보보호 정책: 정보보호 정책의 개념 (132M)
  • Security Action Cycle: 정보보호 시점별 보안 활동(Security Action Cycle) (132M)
  • 정보보안 전문가: 정보보안 전문가의 역할과 역량 (132M)
  • CISO: CISO(Chief Information Security Officer)의 자격요건과 겸직 여부 (121M)
  • ESG와 정보보호: 정보보호 시스템 구축 측면에서의 ESG (129M), 개인정보 침해 및 구제 측면에서의 ESG (129M)

1.1.3 위험관리와 컴플라이언스​

  • 위험 식별/분석/평가/대응(수용, 회피, 전가, 감소)
  • ISO 31000: ISO 31000 (132M)
  • IT 컴플라이언스: IT 컴플라이언스(Compliance)의 주요 요구사항 (116M)

1.2 보안 인증제도와 표준​

1.2.1 정보보호 관리체계 인증​

  • ISMS: 정보보호 인증제도인 ISMS, G-ISMS, PIPL, PIMS (110M), ISMS(Information Security Management System) (119M), 정보보호 관리체계(Information Security Management System)의 개념과 관리과정 (124M), ISMS 의무 대상 기준 (131M), 정보보호 관리체계(ISMS)의 인증 영역과 법적 근거 (138M)
  • ISMS-P: ISMP-P 인증기준과 주요 개정 사항 (119M), ISMS와 ISMS-P 차이점 (131M), ISMS-P 간편인증 제도 (138M)
  • ISO/IEC 27001, ISO/IEC 27002
  • NIST CSF

1.2.2 제품·시스템 보안 인증​

  • CC 인증: CC(Common Criteria) (136M)
  • 정보보호 제품 신속 확인제도: 정보보호 제품 신속 확인제도 (129M)
  • 암호모듈 검증: FIPS(Federal Information Processing Standard) 140-2 (132M)
  • CSAP: 클라우드 컴퓨팅서비스에 대한 공공기관의 보안인증제도 (120M), 클라우드 서비스 보안인증(CSAP) 절차 (128M)
  • ISO/IEC 27017: ISO/IEC 27017(클라우드 서비스 정보보호 통제) (122M)

2. 암호기술​

2.1 대칭키 암호​

2.1.1 대칭키 암호 알고리즘​

  • 대칭키/공개키 비교: 대칭 암호화와 비대칭 암호화 (132M)
  • 블록 암호: 블록 암호화 알고리즘 (130M)
  • DES, 3DES, AES
  • SEED, ARIA, LEA
  • 스트림 암호(RC4, ChaCha20)

2.1.2 블록 암호 운용 모드​

  • ECB: ECB(Electronic CodeBook) 모드 (127M)
  • CBC: CBC(Cipher Block Chaining) 모드 (127M)
  • CFB: CFB(Cipher FeedBack) 모드 (127M)
  • OFB: OFB(Output FeedBack) 모드 (127M)
  • CTR

2.2 공개키 암호​

2.2.1 공개키 암호 알고리즘​

  • RSA: RSA(Rivest-Shamir-Adleman)알고리즘 (126M)
  • ElGamal: 엘가멜(ElGamal) (111M)
  • ECC: 타원곡선 암호(ECC, Elliptic Curve Cryptography) (136M)
  • Diffie-Hellman 키 교환

2.2.2 공개키 응용​

  • 전자봉투: 전자봉투 생성절차와 개봉절차 (133M)
  • 하이브리드 암호 시스템

2.3 해시와 메시지 인증​

2.3.1 해시 함수​

  • 해시 알고리즘: 해쉬 알고리즘(Hash Algorithm) (116M), 해시값(HashValue)과 해시함수의 구분, 종류, 용도 (118M), 해쉬 알고리즘(Hash Algorithm)의 특성 및 종류 (120M), 단방향 해시 함수(Hash Function) (138M)
  • SHA-2, SHA-3
  • 레인보우 테이블: Rainbow Table (138M)
  • 솔트/키 스트레칭: 해시 솔트(Hash Salt) 와 키 스트레칭(Key Stretching) (138M)
  • 머클트리: 머클트리(Merkle Tree) (119M)

2.3.2 메시지 인증 코드​

  • MAC: 메시지 인증 코드(Message Authentication Code) (127M)
  • HMAC: HMAC(Hash-based Message Authentication Code) (117M)

2.4 전자서명과 PKI​

2.4.1 전자서명​

  • 전자서명: 전자서명(Digital Signature) (116M)
  • DSA: DSA(Digital Signature Algorithm) (126M)
  • 전자서명법 개정: 공인인증서와 사설인증서의 구별을 없애는 전자서명법 (122M)
  • 공인인증서: 기존 공인인증서의 적용기술 및 문제점 (114M)

2.4.2 PKI​

  • 인증서(X.509), CA, RA
  • CRL, OCSP

2.5 차세대 암호기술​

2.5.1 양자암호​

  • 양자암호: 양자 암호(Quantum Cryptography) (114M)
  • 양자암호통신: 양자암호통신 (117M), 양자암호통신의 암호키 분배방식 (128M)
  • QKD: 양자키분배(QKD : Quantum Key Distribution) (135M)
  • 양자내성암호: 포스트 양자 암호(Post-Quantum Cryptography) (125M), 양자내성암호(PQC : Post Quantum Cryptography) (135M)

2.5.2 프라이버시 보존 암호​

  • 동형암호: 동형암호(Homomorphic Encryption) (125M), 동형암호(Homomorphic Encryption)의 동작원리와 유형 (133M)
  • 다자간 계산: 다자간 계산(Multi-Party Computation; MPC) (133M)
  • 영지식 증명(Zero-Knowledge Proof)

2.5.3 암호 분석​

  • 암호 공격: 암호문 공격(Ciphertext Attack) (137M)
  • 알려진 평문 공격, 선택 평문 공격

3. 인증 및 접근통제​

3.1 사용자 인증​

3.1.1 인증 개념과 인증 요소​

  • 식별과 인증: 식별(Identification)과 인증(Authentication) (128M)
  • 인증 요소: 정보시스템의 사용자 인증 요소(User Authentication Factor) (120M), 인증 방식에 따른 4가지 유형 및 유형별 특징 (128M)
  • Challenge-Response: 암호화에서의 Challenge-response 방식 (113M)
  • 패스워드 관리: 비밀번호 관리 시스템 (113M)
  • MFA, OTP

3.1.2 생체인증과 비대면 인증​

  • 비대면 인증: 비대면 보안기술 (110M)
  • 바이오정보 보호: 바이오정보 분산관리 (120M)
  • 안면인식: 안면인식 결제 서비스 (138M)
  • 무자각 지속 인증: 무자각 지속 인증(Implicit Continuous Authentication) (120M)
  • 고객확인: 고객확인 절차(KYC : Know Your Customer) (122M)

3.1.3 FIDO​

  • FIDO: FIDO(Fast Identity Online) 2.0 (113M), FIDO(Fast Identity Online) 1.0과 FIDO 2.0 (116M), 패스워드 없는 인증기술인 FIDO(Fast Identity Online) (118M)
  • UAF/U2F: 표준 프로토콜인 UAF와 U2F (118M)
  • WebAuthn, CTAP

3.1.4 인증 프로토콜과 토큰​

  • JWT: JASON Web Token (125M)
  • OAuth 2.0, OpenID Connect, SAML, SSO
  • LDAP: 경량 디렉토리 액세스 프로토콜(LDAP: Lightweight Directory Access Protocol)의 인증 흐름 (129M)
  • PAM: Linux PAM(Pluggable Authentication Modules) (113M)
  • Kerberos

3.2 디지털 신원​

3.2.1 분산 신원증명​

  • DID: DID(Decentralized Identity) (119M), 분산 ID(Decentralized Identity) (122M)
  • GADI: GADI(Global Architecture for Digital Identity) (123M)
  • 모바일 신분증: 모바일 신분증 (121M)
  • 사설인증서: 인터넷전문은행의 사설 인증 방법 (114M), 사설인증서의 종류 및 전자서명 시장의 발전방향 (122M)
  • 블록체인 인증: 블록체인 방식의 인증 방법 (114M)

3.3 접근통제​

3.3.1 접근통제 정책과 메커니즘​

  • 접근통제 개념: 접근제어에 대하여 그개념과정책, 절차, 그리고 이를 구현하는 메커니즘 (133M), 접근 제어(Access Control)의 통제정책 (129M)
  • DAC, MAC, RBAC, ABAC
  • ACL, Capability

3.3.2 접근통제 보안 모델​

  • BLP 모델: 벨 라파듈라(BLP) 모델 (127M)
  • Biba 모델: 비바(BIBA) 모델 (127M)
  • Clark-Wilson 모델: Clark and Wilson 모델 (127M)
  • 만리장성(Chinese Wall) 모델

4. 네트워크 보안​

4.1 네트워크 보안 시스템​

4.1.1 침입 차단·탐지·방지​

  • 방화벽(Firewall)
  • IDS/IPS: 침입탐지시스템(Intrusion Detection System, IDS)과 침입방지시스템(Intrusion Prevention System, IPS) (124M), IPS, 웹 방화벽, L3 스위치, 방화벽, L4 스위치는 이중화로 구성 (121M)
  • WAF(Web Application Firewall)
  • NAC: NAC(Network Access Control) (124M)
  • CDR: CDR(Content Disarm & Reconstruction) (121M)
  • UTM

4.1.2 망 분리와 망 보안체계​

  • 망 분리: 업무용 망을 인터넷 망에서 분리 (113M)
  • DMZ: DMZ(DeMilitarized Zone)존과 Internal Network은 망 분리 (121M)
  • N2SF: 국가 망 보안체계(National Network Security Framework, N2SF) (137M)

4.2 보안 통신 프로토콜​

4.2.1 전송 보안​

  • HTTPS: HTTP의 취약점을 설명하고, 그 대안으로 사용하는 HTTPS의 특징 (113M)
  • SSL/TLS: TLS(Transport Layer Security) 1.2에대한 취약점이 발견되어 TLS 1.3 사용을 권고 (136M)
  • 보안 파일전송: FTP(File Transfer Protocol), FTPS(FTP Secure) 및 SFTP(SSH FTP) (116M)
  • SSH

4.2.2 VPN과 익명 네트워크​

  • VPN: VPN(Virtual Private Network)과 Tor (126M), VPN(Virtual Private Network)의 개념 및 특징 (133M)
  • IPSec VPN/SSL VPN: IPSec(Internet Protocol Security) VPN과 SSL(Secure Socket Layer) VPN (133M)
  • Tor: 익명 네트워크 TOR(The Onion Routing) (113M), VPN(Virtual Private Network)과 Tor (126M)

4.3 네트워크 공격과 대응​

4.3.1 네트워크 공격​

  • 네트워크 스캐닝: 네트워크 스캐닝 (126M)
  • 스푸핑(Spoofing), 스니핑(Sniffing)
  • 중간자 공격(MITM), 세션 하이재킹

4.3.2 DDoS 공격과 대응​

  • DDoS: 디도스 공격(DDoS, Distributed Denial of Service Attack) (116M)
  • 스크러빙 센터: 스크러빙 센터(Scrubbing Center) (116M)
  • CDN 기반 대응: 콘텐츠 전송 네트워크(Content Delivery Network) (116M)
  • DDoS 사이버대피소: DDoS 사이버대피소 (128M)

5. 시스템 및 물리 보안​

5.1 시스템 보안​

5.1.1 서버·OS 보안​

  • Unix 계정 보안: Unix 파일 시스템의 구조 및 /etc/passwd 파일의 구성 (116M)
  • 시스템 하드닝, 패치 관리

5.1.2 하드웨어 보안​

  • CPU 취약점: CPU 아키텍처의 보안 취약점이 멜트다운(Meltdown) (114M), CPU 보안 취약점에서의 스펙터(Spectre) (116M)
  • TPM: TPM(Trusted Platform Module) (132M)
  • 시큐어 부트(Secure Boot)

5.1.3 엔드포인트 보안​

  • 안티바이러스, EDR, XDR
  • DLP(Data Loss Prevention)

5.2 물리 보안과 영상 보안​

5.2.1 물리적 공격 대응​

  • EMP 공격: EMP공격(ElectroMagnetic Pulse attack) (125M), HEMP(High atltitude EMP)의 원리 (125M)

5.2.2 영상 보안​

  • 영상감시시스템: 영상감시시스템(Video Surveillance System) (116M)
  • 지능형 CCTV: 지능형 CCTV 스마트 관제 (121M)

6. 애플리케이션 보안​

6.1 소프트웨어 개발보안​

6.1.1 Secure SDLC​

  • Secure SDLC: 보안 소프트웨어 개발 생명주기(Secure SDLC) 방법론 (121M)
  • SW 보안약점: 소프트웨어 보안약점들을 유형별로 열거하고, 대표적인 웹 개발보안 공격방지 방법 (114M)
  • TOCTOU: 검사시점과 사용시점(TOCTOU) (125M)
  • 시큐어 코딩: 보안 위험성이 없는 안전한 코드로 수정 (121M)
  • 위협 모델링(Threat Modeling)

6.1.2 DevSecOps와 보안 자동화​

  • DevSecOps: CI/CD(Continuous Integration/Continuous Delivery or Continuous Deployment)파이프라인에서 DevSecOps 적용방안 (135M)
  • 보안 품질·자동화: 소프트웨어 보안 품질의 정의와 중요성 (136M), 보안 품질 확보를 위한 자동화 기술과 도구 (136M)
  • SAST, DAST, IAST

6.2 웹·API 보안​

6.2.1 웹 공격과 대응​

  • 인젝션: OWASP에서 발표한 보안 위협 인젝션(Injection)의 개념과 대응 방안 (124M)
  • SQL Injection, XSS, CSRF
  • 포맷 스트링 공격: 포멧 스트링 공격(Format String Attack) (116M)
  • OWASP Top 10

6.2.2 API 보안​

  • Open API 보안: 개방형 API(Open API)의 취약점 및 대응 방안 (134M)
  • API Gateway, Rate Limiting

6.3 소프트웨어 공급망 보안​

6.3.1 공급망 보안​

  • 공급망 보안: 공급망 보안(Supply Chain Security) (136M)
  • SBOM: SBOM(Software Bill of Material) (131M), SBOM(Software Bill of Materials) (134M)
  • 오픈소스 취약점: 오픈소스 소프트웨어 취약점 (134M)

7. 악성코드와 공격기법​

7.1 악성코드​

7.1.1 악성코드 유형​

  • 랜섬웨어: 랜섬웨어 공격에 대하여 사전, 사후적 대응방안 (113M), 랜섬웨어(Ransomware)와 RaaS(Ransomeware as a Service) (128M), 랜섬웨어와 RaaS(Ransomware as a Service)의 개념 및 비교 (138M)
  • 크라임웨어: 크라임웨어(Crimeware) (113M)
  • 인포스틸러: 인포스틸러(InfoStealer) (129M)
  • 스턱스넷: 스턱스넷(Stuxnet) (110M)
  • 백도어: BPFdoor(Berkeley Packet Filter door) 악성코드 (137M)
  • 봇넷: 미라이 봇넷(Mirai Botnet) (126M)
  • 트로이목마, 웜, 루트킷

7.2 공격 기법​

7.2.1 지능형 공격​

  • APT: 지능형 지속공격(APT, Advanced Persistent Threat) (116M)
  • 사이버 킬 체인: 사이버 킬 체인(Cyber Kill Chain) (111M)
  • TTPs: TTPs(Tactics, Techniques and Procedures) (138M)
  • MITRE ATT&CK
  • 공격 표면/공격 벡터: 공격 표면(Attack Surface)과 공격 벡터(Attack Vector) (138M)
  • 측면 이동: 측면 이동(Lateral Movement)의 단계별 메커니즘과 주요 기법 (138M)
  • 크리덴셜 스터핑: 크리덴셜 스터핑(Credential stuffing) (131M)

7.2.2 사회공학 공격​

  • 사회공학: 보안학적 측면에서의 사회공학(Social Engineering) (114M)
  • 스피어 피싱: 스피어 피싱(Spear Phishing) (116M)
  • 큐싱: 큐싱(Qshing) (132M)
  • 스미싱, 파밍

8. 보안관제 및 사고대응​

8.1 보안관제​

8.1.1 보안관제 시스템​

  • SIEM: SIEM(Security Information & Event Management) (135M)
  • SOAR: SOAR(Security Orchestration, Automation and Response) (127M), SOAR(Security Orchestration, Automation & Response) (135M)
  • SOC, 위협 인텔리전스(Threat Intelligence)
  • CTEM: CTEM(Continuous Threat Exposure Management) (139M)

8.1.2 이상행위 탐지​

  • FDS: 이상금융거래 탐지시스템(FDS, Fraud Detection System) (116M)
  • 오남용 탐지: 오남용 행위 탐지 시나리오 생성방안별(4W1H, 데이터생명주기) 생성기준 및 구성요소 (116M)

8.1.3 취약점 관리​

  • CVE, CVSS
  • 모의해킹(Penetration Test)

8.2 디지털 포렌식​

8.2.1 포렌식 절차와 원칙​

  • 디지털 포렌식: 디지터 포렌식의 증거수집기술과 증거분석기술 (117M), 디지털 포렌식(Digital Forensics) (118M), 디지털포렌식 절차 및 활용되는 기술 (121M), 디지털 포렌식의 유형과 절차 (130M)
  • 포렌식 5대 원칙: 디지털 포렌식 수행 시 고려사항 및 디지털 포렌식 5대 원칙 (118M)
  • 클라우드 포렌식: 공공 클라우드 포렌식(Forensic) 조사 절차 (111M), 클라우드 시그니처(Cloud Sigature)탐지 도구 (111M)

8.2.2 포렌식 기술​

  • 아티팩트: 디지털 포렌식에서 아티팩트(Artifact) (137M)
  • 파일 슬랙: 파일 슬랙(file slack) (126M)
  • 파일 카빙: 파일 카빙(FC : File Carving) (126M)
  • 안티포렌식: 안티포렌식(Anti-Forensic) (133M)

9. 개인정보보호와 프라이버시​

9.1.1 개인정보보호 관련 법령​

  • 개인정보보호법: 개인정보보호법 개정안 주요 내용 (130M)
  • 데이터 3법: 데이터 3법 시행령 개정안 (121M), '데이터 3법' 개정 배경과 주요개정내용 (128M)
  • 개인정보 전송요구권: 개인정보 전송요구권과 AI 활용을 위한 자동화 의사결정 대응권 (130M)
  • GDPR
  • 국외이전 규범: APEC(Asia-Pacific Economic Cooperation) CBPR(Cross Border Privacy Rules) (132M), APEC 프라이버시 9 원칙 (132M)

9.1.2 개인정보 안전성 확보​

  • 안전성 확보조치: 개인정보 안전성 확보조치 기준에 명시된 내부관리계획 (127M), 개인정보의 안전성 확보조치 기준 (131M)
  • 암호화 적용: 암호화 적용방안 (131M)
  • 마이데이터 보안: 마이데이터 전송 보안 안내서 (132M)
  • 개인정보 유출 대응: 개인 정보의 정보 및 유출 원인 (116M)

9.2 비식별화와 가명처리​

9.2.1 비식별 조치​

  • 비식별화: 개인정보 비식별 조치 가이드라인 (110M), 개인정보 비식별 조치 (118M), 개인정보의 비식별조치 가이드라인 (120M)
  • 가명·익명처리: 개인정보의 가명 익명처리 기술 (128M), 개인정보보호를 위한 가명처리 기법 (139M)
  • 가명정보 결합: 개인정보처리자 간 가명정보 결합 및 반출방법 (121M)

9.2.2 프라이버시 보호 모델​

  • k-익명성: 프라이버시 보호모델인 k-익명성(k-anonymity) (110M)
  • l-다양성, t-근접성

9.3 프라이버시 강화 기술​

9.3.1 PET​

  • PET: 개인정보 보호 강화기술(Privacy Enhancing Technology) (134M), 개인정보 보호 강화기술(PET:Privacy Enhancing Technology) (138M)
  • 차분 프라이버시: 차분 프라이버시 (138M)
  • 합성데이터: 합성데이터 (138M)
  • PPDM: PPDM(Privacy Preserving Data Mining) (113M)
  • 연합학습: 연합학습의 보안 및 프라이버시 보장형 기술 (128M)

  • 개인정보 안심구역: 개인정보 안심구역 (135M), 개인정보 안심구역과 데이터안심구역 비교 (136M)
  • AI 개인정보보호: 인공지능(AI) 개인정보보호 자율점검표 (125M)
  • 개인영상정보 보호: 폐쇄회로화면(CCTV) 개인영상정보 보호방안 (117M)
  • 디지털 윤리: 디지털 윤리(Digital Ethics)와 개인정보보호(Privacy) (118M)
  • 다크패턴: 다크패턴(Dark Pattern) (134M)

  • SASE, SSE
