  • Text Mining: 텍스트 마이닝의 개념, 기능, 기본 분석절차, 텍스트 마이닝(TextMining)
  • Opinion Mining: 오피니언 마이닝(Opinion Mining), 오피니언 마이닝(Opinion Mining) 수행 절차
  • Process Mining: 프로세스 마이닝의 개념과 필요성, 기술요소

  • Data Swamp: 데이터 늪(Data Swamp), 데이터 스웜프(Data Swamp) 발생 원인과 방지 방안

  • Differential Privacy: 차분 프라이버시
