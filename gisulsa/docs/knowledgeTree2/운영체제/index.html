03. 운영체제

1. 운영체제 개요​

1.1 운영체제 개념과 구조​

1.1.1 운영체제의 기능과 구조​

  • 커널(Kernel)과 시스템 콜(System Call)
  • 사용자 모드/커널 모드
  • 모놀리식 커널, 마이크로커널
  • 프로그램 적재와 실행: 일반적인 운영 체제의 프로그램 동작방식 (129M)
  • 응용 프로그램 가상화: 가상화(Virtualization) (129M)

1.1.2 부팅과 초기화​

  • BIOS/UEFI, 부트로더(Boot Loader)
  • UNIX 부팅과정: UNIX 운영체제 부팅과정 (117M)

1.1.3 인터럽트 처리​

  • 인터럽트 벡터, ISR(Interrupt Service Routine)
  • 인터럽트 처리 우선순위: 인터럽트(Interrupt)의 처리 우선순위 (113M)
  • 폴링(Polling)과 트랩(Trap)

2. 프로세스 관리​

2.1 프로세스와 스레드​

2.1.1 프로세스​

  • 프로세스 상태전이(생성/준비/실행/대기/종료)
  • PCB(Process Control Block)
  • 문맥교환(Context Switching)
  • 프로세스와 스레드 비교: 스레드(Thread)와 프로세스(Process)의 차이점 (116M)

2.1.2 스레드​

  • 스레드/멀티스레드: 스레드(Thread)와 멀티스레드(Multi-thread) (116M)
  • 사용자 수준 스레드, 커널 수준 스레드
  • 멀티스레딩 모델(1:1, N:1, N:M)

2.2 CPU 스케줄링​

2.2.1 스케줄링 개념​

  • 스케줄링 개념: CPU 스케줄링과 디스크 스케줄링의 개념 (137M)
  • 선점형/비선점형 스케줄링
  • 스케줄링 성능 기준(CPU 이용률, 처리량, 반환시간, 대기시간, 응답시간)

2.2.2 스케줄링 알고리즘​

  • FCFS(First Come First Served)
  • SJF: SJF(Shortest Job First) (119M), SJF(Shortest Job First)와 SRT(Shortest Remaining Time) (137M)
  • SRT: SRT(Shortest Remaining Time) (137M)
  • HRN: HRN(Highest Response-ratio Next) (119M)
  • Round Robin(RR)
  • MLQ: MLQ(Multi Level Queue) (119M)
  • MLFQ: MLFQ(Multi Level Feedback Queue) (119M)

2.3 병행성과 동기화​

2.3.1 동기화 문제​

  • 임계구역(Critical Section)과 상호배제(Mutual Exclusion)
  • 경쟁조건: 경쟁조건(Race Condition) (126M)
  • TOCTOU: 검사시점과 사용시점(TOCTOU) (125M)
  • 생산자-소비자 문제, 독자-저자 문제

2.3.2 동기화 기법​

  • 뮤텍스: 뮤텍스(Mutex) (139M)
  • 세마포어: 세마포어(Semaphore)와 모니터(Monitor) (122M), 세마포어(Semaphore) (139M)
  • 모니터: 모니터(Monitor) (122M), 모니터(Monitor) (139M)
  • 스핀 락: 스핀 락(Read/Write Spin Lock) (110M)
  • 공유 자원 동기화: 공유 자원의 충돌이나 일관성 문제를 해결하기 위한 동기화 기법 (136M)
  • 피터슨(Peterson) 알고리즘, Test-and-Set

2.3.3 교착상태​

  • 교착상태: 교착상태(Deadlock) (116M), 교착 상태(Dead Lock) (124M)
  • 발생 4조건(상호배제, 점유대기, 비선점, 환형대기)
  • 교착상태 예방(Prevention), 회피(Avoidance), 발견(Detection), 회복(Recovery)
  • 은행가 알고리즘: 은행가 알고리즘(Banker's Algorithm) (124M), 은행가 알고리즘(Banker's Algorithm) (138M)

2.4 프로세스 간 통신(IPC)​

  • IPC 기법: IPC(Inter Process Communication) 방식의 주요기법 3가지 (117M), IPC(Inter Process Communication) (136M)
  • 파이프(Pipe), 메시지 큐(Message Queue), 공유 메모리(Shared Memory)
  • 소켓(Socket), 시그널(Signal), RPC

3. 메모리 관리​

3.1 실기억장치 관리​

3.1.1 메모리 할당 기법​

  • 고정 분할, 가변 분할
  • 최초 적합(First Fit), 최적 적합(Best Fit), 최악 적합(Worst Fit)
  • 동적 메모리 할당: 동적 메모리 할당의 필요성 (136M)
  • 메모리 누수: 메모리 누수(Memory Leak) (136M)
  • 가비지 컬렉션(Garbage Collection)
  • 내부 단편화, 외부 단편화, 압축(Compaction)

3.1.2 프로세스 주소 공간​

  • 메모리 4영역: 코드(Code) (138M), 데이터(Data) (138M), 힙(Heap) (138M), 스택(Stack) (138M)
  • 주소 바인딩, MMU(Memory Management Unit)
  • 세그먼테이션 오류: 세그먼테이션 오류(Segmentation Fault) (136M)

3.2 가상메모리​

3.2.1 가상메모리 관리 기법​

  • 가상메모리: 가상메모리 관리기법 (139M)
  • 페이징: 페이징 기법 (131M)
  • 세그멘테이션: 세그멘테이션 기법 (131M)
  • 페이지 테이블, TLB(Translation Lookaside Buffer)
  • 요구 페이징(Demand Paging), 페이지 부재(Page Fault)
  • 가상메모리 단편화: 가상메모리 단편화 유형 (139M)

3.2.2 페이지 교체 알고리즘​

  • 페이지 교체: 페이지 교체 알고리즘 (117M)
  • FIFO, LRU, LFU, NUR, OPT, Second Chance(Clock)

3.2.3 지역성과 스레싱​

  • 지역성(Locality) - 시간적/공간적
  • 스레싱: 프로세스 스레싱(Thrashing) (110M), 스레싱 (126M)
  • 워킹셋(Working Set), PFF(Page Fault Frequency)

4. 파일시스템 및 입출력 관리​

4.1 파일시스템​

  • 파일시스템 구조(FAT, i-node, 저널링)
  • UNIX 파일시스템: Unix 파일 시스템의 구조 (116M)
  • 파일 슬랙: 파일 슬랙(file slack) (126M)
  • 디렉터리 구조, 파일 할당 방식(연속/연결/색인)

4.2 입출력 관리​

  • 프로그램 I/O, 인터럽트 구동 I/O, DMA
  • I/O 모델: 네트워크에서의 Non-blocking I/O (113M)
  • 동기/비동기 I/O, Blocking/Non-blocking I/O
  • 버퍼링(Buffering), 스풀링(Spooling)

4.3 디스크 스케줄링​

  • 디스크 스케줄링: CPU 스케줄링과 디스크 스케줄링의 개념 (137M)
  • SSTF: SSTF(Shortest Seek Time First) (137M)
  • SLTF: SLTF(Shortest Latency Time First) (137M)
  • FCFS, SCAN, C-SCAN, N-step SCAN, 에센바흐(Eschenbach) 기법

4.4 저장장치 관리​

  • RAID: RAID 0, 1, 5, 6 (120M)
  • 스토리지 유형: DAS(Direct Attached Storage), NAS(Network Attached Storage), SAN(Storage Area Network) (122M)
  • 스토리지 접근 방식: 블록 스토리지, 파일 스토리지, 오브젝트 스토리지의 데이터 접근 방식 (132M)
  • 스토리지 가상화: 스토리지 가상화(Storage Virtualization) 유형별 특징 (134M)

5. UNIX/Linux 운영체제​

5.1 시스템 구조​

  • 커널, 쉘(Shell), 유틸리티
  • UNIX 부팅과정: UNIX 운영체제 부팅과정 (117M)
  • 데몬(Daemon) 프로세스, fork/exec

5.2 계정과 인증​

  • 계정 관리: /etc/passwd 파일의 구성 (116M)
  • Linux PAM: Linux PAM(Pluggable Authentication Modules) (113M)
  • 파일 권한(Permission), setuid/setgid

6. 임베디드·실시간 운영체제​

6.1 실시간 운영체제(RTOS)​

  • 경성(Hard)/연성(Soft) 실시간 시스템
  • 실시간 스케줄링: Real Time Scheduling (126M)
  • RM(Rate Monotonic), EDF(Earliest Deadline First)
  • 우선순위 역전: 우선순위 역전(Priority Inversion) (126M)
  • 우선순위 상속(Priority Inheritance), 우선순위 상한(Priority Ceiling)

6.2 임베디드 시스템​

  • 임베디드 소프트웨어 테스트: 임베디드 소프트웨어 테스트 (126M)
  • 인터미턴트 컴퓨팅: 인터미턴트 컴퓨팅(Intermittent Computing) (134M)
  • 크로스 컴파일러, 펌웨어(Firmware)

7. 시스템 성능 평가​

7.1 대기행렬 이론​

  • 대기행렬: 대기행렬이론(Queuing Theory) (116M), 대기행렬시스템(Queue System) (120M)
  • 리틀의 법칙: 리틀의 법칙(Little's Law) (117M)
  • M/M/1 모델, 도착률/서비스율

7.2 성능 측정 지표​

  • 처리량(Throughput), 응답시간(Response Time), 가용성(Availability)
  • 벤치마크(Benchmark), 워크로드(Workload)
