15. 디지털신기술

1. 디지털 전환(DX)​

1.1 4차 산업혁명과 디지털 전환​

1.1.1 4차 산업혁명​

  • 4차 산업혁명: 4차 산업혁명의 정의와 연혁 특징, 국내 문제점 및 해결방안, 4차 산업혁명의 개념 및 주요 정보화 활용 기술
  • 초연결 / 초지능 / 초융합

1.1.2 디지털 트랜스포메이션​

  • Digital Transformation: 디지털 트랜스포메이션(Digital Transformation)
  • AX(AI Transformation): 기업의 디지털 전환(AX, AI Transformation)
  • 디지털 혁신 조직: 디지털 혁신을 위한 고려사항과 CoE(Center of Excellence)의 역할
  • Bimodal IT: 바이모달(Bimodal) IT
  • Growth Hacking: 그로스 해킹(Growth Hacking)
  • 기술수용모델: 기술수용모델(Technology Acceptance Model; TAM)
  • 전문성의 민주화: 전문성의 민주화(Democratization of Expertise)
  • 디지털 플랫폼 정부: 디지털 플랫폼 정부의 특징, 구성요소, 기대효과

1.2 디지털 비즈니스​

1.2.1 디지털 비즈니스 모델​

  • 슈퍼앱: 슈퍼앱의 정의와 주요요소, 미니앱
  • 데이터 커머스: 데이터 커머스(Data Commerce)
  • 앰비언트 커머스: 엠비언트 커머스 Ambient
  • 앰비언트 컴퓨팅: 앰비언트 컴퓨팅(Ambient Computing)
  • 화이트 레이블 마케팅: 화이트 레이블 마케팅(White Label Marketing)
  • 플랫폼 경제 / API Economy

1.3 디지털 정책과 윤리​

1.3.1 디지털 정책/경제​

  • 망중립성: 망중립성(Network Neutrality), 망 중립성 정책 내용, 쟁점 및 정책 이슈, 망중립성 이슈
  • 제로 레이팅: 제로 레이팅(Zero Rating), OTT(Over-The-Top) 서비스의 제로 레이팅(zero-rating) 문제점
  • 디지털세: 디지털세 내용과 의미 및 전망
  • 리쇼링: 리쇼링(Reshoring)
  • 데이터 댐: 디지털 뉴딜 '데이터 댐'
  • 반도체 산업: 메모리 반도체와 비메모리 반도체 비교, 반도체 산업의 가치사슬(Value Chain)

1.3.2 디지털 윤리/역기능​

  • 디지털 윤리: 디지털 윤리(Digital Ethics)와 개인정보보호(Privacy)
  • 정보윤리: 정보윤리 정의 및 원칙, 컴퓨터(사이버) 범죄와 중독
  • 디지털 역기능: 디지털 역기능 개념과 사례, 3대 이슈
  • 다크패턴: 다크패턴(Dark Pattern)의 세부 유형 및 대응 방안

2. 블록체인 / Web3​

2.1 블록체인 기반 기술​

2.1.1 블록체인 기초​

  • Blockchain: 블록체인의 개념과 작동 원리, 블록체인(Block Chain)기술, 파일, 데이터베이스, 블록체인 비교
  • 분산원장: 분산원장기술
  • 머클트리: 머클트리(Merkle Tree)
  • 마이닝: 블록체인(Block Chain) 구성요소 중 마이닝(Mining)
  • UTXO: UTXO(Unspent Transaction Output)
  • P2P 네트워크: 하이브리드 P2P(Hybrid P2P) 방식과 퓨어 P2P(Pure P2P) 방식
  • 합의 알고리즘: 블록체인 합의 알고리즘(Consensus Algorithm)의 목적, 원리, 종류

2.1.2 블록체인 유형​

  • Public/Private 블록체인: 블록체인의 생성주체(Public, Private)별 운영 방식, 퍼블릭(Public) 블록체인과 프라이빗(Private) 블록체인 비교, 퍼블릭(Public) 블록체인과 프라이빗(Private) 블록체인의 차이점
  • Hybrid 블록체인: 퍼블릭 블록체인(Public Blockchain), 프라이빗 블록체인(Private Block Chain), 하이브리드 블록체인(Hybrid Blockchain) 비교
  • Hyperledger: 하이퍼레저(Hyperledger)

2.1.3 스마트 컨트랙트​

  • Smart Contract: 스마트 계약(Smart Contract)
  • Smart Contract Audit: Smart Contract Audit
  • Ethereum: 이더리움(Ethereum)의 개념과 특징
  • Solidity: 솔리디티(Solidity)
  • EVM: 이더리움 가상머신(EVM: Ethereum Virtual Machine)
  • DApp: 디앱(DApp, Decentralized Application)

2.1.4 블록체인 보안​

  • 블록체인 보안위협: 블록체인(Block Chain) 플랫폼의 보안위협과 대응 방안, 금융권에서 블록체인 시스템을 도입할 시 고려해야 할 정보보안 이슈, 블록체인기술을 도입하기 위한 보안 고려사항, 블록체인 플랫폼 구축과정에서 성능 및 보안 측면의 고려사항
  • 블록체인 기반 인증: 블록체인 방식의 인증 방법

2.2 Web3 / 토큰 경제​

2.2.1 Web3​

  • Web 3.0: 웹3.0의 도입배경 및 개념, 주요특징 및 기술요소
  • NFT: 대체불가능 토큰(Non-Fungible Token), NFT 특성과 NFT 마켓 플레이스에서의 보안 취약점
  • DeFi: 디파이(De-fi)
  • DAO / Token Economy

2.2.2 분산 신원(DID)​

  • DID: DID(Decentralized Identity), 분산 ID(Decentralized Identity)
  • GADI: GADI(Global Architecture for Digital Identity)
  • 모바일 신분증: 모바일 신분증

3. 메타버스 / XR / 디지털트윈​

3.1 XR(확장현실)​

3.1.1 VR/AR/XR​

  • VR: 가상현실(VR) 생태계 현황(C-P-N-D 관점), 가상현실의 개념, 확산요인, 생태계 현황
  • 가상융합기술(XR): 가상현실, 증강현실, 가상융합기술 비교 및 가상융합경제 발전전략
  • AR / MR / 공간컴퓨팅

3.2 메타버스​

3.2.1 Metaverse​

  • Metaverse: 메타버스(초월주의)의 개념, 운영사례, 시사점, 메타버스(Metaverse), 메타버스의 특징, 보안 위협, 사회적 문제점
  • 메타버스 윤리: 메타버스 윤리원칙(3대 지향가치와 8대 실천원칙)
  • Avatar / Digital Asset

3.3 디지털트윈​

3.3.1 Digital Twin​

  • Digital Twin: 디지털 트윈(Digital Twin), 가상공간(Cyber Space)의 특징과 디지털트윈(DigitalTwin)의 의미, 디지털 트윈 기술의 정의 및 역할, 구성도 및 구축기술, 디지털 트윈(Digital Twin)과 메타버스(Metaverse)

3.4 인터페이스 / 휴먼증강​

3.4.1 차세대 인터페이스​

  • 직감기술: 직감기술(Intuitive Technology)
  • 디지털 휴먼증강: 디지털 휴먼증강(Digital Human Augmentation)
  • 멀티모달 인터페이스: 멀티 모달 인터페이스(MultimodalInterface)의 구성요소

4. IoT / CPS​

4.1 IoT​

4.1.1 IoT 디바이스/식별​

  • IoT / IIoT
  • IoB: 행동인터넷(IoB, Internet of Behavior)
  • 스마트 더스트: 스마트 더스트(Smar Dust)
  • 인터미턴트 컴퓨팅: 인터미턴트 컴퓨팅(Intermittent Computing)
  • IoT 식별체계: 객체식별자 기반 사물인터넷 디바이스 식별체계(TTAK.KO-06.0365/R1), 바코드(Barcode)와 QR코드(Quick Response Code)
  • 실내 측위: IPS(Indoor Positioning System)

4.1.2 IoT 통신 프로토콜​

  • LPWA: LPWA(Low Power Wide Area)
  • IoT 메시징 프로토콜: XMPP, CoAP, MQTT 특징 비교, CoAP / MQTT / LwM2M 프로토콜 구조
  • NFC: NFC(Near Field Communication)
  • MODBUS: MODBUS 프로토콜

4.1.3 IoT 보안​

  • IoT 네트워크 보안: 사물인터넷(IoT) 네트워크 보안 기술의 개념, 특성, 보안 이슈
  • 미라이 봇넷: 미라이 봇넷(Mirai Botnet), IoT 서비스 생애주기별 보안위협, IoT 공통보안 7대원칙

4.2 CPS / 스마트팩토리​

4.2.1 CPS​

  • CPS: CPS(Cyber-physical System), CPS 구축 절차

4.2.2 스마트팩토리​

  • Smart Factory: 스마트팩토리시스템(Smart Factory System), 스마트팩토리(Smart Factory)의 정보시스템 구축 사업 성과측정 항목
  • MES 참조모델: 스마트팩토리에서 MES(Manufacturing Execution System) 참조모델인 ISA-88과 ISA-95 비교
  • POP: POP(Point Of Production)
  • 가상계측: 가상계측(Virtual Metrology)

4.2.3 산업제어시스템(OT)​

  • 퍼듀 모델: 산업제어시스템(Industrial Control System)의 퍼듀(Purdure) 모델
  • OT 보안 표준: ISA/IEC 62443
  • SCADA / PLC

4.3 스마트시티 / 스마트그리드​

4.3.1 스마트시티​

  • 스마트시티: 스마트시티 통합플랫폼, Digital Twin 기술을 활용하여 스마트 시티를 구현
  • 지능형 관제: 지능형 CCTV 스마트 관제

4.3.2 스마트 에너지​

  • 스마트 그리드: 스마트 그리드의 개념과 핵심기술
  • VPP: VPP(Virtual Power Plant) 가상발전소

5. 로봇 / 자율시스템​

5.1 로봇​

5.1.1 지능형 로봇​

  • 지능형 로봇: 인공지능, 사물인터넷, 클라우드가 로봇과 접목하여 인간과 상호작용
  • RPA: 로봇 프로세스 자동화(RPA : Robotics Process Automation)
  • Cobot / AMR / AGV

5.2 자율주행 / 드론​

5.2.1 자율주행​

  • LiDAR: 라이다(LiDAR : Light Detection and Ranging)
  • C-V2X: 차량∙사물 셀룰러 통신(Cellular Vehicle to Everything)
  • 자율주행 자동차: 자율주행 자동차의 세부기술

5.2.2 드론/UAV​

  • 드론: 드론의 보안위협과 대응방안
  • UAV: UAV(Unmanned Aerial Vehicle) 활용
  • UAM

6. 양자기술​

6.1 양자컴퓨팅​

6.1.1 Quantum Computing​

  • Qubit: 큐비트(Qubit)
  • 양자머신러닝: 양자머신러닝(QML, Quantum Machine Learning)
  • 양자우월성 / 양자 알고리즘

6.2 양자암호​

6.2.1 양자암호통신​

  • 양자암호: 양자 암호(Quantum Cryptography), 양자암호통신, 양자암호통신의 암호키 분배방식, 주요기술, 취약점

  • PQC: 포스트 양자 암호(Post-Quantum Cryptography), 양자내성암호(PQC : Post Quantum Cryptography)

7. 차세대 네트워크 (5G/6G)​

7.1 5G​

7.1.1 5G 네트워크​

  • 5G: 초연결 시대의 5G 네트워크의 기술적 특징
  • 네트워크 슬라이싱: 5G 네트워크 슬라이싱(5G Nerwork Slicing)
  • 5G 특화망: 5G 특화망(지역 5G), 5G 특화망을 위한 네트워크 구축 시 고려사항

7.2 6G / 미래 네트워크​

7.2.1 6G​

  • 6G: 6G 이동통신, 6G 이동통신기술의 서비스 특징, 성능 요구사항, 주파수 동향
  • SATIN: 위성-상공-지상 통합형 무선 네트워크(Satelite-Aerial-Terrestrial Integrated Network, SATIN)
  • AI-Native Network: 6G 이동통신기술 핵심 개념인 AI-Native Network(자율 최적화, AI-RAN, 디지털트윈 기반 네트워크 관리)
  • NOMA: 비직교 다중접속(NOMA, Non-Orthogonal Multiple Access)

7.2.2 미래 통신 기술​

  • FSO: 모바일 FSO(Free Space Optics) 통신
  • SDR: SDR(Software Defined Radio)
  • 해저케이블: 해저케이블 에퀴아노(Equiano) 프로젝트
  • NTN / 위성인터넷

8. 핀테크​

8.1 핀테크 서비스​

8.1.1 금융 플랫폼​

  • 핀테크: 핀테크 인터넷전문은행, 간편결제 서비스의 비대면 보안기술
  • 오픈뱅킹: 오픈 뱅킹(Open Banking)의 개념 및 등장 배경, 구성 주체 및 역할
  • 오픈 플랫폼: 은행권 공동 오픈 플랫폼과 Open API
  • 인슈어테크: 인슈어테크(InsurTech)
  • 레그테크: 레그테크(RegTech), 레그테크(Regtech) 정의와 필요성, 주요 특징

  • QR 결제: QR코드 기반의 결제 방식(MPM/CPM 비교)
  • HCE: HCE(Host Card Emulation)
  • 안면인식 결제: 안면인식 결제 서비스
  • SWIFT 표준: 국제은행간 통신협회(SWIFT) Pay Later API 표준

8.2 금융 보안/규제​

8.2.1 금융 리스크 대응​

  • FDS: 이상금융거래 탐지시스템(FDS, Fraud Detection System)
  • KYC: 고객확인 절차(KYC : Know Your Customer)
  • CBDC

9. ESG / Green IT​

9.1 ESG​

9.1.1 ESG 경영과 IT​

  • ESG 경영: ESG(Environmental, Social and Governace) 경영에서 정보기술(IT)의 역할, ESG 경영의 정의 및 목표, 주요 지표
  • ESG와 정보보호: 기업의 ESG(Environment, Social, Governance) 실현(정보보호 시스템 구축, 개인정보 침해 및 구제 측면)
