📄️ 보안 (Security)

C/M 합산 최다 출제 카테고리. 전 회차에 걸쳐 꾸준히 출제.

📄️ 인공지능/머신러닝 (AI/ML)

최근 회차(130~138)에서 급격히 출제 증가. 특히 LLM/생성형 AI 관련.

📄️ 네트워크/통신

C에서 압도적으로 많이 출제. 프로토콜, 무선통신, 오류제어 중심.

📄️ 운영체제 (OS)

C에서 집중 출제. 스케줄링, 동기화, 가상메모리가 3대 핵심.

📄️ 컴퓨터구조

C 전용 영역. M에서는 거의 출제되지 않음.

📄️ 메모리/반도체

C에서 주로 출제. 비휘발성 메모리와 차세대 메모리 비중 높음.

📄️ 하드웨어/프로세서

C에서 주로 출제. AI 가속기와 임베디드 프로세서 중심.

📄️ 데이터베이스

M에서 압도적으로 출제. 정규화, 트랜잭션, 병행제어가 핵심.

📄️ 빅데이터/데이터 관리

M에서 주로 출제. 데이터 품질/거버넌스 비중 증가 추세.

📄️ 소프트웨어 공학

C/M 양쪽에서 고루 출제. 테스트, 방법론, 품질 중심.

📄️ 프로젝트관리

M의 핵심 영역. 감리, ISP/ISMP, 비용산정이 매회 출제.

📄️ 클라우드/가상화

C/M 양쪽에서 출제 증가 추세. 엣지 컴퓨팅, 클라우드 네이티브 부상.

📄️ 블록체인

M에서 역대 최다 반복. 110~125회까지 집중 후 감소 추세.

📄️ 산업응용/융합기술

C/M 양쪽에서 고루 출제. 스마트팩토리, 자율주행, 디지털트윈이 핵심.

📄️ 실감기술/미디어

C에서 주로 출제. VR/AR과 영상 압축 중심.

📄️ 스토리지

C에서 주로 출제. RAID가 가장 빈출.

📄️ 알고리즘/자료구조

C에서 주로 출제. 설계기법과 정렬/탐색이 핵심.

📄️ 법제도/정책

M에서 집중 출제. 최근 AI 관련 법제도 급부상.

📄️ 표준/기능안전

C/M 양쪽에서 출제. 기능안전 표준과 가용성 관련 키워드 중심.

📄️ 인프라/데이터센터

출제 빈도는 낮지만 실무 연관성 높은 영역.

📄️ 기술사 기출문제 카테고리별 키워드 분류

분석 범위: 110회 ~ 138회 (C 20회차 + M 27회차, 총 약 1,500문제)
