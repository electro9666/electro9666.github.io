감리 및 사업관리​

1.​

정보시스템 장애 대응과 관련하여 「전자정부법 시행령」 및 「행정기관 및 공공기관 정보시스템 구축‧운영지침(2025.01.02.)」에 따른 활동으로 가장 적절하지 않은 것은?

  1. 정보시스템의 장애 예방ㆍ대응계획 수립
  2. 관계기관에 장애사실의 즉시 통보
  3. 사업자에게 외부 전문가 활용 체계 구성을 요구
  4. 장애등급 조정 및 원격 백업

2.​

「소프트웨어진흥법」,「국가계약법 시행령」에 따른 공공 정보화 사업 발주와 관련된 설명으로 가장 적절하지 않은 것은?

  1. 상세 요구사항을 작성하기 위하여 별도로 분석 또는 설계 사업을 분리하여 발주할 수 있다.
  2. 민간의 자본과 기술을 활용하여 개발하고 사업자가 일정기간 수익을 얻는 방식으로 사업을 추진할 수 있다.
  3. 디지털서비스 심사위원회에서 사전에 선정한 디지털서비스는 수의계약을 체결할 수 있다.
  4. 공개 SW가 사용되는 사업에서는 직접 구매 방식을 적용하고 민간SW 시장 침해여부를 조사해야 한다.

3.​

「(계약예규) 용역계약일반조건(2024.12.24.)」에 따른 설명으로 가장 적절하지 않은 것은?

  1. 발주기관이 작업장소 등에 관한 비용을 사업예산 또는 예정가격에 계상하지 아니한 경우에는 발주기관이 작업장소 등을 제공한다.
  2. 과업내용 변경에 따른 계약금액의 조정액이 당초 계약금액의 100분의 10이상으로 추정될 경우에는 위원회를 설치하여 과업변경 심의를 하여야 한다.
  3. 용역을 완성한 후 인수가 완료된 때에 인력의 투입도 종료된다.
  4. 해당 계약에 따른 계약목적물에 대한 지식재산권은 발주기관과 계약상대자가 공동으로 소유하며,별도의 정함이 없는 한 지분은 균등한 것으로 한다.

4.​

「전자정부 성과관리 지침(2024.01.16.)」에 따른 정보시스템 운영 성과 측정에 대한 설명으로 가장 적절하지 않은 것은?

  1. 정보시스템 구축 사업 검수 완료 후 1년이 경과한 정보시스템을 대상으로 성과를 측정한다.
  2. 업무 측면의 성과측정은 기능활용도·업무성과 달성도를 고려하여 측정한다.
  3. 성과평가 결과가 총점 40점 미만이라도 서비스 운영 개시 후 3년 이하는 폐기하지 않을 수 있다.
  4. 성과평가 결과가 총점 60점 미만은 통폐합, 기능 고도화, 전면재개발 시행을 권고할 수 있다.

  2. 소프트웨어 개발공정에서 필요한 분석, 설계 등 개발 프로세스에 관한 사항
  3. 소프트웨어 개발 관련 법령, 지침 및 국내외 표준 적용에 관한 사항
  4. 조직의 프로세스 표준화 및 이의 적용ㆍ확산 등에 관한 조직관리 사항

  3. (가): 검사요청 전, (나): 발주자 확인을 거쳐 감리법인

  3. 역전파 알고리즘은 손실함수를 계산하며 가중치를 갱신한다.
  4. 경사소실은 학습모델의 은닉층을 증가시켜 해결할 수 있다.

98.​

다음 중 비지도 학습에 해당하는 것으로 가장 적절한 것은?

  1. K-평균 군집화
  2. 나이브 베이즈 분류
  3. 서포트 벡터 머신
  4. 선형 회귀

99.​

다음 중 양자 컴퓨팅에 대한 설명으로 가장 적절하지 않은 것은?

  1. 쇼어(Shor)의 알고리즘은 소인수분해 문제를 차수 찾기 문제로 변환한다.
  2. 양자 컴퓨터는 특정 함수를 평가할 때 다수의 입력값을 동시에 처리할 수 있다.
  3. 양자 컴퓨터는 중첩 상태의 큐비트를 측정하면 값에 영향을 줄 수 있다.
  4. 양자 컴퓨터는 큐비트 전송 과정에서 오류가 발생하지 않는 장점이 있다.

100.​

다음에서 설명하는 용어로 가장 적절한 것은?

LLM은 작업에 특화된 상대적으로 작은 크기의 데이터셋에서 훈련시켜, 특정 작업을 위한 파라미터를 조정하는 것을 의미한다. 이를 통해 LLM은 사전 훈련된 언어에 대한 지식을 활용하여 특정 작업의 정확도를 향상 시킬 수 있다. 이것은 특정 도메인 및 작업에서의 성능을 크게 향상시키는 것으로 나타났으며, LLM이 다양한 NLP 응용에 빠르게 활용될 수 있게 해준다.

  1. 어텐션
  2. 임베딩
  3. 토큰화
  4. 파인튜닝

101.​

공개키 암호시스템에 대한 설명으로 가장 적절하지 않은 것은?

  1. RSA는 소인수 분해 문제의 어려움에 기반하는 암호시스템으로 암호 방식의 안전성은 소수 p, q에 의존한다.
  2. ElGamal 암호시스템은 이산대수 문제의 어려움을 이용하여 만든 암호 방식으로 평문과 암호문의 길이가 동일하다.
  3. 공개키 암호 방식에서는 공개키와 개인키가 존재하며, 공개키는 누구나 알 수 있지만 개인키는 소유자만이 알 수 있어야 한다.
  4. ECC 암호시스템은 RSA 알고리즘보다 적은 비트 수를 가지고 동일한 암호 강도를 보장할 수 있다.

102.​

암호학적 해시 함수에 대한 설명으로 가장 적절하지 않은 것은?

  1. 암호학적 해시 함수를 이용하면 메시지의 무결성뿐만 아니라 기밀성을 보장할 수 있다.
  2. 암호학적 해시 함수를 이용하여 계산한 해시값으로부터 원래의 입력값인 메시지를 구하는 것은 계산상 불가능해야 한다.
  3. 충돌 저항성을 만족하는 암호학적 해시 함수는 동일한 해시값을 갖는 서로 다른 두 개의 메시지를 구하는 것이 계산상 불가능하다.
  4. 암호학적 해시 함수는 특정 메시지와 그 메시지의 해시값이 주어지더라도, 같은 해시값을 갖는 다른 메시지를 생성하는 것이 어려워야 한다.

103.​

다음 설명에 해당하는 필터링 방식으로 가장 적절한 것은?

특정 IP 또는 IP 대역에 대하여 비정상적인 시도가 감지되었을 경우, 가상의 쓰레기 인터페이스(Null interface)로 보내도록 함으로써 패킷 통신이 되지 않도록 하는 방법이다.

  1. Ingress 필터링
  2. Egress 필터링
  3. Blackhole 필터링
  4. Unicast RPF(Reverse Path Forwarding) 필터링

104.​

다음 그림과 같이 암호화를 수행하는 블록 암호시스템의 운용 모드에 대한 설명으로 가장 적절하지 않은 것은?

  1. 암호화/복호화를 수행하는 과정에서 병렬처리가 가능하므로 고속 구현이 가능하다.
  2. 초기 벡터(IV) 값은 송·수신자 사이에 미리 약속되어 있어야 하지만 공개된 값을 사용해도 무방하다.
  3. 암호문 블록 1개가 손상되는 경우, 복호화 수행 시 평문 블록에 미치는 영향은 2개의 블록에 그친다.
  4. 이전 단계에서 암호화한 결과로 출력된 암호화 블록에 대해서는 이번 단계 평문 블록과 XOR한 후 암호화 과정을 수행한다.

105.​

다음 중 SSL/TLS의 핸드셰이크 프로토콜에서 이루어지는 작업과 가장 거리가 먼 것은?

  1. 클라이언트 인증
  2. 서버 인증
  3. HTTP 전송 데이터에 대한 MAC 계산 및 암호화
  4. 암호 알고리즘 협상

106.​

DNS 스푸핑에 대한 설명으로 가장 적절하지 않은 것은?

  1. DNS 질의/응답에 사용하는 UDP 프로토콜의 비연결 취약성을 이용한 공격이다.
  2. 공격자는 DNS 스푸핑을 수행하기 위해 공격대상이 보내는 메시지를 스니핑해야 한다.
  3. 공격대상에게 전달되는 DNS 질의 메시지를 조작하거나 DNS 서버의 캐시 정보를 삭제하는 방법을 이용한다.
  4. 공격이 성공하는 경우, 공격대상은 정상적인URL로 접속하지만 실제로는 공격자가 만든 가짜 사이트로 접속하게 된다.

107.​

VPN 터널링 프로토콜 L2TP(Layer 2 Tunneling Protocol)와 SSTP(Secure Socket Tunneling Protocol)에서 기밀성, 인증 등의 보안 서비스를 제공하기 위해 사용되는 프로토콜로 가장 적절하게 짝지어진 것은?

  1. L2TP – IPSec, SSTP – TLS
  2. L2TP – PAP, SSTP – SSH
  3. L2TP – TLS, SSTP – PAP
  4. L2TP – SSH, SSTP – IPSec

다음 설명에 대한 보안 기술로 가장 적절한 것은?

과거의 IP 관리 시스템에서 발전한 솔루션으로,MAC 주소를 기반으로 접근 제어 및 인증을 수행하여 임의의 사용자가 접속하는 것을 차단한다.

  1. VPN (Virtual Private Network)
  2. VLAN (Virtual Local Area Network)
  3. DRM (Digital Right Management)
  4. NAC (Network Access Control)

다음에서 설명하는 악성코드로 가장 적절한 것은?

자신의 내부에 압축 또는 암호화된 형태로 포함되어 있는 데이터를 이용하여 악성코드를 생성하는 방식으로 동작하며, 백신 프로그램을 통한 탐지가 어렵고 실제 실행을 해보지 않고서는 악성코드 여부를 확인하는 것이 어렵다.

  1. Dropper
  2. Keylogger
  3. Adware
  4. Spyware

다음 중 아래와 같은 사물인터넷 디바이스 관련 보안 위협에 대한 설명으로 가장 적절한 것은?

Device Pool에 잘못된 시간 정보를 송신하여 디바이스가 계속적으로 시간을 교정하는 데 자원을 소모하도록 하는 공격이다.

  2. De­synchronization
  3. Sybil
  4. Eavesdropping

  4. 취약한 비밀번호

다음 중 데이터베이스 암호화 기술에 대한 설명으로 가장 적절하지 않은 것은?

  1. Plug-In 방식은 DB 서버에 암복호화 모듈이 설치되는 방식으로, 구축 시 응용 프로그램의 수정을 최소화할 수 있다.
  2. API 방식은 DB 서버에 영향을 주지 않아 DB 서버의 성능 저하는 적은 편이지만, 구축 시 응용 프로그램 전체 또는 일부의 수정이 필요하다.
  3. Plug-In 방식은 암복호화 모듈이 라이브러리 형태로 각 애플리케이션 서버에 설치되고, 응용 프로그램에서 해당 암복호화 모듈을 호출하는 방식이다.
  4. API 방식과 Plug-In 방식의 장점을 혼용한 하이브리드 방식에서는 대용량 트랜잭션 처리에Plug-In 방식을 사용하고, 성능 저하가 발생할 수 있는 부분은 API 방식을 사용한다.

웹 애플리케이션을 사용해서 다른 최종 사용자의 클라이언트에서 임의의 스크립트가 실행되는 취약점이다.

  1. Directory Indexing
  2. XPath Injection
  3. Cross-Site Request Forgery(CSRF)
  4. Cross Site Scripting(XSS)

114.​

블록체인은 참여자들이 수행하는 모든 트랜잭션들을 모은 장부라고 할 수 있다. 다음 중 블록체인의 특성에 대한 설명으로 가장 적절하지 않은 것은?

  1. 블록체인은 분산시스템이다.
  2. 블록체인상의 트랜잭션 유효성에 대한 검증은 어떤 참여자라도 수행할 수 있다.
  3. 블록체인상의 트랜잭션에 대한 취소는 해당 트랜잭션의 삭제를 통해 이루어진다.
  4. 블록체인을 보호하기 위해 공개키 암호, 해시함수 등과 같은 기술을 사용할 수 있다.

115.​

웹 애플리케이션 개발 과정에서 입력 데이터에 대한 검증을 소홀히하여 발생할 수 있는 보안 취약점과 가장 거리가 먼 것은?

다음 중 OECD 개인정보보호 원칙으로 가장 적절하지 않은 것은?

  1. 수집 제한의 원칙: 개인정보는 적법하고 공정한 방법을 통해 수집되어야 한다.
  2. 정보 정확성의 원칙: 이용 목적상 필요한 범위 내에서 개인정보의 정확성, 완전성, 최신성이 확보되어야 한다.
  3. 안전성 확보의 원칙: 개인정보의 침해, 누설, 도용 등을 방지하기 위한 물리적·조직적·기술적 안전 조치를 확보해야 한다.
  4. 비공개의 원칙: 개인정보의 처리 및 보호를 위한 정책과 관리자의 정보는 비공개하여야 한다.

120.​

다음 중 가명정보의 기술적 보호조치에 대한 설명으로 가장 적절하지 않은 것은?

  1. 추가정보와 가명정보는 분리하여 보관하는 것을 원칙으로 하고, 불가피한 사유로 물리적인 분리가 어려운 경우 DB 테이블 분리 등 논리적으로 분리하는 것도 가능하다.
  2. 가명정보처리자는 추가정보의 분리 보관, 접근권한 관리, 접근통제 및 접속기록의 보관/점검 등의 기술적 보호조치를 취한다.
  3. 추가정보의 활용 목적달성 및 불필요한 경우에는 추가정보를 파기할 수 있으며 파기에 대한 기록을 작성하고 보관한다.
  4. 개인정보처리자는 가명정보 또는 추가정보에 접근할 수 있는 담당자를 업무목적 달성에 필요한 적정 인원으로 지정하며, 접근권한은 업무에 상관없이 균등 부여한다.
