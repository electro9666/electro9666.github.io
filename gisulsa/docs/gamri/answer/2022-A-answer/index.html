감리 및 사업관리​

1번​

[문제]

프로젝트관리에 관한 국제표준 ISO 21500에서 제시하는 10개의 주제 그룹에 속하지 않은 것은?

  • ① 통합
  • ② 조달
  • ③ 통제
  • ④ 의사소통

[정답] ③

[해설] ISO 21500(Guidance on project management)은 프로젝트관리 프로세스를 **10개 주제 그룹(Subject Group)**과 **5개 프로세스 그룹(Process Group)**의 2차원으로 분류한다. 10개 주제 그룹은 **통합(Integration), 이해관계자(Stakeholder), 범위(Scope), 자원(Resource), 시간(Time), 원가(Cost), 리스크(Risk), 품질(Quality), 조달(Procurement), 의사소통(Communication)**이다. 5개 프로세스 그룹은 **착수(Initiating), 기획(Planning), 실행(Implementing), 통제(Controlling), 종료(Closing)**이다. 따라서 ③ '통제'는 주제 그룹이 아니라 프로세스 그룹의 명칭이므로 정답이다. ① 통합, ② 조달, ④ 의사소통은 모두 10개 주제 그룹에 포함된다. PMBOK 6판의 10개 지식영역과 비교하면 ISO 21500은 '인적자원' 대신 '자원(Resource)'을 쓰고, '일정' 대신 '시간(Time)'을 쓴다는 차이가 있다.

난이도출제 빈도중요도
하 — 주제 그룹과 프로세스 그룹만 구분하면 풀리는 기본 개념중중

2번​

[문제]

다음 중 프로젝트 범위관리를 구성하는 하위 프로세스의 산출물들을 생성 시기가 빠른 순으로 나열한 것으로 옳은 것은?

  • ① 요구사항문서 - 작업분류체계 사전 - 활동 목록 - 변경 요청서
  • ② 요구사항문서 - 활동 목록 - 작업분류체계 사전 - 변경 요청서
  • ③ 활동목록 - 작업분류체계 사전 - 요구사항문서 – 변경 요청서
  • ④ 작업분류체계 사전 - 활동목록 - 요구사항문서 – 변경 요청서

[정답] ①

[해설] PMBOK의 범위관리 흐름은 범위관리 계획수립 → 요구사항 수집 → 범위 정의 → WBS 작성 → 범위 확인 → 범위 통제 순이다. 각 산출물은 다음과 같다.

  • 요구사항문서: '요구사항 수집' 프로세스의 산출물로 가장 먼저 만들어진다.
  • 작업분류체계(WBS) 사전: 'WBS 작성' 프로세스에서 범위 기준선(범위기술서·WBS·WBS 사전)의 일부로 만들어진다.
  • 활동 목록: WBS의 최하위 작업패키지를 활동으로 분해하는 '활동 정의'의 산출물이다. PMBOK 5·6판에서는 일정관리에 속하지만, WBS가 있어야 만들 수 있으므로 WBS 사전 뒤에 온다.
  • 변경 요청서: 기준선이 확정된 뒤 '범위 확인/범위 통제'에서 발생한다.

따라서 순서는 요구사항문서 → WBS 사전 → 활동 목록 → 변경 요청서인 ①이다. ②는 WBS 사전보다 활동 목록을 먼저 두었다. 활동은 WBS 작업패키지를 분해해서 나오므로 틀렸다. ③·④는 요구사항문서를 뒤에 두어 범위관리의 출발점을 무시했다.

난이도출제 빈도중요도
하 — 범위관리 프로세스 순서만 알면 되는 기본 문제중중

3번​

[문제]

다음 중 데이터 이전 및 교육훈련과 관련된 요구사항을 포함하는 요구사항의 분류로 가장 적절한 것은?

  • ① 전환 요구사항
  • ② 비즈니스 요구사항
  • ③ 비기능적 요구사항
  • ④ 이해관계자 요구사항

[정답] ①

[해설] PMBOK의 '요구사항 수집' 프로세스는 요구사항을 비즈니스 / 이해관계자 / 솔루션(기능·비기능) / 전환(Transition and readiness) / 프로젝트 / 품질 요구사항으로 분류한다. 이 중 전환 요구사항은 현재 상태(as-is)에서 미래 상태(to-be)로 옮겨 가는 데 필요한 일시적 역량을 말한다. 대표적인 예가 **데이터 이전(data conversion/migration)**과 **교육훈련(training)**이므로 정답은 ①이다. ② 비즈니스 요구사항은 조직 전체의 상위 목표·필요(사업 기회, 프로젝트 착수 이유)를 기술한다. ③ 비기능적 요구사항은 솔루션 요구사항의 하위 분류로, 신뢰성·보안·성능·안전 같은 환경 조건과 품질 특성을 다룬다. ④ 이해관계자 요구사항은 특정 이해관계자나 이해관계자 그룹의 필요를 다룬다. 셋 다 '이행 기간에만 필요한 데이터 이전·교육'을 가리키는 분류가 아니다.

난이도출제 빈도중요도
하 — PMBOK 요구사항 분류 정의를 알면 즉답 가능중중

4번​

[문제]

어떤 프로젝트가 특정 시점에서 획득가치 분석을 적용한 결과 획득가치(EV) = 800, 계획가치(PV) = 900, 실적원가(AV) = 700로 계산되었다. 이 프로젝트 성과에 대한 설명으로 가장 적절한 것은?

  • ① 일정 성과차이(SV)는 +100이다.
  • ② 원가 성과차이(CV)는 -100이다.
  • ③ 일정 성과지수(SPI)는 0보다 크다.
  • ④ 원가 성과지수(CPI)는 1보다 작다.

[정답] ③

[해설] 지문의 '실적원가(AV)'는 일반적으로 쓰는 **AC(Actual Cost)**와 같은 뜻이다. 공식대로 계산하면 다음과 같다.

  • SV = EV − PV = 800 − 900 = −100
  • CV = EV − AC = 800 − 700 = +100
  • SPI = EV / PV = 800 / 900 ≈ 0.889
  • CPI = EV / AC = 800 / 700 ≈ 1.143

SPI 0.889는 0보다 크므로 ③이 옳다. EV·PV가 모두 양수이면 SPI는 항상 0보다 크므로, ③은 내용상 자명한 참이다. ①은 SV를 +100으로 부호를 거꾸로 적었다. 실제 −100으로 일정 지연 상태다. ②는 CV를 −100이라 했지만 실제 +100으로 원가 절감 상태다. ④는 CPI가 1보다 작다고 했지만 실제 약 1.14로 1보다 크다. 이 프로젝트는 '일정은 지연, 원가는 절감' 상태다(python 검산 결과 동일).

난이도출제 빈도중요도
하 — EVM 기본 공식 네 개로 바로 판정상상

5번​

[문제]

품질 비용(cost of quality)에 관한 설명으로 가장 적절하지 않은 것은?

  • ① 적합(conformance) 비용에는 예방 비용과 평가 비용이 있다.
  • ② 품질 교육 및 훈련, 생산공정계획 및 개선과 관련된 비용은 예방 비용이다.
  • ③ 품질 수준이 100% 양호가 될 때 적합 비용은 최대가 된다.
  • ④ 고객이 발견한 결함과 부적격을 처리하기 위한 비용은 내적 실패(internal failure) 비용이다.

[정답] ④

[해설] 품질비용(COQ)은 다음과 같이 나뉜다.

  • 적합 비용(Cost of Conformance): 예방 비용(교육·훈련, 공정 계획·개선, 문서화, 장비)과 평가 비용(시험, 검사, 품질감사)
  • 부적합 비용(Cost of Non-conformance): 내부 실패 비용(인도 전 조직 내부에서 발견된 결함의 재작업·폐기)과 외부 실패 비용(인도 후 고객이 발견한 결함의 보증수리, 반품, 책임, 평판 손실)

④는 고객이 발견한 결함 처리 비용을 '내적 실패 비용'이라 했으나, 이는 외적(external) 실패 비용이므로 틀렸다. ①은 적합 비용의 구성을 정확히 설명했다. ②의 교육·훈련과 공정 계획·개선은 결함을 미리 막기 위한 대표적 예방 비용이다. ③은 고전적 품질비용 모형 그대로다. 품질 수준이 100% 양호(무결점)에 가까워질수록 예방·평가 투자가 급격히 늘어 적합 비용이 최대가 되고, 부적합 비용은 0에 가까워진다.

난이도출제 빈도중요도
하 — 내부/외부 실패 비용 구분만으로 해결상상

6번​

[문제]

프로젝트 조직에 관한 다음 설명 중 옳은 것을 모두 고른 것은?

가. 중간(균형) 매트릭스 조직(balanced matrix organization) 구조에서 프로젝트 관리자는 기능 관리자 아래에 있어 예산 사용에 제약을 받는다.

나. 강한 매트릭스 조직(strong matrix organization)은 전임 프로젝트 관리자와 프로젝트 행정업무를 전담하는 직원을 가질 수 있다.

다. 약한 매트릭스 조직(weak matrix organization) 구조에서는 직원들이 프로젝트업무를 조정하는 역할을 수행한다.

   j = i + 1;
   while (j<n) do

  • ③ 6

[문제]

다음은 검색 알고리즘에 관한 JAVA Code 문제이다. 숫자 배열 {1, 2, 3, 4}와 정수 k는 3으로 입력되었을 때, 출력 결과로 가장 적절한 것은?

public class Search
{
    public static int search(List<Integer> list, int k)
    {
        int left = 0, right = list.size() -1, result = -1;
        while(left <= right) {
            int mid = left + ((right - left) / 2);
            if (list.get(mid) > k) {
                right = mid -1;
            } else if (list.get(mid) == k) {
                result = mid;
                right = mid -1;
            } else {
                left = mid+1;
            }
        }
        return result;
    }

    public static void main(String[] args) {
        Integer[] intArr = {1, 2, 3, 4};
        List<Integer> list = Arrays.asList(intArr);
        System.out.println(search(list, 3));
    }
}
  • ① 1
  • ② 2
  • ③ 3
  • ④ 4

[정답] ②

[해설] 이 코드는 값이 k와 같을 때도 right = mid - 1로 왼쪽을 계속 탐색해 k가 처음 나타나는 인덱스(lower bound)를 반환하는 이진 탐색이다. 추적하면 다음과 같다.

  1. left=0, right=3 → mid=0+(3−0)/2=1, list[1]=2 < 3 → left=2
  2. left=2, right=3 → mid=2+(3−2)/2=2, list[2]=3 == 3 → result=2, right=1
  3. left=2 > right=1 → 반복 종료, result=2 반환

출력은 2이며 정답은 ②이다(python으로 동일 로직 검산 결과 2). ③ 3은 인덱스가 아니라 찾는 값 자체를 출력한다고 착각한 것이다. ① 1은 첫 mid 값, ④ 4는 배열 길이나 마지막 원소와 헷갈린 값이다.

(단, 코드 실행에 대한 오류는 고려하지 않음)

public void coverage(int x, int y) {
   if ((x > 0) && (y <= 0))
       y = x;
   system.out.printf(x, y);
}
테스트케이스 생성표
TC#조건1 (x>0)의 진리 값조건2 (y<=0)의 진리 값
  • ① TC1 : True – True
  • ② TC2 : True – Flase
  • ③ TC3 : False - True
  • ④ TC4 : False – False

[정답] ④

[해설] MC/DC는 각 개별 조건이 다른 조건을 고정한 상태에서 단독으로 결정 결과를 바꾸는 테스트 쌍을 모두 포함해야 한다. 조건 n개일 때 최소 테스트 수는 보통 n+1개다. 결정식 A && B(A: x>0, B: y<=0)에서 각 조건의 독립 영향 쌍은 다음과 같다.

  • 조건 A: B=True로 고정하고 (T,T)→True, (F,T)→False
  • 조건 B: A=True로 고정하고 (T,T)→True, (T,F)→False

따라서 최소 테스트 집합은 (T,T), (T,F), (F,T) 3개다. (F,F)는 어느 조건의 독립 영향도 보여 주지 못하므로(A나 B 하나만 바꿔도 결과가 계속 False) 최소 집합에 들어가지 않는다. python으로 모든 조합을 탐색한 결과도 독립 쌍은 A가 {(F,T),(T,T)}, B가 {(T,F),(T,T)}뿐이었다. 그러므로 가장 적절하지 않은 것은 ④ TC4: False–False다. ①~③은 모두 최소 MC/DC 집합의 구성원이다. 보기 ②의 'Flase'는 원문의 오타(False)를 그대로 둔 것이다.

적용전 코드
int withdraw(int amount) {
   if (amount > _balence)
       return -1;
   else {
       _balence -= amount;
       return 0;
}
적용후 코드
void withdraw(int amount) throws B_exception {
   if (amount > _balence) throw new B_exception();
   _balence -= amount;
}

  • ② replace exception with test
  • ③ replace parameter with exception

  • ④ Inline Method: 메서드 본문을 호출부에 넣고 메서드를 없애는 기법으로, 지문과 관계없다.

  • ② 가, 나, 라
  • ③ 나, 다, 마
  • ④ 다, 마, 바

[정답] ②

  • 가(○): Git의 브랜치는 특정 커밋을 가리키는 가벼운 포인터(참조) 다.
  • 나(○): 저장소에서 처음 커밋하면 기본 브랜치 master(최근에는 main)가 만들어지고, 커밋할 때마다 가장 최근 커밋으로 자동 이동한다. 지문의 "가장 최근의 브랜치를 가리킨다"는 정확히는 '가장 최근 커밋'을 가리킨다는 뜻이다. 표현이 부정확하지만 출제 의도상 옳은 설명으로 처리되었다.

  • ③ (가) LCOM(Lack of cohesion in methods) (나) RFC(Response for a class)

[해설] Chidamber & Kemerer(CK) 메트릭은 WMC, DIT, NOC, CBO, RFC, LCOM의 6가지다.

  • ③ 클래스 C1에서 클래스 C2로의 연관관계는 C2 클래스 쪽에 '*' 등의 다중성이 명시되어야 한다.

[정답] ③

[해설] 시퀀스 다이어그램에서 :C1은 loop [for each c2 in c2s] 조합 단편 안에서 여러 C2 객체(c2s)에 op21()을 보낸다. 즉 C1 객체 하나가 여러 개의 C2 객체와 연결되어 있으므로, 클래스 다이어그램의 C1→C2 연관(역할명 c2s)에는 C2 쪽에 *(또는 0..*, 1..*) 다중성이 표시되어야 한다. 현재는 다중성이 없어(기본 해석 1) 시퀀스와 불일치하므로 ③이 정답이다. ①: op1()은 C3의 상위 추상 클래스 C4(이탤릭체)에 정의되어 있고 C3가 C4를 상속(일반화)하므로 C3는 op1()을 상속받아 호출이 가능하다. 반드시 C3에 다시 정의할 필요는 없다. ②: C2는 op21() 수행 중 C3 객체에 op1()을 보내는데, 해당 객체를 매개변수·지역변수 등으로 일시적으로 사용하는 것이면 의존관계로 충분하며 시퀀스만으로 연관관계를 강제할 근거가 없다. ④: op12()는 C1이 자기 자신에게 보내는 메시지(self-call)이므로 private(-)이어도 문제없다.

  • ① 나, 가, 라, 다
  • ② 나, 라, 가, 다
  • ③ 다, 나, 가, 라
  • ④ 다, 나, 라, 가

[정답] ④

[해설] 검사시점 회복은 정상 운영 중 검사시점을 수행하는 단계와 장애 뒤 회복하는 단계로 나뉜다.

  • 다(검사시점 수행, 장애 이전): 검사시점에는 메모리의 로그 레코드를 안정 저장장치에 기록하고, 변경된 데이터 버퍼 블록을 모두 디스크에 출력한 뒤 로그 레코드를 남긴다. 장애보다 먼저 일어나므로 순서상 맨 앞이다.
  • 나(분석, 장애 이후): 회복을 시작할 때 UNDO-list는 검사시점에 활동 중이던 트랜잭션으로, REDO-list는 공백으로 초기화한다. 그 뒤 로그를 앞으로 읽어 나가면서 <T, Start>를 만나면 T를 UNDO-list에 넣고, <T, Commit>을 만나면 T를 UNDO-list에서 REDO-list로 옮긴다.

  • ④ PIM-DM: 밀집 모드로, DVMRP와 비슷하게 플러드 앤 프룬 방식의 발신지 기반 트리를 사용한다.

  • ③ 나, 다

    • 두 해석 모두 조문상 근거가 있어 ①과 ②가 모두 정답으로 인정된 것으로 보인다(공식 문제지에서 두 보기 모두 굵게 표시됨. 이의신청 심사 결과문 원문 미확인).

[정답] ④

[해설] **PPTP(Point-to-Point Tunneling Protocol)**는 Microsoft 등이 개발했다. PPP 프레임을 GRE로 캡슐화해 IP망 위로 전달하는 2계층(데이터 링크 계층) 터널링 프로토콜이다. 앞부분 "PPP에 보안 기능을 추가하여 만든 것"은 대체로 맞지만, "네트워크 계층에 적용되는 프로토콜"이라는 부분이 틀렸다. 네트워크 계층(3계층) VPN 프로토콜은 IPSec이다. 따라서 ④가 정답이다. ① L2F는 Cisco가 개발한 2계층 터널링 프로토콜이다. 옳다. ② IPSec은 IETF가 표준화한 3계층 보안 프로토콜로, AH·ESP와 터널·전송 모드를 제공한다. 옳다. ③ L2TP(RFC 2661)는 Cisco의 L2F와 Microsoft의 PPTP를 결합해 두 방식의 장점과 호환성을 살린 2계층 터널링 프로토콜이다. 자체 암호화 기능은 없어 보통 IPSec과 함께 쓴다(L2TP/IPSec). 옳다.
