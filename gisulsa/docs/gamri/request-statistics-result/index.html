정보시스템감리사 필기 기출 출제범위·문제유형 분석

1. 분석 개요​

항목내용
분석 대상gamri/original-converted-md/2023-A.md, 2024-A.md, 2025-A.md
회차제24회(2023) / 제25회(2024) / 제26회(2025) — 모두 A형
문항 수회차당 120문항 × 3회차 = 360문항

과목별 문항 배분 (3회차 공통)​

과목문항 번호문항 수
1. 감리 및 사업관리1 ~ 2525
2. 소프트웨어 공학26 ~ 5025
3. 데이터베이스51 ~ 7525
4. 시스템 구조76 ~ 10025
5. 보안101 ~ 12020

3회차 모두 과목 경계와 문항 수가 완전히 동일하다. 과목별 문항 배분은 고정 구조로 봐도 된다.

집계 기준​

  • 각 문항을 정확히 1개 영역에 배정했다(중복 계상 없음). 따라서 과목별 영역 합계는 항상 해당 과목 문항 수와 일치한다.
  • 문제유형 분석은 한 문항이 여러 유형에 동시에 해당할 수 있다(예: 계산형 + 그림 해석형). 유형별 표에서는 중복 계상하며, 각 표에 그 사실을 명시했다.
  • 영역 배정 근거로 문항 번호를 함께 표기했으므로 원본 md 파일과 대조 검증이 가능하다.

  5. PM 영역은 얕고 넓게 순환한다. 어느 세부영역도 3년 연속 2문항 이상이 아니며, 일정·원가·범위·리스크·인적자원·의사소통을 돌아가며 1~3문항씩 배치한다.

  6. 품질 표준은 ISO/IEC 25010·25023·5055가 고정 출처다. 매년 2~3문항.

  2. 관계이론 3종(관계모델·키·함수종속 / 정규화 / 관계대수)은 매년 합계 5~7문항으로 고정된다. 2023년 5, 2024년 3, 2025년 7. 특히 함수종속 → 후보키/정규형/무손실분해 판정은 매년 형태만 바꿔 반복된다.

  6. 정보검색·질의최적화는 2024년에만 등장한 단발성 영역이다. 반면 2025년에는 XML DTD·데이터 포맷(JSON/CSV)이 새로 들어왔다.

  3. 개인정보보호 법·제도가 급증했다(1 → 2 → 4). 2025년에는 20문항 중 4문항(117~120번)이 연속 배치되어 과목 말미에 개인정보 블록이 고정되는 패턴을 보인다.
  4. VPN 터널링 프로토콜은 3년 연속 출제되었다(2023년 104번, 2024년 112번, 2025년 107번).
  5. 블록체인은 3년 연속 출제되었다(2023년 107번 소프트포크, 2024년 120번 공격 유형, 2025년 114번 특성).
  6. 포렌식·침입탐지·거버넌스는 연도별 단발성이다. 2023년 포렌식 2문항, 2024년 침입탐지 2문항·거버넌스 2문항, 2025년 0문항. 순환 출제로 보인다.

3. 기출문제 유형 분석​

3.1 정답 요구 방향 — 부정형 대 긍정형​

핵심 관찰

  1. 보안은 3년 내내 정확히 12/20(60%)이 부정형이다. 편차가 0이다. 보안 과목은 "틀린 선지 1개 찾기"가 사실상 기본 출제 형식이다.
  2. 감리 및 사업관리도 60%가 부정형이며, 특히 법령·지침 문항은 거의 전부 부정형이다. 2023년은 25문항 중 18문항(72%)이 부정형이었다.
  3. 소프트웨어 공학·데이터베이스는 부정형 비율이 20~25%로 낮다. 대신 계산·코드 해석으로 난도를 만든다.
  4. 2025년 데이터베이스에서 부정형이 3 → 11로 급증했다. "복구할 수 없는 분해", "나올 수 없는 투플", "결과가 다른 하나", "파싱 오류가 발생하는" 등 변형 부정형이 늘었다.

핵심 관찰

  1. 법령·지침 인용형이 가장 뚜렷하게 증가했다(15 → 17 → 23, +53%). 그리고 인용 시 개정 일자까지 명시하는 방식이 강화됐다. 2025년에는 「전자정부법 시행령」·「구축‧운영지침(2025.01.02.)」, 「용역계약 일반조건(2024.12.24.)」, 「감리기준(2024.06.27.)」처럼 거의 모든 인용에 시행일이 붙는다. 최신 개정판 기준 학습이 필수다.
  2. 코드·SQL 해석형이 2배 이상 증가했다(6 → 12 → 14). 단순 문법 암기가 아니라 실행 결과·커버리지 판정·리팩토링 기법 식별을 요구한다.
  3. 계산형은 매년 11~14문항(약 10%)으로 안정적이다. 과목 편중 없이 5과목 전체에 분산된다.
  4. 그림·다이어그램 의존 문항이 매년 8~12문항이다. PDF→MD 변환 자료로 학습할 경우 이 문항들은 이미지 없이는 풀 수 없으므로, converted-md/images/{연도}/ 이미지 참조가 필수다.
  5. 빈칸 채우기형은 감소 추세다(7 → 5 → 2). 반대로 개수형은 증가(0 → 1 → 2).
  6. 조합 선택형은 매년 정확히 10문항으로 고정이다. 편차가 없는 유형이다.

3.3 과목별 유형 특성 요약​

과목지배적 유형난도 형성 방식
1. 감리 및 사업관리법령·지침 인용형 + 부정형(60%)지침 조문의 수치(비율·기간·금액·인원)를 미세하게 틀리게 제시
2. 소프트웨어 공학그림·코드 해석형, 긍정형(79%)다이어그램↔코드 양방향 변환, 리팩토링 전/후 비교, 커버리지 판정
3. 데이터베이스SQL·관계대수 해석형, 계산형함수종속 → 정규형/분해 판정, 인덱스 구조 삽입·삭제 추적, NULL 처리
4. 시스템 구조계산형 + 개념 판별형주소·성능·신호 수치 계산, 프로토콜 필드/명령 세부 구분
5. 보안부정형(60%) + 개념 식별형4개 선지 중 1개 개념을 미세하게 왜곡, 설명문 → 용어 매칭

4. 종합 시사점​

4.1 출제 범위 측면​

#시사점
1과목 구조는 고정이다. 5과목 × 25문항(보안 20)이 3년 불변. 과목별 학습 시간 배분을 구조에 맞춰 설계할 수 있다.
2감리 과목은 법령·지침 최신판 추적이 승부처다. 법령 인용형이 3년간 53% 증가했고, 2025년 과목 1의 76%가 법·제도 문항이다. 개정 일자까지 명시되므로 구판 학습은 오답으로 직결된다.
3매년 고정 출제되는 핵심 6개 축: ① 감리기준·감리대가, ② 테스트 설계기법·커버리지, ③ SQL 조인·중첩질의, ④ 관계이론(함수종속→정규화), ⑤ 네트워크 주소·프로토콜, ⑥ 암호 + 개인정보보호법. 이 6개는 어느 해에도 빠지지 않는다.
4연도 편차가 큰 영역은 오히려 버릴 수 없다. SW 아키텍처(6→0→4), 네트워크(5→8→4), DB 트랜잭션(3→1→1)처럼 0문항 연도가 있어도 다음 해 복귀한다.
5AI·신기술이 전 과목에 침투했다. 2025년 기준 감리(3) + SW공학(3) + DB(3) + 시스템구조(3) = 12문항. 단일 과목 학습으로 대응할 수 없다.
6동일 주제 반복·반전 출제가 실재한다. 신경망 알고리즘 판별(2023-94 ≈ 2024-96), 공개키 암호(2024-115 ≈ 2025-101), 확장성 해싱(2024-71 ≈ 2025-64), CRC(2023-85 ↔ 2025-92 방향 반전), 서브네팅(2023-92 ↔ 2024-87). 직전 2~3회차 기출은 반드시 문항 단위로 정독해야 한다.

4.2 문제 유형 측면​

#시사점
1부정형 대응이 감리·보안 점수를 결정한다. 두 과목 모두 부정형 60%. 정답 선지를 찾는 감각보다 4개 선지 각각의 참/거짓을 판정하는 훈련이 필요하다.
2SW공학·DB는 손으로 풀어야 하는 과목이다. 부정형 비율이 20~25%로 낮은 대신 계산·코드·다이어그램 해석형이 지배한다. 개념 암기만으로는 대응 불가.
3계산형은 매년 11~14문항(약 10%)으로 고정 배당된다. 반복 출제되는 계산 패턴: 자유여유/임계경로, EVM 지표, FP·적정기간, 커버리지 비율, McCabe 복잡도, 카디널리티, 정규형 분해 개수, B/B+트리·해싱 노드 추적, 서브네팅, 캐시 평균접근시간, TPS·가용성.
4이미지 의존 문항이 매년 8~12문항이다. 텍스트 자료만으로 학습하면 최대 10%를 놓친다.
5조합 선택형은 매년 정확히 10문항이다. "가~라 중 옳은 것 모두"는 부분 지식으로 정답률이 급락하므로, 해당 주제는 항목 단위 완결 학습이 필요하다.
62025년 변화 신호 3가지: ① DB 부정형 급증(3→11), ② 법령 인용형 급증(17→23), ③ AI 문항 배증(5→12). 차기 회차 대비 우선순위로 반영할 만하다.
