104번 · 타원곡선 암호기술(ECC)

제22회(2021년) 정보시스템감리사 A형 — 보안

사전 지식​

1. 공개키 암호의 수학적 기반​

난제내용대표 알고리즘
소인수분해 문제(IFP)큰 합성수 n=pqn = pqn=pq에서 p,qp, qp,q를 찾기 어려움RSA, Rabin
이산대수 문제(DLP)gx mod pg^x \bmod pgxmodp에서 xxx를 찾기 어려움Diffie-Hellman, ElGamal, DSA
타원곡선 이산대수 문제(ECDLP)타원곡선 위의 점 Q=kPQ = kPQ=kP에서 kkk를 찾기 어려움ECDH, ECDSA, ECIES

2. 타원곡선 암호(ECC)​

유한체 위의 타원곡선

y2=x3+ax+b(modp)y^2 = x^3 + ax + b \pmod py2=x3+ax+b(modp)

위의 점들이 이루는 군(group)에서 스칼라 곱 Q=kPQ = kPQ=kP 를 계산하기는 쉽지만, PPP와 QQQ로부터 kkk를 구하기는 매우 어렵다는 ECDLP에 안전성을 둔다. 1985년 Koblitz와 Miller가 각각 제안했다.

3. 동일 보안 강도에서의 키 길이 비교 (NIST SP 800-57)​

보안 강도(비트)대칭키RSA/DHECC
802TDEA1024160~223
1123TDEA2048224~255
128AES-1283072256~383
192AES-1927680384~511
256AES-25615360512+

ECC 256비트가 RSA 3072비트와 같은 강도를 낸다. 키가 짧으니 연산량·메모리·대역폭이 적어 스마트카드, IoT, 모바일 환경에 유리하다.

4. 활용​

  • 키 교환: ECDH(TLS의 ECDHE)
  • 전자서명: ECDSA, EdDSA(Ed25519)
  • 암호화: ECIES
  • 비트코인·이더리움 서명(secp256k1), 국내 표준 EC-KCDSA

문제​

정답​

①

상세 풀이​

"가장 적절하지 않은 것"을 고르는 문항이다.

  1. ① "타원곡선 암호기술은 소인수분해 문제에 기반을 둔다." → ECC는 타원곡선 이산대수 문제(ECDLP) 에 기반한다. 소인수분해 문제에 기반한 것은 RSA다. → 부적절 = 정답
  2. ② 키 교환(ECDH), 전자서명(ECDSA)에 사용 가능 → 적절.
  3. ③ 다른 공개키 알고리즘에 비해 계산량이 적다 → 같은 보안 강도에서 키가 훨씬 짧아 연산량이 적다. → 적절.
  4. ④ 짧은 키 길이로 RSA와 동일 수준의 보안 → ECC 256비트 ≈ RSA 3072비트. → 적절.

보기별 판정​

보기판정근거
① 소인수분해 문제에 기반✅ 정답 보기(적절하지 않은 설명)ECC는 ECDLP 기반. 소인수분해는 RSA
② 키 교환·전자서명에 사용오답 보기(적절한 설명)ECDH, ECDSA
③ 계산량이 적다오답 보기(적절한 설명)짧은 키 → 적은 연산·메모리
④ 짧은 키로 RSA와 동등 보안오답 보기(적절한 설명)256비트 ECC ≈ 3072비트 RSA

오답 이유​

  • ①이 틀린 이유: 공개키 암호의 안전성 근거는 알고리즘마다 다르다. RSA = 소인수분해, DH/DSA/ElGamal = 유한체 이산대수, ECC = 타원곡선 위의 이산대수. ECDLP에는 일반 DLP에 쓰이는 지수 계산법(index calculus) 같은 준지수 시간 공격이 적용되지 않아, 짧은 키로도 높은 안전성을 얻는다.
  • ②가 맞는 이유: ECC는 암호 "기법"이 아니라 수학적 "틀"이어서 DH를 옮긴 ECDH, DSA를 옮긴 ECDSA 등 기존 방식을 타원곡선 군 위에 그대로 이식할 수 있다.
  • ③·④가 맞는 이유: 같은 강도에서 키 길이가 RSA의 약 1/10 수준이므로 키 생성·서명 연산이 빠르고 인증서·패킷 크기가 작다. 다만 RSA는 공개지수 e=65537e = 65537e=65537을 쓰는 검증(공개키 연산) 만큼은 매우 빠르다는 점은 참고로 알아둔다.

핵심 정리​

  • ECC = 타원곡선 이산대수 문제(ECDLP), RSA = 소인수분해 문제.
  • 동일 강도 대비 짧은 키(256비트 ECC ≈ 3072비트 RSA) → 적은 연산량, 경량 기기에 적합.
  • 활용: ECDH(키 교환), ECDSA·EdDSA(서명), ECIES(암호화).
