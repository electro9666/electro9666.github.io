020번 · 「SW사업 대가산정 가이드」 — 과업내용 변경에 의한 계약금액 조정

제22회(2021년) 정보시스템감리사 A형 — 감리 및 사업관리

사전 지식​

1. 과업변경 → 계약금액 조정의 규범 체계​

계층규정역할
대통령령「국가계약법 시행령」 제65조(설계변경으로 인한 계약금액의 조정), 용역에 준용증감 금액 산정 원칙
계약예규「용역계약일반조건」 소프트웨어사업 특칙의 과업내용 변경 조항"계약금액 조정은 SW사업 대가의 기준을 준용"
가이드「SW사업 대가산정 가이드」(한국소프트웨어산업협회)조정 금액의 실제 산정 방법

2. 대가 산정의 구성 요소 — 무엇이 고정되고 무엇이 바뀌나​

대가=규모(FP⋅M/M 등)×단가×보정계수×(1+제경비⋅기술료⋅이윤율)×낙찰률\text{대가} = \text{규모(FP·M/M 등)} \times \text{단가} \times \text{보정계수} \times (1 + \text{제경비·기술료·이윤율}) \times \text{낙찰률}대가=규모(FP⋅M/M 등)×단가×보정계수×(1+제경비⋅기술료⋅이윤율)×낙찰률
요소예조정 시 적용 기준
대가산정 방식기능점수 방식, 투입공수 방식당초 계약 시
보정계수규모·연계복잡성·성능·운영환경 호환성·보안성 보정당초 계약 시
제비율제경비·기술료, 이윤, 할인율당초 계약 시
단가FP당 단가, SW기술자 평균임금과업내용 변경요청 시점
낙찰률당초 계약의 낙찰률당초 낙찰률을 곱함

3. 가이드의 조정 기준과 방식​

구분내용
계약금액 조정기준조정액 산정은 과업내용 변경요청 시점을 기준으로 하여 산정한 단가와 동 단가에 낙찰률을 곱한 금액의 범위 안에서 계약당사자 간에 협의하여 결정
계약금액 조정방식「SW사업 대가산정 가이드」를 준용하여 계약조정 금액을 산정. 대가산정 방식(기능점수, 투입공수 등), 보정계수, 제경비/기술료, 이윤, 할인율 등의 제비율은 당초 계약 시의 기준을 동일하게 적용

4. 왜 이렇게 나누나​

원칙이유
단가는 변경요청 시점추가 과업은 '지금' 수행하므로 현재 가격(해당 연도 단가·임금)으로 원가를 보전해야 한다
규칙·비율은 당초 계약 시같은 계약 안에서 산정 규칙이 바뀌면 증액·감액이 서로 다른 잣대로 계산되어 형평이 깨진다. 계약 당시의 경쟁 조건(할인율 등)도 유지해야 한다
낙찰률 곱한 금액 범위 안에서 협의입찰 경쟁으로 형성된 가격 수준을 추가 과업에도 반영(국가계약법 시행령 제65조제3항제3호 — 정부 요구 설계변경 시 "설계변경당시를 기준으로 하여 산정한 단가와 동단가에 낙찰률을 곱한 금액의 범위안에서 계약당사자간에 협의하여 결정"과 같은 구조)

문제​

정답​

③

상세 풀이​

  • (가) "조정액 산정은 ( 가 )을 기준으로 하여 산정한 단가와 동단가에 낙찰률을 곱한 금액의 범위 안에서 협의" → 단가는 최신 가격이어야 하므로 과업내용 변경요청 시점.
  • (나) "대가산정 방식, 보정계수, 제경비/기술료, 이윤, 할인율 등의 제비율은 ( 나 )의 기준을 동일하게 적용" → '동일하게'라는 말 자체가 당초 계약 시의 기준을 유지하라는 뜻이다.

(가) 과업내용 변경요청 시점 · (나) 당초 계약 시 → ③

기억법: "가격은 지금, 규칙은 처음."

보기별 판정​

보기(가) 단가 기준(나) 제비율 기준판정
①당초 계약 시점 ×당초 계약 시 ○오답
②당초 계약 시점 ×과업내용 변경요청 시 ×오답
③과업내용 변경요청 시점 ○당초 계약 시 ○✅ 정답
④과업내용 변경요청 시점 ○과업내용 변경요청 시 ×오답

오답 이유​

  • ①: 단가까지 당초 계약 시점으로 고정하면, 계약 후 임금·단가가 오른 상태에서 추가 과업을 과거 가격으로 수행하게 되어 사업자가 손해를 본다.
  • ②: 단가와 제비율의 기준을 정반대로 뒤집었다.
  • ④: 제비율까지 변경요청 시점으로 바꾸면 계약 도중 산정 규칙이 달라진다. 예컨대 할인율·이윤율을 새로 정하면 당초 경쟁입찰로 정해진 가격 조건이 무너지고, 같은 계약 안의 증액분과 감액분이 서로 다른 잣대로 계산된다. 지문의 '동일하게 적용'이라는 표현과도 맞지 않는다.

핵심 정리​

  • 단가 = 과업내용 변경요청 시점 기준, 그 단가와 낙찰률을 곱한 금액의 범위 안에서 협의.
  • 대가산정 방식·보정계수·제경비/기술료·이윤·할인율 = 당초 계약 시 기준 동일 적용.
  • 기억법: 가격은 지금, 규칙은 처음.

근거 확인 범위: 조정 기준·방식의 문구는 문제 지문과 「SW사업 대가산정 가이드」의 '과업내용 변경에 따른 계약금액 조정' 항목(2024년 A형 002번 해설에서 동일 내용 확인)에 따른다. 국가계약법 시행령 제65조제3항제3호는 국가법령정보센터 원문으로 확인했다. 2020년판 가이드의 해당 쪽 번호는 확인하지 못했다.
