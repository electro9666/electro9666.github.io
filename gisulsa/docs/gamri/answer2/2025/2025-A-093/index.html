093번 · 차분 맨체스터 복호

제26회(2025년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

디지털 → 디지털 인코딩 방식의 분류​

분류방식특징
단극형(Unipolar)NRZ0 또는 +V. DC 성분 큼
극형(Polar)NRZ-L레벨이 곧 값 (예: 낮음=1, 높음=0)
극형NRZ-I비트 시작에서 전이가 있으면 1, 없으면 0 (반전 기준)
극형(바이페이즈)맨체스터비트 중앙에서 반드시 전이, 전이 방향이 값을 결정
극형(바이페이즈)차분 맨체스터비트 중앙에서 반드시 전이(클록용), 값은 비트 시작 전이 유무로 결정
양극형(Bipolar)AMI, B8ZS, HDB30은 0V, 1은 +V/−V 교대

맨체스터 vs 차분 맨체스터​

두 방식 모두 비트 구간 한가운데에 반드시 전이(transition)가 존재한다. 이 중앙 전이가 자체 동기화(self-synchronization) 용 클록 역할을 하여, 같은 값이 길게 이어져도 수신 측이 비트 경계를 잃지 않는다. 차이는 "값을 무엇으로 읽느냐"이다.

구분맨체스터차분 맨체스터
중앙 전이항상 존재 — 값을 표현항상 존재 — 클록만 표현(값과 무관)
값 결정 근거중앙 전이의 방향 (예: 저→고 = 1, 고→저 = 0)비트 시작점의 전이 유무
규약저→고 = 1 / 고→저 = 0 (IEEE 802.3)시작 전이 있음 = 0, 없음 = 1
극성 반전 내성없음 — 신호 극성이 뒤집히면 값도 뒤집힘있음 — 전이 "유무"만 보므로 극성 반전에 강함
대표 적용IEEE 802.3 (10BASE-T 이더넷)IEEE 802.5 (토큰링)
신호 속도(보율)데이터율의 2배데이터율의 2배

차분 맨체스터의 이 "차분(differential)" 이라는 이름은, 절대 레벨이 아니라 직전 구간 끝 레벨과의 차이(전이 유무) 로 값을 판독한다는 뜻이다.

파형 읽는 순서​

  1. 점선(비트 경계)으로 구간을 나눈다. 점선이 k개면 비트는 k+1개다.
  2. 각 구간의 한가운데 전이를 확인한다 — 반드시 있어야 하며, 없으면 차분 맨체스터가 아니거나 위반 부호다.
  3. 각 구간의 시작(경계선 위)에 전이가 있는지만 본다. 있으면 0, 없으면 1.

문제​

정답​

②

상세 풀이​

1단계 — 구간 나누기​

그림의 점선 세로선은 6개이고, 파형 시작점부터 끝까지가 7개의 비트 구간으로 나뉜다. 보기의 이진수가 모두 7자리인 것과도 일치한다.

2단계 — 전이 위치 추출​

파형을 왼쪽부터 따라가며 레벨 변화(전이)가 어디에서 일어나는지 기록한다. H = 높은 레벨, L = 낮은 레벨이다.

전이 발생 위치구간 내 위치방향
파형 맨 처음(구간1 시작)경계H → L
구간1 한가운데중앙L → H
구간2 한가운데중앙H → L
구간2/3 경계—전이 없음 (L 유지)
구간3 한가운데중앙L → H
구간3/4 경계—전이 없음 (H 유지)
구간4 한가운데중앙H → L
구간4/5 경계(구간5 시작)경계L → H
구간5 한가운데중앙H → L
구간5/6 경계(구간6 시작)경계L → H
구간6 한가운데중앙H → L
구간6/7 경계—전이 없음 (L 유지)
구간7 한가운데중앙L → H

모든 구간의 중앙에 전이가 하나씩 존재함을 확인할 수 있다(차분 맨체스터의 필수 조건 충족). 반면 경계 전이는 구간 1, 5, 6의 시작에서만 발생한다.

3단계 — 복호​

"시작 전이 있음 = 0, 없음 = 1" 규칙을 적용한다.

비트구간 앞부분 레벨구간 뒷부분 레벨시작(경계) 전이중앙 전이값
1LH있음 (H→L)L→H0
2HL없음H→L1
3LH없음L→H1
4HL없음H→L1
5HL있음 (L→H)H→L0
6HL있음 (L→H)H→L0
7LH없음L→H1

읽어 내려가면

0 1 1 1 0 0 1  →  0111001

4단계 — 반대 규약 확인​

일부 교재는 "시작 전이 있음 = 1"로 쓰기도 한다. 그 규약을 적용하면 각 비트를 반전한 1000110 이 되는데, 이 값은 보기 어디에도 없다(③ 1000111은 마지막 비트가 다르다). 따라서 출제 의도는 표준 규약(시작 전이 = 0)이며, 답은 0111001 로 확정된다.

따라서 정답은 ②이다.

보기별 판정​

보기판정근거
① 0101110❌ 오답2·3·4번째 비트가 파형과 불일치. 구간 2·3의 경계에는 전이가 없으므로 1이어야 하는데 1 0 1로 읽었다
② 0111001✅ 정답경계 전이가 구간 1·5·6 시작에만 존재 → 해당 자리만 0, 나머지 1
③ 1000111❌ 오답반대 규약을 적용해도 1000110 이므로 마지막 비트가 다르다. 표준 규약에서는 전 비트가 반전
④ 1010001❌ 오답어느 규약으로도 파형과 대응되지 않는다

오답 이유​

  • ① 0101110 — 첫 비트 0은 맞지만 이후가 어긋난다. 이 값은 구간 중앙 전이의 방향을 값으로 읽는 맨체스터 방식과 혼동했을 때 나오기 쉬운 형태다. 차분 맨체스터에서 중앙 전이는 클록 동기화 전용이며 값과 무관하다는 점을 놓친 결과다. 실제 파형의 구간 2·3·4 시작에는 전이가 없으므로 이 자리는 모두 1이어야 한다.

  • ③ 1000111 — "시작 전이 = 1" 이라는 반대 규약을 적용한 값에 가깝다. 그러나 반대 규약의 정확한 결과는 1000110이며, 보기는 마지막 비트가 1로 되어 있어 그마저도 맞지 않는다. 마지막(7번째) 구간의 시작 경계에는 전이가 없으므로, 표준 규약에서는 1, 반대 규약에서는 0이 되어야 한다. 또한 이 문항처럼 보기 중에 0111001(표준 규약 결과)이 그대로 존재하는 경우 표준 규약이 출제 기준임이 명확하다.

  • ④ 1010001 — 파형의 전이 패턴(경계 전이가 1·5·6번 구간 시작에만 존재)과 전혀 대응되지 않는다. 표준 규약으로 읽으면 0이 세 자리(1·5·6번째)에 와야 하는데 이 보기는 0이 네 자리(2·4·5·6번째)에 있다. 반대 규약으로 읽어도 1의 위치가 맞지 않는다. 파형을 NRZ-L처럼 "높으면 1, 낮으면 0"으로 잘못 읽었을 때 나올 수 있는 형태다.

  • 핵심 오류 유형 정리: (가) 중앙 전이를 값으로 읽는 맨체스터와의 혼동(①), (나) 규약 방향 반전(③), (다) 레벨 자체를 값으로 읽는 NRZ-L과의 혼동(④).

핵심 정리​

  • 차분 맨체스터는 비트 중앙 전이가 "항상" 존재하며, 그것은 클록(동기화) 용이지 값이 아니다. 값은 오직 비트 구간 시작점의 전이 유무로 읽는다 — 있으면 0, 없으면 1.
  • 맨체스터는 중앙 전이의 방향이 값(저→고=1, 고→저=0). 두 방식을 혼동하면 전혀 다른 비트열이 나온다.
  • 차분 방식은 절대 레벨이 아니라 변화 유무로 판독하므로 극성 반전(선 두 가닥이 뒤바뀜)에 강하다. 그래서 토큰링(IEEE 802.5)에 채택되었다.
  • 바이페이즈 계열은 비트당 전이가 최소 1회 필요하므로 신호 속도(보율)가 데이터율의 2배여서 대역폭 소모가 크다.
  • 파형 문제 풀이 순서: ① 점선으로 구간 나누기 → ② 중앙 전이 존재 확인 → ③ 경계 전이 유무만 체크.
