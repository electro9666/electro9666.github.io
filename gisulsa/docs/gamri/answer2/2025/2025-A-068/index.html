068번 · Apriori 비-단조 성질

제26회(2025년) 정보시스템감리사 A형 — 데이터베이스

사전 지식​

1) 연관 규칙 마이닝의 기본 지표​

거래 데이터베이스 D(전체 거래 수 N)에서 항목집합 X, Y 에 대해:

지표정의의미
지지도(support)support(X) = (X를 포함한 거래 수) / NX가 얼마나 자주 등장하는가
신뢰도(confidence)confidence(X → Y) = support(X ∪ Y) / support(X)X를 산 사람이 Y도 살 조건부 확률
향상도(lift)lift(X → Y) = confidence(X → Y) / support(Y)1보다 크면 양의 상관, 1이면 독립, 1보다 작으면 음의 상관

빈발 항목집합(frequent itemset) 이란 지지도가 사용자가 정한 최소 지지도(min_sup) 이상인 항목집합이다.

2) 지지도의 반단조(anti-monotone) 성질​

항목집합이 커지면(상위 집합이 되면) 그 항목집합을 모두 포함해야 하므로 조건이 더 까다로워진다. 따라서:

X ⊆ Y  ⟹  support(X) ≥ support(Y)

즉 항목집합이 커질수록 지지도는 결코 증가하지 않는다(감소하거나 같다). 이것을 지지도의 반단조성(anti-monotonicity) 또는 하향 폐쇄 성질(downward closure property) 이라 한다.

간단한 예로 거래 4건이 있다고 하자.

거래항목
T1빵, 우유, 버터
T2빵, 우유
T3빵, 버터
T4우유
항목집합포함 거래지지도
{빵}T1, T2, T33/4 = 0.75
{빵, 우유}T1, T22/4 = 0.50
{빵, 우유, 버터}T11/4 = 0.25

집합이 커질수록 지지도가 단조 감소하는 것을 확인할 수 있다.

3) Apriori 원리의 두 가지 표현​

같은 성질을 방향만 바꿔 말한 것이다.

표현진술용도
하향 폐쇄(양의 형태)빈발 항목집합의 모든 부분집합도 빈발하다후보 생성(join)의 근거
반단조(대우 형태)어떤 항목집합이 빈발하지 않으면 그 모든 상위 집합도 빈발하지 않다가지치기(prune) 의 근거

두 번째 진술이 첫 번째의 대우(contrapositive) 이므로 논리적으로 동치다. 실제 알고리즘에서 탐색 공간을 줄이는 데 직접 쓰이는 것은 가지치기 형태다.

4) Apriori 알고리즘의 동작​

1. C1 = 모든 1-항목집합 → 스캔하여 지지도 계산 → L1 = 빈발 1-항목집합
2. k = 2부터 반복:
   a. [후보 생성] L(k-1) 의 원소들을 조인하여 Ck 생성
   b. [가지치기] Ck의 원소 중 (k-1)-부분집합이 하나라도 L(k-1)에 없으면 제거  ← 반단조성 활용
   c. [지지도 계산] DB를 스캔하여 Ck 각 후보의 지지도 계산
   d. Lk = 지지도가 min_sup 이상인 후보
3. L(k)가 비면 종료. 결과 = L1 ∪ L2 ∪ ... 
4. 빈발 항목집합에서 신뢰도 기준을 만족하는 연관 규칙 생성

2-b 단계가 이 문항이 묻는 반단조성의 직접적인 응용이다. 예를 들어 {A, B} 가 빈발하지 않다고 판명되면, {A, B, C}, {A, B, D}, {A, B, C, D} 등 {A, B} 를 포함하는 모든 상위 집합은 지지도를 계산해 볼 필요조차 없이 후보에서 제거된다. 항목이 n 개일 때 전체 항목집합 수는 2^n − 1 개로 지수적이므로, 이 가지치기가 없으면 알고리즘이 실용성을 잃는다.

5) 비교: 반단조 vs 단조​

성질정의해당 지표
반단조(anti-monotone)집합이 커지면 값이 감소하거나 같음. 조건을 만족 못 하면 상위 집합도 만족 못 함지지도
단조(monotone)집합이 커지면 값이 증가하거나 같음항목집합의 총 가격 합 등

신뢰도는 반단조도 단조도 아니어서, 빈발 항목집합을 먼저 다 구한 뒤 규칙 생성 단계에서 별도로 처리한다.

문제​

정답​

①

상세 풀이​

[1단계] 반단조성의 정의 확인​

지지도의 반단조성은 다음 식에서 출발한다.

X ⊆ Y  ⟹  support(X) ≥ support(Y)

여기에 "빈발 = 지지도 ≥ min_sup" 이라는 정의를 적용한다.

양의 형태(하향 폐쇄)

Y가 빈발  ⟹  support(Y) ≥ min_sup
          ⟹  X ⊆ Y 인 모든 X에 대해 support(X) ≥ support(Y) ≥ min_sup
          ⟹  X도 빈발

→ "빈발 항목집합의 모든 부분집합도 빈발하다."

대우 형태(가지치기)

위 명제의 대우를 취하면:

X가 빈발하지 않음  ⟹  X를 포함하는 모든 상위 집합 Y도 빈발하지 않음

→ 이것이 바로 보기 ①의 진술이다.

[2단계] 구체적 검증​

min_sup = 0.5, 앞의 거래 4건 예제로 확인한다.

항목집합지지도빈발 여부
{버터}2/4 = 0.50빈발
{우유, 버터}1/4 = 0.25빈발 아님
{빵, 우유, 버터}1/4 = 0.25빈발 아님

{우유, 버터} 가 빈발하지 않으므로, 이를 포함하는 {빵, 우유, 버터} 는 지지도를 계산하지 않고도 빈발하지 않다고 단정할 수 있다. 실제 계산해 보아도 0.25로 예측과 일치한다.

[3단계] 각 보기의 진위 판정​

보기진술의 논리 형태판정
①¬빈발(X) ⟹ ¬빈발(상위집합)참 — 반단조성의 대우 형태 그 자체
②크기 ↑ ⟹ 지지도 ↑거짓 — 방향이 반대
③빈발(X) ⟹ 빈발(상위집합)거짓 — 부분집합에 대해서만 성립
④지지도 낮을수록 규칙 가능성 높음거짓 — 정반대

따라서 정답은 ①.

보기별 판정​

보기판정근거
① 빈발하지 않으면 상위 집합도 빈발하지 않다✅ 정답반단조성의 대우 형태이며 Apriori 가지치기의 직접적 근거
② 항목집합 크기가 커질수록 지지도도 증가❌ 오답X ⊆ Y ⟹ support(X) ≥ support(Y) 로 크기가 커지면 지지도는 감소하거나 같다
③ 빈발 항목집합의 모든 상위 집합도 빈발❌ 오답하향 폐쇄는 부분집합 방향으로만 성립한다. 상위 집합 방향은 보장되지 않는다
④ 지지도가 낮을수록 연관 규칙이 될 가능성이 높다❌ 오답빈발(지지도가 높은) 항목집합에서만 규칙을 생성한다. 서술이 정반대다

오답 이유​

  • ②가 틀린 이유: 부등호의 방향을 반대로 진술했다. 항목집합에 원소가 추가되면 그 집합을 포함하기 위한 조건이 더 까다로워지므로 해당 거래 수는 줄어들거나 그대로다. 수식으로는 X ⊆ Y ⟹ support(X) ≥ support(Y) 이고, 앞의 예제에서 {빵} 0.75 → {빵, 우유} 0.50 → {빵, 우유, 버터} 0.25 로 명확히 감소한다. 올바른 서술은 "항목집합의 크기가 증가할수록 지지도는 감소하거나 같다"이다. 지지도가 증가한다면 Apriori의 가지치기 자체가 성립할 수 없다.
  • ③이 틀린 이유: 하향 폐쇄 성질의 방향을 뒤집은 진술이다. 올바른 명제는 "빈발 항목집합의 모든 부분집합(subset) 도 빈발하다"인데, 보기는 상위 집합(superset) 이라고 했다. 반례는 쉽게 찾을 수 있다. 앞 예제에서 min_sup = 0.5 일 때 {빵}(0.75)과 {우유}(0.75)는 모두 빈발이지만, 그 상위 집합인 {빵, 우유, 버터} 는 0.25로 빈발하지 않다. 만약 ③이 참이라면 어떤 항목이든 하나만 빈발하면 전체 항목집합이 모두 빈발해야 하므로, 빈발 항목집합을 찾는다는 문제 자체가 무의미해진다.
  • ④가 틀린 이유: 연관 규칙 마이닝의 절차를 정반대로 서술했다. Apriori는 ① 최소 지지도를 넘는 빈발 항목집합을 먼저 찾고 → ② 그 안에서 최소 신뢰도를 넘는 규칙을 생성하는 2단계 구조다. 즉 지지도가 낮은 항목집합은 애초에 규칙 생성 후보에서 탈락한다. 지지도가 낮다는 것은 그 패턴이 드물게 나타난다는 뜻이므로, 규칙으로 만들어도 통계적 신뢰성이 없고 우연일 가능성이 크다. 올바른 서술은 "지지도가 높은(빈발한) 항목집합일수록 의미 있는 연관 규칙이 될 가능성이 높다"이다.
  • ①이 옳은 이유: 지지도의 반단조성 X ⊆ Y ⟹ support(X) ≥ support(Y) 로부터 대우를 취해 직접 유도되며, Apriori가 k-후보 집합에서 (k−1)-부분집합이 빈발 목록에 없는 후보를 제거하는 가지치기 단계의 논리적 근거가 된다. 이 원리 덕분에 2^n − 1 개의 지수적 탐색 공간을 실용적인 수준으로 줄일 수 있다.

핵심 정리​

  • 지지도의 반단조성(하향 폐쇄): X ⊆ Y ⟹ support(X) ≥ support(Y). 항목집합이 커지면 지지도는 결코 증가하지 않는다.
  • 같은 성질의 두 표현을 방향까지 정확히 구분한다. "빈발 집합의 부분집합은 빈발"(양의 형태, 후보 생성 근거) ↔ "비빈발 집합의 상위 집합은 비빈발"(대우 형태, 가지치기 근거). 보기 ③은 이 방향을 뒤집은 전형적 함정이다.
  • Apriori는 이 가지치기로 2^n − 1 개의 지수적 탐색 공간을 줄인다. {A, B} 가 비빈발이면 이를 포함한 모든 상위 집합은 지지도 계산 없이 제거된다.
  • 절차는 빈발 항목집합 탐색(지지도 기준) → 연관 규칙 생성(신뢰도 기준) 의 2단계다. 지지도가 낮은 항목집합은 규칙 후보가 되지 못한다.
