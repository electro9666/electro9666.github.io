097번 · 과적합과 경사소실

제26회(2025년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

편향-분산 트레이드오프와 과적합·과소적합​

구분과소적합(Underfitting)적정과적합(Overfitting)
모델 복잡도너무 단순적정너무 복잡
학습 데이터 오차높음낮음매우 낮음
검증/테스트 오차높음낮음높음
원인표현력 부족, 학습 부족—학습 데이터를 과하게 학습, 데이터 부족, 파라미터 과다
특성편향(bias) 큼균형분산(variance) 큼 — 잡음까지 암기

과적합의 전형적 신호는 학습 손실은 계속 내려가는데 검증 손실이 어느 시점부터 다시 올라가는 것이다.

과적합 해결 기법​

기법원리
정규화(Regularization)를 통한 가중치 규제손실함수에 가중치 크기에 대한 벌점(penalty)을 더해 큰 가중치를 억제
— L1(Lasso)벌점 = λ · Σ(가중치 절댓값의 합). 일부 가중치를 정확히 0으로 만들어 특징 선택 효과
— L2(Ridge, weight decay)벌점 = λ·Σw². 가중치를 전반적으로 작게 유지해 모델을 완만하게
드롭아웃(Dropout)학습 시 뉴런을 확률적으로 비활성화해 특정 경로 의존을 방지
조기 종료(Early Stopping)검증 손실이 상승 전환하면 학습 중단
데이터 증강(Augmentation)회전·이동·잡음 추가 등으로 학습 데이터 다양화
교차 검증(k-fold CV)데이터 분할을 바꿔 가며 일반화 성능 평가
모델 단순화 / 앙상블파라미터 축소, 배깅·부스팅으로 분산 완화

역전파(Backpropagation)​

단계내용
① 순전파(Forward)입력 → 은닉층 → 출력층으로 계산하여 예측값 산출
② 손실 계산손실함수(MSE, Cross-Entropy 등)로 예측값과 정답의 오차 계산
③ 역전파연쇄법칙(chain rule)으로 출력층 → 입력층 방향으로 각 가중치의 기울기(gradient) 계산
④ 가중치 갱신w ← w − η·∂L/∂w (η = 학습률). 경사하강법(SGD, Adam 등)

즉 역전파는 "손실을 계산하고 그 기울기를 거꾸로 전파하여 가중치를 갱신"하는 절차다.

경사 소실(Vanishing Gradient)과 경사 폭주(Exploding Gradient)​

역전파는 각 층의 미분값을 연쇄적으로 곱해 나간다. 층이 L개면 기울기는 대략 층별 미분값의 L제곱 형태가 된다.

현상조건결과
경사 소실층별 미분값이 1보다 작음 (예: 시그모이드의 최대 미분값 = 0.25)곱이 기하급수적으로 0에 수렴 → 입력층 쪽 가중치가 갱신되지 않아 학습 정체
경사 폭주층별 미분값이 1보다 큼곱이 발산 → 가중치가 NaN으로 튐

즉 은닉층이 깊어질수록 곱해지는 항이 늘어나 경사 소실은 더 심해진다. 깊이는 원인이지 해결책이 아니다.

경사 소실의 해결 기법​

기법원리
ReLU 계열 활성함수ReLU(x)=max(0,x) — 양의 구간 미분값이 1이라 곱해도 줄지 않음. Leaky ReLU, ELU, GELU 등
배치 정규화(Batch Normalization)각 층 입력 분포를 정규화해 활성함수의 포화(saturation) 구간 진입 억제
잔차 연결(Residual/Skip Connection)ResNet의 y = F(x) + x — 항등 경로로 기울기가 그대로 흘러감
가중치 초기화 개선Xavier(Glorot), He 초기화로 층별 분산 유지
LSTM/GRU의 게이트RNN 계열에서 셀 상태를 통해 기울기 경로 확보
그래디언트 클리핑주로 경사 폭주 대응

문제​

정답​

④

상세 풀이​

"가장 적절하지 않은 것"을 고르는 유형이므로, 틀린 서술을 담은 보기가 정답이다.

보기 ① 검증 — 과적합의 원인​

"과적합 문제는 학습 데이터를 과하게 학습한 경우에 발생한다." → 과적합의 정의 그대로다. 모델이 학습 데이터의 잡음과 우연한 패턴까지 암기하여 새로운 데이터에 일반화하지 못하는 상태다. 옳다.

보기 ② 검증 — 과적합의 해결책​

"정규화를 사용한 가중치 규제는 과적합을 해결하는 방법이다." → L1/L2 정규화는 손실함수에 가중치 크기 벌점을 더해 모델이 지나치게 복잡한 결정 경계를 만들지 못하도록 억제한다. 대표적인 과적합 억제 기법이다. 옳다.

L_total = L_data + λ · Σ|w|      (L1)
L_total = L_data + λ · Σ w²      (L2 = weight decay)

보기 ③ 검증 — 역전파의 동작​

"역전파 알고리즘은 손실함수를 계산하며 가중치를 갱신한다." → 순전파로 손실을 구하고, 연쇄법칙으로 손실에 대한 각 가중치의 편미분을 역방향으로 전파하여 w ← w − η·∂L/∂w 로 갱신한다. 옳다.

보기 ④ 검증 — 경사 소실의 해결책​

"경사소실은 학습모델의 은닉층을 증가시켜 해결할 수 있다." → 방향이 정반대다.

은닉층 수곱해지는 미분항 개수입력층 쪽 기울기
3층3개 (예: 0.25³ ≈ 0.0156)작음
10층10개 (0.25¹⁰ ≈ 9.5 × 10⁻⁷)거의 0
20층20개 (0.25²⁰ ≈ 9.1 × 10⁻¹³)완전히 소멸

은닉층을 늘릴수록 곱해지는 항이 늘어 기울기는 더 빠르게 0으로 수렴한다. 즉 은닉층 증가는 경사 소실의 원인이지 해결책이 아니다. 실제 해결책은 ReLU 계열 활성함수, 배치 정규화, 잔차 연결, He/Xavier 초기화 등이다. 적절하지 않다 → 정답.

따라서 정답은 ④이다.

보기별 판정​

보기판정근거
① 과적합은 학습 데이터를 과하게 학습해 발생오답 보기 (서술이 옳음)과적합의 정의. 학습 오차↓ / 검증 오차↑
② 정규화를 통한 가중치 규제는 과적합 해결책오답 보기 (서술이 옳음)L1/L2 벌점항으로 모델 복잡도 억제
③ 역전파는 손실함수를 계산하며 가중치를 갱신오답 보기 (서술이 옳음)순전파 → 손실 → 연쇄법칙 역전파 → 경사하강 갱신
④ 경사소실은 은닉층을 증가시켜 해결✅ 정답 보기 (서술이 틀림)은닉층 증가는 경사 소실의 원인. 해결은 ReLU·배치정규화·잔차연결 등

오답 이유​

이 문항은 "적절하지 않은 것"을 묻는 유형이므로, ①·②·③은 서술이 옳기 때문에 정답이 될 수 없다. 각각이 왜 옳은 서술인지 정리하면 다음과 같다.

  • ① 옳은 서술인 이유 — 과적합은 모델이 학습 데이터에 과도하게 맞춰진(over-fitted) 상태를 가리킨다. 학습 데이터에 포함된 측정 잡음이나 표본 특유의 우연한 패턴까지 함수로 흡수해 버려, 학습 오차는 거의 0에 가까워지지만 새로운 데이터에 대한 검증·테스트 오차는 오히려 상승한다. 분산(variance)이 큰 상태이며, 데이터 양에 비해 파라미터가 많거나 학습 epoch가 과도할 때 나타난다.

  • ② 옳은 서술인 이유 — 정규화(Regularization)는 손실함수에 가중치 크기에 비례하는 벌점항을 더해, 최적화 과정이 큰 가중치를 피하도록 유도한다. 가중치가 작으면 입력의 작은 변화에 출력이 민감하게 반응하지 않아 결정 경계가 완만해지고, 그 결과 학습 데이터의 잡음을 덜 따라가게 되어 일반화 성능이 향상된다. L2(Ridge, weight decay)는 가중치를 전반적으로 축소하고, L1(Lasso)은 일부 가중치를 0으로 만들어 특징 선택 효과까지 준다. 대표적이고 표준적인 과적합 대응책이다.

  • ③ 옳은 서술인 이유 — 역전파는 ㉠ 순전파로 예측값을 만들고, ㉡ 손실함수로 오차를 계산한 뒤, ㉢ 연쇄법칙을 이용해 출력층에서 입력층 방향으로 각 가중치에 대한 손실의 편미분(기울기)을 전파하고, ㉣ 경사하강법으로 w ← w − η·∂L/∂w 갱신을 수행하는 알고리즘이다. 보기의 "손실함수를 계산하며 가중치를 갱신한다"는 이 과정을 요약한 정확한 서술이다.

  • ④ 가 틀린 서술인 이유(정답) — 경사 소실은 역전파 시 각 층의 활성함수 미분값이 연쇄적으로 곱해지면서 기울기가 0으로 수렴하는 현상이다. 시그모이드의 미분 최댓값이 0.25이므로 층이 하나 깊어질 때마다 기울기가 최대 1/4로 줄어든다. 은닉층을 늘리면 곱해지는 항이 늘어 소실이 더 심해질 뿐이다. 실제로 딥러닝이 2000년대 중반까지 정체했던 이유가 바로 이 문제였고, ReLU 활성함수·배치 정규화·He 초기화·잔차 연결(ResNet) 같은 기법이 등장하면서 비로소 100층 이상의 심층망 학습이 가능해졌다. 올바른 서술은 "경사소실은 ReLU 계열 활성함수, 배치 정규화, 잔차 연결, 가중치 초기화 개선 등으로 완화할 수 있다"이다.

핵심 정리​

  • 과적합 = 학습 오차↓ + 검증 오차↑. 해결: 정규화(L1/L2)·드롭아웃·조기 종료·데이터 증강·교차 검증·모델 단순화.
  • 역전파 = 순전파 → 손실 계산 → 연쇄법칙으로 기울기 역전파 → 경사하강법으로 가중치 갱신.
  • 경사 소실은 은닉층이 깊어질수록 심해진다. 층 증가는 원인이지 해결책이 아니다 — 이 뒤집기가 본 문항의 함정.
  • 경사 소실 해결책 4종: ReLU 계열 활성함수 / 배치 정규화 / 잔차(스킵) 연결 / He·Xavier 초기화. 반대 현상인 경사 폭주는 그래디언트 클리핑으로 대응한다.
