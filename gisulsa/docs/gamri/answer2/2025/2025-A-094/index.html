094번 · VLAN 프레임 태깅 표준

제26회(2025년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

VLAN(Virtual LAN)이란​

VLAN은 하나의 물리적 스위치(또는 여러 대의 스위치)를 논리적으로 분할하여 복수의 브로드캐스트 도메인을 만드는 기술이다. 물리적 배선 위치와 무관하게 부서·용도별로 단말을 묶을 수 있다.

도입 효과설명
브로드캐스트 도메인 분리불필요한 브로드캐스트 트래픽을 VLAN 내부로 제한해 성능 향상
보안서로 다른 VLAN 간 통신은 L3 라우팅(또는 L3 스위치) 을 거쳐야 하므로 접근 통제 지점 확보
유연성사용자의 물리적 이동 시 재배선 없이 포트 VLAN 설정만 변경
비용 절감물리 스위치를 부서 수만큼 두지 않아도 됨

VLAN 멤버십 결정 방식​

방식기준비고
포트 기반(정적)스위치 포트 번호가장 일반적. 설정 단순
MAC 주소 기반단말 MAC이동성 좋으나 관리 부담
프로토콜/IP 서브넷 기반상위 계층 정보L3 정보를 참조
동적 VLAN인증 서버(VMPS/RADIUS)IEEE 802.1X 인증과 연계

프레임 태깅(Frame Tagging)과 트렁크​

VLAN이 한 대의 스위치 안에만 있다면 포트 매핑 테이블만으로 충분하다. 그러나 여러 스위치에 걸쳐 같은 VLAN이 존재하면, 스위치 간 연결선(트렁크 링크, trunk) 하나로 여러 VLAN의 프레임이 섞여 흐르게 된다. 이때 "이 프레임이 어느 VLAN 소속인지"를 프레임 자체에 실어 보내야 하는데, 이것이 프레임 태깅이다.

IEEE 802.1Q 태그 구조 (4바이트)​

기존 이더넷 프레임의 출발지 MAC 주소 뒤, 길이/타입 필드 앞에 4바이트가 삽입된다.

필드크기값·의미
TPID (Tag Protocol Identifier)16비트고정값 0x8100 — "이 프레임은 802.1Q 태그 프레임"
PCP (Priority Code Point)3비트우선순위 0~7. IEEE 802.1p 의 CoS 값
DEI/CFI1비트폐기 적격 표시(구 규격에서는 Canonical Format Indicator)
VID (VLAN Identifier)12비트VLAN 번호 0~4095 (0과 4095는 예약 → 사용 가능 1~4094)

프레임 길이는 태그 4바이트만큼 늘어나므로 최대 프레임 크기가 1518 → 1522바이트가 된다(베이비 자이언트 프레임).

  • 태그 프레임 vs 언태그 프레임: 트렁크 링크에는 태그가 붙은 채로, 단말이 연결된 액세스 포트로 나갈 때는 태그를 제거하고 내보낸다.
  • 네이티브 VLAN: 트렁크에서 태그 없이 전달되는 VLAN. 802.1Q만의 개념이다.
  • 시스코 독자 규격인 ISL은 프레임 전체를 26바이트 헤더 + 4바이트 CRC로 캡슐화하는 방식으로, 태그를 삽입하는 802.1Q와 대비된다. 현재는 802.1Q가 사실상 표준이다.

헷갈리기 쉬운 IEEE 802 표준 번호​

표준내용

문제​

정답​

②

상세 풀이​

지문에서 정답을 결정짓는 단서는 세 가지다.

지문의 단서해석
"여러 VLAN 스위치를 사용하는 경우 … 다른 스위치에 연결된 시스템 중 같은 VLAN 그룹에 속하는지를 알아야 한다"스위치를 넘나드는 VLAN 식별 문제 → 트렁크 링크 상황
"프레임 태깅을 정의한 프로토콜"태깅 표준을 직접 지목
"MAC 프레임에 추가적인 헤더를 사용하여 목적지 VLAN을 정의"L2 프레임에 태그 필드를 삽입

  1. 계층과 대상 확인 — "MAC 프레임"이라 했으므로 데이터 링크 계층(L2), 즉 IEEE 802.1 또는 802.3 계열이다. 이 시점에서 무선 WPAN 규격인 802.15.1은 배제된다.

  2. 기능 확인 — "프레임 태깅으로 목적지 VLAN을 정의"는 VLAN 식별 정보를 프레임에 삽입한다는 뜻이다. VLAN 태깅 표준은 IEEE 802.1Q 하나뿐이다.

  3. 구조로 재확인 — 802.1Q는 출발지 MAC 뒤에 TPID(0x8100) + PCP + DEI + VID(12비트) 로 구성된 4바이트 태그를 삽입한다. VID가 곧 지문의 "목적지 VLAN"에 해당한다. 12비트이므로 실사용 VLAN 번호는 1~4094다.

  4. 나머지 보기 배제 — 802.1D는 루프 방지(STP), 802.3af는 전력 공급(PoE), 802.15.1은 블루투스로 모두 VLAN과 무관하다.

따라서 정답은 ②이다.

보기별 판정​

보기판정근거
① IEEE 802.1D❌ 오답MAC 브리지/STP 표준. 루프 방지를 위해 포트를 차단하는 역할이며 VLAN 태깅과 무관
② IEEE 802.1Q✅ 정답VLAN 프레임 태깅 표준. MAC 프레임에 4바이트 태그(TPID·PCP·DEI·VID)를 삽입
③ IEEE 802.3af❌ 오답PoE — 이더넷 케이블로 최대 15.4W 전력을 공급하는 표준
④ IEEE 802.15.1❌ 오답블루투스 — WPAN용 근거리 무선 표준

오답 이유​

  • ① IEEE 802.1D — "MAC Bridges" 표준으로, 여러 스위치가 이중화 경로로 연결되었을 때 브로드캐스트 스톰과 프레임 무한 순환을 막기 위해 스패닝 트리(STP)를 구성하는 규격이다. 논리적으로 루프 없는 트리를 만들어 중복 경로 포트를 Blocking 상태로 두는 것이 역할이다. 같은 802.1 계열이라 번호가 비슷해 혼동하기 쉽지만, 프레임에 어떤 헤더도 추가하지 않으며 VLAN 소속을 표시하지도 않는다. 802.1D의 후속이 802.1w(RSTP), 802.1s(MSTP)다.

  • ③ IEEE 802.3af — PoE(Power over Ethernet) 표준으로, 데이터 케이블(UTP)을 통해 전원을 함께 공급하여 IP 전화기·AP·IP 카메라 등을 별도 전원 없이 설치할 수 있게 한다. 포트당 최대 15.4W를 공급하며, 확장판인 802.3at(PoE+)는 30W, 802.3bt는 최대 90W급이다. 전력 전달 규격이므로 프레임 형식이나 VLAN과는 전혀 관련이 없다.

  • ④ IEEE 802.15.1 — 블루투스(Bluetooth) 의 기반이 된 WPAN(Wireless Personal Area Network) 표준이다. 2.4GHz ISM 대역에서 주파수 호핑(FHSS)을 사용하며 통신 거리는 대체로 10m 내외다. 무선 개인 영역 네트워크 규격이므로, 유선 스위치 간 트렁크에서 VLAN을 구분하는 문제와는 대상 자체가 다르다. 참고로 지그비의 기반은 같은 계열의 802.15.4다.

  • 이 문항은 결국 "802.1Q = VLAN 태깅" 이라는 한 줄을 외우고 있는지를 묻는다. 지문의 "MAC 프레임에 추가 헤더", "프레임 태깅", "목적지 VLAN 정의"라는 표현이 802.1Q 태그(TPID+PCP+DEI+VID)를 그대로 서술한 것이다.

핵심 정리​

  • IEEE 802.1Q = VLAN 프레임 태깅 표준. 출발지 MAC 뒤에 4바이트 태그(TPID 0x8100 / PCP 3비트 / DEI 1비트 / VID 12비트)를 삽입한다.
  • VID가 12비트이므로 VLAN 번호는 0~4095, 0·4095는 예약되어 실사용 1~4094. 태그 때문에 최대 프레임은 1518 → 1522바이트.
  • 태그는 스위치 간 트렁크 링크에서 필요하며, 단말이 붙는 액세스 포트로 나갈 때는 제거된다. 태그 없이 흐르는 VLAN이 네이티브 VLAN이다.
  • 번호 혼동 주의: 802.1D = STP, 802.1p = 우선순위(CoS), 802.1X = 포트 인증, 802.3af = PoE, 802.15.1 = 블루투스, 802.15.4 = 지그비 기반.
