034번 · 강건성과 거리 척도

제26회(2025년) 정보시스템감리사 A형 — 소프트웨어 공학

사전 지식​

AI 소프트웨어의 강건성(Robustness) 정의​

강건성은 입력에 작은 변화(perturbation)가 가해져도 출력이 바뀌지 않는 성질이다. 형식적으로는 다음과 같이 쓴다.

모든 x' 에 대하여  d(x, x') <= ε  이면  f(x') = f(x)

여기서 d(·,·) 가 거리 함수, ε 가 허용 반경이다. 즉 강건성은 거리 척도를 정하지 않으면 정의 자체가 성립하지 않는다. 그래서 AI 안전성 논문·표준에서는 항상 "L2 기준 강건성", "L∞ 기준 강건성"처럼 척도를 명시한다.

민코프스키 거리(Minkowski distance)와 특수화​

두 점 x1 = (a1, a2, ..., an), x2 = (b1, b2, ..., bn) 에 대해

Lp(x1, x2) = ( Σ |ai - bi|^p )^(1/p)
p이름2차원에서의 계산식기하적 의미단위 반경의 모양
p = 1맨해튼(Manhattan), L1, 시가지 거리abs(Δx) + abs(Δy)좌표축을 따라 꺾어서 이동한 총 거리마름모(◇)
p = 2유클리드(Euclidean), L2sqrt(Δx² + Δy²)두 점을 잇는 직선(대각선) 거리원(○)
p → ∞체비쇼프(Chebyshev), L∞, 체스판 거리max(abs(Δx), abs(Δy))좌표 차이 중 가장 큰 값 하나정사각형(□)

세 거리 사이에는 항상 L∞ ≤ L2 ≤ L1 이 성립한다(직각삼각형에서 빗변은 두 변의 합보다 짧고 각 변보다 길다).

그림 읽는 법​

두 점 x1, x2 를 직각삼각형의 두 꼭짓점으로 보면

  • 빗변(대각선) = 두 점을 직접 잇는 선 = 유클리드 거리(L2)
  • 수직 변 = |Δy| (세로 방향 좌표 차이)
  • 수평 변 = |Δx| (가로 방향 좌표 차이)
  • 수직 변 + 수평 변 = 맨해튼 거리(L1)
  • 수직 변과 수평 변 중 더 긴 쪽 = 체비쇼프 거리(L∞)

문제 그림에서 가는 x1과 x2를 잇는 대각선(점선), 나는 오른쪽 수직 선분, 다는 아래쪽 수평 선분이다.

참고 — 'Safe distance'​

보기 ②의 "세이프 거리(Safe distance)"는 민코프스키 계열의 표준 거리 척도 명칭이 아니다. 강건성 논의에서 "safe radius(안전 반경)"라는 용어는 쓰이지만, 이는 어떤 척도로 잰 허용 반경 ε 을 가리키는 말이지 별도의 거리 정의가 아니다.

문제​

정답​

①

상세 풀이​

그림의 세 선분을 좌표 성분으로 치환한다. x1 = (x_a, y_a), x2 = (x_b, y_b) 라 하고 Δx = |x_b - x_a|, Δy = |y_b - y_a| 로 둔다.

  1. 가 (대각선 점선) — x1에서 x2로 곧바로 잇는 선분이다. 직각삼각형의 빗변이므로 피타고라스 정리에 의해 
    가 = sqrt(Δx² + Δy²) = L2 = 유클리드 거리
    → "가 - 유클리드 거리"는 옳다.
  2. 나 (오른쪽 수직 선분) — x2에서 아래로 내린 세로 변이므로 길이는 Δy 하나다. 
    나 = Δy
    체비쇼프 거리는 max(Δx, Δy) 인데, 그림에서 수평 변 다가 수직 변 나보다 길어 보이므로 max는 오히려 다 쪽이다. 설령 나가 더 길더라도 "수직 성분 = 체비쇼프"는 일반적으로 성립하지 않는다(어느 쪽이 큰지는 두 점의 배치에 따라 달라진다). → "나 - 체비쇼프"는 성립하지 않는다.
  3. 다 (아래쪽 수평 선분) — 가로 변이므로 길이는 Δx 하나다. 
    다 = Δx
    맨해튼 거리는 Δx + Δy, 즉 다 + 나 를 합쳐야 한다. 다 하나만으로는 맨해튼 거리가 되지 못한다. → "다 - 맨해튼"은 틀렸다.

정리하면

그림 기호길이대응되는 척도
가sqrt(Δx² + Δy²)유클리드 거리(L2) ✔
나Δy좌표의 세로 성분(단독으로는 특정 척도 아님)
다Δx좌표의 가로 성분(단독으로는 특정 척도 아님)
나 + 다Δx + Δy맨해튼 거리(L1)
max(나, 다)max(Δx, Δy)체비쇼프 거리(L∞)

보기 중 대응이 정확한 것은 ① 가 - 유클리드 거리(Euclidean distance) 뿐이다.

보기별 판정​

보기판정근거
① 가 - 유클리드 거리✅ 정답가는 두 점을 직접 잇는 빗변으로 sqrt(Δx² + Δy²) = L2다.
② 나 - 세이프 거리❌ 오답'Safe distance'는 민코프스키 계열의 거리 척도 명칭이 아니다.
③ 나 - 체비쇼프 거리❌ 오답체비쇼프는 max(Δx, Δy)인데 나는 Δy 성분 하나일 뿐이다.
④ 다 - 맨해튼 거리❌ 오답맨해튼은 Δx + Δy(다 + 나)이며 다 하나로는 성립하지 않는다.

오답 이유​

  • ② 나 - 세이프 거리(Safe distance) — 거리 척도의 표준 분류(민코프스키 L1/L2/L∞, 마할라노비스, 해밍, 코사인 등)에 '세이프 거리'라는 항목은 없다. AI 강건성 문헌에서 쓰는 "safe radius"는 어떤 거리 척도로 측정한 허용 반경 ε을 뜻하는 표현이므로 별도의 거리 정의가 아니며, 그림의 수직 선분과 대응시킬 근거도 없다. 보기 자체가 존재하지 않는 용어를 만들어 낸 함정이다.
  • ③ 나 - 체비쇼프 거리(Chebyshev) — 체비쇼프 거리는 좌표 차이들 중 최댓값이다. 그림에서 나는 세로 변 Δy 이고 다는 가로 변 Δx 인데, 그림상 가로 변이 더 길므로 체비쇼프 거리는 Δx(다 쪽)에 해당한다. 게다가 "수직 선분 = 체비쇼프"라는 일반 규칙은 없고, 두 점의 상대 위치에 따라 최댓값이 가로가 될 수도 세로가 될 수도 있으므로 척도 정의와 맞지 않는다. 올바른 서술은 "나와 다 중 더 긴 쪽 = 체비쇼프 거리"다.
  • ④ 다 - 맨해튼 거리(Manhattan) — 맨해튼 거리는 축을 따라 꺾어서 이동한 총 이동량, 즉 Δx + Δy 이므로 그림에서는 다와 나를 더한 값이다. 다는 그중 가로 성분 하나에 불과하다. 올바른 서술은 "나 + 다 = 맨해튼 거리"다.

핵심 정리​

  • 가=빗변=유클리드(L2), 나+다=맨해튼(L1), max(나,다)=체비쇼프(L∞) — 직각삼각형 그림 하나로 세 척도를 동시에 정리할 수 있다.
  • 세 척도 사이에는 항상 L∞ ≤ L2 ≤ L1 관계가 성립하고, 단위 반경의 모양은 각각 정사각형·원·마름모다.
  • AI 강건성은 d(x, x') ≤ ε → f(x') = f(x) 형태로 정의되므로 거리 척도(L1/L2/L∞)를 명시하지 않으면 강건성 주장 자체가 무의미하다.
