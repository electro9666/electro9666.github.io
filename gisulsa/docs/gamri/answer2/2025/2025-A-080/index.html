080번 · 복수 업무 시스템의 최대 TPS 계산

제26회(2025년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. TPS와 트랜잭션 처리 시간​

TPS(Transaction Per Second) 는 시스템이 1초에 처리하는 트랜잭션 수다. 어떤 업무의 개별 최대 TPS가 T 라면, 그 업무 하나를 처리하는 데 걸리는 자원 점유 시간(서비스 시간)은

서비스 시간 = 1 / T  (초)

예를 들어 최대 40 TPS인 업무는 트랜잭션 1건당 1/40 = 0.025초 의 처리 자원을 소모한다.

2. 혼합 업무 시스템의 최대 TPS — 가중 조화평균​

여러 업무가 하나의 시스템 자원을 공유할 때, 전체 최대 TPS는 각 업무의 서비스 시간을 업무 비중으로 가중 평균한 값의 역수가 된다.

                    1
최대 TPS = ─────────────────────────
            Σ ( wᵢ / Tᵢ )
기호의미
wᵢ업무 i의 비중(전체 요청 중 차지하는 비율, Σwᵢ = 1)
Tᵢ업무 i의 개별 최대 TPS
wᵢ / Tᵢ평균 트랜잭션 1건 중 업무 i가 차지하는 처리 시간

이는 가중 조화평균(weighted harmonic mean) 이며, 처리율(rate)을 평균할 때는 산술평균이 아니라 조화평균을 써야 한다는 원칙에서 나온다.

3. 왜 산술평균이 아닌가​

산술평균 (40 + 400)/2 = 220 TPS 는 명백히 틀렸다. 느린 업무(40 TPS)가 전체 요청의 절반을 차지하는 한, 시스템은 그 느린 업무의 처리 시간에 발목이 잡힌다. 자동차가 갈 때는 시속 40km, 올 때는 시속 400km로 같은 거리를 달렸을 때의 평균 속도를 구하는 문제와 구조가 같다 — 답은 220km/h가 아니라 조화평균이다.

4. 비중 계산​

문제에서 "운영 시 초당 요청 수"가 주어지면 그 비율이 곧 업무 비중이다.

wᵢ = (업무 i의 초당 요청 수) / (전체 초당 요청 수)

5. 검산 감각​

가중 조화평균의 결과는 항상 가장 느린 업무의 개별 TPS 이상, 가장 빠른 업무의 개별 TPS 이하다. 또한 느린 쪽에 크게 치우친다. 이 문항에서는 40 ≤ 결과 ≤ 400 이어야 하며, 비중이 반반이므로 40에 가까운 쪽(수십 TPS 대)이 나와야 정상이다.

문제​

정답​

④

상세 풀이​

1단계 — 주어진 값 정리

업무개별 최대 TPS Tᵢ운영 시 초당 요청 수
A4010건
B40010건
합계—20건

2단계 — 업무 비중 계산

w_A = 10 / (10 + 10) = 10/20 = 0.5
w_B = 10 / (10 + 10) = 10/20 = 0.5

3단계 — 업무별 가중 서비스 시간 계산

w_A / T_A = 0.5 / 40  = 0.0125   초
w_B / T_B = 0.5 / 400 = 0.00125  초

4단계 — 합산(평균 트랜잭션 1건의 처리 시간)

Σ (wᵢ / Tᵢ) = 0.0125 + 0.00125 = 0.01375 초

5단계 — 역수를 취해 최대 TPS 도출

최대 TPS = 1 / 0.01375 = 72.7272...

분수로 정확히 계산하면

1 / (1/80 + 1/800) = 1 / (10/800 + 1/800) = 1 / (11/800) = 800/11 = 72.7272...

6단계 — 검산

40 ≤ 72.727 ≤ 400 을 만족하고, 비중이 반반일 때 느린 쪽(40)에 가깝게 나온다는 예상과도 부합한다.

따라서 정답은 ④ 72.727 이다.

보기별 판정​

보기판정근거
① 36.363❌ 오답비중을 각각 1.0으로 잘못 둔 값 — 1/(1/40 + 1/400) = 800/22 = 36.363
② 38.095❌ 오답A에만 비중 1.0, B에 0.5를 적용한 값 — 1/(1/40 + 0.5/400) = 38.095
③ 66.666❌ 오답A에 비중 0.5, B에 1.0을 적용한 값 — 1/(0.5/40 + 1/400) = 1/0.015 = 66.666
④ 72.727✅ 정답1/(0.5/40 + 0.5/400) = 1/0.01375 = 800/11 ≈ 72.727

오답 이유​

  • ①(36.363) — 업무 비중을 반영하지 않고 두 업무의 서비스 시간을 그대로 합산한 결과다.

    1 / (1/40 + 1/400) = 1 / (0.025 + 0.0025) = 1 / 0.0275 = 36.363

    이 계산은 "A 1건과 B 1건을 반드시 함께 처리해야 한다"는, 즉 트랜잭션 1건이 두 업무를 모두 포함하는 상황의 식이다. 문제에서는 A와 B가 서로 다른 별개의 트랜잭션이고 각각 전체의 절반을 차지하므로, 비중 0.5를 곱해야 한다. 비중 합이 1 + 1 = 2 가 되어 Σwᵢ = 1 조건을 위반한다는 점에서도 잘못된 식이며, 결과값도 정답의 정확히 절반(36.363 × 2 = 72.727)이 되어 비중 누락의 흔적이 그대로 드러난다.

  • ②(38.095) — A 업무에만 비중 1.0을, B 업무에는 0.5를 적용한 비대칭 계산이다.

    1 / (1/40 + 0.5/400) = 1 / (0.025 + 0.00125) = 1 / 0.02625 = 38.095

    두 업무의 초당 요청 수가 10건으로 동일하므로 비중은 반드시 서로 같아야 한다. 요청 수가 같은데 서로 다른 가중치를 주는 것은 전제와 모순이며, 느린 업무 A에 과도한 가중치를 준 탓에 값이 실제보다 크게 낮아졌다.

  • ③(66.666) — ②와 반대로 A에 0.5, B에 1.0을 적용한 경우다.

    1 / (0.5/40 + 1/400) = 1 / (0.0125 + 0.0025) = 1 / 0.015 = 66.666

    정답(72.727)과 자릿수가 비슷해 가장 혼동하기 쉬운 오답이다. 차이는 B의 비중을 0.5로 나누었는지 여부 하나뿐이므로, 계산 시 분자에 넣는 비중의 합이 정확히 1인지를 반드시 확인해야 한다(0.5 + 1 = 1.5 ≠ 1).

  • ④(정답) — 두 업무의 요청 수가 10건으로 같으므로 비중은 각각 0.5다. 0.5/40 + 0.5/400 = 0.01375 의 역수인 800/11 ≈ 72.727 이 시스템의 최대 TPS다.

핵심 정리​

  • 혼합 업무 시스템의 최대 TPS는 가중 조화평균으로 구한다: 최대 TPS = 1 / Σ(wᵢ / Tᵢ).
  • 업무 비중 wᵢ 는 운영 시 초당 요청 수의 비율이며, 합이 반드시 1이 되어야 한다. 이 검증만으로 오답 ①·②·③이 모두 걸러진다.
  • 처리율(TPS, 속도)의 평균은 산술평균이 아니라 조화평균이다. (40+400)/2 = 220 같은 값은 항상 오답이다.
  • 결과는 언제나 가장 느린 업무의 TPS 이상, 가장 빠른 업무의 TPS 이하 구간에 들어오며, 느린 업무 쪽으로 크게 치우친다. 계산 후 이 범위 검산을 습관화한다.
