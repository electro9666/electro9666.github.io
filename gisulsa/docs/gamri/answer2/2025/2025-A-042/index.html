042번 · 문장 커버리지와 분기 커버리지 충족 판정

제26회(2025년) 정보시스템감리사 A형 — 소프트웨어 공학

사전 지식​

화이트박스 테스트 커버리지의 계층​

커버리지다른 이름충족 조건강도
구문 커버리지Statement / Line Coverage, Every Statement Coverage모든 실행 가능한 문장이 최소 1회 실행가장 약함
분기 커버리지Branch / Decision Coverage, Every Branch Coverage모든 판정(decision) 이 참·거짓 결과를 각각 1회 이상 가짐구문보다 강함
조건 커버리지Condition Coverage판정 내 개별 조건이 각각 참·거짓을 1회 이상 가짐분기와 포함관계 없음
조건/분기 커버리지Condition/Decision조건 커버리지 + 분기 커버리지 동시 만족더 강함
변형 조건/결정 커버리지MC/DC각 조건이 독립적으로 판정 결과를 바꿈을 입증항공·안전 필수 등급
경로 커버리지Path Coverage모든 실행 경로 조합을 수행가장 강함

포함 관계​

분기 커버리지 100% ⟹ 구문 커버리지 100% 이다. 모든 판정의 참/거짓 경로를 다 밟았다면, 그 경로 위의 모든 문장도 실행되기 때문이다. 역은 성립하지 않는다.

예: if (x > 0) { y = 1; } 에 대해 x = 5 하나만 테스트하면 문장은 전부 실행되어 구문 커버리지 100%지만, x > 0 이 거짓인 경로를 밟지 않았으므로 분기 커버리지는 50%다.

이 포함 관계 때문에 "분기만 만족하고 구문은 불만족" 이라는 조합은 원리적으로 존재할 수 없다. 이 사실만 알아도 보기 하나를 즉시 제거할 수 있다.

커버리지 계산 절차​

  1. 코드의 문장 수와 판정(decision) 수를 센다.
  2. 각 테스트 케이스를 손으로 실행(desk check)하면서 실행된 문장 번호와 각 판정의 결과(T/F)를 기록한다.
  3. 전체 테스트 케이스의 기록을 합집합으로 모은 뒤, 실행된 문장 수 / 전체 문장 수, 커버된 분기 수 / 전체 분기 수를 계산한다.

문제​

정답​

③

상세 풀이​

1단계 — 코드 구조 파악​

def check_number(num):
    if num > 0:                 # 판정 D1
        if num % 2 == 0:        # 판정 D2
            return "양수 짝수"   # S1
        else:
            return "양수 홀수"   # S2
    else:
        return "음수 또는 0"     # S3
  • 판정(decision): D1 = num > 0, D2 = num % 2 == 0 — 총 2개, 분기는 4개(각 판정의 T/F).
  • 실행 문장: D1 조건문, D2 조건문, S1, S2, S3.

2단계 — 테스트 케이스별 실행 추적​

테스트 케이스입력D1 (num > 0)D2 (num % 2 == 0)실행 문장반환값
test_case_14참4 % 2 == 0 → 참D1, D2, S1"양수 짝수"
test_case_27참7 % 2 == 1 → 거짓D1, D2, S2"양수 홀수"
test_case_3-1거짓평가되지 않음D1, S3"음수 또는 0"

3단계 — 구문 커버리지 계산​

실행된 문장의 합집합 = { D1, D2, S1, S2, S3 } = 전체 문장 5개 모두.

구문 커버리지 = 5 / 5 = 100% → Every Statement Coverage 만족

4단계 — 분기 커버리지 계산​

분기커버한 테스트 케이스
D1 = 참test_case_1, test_case_2
D1 = 거짓test_case_3
D2 = 참test_case_1
D2 = 거짓test_case_2

전체 4개 분기가 모두 커버되었다.

분기 커버리지 = 4 / 4 = 100% → Every Branch Coverage 만족

5단계 — 결론​

두 기준을 모두 만족하므로 정답은 ③ 이다.

보기별 판정​

보기판정근거
① Every Branch Coverage만 만족❌ 오답분기 100%면 구문도 반드시 100%이므로 "분기만 만족"은 논리적으로 불가능하다. 실제로 구문도 100%다.
② Every Statement Coverage만 만족❌ 오답구문은 100%가 맞지만, 4개 분기(D1-T/F, D2-T/F)도 전부 커버되어 분기도 100%다.
③ 모두 만족✅ 정답문장 5/5 = 100%, 분기 4/4 = 100%.
④ 모두 만족하지 않음❌ 오답3개 테스트 케이스가 세 return 문과 두 판정의 T/F를 모두 밟는다.

오답 이유​

  • ① — 커버리지 계층상 분기 커버리지는 구문 커버리지를 포함(subsume) 한다. 모든 분기를 밟았다는 말은 각 분기 경로에 놓인 문장을 최소 1회 실행했다는 뜻이므로, "분기만 100%, 구문은 미만"은 구조적으로 성립하지 않는다. 출제 의도상 이 포함 관계를 아는지를 묻는 함정 보기다.
  • ② — 세 테스트 케이스가 우연히 세 개의 return 문을 하나씩 실행하므로 구문 커버리지가 100%인 것은 맞다. 그러나 각 return 문에 도달하기 위해 D1과 D2의 참·거짓 경로를 모두 지나므로 분기도 자동으로 100%가 된다. "구문만 만족"이 되려면 예컨대 check_number(4) 하나만 실행하는 경우처럼 일부 경로를 빼먹었어야 한다.
  • ④ — 미실행 문장이나 미커버 분기를 하나라도 지목할 수 있어야 성립하는 보기인데, 위 추적표에서 보듯 모든 문장·모든 분기가 커버된다. 단, 조건 커버리지 관점이나 경로 커버리지 관점에서 미흡한 부분이 있는 것은 사실이나, 문제는 statement/branch만 묻고 있으므로 ④는 틀리다.

핵심 정리​

  • 분기 커버리지 100% ⟹ 구문 커버리지 100% (역은 성립 안 함). "분기만 만족"류 보기는 즉시 제거한다.
  • 중첩 if-else에서 모든 return 문을 하나씩 밟는 테스트 집합은 대개 구문·분기 커버리지를 동시에 만족시킨다.
  • 커버리지 문제는 반드시 입력값별 실행 추적표를 손으로 작성해서 푼다.
  • 이 코드에서 조건 하나짜리 판정만 있으므로 조건 커버리지도 분기 커버리지와 동일하게 100%가 된다.
