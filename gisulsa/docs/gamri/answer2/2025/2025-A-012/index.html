012번 · 공공부문 초거대 AI 도입 방식별 체크리스트

제26회(2025년) 정보시스템감리사 A형 — 감리 및 사업관리

사전 지식​

「공공부문 초거대 AI 도입·활용 가이드라인」(2024.04.)​

공공기관이 LLM(초거대 언어모델)을 업무에 도입할 때 도입 방식 선정 → 데이터 준비 → 구축 → 운영·관리의 전 과정에서 확인해야 할 사항을 체크리스트 형태로 제시한 가이드라인이다.

LLM 사용(도입) 방식의 3가지 유형​

구분방식내용비용·기간데이터 통제
1API(서비스) 활용상용·공개 LLM 서비스를 API로 호출해 사용. 프롬프트 엔지니어링·RAG로 업무 적용낮음 / 짧음낮음(외부 전송 검토 필요)
2파인튜닝(추가학습)이미 학습된 파운데이션 모델을 가져와 기관 업무 데이터로 추가학습중간중간
3자체 구축(사전학습)모델을 직접 사전학습·고도화하여 보유매우 높음 / 김높음

방식별 체크리스트의 성격​

가이드라인은 방식마다 확인 항목을 달리 제시한다. 판별의 열쇠는 "모델을 만드는가, 가져와 쓰는가" 이다.

방식대표 체크 항목
API 활용서비스 선정 기준, 사용량·과금 산정, 외부 전송 데이터의 보안·개인정보 검토, 응답 품질 모니터링
파인튜닝업무 특성을 반영한 LLM(파운데이션 모델) 선정, 추가학습용 데이터 준비·정제·라벨링, 학습 인프라(GPU) 확보, 성능 평가 기준, 모델 버전 관리 및 배포 방안
자체 구축대규모 사전학습 데이터 확보, 파운데이션 모델 개발·고도화 및 기대 성능 모니터링, 대규모 컴퓨팅 인프라 구축, 장기 로드맵·전문인력 확보

문제​

정답​

③

상세 풀이​

  1. 문항은 "파인튜닝으로 결정한 경우의 체크리스트로 가장 적절하지 않은 것"을 묻는다. 즉 파인튜닝 방식의 체크 항목이 아닌 것을 골라야 한다.
  2. 파인튜닝의 정의를 먼저 확정한다. 파인튜닝은 이미 사전학습이 끝난 파운데이션 모델을 외부에서 가져와, 기관의 업무 데이터로 추가학습(fine-tuning) 시키는 방식이다. 모델 자체를 처음부터 만들지 않는다.
  3. 이 정의에 비추어 각 보기를 분류한다.
    • ① LLM 선정 → 어떤 파운데이션 모델을 가져올지 고르는 활동이므로 파인튜닝의 출발점이다.
    • ② 추가학습 데이터 준비 → 파인튜닝의 핵심 입력물이다.
    • ④ 모델 버전 관리·배포 → 추가학습으로 만들어진 모델을 서비스에 반영하는 운영 단계 활동이다.
    • ③ 파운데이션 모델 고도화 및 기대 성능 모니터링 → 파운데이션 모델 자체를 개발·개선하는 활동으로, 모델을 직접 만드는 자체 구축(사전학습) 방식의 체크 항목이다.
  4. 따라서 파인튜닝 체크리스트로 적절하지 않은 것은 ③이다.

보기별 판정​

보기판정근거
① 업무 특성을 반영한 LLM 선정 여부❌ 오답 보기(적절한 설명)어떤 파운데이션 모델에 추가학습할지 고르는 파인튜닝 첫 단계
② 추가학습을 위한 데이터 준비 여부❌ 오답 보기(적절한 설명)파인튜닝의 필수 입력물인 학습 데이터 확보·정제
③ 파운데이션 모델 고도화 및 기대 성능 모니터링 검토✅ 정답 보기(적절하지 않은 설명)모델을 직접 개발·고도화하는 자체 구축(사전학습) 방식의 체크 항목
④ 모델 버전 관리 및 배포 방안 마련 검토❌ 오답 보기(적절한 설명)추가학습된 모델의 형상관리·배포는 파인튜닝 후속 운영 항목

오답 이유​

  • ① 업무 특성을 반영한 LLM 선정 여부 — 파인튜닝은 "무엇을 튜닝할 것인가"를 먼저 정해야 한다. 업무 도메인(민원 응대, 법령 검색 등), 한국어 성능, 라이선스, 파라미터 규모, 파인튜닝 지원 여부를 따져 기반 모델을 선정하는 것은 파인튜닝 방식의 대표 체크 항목이므로 적절하다.
  • ② 추가학습을 위한 데이터 준비 여부 — 파인튜닝의 성능은 추가학습 데이터의 품질에 좌우된다. 업무 데이터 수집·정제·라벨링, 개인정보 비식별 조치, 학습/검증 데이터 분리 등이 필요하므로 적절하다.
  • ④ 모델 버전 관리 및 배포 방안 마련 검토 — 추가학습으로 생성된 모델은 지속적으로 재학습·교체되므로 모델 버전(형상) 관리와 배포·롤백 절차가 필요하다. 파인튜닝 결과물을 실제 서비스에 반영하는 단계의 항목이므로 적절하다.
  • ③ 파운데이션 모델 고도화 및 기대 성능 모니터링 검토(정답) — 여기서 대상은 파인튜닝 결과 모델이 아니라 파운데이션 모델 그 자체다. 파운데이션 모델을 고도화한다는 것은 대규모 사전학습을 직접 수행·개선한다는 뜻이고, 이는 막대한 데이터·GPU·전문인력이 필요한 자체 구축 방식의 활동이다. 파인튜닝을 선택한 기관은 파운데이션 모델을 선정해서 가져다 쓰는 입장이므로 이 항목은 방식과 맞지 않는다. 올바른 서술로 바꾼다면 "추가학습된 모델의 성능 평가 및 기대 성능 달성 여부 모니터링"이 되어야 한다.

핵심 정리​

  • 초거대 AI 도입 방식은 API 활용 / 파인튜닝 / 자체 구축(사전학습) 세 가지이며, 체크리스트는 방식별로 다르다.
  • 파인튜닝 = 파운데이션 모델을 "고른다" + 데이터로 "추가학습" + 결과 모델을 "버전관리·배포".
  • 파운데이션 모델을 "개발·고도화"하는 항목은 자체 구축 방식의 것이다. 이 한 줄이 이 문항의 판별 기준이다.
  • 방식별 구분 문제는 "모델을 만드는가(자체 구축) / 가져와 손보는가(파인튜닝) / 그냥 호출하는가(API)"로 접근한다.
