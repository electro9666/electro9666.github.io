098번 · 비지도 학습의 구분

제26회(2025년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

기계학습의 3대 유형​

유형정답 라벨(label)목표대표 과제
지도 학습(Supervised Learning)필요함 (입력 x + 정답 y 쌍)입력→정답 사상 함수 학습분류(Classification), 회귀(Regression)
비지도 학습(Unsupervised Learning)불필요 (입력 x만)데이터에 내재된 구조·패턴 발견군집화(Clustering), 차원 축소, 연관 규칙, 이상 탐지
강화 학습(Reinforcement Learning)라벨 대신 보상(reward)누적 보상을 최대화하는 정책(policy) 학습게임 AI, 로봇 제어, 추천 최적화

※ 중간 형태로 소량의 라벨 데이터 + 대량의 무라벨 데이터를 함께 쓰는 준지도 학습(Semi-supervised), 데이터 자체에서 라벨을 만들어 내는 자기지도 학습(Self-supervised) 이 있다.

지도 학습의 대표 알고리즘​

알고리즘과제요지
선형 회귀(Linear Regression)회귀y = w·x + b 형태로 연속값 예측. 정답 y가 있어야 오차(MSE)를 계산
로지스틱 회귀분류시그모이드로 확률 출력, 이진 분류
나이브 베이즈(Naive Bayes)분류베이즈 정리 + 특징 간 조건부 독립 가정. 클래스 사전확률·우도를 라벨된 데이터로 추정
서포트 벡터 머신(SVM)분류(회귀도 가능)두 클래스를 가르는 마진 최대 초평면을 찾음. 클래스 라벨이 있어야 마진 정의 가능
의사결정나무 / 랜덤 포레스트분류·회귀불순도(지니·엔트로피) 감소 기준 분기 — 라벨 필요
k-NN분류·회귀이웃 k개의 라벨 다수결
신경망(지도 학습 설정)분류·회귀손실함수로 정답과 비교하여 역전파

비지도 학습의 대표 알고리즘​

알고리즘과제요지
K-평균 군집화(K-means Clustering)군집화데이터를 K개 군집으로 분할. 라벨 없이 거리 기반으로 묶음
계층적 군집화(Hierarchical)군집화병합/분할로 덴드로그램 생성
DBSCAN군집화밀도 기반, 군집 수를 미리 정하지 않음, 이상치 자동 분리
주성분 분석(PCA)차원 축소분산이 최대인 축으로 사영
t-SNE / UMAP차원 축소·시각화고차원 이웃 구조 보존
오토인코더차원 축소·이상 탐지입력을 압축·복원하며 잠재표현 학습
연관 규칙(Apriori, FP-Growth)연관 분석장바구니 분석 — 지지도·신뢰도·향상도

K-평균 군집화의 절차​

정답 라벨이 전혀 쓰이지 않는다는 점을 절차로 확인할 수 있다.

단계내용
①군집 수 K를 정하고 중심(centroid) K개를 임의 초기화
② 할당각 데이터 포인트를 가장 가까운 중심의 군집에 배정 (보통 유클리드 거리)
③ 갱신각 군집에 속한 포인트들의 평균으로 중심을 이동
④중심 이동이 없을 때까지(또는 최대 반복까지) ②~③ 반복
  • 목적함수: 군집 내 제곱오차합 SSE(WCSS) 최소화.
  • 적절한 K 선정: 엘보우(Elbow) 기법, 실루엣(Silhouette) 계수.
  • 한계: K를 미리 지정해야 하고, 초기 중심에 따라 지역 최적해에 빠질 수 있으며(→ K-means++ 초기화), 구형(球形) 군집을 가정한다.

문제​

정답​

①

상세 풀이​

판별 기준은 단 하나, "학습에 정답 라벨(y)이 필요한가?" 이다. 필요하면 지도 학습, 필요 없으면 비지도 학습이다.

보기학습에 필요한 데이터라벨 필요 여부유형
① K-평균 군집화입력 특징 x 만불필요비지도 학습(군집화)
② 나이브 베이즈 분류x + 클래스 라벨 y필요지도 학습(분류)
③ 서포트 벡터 머신x + 클래스 라벨 y필요지도 학습(분류)
④ 선형 회귀x + 연속 목표값 y필요지도 학습(회귀)

  1. ② 나이브 베이즈 — 베이즈 정리 P(C|x) ∝ P(C)·P(x|C) 를 쓰려면 클래스 C가 무엇인지 알아야 사전확률 P(C)와 우도 P(x|C)를 추정할 수 있다. 라벨된 학습 데이터가 필수다.

  2. ③ SVM — "두 클래스 사이의 마진을 최대화하는 초평면"을 찾는 기법이다. 클래스 구분이 없으면 마진 자체를 정의할 수 없다. 라벨 필수다.

  3. ④ 선형 회귀 — 목표값 y와 예측값의 오차(MSE)를 최소화하는 방식으로 계수를 추정한다. y가 없으면 오차를 계산할 수 없다. 라벨 필수다.

  4. ① K-평균 — 위 절차표에서 보듯 거리 계산과 평균 계산만 사용한다. 정답 라벨이 개입하는 지점이 한 곳도 없으며, 결과로 나오는 군집 번호는 "발견된 구조"일 뿐 미리 주어진 정답이 아니다. → 비지도 학습

따라서 정답은 ①이다.

보기별 판정​

보기판정근거
① K-평균 군집화✅ 정답라벨 없이 거리·평균만으로 군집을 형성하는 비지도 학습
② 나이브 베이즈 분류❌ 오답클래스 라벨로 사전확률·우도를 추정하는 지도 학습(분류)
③ 서포트 벡터 머신❌ 오답클래스 라벨이 있어야 마진을 정의하는 지도 학습(분류)
④ 선형 회귀❌ 오답목표값 y와의 오차를 최소화하는 지도 학습(회귀)

오답 이유​

  • ② 나이브 베이즈 분류 — 베이즈 정리에 "각 특징이 클래스 조건부로 서로 독립"이라는 단순(naive) 가정을 더한 확률적 분류 알고리즘이다. 학습 단계에서 각 클래스의 사전확률 P(C) 와 클래스별 특징 분포 P(x|C) 를 빈도로 추정하는데, 이는 각 학습 샘플이 어느 클래스에 속하는지 라벨이 붙어 있어야만 가능하다. 스팸 메일 필터링이 대표 사례이며, "스팸/정상"이라는 라벨이 붙은 메일 집합이 반드시 필요하다. 따라서 지도 학습이다.

  • ③ 서포트 벡터 머신(SVM) — 서로 다른 클래스의 데이터를 가르는 결정 초평면 중 마진(가장 가까운 데이터까지의 거리)이 최대인 것을 찾는다. 이때 마진을 결정하는 경계 데이터가 서포트 벡터다. "서로 다른 클래스"라는 개념 자체가 라벨을 전제하므로 비지도 학습이 될 수 없다. 선형 분리가 안 되면 커널 트릭으로 고차원에 사상하여 분리하지만, 라벨이 필요하다는 사실은 변하지 않는다. (참고: 라벨 없이 정상 영역만 학습하는 One-Class SVM은 이상 탐지용 변형으로, 보기의 일반적인 SVM과는 다르다.)

  • ④ 선형 회귀 — 입력 변수와 연속형 목표값 사이의 선형 관계 y = w·x + b 를 추정한다. 학습은 예측값과 실제 y의 잔차 제곱합(MSE)을 최소화하는 방향으로 이루어지므로, 실제 y 값(= 정답 라벨)이 없으면 손실 자체를 정의할 수 없다. 분류가 아닌 회귀 과제이지만, 정답이 필요하다는 점에서 명백히 지도 학습이다.

  • 세 보기 모두 "정답이 주어진 상태에서 그 정답을 맞히도록 배우는" 지도 학습이며, 오직 ①만 정답 없이 데이터 스스로의 구조를 찾는 비지도 학습이다.

핵심 정리​

  • 판별 기준은 "정답 라벨이 필요한가" 하나다. 필요 → 지도, 불필요 → 비지도, 보상 신호 → 강화.
  • 비지도 학습의 4대 과제: 군집화(K-means, 계층적, DBSCAN) / 차원 축소(PCA, t-SNE, 오토인코더) / 연관 규칙(Apriori) / 이상 탐지.
  • K-평균 = 할당(가장 가까운 중심에 배정) ↔ 갱신(중심을 평균으로 이동) 을 수렴까지 반복. 군집 수 K는 엘보우 기법·실루엣 계수로 정한다.
  • 이름에 "분류(classification)"나 "회귀(regression)"가 들어가면 거의 항상 지도 학습, "군집화(clustering)"가 들어가면 비지도 학습이다.
