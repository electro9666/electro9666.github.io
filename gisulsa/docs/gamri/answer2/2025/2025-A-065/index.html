065번 · 집계 뷰 정의(GROUP BY)

제26회(2025년) 정보시스템감리사 A형 — 데이터베이스

사전 지식​

1) 뷰(VIEW)의 개념​

뷰는 하나 이상의 기본 테이블로부터 유도된 가상 테이블(virtual table) 이다. 실제 데이터를 저장하지 않고 정의(SELECT 문)만 데이터 사전에 보관하며, 질의 시점에 원본 테이블에서 계산된다.

CREATE VIEW 뷰이름 [ (열이름1, 열이름2, ...) ]
AS SELECT ...
[ WITH CHECK OPTION ];
특징설명
논리적 독립성기본 테이블 구조가 바뀌어도 뷰 정의만 고치면 응용은 그대로
보안필요한 열·행만 노출하여 접근 제어
질의 단순화복잡한 조인·집계를 이름 하나로 재사용
갱신 제약집계 함수·GROUP BY·DISTINCT·UNION 을 포함한 뷰는 원칙적으로 갱신 불가

CREATE VIEW 뷰이름(열목록) 처럼 괄호로 열 이름을 주면, SELECT 절의 결과 열이 순서대로 그 이름에 대응된다. count(*) 처럼 이름이 없는 표현식에 이름을 붙일 때 유용하다.

2) GROUP BY와 집계 함수​

함수의미NULL 처리
COUNT(*)그룹 내 행의 개수NULL 행도 포함
COUNT(열)그 열이 NULL이 아닌 행 수NULL 제외
SUM / AVG합계 / 평균NULL 제외
MAX / MIN최댓값 / 최솟값NULL 제외

GROUP BY 열 은 그 열의 같은 값을 가진 행들을 하나의 그룹으로 묶고, 집계 함수를 그룹마다 계산한다.

3) SELECT 절 작성 규칙 — 이 문항의 핵심​

GROUP BY 를 사용할 때 SELECT 절에 올 수 있는 것은 다음 둘뿐이다.

  1. GROUP BY 절에 명시된 열
  2. 집계 함수 표현식

따라서 집계 함수와 일반 열을 함께 SELECT 하면서 GROUP BY 가 없으면 표준 SQL에서는 문법 오류다. 예:

SELECT dept, count(*) FROM student;   -- 오류: dept가 GROUP BY에도 집계 함수에도 없음

GROUP BY 없이 집계만 쓰면 테이블 전체가 하나의 그룹이 되어 결과가 1행이다.

SELECT count(*) FROM student;   -- 결과 1행: 7

4) "무엇으로 묶을 것인가"를 결정하는 법​

결과로 얻고 싶은 행의 정체(분류 기준) 가 곧 GROUP BY 열이다.

원하는 결과GROUP BY 열결과 행 수
학년별 인원year학년 종류 수
학과별 인원dept학과 종류 수

문제​

정답​

④

상세 풀이​

[1단계] 요구사항 해석​

문제가 원하는 결과는 "전기공학과 3명, 전자공학과 2명, 컴퓨터공학과 2명" 이다. 즉 분류 기준이 dept(학과) 이고, 결과 행 수는 3행(학과 3종류)이다.

원본 릴레이션을 학과 기준으로 세어 확인한다.

dept해당 s_id인원
전기공학과1001, 1003, 10053
전자공학과1002, 10062
컴퓨터공학과1004, 10072

요구된 결과와 정확히 일치한다. 참고로 학년(year) 기준으로 세면 다음과 같아 요구 결과와 다르다.

year해당 s_id인원
11001, 1004, 10073
21003, 10052
310021
410061

[2단계] 필요한 두 조건 도출​

  1. 그룹화 열 = dept (학년 year 가 아님)
  2. GROUP BY 절이 반드시 있어야 함 (없으면 집계가 그룹별로 나뉘지 않음)

두 조건을 동시에 만족하는 보기를 찾으면 된다.

보기그룹화 열GROUP BY 유무판정
①year없음두 조건 모두 불만족
②year있음열이 틀림
③dept없음GROUP BY 누락
④dept있음두 조건 모두 만족

[3단계] 각 보기의 실행 결과 추적​

① SELECT year, count(*) FROM student; GROUP BY 없이 일반 열 year 와 집계 count(*) 를 함께 선택했다. 표준 SQL에서는 문법 오류로 거부된다. (MySQL의 ONLY_FULL_GROUP_BY 비활성 모드처럼 허용하는 구현에서도 결과는 임의의 year 값 하나와 전체 건수 7이 담긴 1행일 뿐이다.)

(오류)  또는  year=1, t_size=7  ← 1행

② SELECT year, count(*) FROM student GROUP BY year; 문법은 정상이지만 학년별 집계다.

year | t_size
-----+-------
  1  |   3
  2  |   2
  3  |   1
  4  |   1      ← 4행. 요구 결과(3행)와 다름

③ SELECT dept, count(*) FROM student; 열은 dept 로 맞으나 GROUP BY 가 없어 ①과 같은 이유로 문법 오류다.

(오류)  또는  dept=전기공학과, t_size=7  ← 1행. 학과별로 나뉘지 않음

④ SELECT dept, count(*) FROM student GROUP BY dept;

dept        | t_size
------------+--------
전기공학과   |   3
전자공학과   |   2
컴퓨터공학과 |   2      ← 요구 결과와 정확히 일치

뷰 정의부의 size(dept, t_size) 에 의해 첫 열은 dept, 둘째 열(count(*))은 t_size 라는 이름을 갖는다.

따라서 정답은 ④.

보기별 판정​

보기판정근거
① year, count(*) (GROUP BY 없음)❌ 오답분류 기준이 학년이며, GROUP BY 누락으로 문법 오류
② year, count(*) GROUP BY year❌ 오답문법은 맞으나 학년별 집계(3,2,1,1)로 요구 결과와 다름
③ dept, count(*) (GROUP BY 없음)❌ 오답열은 맞으나 GROUP BY가 없어 학과별로 나뉘지 않음(문법 오류)
④ dept, count(*) GROUP BY dept✅ 정답학과별 그룹화로 전기 3·전자 2·컴퓨터 2를 정확히 산출

오답 이유​

  • ①이 틀린 이유: 두 가지 잘못이 겹쳐 있다. 첫째, 분류 기준이 year 여서 요구된 학과별 집계가 아니다. 둘째, GROUP BY 가 없는 상태에서 일반 열(year)과 집계 함수(count(*))를 함께 선택했다. 표준 SQL의 규칙상 GROUP BY 가 없으면 테이블 전체가 한 그룹이 되어 결과가 1행이어야 하는데, 그 1행에 year 값을 무엇으로 넣을지 정의되지 않으므로 오류다. 올바르게 고치려면 SELECT dept, count(*) FROM student GROUP BY dept 가 되어야 한다.
  • ②가 틀린 이유: SQL 문법 자체는 완전히 정상이고 실행도 된다. 문제는 집계 기준이 요구사항과 다르다는 것이다. 결과는 (1, 3), (2, 2), (3, 1), (4, 1) 로 4행이며, 문제가 요구한 (전기공학과, 3), (전자공학과, 2), (컴퓨터공학과, 2) 3행과 값도 의미도 일치하지 않는다. 뷰 이름 size(year, t_size) 에서 첫 열 이름이 year 인 것만 봐도 학과 집계가 아님을 바로 알 수 있다. "전기공학과 3명"과 "1학년 3명"의 3이 우연히 같아 헷갈리기 쉬우니 주의한다.
  • ③이 틀린 이유: 그룹화 열은 dept 로 옳게 잡았지만 GROUP BY dept 절이 빠졌다. GROUP BY 가 없으면 집계 함수는 테이블 전체를 하나의 그룹으로 보므로 count(*) 는 학과별 수가 아니라 전체 7을 반환한다. 이때 dept 열은 그룹 대표값이 정의되지 않아 표준 SQL에서는 문법 오류로 거부된다. ③은 "집계 함수만 쓰면 알아서 분류된다"는 흔한 오해를 노린 보기로, 집계와 분류는 별개이며 분류는 오직 GROUP BY 가 담당한다는 점을 확인시켜 준다.
  • ④가 정답인 이유: 분류 기준(dept)과 그룹화 절(GROUP BY dept)이 모두 갖춰져 학과별 인원 3·2·2를 정확히 산출하며, 뷰 열 이름도 size(dept, t_size) 로 결과 열과 순서대로 대응된다.

핵심 정리​

  • 집계 함수와 일반 열을 함께 SELECT 하려면 그 일반 열이 반드시 GROUP BY 절에 있어야 한다. 없으면 표준 SQL에서 문법 오류다.
  • GROUP BY 없이 집계 함수만 쓰면 테이블 전체가 한 그룹이 되어 결과는 항상 1행이다.
  • GROUP BY 열 = 결과에서 원하는 분류 기준. "학과별"이면 dept, "학년별"이면 year 다. 보기 ②처럼 문법이 멀쩡해도 기준이 다르면 오답이다.
  • CREATE VIEW 뷰이름(열목록) 의 열 이름은 SELECT 결과 열과 순서대로 대응되며, count(*) 같은 무명 표현식에 이름을 붙이는 데 쓰인다. 다만 집계·GROUP BY를 포함한 뷰는 일반적으로 갱신할 수 없다.
