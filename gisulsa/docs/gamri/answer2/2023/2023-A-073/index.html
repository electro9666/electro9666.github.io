073번 · 멀티미디어 데이터 검색 — 매칭 기법

제24회(2023년) 정보시스템감리사 A형 — 데이터베이스

사전 지식​

1. 멀티미디어 검색의 특징​

이미지·영상·음성 같은 멀티미디어 데이터는 "값이 같은가"를 비교하는 정확 일치 검색이 거의 의미가 없다. 대신 색상 히스토그램, 질감, 모양, 음색 같은 특징(feature) 벡터를 추출해 두고, 질의로 주어진 데이터의 특징과 얼마나 비슷한가(유사도) 로 검색한다. 이를 내용 기반 검색(content-based retrieval) 또는 유사성 검색(similarity search) 이라 한다.

2. 멀티미디어 질의 처리 기법​

기법핵심 동작
매칭 기법(matching)저장된 데이터와 질의 데이터의 특징을 수학 함수(거리·유사도 함수) 로 비교하여 유사도를 계산하고, 유사도가 높은(거리가 가까운) 데이터를 찾음
필터링 기법(filtering)계산 비용이 낮은 거친 특징으로 후보를 먼저 걸러 내어 정밀 비교 대상을 줄임
인덱스 기법(index)고차원 특징 벡터를 R-tree, k-d tree 같은 다차원 색인에 넣어 범위·최근접 질의를 빠르게 처리
랭킹 기법(ranking)검색 결과를 유사도 점수 순서로 정렬하여 상위 k개를 제시

3. 대표적인 유사도(거리) 함수​

  • 유클리드 거리: d(x,q)=∑i(xi−qi)2d(x, q) = \sqrt{\sum_i (x_i - q_i)^2}d(x,q)=∑i​(xi​−qi​)2​
  • 코사인 유사도: cos⁡θ=x⋅q∥x∥ ∥q∥\cos\theta = \dfrac{x \cdot q}{\lVert x \rVert \, \lVert q \rVert}cosθ=∥x∥∥q∥x⋅q​
  • 히스토그램 교차(histogram intersection) 등

정답​

③

상세 풀이​

지문의 핵심은 두 부분이다.

  1. "저장된 데이터와 질의 조건으로 주어진 데이터 간의 유사도를 수학 함수로 계산"
  2. "유사도가 높은 데이터를 검색"

두 데이터를 짝지어 비교(matching) 하고 그 정도를 함수로 수치화하는 것은 매칭 기법의 정의다. 정확히 같은 값을 찾는 대신 "얼마나 잘 맞는가"를 계산한다는 점이 멀티미디어 매칭의 특징이다.

보기별 판정​

보기판정근거
① 랭킹 기법오답이미 계산된 유사도로 결과를 순위화하는 단계. 유사도 계산 자체가 아님
② 인덱스 기법오답다차원 색인으로 탐색 공간을 빠르게 접근하는 기법
③ 매칭 기법✅ 정답저장 데이터와 질의 데이터의 유사도를 수학 함수로 계산하여 유사한 데이터를 검색
④ 필터링 기법오답정밀 비교 전에 후보를 제거하여 비교 횟수를 줄이는 기법

오답 이유​

  • ①: 랭킹도 유사도를 이용하지만, 지문처럼 "유사도를 수학 함수로 계산하여 검색"하는 행위가 아니라 계산된 점수로 결과를 정렬·제시하는 후처리다. 유사도 계산(매칭) → 순위화(랭킹)의 순서로 이해하면 구분이 쉽다.
  • ②: 인덱스는 비교 대상을 빨리 찾아가는 접근 구조이지 유사도 계산 방법이 아니다.
  • ④: 필터링은 "유사하지 않은 것을 싸게 빨리 버리는" 단계다. 예를 들어 전체 색상 평균이 크게 다른 이미지를 먼저 제외한 뒤, 남은 후보에만 정밀 매칭을 적용한다.

참고: 이 네 기법의 분류는 법령·표준이 아니라 데이터베이스 교재의 개념 분류이며, 교재마다 명칭이 조금씩 다를 수 있다. 공식 정답은 ③ 매칭 기법이다.

핵심 정리​

  • 매칭 = 유사도를 수학 함수로 계산하여 비슷한 데이터 검색.
  • 필터링 = 후보 걸러내기 / 인덱스 = 다차원 색인 접근 / 랭킹 = 결과 순위화.
  • 흐름: 인덱스로 접근 → 필터링으로 후보 축소 → 매칭으로 유사도 계산 → 랭킹으로 정렬.
