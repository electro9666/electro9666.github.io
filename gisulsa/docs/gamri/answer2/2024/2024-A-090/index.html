090번 · 충돌 도메인을 분할하는 LAN 장비(L2 스위치)

제25회(2024년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. 이더넷의 충돌과 CSMA/CD​

초기 이더넷(IEEE 802.3)은 하나의 동축 케이블을 여러 노드가 공유하는 버스 구조였다. 두 노드가 동시에 전송하면 신호가 겹쳐 충돌(collision) 이 발생하므로, CSMA/CD(Carrier Sense Multiple Access with Collision Detection) 로 제어한다.

[1] Carrier Sense   : 전송 전 매체에 신호가 있는지 감지
[2] Multiple Access : 비어 있으면 전송 시작
[3] Collision Detect: 전송 중 충돌 감지 → 즉시 중단
[4] Jam Signal 송출 : 모든 노드에 충돌 사실 알림(32비트)
[5] Backoff         : 무작위 시간 대기 후 재시도
                      대기 = random(0 ~ 2^k − 1) × 슬롯타임
                      (k = 충돌 횟수, 최대 10까지 지수적 증가)
[6] 16회 연속 충돌  : 폐기하고 상위 계층에 보고

노드가 많아질수록 충돌 확률이 올라가 실효 대역폭이 급락한다. 그래서 "충돌 도메인을 얼마나 잘게 나누는가" 가 LAN 성능의 핵심 지표가 된다.

2. 충돌 도메인 vs 브로드캐스트 도메인​

시험에서 반드시 짝으로 묻는 두 개념이다.

구분충돌 도메인(Collision Domain)브로드캐스트 도메인(Broadcast Domain)
정의동시에 전송하면 충돌이 일어나는 노드들의 범위브로드캐스트 프레임(목적지 MAC = FF:FF:FF:FF:FF:FF)이 도달하는 범위
관련 계층1계층(물리) ~ 2계층2계층(데이터링크)
분할하는 장비브리지, L2 스위치, 라우터라우터, L3 스위치, VLAN
분할 못하는 장비리피터, 허브(오히려 확장)리피터, 허브, L2 스위치

핵심 한 줄: L2 스위치는 충돌 도메인은 나누지만 브로드캐스트 도메인은 나누지 못한다. 브로드캐스트 도메인을 나누려면 VLAN이나 라우터가 필요하다.

3. OSI 계층별 네트워크 장비 정리​

계층장비판단 근거충돌 도메인브로드캐스트 도메인
1계층 (물리)리피터(Repeater)없음 — 신호 증폭·재생만1개 (분할 못함)1개
1계층허브(Hub)없음 — 모든 포트로 플러딩1개 (분할 못함)1개
2계층 (데이터링크)브리지(Bridge)MAC 주소포트 수만큼 분할1개
2계층L2 스위치MAC 주소포트마다 1개씩 분할 ✅1개 (VLAN 쓰면 분할)
3계층 (네트워크)라우터 / L3 스위치IP 주소포트마다 분할포트마다 분할 ✅
4~7계층L4/L7 스위치, 게이트웨이포트 번호 / 응용 데이터분할분할

4. L2 스위치가 충돌 도메인을 나누는 원리​

L2 스위치는 각 포트에 연결된 장비의 MAC 주소를 학습해 MAC 주소 테이블(CAM 테이블) 을 만든다.

동작설명
학습(Learning)프레임이 들어오면 출발지 MAC과 유입 포트를 테이블에 기록
전달(Forwarding)목적지 MAC이 테이블에 있으면 그 포트로만 내보냄
플러딩(Flooding)목적지 MAC을 모르거나 브로드캐스트면 유입 포트를 제외한 모든 포트로 전송
필터링(Filtering)목적지가 유입 포트와 같은 세그먼트면 전달하지 않음
에이징(Aging)일정 시간 갱신 없는 엔트리를 삭제(기본 300초)
[허브]                              [L2 스위치]
  모든 포트로 신호 복사               목적지 포트로만 전달
  → 전체가 하나의 충돌 도메인          → 포트마다 별도 충돌 도메인

    A   B   C   D                       A   B   C   D
     \  |   |  /                        │   │   │   │  ← 각각 독립
      \ |   | /                       ┌─┴───┴───┴───┴─┐
     ┌──────────┐                     │  MAC 테이블   │
     │   허브   │                     │  A→P1 B→P2 …  │
     └──────────┘                     └───────────────┘
   충돌 도메인 = 1개                   충돌 도메인 = 4개

포트마다 충돌 도메인이 분리되는 것을 마이크로 세그멘테이션(micro-segmentation) 이라 한다. 한 포트에 단말 하나만 연결되면 그 충돌 도메인에는 두 개의 송신자(단말과 스위치 포트)만 존재하고, 전이중(full-duplex) 으로 설정하면 송·수신 경로가 분리되어 충돌 자체가 원천적으로 사라진다. 이때 CSMA/CD는 비활성화된다.

5. 혼동하기 쉬운 인접 개념​

함정사실
"허브도 여러 포트가 있으니 충돌 도메인을 나눈다"❌ 허브는 다중 포트 리피터. 들어온 신호를 모든 포트로 복사하므로 전체가 하나의 충돌 도메인
"L2 스위치는 브로드캐스트 도메인도 나눈다"❌ 브로드캐스트는 모든 포트로 플러딩된다. 나누려면 VLAN 또는 라우터
"브리지와 L2 스위치는 다르다"원리는 같다. 브리지는 소프트웨어 기반 소수 포트, 스위치는 ASIC 기반 다수 포트의 고속 구현
"모뎀은 LAN 장비"❌ 변조/복조 장비로 가입자 회선(전화선·케이블)용. LAN 내부 단말 연결과 무관
"USB 허브도 허브니까 네트워크 장비"❌ 주변장치 버스(USB) 확장 장치. 이더넷과 무관

6. 모뎀(MODEM)이란​

MODEM = MOdulator + DEModulator(변조기 + 복조기). 컴퓨터의 디지털 신호를 아날로그 전송 매체(전화선, 케이블TV망, 광선로)에 실을 수 있는 형태로 변조하고, 반대편에서 복조해 되돌린다.

종류매체
전화 모뎀PSTN 아날로그 전화선
ADSL/VDSL 모뎀전화선(구리쌍)
케이블 모뎀HFC 케이블TV망

WAN 접속(가입자 회선)용 장비이므로 "하나의 LAN 내부에 속하는 여러 단말노드를 연결"이라는 지문 조건과 맞지 않는다.

조건 B"이더넷 방식에서 충돌 도메인을 나누는 역할을 수행할 수 있다"
보기조건 A (LAN 내 단말 연결)조건 B (충돌 도메인 분할)결과
① 모뎀❌ WAN 가입자 회선용 변복조 장비❌탈락
② 리피터✅ (허브 형태로 연결 가능)❌ 1계층 — 나누지 못함탈락
③ L2 스위치✅ LAN 내부 단말 연결의 표준 장비✅ 포트마다 충돌 도메인 분리충족
④ USB 허브❌ 주변장치 버스 확장 장치❌탈락

조건 B가 ②를 배제하는 지점​

②의 리피터는 조건 A를 만족한다(다중 포트 리피터인 더미 허브가 여러 단말을 연결하는 장비로 실제로 쓰였다). 그래서 이 문제의 실질적 경합은 ②와 ③ 사이이며, 승부는 조건 B에서 갈린다.

장비동작 계층프레임을 보는가전달 방식결과
리피터 / 허브1계층(물리)❌ 전기 신호만 증폭·재생모든 포트로 복사연결된 전체 = 충돌 도메인 1개
L2 스위치2계층(데이터링크)✅ 목적지 MAC 주소를 해석해당 포트로만 전달포트마다 충돌 도메인 1개

리피터는 프레임의 내용을 전혀 이해하지 못한다. 들어온 신호를 그대로 모든 포트로 흘려보내므로, 두 단말이 동시에 전송하면 리피터를 거쳐 여전히 충돌한다. 오히려 케이블 길이 제한을 늘리면서 충돌 도메인을 넓히는 역할을 한다.

반면 L2 스위치는 프레임을 일단 수신해 목적지 MAC을 읽고, MAC 주소 테이블을 조회해 해당 포트로만 내보낸다. 나머지 포트에서는 동시에 다른 통신이 진행될 수 있으므로 포트별로 충돌 도메인이 독립한다.

왜 "나눌 수 있다"는 표현인가​

지문이 "충돌 도메인을 나누는 역할을 수행할 수 있다"라고 다소 조심스럽게 쓴 이유가 있다. 스위치 포트에 허브를 달아 여러 단말을 붙이면 그 허브 아래는 여전히 하나의 충돌 도메인이다. 즉 스위치는 포트 경계에서 충돌 도메인을 끊어 주는 것이지, 그 아래 구성까지 보장하지는 않는다. 오늘날처럼 포트당 단말 하나를 전이중으로 연결하면 충돌 도메인의 크기가 2가 되어 충돌 자체가 사라진다.

보기별 판정​

보기판정근거
① 모뎀(MODEM)오답 보기디지털 ↔ 아날로그 변조/복조 장비. 전화선·케이블망 등 WAN 가입자 회선 접속용이며 LAN 내부 단말 연결 장비가 아니다
② 리피터(Repeater)오답 보기1계층(물리) 장비로 신호를 증폭·재생해 모든 포트로 흘려보낸다. 연결된 전체가 하나의 충돌 도메인이 되어 분할하지 못한다
③ L2 스위치(L2 Switch)✅ 정답 보기2계층 장비로 목적지 MAC을 조회해 해당 포트로만 전달. 포트마다 충돌 도메인이 분리(마이크로 세그멘테이션)되고 전이중 통신이 가능해진다
④ USB 허브(USB Hub)오답 보기컴퓨터의 주변장치 버스(USB) 를 확장하는 장치. 이더넷 LAN과 무관하며 충돌 도메인 개념이 적용되지 않는다

오답 이유​

  • ①이 틀린 이유: 모뎀은 MOdulator/DEModulator의 약자로, 디지털 신호를 아날로그 전송 매체(전화선, HFC 케이블 등)에 실을 수 있게 변조하고 반대편에서 복조하는 장비다. 가입자와 통신사업자 망을 잇는 WAN 접속 지점의 장비이므로 "하나의 LAN 내부에 속하는 여러 단말노드를 연결"이라는 지문의 조건 A부터 만족하지 못한다. 충돌 도메인은 이더넷 공유 매체에서 정의되는 개념이므로 조건 B와도 무관하다.
  • ②가 틀린 이유: 리피터는 감쇠된 전기 신호를 증폭·재생해 전송 거리를 늘리는 물리 계층(1계층) 장비다. 프레임의 MAC 주소를 해석할 능력이 전혀 없어 들어온 신호를 모든 포트로 그대로 복사한다. 그 결과 리피터로 연결된 세그먼트 전체가 하나의 충돌 도메인이 되며, 노드가 늘수록 충돌 확률과 백오프 대기가 증가해 실효 대역폭이 떨어진다. 다중 포트 리피터인 더미 허브도 마찬가지다. 충돌 도메인을 나누기는커녕 확장하는 장비이므로 조건 B와 정면으로 어긋난다. 조건 A만 보면 그럴듯해 보이는 최대 함정이다.
  • ③이 맞는 이유: L2 스위치는 프레임의 출발지 MAC을 학습해 MAC 주소 테이블(CAM)을 구성하고, 목적지 MAC을 조회해 해당 포트로만 프레임을 전달한다. 다른 포트에서는 동시에 별개의 통신이 진행될 수 있으므로 포트마다 독립적인 충돌 도메인이 형성된다(마이크로 세그멘테이션). 포트당 단말 하나를 전이중으로 연결하면 송·수신 경로가 분리되어 CSMA/CD가 필요 없어지고 충돌이 원천적으로 사라진다. "하나의 LAN 내부에서 여러 단말을 연결"하는 표준 장비이자 "충돌 도메인을 나눌 수 있는" 장비라는 지문의 두 조건을 모두 충족하는 유일한 보기다. 다만 브로드캐스트 프레임은 모든 포트로 플러딩되므로 브로드캐스트 도메인은 여전히 하나이며, 이를 나누려면 VLAN이나 라우터가 필요하다.
  • ④가 틀린 이유: USB 허브는 컴퓨터의 USB 포트 하나를 여러 개로 늘려 키보드·마우스·저장장치 등 주변장치를 연결하는 주변장치 버스 확장 장치다. 이더넷 LAN의 프레임 전달과는 아무 관련이 없고, USB는 호스트가 전송을 중재하는 폴링 기반 버스여서 충돌 도메인이라는 개념 자체가 적용되지 않는다. 이름에 '허브'가 들어가 이더넷 허브와 혼동을 노린 보기일 뿐이다.

핵심 정리​

  • 충돌 도메인을 나누는 장비: 브리지, L2 스위치, 라우터. 나누지 못하는 장비: 리피터, 허브(오히려 확장).
  • 브로드캐스트 도메인을 나누는 장비: 라우터, L3 스위치, VLAN. L2 스위치는 브로드캐스트 도메인을 나누지 못한다.
  • L2 스위치의 5대 동작: 학습(Learning) → 전달(Forwarding) → 플러딩(Flooding) → 필터링(Filtering) → 에이징(Aging).
  • 포트당 단말 1개 + 전이중(full-duplex) 이면 충돌 도메인의 크기가 2가 되어 CSMA/CD가 불필요해진다.
  • 결정타: 리피터·허브는 1계층 장비라 MAC 주소를 보지 못하고 모든 포트로 신호를 복사하므로 전체가 하나의 충돌 도메인이다. 반면 L2 스위치는 목적지 MAC을 조회해 해당 포트로만 전달하므로 포트마다 충돌 도메인이 분리된다. 이 "계층과 판단 기준의 차이"가 ②와 ③을 가른다.
