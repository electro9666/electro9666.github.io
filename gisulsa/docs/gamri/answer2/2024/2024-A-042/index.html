042번 · 제어흐름 그래프와 사이클로매틱 복잡도

제25회(2024년) 정보시스템감리사 A형 — 소프트웨어 공학

사전 지식​

1. 제어흐름 그래프(CFG)란​

프로그램의 실행 경로를 노드(node) 와 간선(edge) 으로 표현한 방향 그래프다.

구성요소의미
노드분기 없이 순차 실행되는 문장 덩어리(basic block) 또는 판단문
간선제어가 한 노드에서 다른 노드로 옮겨가는 흐름
시작 노드함수 진입점(그림에서 속이 찬 원 ●)
종료 노드함수 종료점(그림에서 원 안에 점이 찍힌 ◉)
분기(판단) 노드나가는 간선이 2개 이상인 노드. if, while, for, case가 여기 해당

2. 사이클로매틱 복잡도 V(G)​

McCabe가 제안한 지표로, 선형 독립 경로(linearly independent path)의 최대 개수를 뜻한다. 화이트박스 테스트에서 기본 경로 테스트(basis path testing) 에 필요한 최소 테스트 케이스 수의 상한이자, 코드의 판단 복잡도를 재는 척도다. 구하는 방법이 세 가지이며 연결된 하나의 그래프에서는 모두 같은 값이 나온다.

방법공식주의사항
① 간선·노드 계산V(G)=E−N+2V(G) = E - N + 2V(G)=E−N+2EEE=간선 수, NNN=노드 수. 시작/종료 노드와 되돌아가는(back) 간선을 빠뜨리면 안 된다
② 분기 노드 계산V(G)=P+1V(G) = P + 1V(G)=P+1PPP=판단(분기) 노드 수. 단, 2-way 분기 기준. 다중 분기(switch의 kkk-way)는 k−1k-1k−1개로 환산
③ 영역 계산V(G)=RV(G) = RV(G)=R평면에 그린 그래프의 닫힌 영역 수 + 바깥 영역 1개

일반형은 연결요소 수 CCC 를 포함한 V(G)=E−N+2CV(G) = E - N + 2CV(G)=E−N+2C 이며, 단일 함수의 CFG는 C=1C=1C=1이므로 E−N+2E-N+2E−N+2 가 된다.

3. 계수할 때 흔히 저지르는 실수​

실수결과예방법
시작 노드 ●·종료 노드 ◉ 를 노드로 세지 않음NNN 이 2 작아져 V(G)V(G)V(G) 가 2 커짐원 모양 두 개도 노드다
시작→첫 문장 간선, 종료로 가는 간선을 누락EEE 부족 → V(G)V(G)V(G) 작아짐화살촉을 기준으로 세고, 노드마다 "들어오는 것/나가는 것"을 따로 적는다
루프의 되돌아가는(back) 간선 누락EEE 부족길게 우회해 그려진 선(그림의 8→4, 10→2)이 전형적인 함정
분기 노드를 "분기점이 있는 줄 수"로 셈과다·과소 계수나가는 간선이 2개인 노드만 센다. 합류 노드(들어오는 간선 2개)는 분기가 아니다

4. 혼동하기 쉬운 인접 개념​

개념정의본 문항과의 관계
분기 노드 수 PPP조건문 개수V(G)V(G)V(G) 보다 1 작다. 이것을 그대로 답하면 ①(3)이 된다
합류(merge) 노드들어오는 간선이 2개 이상인 노드복잡도에 직접 더해지지 않는다. 그림의 노드 2, 4, 8이 해당
문장 커버리지 / 분기 커버리지테스트 커버리지 척도V(G)V(G)V(G) 는 커버리지가 아니라 구조 복잡도. 다만 기본 경로 테스트 케이스 수 산정에 쓰인다
Halstead 복잡도연산자·피연산자 개수 기반어휘적 복잡도. 제어 흐름과 무관
V(G)≤10V(G) \le 10V(G)≤10 권고McCabe가 제시한 모듈당 경험적 상한초과 시 분할 대상으로 본다

상세 풀이​

계산 유형이다. 제시된 그래프를 직접 계수하여 두 가지 방법으로 교차 검증한다.

1단계 — 노드 세기​

그림에는 시작 노드 ●, 사각형 노드 1~10, 종료 노드 ◉ 가 있다.

N=1(시작)+10(노드 1 ⁣∼ ⁣10)+1(종료)=12N = 1(\text{시작}) + 10(\text{노드 }1\!\sim\!10) + 1(\text{종료}) = 12N=1(시작)+10(노드 1∼10)+1(종료)=12

2단계 — 간선 세기​

화살표를 출발 노드 순으로 모두 나열한다.

3단계 — 공식 적용​

V(G)=E−N+2=14−12+2=4V(G) = E - N + 2 = 14 - 12 + 2 = 4V(G)=E−N+2=14−12+2=4

나가는 간선이 2개인 노드만 고른다.

P=3  ⇒  V(G)=P+1=3+1=4P = 3 \;\Rightarrow\; V(G) = P + 1 = 3 + 1 = 4P=3⇒V(G)=P+1=3+1=4

두 방법이 모두 4로 일치하므로 정답은 ②다.

참고로 영역 계산으로도 확인된다. 이 그래프에는 닫힌 영역이 3개(바깥 루프 2→3→4→9→10→2, 안쪽 루프 4→5→…→8→4, 그리고 5→6→8/5→7→8이 만드는 마름모)이고 여기에 바깥 무한 영역 1개를 더하면 R=4R = 4R=4 다.

5단계 — 독립 경로 4개를 실제로 뽑아보기​

V(G)=4V(G)=4V(G)=4 라는 말은 "이 함수의 모든 실행 흐름을 조합으로 만들어낼 수 있는 기저(basis) 경로가 4개"라는 뜻이다. 실제로 뽑아보면 다음과 같다.

경로흐름새로 추가되는 간선
경로 1● → 1 → 2 → ◉최단 경로(모든 조건 거짓)
경로 2● → 1 → 2 → 3 → 4 → 9 → 10 → 2 → ◉노드 2의 두 번째 가지 + 바깥 루프
경로 3● → 1 → 2 → 3 → 4 → 5 → 6 → 8 → 4 → 9 → 10 → 2 → ◉노드 4의 아래 가지 + 노드 5의 왼쪽 가지
경로 4● → 1 → 2 → 3 → 4 → 5 → 7 → 8 → 4 → 9 → 10 → 2 → ◉노드 5의 오른쪽 가지

경로를 5개 이상 만들어도 모두 위 4개의 조합으로 표현되므로, 기본 경로 테스트에 필요한 테스트 케이스는 최소 4개다. 이렇게 경로를 직접 나열해 보면 계수 실수로 3이나 5가 나올 수 없다는 점이 확인된다.

① 3오답 보기분기 노드 수 P=3P=3P=3 자체를 답한 값. +1+1+1 을 빠뜨린 전형적 실수
② 4✅ 정답 보기V(G)=14−12+2=4V(G)=14-12+2=4V(G)=14−12+2=4, 교차 검증 3+1=43+1=43+1=4, 영역 수 4로 모두 일치
③ 5오답 보기간선 1개를 더 세거나 노드 1개를 덜 센 경우(예: 시작 또는 종료 노드 누락)
④ 6오답 보기시작·종료 노드를 모두 빼고 14−10+214-10+214−10+2 로 계산한 값

오답 이유​

  • ①이 틀린 이유: 3은 분기 노드의 개수이지 복잡도가 아니다. V(G)=P+1V(G)=P+1V(G)=P+1 에서 +1은 "모든 조건을 거짓으로 통과하는 기본 경로 1개"에 해당하므로 반드시 더해야 한다. 조건 3개짜리 함수는 최소 4개의 독립 경로를 갖는다.
  • ②가 맞는 이유: 노드 12개·간선 14개는 그림에서 직접 셀 수 있고, 되돌아가는 간선 8→4, 10→2 와 종료로 가는 2→◉ 를 포함해도 14−12+2=414-12+2=414−12+2=4 다. 분기 노드가 2·4·5 세 개라는 사실로 독립 검증되므로 계수 실수 가능성이 배제된다.
  • ③이 틀린 이유: 5가 나오려면 E=15E=15E=15 이거나 N=11N=11N=11 이어야 한다. 예컨대 노드 8에서 4로 가는 선과 별개로 8에서 위로 직접 가는 선이 하나 더 있다고 잘못 읽거나, 종료 노드 ◉ 를 노드로 세지 않으면 이 값이 된다.
  • ④가 틀린 이유: 6은 시작·종료 노드를 둘 다 세지 않은 결과(14−10+214-10+214−10+2)다. CFG에서 진입점과 종료점은 명시적인 노드이며, 그림에서도 원 기호로 분명히 그려져 있다.

핵심 정리​

  • V(G)=E−N+2V(G) = E - N + 2V(G)=E−N+2 (단일 함수, C=1C=1C=1) = 분기 노드 수 + 1 = 영역 수. 세 방법은 항상 같은 값을 준다 — 시험장에서는 두 가지로 교차 검증하는 것이 가장 안전하다.
  • 노드에는 시작(●)·종료(◉) 노드가 포함되고, 간선에는 루프의 되돌아가는 간선이 포함된다. 이 둘이 오답을 만드는 주된 원인이다.
  • 분기 노드는 나가는 간선이 2개 이상인 노드다. 들어오는 간선이 2개인 합류 노드(6·7 → 8)는 세지 않는다.
  • 이 그래프는 N=12N=12N=12, E=14E=14E=14 이고 분기 노드는 2·4·5 세 개이므로 V(G)=14−12+2=3+1=4V(G)=14-12+2=3+1=4V(G)=14−12+2=3+1=4 — 분기 노드 수 3을 그대로 답하지 않는 것이 결정타다.
