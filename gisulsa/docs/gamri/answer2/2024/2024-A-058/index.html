058번 · 다치 종속(MVD)과 제4정규형(4NF) 판정

제25회(2024년) 정보시스템감리사 A형 — 데이터베이스

사전 지식​

1. 다치 종속(MVD, Multi-Valued Dependency)이란​

릴레이션 R(X, Y, Z) 에서 다치 종속 X ↠ Y 가 성립한다는 것은

X 값 하나에 대응하는 Y 값들의 집합이, 나머지 속성 Z의 값과 무관하게 결정된다

는 뜻이다. 기호는 ↠(이중 화살표)를 쓴다.

형식적 정의는 다음과 같다. 두 투플 t1, t2 가 X에서 같은 값을 가지면, X는 같고 Y는 t1에서, Z는 t2에서 가져온 투플도 반드시 릴레이션에 존재해야 한다(그리고 그 반대 조합도 존재해야 한다).

함수 종속 X → Y다치 종속 X ↠ Y
X 하나 → Y 값 하나X 하나 → Y 값들의 집합
단일값 제약다중값 제약
X → Y 이면 X ↠ Y 도 성립(FD는 MVD의 특수한 경우)역은 성립하지 않음

2. 자명한 다치 종속(trivial MVD)​

릴레이션 R에서 X ↠ Y 가 다음 중 하나를 만족하면 자명하다.

조건설명
Y ⊆ X우변이 좌변에 포함됨
X ∪ Y = R (릴레이션의 전체 속성)남는 속성 Z가 없음

두 번째 조건이 이 문항의 열쇠다. 속성이 두 개뿐인 릴레이션 R(X, Y) 에서 X ↠ Y 는 항상 자명하다. 왜냐하면 다치 종속이 일으키는 이상 현상은 "서로 무관한 두 다중값 속성이 곱집합처럼 조합되어 중복이 폭증"하는 것인데, 무관한 제3의 속성 Z가 아예 없으면 그런 조합 자체가 생기지 않기 때문이다.

3. MVD 상보성(complementation) 규칙​

R(X, Y, Z) 에서 X ↠ Y 가 성립하면 X ↠ Z 도 자동으로 성립한다. 다치 종속은 언제나 쌍으로 나타난다. 그래서 MVD를 X ↠ Y | Z 로 표기하기도 한다.

이 규칙 때문에 3속성 릴레이션에서 비자명 MVD가 하나 있으면 두 개의 독립적 다중값 속성이 존재한다는 뜻이 되고, 곧바로 곱집합형 중복이 발생한다.

4. 제4정규형(4NF)의 정의​

4NF = BCNF를 만족하면서, 모든 비자명 다치 종속 X ↠ Y 에 대해 X가 릴레이션의 슈퍼키일 것

판정 절차는 다음과 같다.

1) 릴레이션의 속성 집합 R을 확정한다.
2) 주어진 MVD 중 R 안에서 의미를 갖는 것을 고른다.
3) 각 MVD가 자명한지 확인한다.  (Y ⊆ X  또는  X ∪ Y = R)
   - 자명하면 무시한다.
4) 비자명 MVD가 남으면 좌변 X가 슈퍼키인지 본다.
   - 슈퍼키가 아니면 → 4NF 위반
5) 비자명 MVD가 하나도 없으면 → 4NF 만족 (BCNF 조건도 함께 확인)

5. 다치 종속 이상(anomaly)의 실제 모습​

직원_학위_형제(직원이름, 학위명, 형제이름) 에서 홍길동이 학위 2개(학사·석사), 형제 3명(A·B·C)을 가진다고 하자. 직원이름 ↠ 학위명 과 직원이름 ↠ 형제이름 이 모두 성립하므로, 두 집합의 모든 조합이 저장되어야 한다.

직원이름학위명형제이름
홍길동학사A
홍길동학사B
홍길동학사C
홍길동석사A
홍길동석사B
홍길동석사C

2 × 3 = 6개 투플이 필요하다. 학위나 형제가 하나 늘 때마다 행이 곱으로 늘어나고, 학위를 하나 추가하려면 형제 수만큼 행을 삽입해야 하는 삽입·삭제·갱신 이상이 모두 발생한다.

해결책은 독립적인 다중값 속성끼리 분리하는 것이다.

직원_학위(직원이름, 학위명)     -- 2행: (홍길동, 학사), (홍길동, 석사)
직원_형제(직원이름, 형제이름)   -- 3행: (홍길동, A), (홍길동, B), (홍길동, C)

6행 → 5행으로 줄고, 두 릴레이션 모두 2속성이므로 MVD가 자명해져 4NF가 된다. 원래 릴레이션은 두 조각의 자연 조인으로 무손실 복원된다.

6. 혼동하기 쉬운 인접 개념​

혼동 지점정리
"MVD가 있으면 무조건 4NF 위반"아니다. 비자명 MVD만 문제가 된다. 2속성 릴레이션의 MVD는 자명해서 무해하다
4NF와 BCNF의 관계4NF ⊂ BCNF ⊂ 3NF. 4NF이려면 BCNF를 먼저 만족해야 한다
4NF와 5NF4NF는 다치 종속, 5NF(PJNF)는 조인 종속을 다룬다. 5NF가 더 강한 조건
FD와 MVD가 섞여 있으면둘 다 검사해야 한다. FD 위반이면 이미 BCNF/2NF 단계에서 탈락하므로 4NF도 자동 위반
다치 종속 분해의 성질항상 무손실 조인 분해가 보장된다(Fagin의 정리)

정답​

①

상세 풀이​

주어진 종속은 다음과 같다.

종속종류의미
직원이름 ↠ 학위명MVD한 직원이 여러 학위를 가짐
직원이름 ↠ 형제이름MVD한 직원이 여러 형제를 가짐
직원이름 ↠ 담당상품번호MVD한 직원이 여러 상품을 담당
파트키트명 ↠ 파트명MVD한 파트키트가 여러 파트로 구성
파트키트명 → 가격FD파트키트 하나에 가격 하나

각 보기의 릴레이션 속성 집합을 놓고 "그 안에 비자명 MVD가 남는가" 를 판정한다.

보기 ① — 직원_학위(직원이름, 학위명) ← 정답​

  • 릴레이션 속성 집합 R = {직원이름, 학위명}
  • 해당되는 MVD: 직원이름 ↠ 학위명
  • 자명성 검사: X ∪ Y = {직원이름} ∪ {학위명} = {직원이름, 학위명} = R → 자명한 MVD ✅

남는 속성 Z가 없으므로 곱집합형 중복이 생길 여지가 없다. 홍길동의 학위가 학사·석사 두 개라면 딱 2행만 저장된다.

직원이름학위명
홍길동학사
홍길동석사
  • BCNF 검사: 주어진 FD 중 이 릴레이션에 적용되는 것이 없다. 후보키는 (직원이름, 학위명) 전체이고 비자명 FD가 없으므로 BCNF 만족.
  • 비자명 MVD가 하나도 없음 → 4NF 만족 ✅

보기 ② — 직원_학위_형제(직원이름, 학위명, 형제이름)​

  • R = {직원이름, 학위명, 형제이름}
  • MVD 직원이름 ↠ 학위명 검사: X ∪ Y = {직원이름, 학위명} ≠ R (형제이름이 남음) → 비자명
  • 상보성 규칙에 의해 직원이름 ↠ 형제이름 도 성립하며 이 역시 비자명이다.
  • 좌변 검사: 직원이름은 슈퍼키인가? 한 직원에 여러 행이 존재하므로 슈퍼키가 아니다(후보키는 세 속성 전체).

→ 비자명 MVD의 좌변이 슈퍼키가 아님 → 4NF 위반 ❌

앞의 5절에서 본 대로 학위 2개 × 형제 3명 = 6행이 필요한 전형적인 다치 종속 이상이 발생한다. 학위명과 형제이름은 서로 아무 관련이 없는데 한 테이블에 묶여 있는 것이 문제의 본질이다.

보기 ③ — 파트키트_파트_가격(파트키트명, 파트명, 가격)​

이 보기는 두 겹으로 위반한다.

(1) 4NF 위반

  • R = {파트키트명, 파트명, 가격}
  • MVD 파트키트명 ↠ 파트명 검사: X ∪ Y = {파트키트명, 파트명} ≠ R (가격이 남음) → 비자명
  • 파트키트명은 슈퍼키인가? 한 파트키트에 여러 파트가 있으므로 여러 행이 존재 → 슈퍼키 아님

→ 4NF 위반 ❌

(2) 2NF 위반 — 더 근본적인 문제

  • 후보키: 파트키트명 하나로는 행을 특정할 수 없고 (파트키트명, 파트명) 이어야 한다.
  • 그런데 FD 파트키트명 → 가격 이 주어져 있다. 즉 비주요 속성 가격이 복합 기본키의 일부(파트키트명)에만 종속된다.
  • 이것이 부분 함수 종속이며 2NF 위반이다.
파트키트명파트명가격
K1볼트10000
K1너트10000
K1와셔10000

가격 10000이 파트 수만큼 중복 저장되고, 가격을 수정하려면 모든 행을 고쳐야 하는 갱신 이상이 생긴다.

2NF조차 만족하지 못하므로 3NF·BCNF·4NF 어느 것도 만족할 수 없다.

보기 ④ — 직원_상품_학위(직원이름, 담당상품번호, 학위명)​

  • R = {직원이름, 담당상품번호, 학위명}
  • MVD 직원이름 ↠ 학위명 검사: X ∪ Y = {직원이름, 학위명} ≠ R (담당상품번호가 남음) → 비자명
  • 상보성에 의해 직원이름 ↠ 담당상품번호 도 비자명하게 성립한다.
  • 직원이름은 슈퍼키가 아니다.

→ 4NF 위반 ❌

②와 구조가 동일하며, 형제이름 대신 담당상품번호가 들어갔을 뿐이다. 담당상품번호와 학위명은 서로 완전히 독립적인 두 다중값 속성이므로 담당 상품 3건 × 학위 2개 = 6행이 필요해진다.

보기별 판정​

① 직원_학위(직원이름, 학위명)✅ 정답 보기속성이 2개라 직원이름 ↠ 학위명 이 자명한 MVD(X∪Y = R). 비자명 MVD가 없고 FD 위반도 없어 4NF 만족

④ 직원_상품_학위(직원이름, 담당상품번호, 학위명)오답 보기②와 동일 구조. 담당상품번호·학위명이 독립적인 두 다중값 속성이므로 4NF 위반

오답 이유​

  • ②가 틀린 이유: 학위명과 형제이름은 의미상 아무런 연관이 없는 두 다중값 속성이다. "홍길동의 석사 학위"와 "홍길동의 형제 B" 사이에는 어떤 대응 관계도 없는데, 한 릴레이션에 함께 두면 릴레이션의 정의상 모든 조합을 다 저장해야 한다(그렇지 않으면 MVD 제약이 깨진다). 학위 m개, 형제 n개면 m × n 행이 필요하고, 학위를 하나 추가할 때 n개 행을 동시에 삽입해야 하는 삽입 이상이 생긴다. 비자명 MVD 직원이름 ↠ 학위명 의 좌변 직원이름은 슈퍼키가 아니므로(후보키는 세 속성 전체) 4NF를 위반한다. 올바른 설계는 직원_학위(직원이름, 학위명) 과 직원_형제(직원이름, 형제이름) 으로 분리하는 것이다.
  • ③이 틀린 이유: 두 가지 문제가 겹쳐 있어 네 보기 중 정규화 수준이 가장 낮다. 첫째, 비자명 MVD 파트키트명 ↠ 파트명 이 남아 4NF 위반이다. 둘째이자 더 심각한 것은, 후보키가 (파트키트명, 파트명) 복합키인데 FD 파트키트명 → 가격 때문에 비주요 속성 가격이 키의 일부에만 종속된다는 점이다. 이것이 부분 함수 종속이며 2NF 위반이다. 그 결과 한 키트의 가격이 구성 파트 수만큼 중복 저장되고, 가격 변경 시 모든 행을 고쳐야 하는 갱신 이상이 발생한다. 파트키트_가격(파트키트명, 가격) 과 파트키트_파트(파트키트명, 파트명) 으로 분리해야 한다. 이 보기에는 FD와 MVD가 섞여 있어, MVD만 보고 판단하면 2NF 위반을 놓치기 쉽다.
  • ④가 틀린 이유: ②와 구조적으로 완전히 동일하다. 담당상품번호와 학위명은 "직원"이라는 공통 주체에 각각 매달린 서로 독립적인 다중값 속성이다. 한 직원이 상품 3건을 담당하고 학위 2개를 가졌다면 3 × 2 = 6행이 필요하며, 담당 상품이 하나 바뀔 때마다 학위 수만큼 행을 손봐야 한다. 비자명 MVD 직원이름 ↠ 담당상품번호 와 직원이름 ↠ 학위명 이 모두 남아 있고 직원이름은 슈퍼키가 아니므로 4NF 위반이다. 문제의 지문이 직원이름 ↠ 학위명, 직원이름 ↠ 형제이름, 직원이름 ↠ 담당상품번호 세 MVD를 나란히 제시한 것은, 이 셋을 둘씩 묶은 릴레이션은 전부 4NF 위반임을 보이기 위한 장치다.

핵심 정리​

  • 4NF = BCNF + 모든 비자명 MVD의 좌변이 슈퍼키. 판정은 "이 릴레이션 안에 비자명 MVD가 남는가"만 보면 된다.
  • 자명한 MVD의 조건은 Y ⊆ X 또는 X ∪ Y = R 이다. 따라서 속성이 2개뿐인 릴레이션은 MVD가 항상 자명해져 자동으로 4NF다. 이 규칙 하나로 보기 ①이 정답임을 즉시 알 수 있다.
  • MVD 상보성: R(X,Y,Z) 에서 X ↠ Y 이면 X ↠ Z 도 성립한다. 다치 종속은 항상 쌍으로 나타나므로, 3속성 릴레이션에 비자명 MVD가 하나 있으면 독립적인 두 다중값 속성이 공존한다는 뜻이다.
  • 다치 종속 이상의 증상은 행 수가 곱(m × n)으로 폭증하는 것이다. 해결책은 독립적인 다중값 속성끼리 분리하여 각각 2속성 릴레이션으로 만드는 것이며, 이 분해는 항상 무손실이다.
  • FD와 MVD가 함께 주어지면 둘 다 검사하라. 보기 ③은 MVD로 4NF를 위반할 뿐 아니라 파트키트명 → 가격 이라는 부분 함수 종속으로 2NF부터 깨져 있다.
