057번 · 분해된 릴레이션이 모두 BCNF인지 판정하기

제25회(2024년) 정보시스템감리사 A형 — 데이터베이스

사전 지식​

1. 함수적 종속(FD)과 속성 폐포​

함수적 종속 X → Y 는 "X 값이 같으면 Y 값도 반드시 같다"는 제약이다.

속성 폐포(closure) X⁺ 는 X로부터 주어진 FD 집합을 이용해 함수적으로 결정할 수 있는 모든 속성의 집합이다. 계산 절차는 다음과 같다.

X⁺ = X
반복:
   FD 집합의 각 (L → R) 에 대해
      L ⊆ X⁺ 이면  X⁺ = X⁺ ∪ R
더 이상 추가되지 않을 때까지

폐포는 정규형 판정의 만능 도구다.

판정하고 싶은 것폐포로 확인하는 방법
X가 릴레이션 R의 슈퍼키인가X⁺ ⊇ R의 전체 속성
X가 후보키인가X가 슈퍼키이면서 어떤 진부분집합도 슈퍼키가 아님
X → Y 가 성립하는가Y ⊆ X⁺

2. 정규형 계층​

정규형조건제거되는 이상
1NF모든 속성이 원자값다중값
2NF1NF + 부분 함수 종속 제거(키의 일부에만 종속되는 비주요 속성 없음)부분 종속 이상
3NF2NF + 이행적 종속 제거. 엄밀한 정의: 모든 비자명 X→A 에 대해 X가 슈퍼키이거나 A가 주요 속성(어떤 후보키의 구성 원소)이행 종속 이상
BCNF모든 비자명 X→Y 에 대해 X가 슈퍼키 (예외 없음)후보키가 겹칠 때 남는 이상
4NFBCNF + 비자명 다치 종속의 좌변이 슈퍼키다치 종속 이상
5NF4NF + 조인 종속이 후보키에 의해서만 성립조인 종속 이상

3NF와 BCNF의 유일한 차이 — 3NF는 X→A 에서 X가 슈퍼키가 아니더라도 A가 주요 속성이면 허용한다. BCNF는 이 예외를 인정하지 않는다. 그래서 "결정자가 후보키가 아닌 FD가 하나라도 있으면 BCNF 위반" 이다.

3. 분해된 릴레이션의 정규형을 판정하는 절차​

분해 후 각 조각 릴레이션 Ri 를 판정하려면 원래 FD 집합을 Ri 로 투영(projection) 해야 한다.

π_Ri(F) = { X → Y  |  X, Y ⊆ Ri 의 속성,  Y ⊆ X⁺(F 전체 기준) }

핵심은 폐포를 계산할 때는 원래 FD 집합 F 전체를 쓰되, 결과에서 Ri 에 속한 속성만 남긴다는 점이다. F에 명시적으로 적혀 있지 않은 FD가 투영 과정에서 새로 나타날 수 있다는 점이 이 문항의 핵심 함정이다(보기 ④의 BC→D 가 그 예다).

판정 절차

  1. Ri 의 각 속성 부분집합 X에 대해 X⁺ 를 F 전체로 계산한다.
  2. X⁺ ∩ Ri 에서 X를 뺀 것이 비어 있지 않으면 → 투영 FD X → (X⁺ ∩ Ri − X) 가 존재한다.
  3. 그 X가 Ri 의 슈퍼키인지(X⁺ ⊇ Ri) 확인한다.
  4. 슈퍼키가 아닌 X가 하나라도 있으면 BCNF 위반이다.

4. 속성이 2개뿐인 릴레이션은 항상 BCNF​

R(A, B) 에서 가능한 비자명 FD는 A→B 와 B→A 뿐이다.

  • A→B 가 성립하면 A⁺ ⊇ {A,B} 이므로 A는 슈퍼키다.
  • B→A 가 성립하면 마찬가지로 B가 슈퍼키다.
  • 둘 다 성립하지 않으면 비자명 FD가 없어 자동으로 BCNF다.

→ 2속성 릴레이션은 무조건 BCNF다. 보기 ①의 R1(A,B), ②·③의 R2(C,D), ④의 R1(A,C) 는 이 규칙으로 즉시 통과 판정이 난다. 따라서 이 문항은 실질적으로 각 보기의 3속성 릴레이션 하나만 검사하면 된다.

5. 혼동하기 쉬운 인접 개념​

혼동 지점정리
원래 FD에 없는 FD가 조각에 생길 수 있는가생긴다. 폐포를 통해 유도되기 때문. 예: {(A,B)→CD, C→A} 에서 R2(B,C,D) 를 보면 원래 없던 BC→D 가 나타난다
분해하면 정규형이 항상 올라가는가아니다. 어떻게 분해하느냐에 따라 다르다. 이 문항이 정확히 그것을 묻는다
3NF는 만족하는데 BCNF는 위반X→A 에서 X가 슈퍼키가 아니지만 A가 주요 속성인 경우. 보기 ③의 C→A 가 전형적인 예
무손실 분해·종속성 보존이 문제는 정규형만 묻는다. 무손실 여부·종속성 보존은 판정 대상이 아니다

AC{A, C, D}{A, C}—❌
BC{B,C,D,A}{A,B,C}BC → A✅ 예 (후보키)

후보키 = AB, BC 두 개. 주요 속성(prime attribute) = A, B, C (즉 R1의 모든 속성).

위반 FD: C → A — C⁺ = {C, D, A} 에 B가 없으므로 C는 슈퍼키가 아니다. → BCNF 위반

그런데 우변 A는 후보키 AB의 구성 원소인 주요 속성이므로 3NF의 예외 조항("A가 주요 속성이면 허용")에 해당해 3NF는 만족한다.

이 보기가 3NF와 BCNF의 차이를 묻는 가장 전형적인 함정이다. 후보키가 겹치는(AB와 BC가 B를 공유) 구조에서만 나타나는 상황이며, 문제는 BCNF를 요구했으므로 탈락이다.

→ R1이 BCNF 아님(3NF까지만) → 보기 ③ 탈락

보기 ④ — FD = {(A,B)→CD, C→A}, 분해 R1(A,C), R2(B,C,D) ← 정답​

R1(A, C) — 속성 2개 → BCNF ✅

XX⁺X⁺ ∩ R1투영 FDX가 R1의 슈퍼키?
A{A}{A}—❌
C{C, A}{C, A}C → A✅ 예 (C가 R1의 후보키)

유일한 비자명 투영 FD C → A 의 좌변 C가 R1의 후보키이므로 BCNF 만족.

R2(B, C, D) — 여기가 관건이다.

XX⁺ (F = {(A,B)→CD, C→A} 기준)X⁺ ∩ R2투영 FDX가 R2의 슈퍼키?
B{B}{B}—❌
C{C, A}{C}—❌ (A는 R2에 없어 투영에서 사라짐)
D{D}{D}—❌
BC{B,C} → C→A 로 A 추가 → {A,B,C} → (A,B)→CD 로 D 추가 → {A,B,C,D}{B, C, D}BC → D✅ 예 (후보키)
BD{B, D}{B, D}—❌
CD{C, D, A}{C, D}—❌

후보키 = BC 하나. 비자명 투영 FD는 BC → D 단 하나이며 그 좌변이 후보키다. → BCNF 만족 ✅

주목할 점은 두 가지다.

  1. BC → D 는 원래 FD 집합에 명시되어 있지 않다. C → A 로 A를 얻고, 그 A와 B를 합쳐 (A,B) → CD 를 발동시켜 D를 얻는 2단 유도로 나타난다. 이 FD를 찾지 못하면 R2에 키가 없다고 잘못 판단하게 된다.
  2. C → A 는 R2에서 사라진다. A가 R2의 속성이 아니므로 투영 결과 C⁺ ∩ R2 = {C} 가 되어 비자명 FD를 만들지 못한다. 즉 문제를 일으키던 C → A 가 R1으로 격리되면서 R2가 깨끗해졌다. 이것이 이 분해가 성공적인 이유다.

→ R1·R2 모두 BCNF → 보기 ④ 가 정답

종합표​

보기함수적 종속성분해R1 판정R2 판정둘 다 BCNF?
①(A,B)→D, B→C, C→DR1(A,B) / R2(B,C,D)✅ BCNF❌ C→D 위반 (3NF도 위반)아니오
②A→B, B→C, C→DR1(A,B,C) / R2(C,D)❌ B→C 위반 (3NF도 위반)✅ BCNF아니오
③(A,B)→C, C→D, C→AR1(A,B,C) / R2(C,D)❌ C→A 위반 (3NF는 만족)✅ BCNF아니오
④(A,B)→CD, C→AR1(A,C) / R2(B,C,D)✅ BCNF (키 C)✅ BCNF (키 BC)예 ✅

프로그램 검증​

폐포 계산 → 투영 FD 열거 → 슈퍼키 판정을 코드로 구현해 네 보기를 전수 검사했다.

def closure(attrs, fds):
    c = set(attrs); changed = True
    while changed:
        changed = False
        for l, r in fds:
            if set(l) <= c and not set(r) <= c:
                c |= set(r); changed = True
    return c
# 각 조각의 모든 속성 부분집합 X에 대해
#   투영 FD: X -> (closure(X) ∩ 조각) - X
#   BCNF 위반: 투영 FD가 존재하는데 closure(X) ⊉ 조각
보기1: R(A,B)   keys=['AB'] projFD=[]                                   BCNF=YES
       R(B,C,D) keys=['B']  projFD=[B→CD, C→D, BC→D, BD→C]             BCNF=NO  위반: C→D
보기2: R(A,B,C) keys=['A']  projFD=[A→BC, B→C, AB→C, AC→B]             BCNF=NO  위반: B→C
       R(C,D)   keys=['C']  projFD=[C→D]                               BCNF=YES
보기3: R(A,B,C) keys=['AB','BC'] projFD=[C→A, AB→C, BC→A]              BCNF=NO  위반: C→A
       R(C,D)   keys=['C']  projFD=[C→D]                               BCNF=YES
보기4: R(A,C)   keys=['C']  projFD=[C→A]                               BCNF=YES
       R(B,C,D) keys=['BC'] projFD=[BC→D]                              BCNF=YES
       => 모두 BCNF: True

④만 두 조각이 모두 BCNF임을 확인했다.

보기별 판정​

보기판정근거
① R1(A,B) / R2(B,C,D)오답 보기R2에서 C→D 가 성립하는데 C⁺={C,D} 가 B를 포함하지 않아 C는 슈퍼키가 아니다. B→C→D 이행 종속이 남아 3NF도 위반
② R1(A,B,C) / R2(C,D)오답 보기R1에서 B→C 가 성립하는데 B⁺={B,C,D} 에 A가 없어 B는 슈퍼키가 아니다. A→B→C 이행 종속으로 3NF도 위반
③ R1(A,B,C) / R2(C,D)오답 보기R1에서 C→A 가 성립하는데 C⁺={C,D,A} 에 B가 없어 C는 슈퍼키가 아니다. 다만 A가 주요 속성이라 3NF는 만족, BCNF만 위반
④ R1(A,C) / R2(B,C,D)✅ 정답 보기R1의 유일한 FD C→A 는 C가 키, R2의 유일한 FD BC→D 는 BC가 키. 둘 다 좌변이 후보키 → 모두 BCNF

오답 이유​

  • ①이 틀린 이유: R1(A,B)는 2속성이라 자동으로 BCNF지만, 문제가 되는 FD들이 전부 R2(B,C,D)에 몰려 있다. R2의 후보키는 B 하나인데(B⁺ = {B,C,D}), 여기에 B→C 와 C→D 가 함께 살아남아 B → C → D 이행적 종속을 이룬다. 결정자 C의 폐포는 {C, D} 로 B를 결정하지 못하므로 C는 슈퍼키가 아니다. 더구나 D는 어떤 후보키에도 속하지 않는 비주요 속성이므로 3NF의 예외 조항도 적용되지 않아, R2는 BCNF는 물론 3NF조차 만족하지 못한다. 올바르게 고치려면 R2를 다시 (B,C) 와 (C,D) 로 쪼개야 한다.
  • ②가 틀린 이유: 이번에는 문제가 R1(A,B,C) 쪽에 있다. A→B→C→D 라는 일자형 이행 종속 사슬에서 C→D 만 떼어내 R2(C,D)로 분리했으나, 남은 A→B→C 사슬이 R1에 그대로 남았다. R1의 후보키는 A이고, B⁺ = {B,C,D} 에 A가 없으므로 B는 슈퍼키가 아닌데 B→C 가 성립한다. 따라서 BCNF도 3NF도 위반이다. 이행 종속 사슬은 모든 고리를 끊어야 하며, 한 고리만 분리해서는 부족하다는 것을 보여주는 보기다.
  • ③이 틀린 이유: 이 보기가 가장 정교한 함정이다. R1(A,B,C)의 후보키는 AB 와 BC 두 개이고, 따라서 A·B·C가 모두 주요 속성이다. 여기서 C→A 가 성립하는데 C⁺ = {C,D,A} 가 B를 포함하지 않아 C는 슈퍼키가 아니다. BCNF는 "모든 비자명 FD의 좌변이 슈퍼키"를 예외 없이 요구하므로 위반이다. 반면 3NF는 "좌변이 슈퍼키이거나 우변이 주요 속성이면 허용"하는데, 우변 A가 후보키 AB의 구성 원소이므로 3NF는 통과한다. 즉 이 보기는 "3NF이지만 BCNF가 아닌" 교과서적 사례이며, 문제가 요구한 것은 BCNF 이상이므로 답이 될 수 없다. 후보키가 둘 이상이고 서로 속성을 공유할 때만 이런 간극이 생긴다는 점을 기억하면 판별이 쉬워진다.

핵심 정리​

  • BCNF 판정 기준: 모든 비자명 FD X→Y 의 좌변 X가 그 릴레이션의 슈퍼키여야 한다. 예외는 없다.
  • 조각 릴레이션을 판정할 때는 원래 FD 집합 전체로 폐포를 구한 뒤 조각의 속성만 남기는 투영을 해야 한다. 원래 목록에 없던 FD가 유도되어 나타날 수 있다(④의 BC→D 가 C→A + (A,B)→CD 의 2단 유도로 생김).
  • 속성이 2개뿐인 릴레이션은 항상 BCNF다. 이 규칙만으로 네 보기의 절반이 즉시 판정되므로, 실제로는 각 보기의 3속성 릴레이션 하나씩만 검사하면 된다.
  • 3NF와 BCNF의 차이는 딱 하나 — 3NF는 X→A 에서 X가 슈퍼키가 아니어도 A가 주요 속성이면 허용한다. 보기 ③(C→A, A는 주요 속성)이 바로 이 틈에 놓인 함정이다.
  • 정답 ④의 성공 비결은 문제의 FD C→A 를 R1(A,C)로 격리한 것이다. A가 R2에 없으므로 C→A 는 R2에서 투영되지 않고 사라지며, R2에는 좌변이 후보키인 BC→D 만 남아 두 조각 모두 BCNF가 된다.
