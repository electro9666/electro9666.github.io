095번 · BERT는 인코더만 사용하는 모델

제25회(2024년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. BERT의 이름이 곧 정답이다​

BERT = Bidirectional Encoder Representations from Transformers

단어의미
Bidirectional문장을 왼쪽→오른쪽, 오른쪽→왼쪽 양방향으로 동시에 참조해 문맥을 이해
Encoder트랜스포머의 인코더 블록만 사용 → 디코더가 없다
Representations출력은 생성 문장이 아니라 각 토큰의 문맥 표현 벡터
from Transformers트랜스포머(2017)를 기반으로 함

2018년 구글이 발표한 논문 "BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding"에서 제안되었다. 이름을 풀어 쓰는 것만으로 이 문항의 정답(디코더 없음)과 나머지 세 보기(트랜스포머 기반, NLP 딥러닝 아키텍처)가 동시에 확인된다.

2. 트랜스포머 계열 3대 구조 비교​

구조대표 모델사용하는 블록어텐션 방향사전학습 목표주 용도
인코더 전용BERT, RoBERTa, ALBERT, ELECTRA인코더만양방향(전체 참조)MLM (+NSP)분류, NER, 추출형 QA — 이해(NLU)
디코더 전용GPT 계열, LLaMA디코더만단방향(왼쪽만)다음 토큰 예측문장 생성, 대화 — 생성(NLG)
인코더–디코더원 트랜스포머, T5, BART둘 다인코더 양방향 + 디코더 단방향Span 복원 등번역, 요약 — 시퀀스 변환

"BERT는 인코더만, GPT는 디코더만" — 이 대비가 본 문항의 핵심이다. BERT는 문장을 생성할 필요가 없으므로 디코더가 아예 필요 없다.

3. BERT의 입력 표현 — 세 임베딩의 합​

BERT의 입력 벡터는 다음 세 임베딩을 더해서 만든다.

입력 토큰:      [CLS]  나는  학교에  간다  [SEP]  오늘은  월요일  [SEP]
  ① Token Embedding      (WordPiece 어휘 사전, 30,522개)
+ ② Segment Embedding    (문장 A / 문장 B 구분: E_A, E_B)
+ ③ Position Embedding   (0, 1, 2, ... 최대 511 — 학습되는 임베딩)
─────────────────────────
= 최종 입력 표현
임베딩역할비고
토큰 임베딩단어(서브워드) 자체의 의미WordPiece 토크나이저
세그먼트 임베딩두 문장을 입력할 때 어느 쪽 문장인지NSP 태스크를 위해 필요
위치 임베딩(Position Embedding)토큰의 순서 정보어텐션은 순서 불변이므로 필수

원 트랜스포머는 사인·코사인 기반의 고정된 위치 인코딩(positional encoding) 을 썼지만, BERT는 학습되는 위치 임베딩(learned position embedding) 을 사용한다. 방식은 다르지만 위치 정보를 사용한다는 점은 동일하다.

특수 토큰도 함께 알아 둔다.

토큰용도
[CLS]문장 맨 앞. 이 위치의 출력 벡터를 문장 전체 표현으로 써서 분류에 사용
[SEP]문장 구분자
[MASK]MLM 사전학습에서 가려진 토큰

4. BERT의 사전학습(pre-training) 태스크​

태스크내용목적
MLM (Masked Language Model)입력 토큰의 15%를 무작위로 가리고 원래 단어를 맞히도록 학습(그중 80% [MASK], 10% 임의 단어, 10% 유지)양방향 문맥 학습을 가능하게 하는 장치
NSP (Next Sentence Prediction)두 문장이 실제로 이어지는지 이진 분류문장 간 관계 이해(QA·NLI 대비)

단방향 언어모델(GPT)은 "다음 단어 맞히기"로 학습할 수 있지만, 양방향 모델은 그렇게 하면 정답을 미리 보게 되므로(정보 누출) 가림(masking) 이라는 우회 장치가 필요했다. 이것이 MLM의 존재 이유다.

사전학습 후에는 태스크별로 얇은 출력층만 붙여 파인튜닝(fine-tuning) 한다 — 문장 분류, 개체명 인식, 추출형 질의응답(SQuAD), 자연어 추론 등.

5. BERT 모델 규모​

모델인코더 층 수(L)은닉 차원(H)어텐션 헤드(A)파라미터
BERT-base1276812약 1.1억
BERT-large24102416약 3.4억

층 수·차원이 달라도 모두 인코더 블록만 쌓은 구조라는 점은 동일하다.

6. 혼동하기 쉬운 인접 개념​

진술판정이유
"BERT는 인코더와 디코더를 갖는다"✗인코더 전용. 디코더는 GPT·T5의 구성 요소
"BERT는 문장을 생성한다"✗생성용 디코더가 없어 자연스러운 문장 생성에 부적합
"BERT는 위치 임베딩을 쓰지 않는다"✗학습형 위치 임베딩 사용(원 트랜스포머는 고정 사인파 인코딩)
"BERT는 트랜스포머와 무관한 새 구조다"✗트랜스포머 인코더 블록을 그대로 쌓은 구조

문제​

정답​

②

상세 풀이​

"가장 적절하지 않은 것"을 고르는 부정형 문항이다. BERT의 이름을 풀어 쓰는 것만으로 대부분 판별된다.

  1. ① 위치 임베딩을 사용한다 — 적절하다. BERT의 입력 표현은 토큰 임베딩 + 세그먼트 임베딩 + 위치 임베딩의 합이다. 셀프 어텐션은 토큰 순서를 구분하지 못하므로 위치 정보 주입은 필수이며, BERT는 학습되는 위치 임베딩을 사용한다.
  2. ② 인코더와 디코더를 갖는다 — 적절하지 않다. BERT는 Bidirectional Encoder Representations from Transformers, 즉 인코더만 쌓아 만든 모델이며 디코더가 없다. → 정답
  3. ③ 트랜스포머 모델을 기반으로 한다 — 적절하다. 이름의 "from Transformers"가 그대로 말해 주며, BERT-base는 트랜스포머 인코더 블록 12층, BERT-large는 24층으로 구성된다.
  4. ④ 자연어 처리를 위한 딥러닝 아키텍처 중 하나이다 — 적절하다. 2018년 구글이 발표한 대표적 NLP 사전학습 딥러닝 모델로, GLUE·SQuAD 등 다수 벤치마크에서 당시 최고 성능을 기록했다.

보기별 판정​

보기판정근거
① 위치 임베딩 사용오답 보기(적절한 설명)입력 = 토큰 + 세그먼트 + 위치 임베딩의 합. 어텐션이 순서 불변이므로 필수
② 인코더와 디코더를 가짐✅ 정답 보기(적절하지 않은 설명)BERT는 인코더 전용. 디코더 없음(GPT는 디코더 전용, T5는 둘 다)
③ 트랜스포머 기반오답 보기(적절한 설명)트랜스포머 인코더 블록을 base 12층 / large 24층으로 쌓음
④ NLP 딥러닝 아키텍처오답 보기(적절한 설명)2018년 구글 발표, NLU 계열 대표 사전학습 모델

오답 이유​

  • ②가 정답인(적절하지 않은) 이유: BERT의 목적은 문장을 생성하는 것이 아니라 문장을 이해해 각 토큰의 양방향 문맥 표현을 얻는 것이다. 생성은 이전 출력에 조건부로 다음 토큰을 하나씩 내놓는 작업이라 마스크드 셀프어텐션과 cross-attention을 갖춘 디코더가 필요한데, BERT는 그런 작업을 하지 않으므로 디코더를 두지 않았다. 올바른 서술은 "BERT는 트랜스포머의 인코더만을 여러 층 쌓은 인코더 전용 모델이다"이다.
  • ①이 적절한 설명인 이유: 셀프 어텐션은 집합 연산에 가까워 토큰 순서를 바꿔도 결과가 같다(순서 불변). 따라서 "나는 너를 좋아한다"와 "너는 나를 좋아한다"를 구분하려면 위치 정보를 명시적으로 넣어야 한다. BERT는 위치 0~511에 대응하는 학습 가능한 임베딩 벡터를 두고 토큰·세그먼트 임베딩과 더한다. 원 트랜스포머의 고정 사인파 인코딩과 구현 방식이 다를 뿐 "위치 정보를 사용한다"는 사실은 같다.
  • ③이 적절한 설명인 이유: BERT의 각 층은 원 트랜스포머 인코더 블록과 동일하게 멀티 헤드 셀프어텐션 → 잔차연결/LayerNorm → 위치별 피드포워드 → 잔차연결/LayerNorm 순으로 구성된다. 새로운 구조를 만든 것이 아니라, 기존 인코더를 사전학습 방식(MLM+NSP) 과 결합한 것이 BERT의 기여다.
  • ④가 적절한 설명인 이유: BERT는 자연어 처리 분야의 딥러닝 아키텍처이며, "사전학습 후 파인튜닝"이라는 전이학습 패러다임을 NLP에 정착시킨 모델이다. 이 보기는 너무 일반적이어서 틀릴 여지가 없다.

핵심 정리​

  • BERT = Bidirectional Encoder Representations from Transformers — 이름에 "Encoder"가 들어 있고 "Decoder"가 없다. 인코더 전용 모델이다.
  • 3대 구조 대비: BERT = 인코더 전용(이해), GPT = 디코더 전용(생성), T5/BART = 인코더–디코더(변환).
  • BERT 입력 = 토큰 임베딩 + 세그먼트 임베딩 + 위치 임베딩. 특수 토큰은 [CLS](문장 표현), [SEP](구분), [MASK](MLM).
  • 사전학습 태스크는 MLM(토큰 15% 가리기) 과 NSP(다음 문장 예측). 규모는 base(12층·768·12헤드) / large(24층·1024·16헤드).
  • 결정타: "BERT가 디코더를 갖는다"는 서술은 항상 오답이다. 디코더가 있었다면 이름이 Encoder Representations일 수 없다.
