079번 · 4비트 가산기의 오버플로우 플래그(V) 논리식

제25회(2024년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. 전가산기(Full Adder)와 리플 캐리 가산기​

전가산기는 입력 3개(AiA_iAi​, BiB_iBi​, 자리올림 입력 Ci−1C_{i-1}Ci−1​)를 받아 합 SiS_iSi​ 와 자리올림 출력 CiC_iCi​ 를 내는 조합회로다.

Si=Ai⊕Bi⊕Ci−1,Ci=AiBi+(Ai⊕Bi)Ci−1S_i = A_i \oplus B_i \oplus C_{i-1}, \qquad C_i = A_iB_i + (A_i \oplus B_i)C_{i-1}Si​=Ai​⊕Bi​⊕Ci−1​,Ci​=Ai​Bi​+(Ai​⊕Bi​)Ci−1​

전가산기 4개를 이어 붙여 4비트 리플 캐리 가산기(ripple carry adder) 를 만든다. 하위 단의 캐리 출력이 상위 단의 캐리 입력이 되어 물결처럼 전파되므로 이런 이름이 붙었다.

      A4 B4        A3 B3        A2 B2        A1 B1
       ↓  ↓         ↓  ↓         ↓  ↓         ↓  ↓
 C4 ←[ FA ]← C3 ←[ FA ]← C2 ←[ FA ]← C1 ←[ FA ]← C0
       ↓            ↓            ↓            ↓
      S4           S3           S2           S1

문제 그림의 표기를 정리하면 다음과 같다.

기호의미
C0C_0C0​최하위 단으로 들어가는 올림수 입력
C3C_3C3​최상위(4번째) 단으로 들어가는 캐리 (= 3번째 단의 출력)
C4C_4C4​최상위 단에서 나가는 캐리 (최종 자리올림 출력)
S4S_4S4​최상위 비트의 합 = 부호 비트

이 문제에서 가장 중요한 것은 C3C_3C3​ = 부호 비트로 들어가는 캐리, C4C_4C4​ = 부호 비트에서 나가는 캐리라는 대응이다.

2. 2의 보수 표현과 부호 비트​

nnn비트 2의 보수에서 표현 범위는

−2n−1  ≤  x  ≤  2n−1−1-2^{n-1} \;\le\; x \;\le\; 2^{n-1}-1−2n−1≤x≤2n−1−1

4비트라면 −8∼+7-8 \sim +7−8∼+7 이다. 최상위 비트(MSB)가 부호를 나타내며, 0이면 양수, 1이면 음수다.

오버플로(overflow) 란 연산 결과가 이 표현 범위를 벗어나 부호가 뒤집혀 버리는 현상이다.

  0111 (+7)          1000 (-8)
+ 0001 (+1)        + 1111 (-1)
-------- 　        --------
  1000 (-8) ← 양수+양수가 음수!   0111 (+7) ← 음수+음수가 양수!

3. 상태 비트(플래그) 4종 — 그림의 V Z S C​

플래그이름의미이 회로에서의 산출
VoVerflow부호 있는(signed) 연산의 범위 초과C3⊕C4C_3 \oplus C_4C3​⊕C4​
ZZero결과가 0S4+S3+S2+S1‾\overline{S_4 + S_3 + S_2 + S_1}S4​+S3​+S2​+S1​​ (NOR)
SSign결과의 부호S4S_4S4​ (MSB)
CCarry부호 없는(unsigned) 연산의 자리올림C4C_4C4​

문제 그림에서 V Z S C 상자 아래로 NOR 게이트가 S1∼S4S_1 \sim S_4S1​∼S4​ 를 모아 Z를 만들고, S4S_4S4​ 가 S로, C4C_4C4​ 가 C로 연결되며, 왼쪽 상단의 상자(상태 비트 제어 회로)가 C3C_3C3​·C4C_4C4​ 를 받아 V를 만든다.

C와 V의 구분이 이 문제의 출제 의도다. C4C_4C4​ 를 그대로 V로 쓰면 안 된다. C4C_4C4​ 는 unsigned 캐리이고, signed 오버플로는 C3C_3C3​ 과 C4C_4C4​ 의 불일치로 판정한다.

4. 오버플로 판정 조건의 유도​

최상위 비트에서 일어나는 일을 네 경우로 나눠 보면 조건이 드러난다.

C3C_3C3​(들어온 캐리)C4C_4C4​(나간 캐리)피연산자 부호결과 부호오버플로?
00양 + 양양❌ 정상
10양 + 양음✅ 오버플로
01음 + 음양✅ 오버플로
11음 + 음음❌ 정상

→ C3≠C4C_3 \ne C_4C3​=C4​ 일 때만 오버플로 → 두 값의 배타적 논리합

 V=C3⊕C4 \boxed{\,V = C_3 \oplus C_4\,}V=C3​⊕C4​​

직관적 설명: 부호 비트 자리로 캐리가 들어왔는데 나가지 못하면 그 캐리가 부호 비트를 오염시켜 양수가 음수로 바뀐다. 반대로 들어오지 않았는데 나가기만 하면 부호 비트가 소실되어 음수가 양수로 바뀐다. 들어온 만큼 나가면(둘 다 0 또는 둘 다 1) 부호가 보존된다.

동치 표현: 피연산자와 결과의 부호로 써도 같다.

V=A4B4S4‾+A4‾ B4‾S4V = A_4 B_4 \overline{S_4} + \overline{A_4}\,\overline{B_4} S_4V=A4​B4​S4​​+A4​​B4​​S4​

(양수+양수인데 결과가 음수이거나, 음수+음수인데 결과가 양수)

5. 혼동하기 쉬운 인접 개념​

구분Carry(C)oVerflow(V)
대상부호 없는 정수 연산부호 있는(2의 보수) 정수 연산
논리식C=C4C = C_4C=C4​V=C3⊕C4V = C_3 \oplus C_4V=C3​⊕C4​
의미결과가 2n−12^n-12n−1 초과결과가 [−2n−1, 2n−1−1][-2^{n-1},\,2^{n-1}-1][−2n−1,2n−1−1] 벗어남
예: 1000 + 1000C=1C=1C=1 (unsigned 8+8=16 초과)V=1V=1V=1 (signed −8+−8=−16-8 + -8 = -16−8+−8=−16 범위 밖)
예: 0111 + 0001C=0C=0C=0 (unsigned 7+1=8, 4비트 내)V=1V=1V=1 (signed +7+1=+8 > +7)

두 플래그는 독립적이며 어느 한쪽만 1이 될 수도, 둘 다 1이 될 수도 있다. 프로그램이 피연산자를 부호 있는 수로 보느냐 없는 수로 보느냐에 따라 읽을 플래그가 달라진다.

상세 풀이​

1단계 — 문제 유형과 회로 읽기​

"2의 보수로 표현된 수들 간의 덧셈에서 오버플로우 플래그(V) 논리식으로 가장 적절한 것"을 고르는 긍정형 문항이다. 그림에서 상태 비트 제어 회로에 들어가는 신호가 C3C_3C3​ 와 C4C_4C4​ 임을 먼저 확인한다.

  • C3C_3C3​: 세 번째 FA의 캐리 출력 = 최상위(부호) 단으로 들어가는 캐리
  • C4C_4C4​: 네 번째(최상위) FA의 캐리 출력 = 부호 단에서 나가는 캐리

문제가 "2의 보수"라고 명시했으므로 구해야 하는 것은 signed 오버플로(V) 이지 unsigned 캐리(C)가 아니다.

2단계 — 진리표로 판정​

#C3C_3C3​C4C_4C4​실제 상황오버플로① C3+C4C_3+C_4C3​+C4​② C3⋅C4C_3 \cdot C_4C3​⋅C4​③ C3‾+C4‾\overline{C_3}+\overline{C_4}C3​​+C4​​④ C3⊕C4C_3 \oplus C_4C3​⊕C4​
100양+양 → 양 (정상)00 ✔0 ✔1 ✘0 ✔
201음+음 → 양11 ✔0 ✘1 ✔1 ✔
310양+양 → 음11 ✔0 ✘1 ✔1 ✔
411음+음 → 음 (정상)01 ✘1 ✘0 ✔0 ✔

4행 모두 일치하는 식은 ④ C3⊕C4C_3 \oplus C_4C3​⊕C4​ 뿐이다.

3단계 — 구체적 수치 검증​

4비트 2의 보수로 실제 덧셈을 해 보면 진리표가 확인된다.

연산2진 계산C3C_3C3​C4C_4C4​결과 해석V

(−8)+(−1)(-8) + (-1)(−8)+(−1)1000 + 1111 = 011101−9가 +7로1

  • 2번째 행: 0111 + 0001 에서 하위 3비트 111 + 001 이 자리올림을 만들어 C3=1C_3 = 1C3​=1, 그러나 부호 비트가 0+0+1=10+0+1 = 10+0+1=1 로 나가는 캐리는 없어 C4=0C_4 = 0C4​=0. 불일치 → 오버플로
  • 3번째 행: 하위 3비트 000 + 111 에 자리올림이 없어 C3=0C_3 = 0C3​=0, 부호 비트 1+1+01+1+01+1+0 에서 캐리가 나가 C4=1C_4 = 1C4​=1. 불일치 → 오버플로
  • 1·4번째 행: C3=C4C_3 = C_4C3​=C4​ 로 일치 → 정상

V=C3⊕C4V = C_3 \oplus C_4V=C3​⊕C4​

보기별 판정​

보기판정근거
① C3+C4C_3 + C_4C3​+C4​ (OR)오답 보기C3=C4=1C_3{=}C_4{=}1C3​=C4​=1 (음수+음수 정상)에서 1이 되어 정상 연산을 오버플로로 오판
② C3⋅C4C_3 \cdot C_4C3​⋅C4​ (AND)오답 보기두 캐리가 일치하는 경우에만 1 → 실제 오버플로 두 경우(불일치)에서 모두 0. 정반대
③ C3‾+C4‾\overline{C_3} + \overline{C_4}C3​​+C4​​ (NAND 등가)오답 보기C3=C4=0C_3{=}C_4{=}0C3​=C4​=0 (양수+양수 정상)에서 1이 되어 오판. 실제 조건과 무관
④ C3⊕C4C_3 \oplus C_4C3​⊕C4​ (XOR)✅ 정답 보기두 캐리가 불일치할 때만 1 → 진리표 4행 전부 실제 오버플로와 일치

오답 이유​

  • ①이 틀린 이유: OR는 "둘 중 하나라도 1이면 1"이므로 C3=C4=1C_3 = C_4 = 1C3​=C4​=1 인 경우까지 오버플로로 판정한다. 그런데 C3=C4=1C_3 = C_4 = 1C3​=C4​=1 은 1101 + 1110 = 1011 (−3+−2=−5-3 + -2 = -5−3+−2=−5)처럼 음수끼리 더해 정상적인 음수가 나온 경우로, 오버플로가 아니다. 정상 연산을 오류로 보고하게 되어 잘못된 식이다.
  • ②가 틀린 이유: AND는 C3=C4=1C_3 = C_4 = 1C3​=C4​=1 일 때만 1이다. 이는 오버플로가 아닌 경우(음수+음수 정상)를 정확히 골라내는 식이며, 실제 오버플로인 두 경우(C3≠C4C_3{\ne}C_4C3​=C4​)에서는 모두 0을 낸다. 판정 방향이 정확히 반대인 함정 보기다.
  • ③이 틀린 이유: C3‾+C4‾\overline{C_3} + \overline{C_4}C3​​+C4​​ 는 드모르간에 의해 C3⋅C4‾\overline{C_3 \cdot C_4}C3​⋅C4​​ 와 같으므로, "두 캐리가 모두 1인 경우만 0, 나머지는 1"이 된다. 따라서 C3=C4=0C_3 = C_4 = 0C3​=C4​=0 인 경우(양수+양수 정상, 예: 0011 + 0010)에도 1을 내어 오버플로로 오판한다. 오버플로 판정은 불일치를 봐야 하는데 이 식은 둘 다 1인지만 보므로 조건 자체가 어긋난다.
  • ④가 맞는 이유: XOR는 두 입력이 다를 때만 1이다. 최상위 비트로 들어온 캐리와 나간 캐리가 다르면 부호 비트가 오염되어 결과 부호가 뒤집히고, 같으면 부호가 보존된다. 진리표 4행이 실제 오버플로 발생 여부와 완전히 일치하며, 동치식 V=A4B4S4‾+A4‾ B4‾S4V = A_4B_4\overline{S_4} + \overline{A_4}\,\overline{B_4}S_4V=A4​B4​S4​​+A4​​B4​​S4​ 로 전개해도 같은 결과가 나온다.

핵심 정리​

  • V=C3⊕C4V = C_3 \oplus C_4V=C3​⊕C4​ — 부호 비트로 들어간 캐리와 나간 캐리가 다를 때만 signed 오버플로다.
  • C(캐리)와 V(오버플로)는 다른 플래그다. C=C4C = C_4C=C4​ 는 부호 없는 연산의 초과를, V=C3⊕C4V = C_3 \oplus C_4V=C3​⊕C4​ 는 부호 있는(2의 보수) 연산의 범위 초과를 나타낸다. 문제에 "2의 보수"가 나오면 V를 묻는 것이다.
  • 오버플로가 나는 두 경우는 양수+양수 → 음수(C3=1,C4=0C_3{=}1, C_4{=}0C3​=1,C4​=0)와 음수+음수 → 양수(C3=0,C4=1C_3{=}0, C_4{=}1C3​=0,C4​=1) 뿐이다. 부호가 다른 두 수의 덧셈에서는 오버플로가 절대 발생하지 않는다.
  • 4대 상태 플래그: V(오버플로, C3⊕C4C_3\oplus C_4C3​⊕C4​), Z(제로, 합 비트 전부 0 → NOR), S(부호, S4S_4S4​), C(캐리, C4C_4C4​).
  • 이 문제의 결정타: 보기 4개는 OR·AND·NAND·XOR로 구성되어 있는데, "두 값이 다를 때만 1" 이라는 오버플로 조건을 표현하는 것은 XOR 하나뿐이다. 진리표 4행을 그려 넣으면 3초 만에 갈린다.
