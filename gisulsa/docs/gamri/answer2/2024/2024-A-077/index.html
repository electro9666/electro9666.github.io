077번 · 다수 입력 중 하나를 선택하는 조합회로

제25회(2024년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. 디지털 논리회로의 큰 분류​

구분특징기억 소자대표 회로
조합회로(combinational)출력이 현재 입력만으로 결정없음가산기, 인코더·디코더·MUX·DEMUX, 비교기
순차회로(sequential)출력이 현재 입력 + 이전 상태로 결정있음(플립플롭)레지스터, 카운터, 시프트레지스터, 유한상태기계

문제가 "조합회로"라고 명시했으므로 네 보기 모두 조합회로에 속한다. 즉 분류가 아니라 기능으로 가려야 한다.

2. 4대 기능 회로 비교 — 이 문제의 핵심 표​

회로입력출력제어(선택)선역할방향성
인코더(Encoder)2n2^n2n개(그중 1개 활성)n비트 코드없음활성 입력 위치를 코드로 압축다 → 소
디코더(Decoder)n비트 코드2n2^n2n개(그중 1개 활성)없음(Enable은 있을 수 있음)코드를 해독해 한 줄만 활성소 → 다
멀티플렉서(MUX, 다중화기)2n2^n2n개 데이터1개n비트 선택선여러 입력 중 하나를 골라 단일 출력으로다 → 1 (many-to-one)
디멀티플렉서(DEMUX, 역다중화기)1개 데이터2n2^n2n개n비트 선택선하나의 입력을 여러 출력 중 하나로 분배1 → 다 (one-to-many)

구분 기준 두 가지

  1. 코드 변환인가, 데이터 경로 선택인가 — 인코더/디코더는 코드 변환, MUX/DEMUX는 데이터 경로 선택
  2. 어느 쪽이 1개인가 — 출력이 1개면 MUX, 입력이 1개면 DEMUX

3. 멀티플렉서(MUX)의 동작​

4:1 MUX(데이터 입력 I0∼I3I_0 \sim I_3I0​∼I3​, 선택선 S1S0S_1 S_0S1​S0​, 출력 YYY)

S1S_1S1​S0S_0S0​출력 YYY
00I0I_0I0​
01I1I_1I1​
10I2I_2I2​
11I3I_3I3​

논리식:

Y=S1‾ S0‾ I0+S1‾ S0 I1+S1 S0‾ I2+S1 S0 I3Y = \overline{S_1}\,\overline{S_0}\,I_0 + \overline{S_1}\,S_0\,I_1 + S_1\,\overline{S_0}\,I_2 + S_1\,S_0\,I_3Y=S1​​S0​​I0​+S1​​S0​I1​+S1​S0​​I2​+S1​S0​I3​

일반화하면 2n:12^n : 12n:1 MUX는 선택선 nnn개가 필요하다 (2n2^n2n개 입력을 구별하려면 nnn비트가 있어야 하므로).

MUX데이터 입력선택선출력
2:1211
4:1421
8:1831
16:11641

4. 디멀티플렉서(DEMUX)의 동작​

1:4 DEMUX(데이터 입력 DDD, 선택선 S1S0S_1S_0S1​S0​, 출력 Y0∼Y3Y_0 \sim Y_3Y0​∼Y3​)

S1S_1S1​S0S_0S0​활성 출력
00Y0=DY_0 = DY0​=D (나머지 0)
01Y1=DY_1 = DY1​=D
10Y2=DY_2 = DY2​=D
11Y3=DY_3 = DY3​=D

DEMUX의 데이터 입력 DDD를 항상 1로 고정하면 디코더와 동일하게 동작한다. 그래서 DEMUX는 "Enable 입력이 있는 디코더"로 구현되기도 한다. 다만 개념상 DEMUX는 데이터를 분배하고 디코더는 코드를 해독한다는 목적 차이가 있다.

5. 실무 응용​

회로활용
MUX여러 데이터 소스 → 하나의 전송로(시분할 다중화), CPU 내부 버스 선택, ALU 기능 선택, 조합논리 함수 구현
DEMUX하나의 전송로 → 여러 목적지 역다중화, 메모리/주변장치로 데이터 라우팅
인코더키보드 키 입력 → 코드, 인터럽트 우선순위 인코더
디코더메모리 주소 디코딩(칩 선택), 7-세그먼트 구동, 명령어 해독

MUX와 DEMUX는 통신 채널의 양 끝에서 짝을 이룬다. 송신 측에서 여러 신호를 하나로 합치고(MUX), 수신 측에서 다시 나눈다(DEMUX).

6. 혼동하기 쉬운 인접 개념​

함정바로잡기
"디코더도 하나를 선택하니까 MUX 아닌가?"디코더는 출력 한 줄을 활성화할 뿐 입력 데이터를 통과시키지 않는다. 디코더의 입력은 데이터가 아니라 코드다
"인코더가 여러 입력을 하나로 보낸다"인코더 출력은 1개 선이 아니라 n비트 코드이며, 입력 데이터 값을 그대로 내보내지 않는다
MUX ↔ DEMUX 방향 혼동MUX = Many to one, DEMUX = DEliver to many

문제​

정답​

③

상세 풀이​

1단계 — 문제 문장을 조건으로 분해​

"다수의 입력 단자 중에서 조건에 맞는 하나를 선택하여 단일 출력 단자로 연결하는 조합회로"

#조건의미
㉠입력 단자가 다수입력 쪽이 2n2^n2n개
㉡조건(선택신호)에 맞는 하나를 선택선택선이 존재
㉢단일 출력 단자로 연결출력 쪽이 1개
㉣데이터를 연결(통과)코드 변환이 아니라 경로 연결

→ 다(입력) : 1(출력) + 선택선 + 데이터 통과 = 멀티플렉서

2단계 — 보기 대조​

보기입력출력선택선㉠㉡㉢㉣
① 인코더2n2^n2n개n비트 코드(다수 선)없음✔✘✘✘
② 디코더n비트 코드2n2^n2n개없음✘✘✘✘
③ 멀티플렉서2n2^n2n개1개n비트✔✔✔✔
④ 디멀티플렉서1개2n2^n2n개n비트✘✔✘✔

네 조건을 모두 만족하는 것은 ③ 멀티플렉서뿐이다.

3단계 — ④와의 결정적 차이​

④ 디멀티플렉서도 "조건에 맞는 하나를 선택"한다는 서술(㉡)은 만족한다. 그래서 가장 헷갈리는 보기다. 하지만 무엇이 여럿이고 무엇이 하나인가가 정반대다.

MUX   :  I0 ─┐
             │
         I1 ─┼──[선택 S]──▶  Y        (입력 다수 → 출력 1개)
         I2 ─┤
         I3 ─┘

DEMUX :               ┌──▶ Y0
         D ──[선택 S]─┼──▶ Y1        (입력 1개 → 출력 다수)
                      ├──▶ Y2
                      └──▶ Y3

문제는 "단일 출력 단자로 연결"이라고 명시했으므로 출력이 1개인 MUX가 답이다.

4단계 — 결론​

③ 멀티플렉서 → 정답 ③

보기별 판정​

보기판정근거
① 인코더오답 보기2n2^n2n개 입력 중 활성화된 하나의 위치를 n비트 코드로 변환하는 회로. 출력이 단일 단자가 아니고 선택선도 없으며, 입력 데이터를 그대로 통과시키지도 않는다
② 디코더오답 보기n비트 코드를 받아 2n2^n2n개 출력 중 하나를 활성화하는 1 → 다 회로. 입력이 "다수의 데이터 단자"가 아니라 코드이며 방향도 반대다
③ 멀티플렉서✅ 정답 보기2n2^n2n개 데이터 입력 중 n비트 선택선이 지정한 하나를 골라 단일 출력으로 내보내는 다대일 조합회로. 문제 서술과 정확히 일치
④ 디멀티플렉서오답 보기단일 입력을 2n2^n2n개 출력 중 하나로 분배하는 일대다 회로. 선택선이 있다는 점은 같으나 입출력 방향이 정반대

오답 이유​

  • ①이 틀린 이유: 인코더는 2n2^n2n개 입력선 중 활성화된 하나가 몇 번째인지를 nnn비트 이진 코드로 바꿔 출력한다. 즉 결과물은 "선택된 입력의 값"이 아니라 "위치를 나타내는 코드"이며, 출력도 단일 단자가 아니라 nnn개의 선이다. 또한 인코더에는 선택선이 존재하지 않는다 — 무엇을 고를지는 입력 자체가 결정한다. "조건에 맞는 하나를 선택"이라는 문제 서술과 맞지 않는다.
  • ②가 틀린 이유: 디코더는 방향이 정반대다. nnn비트 코드를 입력받아 2n2^n2n개 출력 중 하나만 활성화한다. 문제는 "다수의 입력 단자 중에서 하나를 선택"이라고 했는데, 디코더에서 다수인 쪽은 출력이다. 또한 디코더의 출력은 선택된 입력 데이터가 아니라 단순한 활성화 신호(1) 다. 데이터를 "연결"한다는 서술에 부합하지 않는다.
  • ③이 맞는 이유: 멀티플렉서는 2n2^n2n개의 데이터 입력, nnn개의 선택선, 1개의 출력을 갖는 조합회로로, 선택선의 값이 지정하는 입력을 그대로 출력에 연결(통과) 시킨다. 문제의 네 조건(다수 입력, 선택 조건, 단일 출력, 데이터 연결)을 빠짐없이 만족한다.
  • ④가 틀린 이유: 디멀티플렉서는 MUX의 역연산이다. 입력이 1개, 출력이 2n2^n2n개이며, 선택선이 지정한 출력 쪽 하나로 입력 데이터를 내보낸다. 선택선이 있다는 공통점 때문에 헷갈리기 쉬우나, 문제가 "다수의 입력 단자 중 하나를 골라 단일 출력으로"라고 방향을 못 박았으므로 DEMUX는 성립하지 않는다. "어느 쪽이 1개인가" 를 보면 즉시 갈린다 — 출력이 1이면 MUX, 입력이 1이면 DEMUX.

핵심 정리​

  • MUX(멀티플렉서) = 2n2^n2n개 데이터 입력 + nnn개 선택선 → 1개 출력. 다대일(many-to-one), 데이터 경로를 선택한다.
  • DEMUX(디멀티플렉서) = 1개 데이터 입력 + nnn개 선택선 → 2n2^n2n개 출력. 일대다(one-to-many), 데이터를 분배한다.
  • 인코더 = 2n2^n2n개 입력 → nnn비트 코드(압축), 디코더 = nnn비트 코드 → 2n2^n2n개 중 하나 활성(해독). 둘 다 선택선이 없고 코드 변환이 목적이다.
  • 2n:12^n : 12n:1 MUX의 선택선은 nnn개다. 8:1이면 3개, 16:1이면 4개.
  • 이 문제의 결정타: "다수 입력 → 단일 출력"이라는 방향과 "조건(선택신호)에 따라"라는 단서가 동시에 성립하는 회로는 멀티플렉서뿐이다. 선택선이 있는 DEMUX는 방향이 반대이고, 인코더·디코더는 선택선 자체가 없다.
