118번 · 지식·소유·존재 기반 인증과 생체 템플릿 등록

제25회(2024년) 정보시스템감리사 A형 — 보안

사전 지식​

1. 인증 요소(Authentication Factor)의 4분류​

사용자 인증은 "무엇으로 본인임을 증명하는가"에 따라 네 가지 요소로 나뉜다.

요소영문 표현정의대표 수단장점단점
지식 기반What you know사용자가 알고 있는 정보비밀번호, PIN, 패턴, 보안 질문구축·관리 비용이 가장 저렴, 추가 장비 불필요추측·유추·무차별 대입·사전 공격, 피싱, 재사용, 망각
소유 기반What you have사용자가 가지고 있는 물건OTP 토큰, 스마트카드, 보안카드, 공동인증서(USB), 휴대폰지식 기반보다 강함, 물리적 소지 필요복제·도난·분실·파손·고장, 배터리 소진, 발급·재발급 비용
존재(생체) 기반What you are사용자의 신체적 특징지문, 홍채, 망막, 얼굴, 정맥분실·망각 없음, 편의성 높음등록(enrollment) 필요, 오인식(FAR/FRR), 유출 시 변경 불가, 신체 변화·훼손
행위 기반What you do사용자의 행동 특성서명 필압·속도, 타이핑 리듬, 걸음걸이, 음성지속 인증에 활용 가능상황·건강 상태에 따라 변동

문제 ④번 보기의 "지식, 소유, 존재 및 행위"가 바로 이 네 분류다.

2. 다중요소 인증(MFA)의 정의 — "서로 다른 범주"가 핵심​

용어정의
단일요소 인증(SFA)한 가지 요소만 사용(예: 비밀번호만)
이중요소 인증(2FA, Two-Factor)서로 다른 범주의 인증 요소 2가지를 결합
다중요소 인증(MFA, Multi-Factor)서로 다른 범주의 요소를 2가지 이상 결합

주의할 점은 "서로 다른 범주" 라는 조건이다.

조합2FA인가?이유
비밀번호 + OTP 토큰✅ 2FA지식 + 소유
비밀번호 + 지문✅ 2FA지식 + 존재
스마트카드 + PIN✅ 2FA소유 + 지식(ATM 카드가 대표 사례)
비밀번호 + 보안 질문❌ 2FA 아님둘 다 지식 기반 — 같은 범주의 2단계일 뿐
지문 + 홍채❌ 2FA 아님둘 다 존재 기반

같은 범주를 두 번 쓰는 것은 2FA가 아니라 2단계 인증(two-step) 에 가깝고, 하나의 공격 벡터(예: 피싱)로 둘 다 무너질 수 있다.

3. 생체 인증의 동작 — 등록과 대조는 반드시 한 쌍​

생체 인증은 두 국면(phase) 으로 구성되며, 등록 없이는 대조가 성립하지 않는다.

국면단계내용
① 등록(Enrollment)1. 획득센서로 지문·홍채 등 원본 생체 이미지 취득
2. 특징 추출이미지에서 특징점(지문의 융선 분기점 등)만 추출
3. 템플릿 생성·저장특징점을 생체 템플릿(biometric template) 으로 변환해 DB·스마트카드·보안영역(TEE/Secure Enclave) 에 저장
② 인증(Verification / Identification)4. 제시사용자가 다시 생체 정보를 제시
5. 특징 추출동일 방식으로 특징 추출
6. 대조(Matching)저장된 템플릿과 비교해 유사도가 임계값 이상이면 인증 성공

저장된 템플릿이 없으면 비교 대상이 존재하지 않으므로 인증 자체가 불가능하다. ③번 보기는 이 필수 단계를 부정한다.

보관 방식의 차이

방식저장 위치특징
서버 저장형중앙 DB어느 단말에서든 인증 가능하나, DB 유출 시 대규모 피해
단말/카드 저장형(Match-on-Device)스마트폰 보안영역, 스마트카드템플릿이 기기를 떠나지 않음. FIDO·Apple Touch ID/Face ID 방식

"DB에 등록하지 않는다"는 표현이 Match-on-Device 방식과 혼동될 수 있으나, 이 경우에도 템플릿은 단말 내부에 등록·저장된다. 저장 위치가 바뀔 뿐 등록 자체는 필수다.

4. 생체 인증의 성능 지표와 고유 위험​

지표의미조정 방향
FAR(False Acceptance Rate)타인을 본인으로 잘못 수락하는 비율낮출수록 보안 강화
FRR(False Rejection Rate)본인을 잘못 거부하는 비율낮출수록 편의성 향상
EER(Equal Error Rate)FAR = FRR이 되는 지점낮을수록 우수한 시스템

임계값을 엄격히 하면 FAR은 내려가지만 FRR이 올라간다(보안 ↔ 편의성 트레이드오프).

생체 정보만의 위험

위험설명
변경 불가능성비밀번호는 유출되면 바꾸면 되지만, 지문·홍채는 평생 바꿀 수 없다. 템플릿 유출은 영구적 피해
재사용 불가한 서비스에서 유출된 생체 정보는 다른 서비스에서도 위험
위조(Spoofing)실리콘 지문, 사진·영상 얼굴 → 생체 검출(liveness detection) 로 대응
프라이버시생체 정보는 「개인정보 보호법」상 민감정보로 분류되어 별도 동의·보호조치 대상

이 때문에 최신 설계는 원본 이미지를 저장하지 않고, 복원 불가능한 특징 템플릿만 저장하거나 취소 가능 생체인식(cancelable biometrics) 기법을 적용한다.

5. 혼동하기 쉬운 인접 개념​

함정사실
"생체 인증은 등록 없이 가능하다"불가능. 등록(enrollment) → 대조(matching) 는 불가분의 한 쌍
"생체 인증은 유출돼도 안전하다"반대. 변경 불가능해서 유출 피해가 가장 크다
"생체 인증은 100% 정확하다"FAR·FRR이 존재하는 확률적 판정이다
"지문 + 얼굴이면 2FA"둘 다 존재 기반이므로 2FA 아님
"소유 기반은 복제가 불가능하다"마그네틱 카드 스키밍, SIM 스와핑 등 복제 가능

상세 풀이​

"가장 적절하지 않은 것"을 고르는 부정형 문항이다. 네 보기는 각각 지식 기반(①), 소유 기반(②), 존재 기반(③), 다중요소(④)를 다루고 있어, 인증 요소 분류표를 알고 있으면 대응이 쉽다.

  1. ① "지식 기반 인증방식은 관리 비용이 상대적으로 저렴하지만 공격자에 의한 추측 가능성의 위험이 있다." → 비밀번호·PIN은 별도 하드웨어나 센서가 필요 없어 구축·운영 비용이 가장 낮고, 동시에 추측·사전 공격·무차별 대입·피싱에 취약하다. 지식 기반의 장단점을 정확히 서술했다. → 적절.
  2. ② "소유 기반 인증 방식은 복제 가능성이 있고 분실·파손·고장 등이 발생하는 경우 인증이 불가능하다는 단점이 있다." → OTP 토큰·스마트카드·보안카드는 물리적 매체이므로 복제(스키밍, SIM 스와핑)·분실·파손·배터리 소진 등의 위험을 그대로 안는다. → 적절.
  3. ③ "생체 인증방식은 생체 템플릿이라고 불리는 자신의 생체 정보를 데이터베이스 등에 등록 없이 인증이 가능하다." → 생체 인증은 반드시 등록(enrollment) 단계를 거친다. 원본 생체 이미지에서 특징점을 추출해 생체 템플릿을 만들어 DB·스마트카드·단말 보안영역에 사전 저장해 두어야, 이후 제시된 생체 정보와 대조(matching) 가 가능하다. 저장된 템플릿이 없으면 비교 대상이 없어 인증이 성립하지 않는다. → 부적절 = 정답.
  4. ④ "지식, 소유, 존재 및 행위에 의한 인증 수단 중 2가지의 인증 수단을 결합하여 사용하는 인증 방식을 이중(Two-factor) 인증이라 한다." → 4개 요소 범주를 정확히 열거했고, 그중 2가지를 결합하는 것이 2FA라는 정의도 맞다. → 적절.

③이 틀린 지점을 다시 짚으면, 문장 안에 이미 "생체 템플릿"이라는 단어가 들어 있다. 템플릿이란 등록 과정에서 생성되어 저장되는 참조 데이터를 뜻하므로, "템플릿을 등록 없이 인증한다"는 표현은 그 자체로 자기모순이다.

보기별 판정​

보기판정근거
① 지식 기반 — 저비용, 추측 위험오답 보기(적절한 설명)What you know. 추가 장비 불필요로 비용 최저, 추측·사전·무차별 대입 공격에 취약
② 소유 기반 — 복제·분실·파손 위험오답 보기(적절한 설명)What you have. 물리 매체이므로 복제·도난·분실·고장 시 인증 불가
③ 생체 인증 — 등록 없이 인증 가능✅ 정답 보기(적절하지 않은 설명)생체 인증은 등록(enrollment)으로 템플릿을 생성·저장한 뒤 대조(matching) 하는 구조. 템플릿 없이는 비교 대상이 없어 인증 불가
④ 4개 요소 중 2가지 결합 = 이중 인증오답 보기(적절한 설명)서로 다른 범주 2가지를 결합하는 것이 2FA의 정의

오답 이유​

  • ①이 적절한 이유: 비밀번호·PIN은 사용자의 기억만 있으면 되므로 별도 토큰 발급이나 센서 도입 비용이 들지 않아 가장 저렴하다. 반대로 사람이 기억할 수 있는 수준의 비밀번호는 엔트로피가 낮아 사전 공격·크리덴셜 스터핑·어깨너머 훔쳐보기·피싱에 광범위하게 노출된다. 저비용과 낮은 안전성이 동시에 성립하는 것이 지식 기반의 특징이다.
  • ②가 적절한 이유: 소유 기반은 "물건을 가진 사람만 인증된다"는 전제 위에 서 있으므로, 그 물건이 복제되거나(마그네틱 카드 스키밍, SIM 스와핑) 없어지면 전제가 무너진다. 또 분실·파손·고장·배터리 소진 시 정당한 사용자도 인증하지 못하는 가용성 문제가 생겨 재발급 절차가 필요하다. 보기 문장은 이 두 방향의 단점을 모두 담고 있다.
  • ③이 부적절한 이유: 생체 인증의 동작 원리를 정면으로 부정한다. 반드시 등록 국면에서 원본 생체 정보로부터 특징을 추출해 생체 템플릿을 만들고 이를 저장해야 하며, 인증 국면에서는 새로 제시된 생체 정보의 특징을 저장된 템플릿과 비교해 유사도가 임계값을 넘는지 판단한다. 올바른 서술로 고치면 "생체 인증은 사전에 생체 템플릿을 등록·저장해 두고, 인증 시 제시된 생체 정보와 대조하여 본인 여부를 판정한다"가 된다. 참고로 FIDO·스마트폰 지문인식처럼 템플릿을 중앙 DB 대신 단말 보안영역에 저장하는 방식이 있어 "DB에 등록하지 않는다"고 오해하기 쉬우나, 저장 위치가 단말로 바뀔 뿐 등록 자체는 필수다. 오히려 생체 정보는 유출되면 변경할 수 없다는 점이 생체 인증의 가장 큰 고유 위험이다.
  • ④가 적절한 이유: 인증 요소를 지식(know) / 소유(have) / 존재(are) / 행위(do) 네 범주로 나누고, 그중 서로 다른 범주 2가지를 결합하는 것을 이중요소 인증(2FA)이라 한다. 비밀번호 + OTP, 스마트카드 + PIN, 비밀번호 + 지문이 대표 사례다. 다만 같은 범주를 두 번 쓰는 조합(비밀번호 + 보안 질문)은 2FA가 아니라는 점은 함께 알아 두어야 한다.

핵심 정리​

  • 인증 요소 4분류: 지식(know) / 소유(have) / 존재(are) / 행위(do). 서로 다른 범주 2가지 결합 = 2FA(같은 범주 2개는 2FA가 아님).
  • 생체 인증은 등록(enrollment) → 템플릿 저장 → 대조(matching) 의 구조. 등록 없는 인증은 원리상 불가능하다.
  • 생체 인증의 성능 지표: FAR(타인 수락률) / FRR(본인 거부율) / EER(둘이 같아지는 지점). 임계값은 보안과 편의성의 트레이드오프다.
  • 생체 정보의 최대 위험은 유출 시 변경 불가능이라는 점이며, 「개인정보 보호법」상 민감정보로 취급된다.
  • "생체 템플릿을 등록 없이 인증"이라는 문장은 그 자체로 자기모순 — 템플릿이 곧 등록 과정의 산물이라는 점이 이 문제의 결정타다.
