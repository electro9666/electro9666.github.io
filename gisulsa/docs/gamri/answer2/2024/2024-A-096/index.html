096번 · 신경망 기반 기계학습 알고리즘의 구분

제25회(2024년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. 기계학습 알고리즘의 큰 분류​

"신경망 기반인가 아닌가"는 알고리즘의 계산 구조로 판정한다. 신경망은 뉴런(노드) 계층 + 가중치 + 활성화 함수 + 경사하강/역전파 학습이라는 골격을 갖는다.

계열원리대표 알고리즘
신경망(Neural Network) 계열계층적 뉴런과 가중치, 역전파로 학습MLP, CNN, RNN/LSTM, DBN, 오토인코더/VAE, GAN, 트랜스포머
통계·기하 기반최적화·거리·확률 계산으로 직접 해를 구함SVM, 선형/로지스틱 회귀, k-NN, 나이브 베이즈, PCA
트리·앙상블 기반분기 규칙과 그 결합의사결정트리, 랜덤 포레스트, XGBoost, AdaBoost
군집화거리·밀도 기반 그룹화k-means, DBSCAN, 계층적 군집

2. SVM(Support Vector Machine) — 왜 신경망이 아닌가​

SVM은 1990년대 Vapnik의 통계적 학습 이론(VC 이론) 에 기반한 기법으로, 두 클래스를 가르는 결정 경계의 마진(margin)을 최대화하는 초평면을 찾는다.

결정 함수:  f(x) = w·x + b       →  분류: sign(f(x))
목표     :  마진 2/||w|| 를 최대화  ≡  ||w||²/2 를 최소화
제약     :  yi(w·xi + b) ≥ 1      (모든 학습 샘플에 대해)

이 문제는 볼록 이차계획법(Convex QP) 이며, 라그랑주 쌍대 문제로 변환해 풀면 전역 최적해가 유일하게 보장된다.

개념설명
서포트 벡터마진 경계 위에 놓인 소수의 데이터점. 이들만이 결정 경계를 결정한다
마진 최대화일반화 성능(구조적 위험 최소화)을 높이는 기준
소프트 마진슬랙 변수와 규제 상수 C로 일부 오분류를 허용
커널 트릭비선형 문제를 고차원으로 암묵 사상(RBF, 다항식, 시그모이드 커널)

여기에는 은닉층도, 가중치 갱신을 위한 역전파도, 활성화 함수도 없다. 따라서 SVM은 신경망이 아니다.

덧붙임: "시그모이드 커널"을 쓴 SVM이 2층 퍼셉트론과 형태상 유사하다는 논의가 있으나, 학습 방식(QP 최적화 vs 역전파)이 전혀 다르므로 SVM을 신경망 알고리즘으로 분류하지 않는다.

신경망과의 대비

항목SVM신경망
학습 방식볼록 이차계획법(QP) 최적화경사하강 + 역전파
해의 성질전역 최적해 보장지역 최적해에 수렴할 수 있음
구조초평면 + 커널계층적 뉴런 + 가중치
비선형 처리커널 트릭은닉층 + 비선형 활성화 함수
데이터 요구량소규모에서도 강함대규모 데이터에서 유리

3. 나머지 세 보기 — 모두 신경망​

① DBN(Deep Belief Network)

  • RBM(Restricted Boltzmann Machine) 을 여러 층 쌓아 만든 확률적 심층 신경망
  • 층별 탐욕적 사전학습(greedy layer-wise pretraining) 으로 각 RBM을 비지도 학습한 뒤, 전체를 역전파로 미세조정
  • 2006년 힌턴(Hinton)이 제안해 딥러닝 부흥의 계기를 만든 모델
  • RBM은 가시층–은닉층의 가중치 행렬과 확률적 뉴런으로 구성 → 명백한 신경망

③ VAE(Variational AutoEncoder)

  • 인코더 신경망: 입력 xxx 를 잠재변수 분포의 평균 μ\muμ 와 분산 σ2\sigma^2σ2 로 사상
  • 디코더 신경망: 잠재변수 zzz 로부터 입력을 복원
  • 재매개변수화 트릭(reparameterization trick): z=μ+σ⊙ϵz = \mu + \sigma \odot \epsilonz=μ+σ⊙ϵ 로 두어 샘플링 과정을 미분 가능하게 만들고 역전파로 학습
  • 손실 = 재구성 오차 + KL 발산(정규분포와의 거리) → 두 개의 신경망을 학습하는 생성 모델

④ GAN(Generative Adversarial Network)

  • 생성자 G와 판별자 D라는 두 개의 신경망이 적대적으로 경쟁
  • G는 노이즈로부터 가짜 데이터를 만들고, D는 진짜/가짜를 구별하며, 둘이 minimax 게임을 벌인다
min⁡Gmax⁡D  Ex[log⁡D(x)]+Ez[log⁡(1−D(G(z)))]\min_G \max_D \; \mathbb{E}_{x}[\log D(x)] + \mathbb{E}_{z}[\log (1 - D(G(z)))]Gmin​Dmax​Ex​[logD(x)]+Ez​[log(1−D(G(z)))]
  • 2014년 Goodfellow가 제안. 이미지 생성·초해상도·스타일 변환에 널리 쓰임

정답​

②

상세 풀이​

"신경망 기반 기계학습 알고리즘으로 가장 적절하지 않은 것"을 고르는 부정형 문항이다. 즉 네 보기 중 유일하게 신경망이 아닌 것을 찾으면 된다.

  1. ① DBN(Deep Belief Network) — 신경망이다. RBM을 여러 층 쌓은 확률적 심층 신경망으로, 층별 사전학습 후 역전파로 미세조정한다.
  2. ② SVM(Support Vector Machine) — 신경망이 아니다. 마진을 최대화하는 초평면을 찾는 볼록 이차계획법(QP) 기반 통계적 학습 기법이며, 은닉층·가중치 역전파·활성화 함수가 존재하지 않는다. → 정답
  3. ③ VAE(Variational AutoEncoder) — 신경망이다. 인코더·디코더가 모두 신경망이며 재매개변수화 트릭으로 역전파 학습이 가능하다.
  4. ④ GAN(Generative Adversarial Network) — 신경망이다. 생성자와 판별자, 두 신경망의 적대적 학습 구조다.

①·③·④가 모두 딥러닝 생성/표현학습 모델이라는 공통점을 갖는 반면, ②만 계열이 다르다는 점에서 출제 의도가 뚜렷하다.

보기판정근거
① DBN오답 보기(신경망이 맞음)RBM 스택 구조의 확률적 심층 신경망. 층별 탐욕적 사전학습 + 역전파 미세조정
② SVM✅ 정답 보기(신경망이 아님)마진 최대화 초평면을 이차계획법으로 구하는 통계적 학습 기법. 뉴런·역전파 없음
③ VAE오답 보기(신경망이 맞음)인코더·디코더가 모두 신경망. 재매개변수화 트릭으로 역전파 가능
④ GAN오답 보기(신경망이 맞음)생성자·판별자 두 신경망의 minimax 적대 학습

오답 이유​

  • ②가 정답인(신경망이 아닌) 이유: SVM의 학습은 "가중치를 조금씩 갱신하는 반복 과정"이 아니라 제약이 있는 볼록 최적화 문제를 푸는 것이다. 해가 유일한 전역 최적해로 보장되며(신경망은 지역 최적에 빠질 수 있다), 최종 결정 함수는 소수의 서포트 벡터와 커널 함수로만 표현된다. 비선형 분리는 은닉층이 아니라 커널 트릭으로 해결한다. 구조·학습 방식·이론적 배경 어느 쪽으로도 신경망과 겹치지 않는다.
  • ①이 신경망인 이유: DBN은 가시층과 은닉층 사이에 가중치 행렬을 갖는 RBM을 여러 겹 쌓은 구조다. 각 RBM을 아래층부터 차례로 비지도 학습(contrastive divergence)해 좋은 초기 가중치를 얻은 뒤, 지도 학습 단계에서 전체를 역전파로 미세조정한다. 2006년 이 층별 사전학습 기법이 깊은 신경망의 학습 난제를 돌파하면서 딥러닝 시대가 열렸다.
  • ③이 신경망인 이유: VAE는 오토인코더(인코더 신경망 + 디코더 신경망) 구조에 확률적 잠재변수를 도입한 모델이다. 인코더가 μ,σ\mu, \sigmaμ,σ 를 출력하고 디코더가 복원을 담당하며, 손실함수(재구성 오차 + KL 발산)에 대해 경사하강·역전파로 두 신경망의 가중치를 함께 학습한다.
  • ④가 신경망인 이유: GAN은 아예 신경망이 두 개인 구조다. 생성자는 잠재 노이즈를 데이터 공간으로 사상하는 신경망, 판별자는 진짜/가짜를 분류하는 신경망이며, 서로의 손실을 반대 방향으로 밀어 주며 번갈아 역전파 학습한다.

핵심 정리​

  • 신경망 판별 기준은 계층적 뉴런 + 가중치 + 활성화 함수 + 역전파 학습의 존재 여부다.
  • SVM은 비신경망 대표 주자 — 마진 최대화 초평면을 볼록 이차계획법으로 구하며, 비선형은 커널 트릭으로 처리한다. 해가 전역 최적임이 보장되는 것도 신경망과의 큰 차이다.
  • DBN(RBM 스택), VAE(인코더+디코더), GAN(생성자+판별자) 는 모두 신경망 기반 생성/표현학습 모델이다.
  • 비신경망 계열 묶음: SVM, 의사결정트리·랜덤 포레스트·XGBoost, k-NN, 나이브 베이즈, k-means, PCA. 반대로 이름에 신경망이 드러나지 않지만 신경망인 것: SOM(코호넨), RBM, 오토인코더.
  • 결정타: 보기 중 유일하게 "역전파로 학습하지 않는" 것을 찾으면 된다. 이 문항에서는 SVM이다.
