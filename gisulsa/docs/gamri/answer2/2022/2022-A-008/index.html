008번 · 내부수익률(IRR) 계산

제23회(2022년) 정보시스템감리사 A형 — 감리 및 사업관리

사전 지식​

1. 현재가치와 순현재가치(NPV)​

미래의 돈은 이자율(할인율) rrr 만큼 할인해야 현재 가치와 비교할 수 있다.

PV=FV(1+r)nPV = \frac{FV}{(1 + r)^n}PV=(1+r)nFV​

투자의 순현재가치(NPV) 는 미래 현금흐름의 현재가치 합에서 초기 투자액을 뺀 값이다.

NPV=∑t=1nCFt(1+r)t−C0NPV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} - C_0NPV=∑t=1n​(1+r)tCFt​​−C0​

2. 내부수익률(IRR)의 정의​

IRR은 NPV를 0으로 만드는 할인율이다.

∑t=1nCFt(1+IRR)t−C0=0\sum_{t=1}^{n} \frac{CF_t}{(1 + IRR)^t} - C_0 = 0∑t=1n​(1+IRR)tCFt​​−C0​=0

즉 "이 투자가 스스로 벌어들이는 연평균 복리 수익률"이다. IRR이 자본비용(요구수익률)보다 크면 투자할 가치가 있다.

3. 중간 현금흐름이 없는 경우의 단순화​

투자 후 nnn년 뒤에 한 번만 회수한다면 식은 복리 공식 그대로가 된다.

C0(1+IRR)n=CFn⇒IRR=(CFnC0)1/n−1C_0 (1 + IRR)^n = CF_n \quad\Rightarrow\quad IRR = \left(\frac{CF_n}{C_0}\right)^{1/n} - 1C0​(1+IRR)n=CFn​⇒IRR=(C0​CFn​​)1/n−1

4. 혼동 주의: 단순 수익률과의 차이​

지표계산이 문제에 적용
총 수익률(회수액 − 투자액) ÷ 투자액21% (2년 합계)
단순 연평균총 수익률 ÷ 기간10.5%
IRR(복리)NPV = 0 이 되는 할인율10%

문제​

정답​

①

상세 풀이​

초기 투자 C0=100C_0 = 100C0​=100 만원, 2년 후 회수 CF2=121CF_2 = 121CF2​=121 만원, 중간 현금흐름 없음.

1. NPV = 0 식 세우기

121(1+IRR)2−100=0\frac{121}{(1 + IRR)^2} - 100 = 0(1+IRR)2121​−100=0

2. 정리

(1+IRR)2=121100=1.21(1 + IRR)^2 = \frac{121}{100} = 1.21(1+IRR)2=100121​=1.21

3. 제곱근

1+IRR=1.21=1.1⇒IRR=0.11 + IRR = \sqrt{1.21} = 1.1 \quad\Rightarrow\quad IRR = 0.11+IRR=1.21​=1.1⇒IRR=0.1

4. 검산 — 100×1.1=110100 \times 1.1 = 110100×1.1=110 (1년 후), 110×1.1=121110 \times 1.1 = 121110×1.1=121 (2년 후). 조건과 일치한다.

따라서 내부수익률은 0.1(10%), 정답은 ①이다.

보기별 판정​

보기판정근거
① 0.1✅ 정답 보기100×1.12=121100 \times 1.1^2 = 121100×1.12=121
② 0.2오답 보기100×1.22=144≠121100 \times 1.2^2 = 144 \ne 121100×1.22=144=121
③ 0.3오답 보기100×1.32=169≠121100 \times 1.3^2 = 169 \ne 121100×1.32=169=121
④ 0.4오답 보기100×1.42=196≠121100 \times 1.4^2 = 196 \ne 121100×1.42=196=121

오답 이유​

  • ②가 틀린 이유: 총 수익 21만원을 반올림해 "약 20%"로 본 경우다. 이는 2년 누적 수익률이지 연 수익률이 아니다. 연 20%라면 2년 후 144만원이 되어야 한다.
  • ③·④가 틀린 이유: 할인율이 높아질수록 121만원의 현재가치는 100만원보다 훨씬 작아져 NPV가 음수가 된다. 예컨대 r=0.3r = 0.3r=0.3 이면 121/1.69≈71.6121 / 1.69 \approx 71.6121/1.69≈71.6 으로 NPV ≈ −28.4만원이다.
  • ①이 맞는 이유: 복리로 1년에 10%씩 두 번 불어나야 1.21배가 된다. IRR은 복리 기준이므로 누적 21%를 기간 수로 나누는 것이 아니라 기간 수만큼 제곱근을 취해야 한다.

핵심 정리​

  • IRR = NPV를 0으로 만드는 할인율 = 투자안이 스스로 내는 연 복리 수익률.
  • 중간 현금흐름이 없으면 IRR=(CFn/C0)1/n−1IRR = (CF_n / C_0)^{1/n} - 1IRR=(CFn​/C0​)1/n−1.
  • 이 문제: (121/100)1/2−1=1.1−1=0.1(121/100)^{1/2} - 1 = 1.1 - 1 = 0.1(121/100)1/2−1=1.1−1=0.1.
  • 누적 수익률 21%를 연 수익률로 착각하지 말 것 — 1.21의 제곱근이 1.1이라는 한 줄이 ①을 가려내는 결정타다.
