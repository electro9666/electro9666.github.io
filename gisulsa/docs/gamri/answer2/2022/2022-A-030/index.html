030번 · 이진 탐색(첫 번째 위치 찾기) Java 코드 추적

제23회(2022년) 정보시스템감리사 A형 — 소프트웨어 공학

사전 지식​

1. 이진 탐색의 기본​

정렬된 리스트에서 가운데 원소와 찾는 값 k 를 비교해 탐색 범위를 절반씩 줄인다. 시간 복잡도는 O(log⁡n)O(\log n)O(logn) 이다.

비교 결과일반 이진 탐색이 문제의 코드
list[mid] > k왼쪽 절반 탐색 (right = mid - 1)동일
list[mid] == k즉시 mid 반환result = mid 저장 후 왼쪽 계속 탐색 (right = mid - 1)
list[mid] < k오른쪽 절반 탐색 (left = mid + 1)동일

2. Lower bound(첫 번째 위치) 탐색​

값을 찾은 뒤에도 right = mid - 1 로 왼쪽을 더 탐색하면, 중복 원소가 있을 때 가장 왼쪽(첫 번째) 인덱스를 찾는다. 찾지 못하면 초기값 -1 을 반환한다.

3. 반환값은 인덱스​

search() 는 값이 아니라 인덱스(0부터 시작)를 반환한다. Arrays.asList({1, 2, 3, 4}) 에서 값 3의 인덱스는 2다.

4. mid = left + (right - left) / 2​

(left + right) / 2 와 같은 값이지만 left + right 가 int 범위를 넘는 오버플로를 막는 관용 표현이다. 정수 나눗셈이므로 소수점은 버린다.

상세 풀이​

입력: list = [1, 2, 3, 4] (인덱스 0~3), k = 3. 초기값 left = 0, right = 3, result = -1.

회차leftrightmid 계산list[mid]비교처리
1030 + (3 − 0) / 2 = 122 < 3left = 2
2232 + (3 − 2) / 2 = 233 == 3result = 2, right = 1
321——left <= right 거짓반복 종료

반환값 result = 2 → System.out.println 출력 2 → ②.

Python으로 같은 로직을 실행해 확인한 결과도 같다.

def search(lst, k):
    left, right, result = 0, len(lst) - 1, -1
    while left <= right:
        mid = left + (right - left) // 2
        if lst[mid] > k:
            right = mid - 1
        elif lst[mid] == k:
            result = mid
            right = mid - 1
        else:
            left = mid + 1
    return result

print(search([1, 2, 3, 4], 3))  # 2

보기별 판정​

보기판정근거
① 1오답첫 회차 mid(=1)를 결과로 착각한 경우
② 2✅ 정답값 3은 인덱스 2에 있고, 그보다 왼쪽에 3이 없으므로 result = 2
③ 3오답인덱스가 아니라 값(3)을 출력한다고 착각한 경우
④ 4오답1부터 세는 위치(3번째)나 리스트 크기로 착각한 경우

오답 이유​

  • ①: 1회차에서 mid = 1 이지만 list[1] = 2 는 3보다 작아 left 만 옮긴다. result 는 값이 같을 때만 갱신된다.
  • ③: 메서드는 result = mid 로 인덱스를 저장한다. 찾은 값 3을 반환하지 않는다.
  • ④: Java 리스트 인덱스는 0부터 시작한다. 3은 '세 번째 원소'이지만 인덱스는 2다.

핵심 정리​

  • 같은 값을 찾아도 right = mid - 1 로 계속 왼쪽을 보는 코드는 첫 번째 위치(lower bound) 를 찾는 이진 탐색이다.
  • 반환값은 0부터 시작하는 인덱스, 없으면 -1.
  • 추적표: mid 1(값 2, 오른쪽으로) → mid 2(값 3, result=2, 왼쪽으로) → 종료 → 출력 2.
