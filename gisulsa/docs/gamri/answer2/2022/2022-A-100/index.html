100번 · RAID 10의 읽기·쓰기 IOPS 계산

제23회(2022년) 정보시스템감리사 A형 — 시스템 구조

사전 지식​

1. RAID 10(1+0) 구조​

디스크를 2개씩 미러링(RAID 1) 한 쌍을 만들고, 그 쌍들을 스트라이핑(RAID 0) 한다.

          RAID 0 (스트라이핑)
   ┌─────────┬─────────┬─────────┬─────────┐
 Mirror1   Mirror2   Mirror3   Mirror4
 D1  D2    D3  D4    D5  D6    D7  D8

8개 디스크 → 미러 쌍 4개. 가용 용량은 디스크 4개분(50%).

2. RAID 레벨별 IOPS와 쓰기 페널티​

N개 디스크, 디스크당 IOPS를 XXX 라 하면 이론적 성능은 다음과 같다.

RAID쓰기 페널티읽기 IOPS쓰기 IOPS
RAID 01NXN XNXNXN XNX
RAID 1 / 102NXN XNXNX2\dfrac{N X}{2}2NX​
RAID 54NXN XNXNX4\dfrac{N X}{4}4NX​
RAID 66NXN XNXNX6\dfrac{N X}{6}6NX​
  • 읽기: 미러의 양쪽 디스크 어느 쪽에서도 읽을 수 있으므로 모든 디스크가 읽기에 참여한다.
  • 쓰기: 하나의 논리 쓰기가 미러 쌍의 두 디스크 모두에 기록되어야 하므로 물리 I/O가 2배 → 쓰기 페널티 2.

문제​

정답​

③

상세 풀이​

주어진 값: 디스크 N=8N = 8N=8, 디스크당 읽기·쓰기 X=100,000X = 100{,}000X=100,000 IOPS.

읽기 성능

Read IOPS=N×X=8×100,000=800,000\text{Read IOPS} = N \times X = 8 \times 100{,}000 = 800{,}000Read IOPS=N×X=8×100,000=800,000

미러 쌍의 두 디스크가 각각 독립적으로 읽기 요청을 처리할 수 있으므로 8개 전체가 병렬로 읽는다.

쓰기 성능

Write IOPS=N×X쓰기 페널티=8×100,0002=400,000\text{Write IOPS} = \frac{N \times X}{\text{쓰기 페널티}} = \frac{8 \times 100{,}000}{2} = 400{,}000Write IOPS=쓰기 페널티N×X​=28×100,000​=400,000

쓰기는 미러 쌍의 두 디스크에 동시에 기록되므로 실질적으로 쌍(4개) 단위로만 병렬화된다: 4×100,000=400,0004 \times 100{,}000 = 400{,}0004×100,000=400,000.

따라서 읽기 800,000 IOPS, 쓰기 400,000 IOPS → ③

보기별 판정​

보기판정근거
① 읽기 400,000 / 쓰기 400,000오답읽기를 미러 쌍 단위(4개)로만 계산한 오류
② 읽기 400,000 / 쓰기 800,000오답읽기·쓰기를 뒤바꿈
③ 읽기 800,000 / 쓰기 400,000✅ 정답읽기 = 8 × X, 쓰기 = 8 × X / 2
④ 읽기 800,000 / 쓰기 800,000오답RAID 0처럼 쓰기 페널티를 무시

오답 이유​

  • ①: 미러링된 두 디스크가 같은 데이터를 갖고 있어 읽기는 어느 쪽에서든 가능하다는 점을 놓쳤다.
  • ②: 쓰기가 읽기보다 빠를 수 없다. 미러링은 쓰기를 2배로 만든다.
  • ④: 미러링의 이중 기록(쓰기 페널티 2)을 반영하지 않았다. 이 값은 RAID 0(스트라이핑만)일 때의 성능이다.

핵심 정리​

  • RAID 10: 읽기 = NXN XNX, 쓰기 = NX/2N X / 2NX/2 (쓰기 페널티 2), 가용 용량 50%, 최소 4개 디스크.
  • 쓰기 페널티: RAID 0 = 1, RAID 1·10 = 2, RAID 5 = 4, RAID 6 = 6.
