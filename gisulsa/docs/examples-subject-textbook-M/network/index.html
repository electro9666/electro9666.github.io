네트워크/통신

정보관리기술사 시험에서 네트워크/통신 영역은 OSI 계층 구조와 프로토콜, 라우팅 알고리즘, 전송 제어, 무선통신, 네트워크 가상화 등 광범위한 주제를 다룹니다. 본 교재는 기출문제 분석을 바탕으로 핵심 개념을 체계적으로 정리하였습니다.

목차​

  • OSI 7계층 및 TCP/IP 모델
  • 라우팅 프로토콜 (IGP/EGP/OSPF/BGP)
  • 전송 제어 (슬라이딩 윈도우/혼잡 제어/오류 제어)
  • 무선통신 (5G/6G/LPWA)
  • IoT 프로토콜 (HTTP/MQTT/CoAP/MODBUS)
  • SDN/NFV
  • 소켓 통신 (TCP/WebSocket)
  • 네트워크 가상화 (VLAN/VPN)
  • QoS (Quality of Service)

OSI 7계층 및 TCP/IP 모델​

OSI(Open Systems Interconnection) 7계층 모델은 ISO가 제정한 네트워크 통신 표준 참조 모델로, 서로 다른 시스템 간의 통신을 계층별로 분리하여 표준화한 구조입니다. 물리 계층(1계층)부터 응용 계층(7계층)까지 각 계층은 독립적인 역할을 수행하며, 하위 계층의 서비스를 이용해 상위 계층에 서비스를 제공합니다. 각 계층의 대표 프로토콜과 역할을 명확히 이해하는 것이 시험의 핵심입니다.

각 계층은 1계층(물리): 비트 전송, 케이블/허브, 2계층(데이터링크): 프레임 전송, MAC 주소, 스위치, 3계층(네트워크): 패킷 라우팅, IP 주소, 라우터, 4계층(전송): 종단 간 신뢰성, TCP/UDP, 5계층(세션): 연결 설정/유지/종료, 6계층(표현): 데이터 형식 변환, 암호화, 7계층(응용): 사용자 서비스, HTTP/FTP/SMTP로 구성됩니다. 각 계층은 PDU(Protocol Data Unit)로 구분되어 물리는 비트, 데이터링크는 프레임, 네트워크는 패킷, 전송은 세그먼트라고 부릅니다.

TCP/IP 모델은 OSI 7계층을 실용적으로 압축한 4계층 구조로, 인터넷의 실질적인 표준입니다. 네트워크 접근 계층(OSI 12), 인터넷 계층(OSI 3), 전송 계층(OSI 4), 응용 계층(OSI 57)으로 구성됩니다. 회선교환 방식은 통신 전 전용 경로를 설정하여 안정적이지만 자원 낭비가 발생하며, 패킷교환 방식은 데이터를 패킷으로 분할하여 효율적으로 전송하되 지연이 발생할 수 있어 인터넷의 기반 방식으로 사용됩니다.

관련 기출문제​

  • 122회 3교시 - OSI 7 Layer의 각 계층과 특징
  • 116회 4교시 - 회선교환/패킷교환 방식

라우팅 프로토콜 (IGP/EGP/OSPF/BGP)​

라우팅 프로토콜은 네트워크에서 패킷의 최적 경로를 결정하는 알고리즘으로, 적용 범위에 따라 IGP(Interior Gateway Protocol)와 EGP(Exterior Gateway Protocol)로 구분됩니다. IGP는 하나의 자율 시스템(AS, Autonomous System) 내부에서 사용하며 RIP, OSPF, EIGRP 등이 있습니다. EGP는 서로 다른 AS 간의 라우팅에 사용하며, 현재 인터넷의 표준인 BGP(Border Gateway Protocol)가 대표적입니다.

거리벡터 라우팅(Distance Vector Routing)은 RIP(Routing Information Protocol)가 대표적으로, 각 라우터가 인접 라우터로부터 받은 거리 정보를 바탕으로 라우팅 테이블을 갱신합니다. 홉(hop) 수를 기준으로 최단 경로를 계산하며 구현이 간단하지만, 수렴 속도가 느리고 최대 15홉 제한이 있습니다. 링크 상태 라우팅(Link State Routing)의 대표인 OSPF(Open Shortest Path First)는 네트워크 전체 토폴로지를 파악한 후 다익스트라 알고리즘으로 최단 경로를 계산하여 수렴이 빠르고 대규모 네트워크에 적합합니다.

BGP는 인터넷 백본을 구성하는 AS 간 경로 정보를 교환하는 경로 벡터 프로토콜로, 정책 기반 라우팅을 지원합니다. TCP 179번 포트를 사용하여 신뢰성 있는 경로 정보 교환이 가능하며, ISP(인터넷 서비스 제공자) 간의 라우팅을 담당합니다. 서브네팅(Subnetting)은 하나의 IP 네트워크를 더 작은 논리적 단위로 분할하는 기술로, 슈퍼네팅(Supernetting)은 여러 소규모 네트워크를 하나의 큰 네트워크로 통합하여 라우팅 테이블을 축소합니다.

  • 122회 1교시 - 거리벡터 라우팅
  • 134회 1교시 - RIP와 OSPF 비교
  • 129회 2교시 - 서브네팅과 슈퍼네팅

전송 제어 (슬라이딩 윈도우/혼잡 제어/오류 제어)​

슬라이딩 윈도우(Sliding Window) 기법은 송신측이 수신측의 확인(ACK)을 기다리지 않고 윈도우 크기만큼의 연속된 프레임을 전송하여 네트워크 효율을 높이는 흐름 제어 방법입니다. 윈도우 크기는 송수신 버퍼 크기와 네트워크 상태에 따라 동적으로 조절되며, Go-Back-N ARQ와 Selective Repeat ARQ 방식이 대표적입니다. Go-Back-N은 오류 발생 시 해당 프레임부터 이후 모든 프레임을 재전송하고, Selective Repeat은 오류 프레임만 선택적으로 재전송하여 효율이 더 높습니다.

TCP 혼잡 제어(Congestion Control)는 네트워크 과부하를 방지하기 위한 메커니즘으로, 혼잡 윈도우(cwnd) 크기를 조절하여 전송 속도를 제어합니다. 느린 시작(Slow Start)은 초기에 cwnd를 1 MSS로 시작하여 ACK 수신마다 지수적으로 증가시킵니다. 혼잡 회피(Congestion Avoidance)는 ssthresh(슬로우 스타트 임계값) 도달 후 선형 증가로 전환하며, 혼잡 감지 시 타임아웃이면 ssthresh를 현재 cwnd의 절반으로 줄이고 cwnd를 1로 초기화하고, 3개의 중복 ACK이면 빠른 재전송/빠른 회복(Fast Retransmit/Fast Recovery)을 수행합니다.

오류 제어(Error Control)는 데이터 전송 과정에서 발생하는 오류를 검출하고 정정하는 기술입니다. 오류 검출 기법에는 패리티 비트, 체크섬, CRC(Cyclic Redundancy Check)가 있으며, CRC는 다항식을 이용한 나눗셈 연산으로 높은 검출 능력을 제공합니다. 오류 정정 기법에는 FEC(Forward Error Correction)과 ARQ(Automatic Repeat Request)가 있으며, ARQ는 정지-대기(Stop-and-Wait), Go-Back-N, Selective Repeat 방식으로 구분됩니다. 정지-대기 ARQ는 단순하지만 하나의 프레임 전송 후 ACK을 기다려야 하므로 효율이 낮습니다.

  • 138회 4교시 - 오류 제어 기술 및 ARQ

무선통신 (5G/6G/LPWA)​

5G 이동통신은 초고속(eMBB), 초저지연(uRLLC), 초연결(mMTC)을 세 가지 핵심 서비스 특성으로 하며, 이론상 최대 20Gbps의 전송 속도와 1ms 이하의 지연 시간을 목표로 합니다. 네트워크 슬라이싱(Network Slicing)은 하나의 물리적 네트워크 인프라를 소프트웨어적으로 분리하여 서비스 유형별로 독립적인 가상 네트워크를 구성하는 기술로, 다양한 서비스 요구사항을 동시에 충족할 수 있습니다. 5G 특화망(Private 5G)은 기업이나 특정 지역에서 전용으로 구축하는 5G 네트워크로, 보안성과 안정성이 높아 스마트 팩토리, 국방, 의료 분야에 활용됩니다.

6G 이동통신은 2030년대 상용화를 목표로 개발 중인 차세대 이동통신으로, 5G 대비 50배 이상의 전송 속도(테라bps급)와 0.1ms 수준의 초저지연을 목표로 합니다. AI-Native Network는 6G의 핵심 개념으로, 네트워크 설계 단계부터 AI를 내재화하여 자율 최적화, AI-RAN(AI 기반 무선접속망), 디지털 트윈 기반 네트워크 관리를 구현합니다. SATIN(Satellite-Aerial-Terrestrial Integrated Network)은 위성-상공(UAV)-지상을 통합한 3차원 네트워크로, 재난 대비, 오지 서비스, UAV 활용 등 5G의 음영 지역 없는 커버리지를 제공합니다.

LPWA(Low Power Wide Area)는 저전력으로 넓은 지역을 커버하는 IoT 전용 무선 통신 기술로, LoRa, NB-IoT, Sigfox 등이 대표적입니다. 전송 속도는 낮지만 배터리 수명이 수 년에 달하며 수 킬로미터 이상의 통신 거리를 지원하여 스마트 미터링, 자산 추적, 환경 모니터링 등에 활용됩니다. IEEE 802.11bn(Wi-Fi 8)은 차세대 무선 LAN 표준으로 다중 AP 협력 전송, 극저지연, AI 기반 채널 관리를 특징으로 하며, FSO(Free Space Optics)는 레이저/적외선으로 자유 공간을 통해 데이터를 전송하는 무선 광통신 기술입니다.

IoT 프로토콜 (HTTP/MQTT/CoAP/MODBUS)​

HTTP(HyperText Transfer Protocol)는 웹의 기반 프로토콜로 요청-응답 방식의 비연결성 프로토콜입니다. HTTPS는 HTTP에 TLS(Transport Layer Security)를 결합하여 기밀성, 무결성, 인증을 제공합니다. TLS 1.2는 여러 보안 취약점이 발견되어 TLS 1.3으로 전환이 권고되고 있으며, TLS 1.3은 핸드셰이크 과정을 간소화하고 구식 암호 알고리즘을 제거하여 보안성과 성능을 동시에 개선하였습니다.

MQTT(Message Queuing Telemetry Transport)는 발행-구독(Publish-Subscribe) 모델 기반의 경량 메시지 프로토콜로, TCP/IP 위에서 동작하며 IoT 환경의 저대역폭, 고지연, 불안정한 네트워크에 적합합니다. CoAP(Constrained Application Protocol)는 자원 제약이 심한 IoT 디바이스를 위한 RESTful 프로토콜로, UDP 기반으로 동작하여 오버헤드가 매우 낮습니다. XMPP(Extensible Messaging and Presence Protocol)는 XML 기반의 실시간 메시지 프로토콜로 존재 정보 관리가 특징이나, IoT에서는 MQTT와 CoAP가 더 널리 사용됩니다.

MODBUS는 1979년 Modicon에서 개발한 산업용 직렬 통신 프로토콜로, 마스터-슬레이브 구조로 동작하며 PLC, SCADA 등 산업 자동화 분야에서 사실상의 표준으로 사용됩니다. Modbus RTU(직렬), Modbus ASCII, Modbus TCP/IP 세 가지 변형이 있으며, 단순하고 강건한 구조로 수십 년간 산업 현장에서 광범위하게 사용되고 있습니다. LwM2M(Lightweight M2M)은 OMA에서 정의한 IoT 디바이스 관리 프로토콜로, CoAP 기반으로 부트스트랩, 등록, 보안 등 디바이스 관리 기능을 표준화합니다.

관련 기출문제​

  • 136회 2교시 - TLS 1.2 취약점과 TLS 1.3 개선사항
  • 110회 1교시 - XMPP, CoAP, MQTT 비교
  • 111회 2교시 - IoT 보안 및 CoAP/MQTT/LwM2M
  • 137회 1교시 - MODBUS 프로토콜

SDN/NFV​

SDN(Software Defined Networking)은 네트워크의 제어 평면(Control Plane)과 데이터 평면(Data Plane)을 분리하여 소프트웨어로 네트워크를 중앙에서 프로그래밍 가능하게 하는 기술입니다. 기존 네트워크는 각 장비가 제어와 전달 기능을 모두 가지지만, SDN에서는 SDN 컨트롤러가 네트워크 전체를 중앙에서 제어하고 스위치는 데이터 전달만 담당합니다. OpenFlow는 SDN 컨트롤러와 네트워크 장비 간의 표준 남향(Southbound) 인터페이스 프로토콜로, 플로우 테이블을 통해 패킷 처리 규칙을 동적으로 설정합니다.

IBN(Intent-Based Networking)은 SDN을 더욱 발전시킨 개념으로, 네트워크 관리자가 "무엇을 원하는가(Intent)"를 선언하면 AI/ML이 자동으로 최적의 네트워크 정책을 생성하고 적용합니다. 이는 SDN의 프로그래밍 가능성에 AI 자율화를 결합한 형태로, 복잡한 네트워크 운영을 자동화하고 인적 오류를 최소화합니다. 또한 네트워크 상태를 지속적으로 모니터링하고 의도와 불일치 시 자동으로 수정하는 폐루프(Closed-Loop) 자동화를 구현합니다.

NFV(Network Function Virtualization)는 방화벽, 로드밸런서, IDS 등 전용 하드웨어로 구현되던 네트워크 기능을 소프트웨어로 가상화하여 범용 서버에서 실행하는 기술입니다. NFV는 SDN과 상호보완적 관계로, SDN이 네트워크 경로를 소프트웨어로 제어한다면 NFV는 네트워크 기능 자체를 소프트웨어화합니다. ETSI의 NFV 아키텍처는 VNF(가상 네트워크 기능), NFVI(인프라), MANO(관리 및 오케스트레이션) 세 요소로 구성되며, CAPEX/OPEX 절감과 신속한 서비스 배포를 가능하게 합니다.

  • 135회 1교시 - IBN(Intent-Based Networking)

소켓 통신 (TCP/WebSocket)​

소켓(Socket) 통신은 네트워크에서 두 프로세스가 데이터를 주고받기 위한 종단점(Endpoint)으로, IP 주소와 포트 번호의 조합으로 식별됩니다. TCP 소켓은 연결 지향적으로 3-way handshake(SYN → SYN-ACK → ACK)로 연결을 수립하고 4-way handshake(FIN → ACK → FIN → ACK)로 연결을 종료합니다. 서버는 bind() → listen() → accept() 순서로 연결을 기다리고, 클라이언트는 connect()로 연결을 요청하며, 연결 후 양방향 send()/recv()로 데이터를 교환합니다.

WebSocket은 HTTP 업그레이드 요청으로 시작하여 TCP 기반의 전이중(Full-Duplex) 양방향 통신 채널을 수립하는 프로토콜입니다. 기존 HTTP 폴링 방식과 달리 한 번 연결되면 서버가 클라이언트에게 데이터를 능동적으로 푸시(Push)할 수 있어 실시간 채팅, 주식 시세, 게임 등의 서비스에 적합합니다. TCP 소켓은 범용 네트워크 프로그래밍에 사용되며 애플리케이션 프로토콜을 별도로 정의해야 하지만, WebSocket은 HTTP와의 호환성을 유지하면서 실시간 웹 통신을 위한 표준 프로토콜을 제공합니다.

소켓 통신과 HTTP 통신을 비교하면, HTTP는 요청-응답 기반의 비연결성 프로토콜로 각 요청마다 연결을 수립하고 종료하지만, 소켓 통신은 한 번 연결 후 지속적으로 데이터를 교환할 수 있습니다. Non-blocking I/O는 I/O 작업이 완료될 때까지 블록하지 않고 다른 작업을 처리할 수 있는 방식으로, Node.js와 같은 이벤트 기반 서버에서 고성능 네트워크 서비스를 구현하는 핵심 기술입니다. 이는 동시 연결 수가 많은 실시간 서비스에서 스레드 기반 동기 I/O 대비 메모리 효율과 처리 성능을 크게 개선합니다.

네트워크 가상화 (VLAN/VPN)​

VLAN(Virtual LAN)은 물리적 위치와 관계없이 논리적으로 LAN을 분할하는 기술로, 하나의 스위치에서 여러 독립 네트워크를 구성할 수 있습니다. 802.1Q 태깅을 사용하여 프레임에 VLAN ID를 추가하며, 브로드캐스트 도메인을 분리하여 보안성과 네트워크 효율을 높입니다. VXLAN(Virtual eXtensible LAN)은 VLAN의 4096개 ID 제한을 극복하기 위해 UDP 캡슐화로 VLAN을 확장한 기술로, 약 1600만 개의 논리 네트워크를 지원하여 대규모 클라우드 데이터센터에 적합합니다.

VPN(Virtual Private Network)은 공중 네트워크를 통해 사설 네트워크와 같은 보안 통신을 제공하는 기술로, 터널링, 암호화, 인증을 핵심 기술 요소로 합니다. IPSec VPN은 네트워크 계층(3계층)에서 동작하여 IP 패킷 전체를 암호화하며 AH(인증)와 ESP(암호화) 헤더를 사용합니다. SSL VPN은 전송 계층에서 TLS 기반으로 동작하여 별도 클라이언트 소프트웨어 없이 웹 브라우저만으로 접속 가능하여 원격 사용자 접속에 유리합니다.

DCI(Data Center Interconnect)는 지리적으로 분산된 데이터센터 간을 고속으로 연결하는 기술로, 재해 복구, 부하 분산, 데이터 이전을 위한 핵심 인프라입니다. P2P(Peer-to-Peer) 네트워크는 중앙 서버 없이 참여자들이 직접 자원을 공유하는 분산 통신 방식으로, 퓨어 P2P(완전 분산)와 하이브리드 P2P(부분 중앙화) 방식이 있으며 블록체인의 기반 기술로 활용됩니다. NAC(Network Access Control)는 단말기의 보안 상태를 검증하여 네트워크 접근을 제어하는 기술입니다.

QoS (Quality of Service)​

QoS(Quality of Service)는 네트워크에서 특정 트래픽에 대해 대역폭, 지연, 지터, 패킷 손실 등의 성능 수준을 보장하는 기술입니다. IntServ(Integrated Services)는 RSVP 프로토콜을 사용하여 데이터 흐름별로 자원을 예약하고 서비스 품질을 엄격히 보장하지만, 모든 라우터가 상태 정보를 유지해야 하므로 확장성이 낮습니다. DiffServ(Differentiated Services)는 트래픽을 분류하여 IP 헤더의 DSCP 필드에 표시하고 라우터에서 클래스별로 차별화된 처리를 적용하며, 상태 정보 없이 동작하여 대규모 네트워크에 적합합니다.

WFQ(Weighted Fair Queuing)는 여러 트래픽 플로우에 가중치를 부여하여 가중치에 비례한 대역폭을 공정하게 할당하는 큐잉 알고리즘입니다. 우선순위 큐잉(PQ)이 높은 우선순위 트래픽이 낮은 우선순위 트래픽을 굶주리게 할 수 있는 문제를 해결하며, 음성, 동영상, 데이터 트래픽이 혼재하는 환경에서 각 서비스 수준을 균형 있게 보장합니다. 샤논-하틀리(Shannon-Hartley) 정리는 채널 용량(C = B × log₂(1 + S/N))으로 대역폭과 SNR이 네트워크 최대 전송 속도를 결정함을 수학적으로 표현합니다.

망 중립성(Network Neutrality)은 ISP가 인터넷 트래픽을 내용, 출처, 서비스에 관계없이 동등하게 처리해야 한다는 원칙입니다. 제로 레이팅(Zero Rating)은 특정 서비스 이용 시 데이터 요금을 면제하는 방식으로, 소비자 편의와 망 중립성 위반 사이의 논쟁이 지속됩니다. 최근 Netflix 등 대형 CP(콘텐츠 제공자)의 망 사용료 이슈가 부각되면서 망 중립성 정책은 4차 산업혁명 시대의 중요한 제도적 쟁점으로 다루어지고 있습니다.
