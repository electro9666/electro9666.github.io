확률과 분포 (정규/이항/포아송)​

확률 분포(Probability Distribution)는 확률 변수가 취하는 값과 그 확률 간의 관계를 나타냅니다. 정규 분포(Normal Distribution)는 평균(μ)과 표준편차(σ)로 정의되는 좌우 대칭의 종 모양 연속 분포로, 평균±1σ에 약 68%, ±2σ에 약 95%, ±3σ에 약 99.7%의 데이터가 포함됩니다. 중심극한정리(Central Limit Theorem)에 의해 표본 크기가 충분히 크면 모집단 분포와 관계없이 표본 평균이 정규 분포에 수렴합니다.

이항 분포(Binomial Distribution)는 성공 확률 p인 베르누이 시행을 n회 독립적으로 반복할 때 성공 횟수 X의 분포로, B(n, p)로 표기합니다. 포아송 분포(Poisson Distribution)는 단위 시간·공간에서 사건이 평균 λ회 발생할 때의 이산 분포로, 희귀한 사건 빈도 모델링에 적합합니다. n이 크고 p가 매우 작을 때 이항 분포는 포아송 분포로 근사할 수 있으며(λ = np), n이 크면 정규 분포로도 근사합니다.

가설검정 (t검정/z검정/p-value)​

가설검정(Hypothesis Testing)은 표본 데이터를 기반으로 모집단에 대한 가설의 타당성을 통계적으로 검증하는 절차입니다. 귀무가설(H₀: Null Hypothesis)과 대립가설(H₁: Alternative Hypothesis)을 설정하고, 검정 통계량과 유의수준(α)을 기준으로 귀무가설 기각 여부를 판단합니다. 가설검정 절차는 가설 설정 → 유의수준 결정 → 검정 통계량 계산 → 기각역 설정 → 결론 도출의 5단계입니다.

z검정(z-test)은 모분산을 알거나 표본 크기가 충분히 클 때(n ≥ 30) 사용하며, t검정(t-test)은 모분산이 미지이고 표본 크기가 작을 때 t분포를 사용합니다. p-value는 귀무가설이 참일 때 관측된 검정 통계량 이상의 극단적 결과가 나올 확률로, p-value < α(유의수준)이면 귀무가설을 기각합니다. 1종 오류(α 오류: 귀무가설이 참인데 기각)와 2종 오류(β 오류: 귀무가설이 거짓인데 채택)의 트레이드오프를 이해하는 것이 중요합니다.

회귀분석 (선형/로지스틱)​

회귀분석(Regression Analysis)은 종속변수와 하나 이상의 독립변수 간의 관계를 모형화하는 통계 기법입니다. 선형 회귀(Linear Regression)는 종속변수가 연속형일 때 독립변수와의 선형 관계를 최소 제곱법(OLS: Ordinary Least Squares)으로 추정합니다. 단순 선형 회귀는 y = β₀ + β₁x + ε, 다중 선형 회귀는 y = β₀ + β₁x₁ + β₂x₂ + ... + βₖxₖ + ε 형태입니다.

로지스틱 회귀(Logistic Regression)는 종속변수가 이진형(0/1)일 때 사용하는 분류 모델로, 시그모이드 함수를 통해 확률값(0~1)을 출력합니다. 회귀 모형의 적합성 평가를 위해 결정계수(R²), 수정 결정계수, F통계량, t통계량, AIC/BIC 등을 사용합니다. 다중공선성(Multicollinearity)은 독립변수 간 강한 상관관계로 회귀 계수 추정이 불안정해지는 문제이며, VIF(분산팽창지수)로 진단하고 변수 제거나 릿지 회귀(Ridge Regression)로 대응합니다.

시계열 분석 (ARIMA)​

시계열 분석(Time Series Analysis)은 시간 순서에 따라 수집된 데이터에서 패턴과 추세를 파악하고 미래 값을 예측하는 통계 기법입니다. 정상성(Stationarity)은 시계열 분석의 기본 가정으로, 평균, 분산, 자기공분산이 시간에 관계없이 일정해야 합니다. 비정상 시계열은 차분(Differencing)이나 로그 변환으로 정상화합니다.

ARIMA(AutoRegressive Integrated Moving Average) 모형은 AR(자기회귀), I(적분/차분), MA(이동평균) 세 요소를 결합한 모형으로 ARIMA(p, d, q)로 표기합니다. AR(p) 모형은 과거 p개의 자신 값으로 현재를 설명하고, MA(q) 모형은 과거 q개의 오차항으로 현재를 설명합니다. 계절성이 있는 데이터에는 SARIMA 모형을, 딥러닝 기반 예측에는 LSTM(Long Short-Term Memory) 네트워크가 효과적입니다.

베이즈 정리​

베이즈 정리(Bayes' Theorem)는 사전 확률(Prior Probability)과 새로운 증거(Likelihood)를 결합하여 사후 확률(Posterior Probability)을 계산하는 조건부 확률 정리입니다. 수식으로 표현하면 P(A|B) = P(B|A) × P(A) / P(B)이며, 스팸 필터링, 의료 진단, 문서 분류 등 다양한 분야에서 활용됩니다.

나이브 베이즈 분류기(Naive Bayes Classifier)는 각 특성이 독립이라는 단순화 가정(Naive 가정)하에 베이즈 정리를 적용한 확률 분류기로, 텍스트 분류에 특히 효과적입니다. 베이지안 추론(Bayesian Inference)은 데이터가 추가될수록 사후 확률이 업데이트되는 반복적 학습이 가능하여, 데이터가 적은 상황에서도 사전 지식을 활용한 추론이 가능합니다. 베이즈 정리는 머신러닝의 확률 모델, 불확실성 정량화, A/B 테스트 해석 등에 핵심적으로 사용됩니다.

혼동행렬 (Precision/Recall/F1)​

혼동행렬(Confusion Matrix)은 분류 모델의 예측 결과와 실제 값을 비교하여 성능을 평가하는 도구입니다. TP(True Positive: 실제 양성을 양성으로 예측), TN(True Negative: 실제 음성을 음성으로 예측), FP(False Positive: 실제 음성을 양성으로 예측, 1종 오류), FN(False Negative: 실제 양성을 음성으로 예측, 2종 오류)의 4가지 경우로 구성됩니다.

주요 성능 지표는 다음과 같습니다. 정확도(Accuracy) = (TP+TN)/(TP+TN+FP+FN), 정밀도(Precision) = TP/(TP+FP), 재현율(Recall/Sensitivity) = TP/(TP+FN), F1 Score = 2 × (Precision × Recall) / (Precision + Recall)입니다. 정밀도와 재현율은 트레이드오프 관계로, F1 Score는 두 지표의 조화 평균입니다. 불균형 데이터셋에서는 정확도만으로 모델 성능을 평가하는 것이 부적절하며 Precision, Recall, F1, AUC-ROC 등을 종합적으로 고려해야 합니다.

대기행렬 이론​

대기행렬 이론(Queuing Theory)은 서비스를 기다리는 대기열의 특성을 수학적으로 분석하는 이론으로, 서비스 시스템의 성능 평가와 최적화에 활용됩니다. 주요 분석 요소는 도착 프로세스(Arrival Process), 서비스 시간 분포(Service Time Distribution), 서버 수(Number of Servers), 대기열 용량(Queue Capacity), 서비스 규율(Service Discipline)이며, 켄달 표기법(Kendall's Notation)으로 A/B/c/K/N/Z 형태로 표현합니다.

리틀의 법칙(Little's Law)은 시스템 내 평균 고객 수(L) = 평균 도착률(λ) × 평균 체류 시간(W)의 관계를 나타내는 기본 법칙입니다. M/M/1 큐는 포아송 도착, 지수 서비스 시간, 서버 1개인 기본 모델로, 서버 이용률 ρ = λ/μ이며 ρ < 1일 때 안정적입니다. 대기행렬 이론은 IT 시스템의 서버 용량 계획, 네트워크 트래픽 분석, 콜센터 운영, 은행 창구 배치 등에 폭넓게 적용됩니다.

CRC (순환 중복 검사)​

CRC(Cyclic Redundancy Check, 순환 중복 검사)는 데이터 전송 오류를 감지하기 위한 해시 함수 기반의 오류 검출 코드입니다. 송신 측에서 데이터를 생성 다항식(Generator Polynomial)으로 나누어 나머지(CRC 코드)를 데이터에 첨부하여 전송하고, 수신 측에서 동일한 다항식으로 나누어 나머지가 0인지 확인합니다. 나머지가 0이면 오류 없음, 0이 아니면 오류 발생으로 판단합니다.

CRC-8은 생성 다항식 x⁸ + x² + x + 1(2진수 표현: 100000111)을 사용하는 8비트 CRC입니다. 계산 과정은 데이터워드에 8비트 0을 추가(패딩) → 생성 다항식으로 모듈로-2 나눗셈(XOR 연산) → 나머지가 CRC 코드 → 데이터워드에 CRC 코드 첨부하여 코드워드 생성 → 수신 측에서 코드워드를 생성 다항식으로 나누어 나머지 0 확인 순서입니다. CRC는 이더넷, USB, ZIP 파일 형식 등 다양한 데이터 통신 및 저장 시스템에 표준으로 사용됩니다.
