자료구조 개요​

자료구조(Data Structure)는 데이터를 효율적으로 저장·관리·처리하기 위한 논리적 구조를 의미합니다. 자료구조는 크게 선형 구조(Linear Structure)와 비선형 구조(Non-Linear Structure)로 분류됩니다. 선형 구조는 배열, 연결 리스트, 스택, 큐와 같이 데이터가 순차적으로 나열된 구조이며, 비선형 구조는 트리와 그래프처럼 계층적 또는 망형으로 연결된 구조입니다.

올바른 자료구조 선택은 알고리즘 성능에 직결됩니다. 삽입·삭제가 빈번하면 연결 리스트가, 인덱스 기반 접근이 중요하면 배열이 유리합니다. 자료구조의 특성을 이해하는 것은 시간복잡도와 공간복잡도를 최적화하는 기반이 됩니다.

배열과 연결 리스트​

배열(Array)은 동일한 자료형의 데이터를 연속된 메모리 공간에 저장하는 자료구조입니다. 인덱스를 통해 O(1)의 시간복잡도로 임의 접근이 가능하지만, 삽입·삭제 시 원소를 이동해야 하므로 O(n)의 비용이 발생합니다. 크기가 고정되어 있어 동적 크기 조정이 필요한 경우 불리합니다.

연결 리스트(Linked List)는 노드(Node)가 데이터와 다음 노드를 가리키는 포인터로 구성되며, 메모리 공간이 불연속적입니다. 단순 연결 리스트(Singly Linked List), 이중 연결 리스트(Doubly Linked List), 원형 연결 리스트(Circular Linked List), 다중 연결 리스트(Multi-linked List)로 세분됩니다. 삽입·삭제는 O(1)이지만 임의 접근은 O(n)이 소요됩니다.

스택과 큐​

스택(Stack)은 후입선출(LIFO: Last In First Out) 원칙으로 동작하는 선형 자료구조입니다. 삽입(Push)과 삭제(Pop)가 한쪽 끝(Top)에서만 이루어집니다. 스택 포인터(Top)가 스택 크기(K)를 초과하면 오버플로우(Overflow), 0 이하가 되면 언더플로우(Underflow)가 발생합니다. 함수 호출 스택, 수식 평가, 괄호 검사 등에 활용됩니다.

큐(Queue)는 선입선출(FIFO: First In First Out) 원칙의 선형 자료구조로, 삽입(Enqueue)은 후단(Rear), 삭제(Dequeue)는 전단(Front)에서 발생합니다. 단순 배열 기반 큐는 메모리 낭비 문제가 있어 원형 큐(Circular Queue)로 개선합니다. 우선순위 큐(Priority Queue)는 우선순위가 높은 원소를 먼저 처리하며 힙(Heap) 자료구조로 구현합니다.

  • 133회 2교시 - 스택, 큐, 리스트의 자료 입출력 원리

트리​

트리(Tree)는 계층적 구조를 표현하는 비선형 자료구조로, 루트(Root) 노드를 최상위로 부모-자식 관계를 형성합니다. 이진 트리(Binary Tree)는 각 노드가 최대 2개의 자식 노드를 갖는 트리이며, 이진 탐색 트리(BST: Binary Search Tree)는 왼쪽 자식 < 부모 < 오른쪽 자식 순서를 유지하여 탐색 효율을 O(log n)으로 보장합니다.

힙(Heap)은 완전 이진 트리 기반의 자료구조로, 최대 힙(Max-Heap)은 부모 노드가 자식보다 항상 크고, 최소 힙(Min-Heap)은 부모가 자식보다 항상 작습니다. 힙은 우선순위 큐 구현과 힙 정렬(Heap Sort)에 사용됩니다. 트리 정렬(Tree Sort)은 이진 탐색 트리에 데이터를 삽입한 후 중위 순회(Inorder Traversal)로 정렬된 결과를 얻는 방식입니다.

  • 124회 3교시 - Max-heap과 Min-heap
  • 131회 1교시 - 트리정렬(Tree Sort)

그래프​

그래프(Graph)는 정점(Vertex)과 간선(Edge)으로 구성된 비선형 자료구조입니다. 방향 그래프(Directed Graph)와 무방향 그래프(Undirected Graph), 가중치 그래프(Weighted Graph)로 나뉩니다. 방향성 비순환 그래프(DAG: Directed Acyclic Graph)는 사이클이 없는 방향 그래프로, 작업 스케줄링과 위상 정렬(Topology Sort)에 활용됩니다.

최단 경로 알고리즘으로는 다익스트라(Dijkstra), 벨만-포드(Bellman-Ford), 플로이드-워샬(Floyd-Warshall), A* 알고리즘이 대표적입니다. 다익스트라는 음의 가중치가 없는 그래프에서 단일 출발점 최단 경로를 구하며, 균일비용탐색(Uniform Cost Search)과 유사한 원리를 가집니다. A* 알고리즘은 휴리스틱 함수를 추가하여 탐색 효율을 향상시킵니다.

정렬 알고리즘​

정렬 알고리즘은 데이터를 특정 순서로 재배열하는 알고리즘입니다. 버블 정렬(Bubble Sort), 선택 정렬(Selection Sort), 삽입 정렬(Insertion Sort)은 O(n²)의 시간복잡도를 가지는 단순 정렬입니다. 반면 합병 정렬(Merge Sort), 퀵 정렬(Quick Sort), 힙 정렬(Heap Sort)은 평균 O(n log n)의 성능을 보이며 실무에서 많이 사용됩니다.

퀵 정렬은 피벗(Pivot)을 기준으로 분할 정복(Divide and Conquer) 방식을 사용하며 평균 O(n log n)이지만 최악의 경우 O(n²)이 될 수 있습니다. 합병 정렬은 안정 정렬(Stable Sort)로 O(n log n)을 보장하며 추가 메모리가 필요합니다. 트리 정렬은 BST를 활용하여 삽입과 동시에 정렬하는 방식입니다.

탐색 알고리즘​

이진 탐색(Binary Search)은 정렬된 배열에서 중간 원소와 비교하며 탐색 범위를 절반씩 좁혀나가는 알고리즘으로 O(log n)의 시간복잡도를 가집니다. 순차 탐색이 O(n)인 것과 비교하면 대용량 데이터 처리에 매우 효율적입니다.

BFS(너비 우선 탐색, Breadth-First Search)는 큐를 사용하여 현재 노드의 인접 노드를 먼저 모두 방문하는 방식으로, 최단 경로 탐색에 적합합니다. DFS(깊이 우선 탐색, Depth-First Search)는 스택 또는 재귀를 사용하여 한 경로를 끝까지 탐색한 후 되돌아오는 방식으로, 경로 탐색이나 사이클 감지에 활용됩니다. 균일비용탐색(UCS)은 BFS를 확장하여 가중치 비용이 최소인 경로를 우선 탐색하고, A*는 UCS에 휴리스틱을 더해 더욱 효율적인 탐색을 구현합니다.

  • 137회 1교시 - 이진 탐색 트리

최소 신장 트리 (MST)​

최소 신장 트리(MST: Minimum Spanning Tree)는 가중치 그래프에서 모든 정점을 연결하는 간선의 가중치 합이 최소인 트리입니다. 사이클이 없고 정점 수가 n이면 간선 수는 n-1개입니다. 통신망, 전력망, 도로망 설계 등 비용 최소화 문제에 널리 적용됩니다.

크루스칼(Kruskal) 알고리즘은 간선을 가중치 오름차순으로 정렬한 후, 사이클을 형성하지 않는 간선을 하나씩 선택합니다. 유니온-파인드(Union-Find) 자료구조를 활용하여 O(E log E)의 복잡도를 가집니다. 프림(Prim) 알고리즘은 임의의 정점에서 출발하여 현재 트리에 연결된 간선 중 가중치가 최소인 간선을 반복적으로 추가하는 방식으로, 밀집 그래프에 유리하며 O(V²) 또는 우선순위 큐 사용 시 O(E log V)입니다.

해싱​

해싱(Hashing)은 키(Key)를 해시 함수(Hash Function)에 입력하여 해시 주소(Hash Address)를 계산하고, 해당 위치에 데이터를 저장·검색하는 기법입니다. 평균 O(1)의 탐색 성능을 제공하며, 데이터베이스 인덱스, 캐시, 암호화 등 다양한 분야에 활용됩니다.

해시 충돌(Collision)은 서로 다른 키가 동일한 해시 주소를 생성하는 현상입니다. 충돌 해결 기법으로는 개방 주소법(Open Addressing: 선형 탐사, 이차 탐사, 이중 해싱)과 체이닝(Chaining: 연결 리스트 연결) 방식이 있습니다. 확장성 해싱(Extendible Hashing)은 디렉터리(Directory)와 버킷(Bucket)을 사용하여 동적으로 크기를 조절하며, 데이터베이스의 동적 파일 처리에 적합합니다.

유전 알고리즘​

유전 알고리즘(Genetic Algorithm)은 자연 선택과 유전학의 원리를 모방한 메타휴리스틱 최적화 알고리즘입니다. 해의 집합인 염색체(Chromosome) 집단(Population)을 초기화하고, 적합도 함수(Fitness Function)로 각 개체를 평가하여 우수한 개체를 선택·교차·변이시켜 새로운 세대를 생성하는 과정을 반복합니다.

선택(Selection) 단계에서는 룰렛 휠 선택(Roulette Wheel Selection), 토너먼트 선택(Tournament Selection) 등을 사용하며, 교차(Crossover)와 변이(Mutation)를 통해 해 공간을 탐색합니다. 룰렛 휠 선택은 적합도에 비례하는 확률로 개체를 선택하여 우수한 개체가 선택될 가능성을 높이는 역할을 합니다. 유전 알고리즘은 TSP(외판원 문제), 스케줄링, 신경망 학습 등 복잡한 최적화 문제에 적용됩니다.

복잡도 분석 (빅오 표기법)​

알고리즘 복잡도(Complexity)는 입력 크기 n에 대한 알고리즘의 수행 시간(시간복잡도)과 메모리 사용량(공간복잡도)을 분석하는 척도입니다. 빅오 표기법(Big-O Notation)은 최악의 경우(Worst Case) 수행 시간의 점근적 상한을 표현하며, 알고리즘 성능 비교의 표준 방법론입니다.

주요 복잡도 유형은 O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!) 순으로 성능이 저하됩니다. O(1)은 해시 테이블 접근, O(log n)은 이진 탐색, O(n)은 순차 탐색, O(n log n)은 합병·퀵 정렬, O(n²)은 버블·선택 정렬이 해당됩니다. 알고리즘 선택 시 입력 크기와 제약 조건에 따라 적합한 복잡도 수준을 고려해야 합니다.

유한 오토마타​

유한 오토마타(Finite Automata, FA)는 유한한 수의 상태(State)와 상태 전이(Transition)로 구성된 추상적 계산 모델입니다. 결정적 유한 오토마타(DFA: Deterministic FA)는 각 상태에서 입력 기호에 대해 정확히 하나의 전이가 정의되며, 비결정적 유한 오토마타(NFA: Non-deterministic FA)는 동일 입력에 여러 전이가 가능합니다. DFA와 NFA는 표현 능력이 동일하며 상호 변환 가능합니다.

정규식(Regular Expression)은 유한 오토마타로 인식 가능한 언어(정규 언어)를 표현하는 패턴 기술 방식입니다. 컴파일러의 어휘 분석(Lexical Analysis), 문자열 패턴 매칭, 네트워크 패킷 필터링 등에 광범위하게 사용됩니다. 유한 오토마타는 형식 언어 이론의 기초로, 컴파일러 설계와 프로그래밍 언어 처리에 필수적인 개념입니다.
