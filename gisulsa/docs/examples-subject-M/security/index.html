보안/정보보호

정보관리기술사 기출문제 중 보안/정보보호 관련 문제를 정리한 페이지입니다.

110회​

1교시​

  • 10.프라이버시 보호모델인 k-익명성(k-anonymity)에 대해 설명하시오.

k-익명성은 데이터 공개 시 특정 개인을 식별할 수 없도록 동일한 준식별자 값을 가진 레코드가 최소 k개 이상 존재하도록 보장하는 프라이버시 보호 모델입니다. 개인정보 비식별화의 핵심 기법으로, 데이터 유용성과 프라이버시 보호 사이의 균형을 맞추는 것이 중요합니다. k 값이 클수록 프라이버시 보호 수준은 높아지지만 데이터 정보손실이 증가합니다.

  • 13.스턱스넷(Stuxnet)에 대해 설명하시오.

스턱스넷은 산업제어시스템(SCADA)을 표적으로 설계된 최초의 사이버 무기급 악성코드로, 이란 핵시설의 원심분리기를 물리적으로 파괴하는 데 사용되었습니다. USB 드라이브를 통해 확산되며 PLC(프로그래머블 논리 컨트롤러)의 동작을 은밀히 변조합니다. 이 사건은 사이버전쟁이 물리적 인프라에 실질적 피해를 줄 수 있음을 세계에 처음 입증한 사례입니다.

2교시​

  • 6.최근 핀테크 인터넷전문은행, 간편결제 서비스의 등장으로 비대면 거래가 늘어나면서 이에 대한 보안 기술의 중요성이 강조되고 있다.최근 비대면 보안기술로 각광받는 기술들의 개념과 특징을 열거하고, 이들을 비교 설명하시오.

비대면 보안기술에는 FIDO 생체인증, 블록체인 기반 분산 인증, 간편결제 토큰화(Tokenization), 본인확인 서비스(CI/DI) 등이 포함됩니다. 각 기술은 사용 편의성, 보안 강도, 적용 범위가 서로 달라 서비스 특성에 맞는 선택이 필요합니다. 핀테크 환경에서는 이 기술들을 복합적으로 활용하여 다중 요소 인증 체계를 구성하는 것이 일반적입니다.

3교시​

  • 5.최근 발간된 "개인정보 비식별 조치 가이드라인"의 추진 배경, 비식별 조치기준을 설명하고 향후 기대되는 효과에 대하여 설명하시오.

개인정보 비식별 조치 가이드라인은 빅데이터 활용과 개인정보 보호를 동시에 달성하기 위해 마련된 정부 지침으로, 데이터 산업 활성화를 위한 제도적 기반을 제공합니다. 비식별 조치기준으로는 가명처리, 총계처리, 데이터 삭제, 데이터 범주화, 데이터 마스킹 등 5가지 기법이 제시됩니다. 이를 통해 의료·금융 등 민감 분야의 데이터를 안전하게 활용하여 산업 혁신을 촉진하는 효과가 기대됩니다.

4교시​

  • 2.정보보호 인증제도인 ISMS, G-ISMS, PIPL, PIMS에 대하여 근거 법령, 인증 대상, 인증 평가 내용, 의무여부, 인증 취득 시 혜택을 설명하시오.

ISMS는 정보통신망법 기반의 정보보호 관리체계 인증으로 일정 규모 이상의 정보통신서비스 제공자에게 의무 적용됩니다. G-ISMS는 공공기관 대상, PIMS는 개인정보보호법 기반의 개인정보 관리체계 인증이며, PIPL은 클라우드 서비스의 개인정보보호 인증입니다. 각 인증은 적용 대상과 평가 범위가 다르며 인증 획득 시 과태료 감면, 행정지원 등의 혜택이 부여됩니다.

111회​

1교시​

  • 9.엘가멜(ElGamal)

엘가멜 암호는 이산대수 문제의 어려움에 기반한 공개키 암호 알고리즘으로, Taher ElGamal이 1985년 제안했습니다. 암호화 시 무작위 값을 사용하므로 같은 평문을 암호화해도 매번 다른 암호문이 생성되는 확률적 암호화 특성을 가집니다. 디지털 서명에도 활용되며 DSA(Digital Signature Algorithm)의 기초가 되었습니다.

  • 11.사이버 킬 체인(Cyber Kill Chain)

사이버 킬 체인은 록히드마틴이 제안한 사이버 공격 단계 모델로, 공격자의 침해 과정을 7단계로 구조화하여 각 단계에서 방어 활동을 전개할 수 있도록 합니다. 정찰, 무기화, 전달, 익스플로잇, 설치, C2 통신, 목표달성의 7단계로 구성되며, 초기 단계에서 차단할수록 피해를 최소화할 수 있습니다. APT 공격 대응 프레임워크로 널리 활용됩니다.

2교시​

  • 3.사이버전(Cyber Warfare)의 개념, 특징, 보안 기술을 설명하시오.

사이버전은 국가 또는 국가 지원 조직이 적국의 정보시스템·인프라를 공격하거나 방어하는 디지털 전쟁 형태로, 물리적 충돌 없이 심각한 피해를 유발할 수 있습니다. 익명성, 비대칭성, 경계 모호성이 특징이며 전력망·금융·군사 시스템이 주요 공격 대상입니다. 방어 기술로는 사이버 위협 인텔리전스(CTI), 능동적 방어, 사이버 복원력(Cyber Resilience) 등이 활용됩니다.

  • 6.사물인터넷(IoT) 네트워크는 초연결성을 가지고 있어 장치 간 신뢰성 확보가 필수적으로 요구된다.사물인터넷(IoT) 네트워크 보안 기술의 개념, 특성, CoAP / MQTT / LwM2M 프로토콜 구조, 보안 이슈에 대하여 설명하시오.

IoT 네트워크는 수많은 경량 디바이스가 연결되므로 전통적인 보안 기술을 그대로 적용하기 어려우며 경량 암호화, 디바이스 인증, 펌웨어 보안 업데이트가 핵심 보안 요소입니다. CoAP은 HTTP 대체 경량 프로토콜, MQTT는 발행-구독 방식의 메시지 브로커 프로토콜, LwM2M은 디바이스 관리 표준 프로토콜입니다. 주요 보안 이슈로는 약한 인증, 암호화 미적용, 펌웨어 취약점 등이 있습니다.

3교시​

  • 6.공공 클라우드 포렌식(Forensic) 조사 절차, 클라우드 시그니처(Cloud Sigature)탐지 도구의 개념 및 기능에 대하여 설명하시오.

클라우드 포렌식은 클라우드 환경의 특성(멀티테넌시, 가상화, 분산 저장)으로 인해 전통적 포렌식과 달리 접근 권한 확보와 증거 무결성 유지가 더욱 복잡합니다. 조사 절차는 보존 요청, 증거 수집, 분석, 보고 순으로 진행되며 CSP(클라우드 서비스 제공자)와의 협조가 필수입니다. 클라우드 시그니처 탐지 도구는 로그 분석과 이상 패턴 탐지를 통해 침해 흔적을 식별합니다.

113회​

1교시​

  • 1.크라임웨어(Crimeware)

크라임웨어는 금전적 이익을 목적으로 제작된 악성 소프트웨어의 총칭으로, 트로이목마, 키로거, 랜섬웨어, 스파이웨어 등이 포함됩니다. 사이버 범죄 조직이 조직적으로 제작·유통하며, 다크웹에서 서비스(MaaS) 형태로 판매되기도 합니다. 금융 정보 탈취, 시스템 잠금 후 금전 요구 등 다양한 형태로 피해를 입힙니다.

  • 2.암호화에서의 Challenge-response 방식

Challenge-response 인증은 서버가 무작위 값(Challenge)을 클라이언트에 전송하면 클라이언트가 비밀키로 응답값(Response)을 계산하여 반환하는 방식으로, 패스워드를 네트워크로 직접 전송하지 않아 도청 공격을 방지합니다. 매번 다른 Challenge가 사용되므로 재전송 공격(Replay Attack)에도 안전합니다. OTP, HMAC 기반 인증 등에 널리 활용됩니다.

  • 4.FIDO(Fast Identity Online) 2.0

FIDO 2.0은 비밀번호 없는 강력한 인증을 위한 국제 표준으로, WebAuthn과 CTAP2 두 가지 핵심 사양으로 구성됩니다. 생체인증(지문, 얼굴), 하드웨어 보안키 등을 활용하여 피싱 공격에 강한 공개키 기반 인증을 제공합니다. 브라우저와 플랫폼 수준에서 지원되어 웹 서비스에 쉽게 통합할 수 있습니다.

  • 5.Linux PAM(Pluggable Authentication Modules)

Linux PAM은 인증 방식을 모듈화하여 응용 프로그램의 코드 변경 없이 다양한 인증 메커니즘을 유연하게 적용할 수 있는 프레임워크입니다. 인증(auth), 계정(account), 세션(session), 패스워드(password) 4가지 관리 그룹으로 구성되며 각각 독립적인 모듈로 제어합니다. /etc/pam.d/ 디렉터리의 설정 파일을 통해 서비스별로 인증 정책을 세밀하게 관리합니다.

  • 7.익명 네트워크 TOR(The Onion Routing)

TOR는 데이터를 여러 겹의 암호화 계층(양파 껍질 구조)으로 감싸 여러 중계 노드를 거쳐 전송함으로써 통신자의 IP 주소와 신원을 익명화하는 네트워크입니다. 각 중계 노드는 다음 경로 정보만 알 수 있어 전체 경로를 추적하기 매우 어렵습니다. 프라이버시 보호에 사용되지만 다크웹 접근 등 불법적 용도로도 악용됩니다.

2교시​

  • 5.월드와이드웹(WWW) 프로토콜인 HTTP의 취약점을 설명하고, 그 대안으로 사용하는 HTTPS의 특징에 대하여 설명하시오.

HTTP는 평문 통신 방식으로 도청, 위변조, 위장 공격에 취약하며 상태 비저장(Stateless) 특성상 세션 하이재킹 위험도 존재합니다. HTTPS는 TLS/SSL 프로토콜을 적용하여 기밀성(암호화), 무결성(MAC), 인증(인증서) 세 가지 보안 속성을 모두 제공합니다. 공개키 기반 인증서를 통해 서버 신뢰성을 검증하고 대칭키로 실제 데이터를 암호화합니다.

3교시​

  • 3.랜섬웨어 공격에 대하여 사전, 사후적 대응방안을 기술적, 관리적 관점에서 설명하시오.

랜섬웨어는 피해자의 파일을 암호화하거나 시스템을 잠그고 복호화 대가로 금전을 요구하는 악성코드로, 이메일 피싱과 취약점 익스플로잇을 통해 주로 전파됩니다. 사전 대응으로는 정기 백업, 패치 관리, 직원 보안 교육, EDR 솔루션 도입이 효과적입니다. 사후 대응으로는 감염 시스템 격리, 백업 복원, 침해사고 신고 및 포렌식 분석이 필요합니다.

  • 4.특정 개인의 프라이버시(privacy)를 보호하면서도 그 개인의 정보를 사용하기 위해 설계된 방법의 하나인 PPDM(Privacy Preserving Data Mining)을 정의하고, 그 기법에 대하여 설명하시오.

PPDM(프라이버시 보존 데이터마이닝)은 개인 정보를 직접 노출하지 않으면서 유의미한 패턴과 지식을 도출할 수 있도록 설계된 데이터 분석 방법론입니다. 주요 기법으로는 데이터 변환(교란, 집계), 분산 데이터마이닝, k-익명성 적용, 차분 프라이버시 등이 있습니다. 의료·금융 빅데이터 분석 시 개인정보보호법 준수와 데이터 활용성의 균형을 실현합니다.

  • 6.기업 내부 사용자의 시스템 접근을 더욱 체계적으로 관리하기 위하여 별도의 비밀번호 관리 시스템을 구축하고자 한다. 별도의 비밀번호관리시스템을 구축하는 경우의 장단점을 설명하고, 시스템 개념 구성도 및 처리 절차 등에 대하여 설명하시오.

별도의 비밀번호 관리 시스템(PAM: Privileged Access Management)은 특권 계정의 패스워드를 중앙에서 자동 생성·변경·배포하여 내부자 위협과 계정 탈취 위험을 크게 줄여줍니다. 장점으로는 패스워드 정책 일관성 유지, 감사 로그 자동화가 있으며, 단점으로는 단일 장애점(SPoF) 위험과 도입 비용이 있습니다. 세션 녹화와 접근 승인 워크플로우를 함께 제공하는 것이 일반적입니다.

    • 가.생성형AI의 개념 및 활용 서비스 사례
    • 나.생성형AI의 보안 위협 종류별 주요 원인과 발생 가능한 보안위협
    • 다.생성형AI 모델/서비스 개발 시 보안 고려사항과 보안위협 대응방안

4교시​

    • 나.MPC 기술 종류
    • 다.MPC 기반 인증서비스
  • 3.정보보호 방법을 암호화와 접근제어로 크게 분류할 때, 접근제어에 대하여 그 개념과 정책, 절차, 그리고 이를 구현하는 메커니즘에 대하여 설명하시오.

    • 나.IPSec(Internet Protocol Security) VPN과 SSL(Secure Socket Layer) VPN
    • 다.VPN의 기술요소

    • 나.OWASP LLM에서 제시된 주요 보안 위협
    • 다.기업이 LLM 애플리케이션을 설계, 운영할 때 OWASP LLM을 활용한 보안대응방안
