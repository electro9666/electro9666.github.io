빅데이터/데이터분석

정보관리기술사 기출문제 중 빅데이터/데이터분석 관련 문제를 정리한 페이지입니다.

110회​

1교시​

  • 7.패스트 데이터(Fast Data)에 대해 설명하시오.

패스트 데이터는 빅데이터에서 진화한 개념으로, 대용량 데이터를 실시간으로 수집·처리·분석하여 즉각적인 의사결정을 지원하는 기술이다. IoT 센서, 소셜 미디어, 금융 거래 등에서 발생하는 스트리밍 데이터가 주요 대상이다. 배치 처리 중심의 빅데이터와 달리 실시간 처리(스트림 처리)를 핵심으로 한다.

111회​

1교시​

  • 3.CRISP-DM(Cross Industry Standard Process for Data Mining)

CRISP-DM은 데이터 마이닝 프로젝트의 표준 수행 절차 모델로, 비즈니스 이해→데이터 이해→데이터 준비→모델링→평가→배포의 6단계로 구성된다. 각 단계는 순환 반복 구조로 이전 단계로 돌아가 개선할 수 있다. 산업 전반에 걸쳐 적용 가능한 범용 데이터 분석 방법론으로 널리 활용된다.

  • 10.Open Adoption Software

Open Adoption Software는 오픈소스 소프트웨어를 조직이 체계적으로 도입·운영하기 위한 전략과 프레임워크를 의미한다. 라이선스 컴플라이언스, 보안 취약점 관리, 커뮤니티 기여를 핵심 요소로 포함한다. 클라우드·AI 시대에 오픈소스 의존도가 높아지면서 체계적인 오픈소스 거버넌스 필요성이 증가하고 있다.

4교시​

  • 1.데이터 분석의 분류 모델에서 모델 평가 시 사용되는 혼동행렬(Confusion Matrix)에 대하여 설명하고, 혼동행렬 기반의 모델 성능평가 항목을 산식을 이용하여 설명하시오.

혼동행렬은 분류 모델의 예측 결과를 실제값과 비교하여 TP·TN·FP·FN 4가지 경우로 정리한 표이다. 정확도(Accuracy)=(TP+TN)/전체, 정밀도(Precision)=TP/(TP+FP), 재현율(Recall)=TP/(TP+FN)으로 성능을 평가한다. F1-score는 정밀도와 재현율의 조화 평균으로, 불균형 데이터에서 종합 성능을 측정하는 데 유용하다.

  • 2.네트워크 데이터 분석에서 네트워크 중심성을 평가하는 연결중심성(Degree Centrality), 매개중심성(Betweenness Centrality), 인접중심성(Closeness Centrality)에 대하여 설명하시오.

연결중심성은 노드가 가진 직접 연결 수로 측정하며, 많이 연결된 허브 노드를 식별한다. 매개중심성은 다른 노드 간 최단 경로 상에 얼마나 자주 위치하는지를 측정하여 정보 전달 브로커를 찾는 데 활용된다. 인접중심성은 다른 모든 노드까지의 평균 거리의 역수로, 네트워크 내에서 빠르게 다른 노드에 도달할 수 있는 정도를 나타낸다.

113회​

4교시​

  • 3.기업경쟁력 제고를 위해 빅데이터(BigData) 분석의 중요성이 대두됨에 따라, 기업의 문제점을 체계적으로 파악하고, 이를 해결하여 사업적 가치를 재평가하기 위해서는 통합적 빅데이터 프로젝트 수행이 필요하다. 빅데이터 분석의 특징을 설명한 후 적절한 수행 절차와 각 단계에서의 처리내용을 설명하시오.

빅데이터는 Volume(대용량)·Velocity(고속)·Variety(다양성)·Veracity(정확성)·Value(가치)의 5V 특징을 가진다. 수행 절차는 비즈니스 이해→데이터 수집→전처리→분석 모델링→결과 해석→시각화 및 적용으로 진행된다. 각 단계에서 데이터 품질 관리와 분석 목적 정합성 유지가 핵심이다.

  • 5.오픈 데이터(Open Data)를 정의하고(특히 오픈의 의미를 구체적으로 설명), 그 데이터의 등급을 5단계로 나누어 설명하시오.

오픈 데이터는 누구나 자유롭게 접근·이용·재배포할 수 있는 공개 데이터로, 기술적 개방성과 법적 개방성을 모두 포함한다. 팀 버너스리의 5단계 성숙도 모델에서 1단계(단순 공개)에서 5단계(Linked Open Data)로 갈수록 상호운용성이 높아진다. 5단계에서는 URI 기반의 다른 데이터와 연결이 가능하여 지식 그래프 구축에 활용된다.

114회​

2교시​

  • 3.빅데이터 프로세싱 아키텍처의 필요성, 람다 아키텍처(Lambda Architecture) 와 카파 아키텍처( Capa Architecture)를 비교 설명하시오.

람다 아키텍처는 배치 레이어(정확한 과거 데이터)와 스피드 레이어(실시간 데이터)를 병렬로 운영하여 대용량과 실시간 처리를 동시에 지원한다. 카파 아키텍처는 스트리밍 레이어만 사용하여 구조를 단순화한 방식으로, 모든 데이터를 스트림으로 처리한다. 람다는 정확성이 높지만 복잡성이 높고, 카파는 단순하지만 재처리 비용이 발생할 수 있다.

3교시​

  • 3.데이터웨어하우스에서 다차원 온라인분석처리(MOLAP)의 설계방법과 고려사항을 설명하고, 다음의 요구사항에 맞는 다차원 데이터 큐브를 설계하시오.

MOLAP은 다차원 배열 구조에 데이터를 미리 집계하여 저장함으로써 OLAP 쿼리의 응답 속도를 크게 향상시킨다. 설계 시 차원(Dimension)과 측정값(Measure)을 정의하고, 계층 구조와 집계 수준을 결정하는 것이 핵심이다. 스토리지 폭발 문제를 고려하여 스파스(Sparse) 데이터 처리 방안을 함께 설계해야 한다.

  • 4.시계열분석에 관한 다음 사항에 대하여 답하시오.
    가.시계열분석의 정상성(Statinary)
    나.시계열모형의 유형(자기상관 모형, 이동평균 모형, 자기회귀누적이동평균 모형)
    다.빅데이터의 시계열자료 분석을 위한 심층신경망 기법

시계열 정상성은 평균과 분산이 시간에 따라 일정하고 자기공분산이 시차에만 의존하는 성질로, 대부분의 통계 모형의 전제 조건이다. AR(자기회귀), MA(이동평균), ARIMA(차분+자기회귀+이동평균) 모형이 대표적 시계열 모형이다. 딥러닝 기반으로는 LSTM·GRU 등 순환 신경망이 장기 시계열 패턴 학습에 효과적으로 활용된다.

4교시​

  • 3.조직경쟁력 강화를 위해 데이터 기반의 인사이트를 활용하고자 한다. 이를 위한 분석 주제 도출방안, 도출된 방안을 실행하기 위한 분석 거버넌스 수립방안에 대하여 설명하시오.

데이터 분석 주제 도출은 비즈니스 목표 정렬, 현황 진단, 데이터 자산 파악을 통해 분석 가치와 실현 가능성이 높은 과제를 선별하는 과정이다. 분석 거버넌스는 데이터 소유권, 품질 기준, 분석 윤리, 의사결정 체계를 포함하는 관리 체계이다. CDO(최고데이터책임자) 중심으로 데이터 위원회를 구성하고 분석 표준·프로세스를 제도화하는 것이 핵심이다.

118회​

1교시​

  • 2.빅데이터 분석 플렛폼이 추구하는 데이터 통합 아키텍처 (118정1)

빅데이터 분석 플랫폼의 통합 아키텍처는 데이터 수집·저장·처리·분석·시각화의 전 과정을 단일 플랫폼에서 지원하는 구조이다. 데이터 레이크를 중심으로 배치 처리와 스트리밍 처리를 통합하고, 다양한 분석 도구와 연계하는 아키텍처가 표준으로 자리잡고 있다. Lambda 또는 Kappa 아키텍처 기반으로 확장성과 유연성을 동시에 확보한다.

  • 7.선형회귀모형의 추론에 대한 가정 4가지 (118정1)

선형회귀의 4가지 기본 가정은 선형성(독립변수와 종속변수의 선형 관계), 독립성(잔차 간 자기상관 없음), 등분산성(잔차의 분산이 일정), 정규성(잔차가 정규분포를 따름)이다. 이 가정을 위반하면 회귀계수 추정의 신뢰성이 낮아지므로, 잔차 도표와 통계 검정을 통해 가정 충족 여부를 반드시 확인해야 한다. 가정 위반 시 데이터 변환, 가중 최소제곱법, 로버스트 회귀 등의 대안을 적용한다.

2교시​

  • 1.프로세스 마이닝의 개념과 필요성, 기술요소와 연구분야, 적용사례에 대하여 설명하시오.

프로세스 마이닝은 정보시스템에 기록된 이벤트 로그를 분석하여 실제 비즈니스 프로세스를 자동으로 도출하고 개선 방안을 찾는 기술이다. 프로세스 발견(Discovery), 준거성 검사(Conformance Checking), 프로세스 개선(Enhancement)의 세 가지 유형으로 분류된다. 병원 진료 프로세스 최적화, 제조 공정 병목 분석 등에 널리 적용된다.

  • 3.비정형 데이터를 분석할 예정이다. 다음을 설명하시오.
    가.비정형 데이터 마이닝의 개념과 필요성
    나.텍스트 마이닝의 개념, 기능, 기본 분석절차
    다.사회연결망 분석의 개념, 분석 표현방법, 분석기법, 분석절차

비정형 데이터는 텍스트·이미지·음성·영상 등 정형화되지 않은 데이터로, 전체 데이터의 80% 이상을 차지하므로 분석 필요성이 크다. 텍스트 마이닝은 형태소 분석→불용어 제거→특징 추출→분류·군집 순으로 진행된다. 사회연결망 분석(SNA)은 노드(행위자)와 엣지(관계)로 구성된 그래프를 통해 관계 구조와 영향력을 분석한다.

3교시​

  • 1.데이터 웨어하우스에 적용되는 온라인 분석처리(OLAP, On-Line Analytical Processing)를 온라인 트랜잭션처리(OLTP, On-Line Transaction Processing)와 비교하여 설명하고, 분석정보 데이터베이스(데이터 웨어하우스)와 운영정보 데이터베이스(운영 데이터베이스)가 분리 운영되어야 하는 이유에 대하여 설명하시오.

OLAP은 다차원 분석과 복잡한 쿼리를 위해 설계된 반면, OLTP는 빠른 읽기·쓰기 트랜잭션 처리를 위해 최적화되어 있다. OLAP은 소수의 복잡한 쿼리, OLTP는 다수의 단순 트랜잭션이 특징이다. 두 시스템을 분리함으로써 분석 쿼리의 부하가 운영 서비스의 성능에 영향을 주는 것을 방지하고, 각각의 요구사항에 최적화된 구조를 적용할 수 있다.

119회​

1교시​

  • 7.Data Lake

데이터 레이크는 정형·비정형·반정형 데이터를 원시 형태 그대로 중앙에 저장하는 대규모 저장소이다. 스키마-온-리드(Schema-on-Read) 방식으로, 데이터를 저장할 때가 아닌 사용할 때 구조를 정의한다. 데이터 웨어하우스보다 유연하고 저렴하지만, 관리가 부실하면 데이터 늪(Data Swamp)으로 전락할 위험이 있다.

2교시​

  • 1.두 제품 또는 사건 사이의 연관성 발견을 위해 데이터 마이닝을 실무에서 활용하고 있다. 다음에 대하여 설명하시오.
    가.연관규칙의 특징과 도출 과정
    나.연관정도를 측정하기 위한 3가지 기준
    다.아래 데이터를 참조하여 '기저귀 -> 맥주'의 지지도, 신뢰도, 향상도 도출

연관규칙 분석은 대규모 거래 데이터에서 항목 간 동시 발생 패턴을 발견하는 기법으로, 장바구니 분석이 대표적 사례이다. 지지도(Support)는 전체에서 두 항목이 함께 등장하는 비율, 신뢰도(Confidence)는 선행 항목 등장 시 후행 항목도 등장하는 조건부 확률이다. 향상도(Lift)는 신뢰도를 후행 항목의 지지도로 나눈 값으로, 1보다 크면 양의 상관관계를 의미한다.

  • 3.회귀모형에서 오차의 등분산성(Homoscedasticity)과 다중공선성(Multicollinearity)에 대하여 설명하시오.

등분산성은 회귀 모형에서 독립변수의 값에 관계없이 잔차의 분산이 일정해야 한다는 가정으로, 위반 시 OLS 추정치의 효율성이 저하된다. 다중공선성은 독립변수들 간의 강한 선형 관계로 인해 회귀계수 추정이 불안정해지는 문제이다. 등분산성 위반은 가중 최소제곱법으로, 다중공선성은 릿지 회귀·변수 제거로 대응한다.

3교시​

  • 5.데이터 거래를 위한 데이터 가치평가에 대하여 다음을 설명하시오.
    가.데이터 재화와 데이터 가치의 특징
    나.데이터 가치평가의 모델 및 절차
    다.데이터 가치평가의 활용방안

데이터는 비경합성(동시에 여러 주체가 사용 가능), 비소모성(사용해도 소멸하지 않음), 복제 용이성의 특성을 가지는 독특한 재화이다. 가치평가 모델로는 비용 접근법·시장 접근법·수익 접근법이 있으며, 데이터의 품질·희소성·활용 범위를 반영한다. 데이터 거래소 가격 산정, 투자 유치, 보험·담보 활용, 합병·인수 시 자산 평가에 활용된다.

  • 4.빅데이터 시각화(Visualization)에 대하여 다음을 설명하시오.
    가.개념 및 절차
    나.방법 및 도구

빅데이터 시각화는 방대한 데이터에서 의미 있는 패턴과 트렌드를 직관적으로 전달하기 위한 시각적 표현 기술이다. 절차는 목적 정의→데이터 수집·정제→시각화 방법 선택→시각적 표현→검증·배포 순으로 진행된다. 도구로는 Tableau·Power BI(비즈니스 인텔리전스), D3.js·ECharts(인터랙티브), Matplotlib·Seaborn(데이터 과학)이 활용된다.

3교시​

  • 4.데이터 분석 시 아웃라이어(Outlier)에 대하여 다음을 설명하시오.
    가.아웃라이어의 개념
    나.아웃라이어와 노이즈(Noise)의 차이점
    다.아웃라이어의 3가지 유형인 전역, 맥락, 군집

아웃라이어는 데이터 집합에서 다른 데이터와 현저히 다른 패턴을 보이는 관측값으로, 사기 탐지·결함 검출 등에 활용되거나 분석 왜곡의 원인이 된다. 노이즈는 측정 오류·잡음으로 인한 의미 없는 무작위 편차인 반면, 아웃라이어는 비록 드물지만 실제 의미를 가진 극단값일 수 있다. 전역 이상치는 전체 데이터 기준, 맥락 이상치는 특정 조건·시간대 기준, 집단 이상치는 집합 단위로 비정상적인 경우이다.

  • 5.혼동행렬(Confusion Matrix) 결과를 참고하여 다음을 계산하고 설명하시오.
    가.혼동행렬을 사용한 모델의 성능 평가 원리
    나.정확도, 정밀도, 재현율 계산 결과와 해석
    다.F1-score 계산 결과와 해석

혼동행렬은 분류 모델의 예측 결과를 실제 레이블과 비교하여 TP·FP·FN·TN으로 집계한 표이며, 이를 바탕으로 다양한 성능 지표를 계산한다. 정확도는 전체 중 올바른 예측 비율, 정밀도는 양성 예측 중 실제 양성 비율, 재현율은 실제 양성 중 양성으로 예측한 비율이다. F1-score는 정밀도와 재현율의 조화 평균으로, 두 지표 간 균형을 반영한 종합 성능 지표이다.

1교시​

  • 9.A/B 테스팅을 설명하시오.

A/B 테스팅은 두 가지 버전(A, B)을 동시에 무작위 그룹에 노출하여 어느 버전이 목표 지표에서 더 우수한지를 통계적으로 검증하는 실험 기법이다. 웹 페이지 디자인, 마케팅 메시지, 앱 기능 변경의 효과를 데이터 기반으로 검증하는 데 활용된다. 표본 크기, 실험 기간, 통계적 유의수준 설정이 실험 설계의 핵심 요소이다.

  • 10.데이터 늪(Data Swamp)을 설명하시오.

데이터 늪은 데이터 레이크가 체계적인 거버넌스 없이 운영될 때 데이터가 무분별하게 쌓여 활용 불가능한 상태가 된 것을 의미한다. 메타데이터 부재, 데이터 품질 관리 미흡, 접근 통제 부족이 주요 원인이다. 데이터 카탈로그 구축, 메타데이터 표준화, 데이터 거버넌스 강화로 데이터 늪을 예방하고 데이터 레이크의 가치를 유지할 수 있다.

  • 13.데이터마이닝의 연관 규칙 분석(Association Rule Analysis) 지표를 설명하시오.

연관 규칙 분석 지표는 규칙의 강도와 흥미도를 측정하는 척도로, 지지도·신뢰도·향상도가 대표적이다. 지지도(Support)는 전체 거래 중 두 항목이 함께 나타난 비율, 신뢰도(Confidence)는 선행 항목 등장 시 후행 항목이 등장할 조건부 확률이다. 향상도(Lift)가 1보다 크면 두 항목 간 양의 연관성, 1이면 독립, 1보다 작으면 음의 연관성을 의미한다.

  • 8.데이터 관측가능성(Data Observability)을 설명하시오.

데이터 관측가능성은 데이터 파이프라인과 시스템의 상태를 지속적으로 모니터링하여 데이터 품질 문제를 조기에 탐지하고 근본 원인을 신속히 파악할 수 있는 능력이다. 신선도(Freshness), 분포(Distribution), 볼륨(Volume), 스키마(Schema), 계보(Lineage)의 5가지 핵심 요소로 구성된다. 데이터 다운타임(품질 저하 시간)을 최소화하여 데이터 신뢰성을 유지하는 데 목적이 있다.
