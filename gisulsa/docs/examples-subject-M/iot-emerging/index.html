IoT/신기술/융합

정보관리기술사 기출문제 중 IoT/신기술/융합 관련 문제를 정리한 페이지입니다.

111회​

2교시​

  • 5.인공지능, 사물인터넷, 클라우드가 로봇과 접목하여 인간과 상호작용이 가능한 소셜 로봇이 등장하였다. 소셜 로봇의 개념, 특징, 시장 현황 및 전망에 대하여 설명하시오.

소셜 로봇은 AI, IoT, 클라우드를 융합하여 인간의 감정을 인식하고 자연스러운 의사소통이 가능한 대화형 로봇입니다. 음성 인식, 자연어 처리, 감정 인식, 표정 생성 기술을 결합하여 노인 돌봄, 교육, 서비스 분야에서 활용이 확대되고 있습니다. 고령화 사회와 비대면 서비스 수요 증가로 소셜 로봇 시장이 급성장하고 있으며, AI 기술 고도화로 상호작용 품질이 빠르게 향상되고 있습니다.

113회​

1교시​

  • 4.스마트 더스트(Smart Dust)

스마트 더스트는 먼지처럼 작은 초소형 센서 노드(MEMS 기술 기반)가 무선 통신으로 연결되어 광범위한 영역에서 데이터를 수집하는 기술입니다. 극소형 크기 덕분에 전장 감시, 환경 모니터링, 의료 체내 삽입 등 기존 센서로는 불가능한 영역에 적용 가능합니다. 에너지 하베스팅(빛, 진동, 열)과 초저전력 통신 기술의 발전이 스마트 더스트 상용화의 핵심 과제입니다.

  • 5.엣지 컴퓨팅(Edge Computing)

엣지 컴퓨팅은 데이터를 중앙 클라우드 서버로 보내지 않고 데이터 발생 지점(엣지)의 가까운 곳에서 처리하는 분산 컴퓨팅 패러다임입니다. 네트워크 지연(Latency) 최소화, 대역폭 절감, 데이터 프라이버시 강화, 오프라인 처리 가능이 주요 장점입니다. 자율주행, 스마트 팩토리, 실시간 AR/VR, 헬스케어 모니터링 등 초저지연이 요구되는 분야에서 필수 기술로 자리잡고 있습니다.

  • 9.디지털 트윈(Digital Twin)

디지털 트윈은 물리적 객체, 프로세스, 시스템을 실시간으로 반영하는 정밀한 가상 복제본입니다. IoT 센서 데이터를 지속적으로 수집하여 디지털 모델에 반영함으로써 실시간 모니터링, 시뮬레이션, 예측 유지보수가 가능합니다. 제조업의 생산라인 최적화, 스마트 시티 관리, 의료 장비 모니터링 등 다양한 산업에서 활용이 확대되고 있습니다.

2교시​

  • 2.자율주행자동차의 핵심 장비로 주목받고 있는 라이다(LiDAR : Light Detection and Ranging)의 연혁, 기술종류, 적용분야 및 시사점에 대하여 설명하시오.

라이다(LiDAR)는 레이저 펄스를 발사하고 반사 신호로 물체의 3D 거리와 형상을 측정하는 광학 센서 기술입니다. 기계식, 고체 상태(Solid-State), MEMS 방식으로 발전하였으며 자율주행 차량의 360도 주변 인식에 핵심적으로 사용됩니다. 카메라·레이더와 달리 야간·악천후에도 정확한 3D 포인트 클라우드를 생성할 수 있어 자율주행 안전성의 핵심 센서입니다.

118회​

1교시​

  • 4.가상공간(Cyber Space)의 특징과 디지털트윈(DigitalTwin)의 의미

사이버 공간은 컴퓨터 네트워크로 연결된 디지털 정보의 가상 공간으로, 물리적 제약 없이 정보·서비스·상호작용이 이루어지는 영역입니다. 디지털 트윈은 물리 세계의 객체를 사이버 공간에 그대로 복제한 가상 모델로, 실시간 데이터 연동을 통해 물리-가상 공간의 양방향 상호작용을 가능하게 합니다. CPS(Cyber-Physical System)의 핵심 구현 기술로서 제조, 인프라, 도시 관리 전반의 디지털 전환을 이끌고 있습니다.

  • 8.모바일 엣지 컴퓨팅(Mobile Edge Computing)

MEC(모바일 엣지 컴퓨팅)는 이동통신 기지국이나 네트워크 엣지에 컴퓨팅 자원을 배치하여 모바일 단말기의 연산을 오프로드하는 기술입니다. 5G 네트워크와 결합하여 초저지연(1ms 이하) 서비스를 실현하며 AR/VR, 자율주행, 실시간 게임 등의 응용을 지원합니다. 단말기의 배터리 소비를 줄이고 처리 능력을 확장하면서 클라우드 대비 훨씬 낮은 지연 시간을 제공합니다.

2교시​

  • 6.스마트 그리드의 개념과 핵심기술을 설명하시오.

스마트 그리드는 기존 전력망에 ICT를 융합하여 전력 생산·유통·소비를 양방향으로 실시간 모니터링하고 최적화하는 차세대 전력 인프라입니다. 신재생에너지 통합, 수요 반응(DR), 에너지 저장 시스템(ESS)을 지원하여 에너지 효율을 극대화합니다. 스마트 미터, AMI(원격 검침 인프라), 에너지 관리 시스템(EMS), 사이버 보안이 스마트 그리드의 핵심 기술입니다.

4교시​

  • 5.엣지 컴퓨팅(Edge Computing)은 소형 서버를 통해 실시간으로 처리되는 기술로 독립적인 하드웨어로 구성된다. 다음에 대하여 설명하시오.
    • 가.구성요소

엣지 컴퓨팅의 구성요소는 엣지 디바이스(센서, IoT 단말), 엣지 서버(게이트웨이, 마이크로 서버), 엣지 플랫폼(OS, 미들웨어), 네트워크 인터페이스입니다. 엣지 디바이스에서 수집한 원시 데이터를 엣지 서버에서 1차 처리하고 필요한 데이터만 클라우드로 전송하는 계층 구조를 가집니다. 각 구성요소는 독립적으로 동작 가능하여 네트워크 단절 시에도 로컬 처리를 유지합니다.

  • 나.제품 분류관점의 기반기술로 프로세서, 메모리, 플랫폼, 네트워크의 세부기술

프로세서 측면에서는 저전력 고성능 ARM SoC, AI 가속기(NPU), FPGA가 엣지 연산에 활용됩니다. 메모리는 고속 LPDDR4/5, 플래시 스토리지, 인메모리 데이터베이스가 사용되며, 플랫폼은 경량 Linux, RTOS, 컨테이너(Docker) 기반의 엣지 OS가 핵심입니다. 네트워크는 5G, Wi-Fi 6, 이더넷, LoRaWAN 등 응용 환경에 맞는 다양한 프로토콜이 사용됩니다.

  • 다.공급망 관점의 기술범위로 스마트 팩토리, 자율주행 자동차, 실시간 관리시스템, 리모트 시스템의 세부기술

스마트 팩토리에서 엣지 컴퓨팅은 생산 설비의 이상 감지와 품질 검사를 실시간으로 처리합니다. 자율주행 자동차는 엣지에서 센서 퓨전과 경로 계획을 즉시 처리하여 수십 ms 이내 응답이 필요합니다. 실시간 관리 시스템과 리모트 시스템은 네트워크 지연에 관계없이 현장에서 즉각 처리하고, 오프라인 환경에서도 독립적으로 동작합니다.

119회​

1교시​

  • 7.스마트팩토리시스템(Smart Factory System)

스마트 팩토리는 IoT, AI, 빅데이터, 사이버-물리 시스템(CPS)을 제조 공정에 통합하여 자율적으로 운영되는 지능형 생산 시스템입니다. 제품 설계부터 생산, 물류, 판매까지 전 가치사슬을 디지털화하여 생산성과 품질을 극대화하고 비용과 납기를 최적화합니다. 스마트 팩토리의 성숙도는 기초(ICT 미적용) → 중간1(ICT 일부 적용) → 중간2(ICT 통합) → 고도화(자율 운영) 4단계로 분류됩니다.

3교시​

  • 1.4차 산업의 핵심기술로 부상하고 있는 Digital Twin 기술을 활용하여 스마트 시티를 구현하려고 한다. 다음에 대하여 설명하시오.
    • 가.디지털 트윈 기술의 정의 및 역할

디지털 트윈은 물리적 도시 인프라를 실시간으로 반영하는 가상 복제본으로, IoT 센서 데이터를 지속적으로 동기화하여 현실과 동일한 디지털 모델을 유지합니다. 스마트 시티에서 디지털 트윈은 교통, 에너지, 안전, 환경 등 도시 서비스를 통합 모니터링하고 시나리오 시뮬레이션으로 의사결정을 지원합니다. 실시간 이상 감지, 재난 시뮬레이션, 인프라 예측 유지보수를 통해 도시 운영의 효율성과 안전성을 높입니다.

  • 나.디지털 트윈의 구성도 및 구축기술

디지털 트윈 구축은 물리 레이어(IoT 센서·액추에이터) → 데이터 레이어(데이터 수집·전처리) → 모델 레이어(3D 모델·시뮬레이션) → 서비스 레이어(대시보드·의사결정 지원)의 계층 구조로 이루어집니다. 구축 기술로는 IoT 플랫폼, BIM(건물 정보 모델링), GIS, 3D 시각화, AI/ML 예측 모델, 클라우드/엣지 컴퓨팅이 핵심입니다. 데이터 실시간 동기화를 위한 스트리밍 처리(Kafka, Spark Streaming)와 디지털-물리 양방향 인터페이스 설계가 중요합니다.

  • 다.디지털 트윈 적용 시 고려사항

데이터 수집·전송·저장의 보안과 개인정보보호가 핵심 고려사항으로, 대규모 IoT 환경에서 데이터 무결성 유지가 중요합니다. 물리 세계와 디지털 트윈의 실시간 동기화를 위한 데이터 품질 관리와 센서 오류 대응 체계가 필요합니다. 기존 레거시 시스템과의 통합, 표준화된 데이터 모델 적용, 그리고 디지털 트윈 확장성 확보가 장기 운영의 성공 요인입니다.

119회​

1교시​

  • 6.CPS 구축 절차

CPS(Cyber-Physical System)는 컴퓨팅과 물리 프로세스를 긴밀하게 통합하여 센싱-처리-제어 루프를 형성하는 시스템으로 스마트 팩토리, 자율주행의 기반입니다. 구축 절차는 요구사항 분석 → 물리 시스템 모델링 → 사이버 시스템 설계 → 통합 및 인터페이스 개발 → 검증·시뮬레이션 → 배포·운영의 순서로 진행됩니다. 실시간성, 신뢰성, 보안을 동시에 만족해야 하므로 형식 검증(Formal Verification)과 안전 설계(Safety-critical Design)가 필수입니다.

120회​

1교시​

  • 1.지능형 CCTV 스마트 관제

지능형 CCTV 스마트 관제는 AI(딥러닝 기반 영상 분석)를 활용하여 사람, 차량, 객체를 자동으로 탐지·추적·분류하고 이상 행동을 실시간으로 감지하는 시스템입니다. 기존 사람이 직접 모니터링하는 방식에서 AI가 자동으로 위험 상황을 감지하고 경보를 발령하는 지능화된 관제로 전환됩니다. 객체 탐지(YOLO, ResNet), 행동 인식, 이상 탐지, 얼굴 인식 등의 기술이 통합 적용됩니다.

  • 4.앰비언트 컴퓨팅(Ambient Computing)

앰비언트 컴퓨팅은 컴퓨팅 기기가 주변 환경에 자연스럽게 통합되어 사용자가 의식하지 않아도 지능적으로 서비스를 제공하는 패러다임입니다. 스마트 홈, 웨어러블, 스마트 스피커 등이 대표적 사례로, 사용자 맥락을 인식하고 선제적으로 서비스를 제공하는 것이 특징입니다. Mark Weiser의 유비쿼터스 컴퓨팅 비전의 진화로서, IoT와 AI의 융합으로 실현되고 있습니다.

6G AI-Native Network의 자율 최적화는 AI/ML이 네트워크 운영에 내재화되어 사람의 개입 없이 스스로 성능을 분석하고 최적화하는 기능입니다. 트래픽 패턴 학습, 자원 할당 자동화, 장애 예측·자가 복구를 통해 네트워크 효율을 극대화합니다. 폐쇄 루프 자동화(Closed-Loop Automation)를 통해 인지→분석→결정→실행→학습의 사이클이 자율적으로 반복됩니다.

  • 나.AI-RAN

AI-RAN(AI-Radio Access Network)은 기지국의 무선 접속 네트워크에 AI를 직접 내재화하여 빔포밍 최적화, 스펙트럼 관리, 간섭 제거를 AI로 수행하는 기술입니다. 오픈 RAN(O-RAN) 아키텍처와 결합하여 xApp, rApp 형태의 AI 애플리케이션이 RAN 지능화 컨트롤러(RIC)를 통해 기지국을 제어합니다. 6G 환경에서 테라헤르츠(THz) 주파수 대역과 초대규모 안테나(Massive MIMO) 관리를 AI로 실시간 처리하는 것이 핵심 목표입니다.

  • 다.디지털트윈 기반 네트워크 관리

디지털 트윈 기반 네트워크 관리는 실제 6G 네트워크의 가상 복제본을 구축하여 변경 사항을 실제 배포 전에 시뮬레이션하고 검증하는 방식입니다. 네트워크 디지털 트윈은 실시간 네트워크 상태를 반영하고 장애 시나리오, 트래픽 급증 대응, 소프트웨어 업데이트 영향을 미리 분석합니다. AI와 결합하여 예측적 네트워크 관리(Predictive Network Management)를 실현하고 운영 비용(OPEX)과 다운타임을 최소화합니다.
