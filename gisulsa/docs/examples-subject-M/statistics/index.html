통계/수학

정보관리기술사 기출문제 중 통계/수학 관련 문제를 정리한 페이지입니다.

110회​

3교시​

  • 3.CRC(Cyclic Redundancy Check)의 원리를 기술하고, CRC-8 = x8 + x2 + x + 1이 고 데이터워드가 01101011일때 코드워드를 계산하는 과정을 설명하고, 그 결과가 옳음을 검증하시오.

CRC는 데이터 전송 오류를 검출하기 위해 데이터를 생성 다항식으로 나눈 나머지를 체크 값으로 사용하는 오류 검출 기법입니다. 송신 측은 데이터에 CRC 비트를 덧붙여 전송하고, 수신 측은 동일한 다항식으로 나눠 나머지가 0인지 확인하여 오류를 검출합니다. CRC-8 생성 다항식 x⁸+x²+x+1은 이진수 100000111로 표현되며, 데이터워드 뒤에 8비트 0을 덧붙인 후 모듈로-2 나눗셈을 수행합니다.

111회​

1교시​

  • 1.통계적 가설 검정(Statistical Hypothesis Testing)과 p-value

가설 검정은 표본 데이터를 바탕으로 모집단에 대한 귀무가설(H₀)을 기각할 충분한 근거가 있는지 판단하는 통계적 절차입니다. p-value는 귀무가설이 참일 때 관측된 결과 또는 그보다 극단적인 결과가 나올 확률로, 낮을수록 귀무가설을 기각하는 증거가 강합니다. 일반적으로 p-value가 유의수준(α=0.05)보다 작으면 귀무가설을 기각하고 대립가설을 채택합니다.

4교시​

  • 1.데이터 분석의 분류 모델에서 모델 평가 시 사용되는 혼동행렬(Confusion Matrix)에 대하여 설명하고, 혼동행렬 기반의 모델 성능평가 항목을 산식을 이용하여 설명하시오.

혼동행렬은 분류 모델의 예측 결과를 실제 값과 비교하여 TP, FP, FN, TN의 4가지 경우로 정리한 행렬입니다. 정확도(Accuracy) = (TP+TN)/(TP+FP+FN+TN), 정밀도(Precision) = TP/(TP+FP), 재현율(Recall) = TP/(TP+FN)으로 계산합니다. F1-Score는 정밀도와 재현율의 조화 평균으로 불균형 데이터 평가에 특히 유용합니다.

113회​

3교시​

  • 2.동일한 규격의 제품이 B공장에서 생산될 때 A공장에서 생산될 때 제품의 무게가 더 적다고 주장하고 있다. 이를 확인하기 위하여 아래 표와 같이 제품을 랜덤하게 뽑아 조사하였다. A와 B 공장의 제품 무게는 모두 정규 분포로 가정하여 A공장 제품이 B공장 제품에 비하여 무게가 적다고 할 수 있는지 가설을 설정하고 검정하시오.(단, 유의수준 5%)

귀무가설 H₀: μA ≥ μB (A공장 무게가 B공장 이상), 대립가설 H₁: μA < μB (A공장 무게가 더 적음)로 설정합니다. 두 독립 표본의 평균 차이 검정을 위해 t-검정 또는 z-검정을 적용하며, 표본 분산이 알려진 경우 z-검정을 사용합니다. 계산된 검정 통계량이 유의수준 5% 단측 임계값보다 작으면 H₀를 기각하여 A공장 무게가 더 적다는 결론을 내립니다.

4교시​

  • 4.시계열분석에 관한 다음 사항에 대하여 답하시오.
    • 가.시계열분석의 정상성(Stationary)

정상성(Stationarity)은 시계열 데이터의 평균, 분산, 자기공분산이 시간에 따라 일정하게 유지되는 통계적 특성입니다. 대부분의 시계열 모형(ARIMA 등)은 정상성 가정을 전제로 하므로 분석 전 정상성 검정이 필수적입니다. ADF(Augmented Dickey-Fuller) 검정으로 정상성을 확인하고, 비정상 시계열은 차분(Differencing)이나 로그 변환으로 정상화합니다.

  • 나.시계열모형의 유형(자기상관 모형, 이동평균 모형, 자기회귀누적이동평균 모형)

AR(자기회귀) 모형은 과거 자신의 값으로 현재 값을 예측하며, MA(이동평균) 모형은 과거 오차항의 선형 결합으로 현재 값을 표현합니다. ARIMA(자기회귀누적이동평균) 모형은 AR, 차분(I), MA를 결합한 모형으로 비정상 시계열도 처리 가능합니다. ARIMA(p, d, q)에서 p는 AR 차수, d는 차분 횟수, q는 MA 차수를 의미합니다.

  • 다.빅데이터의 시계열자료 분석을 위한 심층신경망 기법

빅데이터 시계열 분석에는 순환신경망(RNN), LSTM(Long Short-Term Memory), Transformer 기반 모델이 주로 사용됩니다. LSTM은 장기 의존성 문제를 해결하는 게이트 메커니즘을 갖춰 금융, 기상, 트래픽 예측에 효과적입니다. Transformer의 자기주의(Self-Attention) 메커니즘은 병렬 처리 능력으로 긴 시계열에서도 뛰어난 성능을 발휘합니다.

1교시​

  • 10.F1 Score에서 정밀도(Precision), 재현율(Recall)

정밀도(Precision)는 양성으로 예측한 것 중 실제 양성의 비율로 TP/(TP+FP)이며, 거짓 경보(False Alarm)를 최소화하는 지표입니다. 재현율(Recall)은 실제 양성 중 양성으로 예측한 비율로 TP/(TP+FN)이며, 실제 양성을 놓치지 않는 것이 중요할 때 사용합니다. F1-Score는 정밀도와 재현율의 조화 평균 2×(P×R)/(P+R)으로 두 지표의 균형을 반영합니다.

3교시​

  • 5.대기행렬이론(Queuing Theory)의 개념과 처리 기법에 대하여 설명하시오.

대기행렬이론은 서비스를 받기 위해 대기하는 시스템의 성능을 수학적으로 분석하는 이론으로 운영 연구(OR)의 핵심 분야입니다. 도착률(λ), 서비스율(μ), 서버 수, 대기 공간, 도착 분포 등의 파라미터로 시스템을 모델링하여 평균 대기 시간, 큐 길이, 서버 이용률을 계산합니다. M/M/1 모형(포아송 도착, 지수 서비스, 단일 서버)이 기본 모형이며, 이를 확장한 M/M/c(복수 서버), M/G/1 등이 활용됩니다.

1교시​

  • 4.통계적 가설검정의 1차오류와 2차오류

1종 오류(α 오류)는 귀무가설(H₀)이 참임에도 기각하는 오류로 '거짓 양성(False Positive)'이라 하며, 유의수준 α로 통제합니다. 2종 오류(β 오류)는 귀무가설이 거짓임에도 기각하지 못하는 오류로 '거짓 음성(False Negative)'이라 합니다. 1종 오류를 줄이면 2종 오류가 증가하는 상충 관계가 있으며, 검정력(1-β)을 높이려면 표본 크기를 늘려야 합니다.

1교시​

  • 6.통계적 가설 검정(Statistical Hypothesis Test)의 절차

통계적 가설 검정은 귀무가설·대립가설 설정 → 유의수준 결정 → 검정 통계량 선택 → 표본 수집 및 통계량 계산 → p-value 산출 → 기각 여부 결정의 절차로 진행됩니다. 단측 검정(한쪽 방향)과 양측 검정(양쪽 방향)을 연구 목적에 맞게 선택해야 합니다. 통계적 유의성은 실용적 유의성과 다를 수 있으므로 효과 크기(Effect Size)도 함께 보고하는 것이 권장됩니다.

  • 6.대기행렬시스템(Queue System)의 개념을 설명하고, 처리 기법을 예를 들어 설명하시오.

대기행렬 시스템은 고객(작업)이 서비스 시설에 도착하여 대기하고 서비스를 받는 과정을 모델링하는 시스템입니다. 은행 창구, 콜센터, 네트워크 라우터, 프린터 스풀러 등 다양한 실제 시스템이 대기행렬 모델로 분석됩니다. 켄달 표기법(A/B/c/K/N)으로 도착 분포, 서비스 분포, 서버 수, 최대 큐 용량, 모집단 크기를 정의합니다.

3교시​

  • 3.기술통계와 추론통계에 대하여 설명하시오.
    • 가.기술통계와 추론통계의 차이점 비교

기술통계(Descriptive Statistics)는 수집된 데이터 자체를 요약·정리하여 특성을 파악하는 통계로 모집단 추론 없이 데이터를 설명합니다. 추론통계(Inferential Statistics)는 표본 데이터로부터 모집단의 특성을 추정하고 가설을 검정하는 통계로 확률 이론에 기반합니다. 기술통계가 현재 데이터의 '무엇'을 기술한다면, 추론통계는 모집단의 '어떠할 것인가'를 추론합니다.

  • 나.기술통계와 추론통계에 사용되는 기술(각각 4개만 쓰시오.)

기술통계 기술로는 평균(Mean), 중앙값(Median), 표준편차(Standard Deviation), 상관계수(Correlation Coefficient)가 대표적입니다. 추론통계 기술로는 t-검정(T-test), 분산분석(ANOVA), 회귀분석(Regression), 카이제곱 검정(Chi-square Test)이 주요 기법입니다. 두 분야의 기술은 상호 보완적으로 사용되어 데이터에서 의미 있는 인사이트를 도출합니다.

4교시​

  • 3.한 공장에서 스마트 팩토리(Smart Factory) 적용을 통한 생산시간 단축을 확인하려고 한다. 기존 공정에서의 제품 생산시간이 정규분포를 따르며 평균이 30분, 표준 편차가 5분인 것으로 알려져 있다. 스마트 팩토리가 적용된 공정의 제품에 대한 생산시간을 49개 랜덤 추출하여 관측한 결과 평균이 28.5분이었다. 스마트 팩토리가 적용된 공정의 생산시간이 표준편차가 5분인 정규분포를 따른다고 할 때, 스마트 팩토리를 통해 생산시간이 단축되었는지 가설을 설정하고 검정하시오. (단, 유의수준 5%, Z 0.005=1.645)

귀무가설 H₀: μ ≥ 30 (생산시간 단축 없음), 대립가설 H₁: μ < 30 (생산시간 단축됨)으로 설정하는 단측 검정입니다. 검정 통계량 Z = (28.5 - 30) / (5/√49) = -1.5/0.714 ≈ -2.10을 계산합니다. Z = -2.10이 임계값 -1.645보다 작으므로 H₀를 기각하여 유의수준 5%에서 스마트 팩토리가 생산시간을 단축시켰다고 결론 내릴 수 있습니다.

1교시​

  • 1.정규분포 특징

정규분포는 평균을 중심으로 좌우 대칭인 종 모양(Bell Curve) 확률 분포로, 평균=중앙값=최빈값이 일치합니다. 평균±1σ 내 68.27%, ±2σ 내 95.45%, ±3σ 내 99.73%의 데이터가 포함되는 경험칙이 특징입니다. 중심극한정리에 의해 표본 크기가 충분히 크면 모집단의 분포와 무관하게 표본 평균이 정규분포에 근사하여 통계 추론의 기반이 됩니다.

1교시​

  • 3.추정통계의 표본과 불편 추정량

표본(Sample)은 모집단에서 추출한 일부 데이터로, 모집단의 특성을 추정하기 위한 관측값의 집합입니다. 불편 추정량(Unbiased Estimator)은 모수(모집단 파라미터)를 추정할 때 추정량의 기댓값이 모수와 일치하는 추정량입니다. 표본 평균은 모평균의 불편 추정량이고, 표본 분산은 n-1로 나누어야(Bessel's correction) 모분산의 불편 추정량이 됩니다.

2교시​

  • 1.중심극한정리, t-검정, z-검정을 설명하시오.

중심극한정리는 모집단 분포에 관계없이 표본 크기 n이 충분히 크면(n≥30) 표본 평균의 분포가 정규분포에 근사한다는 정리입니다. z-검정은 모분산을 알거나 표본 크기가 클 때 사용하며 표준 정규분포 Z~N(0,1)를 사용합니다. t-검정은 모분산을 모르고 표본 크기가 작을 때 사용하며 자유도(n-1)를 가진 t-분포를 사용합니다.

3교시​

  • 3.다음과 같이 형태소 분석을 통하여 문서별로 단어의 횟수가 식별되었다. 각 문서의 TFIDF(Term Frequency Inverse Document Frequency)를 식별하기 위한 계산 과정과 그 결과를 설명하시오.

TF(단어 빈도)는 특정 문서 내에서 단어가 등장하는 빈도로, 문서 내 해당 단어 출현 횟수를 전체 단어 수로 나눈 값입니다. IDF(역문서 빈도)는 전체 문서 수를 해당 단어가 등장한 문서 수로 나눈 로그값으로, 여러 문서에 공통 등장하는 단어의 중요도를 낮춥니다. TF-IDF = TF × IDF로 계산되며 문서에서 특정 단어의 상대적 중요도를 정량화하는 데 사용됩니다.

2교시​

  • 3.회귀모형에서 오차의 등분산성(Homoscedasticity)과 다중공선성(Multicollinearity)에 대하여 설명하시오.

등분산성(Homoscedasticity)은 회귀 모형의 잔차(오차)가 독립변수 값에 관계없이 일정한 분산을 가져야 한다는 가정입니다. 등분산성이 위반되면(이분산성) OLS 추정량은 불편이지만 최소분산(Best)이 아니게 되어 표준 오차가 왜곡됩니다. 다중공선성은 독립변수 간 강한 선형 관계가 존재할 때 발생하며 VIF(분산 팽창 계수) 10 이상이면 심각한 문제로 간주합니다.

4교시​

  • 3.이항 분포(Binomial Distribution)와 포아송 분포(Poisson Distribution)를 비교 설명하시오.

이항 분포는 성공 확률 p인 독립 시행을 n번 반복했을 때 성공 횟수 X의 분포로 B(n, p)로 표기합니다. 포아송 분포는 단위 시간·공간에서 평균 λ번 발생하는 희귀 사건의 발생 횟수 분포로, n이 크고 p가 매우 작을 때 이항 분포의 근사로 사용됩니다. n→∞, p→0이고 λ=np가 일정할 때 이항 분포는 포아송 분포 Po(λ)에 수렴합니다.

136회​

3교시​

  • 5.혼동행렬(Confusion Matrix) 결과를 참고하여 다음을 계산하고 설명하시오.
    • 결과: True Positive(TP)=100, False Positive(FP)=5, False Negative(FN)=7, True Negative(TN)=9
    • 가.혼동행렬을 사용한 모델의 성능 평가 원리

혼동행렬은 분류 모델의 예측과 실제 결과를 4가지 범주(TP, FP, FN, TN)로 분류하여 성능을 다각도로 평가하는 도구입니다. 단순 정확도만으로는 클래스 불균형 상황에서 성능을 왜곡할 수 있어 정밀도, 재현율, F1-Score 등 다양한 지표를 함께 사용합니다. 어떤 오류(FP vs FN)를 더 용납할 수 있는지 비즈니스 맥락에 따라 최적 임계값을 조정합니다.

  • 나.정확도, 정밀도, 재현율 계산 결과와 해석

정확도(Accuracy) = (100+9)/(100+5+7+9) = 109/121 ≈ 90.1%로 전체 예측 중 올바른 비율입니다. 정밀도(Precision) = 100/(100+5) = 100/105 ≈ 95.2%로 양성 예측 중 실제 양성 비율입니다. 재현율(Recall) = 100/(100+7) = 100/107 ≈ 93.5%로 실제 양성 중 올바르게 탐지한 비율이며, 세 지표 모두 높아 양호한 모델로 평가됩니다.

  • 다.F1-score 계산 결과와 해석

F1-Score는 정밀도와 재현율의 조화 평균으로 2×(P×R)/(P+R)로 계산합니다. F1 = 2×(0.952×0.935)/(0.952+0.935) = 2×0.890/1.887 ≈ 0.943 (94.3%)입니다. F1-Score 94.3%는 정밀도와 재현율이 모두 균형 있게 높음을 나타내며, 특히 클래스 불균형 상황에서도 신뢰할 수 있는 성능 지표입니다.

1교시​

  • 4.베이즈 정리

베이즈 정리는 사전 확률(Prior)과 우도(Likelihood)를 결합하여 사후 확률(Posterior)을 계산하는 조건부 확률 법칙입니다. P(A|B) = P(B|A)×P(A)/P(B)로 표현되며, 새로운 증거(B)를 통해 기존 믿음(A에 대한 확률)을 갱신합니다. 스팸 필터, 의료 진단, 나이브 베이즈 분류기, 베이지안 최적화 등 AI·데이터 분석에서 광범위하게 활용됩니다.

  • 7.자기회귀모형(Autoregressive model)과 이동평균모형(Moving Average model)

AR(자기회귀) 모형은 현재 시점의 값을 과거 p시점의 값들의 선형 결합으로 표현하며 AR(p)로 표기합니다. MA(이동평균) 모형은 현재 시점의 값을 과거 q시점의 오차항들의 선형 결합으로 표현하며 MA(q)로 표기합니다. 두 모형은 ACF(자기상관함수)와 PACF(편자기상관함수)의 패턴으로 구별되며, 함께 결합하면 ARMA(p,q) 모형이 됩니다.
