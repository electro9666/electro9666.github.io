문제 1) 빅데이터 분석기법 - 클러스터링, 필터링, 이상치 탐지

답)

I. 개요​

빅데이터 분석은 대용량·다양·고속의 데이터로부터 의미 있는 패턴과 인사이트를 추출하는 과정이다. 대표적 분석기법으로 유사 데이터를 군집화하는 클러스터링(Clustering), 사용자·콘텐츠 기준으로 정보를 선별·추천하는 필터링(Filtering), 정상 패턴에서 벗어난 데이터를 식별하는 **이상치 탐지(Anomaly Detection)**가 있으며, 분석 목적에 따라 상호 보완적으로 활용된다.

분석기법학습 유형목적대표 알고리즘
클러스터링비지도 학습유사 데이터 군집화K-means, 계층적, DBSCAN
필터링지도/비지도 혼합정보 선별 및 추천협업 필터링, 내용기반 필터링
이상치 탐지비지도/준지도비정상 데이터 식별Z-score, LOF, Isolation Forest

II. 클러스터링(Clustering)​

1. 개념​

레이블 없는 데이터를 유사도(거리)에 기반하여 동질적 그룹(군집)으로 분할하는 비지도 학습 기법. 군집 내 응집도(Cohesion)는 높이고 군집 간 분리도(Separation)는 높이는 것이 목표다.

2. 주요 알고리즘​

가. K-means (분할 기반)​

데이터를 사전 지정한 K개 군집으로 분할하며, 각 데이터를 가장 가까운 중심점에 할당하고 중심을 재계산하는 과정을 반복한다. 목적함수는 군집 내 제곱오차합(SSE)을 최소화한다.

J=∑i=1K∑x∈Ci∥x−μi∥2J = \sum_{i=1}^{K} \sum_{x \in C_i} \lVert x - \mu_i \rVert^2J=∑i=1K​∑x∈Ci​​∥x−μi​∥2

  • CiC_iCi​: i번째 군집, μi\mu_iμi​: 군집 중심(centroid)
  • 최적 K 결정: 엘보우 기법(Elbow Method), 실루엣 계수(Silhouette Coefficient)
# K-means 의사코드
def kmeans(X, K, max_iter):
    centroids = random_init(X, K)      # 중심 초기화
    for _ in range(max_iter):
        labels = assign_nearest(X, centroids)   # 최근접 할당
        new_centroids = mean_by_label(X, labels) # 중심 재계산
        if converged(centroids, new_centroids):  # 수렴 판정
            break
        centroids = new_centroids
    return labels, centroids

나. 계층적 클러스터링(Hierarchical Clustering)​

군집 간 거리를 기준으로 트리(덴드로그램)를 구성하는 기법. 사전에 K를 정할 필요가 없다.

연결 기법군집 간 거리 정의특징
단일연결(Single)두 군집 간 최소 거리체인 현상 발생
완전연결(Complete)두 군집 간 최대 거리조밀한 군집 형성
평균연결(Average)모든 쌍 거리의 평균균형적
Ward병합 시 SSE 증가 최소화크기 균등 군집

다. DBSCAN (밀도 기반)​

데이터 밀도가 높은 영역을 군집으로 식별하고, 저밀도 영역의 데이터를 잡음(Noise)으로 처리하는 기법. 임의 형태의 군집과 이상치를 동시에 탐지할 수 있다.

  • 핵심 파라미터: 반경 EpsEpsEps(ε\varepsilonε), 최소 이웃 수 MinPtsMinPtsMinPts
  • 장점: K 사전 지정 불필요, 비구형 군집 탐지, 잡음 자동 분리
  • 단점: 밀도 편차가 큰 데이터에 취약, 파라미터 민감

III. 필터링(Filtering)​

1. 개념​

대량의 데이터에서 사용자에게 적합하거나 분석에 유효한 정보를 선별하는 기법. 추천 시스템의 핵심 기술인 추천 필터링과 데이터 전처리 단계의 데이터 필터링으로 구분된다.

2. 추천 필터링​

가. 협업 필터링(Collaborative Filtering)​

사용자 또는 아이템 간 유사도를 기반으로, 유사 사용자의 선호나 함께 소비된 아이템 패턴으로 추천하는 기법.

  • 유사도 측정: 코사인 유사도, 피어슨 상관계수
  • 행렬 분해: 사용자-아이템 평점 행렬을 잠재 요인(Latent Factor) 행렬로 분해

r^ui=μ+bu+bi+qiTpu\hat{r}_{ui} = \mu + b_u + b_i + q_i^T p_ur^ui​=μ+bu​+bi​+qiT​pu​

나. 내용기반 필터링(Content-based Filtering)​

아이템의 속성(콘텐츠 특징)과 사용자가 과거 선호한 아이템의 프로파일 유사도를 기반으로 추천하는 기법.

다. 협업 vs 내용기반 비교​

구분협업 필터링내용기반 필터링
기준사용자-아이템 상호작용아이템 속성/콘텐츠
콜드스타트신규 사용자/아이템 취약신규 사용자만 취약
다양성의외성(Serendipity) 높음유사 아이템에 편중
도메인 지식불필요특징 추출 필요
확장성데이터 희소성 문제상대적 안정
보완책하이브리드 필터링으로 상호 단점 보완하이브리드 필터링

3. 데이터 필터링​

데이터 전처리 단계에서 잡음 제거, 결측치 처리, 조건 기반 추출을 수행하는 기법.

유형설명예시
잡음 필터링신호 잡음 제거이동평균, 칼만 필터
콘텐츠 필터링유해/스팸 콘텐츠 차단베이지안 스팸 필터
조건 필터링특정 조건 데이터 추출SQL WHERE, 슬라이딩 윈도우
블룸 필터집합 존재 여부 확률적 판정중복 제거, 캐시

IV. 이상치 탐지(Anomaly Detection)​

1. 개념​

정상 데이터의 패턴에서 통계적·구조적으로 벗어난 데이터(이상치, Outlier)를 식별하는 기법. 사기 탐지, 장애 예측, 침입 탐지 등에 활용된다.

2. 통계 기반 탐지​

데이터 분포를 가정하고 통계량에서 임계치를 벗어난 값을 이상치로 판정.

기법원리판정 기준
Z-score정규분포 표준화∣Z∣>3\lvert Z \rvert > 3∣Z∣>3
IQR사분위 범위 활용Q1−1.5⋅IQRQ1 - 1.5 \cdot IQRQ1−1.5⋅IQR 미만 또는 Q3+1.5⋅IQRQ3 + 1.5 \cdot IQRQ3+1.5⋅IQR 초과
Grubbs 검정단일 이상치 가설검정검정통계량 임계값 초과

Z=x−μσ,IQR=Q3−Q1Z = \frac{x - \mu}{\sigma}, \qquad IQR = Q3 - Q1Z=σx−μ​,IQR=Q3−Q1

3. 거리/밀도 기반 탐지​

데이터 간 거리 또는 국소 밀도를 기준으로 고립된 데이터를 이상치로 판정.

기법특징장단점
KNNk번째 최근접 이웃 거리단순, 고차원 취약
LOF국소 밀도 상대비교밀도 편차 대응, 계산 비용
마할라노비스변수 상관관계 반영다변량 적합, 공분산 추정 필요

4. 모델 기반 탐지​

가. Isolation Forest​

이상치는 정상치보다 적은 분할로 쉽게 고립된다는 원리를 활용. 무작위 분할 트리를 다수 구성하여 데이터의 평균 경로 길이로 이상 점수를 산출한다.

s(x,n)=2−E[h(x)]c(n)s(x, n) = 2^{-\frac{E[h(x)]}{c(n)}}s(x,n)=2−c(n)E[h(x)]​

  • E[h(x)]E[h(x)]E[h(x)]: 평균 경로 길이, c(n)c(n)c(n): 정규화 상수
  • 점수 sss가 1에 가까울수록 이상치, 0.5 부근은 정상

나. 기타 모델 기반 기법​

기법원리적용

V. 분석기법 통합 활용 및 상호 연계​

활용 분야클러스터링필터링이상치 탐지
금융고객 세분화상품 추천사기 거래 탐지
제조공정 그룹화센서 데이터 선별설비 이상 예지
보안트래픽 군집화로그 필터링침입 탐지
커머스구매 패턴 군집상품 추천어뷰징 탐지

결론​

빅데이터 분석기법인 클러스터링, 필터링, 이상치 탐지는 각각 데이터 구조화, 정보 선별, 비정상 식별이라는 고유 목적을 가지며, 실무에서는 전처리(필터링)→군집화(클러스터링)→이상 식별(이상치 탐지)의 파이프라인으로 연계하여 가치를 극대화한다.

정보관리기술사 관점에서는 단일 알고리즘의 정확도보다 데이터 특성(분포, 차원, 규모)과 비즈니스 목적에 부합하는 기법 선정, 그리고 분석 결과의 설명가능성(Explainability)과 운영 자동화(MLOps) 연계가 성공적 빅데이터 활용의 핵심이다. 특히 이상치 탐지는 오탐(False Positive)과 미탐(False Negative)의 균형을 비즈니스 비용 관점에서 조율하는 거버넌스 체계가 동반되어야 한다.
