139회 정보관리기술사(139M) 기출 이유 분석

질문: original내에서 READMD.md를 참고하고, 110M.md ~ 138M.md, 110C.md ~ 138C.md를 분석해서 139M.md의 문제들이 기출된 이유를 추측하라. 문제별로 정리해서 md로 생성

139회(2026.5.16) 정보관리기술사 문제가 출제된 이유를 110~138회 M/C 기출 패턴을 기반으로 추측한다.

1교시 (단답형)​

1_1. WBS(Work Breakdown Structure) 작성방법​

출제 추측 이유: 프로젝트 관리 핵심 주제의 직접적 재출제

회차시험관련 기출

129M2_2WBS 작성 원칙, 장점, 고려사항
  • 128M(2022) 단답형 → 129M(2023) 서술형 → 139M(2026) 다시 단답형 "작성방법" 출제
  • PMBOK 10대 지식영역(범위관리)의 핵심인 WBS는 정보관리기술사의 단골 출제 주제
  • 138M 1_2 프로젝트 위험관리, 139M 1_4 부정적 위험과 같은 흐름으로 PM 영역 단답형 반복 출제

139회의 특징​

  1. AI/LLM이 압도적 핵심 테마: AI 리스크, RAG, Fine-tuning, MAS, AI 학습 데이터 등 AI 관련 6문제(약 23%) 출제
  2. 138회의 흐름 강력 계승: 138M(AI RMF, 위험관리, PET)에 이어 AI 리스크/데이터 보호로 연속 출제
  3. 138C → 139M 교차 출제 활발: 138C의 가상메모리(→4_4), 동기화(→4_2)가 즉시 139M에서 출제
  4. 양자 기술 동시 출제: QML(1_12)과 TurboQuant(2_4)가 같은 시험에 출제 → 양자 + AI 융합 트렌드
  5. 데이터 영역 폭발적 출제: 분산 DB 투명성, 데이터 레이크, 데이터 가치평가, 이상치/편향, 데이터 품질, 빅데이터 분석기법 → 데이터 관련 다수 출제
  6. 공공 부문 가용성 강조: 공공 SLA(2_5), 데이터센터 지리적 위치(4_3) → 행정·공공기관 장애 사회적 이슈 반영
  7. 시점 특화 법/제도: 2026년 전자정부법 개정 및 2027년 의무화 반영
  8. 테스트 영역 정확한 반복: 3_4 소프트웨어 테스트(7대 원리+화이트/블랙박스+동등분할/경계값)가 134M, 137M 흐름 그대로 재출제
