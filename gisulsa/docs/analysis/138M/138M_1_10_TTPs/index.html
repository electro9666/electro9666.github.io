문제 10) TTPs(Tactics, Techniques and Procedures)

답)

I. 개요​

1. 정의​

**TTPs(Tactics, Techniques and Procedures)**란 사이버 위협 행위자(Threat Actor)가 공격 목표를 달성하기 위해 사용하는 행동 패턴을 3계층으로 구조화한 사이버 보안 핵심 개념이다.

2. 계층별 정의​

계층영문정의추상화 수준
Tactics전술공격자가 달성하려는 목적(Why)최상위 (추상적)
Techniques기법전술 목적을 달성하기 위한 방법(How)중간
Procedures절차기법의 구체적 실행 방법(What)최하위 (구체적)

3. 등장 배경​

기존 IOC(Indicators of Compromise) 방어의 한계:

  • IP, 도메인, 파일 해시 등 IOC는 공격자가 쉽게 변경 가능
  • TTPs는 변경 비용이 높아 더 지속적인 탐지 기반 제공
  • 피라미드 오브 페인(Pyramid of Pain): IOC보다 TTPs 탐지가 공격자에게 더 큰 고통

II. Tactics(전술)​

1. 정의​

전술은 공격자가 달성하려는 **전술적 목표(Why)**로, 공격의 단계별 의도를 나타낸다.

2. MITRE ATT&CK 14개 전술 (Enterprise)​

ID전술명설명예시
TA0001Initial Access (초기 접근)네트워크 진입피싱, 취약한 서비스 악용
TA0002Execution (실행)악성 코드 실행PowerShell, 스크립트 실행
TA0003Persistence (지속성)재접근 유지레지스트리 수정, 예약 작업
TA0004Privilege Escalation (권한 상승)상위 권한 획득취약점 익스플로잇
TA0005Defense Evasion (방어 회피)탐지 우회로그 삭제, 난독화

TA0009Collection (수집)데이터 수집키로깅, 스크린샷

TA0043Reconnaissance (정찰)사전 정보 수집OSINT, 스캐닝

기법은 전술 목표를 달성하기 위한 **구체적인 방법(How)**으로, ATT&CK에서 수백 가지 기법이 정의되어 있다.

IV. Procedures(절차)​

1. 정의​

절차는 특정 위협 행위자나 악성코드가 기법을 실행하는 **구체적인 방법(What)**으로, 실제 공격에서 관찰된 세부 행동이다.

2. 전술-기법-절차 계층 예시​

전술 (Tactic): TA0006 - Credential Access (자격증명 탈취)
└── 기법 (Technique): T1003 - OS Credential Dumping
    └── 하위기법: T1003.001 - LSASS Memory
        └── 절차 (Procedure):
            APT29가 Mimikatz를 사용하여 LSASS 프로세스 메모리를
            덤프한 후 평문 자격증명 및 NTLM 해시 추출:

            sekurlsa::logonpasswords
            sekurlsa::wdigest

VI. 활용 방안​

1. 위협 인텔리전스(Threat Intelligence)에서의 활용​

2. 침해사고 분석(Incident Response)에서의 활용​

단계TTPs 활용 방법
탐지 (Detection)ATT&CK 기반 SIEM/EDR 탐지 룰 구성
분석 (Analysis)관찰된 행위를 ATT&CK 기법으로 매핑하여 공격 체인 재구성
귀속 (Attribution)TTPs 패턴으로 APT 그룹 식별 (핑거프린팅)
복구 (Recovery)확인된 TTPs 기반 잔존 위협 제거
사후 조치 (Lessons Learned)탐지되지 않은 TTPs 분석, 방어 gap 보완

3. SOC(보안운영센터) 탐지 룰 개발​

# SIEM 탐지 룰 예시 - T1059.001 PowerShell 난독화 탐지
# (Splunk SPL 형식)

index=windows_events EventCode=4104
| where like(ScriptBlockText, "%FromBase64String%")
   OR like(ScriptBlockText, "%-enc%")
   OR like(ScriptBlockText, "%-EncodedCommand%")
| eval TTP="T1059.001 - PowerShell"
| eval Tactic="TA0002 - Execution"
| stats count by Computer, User, TTP, Tactic
| where count > 3
| alert "PowerShell 난독화 실행 탐지"
# SIGMA 룰 - ATT&CK 매핑 포함
title: PowerShell Encoded Command Execution
id: f62176f3-8128-4c92-b652-d01d3523b4e5
status: stable
description: Detects PowerShell with encoded command parameter
tags:
  - attack.execution
  - attack.t1059.001          # ATT&CK 기법 태깅
logsource:
  product: windows
  service: powershell
detection:
  selection:
    EventID: 4104
    ScriptBlockText|contains:
      - '-EncodedCommand'
      - '-enc '
      - 'FromBase64String'
condition: selection
falsepositives:
  - Legitimate administrative scripts
level: medium

VIII. 전망 및 결론​

1. TTPs 기반 방어의 발전 방향​

구분현재미래
탐지규칙 기반 TTPs 매핑AI/ML 기반 행위 분석 자동화
대응수동 플레이북 실행SOAR 기반 자동화 대응
공유사후 인텔리전스 공유실시간 TTPs 협업 공유
범위엔터프라이즈 중심OT/ICS, 클라우드, AI 시스템 확장

2. 결론​

TTPs는 사이버 보안에서 공격자의 행동 패턴을 체계적으로 이해하고 방어하기 위한 핵심 언어다.

핵심 요약내용
Tactics공격자의 전술적 목표(Why) - ATT&CK 14개 전술
Techniques목표 달성 방법(How) - 200+ 기법, 400+ 하위기법
Procedures구체적 실행 절차(What) - APT별 고유 행동 패턴
ATT&CK 연계전 세계 표준 TTPs 지식베이스로 활용
활용 가치IOC보다 지속적이고 효과적인 위협 탐지 기반

기술사 관점: TTPs는 단순한 기술 분류가 아니라 위협 인텔리전스 기반 사이버 방어 전략의 핵심 프레임워크다. MITRE ATT&CK과 결합하여 레드팀/블루팀 훈련, SOC 탐지 룰 개발, 침해사고 분석, 위협 귀속(Attribution)에 이르는 보안 운영 전 영역에서 공통 언어로 활용되며, 현대 사이버 보안 거버넌스의 필수 요소로 자리잡았다.
