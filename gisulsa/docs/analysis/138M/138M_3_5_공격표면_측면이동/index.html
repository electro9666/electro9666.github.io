문제 5) IT 인프라 확장에 따른 사이버 위협 - 공격 표면과 측면 이동

답)

개요​

클라우드, IoT, 원격근무 확산으로 IT 인프라가 급격히 확장되면서 사이버 위협의 범위와 복잡성이 증가하고 있다. 공격자는 확장된 공격 표면을 통해 침투한 후 측면 이동으로 권한을 확대하여 핵심 자산을 탈취한다. 이를 이해하고 대응하기 위해 MITRE ATT&CK 프레임워크와 사이버 킬체인 관점에서 분석한다.

가. 공격 표면(Attack Surface)과 공격 벡터(Attack Vector)​

1. 공격 표면 (Attack Surface)​

개념​

공격자가 시스템에 접근하거나 데이터를 탈취할 수 있는 모든 잠재적 진입점(Entry Point)과 취약점의 총합. 공격 표면이 클수록 보안 위험이 증가한다.

공격 표면 분류​

IT 인프라 확장에 따른 공격 표면 증가​

인프라 변화공격 표면 증가 요인
클라우드 마이그레이션잘못 구성된 S3 버킷, IAM 권한 과잉, 퍼블릭 API
원격 근무 확산VPN 취약점, 홈 네트워크, 개인 디바이스(BYOD)
IoT 기기 급증취약한 펌웨어, 하드코딩된 패스워드, 패치 미적용
마이크로서비스서비스 간 API, 컨테이너 탈출, 서비스 메시 취약점
서드파티 통합공급망 소프트웨어(SolarWinds형), 오픈소스 취약점
코드형 인프라IaC 설정 오류, 시크릿 노출, Git 레포지토리 유출

공격 표면 관리 (ASM: Attack Surface Management)​

ASM 구성요소도구/기술목적
외부 공격 표면 관리Shodan, Censys, ASM 플랫폼외부 노출 자산 식별
취약점 스캐닝Nessus, Qualys, OpenVAS알려진 취약점 탐지
클라우드 보안 태세CSPM (Prisma, Wiz)클라우드 설정 오류 탐지
코드 보안SAST, SCA, Secret 스캔코드 레벨 취약점
다크웹 모니터링위협 인텔리전스유출 자격증명 탐지

2. 공격 벡터 (Attack Vector)​

개념​

공격자가 공격 표면에 접근하기 위해 사용하는 구체적인 경로나 방법. CVSS(Common Vulnerability Scoring System)에서 공격 벡터는 취약점의 심각도를 평가하는 주요 기준이다.

CVSS 공격 벡터 분류​

공격 벡터설명CVSS 점수 영향
네트워크 (N)원격에서 인터넷/네트워크 통해 공격가장 높은 위험
인접 네트워크 (A)동일 네트워크 세그먼트 내 공격높은 위험
로컬 (L)로컬 접근 필요중간 위험
물리적 (P)물리적 접촉 필요낮은 위험

주요 공격 벡터 유형​

공격 벡터기법MITRE ATT&CK ID
피싱 이메일스피어피싱 첨부파일, 링크T1566
공개 취약점웹 앱, VPN, RDP 취약점 익스플로잇T1190
자격증명 탈취크리덴셜 스터핑, 브루트포스T1110
공급망 공격소프트웨어 업데이트 조작T1195
물리적 미디어USB 드롭 공격, HID 어택T1091
신뢰 관계 악용파트너사 시스템 통해 침투T1199
워터링홀사용자 방문 사이트 악성코드 삽입T1189

사이버 킬체인과 공격 벡터​

나. 측면 이동(Lateral Movement)의 단계별 메커니즘과 주요 기법​

1. 측면 이동 개념​

**측면 이동(Lateral Movement)**은 공격자가 초기 침투 후 내부 네트워크에서 추가 시스템으로 권한을 확장하며 목표 자산에 접근하는 일련의 행위다. MITRE ATT&CK에서 전술(Tactic) TA0008로 분류된다.

2. 측면 이동 단계별 메커니즘​

단계 1: 초기 거점 확보 (Initial Foothold)​

항목내용
MITRE ATT&CKTA0001 (Initial Access)
주요 기법피싱, 취약점 익스플로잇, 크리덴셜 스터핑
결과일반 사용자 권한의 첫 번째 시스템 감염
도구Metasploit, Cobalt Strike, Empire

단계 2: 내부 정찰 (Internal Reconnaissance)​

MITRE 기법ID설명
계정 발견T1087AD 사용자, 그룹, 권한 열거
네트워크 서비스 스캔T1046열린 포트 및 서비스 탐색
도메인 트러스트 발견T1482AD 트러스트 관계 파악
원격 시스템 발견T1018내부 호스트 목록 수집

단계 3: 자격증명 수집 (Credential Harvesting)​

MITRE 기법ID설명도구
OS 자격증명 덤프T1003LSASS 메모리 덤프Mimikatz
NTDS 탈취T1003.003AD 데이터베이스 추출secretsdump.py
키로깅T1056.001키보드 입력 캡처Keylogger
브라우저 자격증명T1555.003브라우저 저장 패스워드LaZagne

단계 4: 측면 이동 실행 (Lateral Movement Execution)​

측면 이동의 핵심 단계로, 수집된 자격증명과 내부 정보를 활용하여 다른 시스템으로 이동한다.

단계 5: 권한 상승 (Privilege Escalation)​

기법설명MITRE ID
토큰 조작고권한 토큰으로 프로세스 실행T1134
수직 권한 상승일반→관리자→도메인 관리자T1068
DCSync 공격DC 복제 권한으로 해시 추출T1003.006

3. 측면 이동 주요 기법​

(1) Pass the Hash (PtH)​

항목내용
MITRE ATT&CKT1550.002
악용 프로토콜SMB, WMI, PSEXEC
대응 방안Protected Users 그룹, Credential Guard, NTLM 비활성화
도구Mimikatz, Impacket, CrackMapExec
# Impacket을 이용한 PtH 예시 (탐지/분석 목적)
# psexec.py -hashes :NTLM_HASH domain/admin@target_ip

(2) Pass the Ticket (PtT) - Kerberos 티켓 악용​

항목내용
MITRE ATT&CKT1550.003
원리Kerberos 인증 티켓 재사용
대응 방안티켓 TTL 단축, AES 암호화 강제, 모니터링

(3) Golden Ticket 공격​

항목내용
MITRE ATT&CKT1558.001
필요 조건krbtgt 계정의 NTLM 해시
위험성AD 전체 장악, krbtgt 패스워드 변경 전까지 지속
유효 기간설정에 따라 최대 10년까지 가능
대응 방안krbtgt 패스워드 2회 변경, 비정상 티켓 탐지

(4) Silver Ticket 공격​

항목내용
MITRE ATT&CKT1558.002
원리서비스 계정 NTLM 해시로 특정 서비스 TGS 위조
차이점Golden Ticket은 TGT 위조, Silver Ticket은 TGS 위조
영향 범위특정 서비스에만 유효 (더 제한적)
탐지 어려움DC 통신 없이 로컬 검증

(5) Remote Service 악용​

(6) Living off the Land (LotL) 기법​

공격자가 합법적인 시스템 도구를 활용하여 탐지를 회피하는 기법

도구악용 방식MITRE ID
PowerShell원격 실행, 정보 수집T1059.001
WMI원격 코드 실행, 영속성T1047
PsExec원격 프로세스 실행T1569.002
WMIC시스템 정보 수집, 원격 실행T1047
certutil악성코드 다운로드T1140
regsvr32코드 실행 우회T1218.010
# LotL 예시: PowerShell을 이용한 원격 실행
# Invoke-Command -ComputerName target -ScriptBlock { whoami }
# (탐지 시나리오 이해를 위한 예시)

4. 측면 이동 탐지 및 대응​

탐지 방법​

탐지 기법설명도구
이상 행위 탐지비정상 로그인 시간/위치/빈도UEBA (Splunk, Exabeam)
네트워크 트래픽 분석내부 SMB, RDP 트래픽 이상NDR (Darktrace, Vectra)
엔드포인트 탐지자격증명 덤프, 의심 프로세스EDR (CrowdStrike, SentinelOne)
로그 분석이벤트 ID 4624, 4625, 4648SIEM (Microsoft Sentinel)
허니팟가짜 시스템으로 공격자 유인HoneyPot, HoneyToken

핵심 Windows 이벤트 ID​

이벤트 ID의미측면 이동 연관성
4624성공적 로그온비정상 원격 로그온 탐지
4625실패한 로그온브루트포스, 자격증명 스터핑
4648명시적 자격증명 사용PtH 공격 패턴
4768/4769Kerberos TGT/TGS 요청Golden/Silver Ticket 탐지
4776NTLM 인증PtH 탐지

대응 방안 (Zero Trust 관점)​

대응 영역구체적 조치
AD 보안 강화Protected Users 그룹, LAPS, Tier 모델
네트워크 분리VLAN, 마이크로세분화, 제로트러스트 NAC
자격증명 보호Credential Guard, MFA 전사 적용
모니터링SIEM/SOAR, EDR, NDR 통합 운영
사고 대응DFIR 절차, AD 재구축 계획 수립

결론​

IT 인프라 확장으로 공격 표면이 기하급수적으로 증가하는 환경에서, 공격자는 다양한 공격 벡터로 진입 후 정교한 측면 이동 기법으로 조직 전체를 장악한다.

대응 전략핵심 내용
공격 표면 관리ASM 도입으로 외부 노출 자산 지속 파악
Zero Trust"절대 신뢰하지 말고, 항상 검증" 원칙 전사 적용
탐지 및 대응MITRE ATT&CK 기반 탐지 룰 구축, SOAR 자동화
보안 인식사회공학 대응 교육, 피싱 시뮬레이션 훈련

MITRE ATT&CK 프레임워크 기반의 위협 모델링과 Red Team/Purple Team 훈련을 통해 측면 이동에 대한 탐지·대응 역량을 지속적으로 강화하는 것이 현대 사이버 보안의 핵심이다.
