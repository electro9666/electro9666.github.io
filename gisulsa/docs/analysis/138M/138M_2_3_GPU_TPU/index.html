문제 3) GPU와 TPU

답)

가. GPU와 TPU 개념​

1) GPU (Graphics Processing Unit)​

GPU는 원래 그래픽 렌더링을 위해 설계된 프로세서로, 수천 개의 소형 코어를 병렬로 운용하여 대규모 행렬 연산을 동시에 처리할 수 있는 범용 병렬 처리 장치이다. NVIDIA CUDA, AMD ROCm 플랫폼 등을 통해 AI/딥러닝 학습의 핵심 인프라로 자리잡았다.

GPU 특성내용
핵심 설계 목적그래픽 렌더링 → AI/HPC 범용 병렬 연산으로 확장
코어 수수천~수만 개 CUDA 코어 (NVIDIA H100: 14,592개)
메모리HBM2e/HBM3 (H100: 80GB, 3.35TB/s 대역폭)
프로그래밍CUDA, OpenCL, ROCm 등 범용 프레임워크
유연성CNN, RNN, Transformer 등 다양한 모델 구조 지원
대표 제품NVIDIA H100/A100/L40S, AMD MI300X

2) TPU (Tensor Processing Unit)​

TPU는 Google이 딥러닝 추론 및 학습에 특화하여 자체 설계한 ASIC(Application-Specific Integrated Circuit)이다. 텐서 연산(행렬 곱셈)을 하드웨어 레벨에서 극한 최적화하여 에너지 효율과 처리량을 극대화한다.

TPU 특성내용
핵심 설계 목적텐서 연산(행렬 곱셈) 전용 가속
핵심 구조시스톨릭 어레이(Systolic Array) 기반 MXU
메모리HBM (TPU v4: 32GB/칩, v5p: 95GB/칩)
연결성ICI(Inter-Chip Interconnect)로 수천 칩 직접 연결
유연성TensorFlow, JAX에 최적화 (제한적 범용성)
세대TPU v1(2016) → v2 → v3 → v4 → v5(2024)
접근 방식Google Cloud TPU로 제공 (자체 구매 불가)

3) 시스톨릭 어레이 (Systolic Array) 원리​

데이터가 PE(Processing Element) 배열을 파이프라인 방식으로 흐르며, 메모리 접근 없이 연산 결과를 인접 PE로 전달한다. 이로써 메모리 대역폭 병목 없이 고밀도 행렬 곱셈을 수행한다.

1) 핵심 비교표​

비교 항목GPUTPU

1) 대규모 모델 학습에서의 TPU 우위​

2) TPU를 선택하는 구체적 이유​

이유상세 내용정량적 효과
규모 확장성TPU Pod는 수천 칩이 단일 ICI 패브릭으로 연결. GPU는 수백 노드 연결 시 네트워크 병목 발생LLM 학습 시 GPU 대비 2~4배 빠른 확장
BF16 최적화BF16(Brain Float 16)은 FP32와 같은 지수 범위를 가지면서 메모리 절반 사용. TPU는 BF16을 하드웨어 네이티브 지원메모리 절약 50%, 처리량 2배
메모리 대역폭시스톨릭 어레이 구조로 On-Chip 데이터 재사용. 메모리 접근 최소화메모리 병목 대폭 감소
에너지 효율특정 연산에 최적화된 ASIC 구조로 GPU 대비 전력 효율 우수같은 FLOPS 대비 에너지 30~50% 절감
JAX 생태계Google의 JAX 프레임워크는 TPU에 최적화, XLA 컴파일러로 자동 최적화코드 수정 없이 TPU 성능 자동 활용
총 소유 비용클라우드 종량제로 유휴 비용 없음, H100 구매비용 대비 소규모 사용 시 유리단기 프로젝트 비용 절감

2) TPU 한계점​

한계내용
벤더 종속Google Cloud 전용, 온프레미스 불가
프레임워크 제한PyTorch 지원 제한적 (torch_xla 필요), 연구 유연성 낮음

3) 향후 전망​

전망 영역내용
TPU 고도화v5/v6 세대로 BF16 처리량 지속 향상, 멀티모달 지원 강화
경쟁 심화AWS Trainium/Inferentia, MS Azure Maia, 삼성 Mach-1 등 커스텀 AI 칩 확산
소프트웨어 개선JAX/PyTorch XLA 호환성 향상으로 TPU 접근성 개선
에너지 효율 경쟁데이터센터 전력 위기로 TFLOPS/W가 핵심 경쟁 지표로 부상
하이브리드 사용학습(TPU) + 추론(GPU/NPU) 혼합 사용 최적화 트렌드
엣지 TPU 확산Google Coral 등 엣지 디바이스용 소형 TPU 보급 확대
표준화ONNX, OpenXLA 등 공통 IR(중간 표현)을 통한 이식성 향상

GPU와 TPU는 상호 보완적 역할을 수행하며, 대규모 LLM 학습에서는 TPU의 확장성·효율성이 두드러지는 반면, 다양한 모델 구조와 연구 환경에서는 GPU의 범용성이 여전히 필수적이다. 향후 AI 인프라는 워크로드 특성에 따라 GPU·TPU·전용 NPU를 혼합 활용하는 이기종(Heterogeneous) 컴퓨팅 체계로 발전할 것이다.
