문제 2) 단방향 해시 함수 (Hash Function)

답)

개요​

단방향 해시 함수(One-Way Hash Function)는 임의 길이의 입력 데이터를 고정 길이의 해시값(다이제스트)으로 변환하는 함수로, 역방향 연산이 계산적으로 불가능한 특성을 가진다. 암호학적 해시 함수는 비밀번호 저장, 무결성 검증, 디지털 서명 등 다양한 보안 영역에서 핵심 기술로 활용된다.

2. 문제점 상세 설명​

문제점설명예시
충돌(Collision) 취약성서로 다른 두 입력이 동일한 해시값 생성 가능MD5: 2004년 충돌 쌍 발견, SHA-1: 2017년 SHAttered 공격
빠른 연산 속도GPU/ASIC으로 초당 수십억 회 해시 연산 가능 → 무차별 대입 공격에 취약RTX 4090: MD5 초당 약 640억 회

역상(Preimage) 공격특정 해시값을 만드는 원본 입력을 찾는 공격무차별 대입, 사전 공격

2. Rainbow Table 공격 원리​

공격 절차:

  1. 공격 준비 단계: 가능한 모든 평문의 해시 체인을 사전 계산하여 테이블 구축
  2. 공격 대상 해시값 획득 (예: DB 탈취)
  3. 해시값에 감축 함수(Reduction Function) 적용 → 평문 후보 생성
  4. 평문 후보의 해시 계산 → 테이블에서 체인 끝값과 일치 여부 검색
  5. 일치하면 해당 체인을 역추적하여 원본 평문 복원

3. Rainbow Table 특성​

항목내용
장점사전 계산으로 실시간 공격 속도 대폭 향상
단점테이블 크기 거대 (수 TB), 솔트 적용 시 무효화
대상솔트 없는 MD5, SHA-1 기반 비밀번호 해시
방어솔트(Salt) 적용으로 완전 무력화

다. 해시 솔트(Hash Salt)와 키 스트레칭(Key Stretching)​

1. 해시 솔트 (Hash Salt)​

개념​

솔트(Salt)는 비밀번호 해싱 전 무작위로 생성하여 추가하는 임의의 데이터로, 동일한 비밀번호도 서로 다른 해시값을 갖게 한다.

솔트 적용 효과​

공격 유형솔트 미적용솔트 적용
Rainbow Table 공격취약무력화 (솔트별 별도 테이블 필요)
사전 공격취약크게 어려워짐
동일 비밀번호 노출동일 해시 → 일괄 탈취다른 해시 → 개별 공격 필요

솔트 구현 예시​

import hashlib
import os

def hash_password(password: str) -> tuple[str, str]:
    # 16바이트 무작위 솔트 생성
    salt = os.urandom(16).hex()
    # 비밀번호 + 솔트 결합 후 해시
    hash_value = hashlib.sha256((password + salt).encode()).hexdigest()
    return hash_value, salt

def verify_password(password: str, stored_hash: str, salt: str) -> bool:
    hash_value = hashlib.sha256((password + salt).encode()).hexdigest()
    return hash_value == stored_hash

2. 키 스트레칭 (Key Stretching)​

개념​

키 스트레칭은 해시 함수를 수천~수백만 회 반복 적용하여 해시 계산 비용을 고의로 높이는 기법이다.

주요 키 스트레칭 알고리즘 비교​

알고리즘반복 방식메모리 사용GPU 저항성특징
PBKDF2해시 반복 (수만 회)낮음낮음RFC 8018 표준, 단순
bcryptBlowfish 기반 반복중간중간cost factor 조절 가능
scrypt메모리 하드 함수높음높음메모리 집약적
Argon2메모리·시간 파라미터높음매우 높음PHC 우승, 현재 권장

bcrypt 동작 원리​

import bcrypt

# 비밀번호 해싱 (cost factor=12: 2^12 = 4096회 반복)
password = b"mypassword"
hashed = bcrypt.hashpw(password, bcrypt.gensalt(rounds=12))
# 결과: $2b$12$[22자리 솔트][31자리 해시]

# 검증
is_valid = bcrypt.checkpw(password, hashed)

결론​

단방향 해시 함수는 현대 보안 시스템의 핵심 기반 기술이나, MD5·SHA-1 등 구형 알고리즘의 취약성, 빠른 연산 속도를 이용한 Rainbow Table·무차별 대입 공격이 주요 위협이다. 이를 대응하기 위해 무작위 솔트로 Rainbow Table을 무력화하고, bcrypt·Argon2 등 키 스트레칭 알고리즘으로 연산 비용을 높여야 한다. 비밀번호 저장에는 반드시 Argon2id를 권장하며, 무결성 검증에는 SHA-256 이상을 사용해야 한다.
