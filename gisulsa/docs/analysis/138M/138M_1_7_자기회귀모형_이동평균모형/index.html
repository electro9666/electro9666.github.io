문제 7) 자기회귀모형(Autoregressive Model)과 이동평균모형(Moving Average Model)

답)

I. 개요​

1. 정의​

시계열(Time Series) 분석에서 과거 데이터의 패턴을 이용해 미래 값을 예측하는 통계 모형으로, 자기회귀모형(AR)과 이동평균모형(MA)은 시계열 예측의 핵심 기반 모형이다.

모형영문정의
AR 모형Autoregressive Model현재 값이 과거 자신의 값들의 선형 결합으로 표현되는 모형
MA 모형Moving Average Model현재 값이 과거 백색잡음(오차)들의 선형 결합으로 표현되는 모형
ARMA 모형Autoregressive Moving AverageAR과 MA를 결합한 복합 모형
ARIMA 모형Autoregressive Integrated Moving Average비정상 시계열에 차분을 적용한 확장 모형

2. 배경 및 필요성​

  • 금융: 주가, 환율, 금리 예측
  • 경제: GDP, 물가지수, 실업률 예측
  • 공학: 신호처리, 음성인식, 진동 분석
  • 기상: 기온, 강수량, 풍속 예측

II. 자기회귀모형(AR Model)​

1. 수학적 정의​

AR(p) 모형 (차수 p인 자기회귀모형):

Yt=ϕ1Yt−1+ϕ2Yt−2+⋯+ϕpYt−p+εtY_t = \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + \cdots + \phi_p Y_{t-p} + \varepsilon_tYt​=ϕ1​Yt−1​+ϕ2​Yt−2​+⋯+ϕp​Yt−p​+εt​

기호의미
YtY_tYt​시점 t에서의 관측값
ϕi\phi_iϕi​i번째 자기회귀 계수 (AR 파라미터)
ppp모형의 차수 (Lag 수)
εt\varepsilon_tεt​백색잡음 (White Noise), εt∼WN(0,σ2)\varepsilon_t \sim WN(0, \sigma^2)εt​∼WN(0,σ2)

AR(1) 예시: Yt=ϕ1Yt−1+εtY_t = \phi_1 Y_{t-1} + \varepsilon_tYt​=ϕ1​Yt−1​+εt​

  • ∣ϕ1∣<1|\phi_1| < 1∣ϕ1​∣<1: 정상 과정(Stationary Process)
  • ϕ1=1\phi_1 = 1ϕ1​=1: 단위근(Unit Root), 비정상 과정

2. AR 모형의 특성​

통계량AR(p) 모형의 특성
ACF (자기상관함수)지수적으로 감소하거나 진동하며 감소 (tailing off)
PACF (편자기상관함수)차수 p 이후 급격히 0으로 절단 (cutting off)
정상성 조건특성방정식 1−ϕ1z−ϕ2z2−⋯−ϕpzp=01 - \phi_1 z - \phi_2 z^2 - \cdots - \phi_p z^p = 01−ϕ1​z−ϕ2​z2−⋯−ϕp​zp=0의 모든 근이 단위원 밖에 존재

3. 모형 식별 - ACF/PACF 분석​

III. 이동평균모형(MA Model)​

1. 수학적 정의​

MA(q) 모형 (차수 q인 이동평균모형):

Yt=εt−θ1εt−1−θ2εt−2−⋯−θqεt−qY_t = \varepsilon_t - \theta_1 \varepsilon_{t-1} - \theta_2 \varepsilon_{t-2} - \cdots - \theta_q \varepsilon_{t-q}Yt​=εt​−θ1​εt−1​−θ2​εt−2​−⋯−θq​εt−q​

또는 양의 부호 관례를 사용할 경우: Yt=μ+εt+θ1εt−1+θ2εt−2+⋯+θqεt−qY_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q}Yt​=μ+εt​+θ1​εt−1​+θ2​εt−2​+⋯+θq​εt−q​

기호의미
YtY_tYt​시점 t에서의 관측값
θi\theta_iθi​i번째 이동평균 계수 (MA 파라미터)
qqq모형의 차수
εt\varepsilon_tεt​백색잡음, εt∼WN(0,σ2)\varepsilon_t \sim WN(0, \sigma^2)εt​∼WN(0,σ2)

MA(1) 예시: Yt=εt+θ1εt−1Y_t = \varepsilon_t + \theta_1 \varepsilon_{t-1}Yt​=εt​+θ1​εt−1​

2. MA 모형의 특성​

통계량MA(q) 모형의 특성
ACF (자기상관함수)차수 q 이후 급격히 0으로 절단 (cutting off)
PACF (편자기상관함수)지수적으로 감소하거나 진동하며 감소 (tailing off)
가역성 조건특성방정식의 모든 근이 단위원 밖에 존재
정상성항상 정상 과정 (모든 MA 모형은 정상)

3. MA 모형의 중요 특성 - 항상 정상​

MA 모형은 차수와 무관하게 항상 정상 과정이다.

Var(Yt)=(1+θ12+θ22+⋯+θq2)σ2=상수\text{Var}(Y_t) = (1 + \theta_1^2 + \theta_2^2 + \cdots + \theta_q^2)\sigma^2 = \text{상수}Var(Yt​)=(1+θ12​+θ22​+⋯+θq2​)σ2=상수

IV. AR과 MA 모형 비교​

1. 핵심 비교표​

비교 항목AR(p) 모형MA(q) 모형
정의과거 관측값의 선형 결합과거 오차의 선형 결합
메모리무한 메모리 (Infinite Memory)유한 메모리 (Finite Memory, q 시점까지)
ACF서서히 감소 (tail off)q 이후 절단 (cut off)
PACFp 이후 절단 (cut off)서서히 감소 (tail off)
정상성 조건특성근이 단위원 밖에 존재해야 함항상 정상
가역성항상 가역특성근이 단위원 밖에 존재해야 함
차수 식별PACF에서 절단점 확인ACF에서 절단점 확인
파라미터 추정OLS (최소제곱법)MLE (최대우도법), 반복추정 필요

V. ARMA 및 ARIMA 확장 모형​

1. ARMA(p, q) 모형​

AR과 MA를 결합한 복합 모형:

Yt=ϕ1Yt−1+⋯+ϕpYt−p+εt+θ1εt−1+⋯+θqεt−qY_t = \phi_1 Y_{t-1} + \cdots + \phi_p Y_{t-p} + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}Yt​=ϕ1​Yt−1​+⋯+ϕp​Yt−p​+εt​+θ1​εt−1​+⋯+θq​εt−q​

  • 정상 시계열에 적용
  • AR(p)나 MA(q) 단독 모형보다 적은 파라미터로 같은 효과
  • 파시모니 원칙(Parsimony Principle): 적은 파라미터로 좋은 설명력

2. ARIMA(p, d, q) 모형 - Box-Jenkins 방법론​

비정상 시계열을 d번 차분하여 정상화한 후 ARMA 적용:

파라미터의미
pAR 차수 (자기회귀 항의 수)
d차분 횟수 (Integration 차수)
qMA 차수 (이동평균 항의 수)

1. 정보 기준(Information Criteria)​

기준수식특징

BIC (Bayesian)−2ln⁡(L)+kln⁡(n)-2\ln(L) + k\ln(n)−2ln(L)+kln(n)파시모니 중시, 과소추정 경향

1. 분야별 적용 사례​

2. 파이썬 구현 예시​

from statsmodels.tsa.arima.model import ARIMA
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import pandas as pd

# 데이터 로드
ts = pd.read_csv('timeseries.csv', index_col='date', parse_dates=True)

# ACF/PACF 시각화로 차수 식별
plot_acf(ts, lags=20)   # MA 차수 q 식별
plot_pacf(ts, lags=20)  # AR 차수 p 식별

# ARIMA(1,1,1) 모형 적합
model = ARIMA(ts, order=(1, 1, 1))
result = model.fit()

# 모형 요약 및 예측
print(result.summary())
forecast = result.forecast(steps=10)

# AIC로 최적 차수 선택 (auto_arima 활용)
from pmdarima import auto_arima
auto_model = auto_arima(ts, seasonal=False, 
                         information_criterion='aic',
                         stepwise=True)

VIII. 전망 및 결론​

1. 딥러닝과의 비교 및 공존​

비교 항목AR/MA/ARIMALSTM/Transformer
해석 가능성높음 (계수 해석 가능)낮음 (블랙박스)
소량 데이터강점약점
대량 데이터한계강점
비선형 패턴약점강점
계산 비용낮음높음
적용 용이성높음중간

2. 결론​

  • AR 모형: 과거 자신의 값으로 현재를 설명 → PACF에서 차수 식별
  • MA 모형: 과거 오차로 현재를 설명 → ACF에서 차수 식별
  • ARIMA: 비정상 시계열의 표준 분석 도구 (Box-Jenkins 방법론)
  • 딥러닝 시대에도 해석 가능성과 소량 데이터 처리에서 여전히 중요한 위치 차지
  • 실무에서는 통계 모형과 딥러닝을 앙상블하여 예측 정확도 향상 추구

핵심 요약: AR은 "나의 과거가 현재를 만든다", MA는 "과거의 실수가 현재에 영향을 미친다"는 철학으로 시계열을 모델링하며, 두 모형의 결합(ARMA)과 차분(ARIMA)을 통해 대부분의 실용적 시계열을 분석할 수 있다.
