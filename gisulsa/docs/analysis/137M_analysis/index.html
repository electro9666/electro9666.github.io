137회 정보관리기술사(137M) 기출 이유 분석

질문: original내에서 README.md를 참고하고, 110M.md ~ 136M.md, 110C.md ~ 136C.md를 분석해서 137M.md의 문제들이 기출된 이유를 추측하라. 문제별로 정리해서 md로 생성

137회(2025.8.23) 정보관리기술사 문제가 출제된 이유를 110~136회 M/C 기출 패턴을 기반으로 추측한다.

1교시 (단답형)​

1_1. 동적 라우팅 프로토콜 IGP와 EGP​

출제 추측 이유: 네트워크 기본 개념의 주기적 출제

회차시험관련 기출
123M1_11거리벡터 라우팅(Distance Vector Routing)
123M3_5OSI 7 Layer 각 계층과 특징
116M2_4Ad-hoc 네트워크 경로제어 (Reactive/Proactive)
135C3_5네트워크 프로토콜 개념, 3요소, 기능
  • 라우팅 프로토콜은 네트워크의 고전적 핵심 주제이며, 123M에서 거리벡터 라우팅이 출제된 이후 확장
  • IGP/EGP 구분은 네트워크 기본이지만 오랜만에 출제 → "고전적 지식의 오랜만의 출제" 패턴
  • C 시험에서 네트워크가 빈출되므로 C→M 교차 출제 성격

1_2. 디지털 포렌식에서 아티팩트(Artifact)​

출제 추측 이유: 디지털 포렌식의 반복 출제에서 세부 키워드 확장

회차시험관련 기출
129M4_2디지털 포렌식 개념, 유형, 절차, 기술
126M4_6파일 카빙(File Carving) 기법
121M2_3디지털 포렌식 절차 및 기술
117M4_3디지털 포렌식 조사모델, 5대 원칙
116M4_5디지털 포렌식 증거수집/분석 기술
111C1_11디지털 포렌식
  • 디지털 포렌식은 거의 매 3~4회마다 출제되는 초빈출 주제
  • 기존에는 절차/원칙 위주 → 이번에는 아티팩트라는 세부 개념으로 심화
  • 사이버 범죄 증가에 따른 지속적 중요성 반영

1_3. MODBUS 프로토콜​

출제 추측 이유: 산업제어시스템(ICS) 프로토콜의 주기적 출제

회차시험관련 기출
113C1_5Modbus TCP, RTU
119C2_5SCADA 시스템
120C2_4SCADA 구성요소, 감시와 제어
124M4_6산업제어시스템 퍼듀(Purdue) 모델
  • 113C(2017)에서 단답형으로 출제된 동일 주제 재출제 → 약 8년만
  • 스마트팩토리, OT 보안 등 산업 IoT 트렌드와 맞물림
  • M 시험에서는 SCADA/ICS 관련이 간헐적으로 출제되는 영역

1_4. 암호문 공격(Ciphertext Attack)​

출제 추측 이유: 암호학 공격 기법의 주기적 출제

회차시험관련 기출
116M1_3해시 알고리즘
113M1_2Challenge-Response 방식
126M4_5RSA/DSA 비교
125M4_6블록 암호 모드 (ECB/CBC/CFB/OFB)
  • 암호학은 보안의 핵심 기반 지식으로 주기적 출제
  • 기존에는 암호 알고리즘/프로토콜 위주 → 이번에는 공격 관점(Known/Chosen/Adaptive)으로 전환
  • 양자 컴퓨팅 시대의 암호 안전성 논의와 맞물림

1_5. GNN(Graph Neural Network)​

출제 추측 이유: AI/딥러닝 아키텍처의 최신 트렌드

회차시험관련 기출
114M1_6그래프 데이터베이스(Graph Database)
122M4_4NER, Word Embedding, BERT/GPT-3 비교
126M1_4SNN(Spiking Neural Networks)
131C1_7CNN 계층(Layer)
  • 그래프 DB(114M)에서 그래프 신경망으로 확장 → 데이터 구조와 AI의 융합
  • CNN, RNN, SNN 등 다양한 신경망 아키텍처가 순차적으로 출제되는 패턴의 연장
  • 추천 시스템, 소셜 네트워크 분석 등 실무 활용도 증가

1_6. AI 거버넌스(AI Governance)​

출제 추측 이유: AI 윤리/거버넌스의 지속적 출제

회차시험관련 기출
134M1_2인공지능 윤리기준 3대 원칙, 10대 핵심 요건
130M2_3AI 윤리 거버넌스 모형
123M4_6AI 윤리 필요성 및 정책 동향
131C2_6AI 윤리 개념, 주요사례, 고려사항
136M1_2범용 AI 위험관리 프레임워크
  • AI 윤리/거버넌스는 123회부터 꾸준히 출제
  • 직전 136M에서 "범용 AI 위험관리 프레임워크"가 출제된 후 AI 거버넌스 전체로 확장
  • 인공지능기본법 제정 논의가 진행 중인 시점의 사회적 이슈 반영

1_7. 트랜스포머(Transformer)와 MoE(Mixture of Experts)​

출제 추측 이유: 생성형 AI 핵심 아키텍처의 최신 트렌드

회차시험관련 기출
122M4_4BERT와 GPT-3 비교
136M1_3에이전틱 AI(Agentic AI)
135C2_4sLLM 정의, 주요 기술
136C1_12RAG
  • BERT/GPT(122M)에서 → 트랜스포머/MoE로 기반 아키텍처 심화
  • LLM의 핵심 기술인 트랜스포머와, GPT-4/Mixtral 등에 사용되는 MoE를 묻는 최신 트렌드
  • 기출에서 유추하기 어려운 고득점자 분별 목적

1_8. AI 신뢰성 검인증 제도(CAT)​

출제 추측 이유: AI 관련 제도/인증의 최신 트렌드

회차시험관련 기출
134M1_2인공지능 윤리기준
136M1_2범용 AI 위험관리 프레임워크
130M2_3AI 윤리 거버넌스
  • AI 거버넌스(1_6)와 함께 AI 제도 관련 2문제 동시 출제
  • 과기정통부의 AI 신뢰성 검인증 제도는 최신 정책 반영
  • 기출에서 직접 유추 불가한 신규 키워드

1_9. A/B 테스팅​

출제 추측 이유: 소프트웨어 테스트/데이터 분석 기법의 확장

회차시험관련 기출
130M1_8화이트박스/블랙박스 테스트 비교
114M3_6화이트/블랙박스 4가지 검증기준
121M3_4블랙박스 테스트 기법
111M1_1통계적 가설 검정
  • 기존 테스트 기법(블랙/화이트박스)에서 실무 데이터 기반 테스트로 확장
  • 통계적 가설 검정(111M)의 실제 적용 사례로서의 A/B 테스팅
  • 디지털 서비스 운영에서 실무적 중요성 증가

1_10. 데이터 늪(Data Swamp)​

출제 추측 이유: 데이터 관리 영역의 최신 키워드

회차시험관련 기출
117M1_7Data Lake
129M1_4데이터 거버넌스
125M3_3데이터 거버넌스 개념 및 주요 기능
131C2_3데이터 웨어하우스와 데이터 레이크 비교
  • Data Lake(117M)의 실패 사례/안티패턴으로서의 Data Swamp
  • 데이터 거버넌스의 중요성을 강조하는 관리적 관점의 키워드
  • 기출의 Data Lake에서 상위/연관 개념으로 확장

1_11. 소프트웨어 역공학과 재공학​

출제 추측 이유: 과거 직접 기출의 재출제

회차시험관련 기출
114M1_11재공학(Re-engineering), 역공학(Reverse Engineering)
118M4_2리팩토링 + 3R(Reverse-Engineering, Re-Engineering, Re-use)
125M3_2리팩토링 정의, 목적, 코드스멜
  • 114회(2018)에서 동일하게 출제된 직접 기출 재출제 → 약 7년만
  • "고전적 지식의 오랜만의 출제" 패턴에 해당
  • 레거시 시스템 현대화(클라우드 전환) 수요 증가와 맞물림

1_12. 이진 탐색 트리​

출제 추측 이유: 자료구조 기본 개념의 주기적 출제

회차시험관련 기출
131C4_1이진트리 순회 (전위/중위/후위)
124M1_4선형 자료구조와 비선형 자료구조
130M3_2선형/비선형 구조 개념 및 유형
123M3_2자료구조 Heap (Max-heap/Min-heap)
116M1_7우선순위 큐(Priority Queue)
  • 자료구조는 주기적으로 출제되는 고전 영역
  • 131C에서 이진트리 순회가 출제된 후 M에서 이진 탐색 트리로 교차 출제
  • 알고리즘/자료구조는 기술사 시험의 기본 지식 영역

1_13. 데이터마이닝 연관 규칙 분석 지표​

출제 추측 이유: 과거 기출의 직접적 재출제

회차시험관련 기출
117M2_1연관규칙 특징, 3가지 기준(지지도/신뢰도/향상도), 계산
129M3_1의사결정나무 모델
111M4_1혼동행렬(Confusion Matrix)
  • 117회(2019)에서 서술형으로 상세 출제된 주제가 단답형으로 재출제 → 약 6년만
  • 데이터마이닝 기법은 주기적 반복 영역
  • 지지도/신뢰도/향상도 지표가 핵심

2교시 (서술형)​

2_1. 캐시 메모리 (Write Policy, Cache Coherence)​

출제 추측 이유: C 시험 빈출 주제의 M 교차 출제

회차시험관련 기출
135C4_1캐시 메모리 주소 매핑, 쓰기 정책, 일관성 기법
132C4_3캐시 메모리 개념/구조, 지역성, 일관성
120C3_1캐시 일관성 (디렉토리/스누피 프로토콜)
114C4_1캐시 매핑 방식, 교체 알고리즘
136C2_4캐시 메모리 교체 기법, Write Through/Back, MESI
  • 캐시 메모리는 C 시험에서 초빈출 (114C, 120C, 132C, 135C, 136C)
  • 직전 136C에서 출제 → M으로 교차 출제 패턴
  • 이번에는 쓰기 정책과 일관성에 초점 → C 기출과 거의 동일한 범위

2_2. SLA 구성요소, 절차, 평가지표​

출제 추측 이유: IT 서비스 관리의 반복 출제

회차시험관련 기출
122M4_2SLA/OLA, Penalty/Incentive, SIP, Annual Reset
129M3_6금융 클라우드 SLA 가이드
117M1_5SLM(Service Level Management) 프레임워크
  • SLA는 정보관리기술사의 핵심 업무 영역
  • 122회(2020) 이후 약 5년만에 재출제 → 주기적 반복
  • 운영 전환 시나리오를 제시하여 실무 적용 관점 강조

2_3. MCP(Model Context Protocol) 보안 취약점​

출제 추측 이유: 직전 회차 단답형 → 서술형 확장

회차시험관련 기출
136M1_13MCP(Model Context Protocol) - 단답형
136M2_3AI 기반 개발에서 LLM 보안 위험
  • 직전 136M에서 MCP가 단답형으로 출제 → 137M에서 서술형으로 확장
  • README의 "이전 기출 내용이 심화, 확장된 경우" 패턴에 정확히 부합
  • 136M에서 LLM 보안 위험도 출제되어 AI 보안이 연속 핵심 테마

2_4. 초거대 AI 도입·활용 가이드라인 2.0​

출제 추측 이유: 직전 C 시험 출제 주제의 M 교차 출제

회차시험관련 기출
135C2_2초거대 AI 도입 가이드라인 (개념, 도입 원칙, 사전 고려사항)
136M2_3AI 기반 SW 개발에서 LLM 보안 위험
134M4_4파운데이션 모델 개념, 특징, 기반기술
  • 135C에서 초거대 AI 가이드라인이 출제 → 137M에서 2.0 버전으로 교차 출제
  • "C에서 출제된 내용이 다음 M에서 출제" 패턴
  • 이번에는 가이드라인 **2.0(개정판)**으로 최신화

2_5. 동적 테스트 (명세 기반/구조 기반, 동등 분할/분류 트리)​

출제 추측 이유: SW 테스트의 반복 출제에서 실전 문제 추가

회차시험관련 기출
130M1_8화이트박스/블랙박스 테스트 비교
114M3_6화이트/블랙박스 4가지 검증기준, 테스트 자동화 도구
121M3_4블랙박스 테스트 기법 (날짜 처리 테스트 케이스 작성)
130M3_3통합 테스트 (하향식/상향식)
132C3_5KS X ISO/IEC/IEEE 29119 테스트 설계 기법
  • SW 테스트는 매 3~5회마다 출제되는 핵심 영역
  • 121M에서도 블랙박스 테스트 케이스 작성 문제가 출제 → 실전 계산 문제 패턴 반복
  • 명세 기반(동등 분할, 분류 트리)이라는 구체적 기법 요구

2_6. TEXT2SQL​

출제 추측 이유: 생성형 AI + 데이터베이스 융합의 최신 트렌드

회차시험관련 기출
136C1_12RAG(Retrieval-Augmented Generation)
136M1_3에이전틱 AI
135C2_4sLLM 정의, 주요 기술
122M4_4자연어처리 NER, BERT/GPT-3
  • LLM 활용의 구체적 사례로서 자연어→SQL 변환
  • RAG(136C), 에이전틱 AI(136M) 등 LLM 활용 기술이 연속 출제되는 흐름

137회의 특징​

  1. AI/LLM이 압도적 핵심 테마: 전체 31문제 중 8문제(26%)가 AI 관련. 트랜스포머/MoE, MCP, TEXT2SQL, 벡터DB 등 생성형 AI 생태계 전반을 포괄
  2. 직전 회차 연속성 강함: 136M의 MCP(단답)→137M MCP 보안(서술), 136M 에이전틱 AI→137M TEXT2SQL 등 직전 회차 키워드의 심화
  3. 최신 보안 사건 반영: BPFdoor(통신사 해킹), N2SF(망 보안체계 개편) 등 시사적 보안 이슈 직접 출제
  4. 고전+최신 균형: 유전 알고리즘, 재공학/역공학, 연관규칙 등 7~8년만의 고전 재출제와 MoE, TEXT2SQL, 벡터DB 등 완전 신규 키워드가 균형
  5. C 시험과의 교차 활발: 캐시 메모리(136C), 초거대 AI 가이드라인(135C), 스케줄링(136C) 등 직전 C 출제 주제의 M 이동

3. 다음 시험(138회)에서의 재출제 가능성​

그대로 재출제될 가능성이 낮은 문제​

137M 문제이유
1_3 MODBUS산업제어 특화 프로토콜. 113C(2017) → 137M(2025) 8년만. 연속 출제 가능성 낮음
1_11 재공학/역공학114M(2018) → 137M(2025) 7년만. 다시 금방 나오지 않음
1_13 연관 규칙 지표117M(2019) → 137M(2025). 재출제 직후이므로 당분간 출제 가능성 낮음
4_1 BPFdoor특정 악성코드 사례. 동일 악성코드가 연속 출제되지 않음
4_5 유전 알고리즘113M(2017) → 137M(2025) 8년만 재출제. 연속 출제 가능성 낮음

138회에서 심화/변형 출제 가능성이 높은 문제 (반드시 공부)​

137M 문제138회 예상 출제 방향
1_6 AI 거버넌스AI 법/제도 트렌드 지속. 138M에서 AI RMF, ISO 42001, 인공지능기본법으로 실제 출제됨
1_7 트랜스포머/MoELLM 아키텍처는 계속 확장. 138C에서 Self-Attention 메커니즘으로 실제 출제됨
2_3 MCP 보안AI 보안 트렌드 지속. 138M에서 프롬프트 인젝션, 모델 전도 공격으로 실제 출제됨
2_4 초거대 AI 가이드라인138M에서 생성형 AI 이용자보호 가이드라인, 인공지능기본법으로 실제 출제됨
3_4 트랜잭션 격리 수준DB 기본 주제는 반복. 138M에서 참조 무결성으로 실제 출제됨
3_6 N2SF보안 정책은 지속 출제. 138M에서 ISMS-P 강화 방안으로 실제 출제됨
4_2 벡터DBAI 인프라 트렌드 지속. RAG, sLLM 등과 연계하여 계속 출제 예상
4_3 쿠버네티스클라우드 네이티브 핵심. 138M에서 클라우드 네이티브 전환(2_4)으로 실제 출제됨

137M에는 없었으나 138회에서 신규 출제된 주제​

138M 출제 주제137M과의 관계
AI RMF / ISO 42001137M AI 거버넌스(1_6)의 구체적 프레임워크로 심화
프롬프트 인젝션 / 모델 전도137M MCP 보안(2_3)에서 AI 보안 위협으로 확장
인공지능기본법137M AI 거버넌스(1_6) → 법률 제정 후 직접 출제
FTS/HA137M Multi-Region Active-Active(3_3) → 가용성의 기본 개념으로 출제
GPU/TPU137M 트랜스포머/MoE(1_7) → AI 하드웨어로 확장
오픈소스 DBMS 전환137M에 없었던 완전 신규 실무 트렌드
