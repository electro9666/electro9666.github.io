기술사 기출문제 토픽 분류 체계

분석 범위: 110회 ~ 138회 (컴퓨터시스템응용기술사 + 정보관리기술사) 관점: "대규모 웹서비스 구현을 위한 기술 집합"으로서의 분류

분류 1: 물리-논리-관리 3계층 (Physical / Logical / Management)​

가장 근본적인 분류. 만질 수 있는가? → 소프트웨어인가? → 사람/프로세스인가?

1-1. 물리 계층 (Physical Layer)​

하드웨어, 전기 신호, 물리 장비에 해당하는 토픽

세부 분류토픽
프로세서CPU, GPU, TPU, NPU, FPGA, ASIC, ARM 프로세서, 뉴로모픽 칩, Many-Core, PIM
메모리SDRAM, DDR SDRAM, SRAM/DRAM, Flash(NAND/NOR), FeRAM, MRAM, STT-MRAM, PRAM, HBM, SLC/MLC/TLC
저장장치RAID, SSD, SAN, NAS, DAS, 스토리지 티어링, 스토리지 프로비저닝
네트워크 장비L2/L4 스위치, 라우터, 방화벽(HW), 안테나, LiDAR, RADAR
버스/인터페이스PCI Express, Thunderbolt, CXL, JTAG, DMA, 버스 중재, I/O 인터페이스
센서/디바이스IoT 센서, RFID, 무선충전, UWB, 드론/안티드론, CCTV
통신 인프라5G/6G 기지국, Wi-Fi 6E/7, BLE, Zigbee, LoRa/LPWA, Wi-SUN
전력/환경UPS, 마이크로 에너지 하베스팅, 데이터센터(TIA-942), PoE
양자 컴퓨팅양자 컴퓨터, 큐빗, 양자 암호통신, QKD

1-2. 논리 계층 (Logical Layer)​

소프트웨어, 알고리즘, 프로토콜, 데이터 구조

세부 분류토픽
운영체제프로세스 스케줄링, 인터럽트, 교착상태, 세마포어/뮤텍스, 문맥교환, 가상메모리, 페이지 테이블/TLB, 메모리 단편화, 스레드, Thrashing
네트워크 프로토콜OSI 7계층, TCP/UDP/SCTP, HTTP 3.0, IPv6, HDLC, ARP, DNS, DHCP, MQTT, CoAP, SIP, IPsec, SSL/TLS
알고리즘분할정복, 그리디, DP, 백트래킹, 정렬, MST, 해밍코드, FEC/ARQ, CRC
데이터베이스정규화, 트랜잭션, 병행제어(MVCC), NoSQL, 그래프DB, 인메모리DB, 파티셔닝, 샤딩, OLAP/OLTP, 옵티마이저
AI/MLCNN, RNN, 딥러닝, 강화학습, SVM, 랜덤포레스트, 앙상블, GAN, LLM, XAI, 적대적 공격, Knowledge Distillation, Active Learning, Fine-tuning
SW 아키텍처MSA, 모놀리스, 디자인 패턴(Observer, Factory Method), MVC, SOLID, 리팩토링
클라우드/가상화IaaS/PaaS/SaaS, 컨테이너, Docker, Hypervisor, OpenStack, 서버리스(FaaS), 엣지 컴퓨팅, 포그 컴퓨팅
보안 SW암호화(대칭/비대칭), 해시, 전자서명, OAuth 2.0, WAF, IDS/IPS, DRM/DLP, Secure Coding
데이터 처리빅데이터, 스트림 처리, 데이터 레이크, ETL, 데이터 프로파일링, 웹 마이닝
블록체인합의 알고리즘, 분산원장, 스마트 컨트랙트, DeFi, NFT, DID

1-3. 관리 계층 (Management Layer)​

프로젝트, 조직, 법/제도, 전략에 해당하는 토픽

세부 분류토픽
프로젝트 관리PMO, 감리, ISP/ISMP, WBS, CMMI, ISO 21500, CPM, EVM, 갈등관리
품질 관리SW 품질인증, PDCA, 테스트 설계(블랙박스/화이트박스), 성능시험, ISO 25000, SW 비용산정/기능점수
보안 관리ISMS/ISMS-P, 개인정보 보호, 디지털 포렌식, 제로 트러스트, AI 윤리, 정보보호 거버넌스
법/제도데이터 3법, 지능정보화법, AI 기본법, 오픈소스 라이선스, 망 중립성, 전자정부 성과평가
전략/기획EA(전사아키텍처), IT-ROI, IT 아웃소싱, 디지털 전환, 플랫폼 전략
표준/규격ISO 26262, IEC 61508, OWASP, IEEE 802.11, SBOM

분류 3: 컴퓨터(C) vs 네트워크(N) vs 데이터(D) vs 관리(M)​

사용자가 제안한 물리적 분류(컴퓨터/네트워크)에 데이터와 관리를 추가한 4분류

C - 컴퓨터 (Computing)​

하드웨어 설계, 프로세서, 메모리, OS 내부 동작

프로세서: CPU, GPU, TPU, NPU, ARM, FPGA, 뉴로모픽, 양자컴퓨터, PIM
메모리:   SDRAM, DDR, Flash, HBM, FeRAM, MRAM, PRAM, 캐시
스토리지: RAID, SAN/NAS/DAS, SSD, 스토리지 티어링
OS:       스케줄링, 인터럽트, 교착상태, 세마포어, 가상메모리, TLB
구조:     파이프라인, 버스 중재, DMA, 워치독 타이머, I/O

N - 네트워크 (Networking)​

통신 프로토콜, 전송, 무선, 인터넷

기본:    OSI 7계층, TCP/UDP, IPv6, ARP, DNS, DHCP, HTTP
데이터링크: HDLC, CSMA/CD, 맨체스터 코딩, 이더넷
무선:    5G, 6G, Wi-Fi, BLE, Zigbee, LPWA, NB-IoT, UWB
고급:    SDN/NFV, 네트워크 슬라이싱, VPN, IPsec, MPTCP
오류:    FEC, ARQ, 해밍코드, CRC, 흐름/혼잡제어
응용:    MQTT, CoAP, SIP, WebRTC, V2X, Open RAN

D - 데이터/지능 (Data & Intelligence)​

데이터베이스, AI/ML, 빅데이터, 블록체인

DB:       정규화, 병행제어, NoSQL, 그래프DB, 인메모리DB, 옵티마이저
빅데이터: HDFS, 스트림 처리, 데이터 레이크, ETL, 데이터 품질
AI/ML:    CNN, RNN, SVM, 강화학습, LLM, GAN, XAI, 앙상블
블록체인: 합의, 스마트컨트랙트, DeFi, NFT, DID
응용 AI:  디지털 트윈, 자율주행, 스마트팩토리, 챗봇, 메타버스

M - 관리/보안 (Management & Security)​

프로젝트, 보안, 법제도, 전략

프로젝트: PMO, 감리, ISP/ISMP, WBS, CMMI, EVM, HW 규모산정
개발:     애자일, DevOps, CBD, 테스트, SW 비용산정, 기능점수
보안:     ISMS, 제로 트러스트, 방화벽/IDS/IPS, 암호, 포렌식
개인정보: 비식별, PET, 마이데이터, 데이터 3법
법/전략:  AI 기본법, 오픈소스 라이선스, 플랫폼 전략, ESG

분류 5: 기술 성숙도 (Technology Maturity)​

토픽의 성숙도에 따른 분류

정착기 (Established) - 꾸준히 반복 출제, 기초 지식​

OS: 프로세스 스케줄링, 인터럽트, 교착상태, 세마포어, 가상메모리
네트워크: OSI 7계층, TCP/UDP, IPv6, HDLC, DNS
DB: 정규화, 트랜잭션, 병행제어
보안: 암호화(대칭/비대칭), 방화벽/IDS/IPS, 전자서명
HW: 캐시 메모리, RAID, Flash 메모리
관리: WBS, CMMI, 테스트 기법, PMO/감리

성장기 (Growing) - 산업 적용 확대 중​

블록체인, 클라우드(IaaS/PaaS/SaaS), 엣지 컴퓨팅, MSA/컨테이너
디지털 트윈, 스마트팩토리, 자율주행, V2X, 5G
NoSQL, 빅데이터, CNN/RNN, 강화학습
ISMS-P, DevOps, 개인정보 비식별, 디지털 포렌식

부상기 (Emerging) - 최근 급부상, 향후 출제 가능성 높음​

LLM/생성형 AI, On-Device AI, MCP(Model Context Protocol)
제로 트러스트, PET, SBOM, OWASP LLM 보안
6G, Wi-Fi 7, 양자 컴퓨팅, 뉴로모픽
랜섬웨어/RaaS, AI 윤리/AI 기본법
메타버스, UAM, 디지털 플랫폼 정부

리바이벌 (Revival) - 오래되었으나 재출제​

HDLC (110→137), 방화벽/IDS/IPS (110→137)
파이프라인 해저드 (111→137), 랜섬웨어 (110→138)
대칭/비대칭 암호 (110→131)

분류 6: 웹서비스 구축 단계별 (SDLC 관점)​

"대규모 웹서비스를 만든다"는 관점에서, 각 단계에 필요한 토픽

1단계: 기획/전략​

ISP/ISMP, EA, IT-ROI, 타당성 분석, 플랫폼 전략
규제 샌드박스, 데이터 3법, AI 기본법
디지털 전환, 4차 산업혁명, ESG

2단계: 설계/아키텍처​

MSA, SOA, 디자인 패턴, SOLID, EA
클라우드 아키텍처, 컨테이너, 서버리스
DB 설계(정규화, 파티셔닝, 샤딩)
네트워크 설계(SDN/NFV, 슬라이싱, VPN)
API 설계(REST, GraphQL, API Gateway)

3단계: 개발/구현​

개발방법론(Agile, DevOps, CBD, XP)
프로그래밍(함수형, OOP, 리팩토링)
Secure Coding, CWE, OWASP
프레임워크(Spring Boot, Docker, TensorFlow)
블록체인 스마트 컨트랙트

4단계: 테스트/품질​

테스트 설계(블랙/화이트박스), 정적/동적 분석
성능시험, 커버리지, 테스트 자동화
SW 품질인증(ISO 25000), CMMI

5단계: 인프라/배포​

서버: CPU/GPU/NPU, 메모리, RAID, SAN
네트워크: L2/L4 스위치, 5G, CDN
클라우드: IaaS/PaaS/SaaS, CSAP
가상화: Hypervisor, VM, 컨테이너
배포: CI/CD, 카나리, 블루/그린

6단계: 운영/보안​

모니터링: SIEM, SOAR, 디지털 포렌식
보안: ISMS-P, 제로 트러스트, WAF, IDS/IPS
인증: OAuth, FIDO, DID, 동형암호
공격 대응: DDoS, 랜섬웨어, APT, XSS
데이터 보호: PET, 비식별, 마이데이터
재해복구: BCP, DR 시스템

7단계: 관리/감리​

PMO, 감리, EVM, SW 비용산정, 기능점수
HW 규모산정, IT 아웃소싱, IT-ROI

분류 7: 도메인 매트릭스 (기술 × 관점)​

기술 도메인(행)과 관점(열)의 교차 매트릭스

기술 도메인원리/구조 (C 주력)구현/개발운영/보안관리/정책 (M 주력)
컴퓨팅CPU/GPU/TPU 구조, 파이프라인병렬 프로그래밍, CUDAHW 규모산정, 성능HW 조달, 비용
메모리캐시 매핑, TLB, 가상메모리메모리 최적화, Leak 방지모니터링용량 계획
OS스케줄링, 인터럽트, 교착상태커널 프로그래밍프로세스 관리서버 운영
네트워크OSI, TCP/UDP, 오류제어소켓 프로그래밍, APIVPN, 방화벽, SDN망 중립성, 5G 정책
DB정규화, B-트리, 옵티마이저SQL, NoSQL 모델링병행제어, 백업데이터 품질, MDM
AICNN/RNN 구조, 역전파TensorFlow, 파인튜닝MLOps, 모니터링AI 윤리, AI 기본법
보안암호 알고리즘, 해시Secure Coding, SBOMISMS-P, 포렌식개인정보법, PET
클라우드가상화, 컨테이너 구조Docker, K8s, 서버리스CSAP, 보안 감사클라우드 감리, SLA
블록체인합의 알고리즘, 분산원장스마트 컨트랙트보안 감사, DeFi법제도, 비즈니스 모델
융합CPS, 센서 기술IoT 개발, V2X스마트팩토리 운영디지털 트윈 전략
