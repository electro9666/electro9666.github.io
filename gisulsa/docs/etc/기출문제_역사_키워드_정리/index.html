기출문제 역사 키워드 정리 (사건·국가·인물·단체)

분석 범위: original/ 폴더 전체 (110회~138회, C/M)

관점: 단순 기술 개념이 아니라, 역사적 맥락(제도 변화·국제 표준화·기관/인물 영향) 으로 읽히는 키워드 중심

1) 사건(이슈/변곡점) 키워드​

키워드역사적 맥락대표 출제 맥락
4차 산업혁명기출 전 구간에서 가장 오래 반복되는 거시 담론. 기술 트렌드 서술형 문제의 기본 프레임으로 작동.정의·연혁·영향·대응전략, 스마트팩토리/플랫폼 전략 연계
코로나-19디지털 전환 가속의 분기점 사건으로 등장.언택트 시대, 데이터 주권·거버넌스 이슈
GDPR 시행(2018-05-25)EU 개인정보 규제가 국내 기업까지 영향을 준 대표적 글로벌 규범 사건.EU GDPR과 한국 개인정보보호법 비교, 대응 필요성
데이터 3법 개정국내 데이터 활용·보호 균형 정책의 핵심 전환점.개정 배경/주요내용/산업 활용(클라우드·마이데이터)
개인정보보호법 개정안(2023-02-27 의결)데이터 경제 확산을 반영한 최근 법제 변화 사례.개정 주요 내용 및 현장 적용
인공지능기본법 시행(2026-01-22)AI 거버넌스를 독립 법률 체계로 다루기 시작한 최신 제도 변화.기본 원칙, 국가AI전략위원회, 산업육성 시책
멜트다운(Meltdown)CPU 마이크로아키텍처 취약점이 사회적 보안 이슈로 확장된 사건.하드웨어 구조 취약점과 보안 대응
랜섬웨어의 RaaS 진화단순 악성코드에서 서비스형 범죄 생태계로 변한 보안 위협의 진화 단계.감염 경로, 암호화 동작, 대응 절차

2) 국가/권역 키워드​

키워드역사적 관점 의미대표 출제 맥락
한국(대한민국)법·가이드라인·공공정책의 직접 적용 무대.개인정보보호법, 공공부문 가이드라인, 전자정부
미국AI/표준·아키텍처·산업 규범의 영향력이 큰 축.미국 국립표준기술연구소(NIST), IEEE 중심 표준 프레임
EU/유럽데이터 보호 규범 수출(Brussels Effect)을 보여주는 지역.GDPR, IEC/유럽 중심 표준체계
중국글로벌 AI/반도체 경쟁 맥락에서 간헐적으로 등장.국가별 AI·산업 전략 비교
영국개인정보·규제 논의에서 유럽 권역과 함께 참조되는 축.국제 제도 비교

3) 인물(사상/법칙/테스트를 남긴 인물) 키워드​

키워드역사적 의미대표 출제 맥락
폰 노이만(John von Neumann)현대 컴퓨터 구조의 고전 패러다임 제시.뉴로모픽 컴퓨팅과 폰 노이만 아키텍처 비교
앨런 튜링(Alan Turing)기계지능 판별 논의의 기점.튜링 테스트, CAPTCHA 맥락
M. M. Lehman소프트웨어 진화 법칙 제시로 유지보수/진화 이론 정립.Lehman 소프트웨어 진화 법칙
Richard Pollack프로세서 성능 스케일링 한계를 설명하는 법칙으로 인용.Pollack's Rule
Thomas Bayes확률적 추론의 고전 기반.베이즈 정리, 베이지안 최적화

4) 단체/기관/표준기구 키워드​

4-1. 국제 표준·연구·협의체​

키워드성격대표 출제 맥락
ISO국제표준화기구ISO/IEC 42001, ISO 25010, 거버넌스/품질 표준
IEC전기·전자 분야 국제표준기구IEC 61508 기능안전, IEEE와 비교
IEEE전기전자공학회(사실상 표준 영향력 큼)통신/네트워크·컴퓨팅 표준 프레임
NIST(미국 국립표준기술연구소)美 표준·가이드 주도 기관AI RMF, 보안 프레임워크
OECD국제 정책 협의체프라이버시 8원칙
OGC공간정보 표준 단체IMDF(실내지도 포맷) 표준화 동향
SWIFT국제 금융 통신 협회API 표준/금융 인프라 연계
TTA국내 ICT 표준화 기관다수 TTAK 표준(가이드라인/지침)

4-2. 국내 정책·행정 주체​

키워드성격대표 출제 맥락
행정안전부디지털정부·공공데이터 주무 부처UI/UX 가이드라인, 공공데이터 표준화 매뉴얼
개인정보보호위원회개인정보 정책·감독 기관AI 개인정보 자율점검표, 마이데이터 보안 안내
국가정보원국가 보안 정책 주체국가 망 보안체계(N2SF) 가이드라인
국가사이버안보센터사이버 위협 대응 기관생성형 AI 보안 가이드라인
국회입법 기관개인정보보호법·데이터 관련 법률 개정

5) 빠른 암기 포인트 (시험용)​

  • 사건: 4차 산업혁명 → 코로나-19 → 데이터 3법/개인정보보호법 개정 → 인공지능기본법 시행 순으로 시간축을 잡으면 서술이 쉬움.
  • 국가: 한국(집행/실무), 미국(프레임워크/표준), EU(규제) 3축 비교가 가장 자주 통함.
  • 인물: 폰 노이만(구조), 튜링(지능판별), 리먼(진화), 폴락(성능한계), 베이즈(추론)로 역할을 분리해 암기.
  • 단체: ISO/IEC/IEEE/NIST/OECD/TTA를 "표준-정책-실행" 관점으로 묶어 정리하면 답안 확장성이 높음.

6) 참고: 원문에서 많이 보인 역사 키워드(빈도 체감)​

  • 반복성이 특히 높은 축: 4차 산업혁명, ISO/IEC/IEEE, 데이터 3법, 개인정보보호법, TTA 표준, AI 가이드라인.
  • 최근(136~138회) 강화 축: AI RMF, 인공지능기본법, 생성형 AI 이용자 보호 가이드라인, N2SF, PET.
