04. 데이터 / DB

1. 데이터 모델링​

1.1 데이터 모델링 기초​

1.1.1 모델링 개념​

  • Data Modeling: 데이터 구조와 관계를 체계적으로 표현하는 활동
  • Abstraction: 핵심만 추려 데이터를 단순화하는 추상화
  • Business Rule: 데이터에 적용되는 업무 규칙
  • Data Independence: 데이터와 응용의 독립성 확보
  • Inside-Out: 핵심 엔터티부터 확장하는 모델링 접근
  • Outside-In: 외부 요구부터 내부로 좁혀가는 모델링 접근

1.2 데이터 모델​

1.2.1 모델 종류​

  • Conceptual Data Model: 업무 관점의 개념적 데이터 모델
  • Logical Data Model: 구조·규칙을 정의한 논리적 데이터 모델
  • Physical Data Model: DBMS 구현을 반영한 물리적 데이터 모델

1.2.2 모델링 절차​

  • Forward Engineering: 모델에서 실제 DB를 생성하는 순공학
  • Reverse Engineering: 기존 DB에서 모델을 도출하는 역공학
  • Data Modeling Process: 개념→논리→물리로 이어지는 모델링 절차

1.3 엔터티​

1.3.1 Entity​

  • Strong Entity: 독립적으로 존재하는 강한 엔터티
  • Weak Entity: 다른 엔터티에 의존하는 약한 엔터티
  • Supertype: 공통 속성을 가진 상위 유형
  • Subtype: 상위 유형을 상속한 하위 유형

1.4 속성​

1.4.1 Attribute​

  • Simple Attribute: 더 나눌 수 없는 단순 속성
  • Composite Attribute: 여러 하위 속성으로 구성된 복합 속성
  • Derived Attribute: 다른 값에서 계산되는 유도 속성
  • Multi-valued Attribute: 여러 값을 가질 수 있는 다중값 속성

1.5 관계​

1.5.1 Relationship​

  • Cardinality: 관계에 참여하는 개체 수를 나타내는 관계 차수
  • Optionality: 관계 참여의 선택·필수 여부
  • Identifying Relationship: 식별자에 영향을 주는 식별 관계
  • Non-identifying Relationship: 식별자에 영향 없는 비식별 관계

1.6 식별자​

1.6.1 Key​

  • Primary Key: 튜플을 유일하게 식별하는 기본키
  • Foreign Key: 다른 테이블을 참조하는 외래키
  • Alternate Key: 기본키 외의 후보키인 대체키
  • Composite Key: 여러 컬럼으로 구성된 복합키
  • Surrogate Key: 인위적으로 부여한 대리키

1.7 무결성​

1.7.1 Integrity​

  • Entity Integrity: 기본키의 유일성·비널을 보장하는 개체 무결성
  • Referential Integrity: 외래키 참조 일관성을 보장하는 참조 무결성
  • Domain Integrity: 속성 값이 허용 범위를 지키는 도메인 무결성
  • Business Integrity: 업무 규칙을 반영한 무결성

1.8 정규화​

1.8.1 Normalization​

  • 1NF: 원자값만 갖도록 하는 제1정규형
  • 2NF: 부분 함수 종속을 제거한 제2정규형
  • 3NF: 이행 함수 종속을 제거한 제3정규형
  • BCNF: 결정자가 후보키가 되도록 하는 정규형
  • Denormalization: 성능을 위해 의도적으로 중복을 허용하는 반정규화

2. 관계형 데이터베이스​

2.1 관계형 모델​

2.1.1 Relational Model​

  • Relation: 행과 열로 구성된 관계(테이블)
  • Tuple: 관계의 한 행인 튜플
  • Attribute: 관계의 한 열인 속성
  • Domain: 속성이 가질 수 있는 값의 범위
  • Relational Algebra: 관계 연산을 다루는 관계대수

2.2 SQL​

2.2.1 DDL​

  • CREATE: 객체를 생성하는 정의어
  • ALTER: 객체 구조를 변경하는 정의어
  • DROP: 객체를 삭제하는 정의어

2.2.2 DML​

  • SELECT: 데이터를 조회하는 조작어
  • INSERT: 데이터를 삽입하는 조작어
  • UPDATE: 데이터를 수정하는 조작어
  • DELETE: 데이터를 삭제하는 조작어
  • MERGE: 삽입·수정을 한 번에 처리하는 조작어

2.2.3 DCL​

  • GRANT: 권한을 부여하는 제어어
  • REVOKE: 권한을 회수하는 제어어

2.2.4 TCL​

  • COMMIT: 트랜잭션을 확정하는 제어어
  • ROLLBACK: 트랜잭션을 취소하는 제어어
  • SAVEPOINT: 롤백 지점을 지정하는 제어어

2.3 Query Optimization​

2.3.1 SQL 성능​

  • Optimizer: 최적 실행 경로를 결정하는 옵티마이저
  • Execution Plan: 쿼리 실행 방식을 나타내는 실행 계획
  • Hint: 옵티마이저에 실행 방식을 지시하는 힌트
  • Join Strategy: 테이블 결합 방식을 정하는 조인 전략

2.4 Index​

2.4.1 Index 구조​

  • B-Tree: 균형 트리 기반의 대표적 인덱스 구조
  • Bitmap Index: 비트맵으로 값을 표현하는 인덱스
  • Clustered Index: 데이터를 키 순으로 정렬 저장하는 인덱스
  • Non-clustered Index: 데이터와 분리된 별도 인덱스
  • Covering Index: 쿼리에 필요한 컬럼을 모두 포함한 인덱스

3. 트랜잭션​

3.1 Transaction​

3.1.1 ACID​

  • Atomicity: 전부 성공 또는 전부 취소되는 원자성
  • Consistency: 트랜잭션 후에도 일관성을 유지하는 성질
  • Isolation: 동시 트랜잭션이 서로 간섭하지 않는 고립성
  • Durability: 완료된 결과가 영구 보존되는 지속성

3.2 동시성 제어​

3.2.1 Concurrency​

  • Lock: 자원 접근을 제어하는 잠금
  • Deadlock: 서로 자원을 기다려 멈추는 교착 상태
  • Timestamp: 시간순으로 트랜잭션을 제어하는 기법
  • MVCC: 버전을 이용한 다중버전 동시성 제어
  • Optimistic Lock: 충돌이 드물다고 보는 낙관적 잠금
  • Pessimistic Lock: 충돌을 예상해 미리 잠그는 비관적 잠금

3.3 회복​

3.3.1 Recovery​

  • REDO: 완료된 트랜잭션을 다시 적용하는 회복 기법
  • UNDO: 미완료 트랜잭션을 취소하는 회복 기법
  • Checkpoint: 회복 기준점을 기록하는 지점
  • Log: 트랜잭션 변경을 기록하는 로그

4. NoSQL​

4.1 Key-Value​

4.1.1 Key Value Store​

  • Redis: 인메모리 기반의 고속 키-값 저장소
  • DynamoDB: AWS의 관리형 키-값 데이터베이스

4.2 Document​

4.2.1 Document DB​

  • MongoDB: JSON 문서 기반의 대표적 문서 DB
  • CouchDB: HTTP·JSON 기반의 문서 DB

4.3 Column​

4.3.1 Column Family​

  • Cassandra: 분산 확장에 강한 컬럼 패밀리 DB
  • HBase: 하둡 기반의 분산 컬럼 DB

4.4 Graph​

4.4.1 Graph DB​

  • Neo4j: 노드·관계 중심의 대표적 그래프 DB
  • RDF: 자원을 삼중항으로 표현하는 데이터 모델
  • SPARQL: RDF 데이터를 조회하는 질의 언어

5. 데이터웨어하우스​

5.1 DW​

5.1.1 Warehouse​

  • Data Warehouse: 분석을 위해 통합·축적한 데이터 저장소
  • Data Mart: 특정 주제·부서용의 소규모 데이터 저장소
  • ODS: 운영 데이터를 통합한 운영 데이터 저장소

5.2 ETL​

5.2.1 Data Integration​

  • ETL: 추출·변환·적재로 데이터를 통합하는 방식
  • ELT: 적재 후 변환하는 데이터 통합 방식
  • CDC: 변경된 데이터만 감지·반영하는 기법

5.3 분석​

5.3.1 OLAP​

  • MOLAP: 다차원 큐브 기반의 OLAP
  • ROLAP: 관계형 DB 기반의 OLAP
  • HOLAP: MOLAP과 ROLAP을 결합한 방식

6. 빅데이터 플랫폼​

6.1 Big Data​

6.1.1 Big Data​

  • 3V: 규모·속도·다양성의 빅데이터 3대 특성
  • 5V: 3V에 정확성·가치를 더한 특성
  • Data Lake: 원천 데이터를 원형으로 저장하는 저장소

6.2 Hadoop​

6.2.1 Hadoop Ecosystem​

  • HDFS: 대용량 파일을 분산 저장하는 하둡 파일시스템
  • MapReduce: 분산 병렬 처리를 위한 프로그래밍 모델
  • YARN: 하둡의 자원 관리·스케줄링 계층
  • Hive: SQL로 하둡 데이터를 조회하는 도구
  • Pig: 스크립트로 대용량 데이터를 처리하는 도구

6.3 Spark​

6.3.1 Spark​

  • RDD: 스파크의 분산 불변 데이터 집합
  • DataFrame: 구조화 데이터를 다루는 스파크 추상화
  • Spark SQL: 스파크에서 SQL로 데이터를 처리하는 모듈
  • Streaming: 실시간 스트림을 처리하는 스파크 기능

7. 데이터 아키텍처​

7.1 데이터 관리​

7.1.1 Architecture​

  • Data Architecture: 데이터 구조·흐름·표준을 정의한 아키텍처
  • Metadata: 데이터를 설명하는 데이터
  • Master Data: 핵심 업무 기준이 되는 마스터 데이터
  • Reference Data: 코드·분류 등 참조용 기준 데이터

7.2 데이터 거버넌스​

7.2.1 Governance​

  • Data Governance: 데이터 관리 정책·책임을 통제하는 거버넌스
  • Data Steward: 데이터 품질·관리를 실무 담당하는 역할
  • Data Owner: 데이터에 대한 책임·권한을 가진 소유자
  • Data Catalog: 데이터 자산을 정리·검색하는 목록

7.3 데이터 품질​

7.3.1 Data Quality​

  • Accuracy: 데이터가 실제와 일치하는 정확성
  • Completeness: 필요한 데이터가 빠짐없는 완전성
  • Consistency: 데이터가 서로 모순 없는 일관성
  • Timeliness: 데이터가 제때 제공되는 적시성
  • Validity: 데이터가 규칙을 지키는 유효성

8. 데이터 플랫폼​

8.1 최신 데이터 플랫폼​

8.1.1 Modern Data Platform​

  • Data Lakehouse: 레이크와 웨어하우스를 결합한 플랫폼
  • Data Mesh: 도메인 단위로 데이터를 분산 소유하는 방식
  • Data Fabric: 데이터를 통합·연결하는 지능형 계층

8.2 실시간 데이터​

8.2.1 Streaming​

  • Kafka: 대용량 이벤트 스트리밍 플랫폼
  • Flink: 실시간 스트림 처리 엔진
  • CDC: 변경 데이터를 실시간 감지·전달하는 기법
  • Event Streaming: 이벤트를 스트림으로 처리하는 방식

9. AI 데이터​

9.1 AI Data​

9.1.1 AI Pipeline​

  • Feature Store: 학습·추론용 피처를 저장·공유하는 저장소
  • Vector Database: 임베딩 벡터를 저장·검색하는 DB
  • Embedding: 데이터를 벡터로 표현한 임베딩
  • RAG: 검색으로 보강해 답변 품질을 높이는 방식
  • Knowledge Graph: 개체와 관계를 그래프로 표현한 지식 그래프

9.2 MLOps 데이터​

9.2.1 ML Data​

  • Dataset Versioning: 데이터셋 변경 이력을 관리하는 버전 관리
  • Data Drift: 시간에 따라 데이터 분포가 변하는 현상
  • Feature Engineering: 유용한 피처를 만드는 특성 공학
  • Data Labeling: 학습을 위해 데이터에 정답을 부여하는 작업

10. 데이터 보안​

10.1 개인정보​

10.1.1 Privacy​

  • Masking: 데이터 일부를 가리는 마스킹
  • Encryption: 데이터를 암호화해 보호하는 기법
  • Tokenization: 민감 값을 토큰으로 대체하는 기법
  • Pseudonymization: 식별정보를 가명 처리하는 기법

10.2 데이터 보호​

10.2.1 Security​

  • Backup: 데이터를 복제 보관하는 백업
  • Replication: 데이터를 실시간 복제하는 복제
  • Disaster Recovery: 재해 시 데이터를 복구하는 체계
  • Data Loss Prevention (DLP): 데이터 유출을 방지하는 솔루션
