07. 정보보안

1. 정보보안 개요​

1.1 보안 기본​

1.1.1 정보보안 개념​

  • Information Security: 정보의 기밀성·무결성·가용성을 지키는 활동
  • CIA Triad: 기밀성·무결성·가용성의 보안 3대 요소
  • AAA: 인증·인가·계정관리의 보안 프레임워크
  • Security Policy: 보안 목표·규칙을 정의한 정책
  • Security Governance: 보안을 통제·관리하는 거버넌스
  • Zero Trust: 아무것도 신뢰하지 않고 항상 검증하는 보안

1.2 보안 관리​

1.2.1 보안관리체계​

  • ISMS: 정보보호 관리체계 인증
  • ISMS-P: 정보보호·개인정보보호 관리체계 인증
  • ISO/IEC 27001: 정보보안 관리체계 국제 표준
  • ISO/IEC 27002: 정보보안 통제 실무 지침
  • NIST CSF: NIST의 사이버보안 프레임워크

1.2.2 위험관리​

  • Risk Assessment: 위험을 식별·평가하는 활동
  • Risk Analysis: 위험의 크기·영향을 분석하는 활동
  • Risk Treatment: 위험을 처리·대응하는 활동
  • Risk Register: 식별된 위험을 정리한 등록부

2. 암호기술​

2.1 대칭키​

2.1.1 Symmetric Cryptography​

  • DES: 초기의 대칭키 블록 암호
  • 3DES: DES를 3번 적용해 강화한 암호
  • AES: 현재 표준으로 쓰이는 대칭키 암호
  • SEED: 국내에서 개발한 대칭키 암호
  • ARIA: 국내 표준 대칭키 블록 암호

2.2 공개키​

2.2.1 Asymmetric Cryptography​

  • RSA: 소인수분해 기반의 공개키 암호
  • ECC: 타원곡선 기반의 공개키 암호
  • Diffie-Hellman: 안전하게 키를 교환하는 방식
  • ElGamal: 이산대수 기반의 공개키 암호

2.3 해시​

2.3.1 Hash​

  • SHA: 표준 해시 함수 계열
  • SHA-2: 널리 쓰이는 안전한 해시 함수군
  • SHA-3: 스펀지 구조 기반의 최신 해시 함수
  • HMAC: 해시와 키로 무결성을 검증하는 인증 코드
  • Salt: 해시 강화를 위해 추가하는 무작위 값

2.4 전자서명​

2.4.1 Digital Signature​

  • PKI: 공개키 기반의 인증 체계
  • Certificate: 공개키 소유자를 증명하는 인증서
  • CA: 인증서를 발급하는 인증기관
  • CRL: 폐기된 인증서 목록
  • OCSP: 인증서 상태를 실시간 확인하는 프로토콜

3. 인증 및 접근통제​

3.1 인증​

3.1.1 Authentication​

  • Password: 비밀번호 기반 인증
  • MFA: 두 가지 이상 수단으로 인증하는 다중 인증
  • OTP: 일회용 비밀번호 인증
  • Biometrics: 생체 정보를 이용한 인증
  • FIDO: 비밀번호 없는 생체·기기 기반 인증 표준

3.2 권한관리​

3.2.1 Authorization​

  • RBAC: 역할 기반으로 권한을 부여하는 접근통제
  • ABAC: 속성 기반으로 권한을 부여하는 접근통제
  • DAC: 소유자가 권한을 결정하는 임의 접근통제
  • MAC: 정책에 따라 강제하는 강제 접근통제
  • ACL: 자원별 접근 권한을 나열한 목록

3.3 IAM​

3.3.1 Identity Management​

  • IAM: 신원과 접근 권한을 관리하는 체계
  • SSO: 한 번 로그인으로 여러 서비스를 쓰는 통합 인증
  • Federation: 서로 다른 도메인 간 신원을 연계하는 방식
  • OAuth: 권한을 위임하는 인가 프로토콜
  • OpenID Connect: OAuth 기반의 인증 프로토콜
  • SAML: XML 기반의 인증·인가 연계 표준

4. 네트워크 보안​

4.1 네트워크 보호​

4.1.1 Network Security​

  • Firewall: 트래픽을 통제하는 방화벽
  • IDS: 침입을 탐지하는 시스템
  • IPS: 침입을 탐지·차단하는 시스템
  • WAF: 웹 공격을 차단하는 웹 방화벽
  • NAC: 네트워크 접근을 통제하는 시스템

4.2 보안통신​

4.2.1 Secure Communication​

  • SSL/TLS: 통신을 암호화하는 보안 프로토콜
  • IPSec: IP 계층에서 통신을 보호하는 프로토콜
  • VPN: 암호화된 가상 사설망
  • SSH: 원격 접속을 암호화하는 프로토콜
  • HTTPS: TLS로 보호되는 웹 통신 프로토콜

4.3 공격 및 방어​

4.3.1 Network Attack​

  • DDoS: 대량 트래픽으로 서비스를 마비시키는 공격
  • Spoofing: 신원을 위장하는 공격
  • Sniffing: 네트워크 패킷을 몰래 가로채는 공격
  • MITM: 통신 중간에서 가로채는 중간자 공격
  • Session Hijacking: 세션을 탈취해 접근하는 공격

5. 시스템 보안​

5.1 서버 보안​

5.1.1 Operating System Security​

  • Linux Security: 리눅스 시스템 보안 설정·관리
  • Windows Security: 윈도우 시스템 보안 설정·관리
  • Hardening: 불필요 요소를 제거해 보안을 강화하는 활동
  • Patch Management: 취약점 패치를 관리하는 활동

5.2 엔드포인트​

5.2.1 Endpoint Security​

  • Anti Virus: 악성코드를 탐지·제거하는 백신
  • EDR: 단말 위협을 탐지·대응하는 솔루션
  • XDR: 여러 영역을 통합해 위협에 대응하는 솔루션
  • Device Control: 외부 장치 사용을 통제하는 기능

5.3 가상화 보안​

5.3.1 Virtualization Security​

  • VM Security: 가상머신 환경의 보안
  • Container Security: 컨테이너 환경의 보안
  • Kubernetes Security: 쿠버네티스 환경의 보안

6. 애플리케이션 보안​

6.1 Secure SDLC​

6.1.1 Secure Development​

  • Secure SDLC: 개발 전 과정에 보안을 내재화한 방법론
  • Threat Modeling: 위협을 사전에 식별·분석하는 활동
  • Secure Coding: 취약점을 예방하며 코드를 작성하는 활동
  • DevSecOps: 개발·운영에 보안을 통합한 방식

6.2 웹보안​

6.2.1 Web Security​

  • SQL Injection: SQL 조작으로 DB를 공격하는 기법
  • XSS: 악성 스크립트를 삽입하는 크로스사이트 스크립팅
  • CSRF: 사용자 권한을 도용해 요청을 위조하는 공격
  • SSRF: 서버가 내부 자원을 요청하게 만드는 공격
  • File Upload: 악성 파일 업로드를 통한 공격

6.3 API 보안​

6.3.1 API Security​

  • OAuth: 권한을 위임하는 인가 프로토콜
  • JWT: 클레임을 담아 서명한 토큰
  • API Gateway: API 요청을 중앙에서 통제하는 게이트웨이
  • Rate Limiting: 요청 횟수를 제한하는 기법

7. 클라우드 보안​

7.1 Cloud Security​

7.1.1 Cloud Security​

  • Shared Responsibility Model: 공급자·사용자가 보안을 분담하는 모델
  • CSPM: 클라우드 설정 위험을 관리하는 솔루션
  • CWPP: 워크로드를 보호하는 솔루션
  • CNAPP: 클라우드 네이티브 보안을 통합한 플랫폼

7.2 데이터 보안​

7.2.1 Data Protection​

  • Encryption: 데이터를 암호화해 보호하는 기법
  • Tokenization: 민감 값을 토큰으로 대체하는 기법
  • Masking: 데이터 일부를 가리는 마스킹
  • DLP: 데이터 유출을 방지하는 솔루션

7.3 Zero Trust​

7.3.1 Zero Trust​

  • Micro Segmentation: 네트워크를 세분화해 격리하는 기법
  • Continuous Verification: 접근을 지속적으로 검증하는 원칙
  • Least Privilege: 최소한의 권한만 부여하는 원칙

8. 개인정보 보호​

8.1 개인정보​

8.1.1 Privacy​

  • Personal Information: 개인을 식별할 수 있는 정보
  • Pseudonymization: 식별정보를 가명 처리하는 기법
  • Anonymization: 식별이 불가능하도록 익명화하는 기법
  • Consent: 정보 처리에 대한 동의

8.2 개인정보 관리​

8.2.1 Privacy Management​

  • Privacy by Design: 설계 단계부터 개인정보를 고려하는 원칙
  • Data Lifecycle: 데이터의 수집부터 파기까지의 생명주기
  • Data Retention: 데이터 보관 기간을 관리하는 정책

9. 보안 운영​

9.1 보안관제​

9.1.1 Security Operations​

  • SOC: 보안을 상시 관제하는 조직·센터
  • SIEM: 보안 이벤트를 수집·분석하는 시스템
  • SOAR: 보안 대응을 자동화·조율하는 체계
  • Threat Intelligence: 위협 정보를 수집·분석하는 활동

9.2 사고대응​

9.2.1 Incident Response​

  • Incident Handling: 보안 사고를 처리하는 활동
  • Digital Forensics: 디지털 증거를 수집·분석하는 활동
  • Malware Analysis: 악성코드를 분석하는 활동
  • CERT: 침해사고에 대응하는 전문 조직

9.3 취약점 관리​

9.3.1 Vulnerability​

  • CVE: 공개된 취약점을 식별하는 표준 코드
  • CVSS: 취약점 심각도를 점수화하는 체계
  • Penetration Test: 실제 공격을 모의하는 침투 테스트
  • Vulnerability Assessment: 취약점을 식별·평가하는 활동

10. 최신 정보보안​

10.1 AI 보안​

10.1.1 AI Security​

  • Prompt Injection: 악의적 프롬프트로 모델을 조작하는 공격
  • Adversarial Attack: 교란 입력으로 오작동을 유발하는 공격
  • Model Poisoning: 학습 과정을 오염시키는 공격
  • AI Governance: AI의 개발·운영을 통제하는 거버넌스

10.2 차세대 보안​

10.2.1 Emerging Security​

  • Zero Trust Architecture: 제로 트러스트를 구현한 보안 아키텍처
  • SASE: 네트워크와 보안을 통합한 클라우드 기반 서비스
  • SSE: SASE의 보안 기능을 담당하는 보안 서비스 엣지
  • Confidential Computing: 사용 중 데이터를 암호화 보호하는 컴퓨팅
  • Post Quantum Cryptography: 양자 컴퓨터에 대비한 암호 기술
