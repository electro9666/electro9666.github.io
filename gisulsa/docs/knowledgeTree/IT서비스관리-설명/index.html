09. IT서비스관리 (ITSM)

1. IT서비스관리 개요​

1.1 ITSM 기본​

1.1.1 ITSM 개념​

  • IT Service Management (ITSM): IT 서비스를 체계적으로 관리하는 활동
  • IT Service: 고객에게 가치를 제공하는 IT 서비스
  • Service Value: 서비스가 창출하는 가치
  • Service Lifecycle: 서비스의 전략부터 개선까지의 생명주기
  • Service Relationship: 공급자와 고객 간 서비스 관계

1.2 ITIL​

1.2.1 ITIL Framework​

  • ITIL v3: 서비스 생명주기 중심의 ITIL 이전 버전
  • ITIL 4: 가치·실천 중심으로 개편된 최신 ITIL
  • Service Value System (SVS): 가치를 창출하는 전체 시스템
  • Service Value Chain: 가치를 만드는 활동 흐름
  • Guiding Principles: ITIL의 핵심 안내 원칙

1.3 서비스관리 표준​

1.3.1 Standards​

  • ISO/IEC 20000: IT 서비스 관리 국제 표준
  • COBIT: IT 거버넌스·관리 프레임워크
  • MOF: 마이크로소프트의 운영 프레임워크

2. 서비스 전략 및 설계​

2.1 서비스 전략​

2.1.1 Strategy​

  • Service Portfolio: 전체 서비스 자산을 관리하는 포트폴리오
  • Service Catalog: 제공 중인 서비스를 정리한 카탈로그
  • Business Relationship Management: 고객 관계를 관리하는 활동
  • Demand Management: 서비스 수요를 예측·조절하는 활동

2.2 서비스 설계​

2.2.1 Design​

  • Service Design: 서비스를 설계하는 활동
  • Availability Management: 서비스 가용성을 관리하는 활동
  • Capacity Management: 자원 용량을 관리하는 활동
  • IT Service Continuity Management: 서비스 연속성을 보장하는 관리
  • Information Security Management: 정보 보안을 관리하는 활동

3. 서비스 전환​

3.1 변경관리​

3.1.1 Change Management​

  • Standard Change: 사전 승인된 정형 변경
  • Normal Change: 검토·승인이 필요한 일반 변경
  • Emergency Change: 긴급히 처리하는 변경
  • CAB: 변경을 심의하는 변경자문위원회

3.2 릴리즈관리​

3.2.1 Release Management​

  • Release: 변경을 묶어 배포용으로 공식화하는 활동
  • Deployment: 릴리즈를 실제 환경에 배치하는 활동
  • Version Management: 버전을 관리하는 활동
  • Rollback: 문제 발생 시 이전 상태로 되돌리는 활동

3.3 구성관리​

3.3.1 Configuration Management​

  • CMDB: 구성 항목 정보를 저장하는 관리 DB
  • Configuration Item (CI): 관리 대상이 되는 구성 항목
  • Asset: 관리되는 IT 자산
  • Discovery: 구성 항목을 자동 탐지하는 활동

4. 서비스 운영​

4.1 운영 프로세스​

4.1.1 Operations​

  • Service Desk: 사용자 문의를 접수·처리하는 단일 창구
  • Incident Management: 장애를 신속 복구하는 관리
  • Request Fulfillment: 서비스 요청을 처리하는 활동
  • Event Management: 이벤트를 감지·처리하는 관리

4.2 문제관리​

4.2.1 Problem Management​

  • Root Cause Analysis: 근본 원인을 분석하는 활동
  • Known Error: 원인이 파악된 알려진 오류
  • KEDB: 알려진 오류를 정리한 데이터베이스

4.3 접근관리​

4.3.1 Access Management​

  • Identity Management: 신원을 관리하는 활동
  • Access Control: 접근 권한을 통제하는 활동
  • Privileged Account: 높은 권한을 가진 특권 계정

5. 서비스 개선​

5.1 지속적 개선​

5.1.1 Continual Improvement​

  • CSI: 서비스를 지속적으로 개선하는 활동
  • PDCA: 계획-실행-점검-조치의 개선 순환
  • KPI: 성과를 측정하는 핵심 지표
  • CSF: 성공에 결정적인 핵심 성공 요인

5.2 서비스 측정​

5.2.1 Measurement​

  • SLA: 고객과 합의한 서비스 수준 협약
  • SLO: 목표로 삼는 서비스 수준 목표
  • SLI: 서비스 수준을 나타내는 지표
  • XLA: 사용자 경험 기반의 서비스 수준 협약

6. IT 운영관리​

6.1 운영관리​

6.1.1 IT Operations​

  • ITOM: IT 운영을 관리하는 활동
  • Monitoring: 시스템 상태를 감시하는 활동
  • Batch Management: 일괄 작업을 관리하는 활동
  • Job Scheduling: 작업 실행을 예약·관리하는 활동

6.2 자산관리​

6.2.1 IT Asset Management​

  • ITAM: IT 자산을 관리하는 활동
  • Hardware Asset Management: 하드웨어 자산을 관리하는 활동
  • Software Asset Management: 소프트웨어 자산을 관리하는 활동
  • License Management: 라이선스를 관리하는 활동

6.3 운영자동화​

6.3.1 Automation​

  • Runbook Automation: 운영 절차를 자동화하는 방식
  • Workflow Automation: 업무 흐름을 자동화하는 방식
  • Self Healing: 장애를 스스로 복구하는 기능
  • Auto Remediation: 문제를 자동으로 조치하는 기능

7. 서비스 거버넌스​

7.1 거버넌스​

7.1.1 Governance​

  • COBIT: IT 거버넌스·관리 프레임워크
  • Governance: 통제·의사결정 체계
  • Compliance: 규제·정책 준수
  • Audit: 준수 여부를 점검하는 감사

7.2 위험관리​

7.2.1 Risk​

  • Operational Risk: 운영 과정에서 발생하는 위험
  • Service Risk: 서비스에 영향을 주는 위험
  • Business Continuity: 사업을 지속하는 연속성 관리
  • Disaster Recovery: 재해 시 시스템을 복구하는 체계

8. 디지털 서비스관리​

8.1 DevOps​

8.1.1 DevOps Integration​

  • DevOps: 개발과 운영을 통합하는 문화·실천
  • DevSecOps: 개발·운영에 보안을 통합한 방식
  • GitOps: Git 기반으로 배포를 관리하는 방식
  • Continuous Delivery: 언제든 배포 가능한 상태를 유지하는 방식

8.2 SRE​

8.2.1 Site Reliability Engineering​

  • SRE: 공학으로 운영을 개선하는 사이트 신뢰성 공학
  • Error Budget: 허용 가능한 오류 한도
  • Toil: 반복적인 수작업 운영 부담
  • Reliability Engineering: 신뢰성을 확보하는 공학 활동

8.3 AIOps​

8.3.1 AI Operations​

  • AIOps: AI로 IT 운영을 지능화하는 방식
  • Event Correlation: 이벤트 간 연관성을 분석하는 활동
  • Predictive Analytics: 데이터로 미래를 예측하는 분석
  • Intelligent Automation: AI 기반의 지능형 자동화

9. IT 서비스 품질​

9.1 품질관리​

9.1.1 Service Quality​

  • Service Availability: 서비스가 정상 동작하는 가용성
  • Reliability: 오류 없이 동작하는 신뢰성
  • Maintainability: 수정·개선의 용이성
  • Customer Satisfaction: 고객 만족도

9.2 서비스 성과​

9.2.1 Performance​

  • KPI: 성과를 측정하는 핵심 지표
  • CSF: 성공에 결정적인 핵심 성공 요인
  • Balanced Scorecard: 균형 잡힌 성과 관리 도구
  • Value Stream: 가치를 만드는 활동 흐름

10. 최신 IT서비스관리​

10.1 Digital ITSM​

10.1.1 Digital Service​

  • Enterprise Service Management (ESM): ITSM을 전사로 확장한 서비스 관리
  • Experience Level Agreement (XLA): 사용자 경험 기반의 서비스 수준 협약
  • Platform Engineering: 개발자 셀프서비스 플랫폼을 구축하는 분야
  • Internal Developer Platform (IDP): 개발자용 내부 개발 플랫폼

10.2 AI 기반 서비스관리​

10.2.1 AI Service Management​

  • AI Service Desk: AI로 문의를 응대하는 서비스 데스크
  • AI ChatOps: 채팅으로 운영을 수행하는 AI 방식
  • Autonomous Operations: 사람 개입 없이 운영하는 자율 운영
  • Digital Employee Experience (DEX): 직원의 디지털 업무 경험
