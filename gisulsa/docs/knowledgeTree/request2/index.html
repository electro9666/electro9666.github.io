좋습니다.

지금까지 논의하면서 느낀 점은 "과목"이 아니라 "정보관리기술사의 Body of Knowledge(BOK)"를 먼저 정의해야 한다는 것입니다.

기술사는 특정 프로그래밍 기술을 평가하는 시험이 아니라 기업의 정보시스템을 기획·구축·운영·관리하는 최고 수준의 IT 전문가를 평가합니다. 따라서 BOK도 그 관점에서 구성하는 것이 적절합니다.

제가 추천하는 최상위 BOK는 다음과 같습니다.

정보관리기술사 Body of Knowledge (BOK)

Information Management Professional Engineer (BOK)

1. Computer Science Foundation
2. Software Engineering
3. Data & Artificial Intelligence
4. Infrastructure & Platform
5. Enterprise Management
6. Emerging Technology

이 6개의 축은 서로 겹치지 않으면서도 정보관리기술사의 출제 범위를 거의 모두 포괄합니다.

1. Computer Science Foundation (기초 CS)

컴퓨터 시스템의 원리를 이해하는 기반 지식

Computer Science Foundation
├─ 자료구조
├─ 알고리즘
├─ 컴퓨터구조
├─ 운영체제
├─ 네트워크
├─ 분산시스템
├─ 병렬처리
└─ 시스템 성능

예시 기출

  • Cache
  • Virtual Memory
  • Deadlock
  • TCP/IP
  • CAP Theorem
  • Consistency
  • Load Balancing

2. Software Engineering (소프트웨어 엔지니어링)

시스템을 분석·설계·개발·관리하는 지식

Software Engineering
├─ 소프트웨어공학
├─ 소프트웨어아키텍처
├─ 개발방법론
├─ 프로젝트관리(PMP)
├─ 품질관리
├─ 테스트
├─ 형상관리
└─ DevOps

예시

  • Agile
  • MSA
  • DDD
  • CBD
  • CI/CD
  • Scrum
  • ATAM

3. Data & Artificial Intelligence

데이터를 자산화하고 AI를 활용하는 지식

Data & AI
├─ 데이터베이스
├─ 데이터모델링
├─ 데이터아키텍처
├─ 데이터거버넌스
├─ 빅데이터
├─ 데이터분석
├─ 머신러닝
├─ 생성형AI
└─ AI 거버넌스

예시

  • 정규화
  • Data Lake
  • Data Mesh
  • LLM
  • Vector DB
  • AI RMF

4. Infrastructure & Platform

IT 서비스를 실행하는 기반 플랫폼

Infrastructure & Platform
├─ 클라우드
├─ 정보보안
├─ ITSM
├─ 데이터센터
├─ 가상화

├─ Kubernetes

└─ SRE

예시

  • IaC

5. Enterprise Management

기업 관점에서 IT를 기획·통제·운영하는 지식

Enterprise Management
├─ IT경영
├─ EA
├─ IT거버넌스
├─ BPM
├─ BPR
├─ ERP
├─ CRM
├─ SCM
├─ IT투자관리
├─ 법·제도
├─ 계약·조달
├─ 감리
└─ 컴플라이언스

예시

  • TOGAF
  • KPI

미래 기술과 디지털 혁신

Emerging Technology
├─ Digital Transformation
├─ IoT
├─ CPS
├─ Digital Twin
├─ Blockchain
├─ Web3
├─ XR
├─ Quantum
├─ Robotics

예시

전체 BOK 구조

Information Management Professional Engineer

├─ 1. Computer Science Foundation
│
├─ 2. Software Engineering
│
├─ 3. Data & Artificial Intelligence
│
├─ 4. Infrastructure & Platform
│
├─ 5. Enterprise Management
│
└─ 6. Emerging Technology

왜 이 구조를 추천하는가?​

이 구조는 정보관리기술사의 역할과도 일치합니다.

  • 기초 원리 이해 → Computer Science Foundation
  • 시스템 개발 → Software Engineering
  • 데이터 활용 → Data & AI
  • 플랫폼 운영 → Infrastructure & Platform
  • 기업 관점의 관리 → Enterprise Management
  • 미래 변화 대응 → Emerging Technology

즉, 단순히 컴퓨터공학 교과목을 나열한 것이 아니라 기업의 정보시스템을 생애주기(Lifecycle)와 관리 관점에서 아우르는 BOK입니다.

한 가지 보완 제안​

현재의 6개 BOK도 충분히 체계적이지만, 정보관리기술사 기출을 장기간 관리하고 새로운 기술을 계속 추가할 계획이라면 **Level 0(최상위 BOK) → Level 1(6개 영역) → Level 2(15~20개 과목) → Level 3(대분류) → Level 4(중분류) → Level 5(소분류) → Level 6(기출 키워드)**의 7단계 계층으로 설계하는 것을 추천합니다. 이렇게 하면 새로운 기출과 기술이 등장해도 기존 구조를 거의 변경하지 않고 확장할 수 있습니다.
