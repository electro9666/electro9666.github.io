06. 클라우드 (Cloud Computing)

1. 클라우드 컴퓨팅 기초​

1.1 클라우드 개요​

1.1.1 기본 개념​

  • Cloud Computing: 인터넷으로 IT 자원을 필요할 때 이용하는 컴퓨팅
  • Cloud Native: 클라우드 환경에 최적화해 설계·운영하는 방식
  • Utility Computing: 사용량 기반으로 자원을 제공하는 방식
  • On-premise: 자체 시설에 직접 구축·운영하는 방식
  • Cloud Transformation: 기존 시스템을 클라우드로 전환하는 활동

1.2 클라우드 특성​

1.2.1 NIST 특성​

  • On-demand Self Service: 필요 시 스스로 자원을 조달하는 특성
  • Broad Network Access: 다양한 기기로 네트워크 접근이 가능한 특성
  • Resource Pooling: 자원을 모아 공유·할당하는 특성
  • Rapid Elasticity: 수요에 따라 신속히 확장·축소하는 특성
  • Measured Service: 사용량을 측정해 과금하는 특성

1.3 서비스 모델​

1.3.1 Service Model​

  • IaaS: 인프라를 서비스로 제공하는 모델
  • PaaS: 개발·실행 플랫폼을 서비스로 제공하는 모델
  • SaaS: 소프트웨어를 서비스로 제공하는 모델
  • FaaS: 함수 단위로 실행하는 서버리스 모델
  • CaaS: 컨테이너 실행 환경을 서비스로 제공하는 모델
  • DBaaS: 데이터베이스를 관리형 서비스로 제공하는 모델

1.4 구축 모델​

1.4.1 Deployment Model​

  • Public Cloud: 공용으로 제공되는 퍼블릭 클라우드
  • Private Cloud: 특정 조직 전용의 프라이빗 클라우드
  • Hybrid Cloud: 공용·전용을 결합한 하이브리드 클라우드
  • Multi Cloud: 여러 클라우드를 함께 사용하는 방식
  • Community Cloud: 공동체가 공유하는 클라우드

2. 클라우드 인프라​

2.1 가상화​

2.1.1 Virtualization​

  • Hypervisor: 가상머신을 생성·관리하는 계층
  • Type 1 Hypervisor: 하드웨어에 직접 설치하는 베어메탈 방식
  • Type 2 Hypervisor: OS 위에서 동작하는 호스트형 방식
  • VM: 가상화로 구현된 가상 머신
  • Virtual Machine Image: VM 생성에 쓰이는 이미지

2.2 컨테이너​

2.2.1 Container​

  • Docker: 애플리케이션을 컨테이너로 패키징·실행하는 플랫폼
  • OCI: 컨테이너 이미지·런타임의 개방형 표준
  • Image: 실행 요소를 담은 컨테이너 이미지
  • Registry: 컨테이너 이미지를 저장·배포하는 저장소
  • Namespace: 프로세스 자원을 격리하는 리눅스 기능
  • cgroups: 자원 사용량을 제한·격리하는 리눅스 기능

2.3 Kubernetes​

2.3.1 Kubernetes Architecture​

  • Pod: 컨테이너를 묶은 최소 배포 단위
  • Node: 파드를 실행하는 작업 노드
  • Cluster: 노드들로 구성된 쿠버네티스 클러스터
  • Deployment: 파드 배포·업데이트를 관리하는 객체
  • ReplicaSet: 파드 복제본 수를 유지하는 컨트롤러
  • DaemonSet: 모든 노드에 파드를 배치하는 컨트롤러
  • StatefulSet: 상태를 가진 파드를 관리하는 컨트롤러
  • Job: 일회성 작업을 실행하는 객체
  • CronJob: 예약된 시간에 작업을 실행하는 객체

2.3.2 Kubernetes Networking​

  • Service: 파드 집합에 안정적 접근을 제공하는 추상화
  • Ingress: 외부 트래픽을 서비스로 라우팅하는 진입점
  • Network Policy: 파드 간 통신을 제어하는 정책
  • CNI: 컨테이너 네트워크를 연결하는 인터페이스 표준

2.3.3 Kubernetes Storage​

  • Persistent Volume: 클러스터에 제공되는 영구 저장소
  • Persistent Volume Claim: 저장소를 요청하는 선언
  • Storage Class: 동적 저장소 프로비저닝을 정의하는 클래스
  • CSI: 컨테이너 스토리지를 연결하는 인터페이스 표준

3. 클라우드 네이티브​

3.1 Cloud Native​

3.1.1 Architecture​

  • Twelve-Factor App: 클라우드 앱 설계의 12가지 원칙
  • Immutable Infrastructure: 변경 대신 교체하는 불변 인프라
  • Stateless Application: 상태를 저장하지 않는 무상태 애플리케이션

3.2 MSA​

3.2.1 Microservices​

  • Service Discovery: 서비스 위치를 동적으로 찾는 메커니즘
  • API Gateway: 요청을 중앙에서 라우팅·관리하는 게이트웨이
  • Service Mesh: 서비스 간 통신을 인프라에서 제어하는 메시
  • Sidecar: 애플리케이션 옆에서 공통 기능을 담당하는 패턴
  • Envoy: 서비스 메시에 널리 쓰이는 프록시 서버

3.3 DevOps​

3.3.1 Automation​

  • CI/CD: 통합·배포를 자동화하는 지속적 파이프라인
  • GitOps: Git을 단일 소스로 배포를 관리하는 방식
  • DevSecOps: 개발 전 과정에 보안을 통합한 방식
  • Continuous Delivery: 언제든 배포 가능한 상태를 유지하는 방식

4. 클라우드 운영​

4.1 자동화​

4.1.1 Infrastructure as Code​

  • Terraform: 코드로 인프라를 프로비저닝하는 IaC 도구
  • CloudFormation: AWS 자원을 코드로 관리하는 도구
  • Ansible: 구성 관리·자동화를 수행하는 도구
  • Pulumi: 프로그래밍 언어로 인프라를 정의하는 도구

4.2 운영관리​

4.2.1 Cloud Operations​

  • Auto Scaling: 부하에 따라 자원을 자동 조절하는 기능
  • Load Balancer: 트래픽을 여러 자원에 분산하는 부하 분산기
  • CDN: 콘텐츠를 지역 캐시로 빠르게 전달하는 네트워크
  • DNS: 도메인을 IP로 변환하는 이름 해석 서비스
  • Health Check: 자원 상태를 주기적으로 점검하는 기능

4.3 관측성​

4.3.1 Observability​

  • Logging: 이벤트 기록을 남기는 로깅
  • Monitoring: 시스템 상태를 감시하는 모니터링
  • Metrics: 정량적 상태를 나타내는 지표
  • Tracing: 요청 흐름을 추적하는 트레이싱
  • OpenTelemetry: 관측 데이터 수집의 개방형 표준

5. 클라우드 데이터​

5.1 Storage​

5.1.1 Storage Service​

  • Object Storage: 객체 단위로 저장하는 스토리지
  • Block Storage: 블록 단위로 저장하는 고성능 스토리지
  • File Storage: 파일 시스템 형태의 공유 스토리지

5.2 Database​

5.2.1 Cloud Database​

  • RDS: 관리형 관계형 데이터베이스 서비스
  • NoSQL: 비정형·확장에 강한 비관계형 DB
  • NewSQL: RDB의 일관성과 NoSQL의 확장성을 결합한 DB
  • Distributed Database: 여러 노드에 분산 저장하는 DB

5.3 Data Platform​

5.3.1 Data Service​

  • Data Lake: 원천 데이터를 원형으로 저장하는 저장소
  • Data Warehouse: 분석용으로 통합·축적한 저장소
  • Lakehouse: 레이크와 웨어하우스를 결합한 구조
  • Streaming Platform: 실시간 데이터를 처리하는 플랫폼

6. 클라우드 보안​

6.1 보안 기본​

6.1.1 Security Model​

  • Shared Responsibility Model: 공급자·사용자가 보안을 분담하는 모델
  • Zero Trust: 아무것도 신뢰하지 않고 항상 검증하는 보안
  • IAM: 접근 주체와 권한을 관리하는 체계
  • MFA: 두 가지 이상 수단으로 인증하는 다중 인증

6.2 데이터 보안​

6.2.1 Data Security​

  • Encryption: 데이터를 암호화해 보호하는 기법
  • KMS: 암호화 키를 관리하는 서비스
  • HSM: 키를 하드웨어로 안전하게 보관하는 장비
  • Tokenization: 민감 값을 토큰으로 대체하는 기법

6.3 네트워크 보안​

6.3.1 Network Security​

  • Security Group: 인스턴스 단위의 가상 방화벽
  • NACL: 서브넷 단위의 네트워크 접근 제어 목록
  • VPN: 암호화된 가상 사설망
  • WAF: 웹 공격을 차단하는 웹 방화벽
  • Firewall: 트래픽을 통제하는 방화벽

6.4 운영 보안​

6.4.1 Security Operations​

  • CSPM: 클라우드 설정 위험을 관리하는 솔루션
  • CWPP: 워크로드를 보호하는 솔루션
  • CNAPP: 클라우드 네이티브 보안을 통합한 플랫폼
  • SIEM: 보안 이벤트를 수집·분석하는 시스템
  • SOAR: 보안 대응을 자동화·조율하는 체계

7. 클라우드 거버넌스​

7.1 거버넌스​

7.1.1 Governance​

  • Cloud Governance: 클라우드 사용을 통제하는 거버넌스
  • Landing Zone: 표준화된 초기 클라우드 환경 구성
  • Policy as Code: 정책을 코드로 정의·적용하는 방식
  • Tagging Strategy: 자원에 태그를 부여해 관리하는 전략

7.2 비용관리​

7.2.1 FinOps​

  • FinOps: 클라우드 비용을 최적화하는 운영 문화
  • Cost Allocation: 비용을 부서·프로젝트에 배분하는 활동
  • Reserved Instance: 약정으로 할인받는 예약 인스턴스
  • Savings Plan: 사용 약정으로 비용을 절감하는 요금제
  • Chargeback: 사용 비용을 실제 부서에 청구하는 방식
  • Showback: 사용 비용을 청구 없이 보여주는 방식

7.3 서비스 수준​

7.3.1 SLA​

  • SLA: 고객과 합의한 서비스 수준 협약
  • SLI: 서비스 수준을 나타내는 지표
  • SLO: 목표로 삼는 서비스 수준 목표
  • Availability: 서비스가 정상 동작하는 가용성

8. 클라우드 아키텍처​

8.1 설계원칙​

8.1.1 Cloud Architecture​

  • Well-Architected Framework: 클라우드 설계 모범사례 프레임워크
  • Scalability: 부하 증가에 대응하는 확장성
  • Resilience: 장애에서 회복하는 복원력
  • Fault Tolerance: 결함이 있어도 동작하는 내결함성

8.2 고가용성​

8.2.1 High Availability​

  • Multi-AZ: 여러 가용영역에 분산 배치하는 구성
  • Multi-Region: 여러 리전에 분산 배치하는 구성
  • Disaster Recovery: 재해 시 시스템을 복구하는 체계
  • Backup: 데이터를 복제 보관하는 백업
  • Replication: 데이터를 실시간 복제하는 복제

8.3 분산시스템​

8.3.1 Distributed Computing​

  • CAP Theorem: 일관성·가용성·분단내성 중 둘만 보장한다는 정리
  • BASE: 최종 일관성을 지향하는 분산 특성
  • Eventual Consistency: 시간이 지나면 일관성에 도달하는 성질
  • Consensus: 분산 노드가 합의에 이르는 메커니즘

9. 멀티클라우드​

9.1 Hybrid Cloud​

9.1.1 Hybrid​

  • Hybrid Architecture: 온프레미스와 클라우드를 결합한 구조
  • Cloud Bursting: 부하 급증 시 클라우드로 확장하는 방식
  • Edge Cloud: 사용자 근처에 배치한 엣지 클라우드

9.2 Multi Cloud​

9.2.1 Multi Cloud​

  • Vendor Lock-in: 특정 공급자에 종속되는 현상
  • Cloud Brokerage: 여러 클라우드를 중개·관리하는 서비스
  • Cross Cloud Networking: 클라우드 간 네트워크를 연결하는 기술

10. 최신 클라우드​

10.1 차세대 클라우드​

10.1.1 Emerging Technology​

  • Serverless: 서버 관리 없이 실행하는 서버리스 컴퓨팅
  • Edge Computing: 데이터 발생 근처에서 처리하는 방식
  • Green Cloud: 에너지 효율을 고려한 친환경 클라우드
  • Confidential Computing: 사용 중 데이터를 암호화 보호하는 컴퓨팅
  • GPU Cloud: GPU 자원을 제공하는 클라우드

10.2 AI Cloud​

10.2.1 AI Infrastructure​

  • AI Cloud: AI 워크로드에 특화된 클라우드
  • AI Factory: AI 모델을 대량 생산하는 인프라
  • GPU Cluster: GPU를 묶은 대규모 연산 클러스터
  • AI Platform: AI 개발·운영을 지원하는 통합 플랫폼
