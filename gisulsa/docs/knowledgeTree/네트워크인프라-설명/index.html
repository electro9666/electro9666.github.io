08. 네트워크 및 IT 인프라

1. 네트워크 기초​

1.1 네트워크 개요​

1.1.1 기본 개념​

  • Computer Network: 여러 기기를 연결해 통신하는 컴퓨터 네트워크
  • Protocol: 통신 규칙을 정의한 프로토콜
  • Packet: 전송 단위로 나눈 데이터 묶음
  • Frame: 데이터링크 계층의 전송 단위
  • MTU: 한 번에 전송 가능한 최대 패킷 크기
  • QoS: 트래픽 우선순위로 품질을 보장하는 기술

1.2 OSI 참조모델​

1.2.1 OSI 7 Layer​

  • Physical Layer: 비트를 전기·신호로 전송하는 물리 계층
  • Data Link Layer: 인접 노드 간 프레임을 전달하는 데이터링크 계층
  • Network Layer: 경로를 정해 패킷을 전달하는 네트워크 계층
  • Transport Layer: 종단 간 신뢰성 있는 전송을 담당하는 계층
  • Session Layer: 통신 세션을 설정·관리하는 세션 계층
  • Presentation Layer: 데이터 형식·암호화를 다루는 표현 계층
  • Application Layer: 사용자 응용과 접하는 응용 계층

1.3 TCP/IP​

1.3.1 TCP/IP Model​

  • IP: 패킷을 주소 기반으로 전달하는 인터넷 프로토콜
  • TCP: 신뢰성 있는 연결형 전송 프로토콜
  • UDP: 빠른 비연결형 전송 프로토콜
  • ICMP: 오류·상태를 전달하는 제어 프로토콜
  • ARP: IP를 MAC 주소로 변환하는 프로토콜
  • DHCP: IP 주소를 자동 할당하는 프로토콜

2. 네트워크 프로토콜​

2.1 전송계층​

2.1.1 TCP​

  • Three-way Handshake: 연결을 3단계로 설정하는 절차
  • Flow Control: 수신 속도에 맞춰 전송량을 조절하는 흐름 제어
  • Congestion Control: 네트워크 혼잡을 완화하는 혼잡 제어
  • Sliding Window: 윈도우 단위로 전송량을 관리하는 기법

2.2 응용계층​

2.2.1 Application Protocol​

  • HTTP: 웹 자원을 주고받는 통신 프로토콜
  • HTTPS: TLS로 암호화된 웹 통신 프로토콜
  • DNS: 도메인을 IP로 변환하는 이름 해석 프로토콜
  • SMTP: 이메일을 전송하는 프로토콜
  • FTP: 파일을 전송하는 프로토콜
  • SNMP: 네트워크 장비를 관리하는 프로토콜
  • MQTT: IoT에 쓰이는 경량 메시징 프로토콜

2.3 라우팅​

2.3.1 Routing​

  • RIP: 홉 수 기반의 거리벡터 라우팅 프로토콜
  • OSPF: 링크 상태 기반의 라우팅 프로토콜
  • BGP: 자율시스템 간 경로를 교환하는 라우팅 프로토콜
  • Static Routing: 경로를 수동 설정하는 정적 라우팅
  • Dynamic Routing: 경로를 자동 계산하는 동적 라우팅

3. 네트워크 장비​

3.1 스위치​

3.1.1 Switching​

  • L2 Switch: MAC 주소 기반으로 전달하는 2계층 스위치
  • L3 Switch: IP 라우팅 기능을 갖춘 3계층 스위치
  • VLAN: 물리망을 논리적으로 분할한 가상 LAN
  • STP: 루프를 방지하는 스패닝 트리 프로토콜
  • Trunk: 여러 VLAN을 한 링크로 전달하는 트렁크

3.2 라우터​

3.2.1 Router​

  • NAT: 사설 IP를 공인 IP로 변환하는 기술
  • PAT: 포트로 여러 IP를 하나로 변환하는 기술
  • Routing Table: 경로 정보를 담은 라우팅 테이블

3.3 로드밸런서​

3.3.1 Load Balancing​

  • L4 Load Balancer: IP·포트 기반으로 분산하는 부하 분산기
  • L7 Load Balancer: 애플리케이션 내용 기반으로 분산하는 부하 분산기
  • Reverse Proxy: 서버 앞단에서 요청을 중계하는 프록시

4. 데이터센터 인프라​

4.1 서버​

4.1.1 Computing​

  • Physical Server: 물리적 하드웨어 서버
  • Blade Server: 얇은 모듈형으로 밀집 배치하는 서버
  • Rack Server: 랙에 장착하는 표준형 서버

4.2 스토리지​

4.2.1 Storage​

  • DAS: 서버에 직접 연결하는 저장장치
  • NAS: 네트워크로 파일을 공유하는 저장장치
  • SAN: 고속 네트워크 기반의 블록 저장장치
  • Object Storage: 객체 단위로 저장하는 스토리지

4.3 백업​

4.3.1 Backup​

  • Full Backup: 전체 데이터를 백업하는 방식
  • Incremental Backup: 변경분만 백업하는 증분 백업
  • Differential Backup: 최근 전체 백업 이후 변경분을 백업하는 차등 백업
  • Snapshot: 특정 시점 상태를 저장하는 스냅샷

5. 운영체제 및 가상화​

5.1 운영체제​

5.1.1 OS​

  • Linux: 오픈소스 기반의 유닉스 계열 운영체제
  • Windows Server: 마이크로소프트의 서버 운영체제
  • UNIX: 안정성이 높은 다중 사용자 운영체제
  • Process: 실행 중인 프로그램 단위
  • Thread: 프로세스 내 실행 흐름 단위
  • Scheduling: CPU에 작업을 배분하는 스케줄링

5.2 가상화​

5.2.1 Virtualization​

  • Hypervisor: 가상머신을 생성·관리하는 계층
  • VMware: 대표적 상용 가상화 플랫폼
  • KVM: 리눅스 커널 기반의 가상화 기술
  • Xen: 오픈소스 하이퍼바이저

5.3 컨테이너​

5.3.1 Container​

  • Docker: 애플리케이션을 컨테이너로 실행하는 플랫폼
  • Kubernetes: 컨테이너를 오케스트레이션하는 플랫폼
  • Podman: 데몬 없이 동작하는 컨테이너 도구
  • Container Runtime: 컨테이너를 실행하는 런타임

6. 네트워크 운영​

6.1 운영관리​

6.1.1 Network Operation​

  • NMS: 네트워크를 감시·관리하는 시스템
  • SNMP: 네트워크 장비를 관리하는 프로토콜
  • NetFlow: 트래픽 흐름을 수집·분석하는 기술
  • Syslog: 시스템 로그를 수집하는 표준

6.2 장애관리​

6.2.1 Fault Management​

  • Root Cause Analysis: 장애의 근본 원인을 분석하는 활동
  • MTBF: 고장 사이의 평균 시간
  • MTTR: 평균 복구 시간
  • Incident Management: 장애를 처리·복구하는 관리

6.3 성능관리​

6.3.1 Performance​

  • Throughput: 단위 시간당 처리량
  • Latency: 요청과 응답 사이의 지연 시간
  • Jitter: 지연 시간의 변동 폭
  • Packet Loss: 전송 중 손실되는 패킷 비율

7. 고가용성 및 재해복구​

7.1 고가용성​

7.1.1 High Availability​

  • HA: 장애에도 서비스를 지속하는 고가용성
  • Cluster: 여러 노드를 묶어 가용성을 높이는 구성
  • Failover: 장애 시 예비로 전환하는 기법
  • Load Balancing: 부하를 분산하는 기법

7.2 재해복구​

7.2.1 Disaster Recovery​

  • DR: 재해 시 시스템을 복구하는 체계
  • RTO: 목표 복구 시간
  • RPO: 허용 가능한 데이터 손실 시점
  • Backup Site: 복구용 예비 사이트
  • Active-Active: 두 사이트를 동시 운영하는 구성
  • Active-Standby: 주 사이트 장애 시 대기 사이트로 전환하는 구성

8. 인프라 자동화​

8.1 자동화​

8.1.1 Automation​

  • Infrastructure as Code: 코드로 인프라를 관리하는 방식
  • Ansible: 구성 관리·자동화를 수행하는 도구
  • Terraform: 코드로 인프라를 프로비저닝하는 도구
  • PXE: 네트워크로 OS를 부팅·설치하는 기술

8.2 운영자동화​

8.2.1 Operations​

  • Configuration Management: 시스템 구성을 통제하는 관리
  • Provisioning: 자원을 준비·할당하는 활동
  • Auto Scaling: 부하에 따라 자원을 자동 조절하는 기능

9. 네트워크 아키텍처​

9.1 기업 네트워크​

9.1.1 Enterprise Network​

  • LAN: 근거리 지역 네트워크
  • WAN: 원거리 광역 네트워크
  • SDN: 소프트웨어로 네트워크를 제어하는 기술
  • SD-WAN: 소프트웨어로 WAN을 제어하는 기술

9.2 최신 네트워크​

9.2.1 Modern Network​

  • NFV: 네트워크 기능을 소프트웨어로 가상화하는 기술
  • VXLAN: L2를 L3 위로 확장하는 오버레이 기술
  • EVPN: VXLAN 제어를 담당하는 이더넷 VPN
  • Spine-Leaf: 확장성이 높은 데이터센터 네트워크 구조

10. 최신 인프라​

10.1 차세대 인프라​

10.1.1 Emerging Infrastructure​

  • Edge Computing: 데이터 발생 근처에서 처리하는 방식
  • Hyper Converged Infrastructure (HCI): 컴퓨팅·스토리지·네트워크를 통합한 인프라
  • Composable Infrastructure: 자원을 유연하게 조립하는 인프라
  • Software Defined Data Center (SDDC): 소프트웨어로 정의·관리하는 데이터센터

10.2 운영 트렌드​

10.2.1 Future Operation​

  • AIOps: AI로 IT 운영을 지능화하는 방식
  • Observability: 내부 상태를 관측할 수 있는 관측성
  • Digital Infrastructure: 디지털 서비스를 뒷받침하는 인프라
  • Green Data Center: 에너지 효율을 고려한 친환경 데이터센터
