05. AI / 빅데이터

1. AI 기초​

1.1 인공지능 개요​

1.1.1 AI 기본개념​

  • Artificial Intelligence: 인간의 지능을 기계로 구현하는 기술
  • Machine Intelligence: 기계가 학습·추론하는 지능
  • Strong AI: 인간 수준의 범용 지능을 갖춘 강한 AI
  • Weak AI: 특정 작업에 특화된 약한 AI
  • Expert System: 전문가 지식을 규칙으로 구현한 시스템
  • Knowledge Representation: 지식을 컴퓨터가 다루도록 표현하는 방식

1.2 AI 발전​

1.2.1 AI Evolution​

  • Symbolic AI: 규칙·기호 기반의 초기 인공지능
  • Machine Learning: 데이터로 규칙을 학습하는 머신러닝
  • Deep Learning: 심층 신경망 기반의 딥러닝
  • Generative AI: 새로운 콘텐츠를 생성하는 생성형 AI
  • Agentic AI: 자율적으로 목표를 수행하는 에이전트형 AI

1.3 AI 윤리​

1.3.1 Responsible AI​

  • AI Ethics: AI의 윤리적 개발·사용 원칙
  • Explainable AI (XAI): 판단 근거를 설명 가능한 AI
  • Fairness: 편향 없이 공정하게 작동하는 성질
  • Transparency: 동작·결정 과정을 투명하게 공개하는 성질
  • Accountability: 결과에 대한 책임을 지는 책무성
  • AI Trustworthiness: 신뢰할 수 있는 AI 특성

2. 머신러닝​

2.1 학습방법​

2.1.1 Learning Type​

  • Supervised Learning: 정답이 있는 데이터로 학습하는 지도학습
  • Unsupervised Learning: 정답 없이 패턴을 찾는 비지도학습
  • Semi-supervised Learning: 일부 정답만으로 학습하는 준지도학습
  • Reinforcement Learning: 보상으로 행동을 학습하는 강화학습
  • Self-supervised Learning: 데이터 자체로 라벨을 만드는 자기지도학습

2.2 모델​

2.2.1 Machine Learning Model​

  • Decision Tree: 조건 분기로 예측하는 의사결정 트리
  • Random Forest: 여러 트리를 앙상블한 모델
  • SVM: 최적 경계로 분류하는 서포트 벡터 머신
  • Naive Bayes: 베이즈 정리 기반의 확률 분류기
  • K-Means: 데이터를 K개 군집으로 나누는 알고리즘
  • PCA: 차원을 축소하는 주성분 분석

2.3 모델평가​

2.3.1 Evaluation​

  • Accuracy: 전체 중 맞힌 비율인 정확도
  • Precision: 양성 예측 중 실제 양성 비율인 정밀도
  • Recall: 실제 양성 중 맞힌 비율인 재현율
  • F1 Score: 정밀도와 재현율의 조화 평균
  • ROC: 임계값 변화에 따른 성능 곡선
  • AUC: ROC 곡선 아래 면적으로 성능을 나타내는 지표
  • Confusion Matrix: 예측·실제를 표로 정리한 혼동 행렬

3. 딥러닝​

3.1 신경망​

3.1.1 Neural Network​

  • Perceptron: 신경망의 기본 단위인 퍼셉트론
  • MLP: 은닉층을 가진 다층 퍼셉트론
  • Activation Function: 비선형성을 부여하는 활성화 함수
  • Backpropagation: 오차를 역전파해 가중치를 학습하는 알고리즘

3.2 딥러닝 모델​

3.2.1 Deep Learning​

  • CNN: 이미지 처리에 강한 합성곱 신경망
  • RNN: 순차 데이터를 처리하는 순환 신경망
  • LSTM: 장기 의존성을 학습하는 순환 신경망
  • GRU: LSTM을 간소화한 순환 신경망
  • AutoEncoder: 입력을 압축·복원하며 학습하는 신경망

3.3 Transformer​

3.3.1 Transformer 기반​

  • Transformer: 어텐션 기반의 병렬 처리 신경망
  • Attention: 중요한 부분에 가중치를 주는 메커니즘
  • Self-Attention: 입력 내 요소 간 관계를 계산하는 어텐션
  • Positional Encoding: 순서 정보를 부여하는 위치 인코딩
  • Encoder: 입력을 표현으로 변환하는 인코더
  • Decoder: 표현에서 출력을 생성하는 디코더

4. 생성형 AI​

4.1 LLM​

4.1.1 Large Language Model​

  • GPT: 트랜스포머 기반의 대표적 생성형 언어모델
  • LLM: 대규모 텍스트로 학습한 거대 언어모델
  • Token: 모델이 처리하는 텍스트의 기본 단위
  • Context Window: 한 번에 처리 가능한 토큰 범위
  • Prompt: 모델에 입력하는 지시·질문

4.2 Prompt Engineering​

4.2.1 Prompt​

  • Zero-shot: 예시 없이 지시만으로 수행하는 방식
  • One-shot: 예시 하나를 제공하는 방식
  • Few-shot: 예시 몇 개를 제공하는 방식
  • Chain of Thought: 단계적 추론을 유도하는 기법
  • Role Prompt: 역할을 부여해 응답을 유도하는 기법

4.3 RAG​

4.3.1 Retrieval​

  • RAG: 검색으로 보강해 답변 품질을 높이는 방식
  • Embedding: 데이터를 벡터로 표현한 임베딩
  • Vector Database: 임베딩 벡터를 저장·검색하는 DB
  • Semantic Search: 의미 기반으로 검색하는 방식
  • Retriever: 관련 문서를 찾아오는 검색기
  • Reranker: 검색 결과를 재정렬해 정확도를 높이는 모델

4.4 AI Agent​

4.4.1 Agent​

  • AI Agent: 자율적으로 목표를 수행하는 AI 에이전트
  • Multi-Agent: 여러 에이전트가 협업하는 방식
  • Tool Calling: 외부 도구를 호출해 작업하는 기능
  • Function Calling: 정의된 함수를 호출하는 기능
  • MCP: AI와 도구·데이터를 연결하는 개방형 프로토콜
  • A2A: 에이전트 간 상호작용·협업 방식

5. AI 플랫폼​

5.1 AI 개발​

5.1.1 AI Pipeline​

  • Data Collection: 학습용 데이터를 수집하는 단계
  • Data Labeling: 데이터에 정답을 부여하는 라벨링
  • Feature Engineering: 유용한 피처를 만드는 특성 공학
  • Model Training: 데이터로 모델을 학습시키는 단계

5.2 MLOps​

5.2.1 MLOps​

  • ML Pipeline: 학습·배포를 자동화한 ML 파이프라인
  • Model Registry: 모델 버전을 관리하는 저장소
  • CI/CD for ML: ML에 적용한 지속적 통합·배포
  • Feature Store: 피처를 저장·공유하는 저장소
  • Model Monitoring: 운영 중 모델 성능을 감시하는 활동

5.3 운영​

5.3.1 AI Operations​

  • Model Serving: 학습 모델을 서비스로 제공하는 활동
  • Drift Detection: 데이터·성능 변화를 감지하는 활동
  • A/B Testing: 두 모델을 비교 검증하는 실험
  • Shadow Deployment: 실제 트래픽으로 몰래 검증하는 배포

6. 빅데이터​

6.1 Big Data​

6.1.1 Big Data 개념​

  • 3V: 규모·속도·다양성의 빅데이터 3대 특성
  • 5V: 3V에 정확성·가치를 더한 특성
  • Data Lake: 원천 데이터를 원형으로 저장하는 저장소
  • Data Warehouse: 분석을 위해 통합·축적한 데이터 저장소

6.2 Hadoop​

6.2.1 Hadoop​

  • HDFS: 대용량 파일을 분산 저장하는 하둡 파일시스템
  • MapReduce: 분산 병렬 처리를 위한 프로그래밍 모델
  • YARN: 하둡의 자원 관리·스케줄링 계층
  • Hive: SQL로 하둡 데이터를 조회하는 도구
  • Pig: 스크립트로 대용량 데이터를 처리하는 도구

6.3 Spark​

6.3.1 Spark​

  • RDD: 스파크의 분산 불변 데이터 집합
  • DataFrame: 구조화 데이터를 다루는 스파크 추상화
  • Spark SQL: 스파크에서 SQL로 데이터를 처리하는 모듈
  • Spark Streaming: 실시간 스트림을 처리하는 스파크 기능

6.4 실시간 데이터​

6.4.1 Streaming​

  • Kafka: 대용량 이벤트 스트리밍 플랫폼
  • Flink: 실시간 스트림 처리 엔진
  • Storm: 실시간 분산 스트림 처리 시스템
  • CEP: 복합 이벤트를 실시간 분석하는 처리 기법

7. AI 데이터​

7.1 데이터 품질​

7.1.1 AI Data​

  • Data Quality: 학습에 적합한 데이터의 품질
  • Data Cleansing: 오류·결측을 정제하는 활동
  • Data Augmentation: 데이터를 변형·증강하는 기법
  • Synthetic Data: 인공적으로 생성한 합성 데이터

7.2 Feature​

7.2.1 Feature Engineering​

  • Feature Selection: 유의미한 피처를 선택하는 활동
  • Feature Extraction: 원천에서 새로운 피처를 추출하는 활동
  • Feature Store: 피처를 저장·공유하는 저장소

7.3 Vector​

7.3.1 Semantic Data​

  • Vector DB: 임베딩 벡터를 저장·검색하는 DB
  • Embedding: 데이터를 벡터로 표현한 임베딩
  • Similarity Search: 유사한 벡터를 찾는 검색
  • Knowledge Graph: 개체와 관계를 그래프로 표현한 지식 그래프

8. AI 거버넌스​

8.1 AI 관리​

8.1.1 Governance​

  • AI Governance: AI의 개발·운영을 통제하는 거버넌스
  • AI Risk: AI가 유발하는 위험
  • AI Compliance: AI 관련 규제·표준 준수
  • AI Lifecycle: AI의 개발부터 폐기까지의 생명주기

8.2 AI 표준​

8.2.1 Standards​

  • AI RMF: NIST의 AI 위험관리 프레임워크
  • ISO/IEC 42001: AI 관리체계에 관한 국제 표준
  • ISO/IEC 23894: AI 위험관리에 관한 국제 표준
  • OECD AI Principles: OECD가 제시한 AI 원칙

8.3 AI 보안​

8.3.1 AI Security​

  • Adversarial Attack: 교란 입력으로 오작동을 유발하는 공격
  • Prompt Injection: 악의적 프롬프트로 모델을 조작하는 공격
  • Data Poisoning: 학습 데이터를 오염시키는 공격
  • Model Theft: 모델을 복제·탈취하는 공격
  • Jailbreak: 안전장치를 우회해 제약을 푸는 공격

9. AI 서비스​

9.1 AI 응용​

9.1.1 Business AI​

  • Recommendation System: 사용자 취향에 맞춰 추천하는 시스템
  • Chatbot: 대화로 응대하는 챗봇
  • OCR: 이미지에서 문자를 인식하는 기술
  • Speech Recognition: 음성을 텍스트로 변환하는 기술
  • Computer Vision: 이미지·영상을 이해하는 기술

9.2 산업 AI​

9.2.1 Industry AI​

  • Digital Twin: 실물을 디지털로 복제해 시뮬레이션하는 기술
  • Smart Factory: AI로 자동화·최적화한 지능형 공장
  • Autonomous Driving: AI 기반의 자율주행
  • AIoT: AI와 IoT를 결합한 지능형 사물인터넷

10. 최신 AI​

10.1 차세대 AI​

10.1.1 Emerging AI​

  • Multimodal AI: 텍스트·이미지 등 여러 형식을 다루는 AI
  • Small Language Model (SLM): 경량화한 소형 언어모델
  • Edge AI: 단말·엣지에서 추론하는 AI
  • Federated Learning: 데이터를 모으지 않고 분산 학습하는 방식
  • TinyML: 초소형 기기에서 동작하는 머신러닝

10.2 미래기술​

10.2.1 Future AI​

  • Artificial General Intelligence (AGI): 인간 수준의 범용 인공지능
  • Artificial Super Intelligence (ASI): 인간을 능가하는 초지능
  • Physical AI: 물리 세계와 상호작용하는 AI
  • Embodied AI: 신체를 가지고 환경과 상호작용하는 AI
