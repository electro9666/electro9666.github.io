12. 디지털 신기술

1. 디지털 전환​

1.1 Digital Transformation​

1.1.1 DX​

  • Digital Transformation: 디지털 기술로 업무·사업을 혁신하는 전환
  • Hyper Automation: 여러 기술로 업무를 광범위하게 자동화하는 방식
  • Intelligent Enterprise: AI·데이터로 운영되는 지능형 기업
  • Digital Platform: 디지털 서비스를 제공하는 플랫폼
  • Digital Business: 디지털 기반의 사업 모델

1.2 플랫폼 경제​

1.2.1 Platform​

  • Platform Business: 플랫폼 기반의 사업 모델
  • API Economy: API로 가치를 교환하는 경제
  • Ecosystem: 참여자가 상호작용하는 생태계
  • Network Effect: 사용자가 늘수록 가치가 커지는 효과

1.3 고객경험​

1.3.1 Experience​

  • Customer Experience (CX): 고객이 겪는 총체적 경험
  • Employee Experience (EX): 직원이 겪는 업무 경험
  • User Experience (UX): 사용자가 제품에서 겪는 경험
  • Omnichannel: 여러 채널을 끊김 없이 연결한 방식

2. IoT / CPS​

2.1 IoT​

2.1.1 Internet of Things​

  • IoT: 사물을 네트워크로 연결하는 사물인터넷
  • IIoT: 산업 현장에 적용한 산업용 IoT
  • Smart Sensor: 데이터를 감지·처리하는 지능형 센서
  • Edge Device: 현장에서 데이터를 처리하는 엣지 기기

2.2 CPS​

2.2.1 Cyber Physical System​

  • CPS: 물리 시스템과 사이버 시스템을 결합한 시스템
  • Digital Twin: 실물을 디지털로 복제해 시뮬레이션하는 기술
  • Smart Factory: AI·IoT로 지능화한 공장
  • Smart City: ICT로 도시 기능을 지능화한 도시

2.3 Connected Technology​

2.3.1 Connectivity​

  • LPWAN: 저전력 광역 통신 기술
  • MQTT: IoT에 쓰이는 경량 메시징 프로토콜
  • OPC-UA: 산업 장비 간 상호운용 통신 표준
  • Matter: 스마트홈 기기의 연결 표준

3. Blockchain / Web3​

3.1 Blockchain​

3.1.1 Distributed Ledger​

  • Blockchain: 거래를 분산 저장하는 블록체인
  • Distributed Ledger: 여러 노드가 공유하는 분산 원장
  • Consensus Algorithm: 노드 간 합의를 이루는 알고리즘
  • Smart Contract: 조건 충족 시 자동 실행되는 계약

3.2 Web3​

3.2.1 Web3​

  • Decentralized Identity (DID): 분산 기반의 자기주권 신원
  • NFT: 소유권을 증명하는 대체 불가 토큰
  • DAO: 탈중앙화된 자율 조직
  • Token Economy: 토큰으로 가치를 순환시키는 경제

3.3 Enterprise Blockchain​

3.3.1 Enterprise​

  • Hyperledger: 기업용 오픈소스 블록체인 프로젝트
  • Enterprise Blockchain: 기업 환경에 적용한 블록체인
  • CBDC: 중앙은행이 발행하는 디지털 화폐

4. XR / Metaverse​

4.1 XR​

4.1.1 Extended Reality​

  • VR: 완전한 가상 환경을 구현하는 가상현실
  • AR: 현실에 정보를 덧입히는 증강현실
  • MR: 현실과 가상을 결합한 혼합현실
  • XR: VR·AR·MR을 아우르는 확장현실

4.2 Metaverse​

4.2.1 Virtual World​

  • Metaverse: 가상과 현실이 융합된 3차원 세계
  • Avatar: 가상 세계 속 사용자의 분신
  • Spatial Computing: 공간을 인식·활용하는 컴퓨팅
  • Digital Asset: 가상 세계의 디지털 자산

4.3 공간컴퓨팅​

4.3.1 Spatial Computing​

  • Apple Vision: 애플의 공간컴퓨팅 헤드셋
  • Spatial AI: 공간을 이해하는 인공지능
  • Human Computer Interaction: 사람과 컴퓨터의 상호작용

5. Edge Computing​

5.1 Edge​

5.1.1 Edge Platform​

  • Edge Computing: 데이터 발생 근처에서 처리하는 방식
  • MEC: 이동통신망 가장자리에서 처리하는 컴퓨팅
  • Fog Computing: 엣지와 클라우드 사이에서 처리하는 방식
  • Cloud Edge: 클라우드를 엣지로 확장한 컴퓨팅

5.2 실시간 시스템​

5.2.1 Real-Time​

  • Edge AI: 단말·엣지에서 추론하는 AI
  • Stream Processing: 데이터를 실시간 스트림으로 처리하는 방식
  • Real-time Analytics: 실시간으로 데이터를 분석하는 활동
  • Edge Gateway: 엣지 데이터를 수집·중계하는 게이트웨이

6. 차세대 네트워크​

6.1 Mobile Network​

6.1.1 Mobile​

  • 5G: 초고속·초저지연의 5세대 이동통신
  • 6G: 5G를 넘어서는 차세대 이동통신
  • Network Slicing: 하나의 망을 용도별로 분할하는 기술
  • Open RAN: 개방형 표준의 무선 접속망

6.2 미래 네트워크​

6.2.1 Future Network​

  • NTN: 위성 등 비지상 기반의 네트워크
  • Satellite Internet: 위성으로 제공하는 인터넷
  • UAM Network: 도심 항공 모빌리티용 네트워크
  • V2X: 차량과 사물이 통신하는 기술

7. 양자기술​

7.1 Quantum​

7.1.1 Quantum Computing​

  • Quantum Computer: 양자역학 원리로 연산하는 컴퓨터
  • Quantum Bit: 중첩 상태를 갖는 양자 비트(큐비트)
  • Quantum Algorithm: 양자 컴퓨터용 알고리즘
  • Quantum Supremacy: 양자 컴퓨터가 고전을 능가하는 우위

7.2 Quantum Security​

7.2.1 PQC​

  • Post Quantum Cryptography: 양자 컴퓨터에 대비한 암호 기술
  • QKD: 양자 원리로 키를 안전하게 분배하는 기술
  • Quantum Network: 양자 정보를 전송하는 네트워크

8. 로봇 / 자율시스템​

8.1 Robotics​

8.1.1 Robot​

  • Intelligent Robot: AI가 탑재된 지능형 로봇
  • Cobot: 사람과 협업하는 협동 로봇
  • AMR: 자율적으로 이동하는 자율주행 로봇
  • AGV: 정해진 경로로 이동하는 무인 운반차

8.2 Autonomous​

8.2.1 Autonomous System​

  • Autonomous Driving: AI 기반의 자율주행
  • Drone: 무인 비행체인 드론
  • Autonomous Navigation: 스스로 경로를 찾는 자율 항법
  • Physical AI: 물리 세계와 상호작용하는 AI

9. Green ICT​

9.1 ESG​

9.1.1 Sustainable ICT​

  • ESG: 환경·사회·지배구조를 고려하는 경영 기준
  • Green IT: 친환경을 고려한 IT
  • Green Software: 에너지 효율을 고려한 친환경 소프트웨어
  • Carbon Neutral: 탄소 배출을 상쇄해 순배출을 0으로 만드는 것

9.2 Green Data Center​

9.2.1 Green Infrastructure​

  • Green Data Center: 에너지 효율을 고려한 친환경 데이터센터
  • PUE: 데이터센터 에너지 효율을 나타내는 지표
  • Renewable Energy: 재생 가능한 에너지
  • Carbon Footprint: 배출된 탄소의 총량인 탄소 발자국

10. 미래 디지털 기술​

10.1 Emerging Technology​

10.1.1 Future Tech​

  • Ambient Computing: 환경에 스며든 자연스러운 컴퓨팅
  • Human Digital Twin: 사람을 디지털로 복제한 트윈
  • Synthetic Data: 인공적으로 생성한 합성 데이터
  • Digital Human: 사람처럼 구현된 디지털 휴먼

10.2 융합기술​

10.2.1 Convergence​

  • AI + IoT: AI와 IoT를 결합한 지능형 사물인터넷
  • AI + Cloud: AI와 클라우드를 결합한 지능형 클라우드
  • AI + Robot: AI와 로봇을 결합한 지능형 로봇
  • AI + Blockchain: AI와 블록체인을 결합한 융합 기술
