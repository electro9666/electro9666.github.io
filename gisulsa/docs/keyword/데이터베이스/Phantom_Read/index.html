Phantom Read

Phantom Read은(는) 한 트랜잭션 내에서 동일한 조건으로 두 번 조회했을 때, 첫 번째에는 없던 행이 두 번째에 나타나는 이상현상.

개념​

  • 트랜잭션 A가 범위 조회 후, 트랜잭션 B가 해당 범위에 새 행을 INSERT·COMMIT
  • 트랜잭션 A가 같은 범위를 다시 조회하면 이전에 없던 '유령(Phantom)' 행이 나타남
  • REPEATABLE READ 이하에서 발생 가능, SERIALIZABLE에서만 완전히 방지

발생 시나리오​

항목설명
T1: A가 범위 조회SELECT WHERE 부서='영업' → 3건
T2: B가 INSERT영업부 직원 추가 + COMMIT
T3: A가 재조회SELECT WHERE 부서='영업' → 4건(Phantom)

실제 사례​

  • 급여 시스템에서 부서별 급여 합산 중 새 직원 추가로 합산액 불일치
  • 보고서 생성 중 범위 내 데이터가 변경되어 페이지별 합계 불일치

관련 키워드​
