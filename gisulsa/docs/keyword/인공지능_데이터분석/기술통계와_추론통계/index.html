기술통계와 추론통계

기술통계는 수집된 데이터를 요약·정리하는 통계이고, 추론통계는 표본으로 모집단의 특성을 추론하는 통계이다.

개념​

  • 기술통계(Descriptive Statistics): 평균, 분산, 표준편차, 중앙값 등으로 데이터 특성 요약
  • 추론통계(Inferential Statistics): 표본에서 모집단의 모수를 추정하거나 가설을 검정
  • 기술통계로 데이터를 파악한 뒤, 추론통계로 일반화하는 것이 일반적 절차

비교​

항목기술통계추론통계
목적데이터 요약·정리모집단 특성 추론
대상수집된 데이터 전체표본 → 모집단
방법평균, 분산, 히스토그램가설검정, 구간추정, 회귀분석
결과확정적확률적(신뢰도 포함)

실제 사례​

  • 기업 매출 데이터의 월별 평균·추이 요약(기술통계)
  • A/B 테스트에서 표본 결과로 전체 사용자 효과를 추론(추론통계)

관련 키워드​

  • 정규분포 특징
  • 통계적 가설 검정, p-value
  • 점추정과 구간추정
