유스케이스 다이어그램

유스케이스 다이어그램(Use Case Diagram)은 사용자(액터)와 시스템이 제공하는 기능(유스케이스) 간의 관계를 표현하는 UML 다이어그램이다.

개념​

  • 시스템의 기능적 범위를 정의하는 요구사항 분석 도구
  • 액터(Actor), 유스케이스(Use Case), 관계(Association, Include, Extend)로 구성
  • 시스템 경계(System Boundary)로 내부·외부를 구분

주요 관계​

관계설명
연관(Association)액터와 유스케이스 간의 상호작용
포함(Include)반드시 포함되는 공통 기능(점선 화살표, <<include>>)
확장(Extend)선택적으로 확장되는 기능(점선 화살표, <<extend>>)
일반화액터 또는 유스케이스 간의 상속 관계

실제 사례​

  • 은행 시스템: 고객(액터)—계좌조회, 이체, 대출신청(유스케이스)의 관계 표현
  • 쇼핑몰: 회원(액터)—상품검색, 주문, 결제(유스케이스), 결제에 <<include>> 인증

관련 키워드​

  • UML 행위 다이어그램
  • 클래스 다이어그램(Class Diagram)
  • 순차 다이어그램(Sequence Diagram)
  • 요구공학(Requirement Engineering)
