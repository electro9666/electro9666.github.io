다중연결리스트(Multi-linked List)

다중연결리스트(Multi-linked List)는 하나의 노드가 여러 개의 포인터를 가져 다양한 방향으로 탐색할 수 있는 연결리스트이다.

개념​

  • 일반 연결리스트: 다음 노드를 가리키는 포인터 1개
  • 다중연결리스트: 포인터가 여러 개 → 한 노드에서 여러 방향으로 이동 가능
  • 다차원 데이터나 복잡한 관계를 표현할 때 유용

일반 연결리스트와의 비교​

구분단일 연결리스트이중 연결리스트다중 연결리스트
포인터 수1개(next)2개(prev, next)n개
탐색 방향단방향양방향다방향
활용단순 순차 접근양방향 순회희소 행렬, 다차원 데이터

주요 활용​

활용 분야설명
희소 행렬 표현0이 아닌 값만 노드로 저장, 행·열 방향 포인터
다차원 리스트여러 기준으로 정렬된 데이터를 동시에 유지
그래프 표현인접 리스트의 확장 형태

선형 자료구조 내 위치​

  • 선형: 스택(LIFO), 큐(FIFO), 연결리스트, 다중연결리스트
  • 비선형: 이진 탐색 트리, Heap, DAG

관련 키워드​

  • 스택 / 큐
  • 이진 탐색 트리
  • 희소 행렬
