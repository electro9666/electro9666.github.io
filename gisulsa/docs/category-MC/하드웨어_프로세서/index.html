하드웨어/프로세서

C에서 주로 출제. AI 가속기와 임베디드 프로세서 중심.

7-1. AI 가속기/프로세서​

  • GPU(Graphics Processing Unit)
  • TPU(Tensor Processing Unit)
  • NPU(Neural Processing Unit)
  • FPGA, ASIC
  • CPU vs GPU vs FPGA vs ASIC 비교
  • 뉴로모픽 칩(Neuromorphic), SNN(Spiking Neural Network)
  • 양자 컴퓨터, 큐빗
  • 양자 머신러닝(QML)

7-2. 임베디드/프로세서​

  • ARM 프로세서, ARM 동작모드
  • RISC-V
  • Many-core 프로세서
  • 워치독 타이머(Watchdog Timer)
  • PWM(Pulse Width Modulation)
  • JTAG
  • CAN 통신

7-3. 인터페이스/버스​

  • PCI Express(PCIe)
  • Thunderbolt
  • DLL(Dynamic Link Library)

7-4. 센서/디바이스​

  • LiDAR, RADAR
  • 무선충전(자기유도, 자기공진, WPT)
  • 드론, 안티드론
  • UPS
  • PoE(Power over Ethernet)
  • 마이크로 에너지 수확(Energy Harvesting)
