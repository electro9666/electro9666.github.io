보안 (Security)

C/M 합산 최다 출제 카테고리. 전 회차에 걸쳐 꾸준히 출제.

1-1. 공격/위협​

  • 랜섬웨어, RaaS(Ransomware-as-a-Service)
  • DDoS, DRDoS
  • XSS(Cross Site Scripting), CSRF
  • SQL Injection
  • 래터럴 무브먼트(Lateral Movement), 공격 표면(Attack Surface)
  • APT, 워터링홀 공격, 사이버킬체인
  • 스푸핑(ARP/IP/DNS Spoofing)
  • 멜트다운(Meltdown), 스펙터(Spectre)
  • 버퍼 오버플로우(Buffer Overflow)
  • Stuxnet, BPFdoor
  • Model DoS, 프롬프트 인젝션(Prompt Injection), 모델 전도 공격(Model Inversion Attack)

1-2. 방어/탐지​

  • 방화벽, IDS(침입탐지), IPS(침입방지), 웹방화벽(WAF)
  • 제로트러스트(Zero Trust), 제로트러스트 2.0
  • 망분리(내부망/외부망)
  • 샌드박스(Sandbox)
  • 융합보안관제, SIEM, SOAR
  • 안티드론
  • 국가망보안체계(N2SF)

1-3. 암호/인증​

  • 대칭 암호화, 비대칭(공개키) 암호화
  • 해시 함수, Rainbow Table, 해시 솔트(Salt), 키 스트레칭(Key Stretching)
  • Diffie-Hellman 키교환, 암호키 관리
  • 디지털 서명, 메시지 인증
  • OAuth 2.0, FIDO
  • 영지식증명(Zero Knowledge Proof)
  • PKI, PMI
  • 양자암호, 양자키분배(QKD), 양자 알고리즘(Shor, Grover)
  • 동형암호, 차분 프라이버시, 합성데이터
  • CAPTCHA

1-4. 프라이버시 보호 기술​

  • PET(Privacy Enhancing Technology)
  • k-익명성(k-anonymity)
  • 개인정보 비식별 조치(가명처리, 익명처리)
  • 마이데이터
  • 프라이버시 바이 디자인(Privacy by Design)

1-5. 보안 관리체계​

  • ISMS, ISMS-P, ISMS-P 간편인증
  • 재해복구(DR), BCP(업무연속성계획), Active-Active DR
  • 디지털 포렌식, 아티팩트, 안티포렌식
  • Secure Coding, CWE
  • SBOM(Software Bill of Materials)
  • OWASP, OWASP LLM 보안 위협
  • DRM, DLP(Data Loss Prevention)
  • FDS(이상거래탐지시스템)
  • 정보보호 거버넌스

1-6. 보안 모델/접근제어​

  • BiBa 무결성 모델
  • Chinese Wall 모델(만리장성 모델)
  • 접근통제(MAC, DAC, RBAC, ABAC)

1-7. 개인정보 법제​

  • 개인정보보호법
  • 데이터 3법
  • GDPR
  • OECD 프라이버시 8원칙
  • CBPR(국경간 프라이버시 규칙)
