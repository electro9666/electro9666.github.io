기술사 기출문제 카테고리별 키워드 분류

분석 범위: 110회 ~ 138회 (C 20회차 + M 27회차, 총 약 1,500문제) C = 컴퓨터시스템응용기술사, M = 정보관리기술사 각 문제에서 추출한 키워드를 카테고리별로 분류

1. 보안 (Security)​

1-1. 공격/위협​

  • 랜섬웨어, RaaS(Ransomware-as-a-Service)
  • DDoS, DRDoS
  • XSS(Cross Site Scripting), CSRF
  • SQL Injection
  • 래터럴 무브먼트(Lateral Movement), 공격 표면(Attack Surface)
  • APT, 워터링홀 공격, 사이버킬체인
  • 스푸핑(ARP/IP/DNS Spoofing)
  • 멜트다운(Meltdown), 스펙터(Spectre)
  • 버퍼 오버플로우(Buffer Overflow)
  • Stuxnet, BPFdoor
  • Model DoS, 프롬프트 인젝션(Prompt Injection), 모델 전도 공격(Model Inversion Attack)

1-2. 방어/탐지​

  • 방화벽, IDS(침입탐지), IPS(침입방지), 웹방화벽(WAF)
  • 제로트러스트(Zero Trust), 제로트러스트 2.0
  • 망분리(내부망/외부망)
  • 샌드박스(Sandbox)
  • 융합보안관제, SIEM, SOAR
  • 안티드론
  • 국가망보안체계(N2SF)

1-3. 암호/인증​

  • 대칭 암호화, 비대칭(공개키) 암호화
  • 해시 함수, Rainbow Table, 해시 솔트(Salt), 키 스트레칭(Key Stretching)
  • Diffie-Hellman 키교환, 암호키 관리
  • 디지털 서명, 메시지 인증
  • OAuth 2.0, FIDO
  • 영지식증명(Zero Knowledge Proof)
  • PKI, PMI
  • 양자암호, 양자키분배(QKD), 양자 알고리즘(Shor, Grover)
  • 동형암호, 차분 프라이버시, 합성데이터
  • CAPTCHA

1-4. 프라이버시 보호 기술​

  • PET(Privacy Enhancing Technology)
  • k-익명성(k-anonymity)
  • 개인정보 비식별 조치(가명처리, 익명처리)
  • 마이데이터
  • 프라이버시 바이 디자인(Privacy by Design)

1-5. 보안 관리체계​

  • ISMS, ISMS-P, ISMS-P 간편인증
  • 재해복구(DR), BCP(업무연속성계획), Active-Active DR
  • 디지털 포렌식, 아티팩트, 안티포렌식
  • Secure Coding, CWE
  • SBOM(Software Bill of Materials)
  • OWASP, OWASP LLM 보안 위협
  • DRM, DLP(Data Loss Prevention)
  • FDS(이상거래탐지시스템)
  • 정보보호 거버넌스

1-6. 보안 모델/접근제어​

  • BiBa 무결성 모델
  • Chinese Wall 모델(만리장성 모델)
  • 접근통제(MAC, DAC, RBAC, ABAC)

1-7. 개인정보 법제​

  • 개인정보보호법
  • 데이터 3법
  • GDPR
  • OECD 프라이버시 8원칙
  • CBPR(국경간 프라이버시 규칙)

2. 인공지능/머신러닝 (AI/ML)​

2-1. 기초 머신러닝​

  • SVM(서포트벡터머신)
  • 선형회귀, 로지스틱회귀
  • Random Forest, 의사결정나무
  • 앙상블 학습(배깅, 부스팅)
  • 교차검증(k-fold Cross Validation)
  • Active Learning(능동 학습)
  • PCA(주성분 분석), 차원축소
  • 군집분석(Clustering)
  • 연관규칙 분석(지지도, 신뢰도, 향상도)

2-2. 딥러닝​

  • CNN(합성곱 신경망)
  • RNN(순환 신경망)
  • GAN(생성적 적대 신경망)
  • GNN(그래프 신경망)
  • Self-Attention, Transformer
  • 역전파(Backpropagation)
  • 경사하강법(SGD, 배치, 미니배치)
  • 기울기소실(Vanishing Gradient)
  • 활성화 함수, Softmax, 원핫인코딩

2-3. 강화학습​

  • 강화학습(Reinforcement Learning)
  • 마르코프 결정 프로세스(MDP)
  • Policy Gradient, Actor-Critic

2-4. LLM/생성형 AI​

  • LLM(대규모 언어 모델), sLLM(소형 LLM)
  • RAG(Retrieval-Augmented Generation)
  • Fine-tuning, 파인튜닝
  • Knowledge Distillation(지식 증류)
  • 초거대 AI, 공공부문 초거대 AI 도입 가이드라인
  • MLOps, DevOps와 비교
  • TTFT(Time To First Token), TPOT(Time Per Output Token)
  • 프롬프트 인젝션, 프롬프트 엔지니어링
  • MCP(Model Context Protocol)
  • TEXT2SQL
  • 트랜스포머, MoE(Mixture of Experts)

2-5. AI 모델 경량화/최적화​

  • 온디바이스 AI, 엣지 AI
  • 모델 경량화, 양자화, 프루닝
  • 차원의 저주(Curse of Dimensionality)
  • 과적합, 하이퍼파라미터 튜닝

2-6. AI 보안/신뢰​

  • 적대적 공격(Adversarial Attack), 적대적 훈련
  • 모델 전도 공격(Model Inversion Attack)
  • Model DoS
  • AI 데이터 품질 평가
  • AI 편향(Bias)
  • 멀티모달 AI, 멀티모달 데이터 품질검증
  • AI 신뢰성 검인증(CAT)

2-7. AI 응용​

  • 챗봇(ChatBot)
  • 추천시스템(협업필터링, 행렬분해)
  • 유사도 측정(자카드, 코사인, 실루엣계수)
  • 로보어드바이저
  • 안면인식 결제
  • 베이즈 정리
  • MCTS(몬테카를로 트리탐색)
  • 모라벡의 역설
  • 튜링 테스트
  • AIaaS(AI as a Service)
  • YOLO(객체인식)
  • 자기회귀모형, 이동평균모형

2-8. AI 거버넌스/윤리​

  • AI 윤리
  • AI 거버넌스
  • AI 기본법(인공지능 발전과 신뢰 기반 조성 등에 관한 기본법)
  • AI RMF(NIST AI Risk Management Framework)
  • ISO/IEC 42001:2023(AI 관리시스템)
  • 생성형 AI 이용자 보호 가이드라인

3. 네트워크/통신​

3-1. 기본 프로토콜/계층​

  • OSI 7계층 참조모델
  • TCP(흐름제어, 오류제어, 혼잡제어, 3-way/4-way handshake)
  • UDP
  • IPv6(헤더구조, 애니캐스트, 멀티캐스트, ND, ICMPv6)
  • HTTP 3.0, QUIC
  • DNS, DNSSEC
  • DHCP
  • ARP, RARP, ARP Spoofing
  • ICMP, IGMP
  • SCTP, MPTCP

3-2. 데이터링크/오류제어​

  • HDLC(High-level Data Link Control)
  • CSMA/CD
  • 맨체스터 코딩
  • FEC(Forward Error Correction), ARQ(Stop-and-Wait, Go-Back-N)
  • 해밍코드, 해밍거리
  • CRC(Cyclic Redundancy Check)
  • 흐름제어, 슬라이딩 윈도우

3-3. 무선/이동통신​

  • 5G, 5G 특화망, 5G 백홀(MPLS-TP)
  • 6G, AI-Native Network, AI-RAN
  • Wi-Fi 6E, Wi-Fi 7(IEEE 802.11be)
  • Wi-SUN
  • Bluetooth, BLE
  • Zigbee, UWB(초광대역)
  • LPWA, NB-IoT, LoRa
  • FHSS, DSSS(대역확산)
  • 네트워크 슬라이싱(Network Slicing)
  • Open RAN
  • D2D(Device to Device) 통신
  • PS-LTE, LTE-R, LTE-M

3-4. 고급 네트워크/아키텍처​

  • SDN(Software Defined Networking), OpenFlow
  • NFV(Network Functions Virtualization)
  • VPN, SSL VPN, IPsec
  • IP 터널링
  • L2/L4 스위치, SLB(로드밸런싱)
  • 네트워크 토폴로지(버스, 링, 스타, 메쉬)
  • RPC(원격 프로시저 호출)
  • MQTT, CoAP, XMPP
  • SIP(Session Initiation Protocol)
  • ASN.1, BER/DER/CER
  • V2X(차량통신)
  • OPC UA
  • Modbus
  • 소스코딩, 채널코딩
  • Multiplexing, Multiple Access
  • 채널용량, 샤논 정리
  • 스트리밍 프로토콜(RTSP, HLS, DASH)
  • 디지털 계위(PDH, SDH, SONET)

4. 운영체제 (OS)​

4-1. 프로세스/스레드​

  • 프로세스 상태(생성/준비/실행/대기/종료)
  • PCB(Process Control Block)
  • 문맥교환(Context Switch)
  • 프로세스 스케줄링(Round Robin, EDF, RM, SJF, SRT, HRN, MLQ, MQMS)
  • 우선순위 상속(Priority Inheritance), 우선순위 역전(Priority Inversion), PIP, PCP
  • 기아현상(Starvation)
  • 스레싱(Thrashing)

4-2. 동기화/교착상태​

  • 세마포어(Semaphore), P/V 연산
  • 뮤텍스(Mutex)
  • 모니터(Monitor)
  • 스핀 락(Spin Lock)
  • 교착상태(Deadlock) 발생 4조건(상호배제, 점유대기, 비선점, 순환대기)
  • 은행가 알고리즘(Banker's Algorithm)

4-3. 메모리 관리​

  • 가상메모리(Virtual Memory)
  • 페이지 테이블, 페이지 교체 알고리즘(LRU, FIFO, Optimal)
  • TLB(Translation Lookaside Buffer)
  • MMU(Memory Management Unit), IOMMU
  • 메모리 단편화(내부/외부)
  • 세그멘테이션(Segmentation)
  • 메모리 누수(Memory Leak)
  • OS 메모리 영역(코드/데이터/힙/스택)

4-4. 기타 OS​

  • 인터럽트(ISR, 벡터인터럽트, 마스커블/비마스커블)
  • 시스템 콜(System Call)
  • 이중모드(Dual Mode, 커널모드/사용자모드)
  • 보안 OS(Secure OS), 강제접근제어
  • 유니커널(Unikernel)
  • UNIX(커널, 쉘, 파일시스템)
  • NOS(Network OS)
  • RTOS(실시간 운영체제)

5. 컴퓨터구조​

5-1. CPU​

  • CPU 구조, 메이저 상태
  • CPU 내부 레지스터(PC, IR, MAR, MBR, AC)
  • 상태 레지스터(Status Register), 조건 플래그
  • 파이프라인, Pipeline Hazard(구조적/데이터/제어)
  • 분기예측, 예측실행(Speculative Execution)
  • SMT(동시 멀티스레딩), 하이퍼스레딩(Hyperthreading)
  • CPU 제어장치(마이크로프로그래밍, 하드와이어드)
  • 병렬컴퓨팅, Flynn 분류(SISD, SIMD, MISD, MIMD)
  • 폴락의 법칙(Pollack's Rule)

5-2. 캐시 메모리​

  • 캐시 메모리 주소 매핑(직접, 연관, 집합연관)
  • 캐시 교체 알고리즘(LRU, FIFO, Random)
  • 캐시 쓰기 정책(Write Through, Write Back)
  • 캐시 일관성(Cache Coherence), MESI 프로토콜
  • 디렉토리 프로토콜, 스누피 프로토콜
  • 지역성(Locality, 시간적/공간적)

5-3. 버스/입출력​

  • DMA(Direct Memory Access), SG-DMA, RDMA, Burst Mode, Cycle Stealing
  • 버스 중재(Bus Arbitration)
  • 시스템 버스
  • I/O 전송방식(폴링, 인터럽트, DMA)
  • Memory Mapped I/O, Isolated I/O
  • I/O 인터페이스

5-4. 논리회로​

  • 전가산기(Full Adder)
  • 3-상태 버퍼(Tri-State Buffer)

6-3. 차세대 메모리/패키징​

8-4. NoSQL/분산DB​

  • NoSQL(Key-Value, Document, Column, Graph)
