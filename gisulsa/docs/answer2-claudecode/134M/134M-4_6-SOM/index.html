SOM(Self Organizing Map, 자기조직화지도)

문제​

6.군집분석 기법인 SOM(Self Organizing Map)에 대하여 설명하시오.
가.SOM 정의 및 특징
나.SOM 구성요소
다.SOM과 신경망 분석기법의 차이점

Ⅰ. 개요​

SOM(자기조직화지도) 은 핀란드의 Teuvo Kohonen이 제안한 비지도 학습 기반 인공신경망으로, 고차원 데이터를 저차원(주로 2차원) 격자에 사상(Mapping)하면서 데이터의 위상적 구조(Topology)를 보존하는 기법이다. 코호넨 맵(Kohonen Map) 이라고도 한다.

Ⅱ. 가. SOM의 정의 및 특징​

1. 정의​

SOM은 경쟁 학습(Competitive Learning) 을 통해 입력 데이터와 가장 유사한 뉴런(승자)을 선택하고, 승자와 그 이웃 뉴런의 가중치를 함께 조정함으로써, 유사한 데이터가 지도상 인접한 위치에 배치되도록 스스로 조직화하는 신경망이다.

   [SOM의 핵심 아이디어 — 위상 보존 사상]

   [고차원 입력 공간]                    [**2차원 출력 격자(Map)**]
   (예: 100차원 고객 데이터)              ┌───┬───┬───┬───┐
                                          │ ● │ ● │ ○ │ ○ │
      ●●●  ○○○                           ├───┼───┼───┼───┤
     ● ●●  ○ ○○     ──── 사상 ────►      │ ● │ ● │ ○ │ ○ │
      ●●   ○○○                           ├───┼───┼───┼───┤
        ▲    ▲                            │ ▲ │ ▲ │ ■ │ ■ │
     군집A  군집B                          └───┴───┴───┴───┘
                                          **유사한 데이터 = 인접한 격자**
   ⇒ **고차원의 근접 관계가 저차원에서도 유지**(위상 보존)
   ⇒ 사람이 눈으로 볼 수 있는 형태로 **시각화** 가능

2. 학습 원리 — 경쟁 학습​

 ① **초기화** : 각 뉴런의 가중치 벡터를 무작위(또는 PCA 기반)로 설정
        ▼
 ② **입력 제시** : 입력 데이터 x 를 하나 선택
        ▼
 ③ **승자 선택(Competition)**
    모든 뉴런과의 거리를 계산 → **가장 가까운 뉴런 = BMU**(Best Matching Unit)
        **BMU = argmin ‖x − wᵢ‖**
        ▼
 ④ **가중치 갱신(Cooperation & Adaptation)**
    **BMU와 그 이웃 뉴런**의 가중치를 입력 벡터 쪽으로 이동
        **wᵢ(t+1) = wᵢ(t) + α(t) · hᵢ(t) · [x − wᵢ(t)]**
        · **α(t)** : 학습률(시간이 지날수록 감소)
        · **hᵢ(t)** : 이웃 함수(BMU에서 멀수록 작은 값, 반경도 감소)
        ▼
 ⑤ **반복** : ②~④를 수렴할 때까지 반복
        ▼
    **자기조직화 완료** — 유사 데이터가 인접 뉴런에 매핑됨

   [**승자독식과의 차이 — SOM의 핵심**]
   일반 경쟁학습 : **승자만** 갱신 → 위상 관계 없음
   **SOM**       : **승자 + 이웃**을 함께 갱신 → **위상 보존 실현**

3. 주요 특징​

특징내용
① 비지도 학습정답 레이블 없이 데이터의 구조를 스스로 발견
② 위상 보존(Topology Preserving)고차원 공간의 근접 관계를 저차원 격자에서 유지 — SOM의 가장 핵심적 특징
③ 차원 축소수백 차원 데이터를 2차원 지도로 압축(비선형 차원 축소)
④ 시각화 우수결과를 격자 형태로 직관적 시각화 가능(U-Matrix, 성분 평면)
⑤ 경쟁 학습·이웃 협력승자와 이웃을 함께 학습 → 부드러운 사상 형성
⑥ 군집 수 사전 지정 불필요K-Means와 달리 k를 미리 정하지 않음(격자 크기는 지정)
⑦ 이상치에 강건이웃 협력 구조로 개별 이상치의 영향 완화
한계· 격자 크기·형태를 사전 결정해야 함
· 학습률·이웃 반경 등 하이퍼파라미터 민감
· 대용량·고차원에서 계산 비용 큼
· 결과의 재현성 낮음(초기값 의존)
· 군집 경계가 명확히 구분되지 않아 후처리 필요

Ⅲ. 나. SOM의 구성요소​

1. 구조​

   ┌──────────────── **출력층(경쟁층·Kohonen Layer)** ────────────────┐
   │   ┌───┬───┬───┬───┐                                             │
   │   │ N │ N │ N │ N │  각 뉴런 = **가중치 벡터**(입력 차원과 동일)  │
   │   ├───┼───┼───┼───┤  뉴런 간 **격자(Grid) 구조**로 이웃 관계 정의 │
   │   │ N │**BMU**│ N │  · 사각형(Rectangular) / **육각형(Hexagonal)**│
   │   ├───┼───┼───┼───┤    ← 육각형이 이웃 거리가 균등하여 선호       │
   │   │ N │ N │ N │ N │                                             │
   │   └───┴───┴───┴───┘                                             │
   └────────────▲─────────────────────────────────────────────────────┘
                │  **완전 연결**(모든 입력 노드가 모든 출력 뉴런에 연결)
   ┌────────────┴─────────────────────────────────────────────────────┐
   │   **입력층(Input Layer)**                                         │
   │   x₁   x₂   x₃   ...   xₙ   ← 입력 벡터의 각 차원(특성)            │
   └──────────────────────────────────────────────────────────────────┘
   ※ **은닉층이 없는 2층 구조**(입력층 – 출력층)

2. 구성요소 상세​

구성요소내용
① 입력층
(Input Layer)		· 입력 데이터의 특성(Feature) 벡터를 받는 층
· 노드 수 = 입력 데이터의 차원 수
· 별도 연산 없이 값을 전달
② 출력층·경쟁층
(Output / Kohonen Layer)		· 2차원 격자 형태로 배열된 뉴런들의 집합
· 각 뉴런은 입력과 동일한 차원의 가중치 벡터 보유
· 격자 형태: 사각형·육각형(육각형은 이웃 간 거리가 균등)
· 크기(예: 10×10)는 사전에 결정 — 데이터 규모에 따라 조정
③ 가중치 벡터
(Weight / Codebook Vector)		· 각 뉴런이 대표하는 입력 공간상의 위치
· 학습을 통해 갱신되며, 최종적으로 군집의 중심(프로토타입) 역할
· 초기화: 무작위 또는 PCA 기반
④ BMU
(Best Matching Unit, 승자 뉴런)		· 입력 벡터와 가중치 벡터 간 거리가 최소인 뉴런
· 거리 척도: 유클리드 거리(주로), 코사인 유사도
· BMU와 그 이웃이 학습 대상이 됨
⑤ 이웃 함수
(Neighborhood Function)		· BMU 주변 뉴런의 학습 강도를 결정
· 가우시안 함수·버블 함수 등 사용
· 이웃 반경 σ(t)는 학습이 진행될수록 감소
→ 초기: 넓은 영역 조정(전역 구조 형성) → 후기: 국소 미세 조정
⑥ 학습률
(Learning Rate, α)		· 가중치 갱신의 크기를 결정(0 < α < 1)
· 시간에 따라 점진적으로 감소(수렴 보장)
⑦ 반복 횟수(Epoch)전체 데이터를 학습하는 반복 횟수

3. 결과 시각화 도구​

시각화내용
U-Matrix
(Unified Distance Matrix)		인접 뉴런 간 가중치 거리를 색상으로 표현
· 어두운 영역 = 거리 큼 = 군집 경계
· 밝은 영역 = 거리 작음 = 동일 군집
→ 군집 구조를 시각적으로 파악하는 대표 도구
성분 평면(Component Plane)각 특성(변수)별로 지도상 분포를 표현 → 변수 간 관계·기여도 분석
히트맵·빈도맵각 뉴런에 매핑된 데이터 개수 표시

Ⅳ. 다. SOM과 신경망 분석기법의 차이점​

1. SOM과 일반 신경망(MLP·딥러닝) 비교​

비교 기준SOM일반 신경망(MLP·딥러닝)
학습 방식비지도 학습(정답 불필요)주로 지도 학습(정답 레이블 필요)
학습 원리경쟁 학습(Competitive Learning)오차 역전파(Backpropagation)
목적군집화·차원 축소·시각화분류·예측·회귀
네트워크 구조2층(입력층–출력층), 은닉층 없음다층(입력–은닉층(다수)–출력)
뉴런 간 관계격자 구조로 이웃 관계 정의(위상 존재)층 내 뉴런 간 관계 없음(독립)
가중치 갱신 대상승자(BMU)와 그 이웃 뉴런모든 뉴런(오차 기여도에 따라)
활성화 함수사용하지 않음(거리 계산으로 대체)ReLU·Sigmoid·Softmax 등 사용
출력 형태2차원 지도상의 위치클래스 확률·연속값
오차 개념없음(정답이 없으므로)손실 함수로 오차 측정·최소화
해석 가능성높음(시각화로 직관적 이해)낮음(블랙박스)
위상 보존있음(SOM의 핵심 특징)없음
적용 데이터레이블 없는 탐색적 데이터레이블이 있는 학습 데이터

2. SOM과 다른 군집분석 기법 비교​

비교 기준SOMK-Means계층적 군집DBSCAN
기반신경망(경쟁학습)중심 기반거리 기반밀도 기반
군집 수 지정불필요(격자 크기 지정)사전 지정 필수(k)불필요(덴드로그램)불필요
위상 보존·시각화가능(핵심 강점)불가덴드로그램불가
차원 축소동시 수행불가불가불가
군집 형태유연구형에 편향유연임의 형태
이상치 처리강건민감민감이상치 탐지
계산 비용높음낮음매우 높음중간
결과 해석시각적 해석 우수단순계층 구조밀도 기반
   [**SOM의 차별적 가치**]
   K-Means : "**몇 개의 군집**으로 나뉘는가" → 군집 결과만 제공
   **SOM**  : "**데이터가 어떤 구조로 분포**하는가" → **군집 + 관계 + 시각화**
   ⇒ SOM은 군집화 도구이자 **탐색적 데이터 분석(EDA) 도구**

3. SOM의 위치​

   [기법 계보]
   **인공신경망**
        ├─ 지도학습 : MLP · CNN · RNN · Transformer
        └─ **비지도학습** : **SOM** · 오토인코더 · GAN · **VAE**
                              ▲
                    "신경망 기반 군집분석"이라는
                    독특한 위치를 차지
   ※ **차원 축소 관점**에서는 PCA·t-SNE·UMAP과 비교됨
     · PCA : 선형 · 빠름 · 전역 구조
     · t-SNE/UMAP : 비선형 · **국소 구조 보존 우수**
     · **SOM** : 비선형 · **격자 구조 + 프로토타입 제공**(군집 중심 해석 가능)

Ⅴ. 활용 사례 및 고려사항​

1. 활용 사례​

분야활용 내용
고객 세분화구매 이력·인구통계 기반 고객 군집화 및 시각화 → 마케팅 타겟팅
금융이상거래 탐지(정상 패턴에서 벗어난 뉴런에 매핑), 신용 위험 군집화
제조·품질공정 데이터 군집화로 불량 유형 분류, 설비 상태 모니터링
의료·생명유전자 발현 데이터 군집화, 환자 유형 분류
문서·텍스트문서 군집화(WEBSOM), 토픽 시각화
네트워크 보안트래픽 패턴 군집화를 통한 침입 탐지
탐색적 분석고차원 데이터의 구조 파악·시각화(EDA 단계)

2. 적용 시 고려사항​

고려사항내용
데이터 전처리정규화·표준화 필수 — 척도가 다르면 거리 계산이 왜곡됨
격자 크기 결정너무 작으면 군집이 뭉개지고, 너무 크면 과분할
→ 경험식(약 5√n) 또는 실험적 결정
격자 형태육각형 격자가 이웃 간 거리가 균등하여 일반적으로 우수
하이퍼파라미터학습률·이웃 반경의 감소 스케줄이 결과에 큰 영향
재현성초기값에 의존 → 여러 번 수행 후 안정적 결과 선택, 시드 고정
군집 경계 도출SOM 자체는 명확한 군집 라벨을 주지 않음
→ U-Matrix 분석 또는 SOM 결과에 K-Means를 2차 적용하는 방식 활용
성능 평가양자화 오차(Quantization Error), 위상 오차(Topographic Error), 실루엣 계수
대안 검토시각화가 목적이면 t-SNE·UMAP이 더 우수할 수 있음 → 목적에 따라 선택

Ⅵ. 결론​

SOM은 비지도 학습 신경망으로 군집화와 차원 축소, 시각화를 동시에 수행하는 독특한 기법이며, 특히 고차원 데이터의 위상 구조를 2차원 지도에 보존한다는 점이 다른 군집 기법과 구별되는 핵심 가치이다.

일반 신경망과의 근본적 차이는 ① 정답 없이 학습하고(비지도), ② 오차 역전파가 아닌 경쟁 학습을 사용하며, ③ 승자뿐 아니라 이웃 뉴런을 함께 갱신하여 위상을 보존한다는 점이다. 이 세 번째 특성이 SOM을 단순한 군집 도구가 아닌 데이터 구조 탐색 도구로 만든다.

실무 적용 시에는 ① 정규화 전처리가 필수이고, ② 격자 크기·학습률 등 하이퍼파라미터에 민감하므로 여러 설정으로 실험해야 하며, ③ SOM은 군집 라벨을 직접 제공하지 않으므로 U-Matrix 분석이나 K-Means 2차 적용으로 군집 경계를 도출하는 후처리가 필요하다.

다만 계산 비용이 크고 재현성이 낮다는 한계가 있어, 순수 시각화 목적이라면 t-SNE·UMAP, 단순 군집화가 목적이라면 K-Means가 더 효율적일 수 있다. 따라서 SOM은 "군집 구조와 변수 간 관계를 함께 해석해야 하는 탐색적 분석" 에 가장 적합한 선택이다.
