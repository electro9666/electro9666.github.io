HBM(High Bandwidth Memory, 고대역폭 메모리)

문제​

12.고대역 초고속 메모리(High Bandwidth Memory)

Ⅰ. 개요​

HBM은 여러 개의 DRAM 다이를 수직으로 적층(3D Stacking) 하고 TSV(실리콘 관통전극) 로 연결하여, 기존 메모리 대비 압도적으로 넓은 대역폭과 낮은 전력을 제공하는 고성능 메모리이다. AI 가속기(GPU·NPU)의 메모리 병목(Memory Wall) 을 해소하는 핵심 부품이다.

Ⅱ. 구조 및 동작 원리​

   [기존 GDDR — 평면 배치]              [**HBM** — 수직 적층]
   GPU ──── 좁고 긴 배선 ──── DRAM      ┌── DRAM Die 4~12단 ──┐
        (버스 폭 32~64bit)              │  ▓▓▓▓▓▓▓▓  ← **TSV**  │
        → 대역폭 한계·전력 소모 큼       │  ▓▓▓▓▓▓▓▓            │
                                        │  ▓▓▓▓▓▓▓▓            │
                                        │  Base Die(로직)      │
                                        └──────┬───────────────┘
                                        **인터포저(Interposer)**
                                        ┌──────┴───────────────┐
                                        │   GPU / AI 가속기     │
                                        └──────────────────────┘
                                        **버스 폭 1,024bit × 스택 수**
                                        → 짧은 배선 = 고대역폭·저전력
핵심 기술내용
3D 적층(Stacking)DRAM 다이를 4~12단 수직 적층 → 면적 대비 용량 극대화
TSV(Through Silicon Via)다이를 관통하는 수직 전극으로 층간 초고속 연결
인터포저(Interposer)프로세서와 HBM을 연결하는 실리콘 기판 — 2.5D 패키징
광폭 인터페이스스택당 1,024비트 버스(GDDR6는 32비트) → 대역폭 급증
본딩 기술MR-MUF, 하이브리드 본딩(적층 수 확대·발열 개선)

Ⅲ. 특징 및 세대별 발전​

비교 기준HBMGDDRDDR
구조3D 적층 + TSV평면(PCB 실장)평면(모듈)
버스 폭1,024bit/스택32bit/칩64bit/채널
대역폭매우 높음(TB/s급)높음보통
전력 효율우수(짧은 배선)보통보통
용량/면적매우 높음보통낮음
비용매우 높음중간낮음
지연시간보통낮음낮음
주 용도AI 학습·HPC·데이터센터그래픽카드·게임PC·서버 주기억
세대특징
HBM1 → HBM2 → HBM2E적층 수·속도 점진 향상
HBM3 / HBM3EAI 학습 가속기의 현재 주력(NVIDIA H100·H200 등)
HBM4차세대 — 버스 폭 확대(2,048bit), 커스텀 베이스 다이로 고객 맞춤화

Ⅳ. 활용 및 과제​

구분내용
활용AI 학습·추론 가속기(LLM의 대규모 파라미터 적재), HPC·슈퍼컴퓨터, 고성능 네트워크 장비, 자율주행
필요성LLM 학습은 연산보다 메모리 대역폭이 병목 → HBM 용량·대역폭이 곧 모델 처리 성능
과제① 높은 생산 원가와 낮은 수율(적층 공정 난이도)
② 발열 관리 — 적층 구조상 열 배출 곤란
③ 공급 부족 — AI 수요 폭증으로 수급이 AI 인프라의 제약 요인
④ 프로세서와 함께 패키징되어 용량 확장 불가(교체 불가)
보완 기술CXL — HBM의 용량 한계를 외부 메모리 확장·풀링으로 보완(계층적 메모리 구성)

Ⅴ. 결론​

HBM은 AI 시대 반도체 경쟁의 핵심 부품으로, 연산 성능이 아무리 높아도 데이터를 공급하지 못하면 무의미하다는 메모리 병목 문제의 직접적 해법이다. 국내 기업이 세계 시장을 주도하고 있어 산업적 의미도 크다.

다만 고비용·발열·용량 확장 불가라는 제약이 있으므로, 실무 인프라 설계 시에는 HBM(고대역·소용량) + CXL 기반 확장 메모리(대용량) + 시스템 메모리로 이어지는 계층적 메모리 구조를 고려하고, 워크로드 특성에 따라 접근 빈도가 높은 데이터를 HBM에 배치하는 티어링 전략을 병행하는 것이 효율적이다.
