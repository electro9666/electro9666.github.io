인터미턴트 컴퓨팅(Intermittent Computing)

문제​

9.인터미턴트 컴퓨팅(Intermittent Computing)

Ⅰ. 개요​

인터미턴트 컴퓨팅(간헐적 컴퓨팅) 은 배터리 없이 주변 환경에서 에너지를 수확(Energy Harvesting)하여 동작하는 장치가, 전력 공급이 간헐적으로 끊기는 상황에서도 연산을 이어서 수행할 수 있도록 하는 컴퓨팅 패러다임이다.

Ⅱ. 동작 원리​

   [에너지 수확 → 간헐적 실행]
   에너지원(태양광·진동·RF·열)
        │ 수확(Harvesting)
        ▼
   커패시터 충전 ──► **임계 전압 도달** ──► 실행 시작
        ▲                                     │ 연산 수행
        │                                     ▼
        └──── 전력 소진 → **전원 차단** ◄─────┘
                    │
              **체크포인트로 상태 저장**(비휘발성 메모리)
                    │
              재충전 후 **저장 지점부터 재개**(복원)

   [실행 패턴]
   전력 │ ▁▄█▄▁    ▁▄█▄▁    ▁▄█▄▁
        └─실행─OFF─실행─OFF─실행──► 시간
          ▲ **수십 ms 단위로 On/Off 반복**
핵심 기술내용
에너지 수확태양광·진동(압전)·열전·RF(무선전파) 로부터 미세 전력 확보
비휘발성 메모리(NVM)FRAM·MRAM·ReRAM — 전원 차단 시에도 상태 유지, 저전력·고속
체크포인팅(Checkpointing)전력 차단 직전 레지스터·메모리 상태를 NVM에 저장 후 복원
간헐성 인식 프로그래밍태스크 단위 분할, 멱등성(Idempotency) 보장, 트랜잭션 기반 실행 모델
전력 관리전압 감지 회로, 적응적 실행 스케줄링

Ⅲ. 과제 및 활용​

구분내용
주요 과제① 메모리 일관성 문제 — 재실행 시 비멱등 연산의 중복 수행으로 데이터 불일치
② 진행 보장(Forward Progress) — 체크포인트 오버헤드가 커서 영원히 진전하지 못하는 현상
③ 주변장치 상태 복원(센서·통신 모듈은 상태 저장 불가)
④ 시간 개념 상실 — 전원 차단 중 경과 시간 측정 곤란
장점배터리 불필요 → 교체·폐기 비용 제거, 수명 반영구, 친환경, 초소형화 가능
활용 분야배터리리스 IoT 센서(구조물·교량 모니터링), 웨어러블·의료 임플란트, RFID·NFC 기반 스마트태그, 우주·오지 등 배터리 교체가 불가능한 환경, 스마트 농업·환경 감시
관련 개념TinyML(초저전력 온디바이스 AI)과 결합하여 배터리 없는 지능형 센서 구현

Ⅳ. 결론​

인터미턴트 컴퓨팅은 "배터리 수명이 IoT 확산의 최대 제약" 이라는 문제에 대한 근본적 해법으로, 수조 개 규모의 초소형 센서 배치를 가능하게 하는 기반 기술이다.

다만 전원이 예고 없이 끊기는 환경에서 연산의 정확성과 진행을 보장하는 것이 본질적 난제이므로, ① 비휘발성 메모리 기반의 효율적 체크포인팅, ② 멱등성을 고려한 프로그래밍 모델, ③ 하드웨어–소프트웨어 협력 설계가 함께 발전해야 실용화가 가능하다. 지속가능성(배터리 폐기물 감축) 측면에서도 주목할 기술이다.
