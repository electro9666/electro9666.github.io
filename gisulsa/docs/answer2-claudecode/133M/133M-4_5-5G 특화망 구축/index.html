5G 특화망 구축

문제​

5.5G 특화망을 위한 네트워크를 구축할 때 고려되어야 할 사항에 대하여 다음을 설명하시오.
가.안정성‧신뢰성 확보 방안
나.간섭회피 방안

Ⅰ. 개요​

1. 5G 특화망의 개념​

5G 특화망(이음5G) 이란 이동통신사가 아닌 수요 기업·기관이 특정 구역(건물·공장·병원 등)에 직접 구축·운영하는 5G 전용 네트워크이다. 국내에서는 4.7GHz 대역(100MHz) 과 28GHz 대역(600MHz) 이 특화망 주파수로 공급된다.

   [등장 배경]
   Wi-Fi   : 저비용·구축 용이  /  **이동성·간섭·보안·안정성 취약**
   공중망(MNO) : 광역 커버리지 /  **커스터마이징 불가·데이터 외부 경유**
        │  스마트팩토리·자율주행 로봇·원격의료 등
        │  **초저지연·초신뢰(URLLC)** 요구 확산
        ▼
   [**5G 특화망**] **주파수 할당·지정**을 통한 **자가 구축형 5G**
   · **데이터가 외부로 나가지 않음**(보안·기밀 보호)
   · 업무 특성에 맞는 **QoS·슬라이싱 직접 설계**
   · **초저지연·고신뢰** 무선 환경 확보

   근거 : **전파법**·**전기통신사업법**(기간통신사업 등록 또는 자가전기통신설비 신고),
          과기정통부 **5G 특화망 주파수 공급 방안**(2021)

2. 구축 유형 및 주파수 특성​

유형내용
기간통신사업자 등록형타인에게 서비스 제공 가능(제3자 대상)
자가망 설치자 신고형자기 구역 내 자체 사용 — 대부분의 제조·물류 현장
주파수특성적합 용도
4.7GHz(100MHz)커버리지 넓음, 회절 양호, 실내외 범용공장 전체 커버리지, 이동 로봇
28GHz(600MHz)초광대역·초저지연, 직진성 강함, 차폐에 취약, 커버리지 좁음고정형 대용량(AR/VR·머신비전), 국소 고밀도

3. 5G 특화망의 핵심 요구 성능​

서비스 유형요구 성능적용 사례
URLLC(초저지연·초신뢰)지연 1~10ms, 신뢰도 99.999%로봇 제어, 안전 설비, 원격 제어
eMBB(초광대역)수 Gbps머신비전 영상, AR/VR 원격 지원
mMTC(대규모 연결)km²당 100만 단말센서·IoT 대량 수용

Ⅱ. 가. 안정성·신뢰성 확보 방안​

1. 안정성·신뢰성 확보의 계층 구조​

 ┌──────── **① 무선 구간**(RAN) ────────────────────────────┐
 │  기지국 이중화 · 셀 중첩 설계 · 다중 연결 · 빔포밍         │
 ├──────── **② 코어 구간**(5GC) ────────────────────────────┤
 │  **MEC**(엣지 코어) · 코어 이중화 · **네트워크 슬라이싱**  │
 ├──────── **③ 전송·전원 구간** ────────────────────────────┤
 │  광 링 구성 · 경로 이중화 · **UPS·비상 발전**              │
 ├──────── **④ 운영·관리** ─────────────────────────────────┤
 │  통합 관제(NMS) · 예방 정비 · **장애 대응 체계**           │
 ├──────── **⑤ 보안** ──────────────────────────────────────┤
 │  단말 인증(SIM) · 암호화 · 망분리 · 접근통제               │
 └───────────────────────────────────────────────────────────┘

2. 무선 구간(RAN) 신뢰성 확보​

방안내용
커버리지 중첩 설계
(Overlapping Cell)		· 인접 기지국(RU) 커버리지를 의도적으로 중첩 → 하나가 장애·차폐되어도 서비스 지속
· 음영지역(Dead Zone) 제거 — 사전 전파 측정(Site Survey) 및 시뮬레이션 필수
기지국·장비 이중화· RU(무선유닛)·DU/CU 이중화, 장애 시 자동 절체
· 핵심 구역은 N+1 구성
다중 연결(Multi-Connectivity)· 단말이 2개 이상 기지국에 동시 접속 → 한쪽 실패 시 즉시 대체
· PDCP 중복 전송(Packet Duplication) — 동일 패킷을 두 경로로 전송하여 신뢰도 99.999% 달성
빔포밍·MIMO지향성 빔으로 신호 품질 향상, 다중 안테나로 다이버시티 확보
URLLC 전송 기법· 짧은 전송 시간 간격(Mini-slot), 사전 스케줄링(Grant-free)
· 강건한 변조·부호화(MCS) 선택 — 속도보다 신뢰도 우선
안테나 배치 최적화금속 구조물·랙·크레인 등 차폐물 고려, 천장·기둥 분산 배치, DAS·소형셀 활용
이동성 관리(Handover)이동 로봇·AGV의 무중단 핸드오버 설계, 셀 경계 최적화, 핸드오버 실패율 관리

3. 코어 구간(5GC) 신뢰성 확보​

방안내용
로컬 코어(On-premise 5GC)· 코어망을 현장 내부에 구축 → 외부 회선 장애와 무관하게 자체 운영 지속
· 데이터가 외부로 나가지 않음(보안·지연 동시 확보)
MEC(Multi-access Edge Computing)· 애플리케이션 서버를 기지국 인접에 배치 → 전송 경로 단축으로 초저지연 달성
· 중앙 서버 장애 시에도 로컬 처리 지속
코어 기능 이중화AMF·SMF·UPF 등 NF(Network Function) 다중화, 상태 동기화, 자동 페일오버
네트워크 슬라이싱· 하나의 물리망을 논리적으로 분리
· 제어용 슬라이스(URLLC), 영상용 슬라이스(eMBB), 센서용(mMTC) 분리
· 한 슬라이스의 폭주가 다른 슬라이스에 영향을 주지 않음 ← 신뢰성의 핵심
QoS 보장5QI(5G QoS Identifier) 기반 우선순위·대역 보장, 안전 관련 트래픽 최우선
가상화 기반 복원력컨테이너·클라우드 네이티브 코어 → 자동 복구·확장

4. 전송·전원 및 물리 인프라​

방안내용
전송망 이중화· 광케이블 링(Ring) 구성 → 단선 시 반대 경로로 우회
· 경로 물리적 분리(동일 관로 회피)
전원 이중화UPS + 비상 발전기, 이중 전원 공급(A/B 계통), PoE 백업
환경 대응산업 현장의 온도·습도·분진·진동 대응 → 산업용 등급(IP 등급) 장비 선정
물리 보안장비실 출입통제, 안테나 물리적 보호

5. 운영·관리 체계​

방안내용
통합 관제(NMS/EMS)· 기지국·코어·단말 실시간 상태 모니터링
· 무선 품질 지표(RSRP·SINR·패킷 손실·지연) 상시 수집
예방 정비·예지 보전성능 추이 분석으로 장애 사전 예측, 정기 점검
장애 대응 체계장애 등급별 대응 절차·에스컬레이션, 예비 장비(Spare) 확보, 복구 목표(RTO) 설정
성능 시험·검증구축 후 커버리지·지연·처리량 실측, 부하·절체 시험, 주기적 재측정
변경 관리설비 배치 변경(라인 재배치) 시 전파 환경 재검증
운영 인력·역량무선 전문 인력 확보 또는 전문 사업자 운영 위탁, 교육

6. 보안 (신뢰성의 필수 요소)​

방안내용
단말 인증SIM/eSIM 기반 강력한 상호 인증 — Wi-Fi 대비 우수한 접근통제, 비인가 단말 차단
무선 구간 암호화3GPP 표준 암호화, 무결성 보호
망 분리·접근통제특화망과 사내 업무망·인터넷 분리, 방화벽·NAC
슬라이스 격리업무별 슬라이스 분리로 침해 확산 차단
단말·IoT 보안단말 취약점 관리, 펌웨어 업데이트 체계
로그·감사접속·트래픽 기록, 이상행위 탐지

Ⅲ. 나. 간섭 회피 방안​

1. 간섭의 유형 및 원인​

   [**5G 특화망에서 발생하는 간섭 유형**]

   ┌── **① 동일 채널 간섭**(Co-channel) ──────────────────────┐
   │  인접 셀·인접 특화망이 **같은 주파수** 사용 → 신호 충돌   │
   ├── **② 인접 채널 간섭**(Adjacent Channel) ────────────────┤
   │  옆 대역 신호의 **누설·수신 필터 한계** → 성능 저하       │
   ├── **③ 외부망 간섭** ─────────────────────────────────────┤
   │  **인접 사업장의 특화망**, 이동통신 공중망, 위성·레이더    │
   ├── **④ 상하향 교차 간섭**(TDD Cross-link) ────────────────┤
   │  **TDD 동기 불일치** 시 상향-하향 신호가 서로 간섭        │
   ├── **⑤ 자기 간섭·다중경로** ─────────────────────────────┤
   │  금속 구조물 **반사·산란** → 다중경로 페이딩              │
   ├── **⑥ 비면허 대역 기기 간섭** ──────────────────────────┤
   │  Wi-Fi·산업용 무선기기·전자레인지 등 (근접 대역·고조파)    │
   └───────────────────────────────────────────────────────────┘

   ※ 산업 현장 특유 요인 : **금속 벽·설비**, 이동 크레인, 용접기 등
      **전자파 잡음(EMI) 발생원**이 많음

2. 사전 설계 단계의 간섭 회피​

방안내용
① 전파 환경 사전 조사(Site Survey)· 기존 전파 사용 현황 실측(스펙트럼 분석), 간섭원 식별
· 인접 사업장의 특화망 사용 여부 확인
· 구조물·금속 설비의 전파 영향 측정
② 전파 시뮬레이션·셀 설계· 3D 도면 기반 전파 예측(Ray Tracing)
· 기지국 위치·높이·개수 최적화, 셀 경계 설계
· 커버리지와 간섭의 균형점 도출
③ 주파수 계획(Frequency Planning)· 셀 간 주파수 재사용 계획(Frequency Reuse)
· 인접 셀은 다른 채널 또는 충분한 이격 확보
· 4.7GHz vs 28GHz 용도별 분리 배치
④ 대역 선택 전략· 28GHz는 직진성이 강하고 차폐가 쉬워 간섭 위험 낮음 → 고밀도·구획 환경에 유리
· 4.7GHz는 커버리지 유리하나 인접 간섭 관리 필요
⑤ 출력 전력 설계필요 최소 전력 사용 → 불필요한 전파 확산·인접 간섭 억제
⑥ 안테나 설계· 지향성 안테나로 필요 방향만 커버
· 다운틸트(하향 각도) 조정으로 외부 유출 최소화
· 편파 다이버시티 활용

3. 물리적·구조적 간섭 회피​

방안내용
전파 차폐(Shielding)· 건물 외벽·창호에 차폐 필름·메탈 메시 적용 → 외부 유출·유입 차단
· 구역 간 차폐로 셀 격리
공간 분리간섭원(용접기·고주파 설비)과 물리적 이격, 안테나 위치 조정
실내 분산 안테나(DAS)·소형셀저출력 다수 셀 배치 → 각 셀의 출력을 낮춰 간섭 감소
차폐물 활용벽·구조물을 자연 차폐로 활용하여 셀 경계 설정
EMI 대책노이즈 발생 설비에 대한 차폐·접지·필터 적용

4. 기술적 간섭 제어 기법​

기법내용
빔포밍(Beamforming)· 특정 단말 방향으로만 신호 집중 → 다른 방향 간섭 최소화
· Massive MIMO 기반 다중 빔 운용
간섭 조정(ICIC / eICIC)· 셀 간 간섭 조정 — 인접 셀과 자원(주파수·시간) 사용 협조
· 셀 경계 단말에 다른 자원 블록 할당
동적 자원 할당스케줄러가 간섭 상황을 반영해 자원 배분, 채널 품질(CQI) 기반 적응
전력 제어(Power Control)단말·기지국 송신 전력 동적 조절 — 필요 최소 수준 유지
TDD 동기화· 인접 망과 상·하향 전송 시점(슬롯 구조) 일치 → 교차 간섭 방지
· GPS 기반 시각 동기 필수
적응형 변조·부호화(AMC)간섭 상황에 따라 변조 방식 조정 → 신뢰도 유지
주파수 홉핑·간섭 회피 스케줄링간섭이 심한 자원 블록 회피
간섭 제거 수신기(IC/SIC)수신단에서 간섭 신호를 추정·제거
채널 자동 선택간섭 감지 시 자동으로 간섭이 적은 채널로 전환

5. 운영·제도적 간섭 관리​

방안내용
주파수 이용 조건 준수· 과기정통부가 정한 출력·간섭 보호 기준 준수
· 전파법상 혼신 방지 의무, 지정 구역 외 전파 유출 제한
인접 사업자 협의인접 사업장과 주파수·출력·TDD 구조 협의, 상호 간섭 회피 합의
간섭 상시 모니터링· 스펙트럼 모니터링 시스템 운영
· 무선 품질 지표(SINR·간섭 레벨) 추이 감시
· 이상 시 자동 경보
정기 재측정설비 배치 변경·증설 시 전파 환경 재조사 및 재설계
혼신 신고·조치 절차혼신 발생 시 중앙전파관리소 신고·조사 요청 절차 확보
비면허 기기 관리현장 내 Wi-Fi·무선 기기의 채널 계획 통합 관리

Ⅳ. 구축 시 종합 고려사항​

고려사항내용
① 요구 성능의 명확한 정의어떤 서비스가 어떤 지연·신뢰도를 요구하는가 → 이것이 설계 전체를 결정
(로봇 제어 1ms vs 영상 전송 대역폭)
② 사전 전파 측정의 필수성시뮬레이션만으로는 산업 현장의 금속 구조물 영향 예측 불가 → 실측 필수
③ 주파수 선택커버리지(4.7GHz) vs 초광대역·저간섭(28GHz) — 혼용 설계 검토
④ 투자 대비 효과(TCO)구축비·운영비 vs Wi-Fi 6/7·공중망 대비 편익 → URLLC 요구가 없으면 특화망은 과투자
⑤ 운영 역량 확보무선망 운영은 전문 영역 → 인력 확보 또는 전문 사업자 운영 위탁(Managed Service)
⑥ 단말 생태계5G 지원 산업용 단말·모듈의 가용성·비용 확인
⑦ 확장성향후 라인 증설·구역 확장 대비 모듈형 설계
⑧ 법·제도 준수주파수 지정·신고 절차, 전파법·전기통신사업법, 인체 보호 기준(전자파 강도)
⑨ 기존 인프라 연계사내 유선망·MES/SCADA·클라우드와의 연동 및 보안 경계 설계
⑩ 단계적 구축전면 구축보다 핵심 구역 파일럿 → 검증 → 확대가 위험 최소화

Ⅴ. 결론​

5G 특화망은 Wi-Fi가 제공하지 못하는 초저지연·초신뢰·강력한 단말 인증과, 공중망이 제공하지 못하는 데이터 자체 통제·맞춤형 QoS를 동시에 확보하기 위한 인프라이다. 그러나 구축 자체가 목적이 될 수는 없으며, URLLC 수준의 요구 성능이 실제로 필요한가를 먼저 검증하는 것이 첫 번째 판단이 되어야 한다.

안정성·신뢰성 확보의 핵심은 계층별 이중화이다. 무선 구간에서는 셀 중첩과 다중 연결(패킷 중복 전송) 로 무선 단절에 대비하고, 코어 구간에서는 로컬 5GC와 MEC 배치로 외부 의존성을 제거하며, 네트워크 슬라이싱으로 안전 관련 제어 트래픽을 영상·데이터 트래픽과 논리적으로 격리하는 것이 결정적이다. 전송·전원 이중화와 통합 관제, 그리고 SIM 기반 강력한 단말 인증까지 포함될 때 비로소 산업 현장이 요구하는 99.999% 신뢰도에 도달할 수 있다.

간섭 회피의 요체는 사후 대응이 아니라 사전 설계이다. 산업 현장은 금속 구조물과 EMI 발생원이 밀집해 있어 시뮬레이션만으로는 전파 환경을 예측할 수 없으므로, 실측 기반 사이트 서베이가 반드시 선행되어야 한다. 이후 주파수 재사용 계획·지향성 안테나·최소 출력 설계로 간섭 발생 자체를 줄이고, 빔포밍·ICIC·전력 제어·TDD 동기화로 잔여 간섭을 기술적으로 제어하며, 차폐와 인접 사업자 협의로 외부 간섭을 관리하는 3중 접근이 필요하다. 특히 TDD 동기 불일치로 인한 교차 간섭은 인접 망이 존재할 때 가장 심각한 성능 저하를 유발하므로, GPS 기반 시각 동기와 인접 사업자와의 슬롯 구조 협의가 필수적이다.

끝으로, 5G 특화망은 구축 시점의 최적 설계가 영구히 유지되지 않는다는 점을 유념해야 한다. 생산 라인 재배치, 설비 증설, 인접 사업장의 신규 특화망 개통은 모두 전파 환경을 변화시킨다. 따라서 상시 스펙트럼 모니터링과 변경 시 재검증 체계를 운영 프로세스에 내재화하는 것이 장기적 안정성의 관건이며, 자체 운영 역량이 부족한 경우 전문 사업자를 통한 운영 위탁이 현실적인 대안이 된다.
