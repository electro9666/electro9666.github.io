인공신경망, 역전파

문제​

6.인공신경망에 대하여 다음을 설명하시오.
가.인공신경망의 개념, 구성요소, 역할
나.피드포워드 뉴럴 네트워크(Feedforward Neural Network) 개념 및 절차
다.역전파(Backpropagation) 개념 및 절차
라.활성화 함수의 종류 및 역할

Ⅰ. 개요​

1. 배경​

전통적 프로그래밍은 규칙을 사람이 명시해야 했으나, 이미지 인식·음성 인식처럼 규칙을 언어로 표현할 수 없는 문제가 존재한다. 인공신경망(ANN) 은 생물학적 뉴런의 정보처리 방식을 모사하여 데이터로부터 규칙(가중치)을 스스로 학습한다.

   [발전 과정]
   **퍼셉트론**(1957) — 선형 분류만 가능
        │  **XOR 문제**로 한계 노출 → 1차 AI 겨울
        ▼
   **다층 퍼셉트론(MLP) + 역전파**(1986, Rumelhart) — 비선형 문제 해결
        │  **기울기 소실**·데이터·연산 부족 → 2차 AI 겨울
        ▼
   **딥러닝**(2006~) — **ReLU·GPU·빅데이터·사전학습**으로 한계 극복
        ▼
   CNN(영상) · RNN/LSTM(순차) · **Transformer**(2017, 현재 LLM의 기반)

Ⅱ. 가. 인공신경망의 개념, 구성요소, 역할​

1. 개념​

인공신경망(ANN: Artificial Neural Network) 은 다수의 인공 뉴런(노드) 을 계층적으로 연결하고, 연결 강도(가중치)를 데이터로부터 학습하여 입력과 출력 간의 복잡한 비선형 관계를 근사하는 기계학습 모델이다.

   [생물학적 뉴런 → 인공 뉴런]

   수상돌기(입력) → 세포체(가중합) → 축삭(출력) → 시냅스(연결강도)
        ▼                ▼                ▼            ▼
     **입력 x**      **Σ(wx)+b**      **활성화 f()**   **가중치 w**

   [인공 뉴런의 계산]
                x₁ ──w₁──┐
                x₂ ──w₂──┤
                x₃ ──w₃──┼──▶ **z = Σ(wᵢxᵢ) + b** ──▶ **a = f(z)** ──▶ 출력
                          │            (가중합)         (활성화 함수)
                    **b**(편향)

2. 구성요소​

구성요소내용역할
뉴런(노드)신경망의 최소 연산 단위가중합 계산 + 활성화
가중치(Weight, w)뉴런 간 연결 강도학습의 대상 — 입력의 중요도를 표현
편향(Bias, b)활성화 임계값 조정 항결정 경계의 평행 이동 — 표현력 확보
활성화 함수(Activation)가중합을 변환하는 비선형 함수비선형성 부여(핵심), 출력 범위 제한
입력층(Input Layer)특징(Feature) 수만큼의 노드데이터 입력
은닉층(Hidden Layer)입력과 출력 사이의 계층특징 추출·추상화(층이 깊을수록 고수준 특징)
출력층(Output Layer)최종 결과 산출예측값·분류 확률 출력
손실 함수(Loss Function)예측과 정답의 오차 측정학습의 목표 지표
최적화 알고리즘(Optimizer)가중치 갱신 방법손실 최소화(경사하강법·Adam)
하이퍼파라미터학습률·층수·노드수·배치크기·에폭사람이 설정하는 학습 조건
   [전형적 신경망 구조 — 다층 퍼셉트론(MLP)]

   **입력층**        **은닉층 1**      **은닉층 2**      **출력층**
    ○ x₁ ──────────▶ ○ ──────────────▶ ○ ────────────▶ ○ ŷ₁
    ○ x₂ ──────────▶ ○ ──────────────▶ ○ ────────────▶ ○ ŷ₂
    ○ x₃ ──────────▶ ○ ──────────────▶ ○
                     ○                 ○
      (특징 입력)   (저수준 특징)     (고수준 특징)    (예측)
      ※ 인접 층 간 **완전연결(Fully Connected)**, 가중치 행렬 W로 표현

3. 역할​

역할내용
① 비선형 함수 근사범용 근사 정리(Universal Approximation Theorem) — 충분한 은닉 노드가 있으면 임의의 연속 함수 근사 가능
② 자동 특징 추출사람이 특징을 설계(Feature Engineering)하지 않아도 데이터로부터 계층적 특징 학습
③ 분류·예측이미지 분류, 수요 예측, 이상 탐지
④ 표현 학습고차원 데이터를 의미 있는 저차원 벡터(임베딩) 로 변환
⑤ 생성새로운 데이터 생성(GAN·확산모델·LLM)
⑥ 일반화학습하지 않은 새로운 데이터에도 적용 가능한 규칙 획득

Ⅲ. 나. 피드포워드 뉴럴 네트워크 (FNN)​

1. 개념​

피드포워드 신경망(FNN) 은 정보가 입력층 → 은닉층 → 출력층 방향으로만 흐르고 순환(Feedback)이 없는 가장 기본적인 신경망 구조이다. 순전파(Forward Propagation) 는 이 흐름을 따라 예측값을 계산하는 과정이다.

특징내용
단방향 흐름순환·되먹임 없음 — 유향 비순환 그래프(DAG) 구조
계층 구조인접 층 간 완전연결(Fully Connected), 동일 층 내 연결 없음
기억 없음입력마다 독립 처리 → 순차 데이터 부적합(RNN·Transformer 필요)
대표 형태다층 퍼셉트론(MLP)
용도분류·회귀, 그리고 CNN·Transformer 내부의 FFN 계층으로도 사용

2. 순전파 절차​

   ① **입력 데이터 제공**
        │  x = [x₁, x₂, …, xₙ]  (정규화·표준화 적용)
        ▼
   ② **은닉층 1 가중합 계산**
        │  **z⁽¹⁾ = W⁽¹⁾·x + b⁽¹⁾**      (행렬 연산)
        ▼
   ③ **활성화 함수 적용**
        │  **a⁽¹⁾ = f(z⁽¹⁾)**            (예: ReLU)
        ▼
   ④ **다음 층으로 전달 — ②~③ 반복**
        │  **z⁽ˡ⁾ = W⁽ˡ⁾·a⁽ˡ⁻¹⁾ + b⁽ˡ⁾**
        │  **a⁽ˡ⁾ = f(z⁽ˡ⁾)**
        ▼
   ⑤ **출력층 계산**
        │  회귀 → **항등함수(Linear)**
        │  이진 분류 → **Sigmoid**
        │  다중 분류 → **Softmax**(확률 분포)
        ▼
   ⑥ **예측값 ŷ 산출**
        ▼
   ⑦ **손실 계산**
        │  회귀 → **MSE**,  분류 → **Cross-Entropy**
        │  **L = Loss(ŷ, y)**
        ▼
        └────▶ (학습 시) **역전파 단계로 진행**
단계수식의미
가중합z = Wx + b입력의 선형 결합
활성화a = f(z)비선형 변환 — 표현력 확보
출력ŷ = f_out(z_out)과업에 맞는 형태로 변환
손실L = Loss(ŷ, y)오차의 정량화

Ⅳ. 다. 역전파 (Backpropagation)​

1. 개념​

역전파는 출력층에서 계산된 오차를 입력층 방향으로 거꾸로 전파하면서, 연쇄법칙(Chain Rule) 을 이용해 각 가중치가 오차에 기여한 정도(기울기, Gradient) 를 효율적으로 계산하고, 이를 경사하강법으로 가중치를 갱신하는 학습 알고리즘이다.

   [역전파의 핵심 아이디어]

   "이 가중치를 조금 바꾸면 오차가 얼마나 변하는가?"
        = **∂L/∂w** (손실에 대한 가중치의 편미분)
        ▼
   각 층마다 **미분값을 계산하면 연산량 폭발**
        ▼
   [**연쇄법칙 + 재사용**]
   출력층에서 계산한 오차 신호를 **역방향으로 재활용**
        ▼
   ⇒ **한 번의 역방향 순회로 모든 가중치의 기울기 계산**
      (계산 복잡도를 순전파 수준으로 낮춤 = 딥러닝을 가능하게 한 핵심)

2. 역전파 절차​

   ┌─────────── **순전파**(Forward) ───────────┐
   │  x → z⁽¹⁾ → a⁽¹⁾ → z⁽²⁾ → a⁽²⁾ → ŷ       │
   │  중간 계산값(z, a)을 **저장**              │
   └──────────────────┬────────────────────────┘
                      ▼
   ① **손실 계산**    L = Loss(ŷ, y)
                      ▼
   ┌─────────── **역전파**(Backward) ──────────┐
   │                                            │
   │ ② **출력층 오차 신호 계산**                 │
   │     δ⁽ᴸ⁾ = ∂L/∂z⁽ᴸ⁾                       │
   │     (Softmax + Cross-Entropy → **δ = ŷ − y**)│
   │            ▼                               │
   │ ③ **출력층 기울기 계산**                    │
   │     **∂L/∂W⁽ᴸ⁾ = δ⁽ᴸ⁾ · (a⁽ᴸ⁻¹⁾)ᵀ**        │
   │     **∂L/∂b⁽ᴸ⁾ = δ⁽ᴸ⁾**                    │
   │            ▼                               │
   │ ④ **이전 층으로 오차 전파**(연쇄법칙)       │
   │     **δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾)ᵀ·δ⁽ˡ⁺¹⁾ ⊙ f′(z⁽ˡ⁾)** │
   │     ※ ⊙ = 요소별 곱, f′ = 활성화 함수 미분  │
   │            ▼                               │
   │ ⑤ **③~④를 입력층까지 반복**                │
   └──────────────────┬─────────────────────────┘
                      ▼
   ⑥ **가중치 갱신**(경사하강법)
        **W ← W − η·(∂L/∂W)**      (η = 학습률)
        **b ← b − η·(∂L/∂b)**
                      ▼
   ⑦ **다음 배치·에폭 반복** → 손실이 수렴할 때까지

3. 학습 관련 기법​

구분기법내용
경사하강 방식배치 GD전체 데이터로 1회 갱신 — 안정적, 느림
확률적 GD(SGD)샘플 1개씩 갱신 — 빠름, 불안정
미니배치 GD일반적 선택(32~256) — 안정성과 속도 균형
최적화 기법Momentum이전 방향을 관성으로 반영 → 진동 감소
RMSProp / AdaGrad파라미터별 학습률 적응 조정
AdamMomentum + RMSProp — 현재 사실상 표준
일반화 기법드롭아웃(Dropout)학습 시 뉴런 일부 무작위 비활성화 → 과적합 방지
배치 정규화(BN)층 입력 분포 정규화 → 학습 안정·가속
L1/L2 규제가중치 크기 제한
조기 종료(Early Stopping)검증 손실 증가 시 중단
가중치 초기화Xavier(Sigmoid/tanh), He(ReLU) 초기화

4. 역전파의 문제점과 해결​

문제원인해결
기울기 소실(Vanishing Gradient)Sigmoid/tanh의 미분값이 0~0.25 → 층을 거칠수록 기울기가 0에 수렴ReLU 계열 활성화, 배치 정규화, 잔차 연결(ResNet), LSTM 게이트
기울기 폭발(Exploding Gradient)기울기가 반복 곱해져 발산기울기 클리핑, 가중치 초기화, 정규화
국소 최적해·안장점비볼록 손실 함수Momentum·Adam, 학습률 스케줄링
과적합모델 복잡도 > 데이터드롭아웃·규제·데이터 증강·조기 종료
학습률 설정 곤란너무 크면 발산, 작으면 정체적응적 옵티마이저, 학습률 스케줄(Warmup·Cosine)
높은 연산 비용대규모 파라미터GPU/TPU, 혼합정밀도, 분산 학습

Ⅴ. 라. 활성화 함수의 종류 및 역할​

1. 역할​

   [**활성화 함수가 없다면?**]

   층을 아무리 쌓아도  a = W₂(W₁x + b₁) + b₂ = **W′x + b′**
        ▼
   결국 **하나의 선형 변환**과 동일 → **깊이의 의미 소멸**
   ⇒ XOR 같은 **비선형 문제 해결 불가**
        ▼
   [**활성화 함수의 역할**]
   ① **비선형성 부여** — 층을 쌓는 의미 창출(핵심 역할)
   ② **출력 범위 제한** — 확률(0~1) 등 해석 가능한 형태로 변환
   ③ **선택적 활성화** — 특정 뉴런만 반응(희소성)
   ④ **기울기 전달** — 미분 가능해야 역전파 수행 가능
역할상세
① 비선형성 부여다층 구조가 복잡한 결정 경계를 학습할 수 있게 함 — 가장 본질적 역할
② 출력 형태 변환Sigmoid → 확률, Softmax → 확률 분포, Linear → 실수값
③ 학습 안정성미분값의 크기가 기울기 소실/폭발을 좌우
④ 희소 표현ReLU는 음수를 0으로 → 희소 활성화로 연산 효율·일반화 향상

2. 활성화 함수의 종류​

Ⅵ. 결론​

인공신경망은 가중치라는 학습 가능한 파라미터와 활성화 함수라는 비선형 변환을 계층적으로 쌓아, 데이터로부터 복잡한 함수 관계를 근사하는 모델이다. 그 동작은 순전파(예측) → 손실 계산 → 역전파(기울기 계산) → 가중치 갱신의 반복이라는 단일 루프로 요약된다.

이 구조에서 세 요소가 각각 결정적 역할을 한다. 첫째, 활성화 함수는 비선형성을 부여한다. 이것이 없으면 층을 아무리 깊게 쌓아도 하나의 선형 변환에 불과하므로, 깊이 자체가 무의미해진다. 둘째, 역전파는 학습을 계산 가능하게 만든다. 연쇄법칙으로 오차 신호를 역방향 재사용함으로써, 수백만 개 파라미터의 기울기를 순전파 수준의 비용으로 계산할 수 있게 한 것이 딥러닝 실현의 핵심 돌파구였다. 셋째, 최적화 기법과 정규화가 학습의 안정성과 일반화를 좌우한다.

역사적으로 신경망의 두 차례 침체는 모두 기울기 소실과 연산 자원의 한계에서 비롯되었고, 이를 해결한 것이 ReLU 계열 활성화 함수, 배치 정규화, 잔차 연결, GPU 병렬 연산이었다. 즉 알고리즘 자체(역전파)는 1986년에 이미 완성되어 있었고, 이를 실용화한 것은 활성화 함수와 하드웨어의 진보였다는 점은 실무적으로 시사하는 바가 크다.

현재의 Transformer 기반 LLM 역시 본질적으로는 동일한 원리 — 순전파, 역전파, GELU 활성화, Adam 최적화 — 위에서 동작한다. 따라서 신경망의 기본 메커니즘에 대한 정확한 이해는 최신 AI 기술을 평가하고 도입 판단을 내리는 데 있어 여전히 필수적인 기반 지식이 된다.
