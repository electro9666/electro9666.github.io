국가 망 보안체계(N2SF: National Network Security Framework)

Ⅰ. 개요​

1. 추진 배경​

기존 공공부문의 망 분리(Network Separation) 정책은 물리적 분리를 통해 보안을 확보했으나, 클라우드·AI·협업 도구 등 신기술 도입을 원천적으로 차단하고 업무 효율을 저하시킨다는 지적이 지속되었다.

   [기존 망분리]                       [N2SF]
   업무망 ─── 완전 차단 ─── 인터넷망     **데이터 중요도 기반 등급 분류(C/S/O)**
   ▲ 신기술(클라우드·AI) 도입 불가        ▲ 등급별 차등 보안통제
   ▲ 이중 단말·업무 비효율                ▲ **필요한 흐름은 허용**하되 통제
   ▲ 내부 침투 시 확산 방어 취약          ▲ **제로 트러스트** 개념 결합

2. 개념​

국가정보원이 2025년 1월 공공기관 대상으로 발표한 N2SF는 일률적 망분리에서 벗어나, 데이터의 중요도에 따라 등급을 분류하고 등급별로 차등화된 보안통제를 적용하는 다층 보안체계(Multi-Layered Security Framework) 이다. 미국 NIST의 위험관리 프레임워크(RMF)·제로 트러스트 개념을 국내 환경에 맞게 적용하였다.

Ⅱ. 가. 국가 망 보안체계(N2SF)의 개념​

1. 기본 원칙​

원칙내용
데이터 중심 보안망(네트워크)이 아닌 데이터의 중요도를 기준으로 보안 수준 결정
위험 기반 차등 통제등급별로 필요한 보안통제를 차등 적용(획일적 차단 지양)
업무 효율성 조화보안을 유지하면서 신기술(클라우드·AI·협업) 활용 허용
제로 트러스트"절대 신뢰하지 말고 항상 검증" — 내부도 신뢰하지 않고 접근 시마다 인증·인가
자율과 책임기관이 자체 위험평가를 통해 등급을 판단하되 결과에 책임

2. 보안 등급 체계 (C-S-O 모델)​

   ┌─────────────────────────────────────────────────────────┐
   │ **C (Classified)** — 기밀 : 국가기밀·안보 관련 핵심 정보 │
   │    ⇒ 최고 수준 통제, **물리적 분리 원칙 유지**            │
   ├─────────────────────────────────────────────────────────┤
   │ **S (Sensitive)** — 민감 : 개인정보·내부 업무자료 등      │
   │    ⇒ 논리적 분리 + **강화된 접근통제·암호화·모니터링**    │
   ├─────────────────────────────────────────────────────────┤
   │ **O (Open)** — 공개 : 대외 공개 가능 정보                │
   │    ⇒ 기본 보안통제, **인터넷·클라우드 자유 활용**         │
   └─────────────────────────────────────────────────────────┘
   ※ 등급 간 데이터 이동은 **통제된 연계 지점(보안 게이트웨이)** 을 통해서만 허용

3. 기존 망분리와의 비교​

비교 기준기존 망분리N2SF
기준네트워크(망) 단위데이터 중요도 단위
통제 방식일률적·물리적 차단등급별 차등 통제
신기술 도입사실상 불가가능(클라우드·AI·SaaS)
내부 위협내부는 신뢰(확산 취약)제로 트러스트(내부도 검증)
업무 효율낮음(이중 단말·자료 이동 불편)개선
책임지침 준수 중심기관의 위험평가와 자율 책임
관리 난이도단순높음(분류·통제 설계 필요)

Ⅲ. 나. 국가 망 보안체계(N2SF)의 적용 절차​

 ① **준비(Prepare)** ─► ② **분류(Categorize)** ─► ③ **통제 선정(Select)**
   추진체계·범위 확정      데이터·시스템 등급(C/S/O)     등급별 보안통제 항목 결정
   자산 식별                                                    │
        │                                                       ▼
 ⑥ **지속 관리(Monitor)** ◄─ ⑤ **승인(Authorize)** ◄─ ④ **구현·평가(Implement)**
   모니터링·재평가·개선        책임자 승인·운영 개시       통제 적용 및 유효성 검증
        └─────────────── 환경 변화 시 재분류·재평가 ───────────────┘
단계주요 활동산출물
① 준비추진 조직 구성, 적용 범위 결정, 정보자산·업무 식별, 현행 아키텍처 분석, 위험관리 전략 수립추진계획서, 자산 목록
② 분류(등급 지정)데이터·정보시스템의 기밀성·무결성·가용성 영향도 평가, C/S/O 등급 부여, 등급 간 데이터 흐름 식별등급 분류표, 데이터 흐름도
③ 보안통제 선정등급별 기준 보안통제(Baseline) 선택, 기관 환경에 맞게 조정(Tailoring), 보완 통제 결정보안통제 목록, 적용 계획
④ 구현·평가통제 실제 구현(접근통제·암호화·경계 보안·로깅), 취약점 점검·모의훈련으로 유효성 평가구현 결과서, 보안성 평가 결과
⑤ 승인잔여 위험 검토, 기관장(책임자)의 운영 승인, 미흡사항 조치계획 확정승인서, 위험수용 문서
⑥ 지속 관리상시 모니터링, 이상 탐지·대응, 정기 재평가 및 등급 재분류, 변경 관리모니터링 보고서, 개선계획
  • 핵심 특징: 일회성 구축이 아닌 RMF 기반의 순환적(Continuous) 위험관리 프로세스이며, ②단계의 데이터 등급 분류가 전체 성패를 좌우한다.

Ⅳ. 다. 국가 망 보안체계(N2SF) 고려사항​

구분고려사항상세 내용 및 대응
분류 체계등급 분류의 정확성·일관성기관마다 판단 기준이 달라지면 체계 자체가 무의미 → 명확한 분류 기준·사례집 마련, 분류 심의 절차, 과도한 C등급 지정(보수적 분류)으로 인한 효과 상실 경계
데이터 흐름 식별등급 간 이동 경로를 빠짐없이 식별해야 통제 설계 가능 → 데이터 흐름도(Data Flow) 작성 필수
아키텍처등급 간 연계 통제등급 경계에 보안 게이트웨이·망연계 솔루션(CDR·파일 정화) 배치, 단방향 전송 등
제로 트러스트 구현사용자·기기 식별과 인증(MFA), 최소 권한, 마이크로 세그멘테이션, 지속적 신뢰 평가
클라우드 활용CSAP 인증 클라우드 이용, 등급별 클라우드 배치 모델(퍼블릭/프라이빗) 결정, 데이터 위치 통제
기술암호화·키 관리전송·저장 암호화, 검증필 암호모듈(KCMVP) 사용, 키 관리 체계
통합 모니터링등급별 로그 수집·분석, SIEM·EDR 연동, 이상행위 탐지(UEBA)
단말 보안업무 단말의 신뢰성 검증(디바이스 상태 평가), 가상화(VDI·DaaS) 활용
전환 관리단계적 전환기존 망분리에서 급격한 전환은 위험 → 시범 적용 후 확대, 전환 기간 중 병행 운영
레거시 대응구형 시스템의 인증·암호화 미지원 → 보완 통제(프록시·게이트웨이) 적용
관리·조직거버넌스·책임기관 자율에 따른 책임 증가 → 최고책임자(CISO) 권한 강화, 의사결정 절차 문서화
인력·역량위험평가·제로 트러스트 설계 역량 필요 → 전문 인력 확보·교육, 외부 컨설팅
예산통제 구현·솔루션 도입 비용 → 위험 기반 우선순위로 단계적 투자
제도 정합성타 제도와의 연계ISMS-P, CSAP, 개인정보보호법과 중복 항목 정합성 확보, 이중 규제 부담 완화
감사·검증적용 결과에 대한 객관적 검증(보안성 평가·감리) 체계
운영사용자 수용성보안 강화로 업무 불편이 커지면 우회 사용(섀도 IT) 발생 → 사용성 고려, 교육·소통
지속 개선신기술·위협 변화에 따른 정기 재평가와 통제 갱신

Ⅴ. 결론​

N2SF는 "망을 나누는 보안"에서 "데이터를 지키는 보안"으로의 패러다임 전환이며, 획일적 망분리가 초래한 신기술 도입 지연 문제를 해결하면서도 제로 트러스트 개념으로 내부 위협 대응력을 강화한다는 점에서 진일보한 체계이다.

다만 성공의 관건은 기술 도입이 아니라 ② 데이터 등급 분류 단계의 정확성과 일관성에 있다. 분류가 부실하면 통제 전체가 무의미해지고, 반대로 보수적으로 과도하게 높은 등급을 지정하면 기존 망분리와 다를 바 없어진다.

따라서 실무적으로는 ① 명확한 분류 기준과 사례 중심 가이드를 마련하고, ② 데이터 흐름도를 기반으로 등급 간 연계 지점에 통제를 집중하며, ③ 기존 망분리에서 시범 적용을 거쳐 단계적으로 전환하고, ④ ISMS-P·CSAP 등 기존 인증체계와 통제 항목을 통합 관리하여 중복 부담을 줄이는 접근이 바람직하다. 궁극적으로 N2SF는 보안과 업무 효율의 균형을 기관 스스로 판단하고 책임지는 체계이므로, 기관의 위험관리 역량 확보가 제도 정착의 전제 조건이다.
