GNN(Graph Neural Network, 그래프 신경망)

Ⅰ. 개요​

GNN은 노드(Node)와 엣지(Edge)로 구성된 비정형 그래프 데이터를 직접 입력으로 받아, 이웃 노드의 정보를 반복적으로 집계·전파(Message Passing) 함으로써 노드·엣지·그래프 단위의 표현(Embedding)을 학습하는 신경망이다. 격자 구조를 전제하는 CNN·RNN으로는 다룰 수 없는 관계형 데이터에 적용된다.

Ⅱ. 동작 원리 — 메시지 패싱​

   [k번째 계층에서 노드 v의 갱신]
        ┌── 이웃 u1 ──┐
   u2 ──┤  메시지 전달 ├──► **집계(Aggregate)** : sum/mean/max
        └── 이웃 u3 ──┘              ▼
                          **갱신(Update)** : h_v^(k) = σ(W·[h_v^(k−1) ‖ AGG])
   ※ 계층을 k번 쌓으면 **k-hop 이웃 정보까지 반영**
   ※ 집계 함수는 **순서 불변(Permutation Invariant)** 이어야 함
단계내용
① Message각 이웃 노드의 특징을 변환하여 메시지 생성
② Aggregate이웃 메시지를 순서 무관하게 집계(평균·합·최대·어텐션 가중합)
③ Update자신의 이전 표현과 결합해 새 표현 산출
④ Readout그래프 단위 예측 시 전체 노드 표현을 통합(Pooling)

Ⅲ. 주요 모델 및 활용​

모델특징
GCN(Graph Convolutional Network)정규화된 인접행렬 기반 평균 집계, 가장 기본적 형태
GraphSAGE이웃 샘플링으로 대규모 그래프 확장, 미학습 노드 추론(Inductive) 가능
GAT(Graph Attention Network)어텐션으로 이웃별 중요도 학습 → 성능·해석력 우수
GIN그래프 구조 판별력(WL-test) 최대화
과업 유형활용 사례
노드 분류이상거래·보험사기 탐지, 악성 계정 식별, 논문 주제 분류
링크 예측추천 시스템(사용자–상품 그래프), 지식그래프 보완, 신약 상호작용 예측
그래프 분류분자 구조 기반 신약 개발, 화합물 물성 예측
기타교통 흐름 예측(도로망), 네트워크 장애 전파 분석, 코드 취약점 탐지
구분내용
장점관계·구조 정보 활용, 순서 불변성, 미지 노드로 일반화(Inductive)
한계Over-smoothing(층이 깊으면 노드 표현이 균질화), 대규모 그래프의 계산·메모리 부담, 동적 그래프 대응 곤란, 설명가능성

Ⅳ. 결론​

GNN은 "데이터 간 관계 자체가 정보" 인 영역에서 기존 딥러닝이 도달하지 못한 성능을 제공한다. 다만 층을 깊게 쌓기 어려운 Over-smoothing 문제와 확장성 제약이 있으므로, 실무에서는 이웃 샘플링(GraphSAGE)·잔차 연결·그래프 분할로 규모 문제를 해결하고, 금융 이상탐지·추천·신약 개발 등 관계 구조가 명확한 도메인에 우선 적용하는 것이 효과적이다.
