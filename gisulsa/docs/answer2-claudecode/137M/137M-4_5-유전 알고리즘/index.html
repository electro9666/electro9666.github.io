유전 알고리즘(Genetic Algorithm)

Ⅰ. 개요​

1. 배경​

조합 최적화 문제(외판원 문제·일정 계획 등)는 탐색 공간이 지수적으로 커져 완전 탐색이 불가능하다. 이에 자연계의 진화 원리(적자생존·유전·돌연변이) 를 모방하여 실용적 시간 내에 우수한 해를 찾는 메타휴리스틱(Metaheuristic) 기법이 유전 알고리즘이다.

Ⅱ. 가. 유전 알고리즘의 개념 및 절차​

1. 개념​

유전 알고리즘(GA) 은 Holland가 제안한 진화 연산 기법으로, 여러 개의 후보 해(개체)로 구성된 집단(Population) 을 유지하면서 선택·교차·돌연변이 연산을 세대에 걸쳐 반복 적용하여 점진적으로 더 우수한 해로 진화시키는 확률적 탐색 알고리즘이다.

생물학 개념GA 대응 개념
개체(Individual)하나의 후보 해(Solution)
염색체(Chromosome)해의 인코딩된 표현(비트열·실수 벡터·순열)
유전자(Gene)염색체를 구성하는 개별 요소(변수 값)
집단(Population)동시에 유지되는 후보 해의 집합
적합도(Fitness)해의 우수성 평가값(목적함수)
세대(Generation)알고리즘의 1회 반복 주기

2. 수행 절차​

   ① **초기 집단 생성**(무작위 N개 해)
        │
        ▼
   ② **적합도 평가**(Fitness Evaluation) ◄─────────────────┐
        │  각 개체의 목적함수 값 계산                       │
        ▼                                                  │
   ③ **종료 조건 판단** ── 만족 ──► [최적해 출력·종료]      │
        │ 미만족                                            │
        ▼                                                  │
   ④ **선택(Selection)** : 적합도 높은 개체를 부모로 선택    │
        │                                                  │
        ▼                                                  │
   ⑤ **교차(Crossover)** : 부모 유전자를 결합해 자손 생성    │  세대 반복
        │                  (탐색의 **활용 Exploitation**)   │
        ▼                                                  │
   ⑥ **돌연변이(Mutation)** : 일부 유전자 무작위 변형        │
        │                  (탐색의 **탐험 Exploration**)    │
        ▼                                                  │
   ⑦ **대치(Replacement)** : 새 세대 집단 구성 ─────────────┘
단계상세 내용
① 초기화해의 표현 방식(인코딩) 결정 후 무작위로 집단 생성. 집단 크기는 다양성과 계산비용의 균형으로 결정
② 적합도 평가문제의 목적함수로 각 개체 점수화. 적합도 함수 설계가 성능을 좌우
③ 종료 판단최대 세대 수 도달 / 목표 적합도 달성 / 일정 세대 동안 개선 없음(수렴)
④ 선택우수 개체에 높은 재생산 기회 부여(아래 참조)
⑤ 교차두 부모의 유전자를 조합해 자손 생성. 교차율(Pc) 통상 0.6~0.95
⑥ 돌연변이낮은 확률로 유전자 변경 → 지역 최적해 탈출. 돌연변이율(Pm) 통상 0.001~0.05
⑦ 대치세대 교체(Generational) 또는 일부 교체(Steady-state), 엘리트 보존

3. 인코딩 및 유전 연산자​

구분방식내용
인코딩이진(Binary)10110101 — 전통적 방식, 단순
실수(Real-valued)연속 최적화 문제에 적합
순열(Permutation)3-1-4-2-5 — TSP·일정 계획 등 순서 문제
트리유전 프로그래밍(GP), 수식·프로그램 표현
선택룰렛 휠(Roulette Wheel)적합도 비례 확률 선택 — 직관적이나 초기 수렴 위험
토너먼트(Tournament)k개 무작위 추출 후 최우수 선택 — 선택압 조절 용이, 가장 널리 사용
순위 기반(Rank)적합도 값이 아닌 순위로 선택 → 스케일 문제 완화
엘리트주의(Elitism)최우수 개체를 다음 세대에 무조건 보존 → 성능 퇴화 방지
교차1점/다점 교차특정 지점 기준으로 부모 유전자 교환
균등 교차(Uniform)유전자별로 무작위 선택
순서 교차(OX)·PMX순열 표현에서 중복 없는 자손 생성(TSP 등)
돌연변이비트 반전 / 스왑 / 역위표현 방식에 맞는 변형 연산 적용
   [1점 교차 예시]
   부모1 : 1011 | 0101        자손1 : 1011 | 1100
   부모2 : 0110 | 1100   ──►  자손2 : 0110 | 0101
                교차점

   [돌연변이 예시]
   1011 1100  ──► 1011 **0**100   (한 비트 반전)

Ⅲ. 나. 유전 알고리즘의 최적화 방법​

1. 최적화의 핵심 원리 — 탐험과 활용의 균형​

   [Exploration(탐험) ↔ Exploitation(활용) 균형]

   탐험 과다(높은 돌연변이율·낮은 선택압)          활용 과다(낮은 돌연변이율·높은 선택압)
   → 무작위 탐색과 유사, 수렴 실패                → **조기 수렴(Premature Convergence)**
                                                     지역 최적해에 갇힘
                    └──────► **최적 균형점** ◄──────┘
                       세대 초기: 탐험 중심 → 후기: 활용 중심

2. 최적화 기법​

구분기법내용
파라미터 최적화적응형 파라미터(Adaptive GA)세대·다양성에 따라 교차율·돌연변이율을 동적 조정 — 다양성 감소 시 돌연변이율 상향
집단 크기 조절초기 큰 집단으로 다양성 확보 → 후기 축소로 계산 절감
자기 적응(Self-adaptive)파라미터 자체를 염색체에 인코딩하여 함께 진화
다양성 유지적합도 공유(Fitness Sharing)유사 개체들의 적합도를 나눠 군집 집중 억제
혼잡 제거(Crowding)유사한 개체로 대치하여 다양성 보존
니칭(Niching)탐색 공간을 여러 니치로 분할해 다중 해 동시 탐색
중복 제거동일 개체 제거로 조기 수렴 방지
수렴 성능 향상엘리트주의(Elitism)최우수 개체 보존 — 성능 퇴화 방지의 기본 기법
선택압(Selection Pressure) 조절토너먼트 크기 k 조정으로 수렴 속도 제어
적합도 스케일링선형 스케일링·시그마 절단으로 특정 개체의 지배 방지
지역 탐색 결합메미틱 알고리즘(Memetic Algorithm)GA(전역 탐색) + 지역 탐색(Local Search·힐 클라이밍) 결합 → 해의 정밀도 대폭 향상
하이브리드시뮬레이티드 어닐링·타부 서치와 결합
구조적 개선병렬 GA(Island Model)집단을 여러 섬으로 분할해 독립 진화 후 주기적 이주(Migration) → 다양성 유지 + 병렬 처리
세대 모델 선택Steady-state(점진 교체)로 우수 해 유지 강화
다목적 최적화NSGA-II / MOEA상충하는 여러 목적을 동시 최적화 → 파레토 최적해 집합 도출(비지배 정렬 + 혼잡 거리)
제약 조건 처리페널티 함수제약 위반 시 적합도 감점
수선(Repair) 기법위반 해를 유효한 해로 보정
평가 효율화대리 모델(Surrogate)적합도 평가 비용이 큰 경우 근사 모델로 대체 평가

3. 성능 개선 실무 지침​

지침내용
적합도 함수 설계 우선GA 성능의 대부분은 문제 표현(인코딩)과 적합도 함수 설계에서 결정
엘리트주의 기본 적용최우수 해 손실을 방지하는 가장 저렴하고 효과적인 기법
수렴 진단집단 다양성 지표(유전자 분산) 모니터링 → 급감 시 돌연변이율 상향
재시작(Restart)수렴 정체 시 일부 개체를 무작위로 재생성
파라미터 튜닝여러 조합에 대한 실험 필요(문제 의존적) — No Free Lunch 정리

Ⅳ. GA의 특징 및 활용​

1. 장단점​

구분내용
장점① 미분 불가능·불연속·비선형 문제에도 적용 가능(도함수 불필요)
② 집단 기반 병렬 탐색으로 지역 최적해 탈출 능력 우수
③ 다목적 최적화·제약 문제에 유연하게 확장
④ 문제 구조에 대한 사전 지식이 적어도 적용 가능
단점① 전역 최적해 보장 없음(근사 해)
② 조기 수렴 위험
③ 파라미터(집단 크기·교차율·돌연변이율) 튜닝 부담
④ 적합도 평가 비용이 크면 계산 시간 과다
⑤ 실행마다 결과가 달라짐(확률적)

2. 활용 분야​

분야활용 사례
조합 최적화외판원 문제(TSP), 차량 경로 계획(VRP), 배낭 문제, 작업 일정 계획(Job Shop Scheduling)
공학 설계구조물 최적 설계, 안테나 형상 설계, 회로 배치
AI·기계학습하이퍼파라미터 최적화, 신경망 구조 탐색(NAS), 특징 선택(Feature Selection)
IT 운영자원 배분·부하 분산, 클라우드 인스턴스 배치, 네트워크 토폴로지 최적화
금융·물류포트폴리오 최적화, 재고·물류 네트워크 설계

3. 유사 기법과의 비교​

기법특징
유전 알고리즘집단 기반, 교차·돌연변이로 진화
시뮬레이티드 어닐링단일 해 기반, 확률적 수용으로 지역해 탈출
입자 군집 최적화(PSO)집단 기반, 개체 간 정보 공유로 이동(연속 문제에 강함)
개미 군집(ACO)페로몬 기반 경로 탐색(경로 문제에 특화)
경사 하강법미분 기반, 빠르나 지역 최적해에 취약·미분 가능해야 함

Ⅴ. 결론​

유전 알고리즘은 탐색 공간이 방대하고 목적함수가 미분 불가능하거나 복잡한 문제에서, 합리적 시간 내에 실용적으로 우수한 해를 찾는 강력한 메타휴리스틱이다. 다만 전역 최적해를 보장하지 않으며 조기 수렴 위험이 상존한다는 본질적 한계를 갖는다.

따라서 실무 적용 시에는 ① 문제에 맞는 인코딩과 적합도 함수 설계에 가장 많은 노력을 투입하고, ② 엘리트주의를 기본 적용하되 ③ 집단 다양성을 모니터링하며 적응형 파라미터로 탐험-활용 균형을 유지해야 한다. ④ 해의 정밀도가 중요하면 지역 탐색을 결합한 메미틱 알고리즘을, 목적이 여럿이면 NSGA-II 계열을 적용하는 것이 효과적이다.

궁극적으로 GA는 만능 해법이 아니며(No Free Lunch 정리), 문제의 구조를 알고 있다면 전용 알고리즘이 우수하므로, 문제 특성에 따른 기법 선택 판단이 기술사에게 요구되는 핵심 역량이다.
