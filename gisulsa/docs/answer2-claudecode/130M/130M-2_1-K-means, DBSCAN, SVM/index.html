K-means, DBSCAN, SVM

문제​

1.데이터 마이닝의 기법 중 아래 기법에 대하여 설명하시오.
1) K-means Clustering
2) DBSCAN(Density Based Spatial Clustering of Applications with Noise)
3) SVM(Support Vector Machine)

Ⅰ. 개요​

1. 데이터 마이닝 기법의 분류와 대상 기법의 위치​

데이터 마이닝(Data Mining) 은 대용량 데이터에서 유용한 패턴과 규칙을 발견하는 과정이며, 학습 방식에 따라 비지도 학습(군집화) 과 지도 학습(분류·예측) 으로 구분된다.

 ┌───────────── **데이터 마이닝 기법 분류** ─────────────┐
 │                                                       │
 │ **[비지도 학습]** — 정답 레이블 없음                  │
 │   · **군집화(Clustering)**                            │
 │       ├─ 분할 기반 : **K-means**, K-medoids ①         │
 │       ├─ **밀도 기반 : DBSCAN**, OPTICS ②             │
 │       ├─ 계층 기반 : AGNES, DIANA                     │
 │       └─ 모델 기반 : GMM(EM 알고리즘)                 │
 │   · 연관규칙(Apriori), 차원축소(PCA)                  │
 │                                                       │
 │ **[지도 학습]** — 정답 레이블 존재                    │
 │   · **분류(Classification)**                          │
 │       ├─ **SVM** ③ ├─ 의사결정나무 ├─ 나이브베이즈    │
 │       └─ KNN, 신경망, 앙상블(RF, GBM)                 │
 │   · 회귀(Regression)                                  │
 └───────────────────────────────────────────────────────┘

2. 세 기법의 관계​

기법학습 유형핵심 아이디어해결 문제
K-means비지도(군집)중심(Centroid)까지의 거리 최소화데이터를 K개 그룹으로 분할
DBSCAN비지도(군집)밀도가 높은 영역을 연결임의 형태 군집 + 이상치 탐지
SVM지도(분류)마진(Margin)을 최대화하는 초평면두 클래스의 최적 경계 결정

Ⅱ. K-means Clustering​

1. 개념 및 원리​

K-means는 데이터를 사전에 지정한 K개의 군집으로 나누고, 각 군집의 중심(Centroid)과 소속 데이터 간 거리 제곱합(SSE)을 최소화하는 분할 기반(Partitioning) 군집 알고리즘이다.

   [**목적 함수**]
   **J = Σ(i=1..K) Σ(x ∈ Cᵢ) ‖x − μᵢ‖²**   → **최소화(SSE, 관성)**
        μᵢ : 군집 Cᵢ 의 중심(평균 벡터)

2. 수행 절차​

   [**K-means 알고리즘 (Lloyd's Algorithm)**]

   **① 초기화** : K개의 초기 중심점 무작위 선택
        │        (**K-means++** : 서로 멀리 떨어지도록 확률적 선택 → 권장)
        ▼
   **② 할당(Assignment)** : 각 데이터를 **가장 가까운 중심**의 군집에 배정
        │        d(x, μᵢ) = 유클리드 거리
        ▼
   **③ 갱신(Update)** : 각 군집에 속한 데이터의 **평균**으로 중심 재계산
        │
        ▼
   **④ 반복** : ②~③을 **중심 변화가 없을 때(수렴)** 까지 반복
        │        (또는 최대 반복 횟수 도달)
        ▼
   **⑤ 종료** : 최종 군집 결과 도출

   ※ **EM 알고리즘의 구조**(E-step = 할당, M-step = 갱신)와 동일
   ※ 시간 복잡도 : **O(n · K · d · i)** — 대용량 데이터에 유리

3. 최적 K 결정 방법​

방법내용
엘보우 기법(Elbow)K 증가에 따른 SSE 감소 곡선의 꺾이는 지점(팔꿈치) 선택
실루엣 계수(Silhouette)(b−a)/max(a,b) — 군집 내 응집도(a)와 군집 간 분리도(b) 비교, 1에 가까울수록 우수
Gap Statistic무작위 균등분포 대비 SSE 개선 정도 비교
도메인 지식업무적으로 의미 있는 세그먼트 수(예: 고객 등급 5단계)

4. 장단점​

구분내용
장점· 알고리즘 단순·직관적, 구현·해석 용이
· 계산 속도 빠름(O(n)) → 대용량 데이터에 적합, 병렬화 용이
· 중심점으로 군집의 대표값(프로파일) 해석 가능
단점· K를 사전에 지정해야 함
· 초기 중심점에 따라 결과가 달라짐(지역 최적해)
· 구형(Spherical)·유사 크기 군집만 잘 탐지 → 초승달·고리 형태 실패
· 이상치(Outlier)에 매우 민감(평균 사용) → 중심 왜곡
· 범주형 데이터 부적합(평균 정의 불가) → K-modes 사용
· 변수 스케일 차이에 민감 → 정규화 필수

Ⅲ. DBSCAN (밀도 기반 군집)​

1. 개념 및 원리​

DBSCAN은 "데이터가 조밀하게 모여 있는 영역을 하나의 군집으로 보고, 밀도가 낮은 영역의 점은 잡음(Noise)으로 분류" 하는 밀도 기반 군집 알고리즘이다. K 지정이 불필요하며 임의 형태의 군집과 이상치를 동시에 탐지한다.

2. 핵심 개념 및 파라미터​

구분내용
ε(Epsilon)이웃을 판단하는 반경(거리 임계값)
MinPtsε 반경 내에 있어야 하는 최소 데이터 개수
핵심점(Core Point)ε 반경 내 이웃 수 ≥ MinPts → 군집의 내부
경계점(Border Point)이웃 수 < MinPts 이지만 핵심점의 ε 반경 내에 존재 → 군집의 가장자리
잡음점(Noise Point)핵심점도 경계점도 아님 → 이상치(Outlier)로 분류
직접 밀도 도달핵심점 p의 ε 반경 내에 q가 있으면 q는 p로부터 직접 도달 가능
밀도 연결(Density-Connected)핵심점들의 연쇄로 연결된 점들 → 하나의 군집
   [**DBSCAN 개념도** (MinPts = 4)]

              ● ● ●               ○ : 경계점
            ● **⊕** ● ●            ⊕ : 핵심점(이웃≥4)
          ● ● **⊕** **⊕** ● ○      ✕ : 잡음점
            ○ ● **⊕** ●
              ● ●         ✕ ← **이상치(어느 군집에도 미포함)**

              ● ● ●
            ● **⊕** ● ○     ⇒ **밀도로 연결된 영역 = 군집**
              ● ●              **밀도가 끊긴 곳 = 군집 경계**

3. 수행 절차​

   **① 임의의 미방문 점 p 선택**
        ▼
   **② p의 ε-이웃 개수 확인**
        ├─ **≥ MinPts** → p는 **핵심점** → **새 군집 생성**
        │        ▼
        │   **③ 이웃점들을 군집에 추가**하고,
        │      각 이웃이 핵심점이면 **그 이웃의 이웃까지 확장(연쇄 확장)**
        │      → 더 이상 확장 불가할 때까지 반복
        └─ **< MinPts** → **일단 잡음으로 표시**
                (이후 다른 핵심점의 이웃이면 **경계점으로 전환**)
        ▼
   **④ 모든 점을 방문할 때까지 ①~③ 반복**

   ※ 시간 복잡도 : **O(n log n)**(공간 인덱스 사용 시) ~ O(n²)

4. 파라미터 결정 방법​

파라미터결정 방법
MinPts경험적으로 차원 수(d) + 1 이상, 일반적으로 2×d 권장. 노이즈 많으면 크게 설정
εK-거리 그래프(K-distance Plot) — 각 점의 K번째 최근접 이웃 거리를 정렬한 그래프에서 급격히 꺾이는 지점(Knee) 선택

5. 장단점​

구분내용
장점· 군집 개수 K 사전 지정 불필요(데이터가 스스로 결정)
· 임의 형태의 군집 탐지 가능(초승달·나선·고리형)
· 이상치를 자동으로 분리 → 이상탐지에 직접 활용
· 초기값에 따른 결과 변동 없음(결정론적, 경계점 제외)
단점· ε, MinPts 설정에 결과가 매우 민감
· 밀도가 다른 군집이 혼재하면 탐지 실패(전역 파라미터의 한계) → OPTICS·HDBSCAN으로 보완
· 고차원 데이터에서 성능 저하(차원의 저주 — 거리 개념 희석)
· 대용량 데이터에서 메모리·연산 부담(이웃 탐색)

Ⅳ. SVM (Support Vector Machine)​

1. 개념 및 원리​

SVM은 두 클래스를 분리하는 여러 초평면(Hyperplane) 중, 각 클래스의 가장 가까운 데이터(서포트 벡터)와의 거리(마진, Margin)를 최대화하는 최적 결정 경계를 찾는 지도 학습 기반 분류 알고리즘이다.

   [**최대 마진 분류기**]

        ○ ○                  ○ : 클래스 A
      ○ ○ ○ **○**  ← 서포트 벡터   ● : 클래스 B
      ─ ─ ─ ─ ─ ─ ─ ─ ─   ← **+1 경계(마진 경계)**
                ↕ **마진(Margin)**
      ━━━━━━━━━━━━━━━   ← **결정 초평면 (w·x + b = 0)**
                ↕
      ─ ─ ─ ─ ─ ─ ─ ─ ─   ← **−1 경계**
        **●** ● ●  ← 서포트 벡터
          ● ● ●

   **마진 = 2 / ‖w‖**  ⇒ **‖w‖를 최소화 = 마진 최대화**
   ⇒ **경계에 가장 가까운 소수의 점(서포트 벡터)만이 모델을 결정**

2. 수학적 정식화​

   [**Hard Margin SVM** — 완전 분리 가능한 경우]
   **min (1/2)‖w‖²**   s.t.  **yᵢ(w·xᵢ + b) ≥ 1**,  ∀i

   [**Soft Margin SVM** — 오분류 허용(현실적)]
   **min (1/2)‖w‖² + C·Σξᵢ**   s.t.  yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ,  ξᵢ ≥ 0
        **ξ(슬랙 변수)** : 마진 침범·오분류 허용량
        **C(비용 파라미터)** :
          · **C 크면** → 오분류 강하게 처벌 → **마진 좁음, 과적합 위험**
          · **C 작으면** → 오분류 관대 → **마진 넓음, 일반화 향상(과소적합 위험)**

   ⇒ **라그랑주 쌍대 문제(Dual)** 로 변환 → **볼록 2차 계획법(QP)**
   ⇒ **전역 최적해 보장**(지역 최적해 없음) ← SVM의 이론적 강점

3. 커널 트릭 (Kernel Trick)​

   [**비선형 문제의 해결**]

   1차원(선형 분리 불가)          2차원 사상 후(선형 분리 가능)
   ● ● ○ ○ ○ ● ●        ──▶       ○ ○ ○  ← 위쪽
   ─────────────           φ(x)     ─────── **초평면**
   (직선으로 못 나눔)               ● ●   ● ●  ← 아래쪽

   **핵심** : 고차원 사상 φ(x)를 **직접 계산하지 않고**,
              **내적만 커널 함수로 대체** → **연산량 폭증 회피**
              **K(xᵢ, xⱼ) = φ(xᵢ) · φ(xⱼ)**
커널수식특징
선형(Linear)K = xᵢ·xⱼ선형 분리 가능, 고차원 텍스트 분류에 효과적, 빠름
다항식(Polynomial)K = (γ xᵢ·xⱼ + r)^d차수 d로 곡률 조정
RBF(가우시안)K = exp(−γ‖xᵢ−xⱼ‖²)가장 범용적, 무한 차원 사상. γ 크면 과적합
시그모이드K = tanh(γ xᵢ·xⱼ + r)신경망 유사

4. 장단점​

구분내용
장점· 마진 최대화 → 일반화 성능 우수(과적합에 강함)
· 볼록 최적화 → 전역 최적해 보장(신경망과 대비되는 강점)
· 커널 트릭으로 비선형 문제 효과적 처리
· 고차원·소표본 데이터에 강함(유전자·텍스트 분류)
· 서포트 벡터만 저장 → 모델이 간결
단점· 대용량 데이터에서 학습 느림(O(n²)~O(n³))
· 커널·C·γ 등 하이퍼파라미터 튜닝 부담
· 결과 해석이 어려움(특히 커널 사용 시 블랙박스)
· 확률값을 직접 제공하지 않음(Platt Scaling 등 별도 보정 필요)
· 다중 클래스 분류는 간접 지원(OvO/OvR 조합)
· 변수 스케일링 필수

Ⅴ. 세 기법의 종합 비교​

비교 기준K-meansDBSCANSVM
학습 유형비지도(군집)비지도(군집)지도(분류/회귀)
핵심 원리중심까지 거리 최소화밀도 연결마진 최대화
사전 지정 파라미터K(군집 수)ε, MinPtsC, 커널, γ
탐지 가능 형태구형(볼록) 군집임의 형태(경계) 선형·비선형 모두

Ⅵ. 결론​

세 기법은 데이터 마이닝의 두 축(비지도 군집화와 지도 분류) 을 대표하며, "거리 기반(K-means) → 밀도 기반(DBSCAN) → 마진 기반(SVM)" 이라는 서로 다른 관점의 최적화 원리를 보여준다.

실무 선택 기준은 명확하다. ① 데이터가 대용량이고 대략적인 세그먼트 프로파일이 필요하면 K-means, ② 군집 형태가 불규칙하거나 이상치 탐지가 목적이면 DBSCAN, ③ 정답 레이블이 존재하고 고차원·소표본에서 높은 일반화 성능이 필요하면 SVM을 선택한다.

세 기법 모두 거리(Distance) 개념에 기반하므로 변수 스케일링(표준화·정규화)이 전처리의 필수 요건이라는 공통점이 있다. 스케일을 맞추지 않으면 값의 범위가 큰 변수가 거리 계산을 지배하여 결과가 왜곡된다. 또한 세 기법 모두 고차원에서는 거리 개념이 희석되는 차원의 저주에 노출되므로, PCA·오토인코더 등 차원 축소를 선행하는 것이 바람직하다(다만 SVM은 커널 방식 덕분에 상대적으로 고차원에 강건하다).

실무에서는 단일 기법 사용보다 조합 적용이 효과적이다. 예를 들어 DBSCAN으로 이상치를 먼저 제거한 뒤 K-means로 군집화하면 K-means의 이상치 민감성 문제를 보완할 수 있고, 군집화 결과를 레이블로 삼아 SVM 분류기를 학습시키면 신규 데이터의 실시간 분류가 가능해진다. 최근에는 HDBSCAN·딥러닝 기반 임베딩 군집화(Deep Clustering) 및 앙상블·부스팅 계열(XGBoost) 이 성능 면에서 우위를 보이고 있으나, 세 기법은 여전히 해석 가능성과 계산 효율 측면에서 강력한 기준선(Baseline) 으로서의 가치를 유지하고 있다.
