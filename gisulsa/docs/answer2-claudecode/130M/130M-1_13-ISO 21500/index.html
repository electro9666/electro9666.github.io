ISO 21500

문제​

13.ISO 21500 구성 모델

Ⅰ. 개요​

ISO 21500(Guidance on Project Management) 은 2012년 제정된 프로젝트 관리에 관한 국제 표준 지침으로, 조직의 규모·업종·프로젝트 유형에 관계없이 적용할 수 있는 범용 프로젝트 관리 개념과 프로세스를 제시한다. 인증 표준이 아닌 지침(Guidance) 이며, PMI의 PMBOK와 상호 정합적으로 설계되었다.

   [등장 배경]
   · 프로젝트 관리 체계가 **PMBOK(미), PRINCE2(영), IPMA(유럽)** 등으로 분산
   · **국가·기업 간 공통 언어(용어·프로세스) 부재** → 글로벌 협업 시 혼선
   · 국제 조달·다국적 프로젝트에서 **공통 기준 요구**
        ▼
   [**ISO 21500**] (2012 제정)
   · **PM의 국제 공통 언어** 제공 — 용어·개념·프로세스 표준화
   · **2021년 개정** : ISO 21500은 **"프로젝트·프로그램·포트폴리오 관리의
     핵심 개념(Context & Concepts)"** 으로 재정의되고,
     상세 프로세스는 **ISO 21502**(프로젝트 관리 실행 지침)로 이관

Ⅱ. ISO 21500의 구성 모델​

1. 전체 구조 (2012년판 — 프로세스 모델)​

 ┌──────────────── **ISO 21500 구성 체계** ────────────────┐
 │                                                         │
 │ **[1] 프로젝트 환경(Context)**                          │
 │     조직 전략 ─▶ 기회/위협 ─▶ **포트폴리오**            │
 │              ─▶ **프로그램** ─▶ **프로젝트** ─▶ 편익    │
 │     · 조직 외부/내부 환경, 거버넌스, 이해관계자          │
 │                          ▼                              │
 │ **[2] 프로세스 그룹(Process Group)** — **5개, 시간 흐름**│
 │   **착수 → 기획 → 이행 → 통제 → 종료**                  │
 │   (Initiating→Planning→Implementing→Controlling→Closing)│
 │                          ×                              │
 │ **[3] 주제 그룹(Subject Group)** — **10개, 관리 영역**   │
 │   통합·이해관계자·범위·자원·시간·원가·리스크·품질·조달·의사소통 │
 │                          ▼                              │
 │   **5 × 10 매트릭스 = 총 39개 프로세스**                 │
 └─────────────────────────────────────────────────────────┘

2. 프로세스 그룹 (5개)​

프로세스 그룹내용주요 산출물
착수(Initiating)프로젝트 공식 승인, 목표·범위 개괄 정의, PM 지정프로젝트 헌장, 이해관계자 등록부
기획(Planning)상세 계획 수립 — 범위·일정·원가·품질·리스크·조달·의사소통프로젝트 계획서, WBS, 일정·예산 기준선
이행(Implementing)계획에 따른 작업 수행, 팀 개발, 품질보증, 정보 배포인도물(Deliverables), 작업성과 데이터
통제(Controlling)계획 대비 실적 감시·측정, 변경 통제, 시정조치성과보고서, 변경요청·승인, EVM 지표
종료(Closing)인수·검수, 계약 종료, 교훈(Lessons Learned) 정리최종 보고서, 프로젝트 완료 확인서, 교훈 기록

3. 주제 그룹 (10개)​

주제 그룹관리 대상주요 프로세스 예시
통합(Integration)전체 조정·통합헌장 개발, 계획 개발, 프로젝트 작업 지휘, 변경 통제, 종료
이해관계자(Stakeholder)관련자 식별·관리이해관계자 식별, 이해관계자 관리
범위(Scope)무엇을 할 것인가범위 정의, WBS 작성, 활동 정의, 범위 통제
자원(Resource)인력·자재·설비팀 확보, 자원 산정, 조직 정의, 팀 개발, 자원 통제
시간(Time)일정활동 순서 배열, 기간 산정, 일정 개발·통제
원가(Cost)비용원가 산정, 예산 편성, 원가 통제(EVM)
리스크(Risk)불확실성리스크 식별, 평가, 대응, 통제
품질(Quality)인도물·프로세스 품질품질 기획, 품질보증(QA), 품질통제(QC)
조달(Procurement)외부 획득조달 기획, 공급자 선정, 조달 관리
의사소통(Communication)정보 흐름의사소통 기획, 정보 배포, 의사소통 관리

4. 프로세스 매트릭스 (5 × 10 = 39개)​

   [**주제 그룹 × 프로세스 그룹 매핑 (일부)**]

   ┌──────────┬────────┬────────────┬──────────┬──────────┬────────┐
   │ 주제\그룹 │ **착수** │  **기획**  │ **이행** │ **통제** │**종료**│
   ├──────────┼────────┼────────────┼──────────┼──────────┼────────┤
   │ **통합**  │ 헌장개발│ 계획개발    │ 작업지휘 │ 작업통제 │ 단계/  │
   │          │        │            │          │ **변경통제**│프로젝트│
   │          │        │            │          │          │ 종료   │
   ├──────────┼────────┼────────────┼──────────┼──────────┼────────┤
   │**이해관계자**│ 식별  │     -      │ 관리     │    -     │   -    │
   ├──────────┼────────┼────────────┼──────────┼──────────┼────────┤
   │ **범위**  │   -    │ 범위정의·  │    -     │ 범위통제 │   -    │
   │          │        │ **WBS**·활동정의│      │          │        │
   ├──────────┼────────┼────────────┼──────────┼──────────┼────────┤
   │ **시간**  │   -    │ 순서배열·  │    -     │ 일정통제 │   -    │
   │          │        │ 기간산정·일정개발│    │          │        │
   ├──────────┼────────┼────────────┼──────────┼──────────┼────────┤
   │ **원가**  │   -    │ 원가산정·  │    -     │ 원가통제 │   -    │
   │          │        │ 예산편성    │          │          │        │
   └──────────┴────────┴────────────┴──────────┴──────────┴────────┘
   ※ 각 프로세스는 **입력(Input) → 활동 → 출력(Output)** 형태로 기술

Ⅲ. ISO 21500과 PMBOK 비교​

구분ISO 21500PMBOK Guide
제정 기관ISO(국제표준화기구)PMI(미국 프로젝트관리협회)
성격국제 표준 지침(비인증)실무 지침서(PMP 자격 근거)
분량·상세도약 40페이지, 개괄적수백 페이지, 도구·기법 상세
구성5 프로세스 그룹 × 10 주제 그룹 = 39 프로세스(6판) 5 프로세스 그룹 × 10 지식영역 = 49 프로세스
(7판 : 12원칙 + 8 성과영역 중심으로 전환)
차이점도구·기법(ITTO) 미제시, 원칙 중심ITTO(입력-도구/기법-산출물) 상세 제시
관계상호 정합적(용어·구조 유사), ISO가 상위 개념 프레임 제공
ISO 21500 계열 표준내용
ISO 21500(2021 개정)프로젝트·프로그램·포트폴리오 관리의 핵심 개념 및 용어
ISO 21502프로젝트 관리 실행 지침(구 21500의 프로세스 내용 승계)
ISO 21503 / 21504프로그램 관리 / 포트폴리오 관리 지침
ISO 21505프로젝트·프로그램·포트폴리오 거버넌스
ISO 21508 / 21511EVM(획득가치관리) / WBS
ISO 10006프로젝트 품질경영 지침

Ⅳ. 특징 및 활용​

구분내용
장점· 국제 공통 언어 제공 → 다국적·다기업 협업 시 소통 비용 절감
· 간결한 구조(39 프로세스) → 조직 상황에 맞춘 테일러링 용이
· 특정 협회·국가에 종속되지 않는 중립성
· 타 ISO 표준(9001·31000·38500)과 용어·구조 정합
한계· 인증 표준이 아님 → 제3자 인증 불가
· 도구·기법 미제시 → 실행하려면 PMBOK·PRINCE2 등 병행 필요
· 애자일·하이브리드 방법론에 대한 구체적 지침 부족
· 개괄적 서술로 초보 조직이 곧바로 적용하기 어려움
활용· 조직 PM 방법론·표준 프로세스 수립의 기준 프레임
· 국제 입찰·계약에서의 PM 역량 기준 제시
· PMO 구축과 프로젝트 성숙도 평가(OPM3·CMMI)의 참조 모델
· PM 교육·용어 통일, 감리·품질보증 기준

Ⅴ. 결론​

ISO 21500의 구성 모델은 "시간의 흐름(5개 프로세스 그룹) × 관리의 대상(10개 주제 그룹)" 이라는 2차원 매트릭스로 프로젝트 관리를 체계화한 것이 핵심이다. 이 구조는 PM 활동을 언제 수행하는가와 무엇을 관리하는가의 두 축으로 명확히 분리함으로써, 프로젝트 관리 지식을 누락 없이 조망할 수 있게 한다.

ISO 21500의 실무적 가치는 상세한 방법론을 제공하는 데 있는 것이 아니라, 조직이 자신의 방법론을 설계할 때 참조할 중립적 기준 골격을 제공하는 데 있다. 따라서 실제 적용 시에는 ISO 21500/21502로 전체 프레임을 정의하고, 세부 도구·기법은 PMBOK(ITTO)이나 PRINCE2에서 차용하는 결합 방식이 효과적이다.

한편 최근 프로젝트 환경이 애자일·하이브리드로 급속히 전환되면서, 계획 중심의 프로세스 모델만으로는 대응에 한계가 있다. PMBOK 7판이 프로세스 중심에서 원칙·성과영역 중심으로 전환하고 ISO 21500이 2021년 개정에서 개념 표준으로 재정의된 것은 이러한 흐름을 반영한 것이다. 결국 기술사 관점에서는 ISO 21500의 39개 프로세스를 기계적으로 적용하기보다, 프로젝트 특성에 맞게 테일러링하고 애자일 실천법과 결합하는 판단력이 요구된다.
