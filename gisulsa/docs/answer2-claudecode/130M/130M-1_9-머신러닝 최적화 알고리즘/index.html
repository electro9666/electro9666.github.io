머신러닝 최적화 알고리즘

문제​

9.머신러닝 최적화 알고리즘(Optimization Algorithm) 유형 및 장단점

Ⅰ. 개요​

최적화 알고리즘(Optimization Algorithm) 은 머신러닝 모델의 손실 함수(Loss Function)를 최소화하는 파라미터(가중치 W, 편향 b) 를 찾아가는 학습(Training)의 핵심 엔진이다. 대부분 경사하강법(Gradient Descent) 을 기반으로, 기울기(∇L)의 반대 방향으로 파라미터를 반복 갱신한다.

   [**기본 원리 : 경사하강법**]

   **W ← W − η · ∇L(W)**      (η : 학습률 Learning Rate)

   손실 L
     │ ＼                          ┌─ **η 너무 크면** : 발산·진동
     │   ＼   ●                    ├─ **η 너무 작으면** : 학습 지연·지역최소 갇힘
     │     ＼_● ↘                  └─ ⇒ **학습률과 갱신 방향**이 최적화의 두 축
     │        ＼_●_↘_______
     └──────────────────── W
              **최소점**

   [해결해야 할 문제]
   ① **지역 최소값(Local Minima)·안장점(Saddle Point)** 탈출
   ② **학습률 설정의 어려움** (파라미터마다 적정값이 다름)
   ③ **진동(Oscillation)** — 협곡 형태 손실면에서 지그재그
   ④ **대용량 데이터**에서의 계산 비용

Ⅱ. 최적화 알고리즘의 유형​

 ┌───────────── **최적화 알고리즘 계보** ─────────────┐
 │                                                    │
 │  **[1] 데이터 사용량 기준**                        │
 │      **BGD** (전체) → **SGD** (1개) → **Mini-batch**│
 │                                                    │
 │  **[2] 갱신 방향(속도) 개선 계열**                 │
 │      SGD → **Momentum** → **NAG**                  │
 │                                                    │
 │  **[3] 학습률(Step Size) 개선 계열**               │
 │      SGD → **AdaGrad** → **RMSProp** → AdaDelta    │
 │                                                    │
 │  **[4] 방향 + 학습률 통합**                        │
 │      Momentum + RMSProp = **Adam**                 │
 │              → **AdamW, NAdam, RAdam, AdaMax**     │
 │                                                    │
 │  **[5] 2차 미분(곡률) 활용**                       │
 │      **Newton법 · 준뉴턴(BFGS, L-BFGS)**           │
 └────────────────────────────────────────────────────┘

1. 데이터 사용량 기준 분류​

유형원리장점단점
BGD
(Batch Gradient Descent)		전체 데이터로 기울기 1회 계산 후 갱신· 안정적 수렴, 기울기 정확
· 병렬 연산 유리		· 메모리 부담 큼, 갱신 느림
· 지역 최소값 탈출 어려움
· 온라인 학습 불가
SGD
(Stochastic GD)		샘플 1개마다 갱신· 갱신 매우 빠름
· 노이즈가 지역최소 탈출에 도움
· 온라인 학습 가능		· 진동 심함, 수렴 불안정
· 벡터 연산 이점 상실
Mini-batch GD일부 묶음(32~256개) 단위 갱신· 속도와 안정성의 절충
· GPU 병렬 처리 최적 → 실무 표준		· 배치 크기 튜닝 필요
· 여전히 학습률 민감

2. 갱신 방향(관성) 개선 계열​

알고리즘원리장점단점
Momentum이전 갱신 방향(속도 v)을 관성으로 누적
v ← γv − η∇L , W ← W + v		· 진동 감소, 수렴 가속
· 관성으로 지역최소·안장점 탈출		· 하이퍼파라미터 γ 추가
· 관성 과다 시 최소점 지나침(Overshoot)
NAG
(Nesterov Accelerated Gradient)		관성으로 미리 이동한 지점에서 기울기 계산(선견지명)· Momentum 대비 Overshoot 억제
· 더 정확한 방향 보정		· 구현 다소 복잡
· 여전히 학습률 수동 조정

3. 학습률(적응형) 개선 계열​

알고리즘원리장점단점
AdaGrad기울기 제곱 누적합(G) 으로 학습률을 나눔
W ← W − η/√(G+ε) · ∇L		· 파라미터별 학습률 자동 조정
· 희소(Sparse) 데이터에 강함(NLP, 추천)		· G가 단조 증가 → 학습률이 0으로 소멸
→ 학습 조기 중단
RMSProp누적합 대신 지수이동평균(EMA) 사용 → 오래된 기울기 감쇠· AdaGrad의 학습률 소멸 해결
· 비정상(Non-stationary)·RNN에 효과적		· 감쇠율 ρ 튜닝 필요
· 관성(방향) 개선은 없음
AdaDeltaRMSProp + 갱신량의 EMA로 학습률 자체 제거· 학습률 초기값 불필요· 수렴 속도가 느릴 수 있음

4. 통합형 (실무 표준)​

알고리즘원리장점단점
Adam
(Adaptive Moment Estimation)		Momentum(1차 모멘트 m) + RMSProp(2차 모멘트 v) 결합 + 편향 보정· 빠르고 안정적인 수렴
· 기본 하이퍼파라미터로도 우수(β₁=0.9, β₂=0.999)
· 사실상 딥러닝 기본값		· 일반화 성능이 SGD+Momentum보다 낮을 수 있음
· 특정 문제에서 수렴 실패 보고
· 메모리 2배(m, v 저장)
AdamWAdam의 가중치 감쇠(Weight Decay)를 기울기와 분리· 정규화 정상 동작 → 일반화 개선
· Transformer·LLM 학습 표준		· 감쇠 계수 추가 튜닝
NAdam / RAdam / AdaMaxAdam + Nesterov / 초기 분산 보정 / 무한 노름초기 학습 안정성 개선개선폭이 문제 의존적
LAMB / LARS레이어별 학습률 정규화초대형 배치(수만) 분산 학습 가능대규모 환경 전용

5. 2차 미분(곡률) 활용​

알고리즘원리장점단점
Newton–Raphson헤시안(2차 미분) 역행렬로 곡률 반영수렴 속도 매우 빠름(2차 수렴)O(n³) 연산·O(n²) 메모리 → 딥러닝 적용 불가
준뉴턴(BFGS/L-BFGS)헤시안을 근사(L-BFGS는 메모리 제한)소규모 파라미터에서 매우 효율적배치 전체 필요 → 대규모 딥러닝 부적합(전통 ML·로지스틱 회귀에 사용)

Ⅲ. 종합 비교​

알고리즘방향 개선학습률 적응수렴 속도일반화 성능주 활용
SGD✕✕느림우수이미지 분류(ResNet 등) 최종 성능
Momentum/NAG○✕보통우수CV 모델 표준 조합
AdaGrad✕○초기 빠름보통희소 데이터(NLP, 추천)
RMSProp✕○빠름보통RNN/시계열
Adam○○매우 빠름보통범용 기본값
AdamW○○매우 빠름우수Transformer·LLM
L-BFGS2차-매우 빠름우수소규모·볼록 문제

Ⅳ. 실무 적용 고려사항​

고려사항내용
① 기본 선택 전략Adam/AdamW로 빠르게 시작 → 성능 한계 시 SGD+Momentum으로 미세조정(Fine-tuning)
② 학습률 스케줄링Warm-up(초기 완만) + Cosine Annealing/Step Decay 병행 → 실제 성능 개선의 핵심 요소
③ 배치 크기와의 관계배치를 k배 키우면 학습률도 k배 또는 √k배 조정(Linear Scaling Rule)
④ 기울기 문제 대응Gradient Clipping(폭주 방지, RNN 필수), 배치 정규화·잔차 연결(소실 완화)
⑤ 정규화와의 결합Adam 사용 시 L2 정규화가 왜곡 → AdamW 사용 권장
⑥ 하이퍼파라미터 탐색Grid/Random Search보다 베이지안 최적화·Hyperband 가 효율적
⑦ 손실면 특성 고려볼록(Convex) 문제는 2차 기법, 비볼록 딥러닝은 1차 적응형 이 현실적

Ⅴ. 결론​

머신러닝 최적화 알고리즘의 발전은 "학습률을 어떻게 자동으로 정할 것인가" 와 "갱신 방향을 어떻게 안정화할 것인가" 라는 두 축의 개선 역사로 요약된다. 이 두 흐름이 Adam(Momentum + RMSProp) 에서 결합되어 오늘날 딥러닝의 기본값이 되었다.

다만 "Adam이 항상 최선"은 아니다. Adam은 수렴은 빠르지만 일반화 성능(Test Accuracy)에서는 SGD+Momentum이 우수한 경우가 많다는 것이 실증적으로 보고되어 있으며, 이는 Adam의 적응형 학습률이 날카로운 최소값(Sharp Minima) 에 수렴하는 경향 때문으로 해석된다. 따라서 연구·실험 단계에서는 Adam으로 빠르게 수렴시키고, 최종 성능이 중요한 프로덕션 모델에서는 SGD+Momentum으로 재학습·미세조정하는 것이 실무적 전략이다.

또한 최적화 알고리즘 선택 못지않게 학습률 스케줄링(Warm-up + Decay) 이 성능에 미치는 영향이 크다는 점을 인식해야 한다. 대규모 언어모델 학습에서 AdamW + Cosine Schedule + Gradient Clipping 조합이 표준으로 자리 잡은 것이 이를 방증한다. 결국 최적화는 단일 알고리즘의 선택 문제가 아니라, 알고리즘·학습률 정책·정규화·배치 구성을 아우르는 학습 설계의 문제로 접근해야 한다.
