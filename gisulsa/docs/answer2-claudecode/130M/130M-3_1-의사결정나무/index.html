의사결정나무

문제​

1.머신 러닝(Machine Learning)에서 활용되는 의사결정나무(Decision Tree) 모델을설명하시오

Ⅰ. 개요​

1. 의사결정나무의 개념​

의사결정나무(Decision Tree) 는 데이터를 특정 속성(Feature)의 조건에 따라 반복적으로 분할하여, 나무 구조의 규칙 집합으로 분류(Classification) 또는 예측(Regression)을 수행하는 지도 학습 알고리즘이다.

   [**의사결정나무의 구조**]

                 ┌─────────────────┐
                 │ **뿌리 노드**    │ ← 전체 데이터 (Root Node)
                 │ 소득 > 5,000만? │
                 └────┬───────┬────┘
                   Yes│       │No
              ┌───────▼──┐ ┌──▼────────┐
              │**내부 노드**│ │**내부 노드**│ ← 분기 조건 (Internal Node)
              │신용등급≥3? │ │ 근속 > 3년?│
              └──┬─────┬─┘ └─┬──────┬──┘
              Yes│     │No Yes│      │No
            ┌────▼┐ ┌──▼──┐ ┌▼───┐ ┌─▼────┐
            │**승인**│ │**거절**│ │**승인**│ │**거절**│ ← **잎 노드**(Leaf/Terminal)
            └─────┘ └─────┘ └────┘ └──────┘

   · **가지(Branch)** : 조건의 분기 · **깊이(Depth)** : 뿌리~잎까지의 레벨 수
   · **규칙 추출** : "소득 > 5,000만 AND 신용등급 ≥ 3 → **승인**"

2. 특징 및 위상​

구분내용
학습 유형지도 학습(Supervised Learning) — 분류·회귀 모두 가능
모델 형태비모수적(Non-parametric) — 데이터 분포 가정 불필요
탐색 방식재귀적 이진(다중) 분할(Recursive Partitioning) — 탐욕적(Greedy) 국소 최적 선택
최대 강점화이트박스 모델 — 의사결정 과정을 사람이 그대로 읽을 수 있음
위상단독 사용보다 앙상블(랜덤포레스트·GBM·XGBoost)의 기본 학습기(Base Learner) 로 널리 활용

Ⅱ. 의사결정나무의 학습 원리​

1. 학습 절차​

   [**의사결정나무 생성 절차**]

   **① 뿌리 노드에 전체 학습 데이터 배치**
        ▼
   **② 분리 기준(Splitting Criterion) 계산**
        · 모든 속성 × 모든 분할점에 대해 **불순도 감소량** 계산
        ▼
   **③ 최적 분리 속성·기준값 선택** (불순도를 가장 많이 낮추는 조건)
        ▼
   **④ 자식 노드로 데이터 분할**
        ▼
   **⑤ ②~④를 재귀 반복**
        ▼
   **⑥ 정지 규칙(Stopping Rule) 도달 시 잎 노드 확정**
        · 노드가 **순수**(모두 같은 클래스) · 최소 샘플 수 미달
        · 최대 깊이 도달 · 불순도 감소량이 임계값 미만
        ▼
   **⑦ 가지치기(Pruning)** — 과적합 방지를 위해 불필요한 가지 제거
        ▼
   **⑧ 최종 모델 확정** → 예측 시 뿌리부터 조건을 따라 잎에 도달

2. 분리 기준 (Splitting Criterion) — 핵심​

핵심 아이디어 : "분할 후 각 노드가 최대한 순수(homogeneous)해지도록" 속성을 선택한다.

가. 분류 문제의 불순도 척도​

척도수식특징
엔트로피(Entropy)E = − Σ pᵢ log₂ pᵢ정보이론 기반 무질서도. 순수 노드 = 0, 5:5 균등 = 1
정보 이득(Information Gain)IG = E(부모) − Σ (nⱼ/n)·E(자식)엔트로피 감소량. ID3/C4.5 사용. 값이 많은 속성 선호 편향
이득 비율(Gain Ratio)GR = IG / SplitInfoC4.5 — 속성 값이 많을수록 페널티 → IG의 편향 보정
지니 지수(Gini Index)G = 1 − Σ pᵢ²CART 사용. log 연산이 없어 계산 빠름, 실무 기본값
카이제곱(χ²)기대빈도 대비 관측빈도 차이CHAID — 통계적 유의성 기반 분할, 다지 분할
   [**엔트로피 · 지니 계산 예시**]  노드에 [○ 6개, ● 4개] (총 10개)

   **엔트로피** = −(0.6·log₂0.6) − (0.4·log₂0.4)
                = −(0.6 × −0.737) − (0.4 × −1.322) = **0.971**

   **지니 지수** = 1 − (0.6² + 0.4²) = 1 − (0.36 + 0.16) = **0.48**

   [**분할 후**]  A조건 → [○6, ●0] / [○0, ●4]
   자식 엔트로피 = (6/10)×0 + (4/10)×0 = **0**
   ⇒ **정보 이득 = 0.971 − 0 = 0.971 (최대)** → **완전 분리, 최적 분할**

   [**불순도 곡선**]
   불순도 ▲
    1.0 │      ╭─**엔트로피**─╮
        │    ╱               ╲
    0.5 │  ╱  ╭─**지니**─╮     ╲
        │ ╱  ╱          ╲     ╲
      0 └──────────────────────── p(클래스1)
        0        0.5           1.0
        └ **순수**    **최대 불순**    **순수** ┘

나. 회귀 문제의 분리 기준​

척도내용
분산 감소(Variance Reduction)분할 후 자식 노드들의 분산 가중합이 최소가 되도록 선택
SSE / MSE예측값(노드 평균)과 실제값의 오차 제곱합 최소화
예측값잎 노드에 속한 데이터의 평균값(회귀트리)

3. 가지치기 (Pruning) — 과적합 방지​

   [**과적합 문제**]
   나무를 끝까지 성장시키면 **모든 학습 데이터를 완벽히 분류**하지만,
   **잡음(Noise)까지 학습** → **새로운 데이터에 대한 성능 급락**

   정확도 ▲
        │        ╭──────── **학습 데이터**(계속 상승)
        │      ╱
        │    ╱  ╭──╮
        │  ╱  ╱     ╲──── **검증 데이터**(하락) ← **과적합 구간**
        │ ╱ ╱          
        └──────┬─────────────▶ 나무의 깊이/복잡도
             **최적점**
방식내용
사전 가지치기
(Pre-pruning, 조기 정지)		성장 중 미리 중단 — max_depth(최대 깊이), min_samples_split(분할 최소 샘플), min_samples_leaf, min_impurity_decrease
장점 : 빠름 / 단점 : 지평선 효과(더 성장하면 좋아질 분할을 놓침)
사후 가지치기
(Post-pruning)		끝까지 성장 후 불필요한 가지 제거 — 비용복잡도 가지치기(CCP): `R_α(T) = R(T) + α·
검증 기반교차 검증(K-Fold) 으로 최적 α·깊이 결정

Ⅲ. 주요 알고리즘 비교​

알고리즘개발분리 기준분할 형태대상특징
ID3Quinlan(1986)정보 이득다지 분할분류(범주형만)최초 모델. 값이 많은 속성 편향, 결측치·연속형 미지원
C4.5 / C5.0Quinlan(1993)이득 비율다지 분할분류ID3 개선 — 연속형·결측치 처리, 규칙 추출, 사후 가지치기
CARTBreiman(1984)지니 지수(분류)
분산 감소(회귀)		이진 분할만분류 + 회귀가장 널리 사용(scikit-learn 기본), 대리 분할(Surrogate)로 결측 처리
CHAIDKass(1980)카이제곱 검정다지 분할분류통계적 유의성 기반, 마케팅 세분화에 활용
QUESTLoh(1997)통계 검정(속성 선택과 분할점 분리)이진 분할분류속성 선택 편향 최소화, 속도 우수

Ⅳ. 장단점 및 보완 기법​

1. 장단점​

구분내용
장점· 해석 가능성이 매우 높음(화이트박스) — 규칙을 그대로 업무 규칙으로 전환 가능
· 전처리 부담 최소 — 정규화·표준화 불필요(거리 기반이 아님), 이상치에 상대적으로 강건
· 범주형·수치형 혼용 가능, 결측치 처리 지원(알고리즘별)
· 비선형 관계와 변수 간 상호작용 자동 포착
· 변수 중요도(Feature Importance) 산출 → 변수 선택에 활용
· 예측 속도 빠름(조건 비교만 수행), 규칙 시각화 용이
단점· 과적합(Overfitting)에 매우 취약 — 깊어질수록 심화
· 불안정성(High Variance) — 데이터가 조금만 바뀌어도 트리 구조가 크게 변함
· 탐욕적 알고리즘 — 각 단계의 국소 최적 선택 → 전역 최적 보장 안 됨
· 축에 평행한 경계(Axis-parallel) 만 생성 → 대각선 형태의 결정 경계 표현 비효율
· 클래스 불균형에 민감(다수 클래스 편향)
· 값의 종류가 많은 속성 선호 편향(IG 기준 시)
· 연속형 목표변수 예측 시 계단형 출력(정밀도 한계)
   [**축 평행 경계의 한계**]

   실제 경계(대각선)            의사결정나무의 근사
       ╲                        ┌─┐
     ○  ╲  ●                  ○ │ │└┐  ●
        ╲                       └┐│ │
     ○   ╲  ●                 ○  ││ └┐  ●
          ╲                      └┘   │
   ⇒ 단순한 대각선도 **계단 형태로 여러 번 분할**해야 근사 가능
   ⇒ 이 한계가 **앙상블(여러 트리 결합)** 이 효과적인 이유 중 하나

2. 한계 극복 — 앙상블 기법​

기법원리효과
배깅(Bagging)부트스트랩 표본으로 여러 트리를 학습 후 투표·평균분산 감소 → 불안정성 완화
랜덤 포레스트(Random Forest)배깅 + 분할 시 속성도 무작위 선택트리 간 상관성 제거 → 일반화 성능 크게 향상
부스팅(Boosting) — AdaBoost, GBM, XGBoost, LightGBM이전 트리의 오차를 다음 트리가 보정(순차 학습)편향 감소 → 최고 수준의 예측 성능(정형 데이터 SOTA)
XAI 결합SHAP·Feature Importance로 앙상블의 해석력 보완앙상블의 블랙박스화 문제 완화
비교단일 의사결정나무앙상블(RF/XGBoost)
예측 성능보통매우 우수
해석 가능성매우 높음낮음(SHAP 등 필요)
안정성낮음(고분산)높음
학습 속도빠름느림
적합 상황설명 책임이 중요(규제 산업), 규칙 도출예측 정확도가 최우선

Ⅴ. 활용 분야 및 실무 고려사항​

1. 활용 분야​

분야활용 사례
금융신용평가(대출 승인/거절), 카드 이상거래 탐지, 부도 예측 — 거절 사유 설명 의무 때문에 해석 가능성이 필수
의료진단 보조, 질병 위험군 분류, 임상 의사결정 지원(CDSS) — 의료진이 근거를 확인해야 함
마케팅고객 세분화, 이탈(Churn) 예측, 타겟 마케팅 반응 예측
제조불량 원인 분석, 설비 이상 진단, 품질 인자 도출
보안침입 탐지(IDS) 규칙 생성, 악성코드 분류, 스팸 필터
공공복지 대상 선별, 세무 조사 대상 선정 — 행정 처분의 근거 설명 필요

2. 실무 적용 시 고려사항​

고려사항내용
① 과적합 통제max_depth·min_samples_leaf 등 사전 가지치기 + CCP(사후 가지치기) 병행, 교차 검증으로 최적 복잡도 결정
② 클래스 불균형 대응class_weight='balanced', 오버샘플링(SMOTE)·언더샘플링, 평가지표를 정확도 대신 F1·AUC·재현율로 사용
③ 변수 중요도 해석 주의불순도 기반 중요도는 고유값이 많은 변수를 과대평가 → Permutation Importance·SHAP 병행 권장
④ 안정성 확보단일 트리의 불안정성 → 부트스트랩 재현성 확인, 중요 의사결정에는 앙상블 사용 후 대표 규칙 추출
⑤ 규칙의 업무 검증통계적으로 유의해도 업무적으로 무의미하거나 차별적인 규칙(예: 성별·지역 기반) 발생 가능 → 도메인 전문가 검토 및 공정성 검증 필수
⑥ 설명가능성 활용금융·의료·공공 등 규제 산업에서는 예측 정확도보다 설명 책임(Accountability) 이 우선 → 단일 트리 또는 트리 기반 규칙 추출이 유리
⑦ 개인정보보호법 대응자동화된 결정에 대한 설명요구권(제37조의2) 대응 시, 의사결정나무는 결정 근거 제시가 용이한 구조
⑧ 운영 관리(MLOps)데이터 분포 변화 시 트리 구조가 크게 변함 → 드리프트 모니터링과 주기적 재학습 필요

Ⅵ. 결론​

의사결정나무는 "데이터를 가장 순수하게 나누는 질문을 반복적으로 던진다" 는 단순한 원리로 작동하지만, 인간의 의사결정 방식과 가장 유사한 구조를 갖는다는 점에서 머신러닝 알고리즘 중 독보적인 위치를 차지한다. 학습 결과가 곧바로 읽을 수 있는 IF-THEN 규칙으로 표현되므로, 모델이 왜 그런 판단을 내렸는지 설명할 수 있는 유일한 수준의 직관성을 제공한다.

그러나 단일 의사결정나무는 과적합과 높은 분산(불안정성) 이라는 근본적 약점을 갖는다. 학습 데이터의 작은 변화에도 트리 구조가 완전히 달라질 수 있어 예측 신뢰성이 떨어지며, 축에 평행한 경계만 생성할 수 있어 복잡한 패턴 표현에 비효율적이다. 이 때문에 실무에서는 단일 트리보다 랜덤 포레스트·XGBoost 등 앙상블 형태로 사용하는 것이 표준이 되었으며, 특히 정형 데이터 예측에서는 딥러닝보다 트리 기반 앙상블이 여전히 우수한 성능을 보이는 경우가 많다.

여기서 발생하는 것이 "성능과 설명가능성의 Trade-off" 이다. 앙상블은 성능을 얻는 대신 의사결정나무의 최대 강점인 해석 가능성을 잃는다. 따라서 실무 선택 기준은 명확하다. ① 예측 정확도가 최우선이면 앙상블 + SHAP 등 XAI 보완, ② 설명 책임이 법적·윤리적으로 요구되면(금융 신용평가, 의료 진단, 공공 행정 처분) 단일 트리 또는 규칙 기반 모델을 선택하는 것이다.

특히 주목할 점은 2023년 개정 개인정보보호법의 자동화된 결정에 대한 설명요구권(제37조의2) 시행으로, 알고리즘의 판단 근거를 정보주체에게 설명해야 할 법적 의무가 생겼다는 것이다. 딥러닝 모델은 이 요구에 대응하기 근본적으로 어려운 반면, 의사결정나무는 결정 경로를 그대로 제시하는 것만으로 설명 의무를 충족할 수 있다. 이는 성능 경쟁에서 밀린 것처럼 보였던 의사결정나무가 규제 대응 관점에서 오히려 재평가받는 이유이며, 기술사 관점에서는 "가장 성능이 좋은 모델"이 아니라 "요구되는 설명 수준을 충족하면서 성능이 가장 좋은 모델"을 선택하는 판단이 요구된다.
