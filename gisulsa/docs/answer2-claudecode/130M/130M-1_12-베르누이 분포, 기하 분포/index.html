베르누이 분포, 기하 분포

문제​

12.베르누이 분포(Bernoulli distribution)와 기하 분포(Geometric Distribution

Ⅰ. 개요​

베르누이 분포와 기하 분포는 모두 성공/실패 두 가지 결과만 갖는 베르누이 시행(Bernoulli Trial) 을 기반으로 하는 이산확률분포이다. 베르누이 분포는 단 1회 시행의 결과를, 기하 분포는 첫 성공이 나올 때까지의 시행 횟수를 모형화한다.

   [**베르누이 시행의 3대 조건**]
   ① 각 시행의 결과는 **성공(1) 또는 실패(0)** 두 가지뿐
   ② 각 시행의 **성공 확률 p가 일정**
   ③ 각 시행은 **서로 독립**

   [**베르누이 시행에서 파생되는 분포 계보**]

                **베르누이 시행** (p)
                        │
      ┌─────────────┬───┴────┬──────────────┐
      ▼             ▼        ▼              ▼
   **베르누이**   **이항**  **기하**      **음이항**
   1회 시행     n회 중    **첫 성공까지** **r번째 성공까지**
   의 결과      성공 횟수   시행 횟수      시행 횟수
      │             │        │
      │      (n→∞, p→0)      │(연속형 대응)
      ▼             ▼        ▼
   특수형        **푸아송**  **지수 분포**

Ⅱ. 베르누이 분포 (Bernoulli Distribution)​

구분내용
정의단 한 번의 베르누이 시행에서 성공(1) 또는 실패(0)를 취하는 확률변수 X의 분포
확률질량함수(PMF)P(X = x) = p^x (1−p)^(1−x), x ∈ {0, 1}
즉 P(X=1) = p, P(X=0) = 1−p = q
모수(Parameter)p (0 ≤ p ≤ 1) — 성공 확률
기댓값(평균)E(X) = p
분산Var(X) = p(1−p) = pq
표기X ~ Bernoulli(p)
   [**베르누이 분포 형태 (p = 0.3)**]

   P(X)
   0.7 │  ███
       │  ███
   0.3 │  ███        ███
       │  ███        ███
       └───────────────────── X
          **0(실패)**   **1(성공)**

   [**분산의 특징**]
   Var = p(1−p) 는 **p = 0.5 에서 최대(0.25)**
   ⇒ **성공/실패가 반반일 때 불확실성이 가장 큼**
     (p=0 또는 1이면 결과가 확정 → 분산 0)
활용 사례내용
분류 문제로지스틱 회귀의 종속변수 분포 가정, 이진 분류의 우도(Likelihood)
품질 관리제품 1개의 양품/불량 판정
A/B 테스트사용자 1명의 전환(Conversion) 여부
시스템 운영요청 1건의 성공/실패, 패킷 1개의 전송 성공 여부
머신러닝베르누이 나이브베이즈(단어 출현 여부), 드롭아웃(뉴런 유지 여부)

Ⅲ. 기하 분포 (Geometric Distribution)​

구분내용
정의독립적인 베르누이 시행을 반복할 때, 첫 번째 성공이 나타날 때까지의 시행 횟수(또는 실패 횟수) 의 분포
정의 방식 ①
(시행 횟수 X, X = 1,2,3…)		P(X = k) = (1−p)^(k−1) · p
E(X) = 1/p, Var(X) = (1−p)/p²
정의 방식 ②
(첫 성공 전 실패 횟수 Y, Y = 0,1,2…)		P(Y = k) = (1−p)^k · p
E(Y) = (1−p)/p, Var(Y) = (1−p)/p²
모수p — 매 시행의 성공 확률
누적분포P(X ≤ k) = 1 − (1−p)^k (k번 이내 성공할 확률)
표기X ~ Geo(p)
   [**기하 분포 형태 (p = 0.3)** — 단조 감소]

   P(X=k)
   0.30 │ ███
   0.21 │ ███ ███
   0.15 │ ███ ███ ███
   0.10 │ ███ ███ ███ ███
   0.07 │ ███ ███ ███ ███ ███
        └───────────────────────── k(시행 횟수)
          1   2   3   4   5 ...

   ⇒ **k가 커질수록 확률 감소**(첫 시행에서 성공할 확률이 가장 큼)
   ⇒ 평균 **E(X) = 1/p = 1/0.3 ≒ 3.33회** 만에 첫 성공 기대

무기억성(Memoryless Property) — 기하 분포의 핵심 특징​

   **P(X > m + n | X > m) = P(X > n)**

   [의미] "**이미 m번 실패했다는 사실이, 앞으로의 성공 확률에 영향을 주지 않는다**"

   예) 당첨 확률 1%인 뽑기를 **100번 실패**했더라도,
       **101번째의 당첨 확률은 여전히 1%** (도박사의 오류 반박)

   ※ **이산형 분포 중 무기억성을 갖는 유일한 분포**가 기하 분포이며,
     연속형에서는 **지수 분포(Exponential)** 가 대응된다.
활용 사례내용
신뢰성 공학첫 고장까지의 시도 횟수, 부품 교체 주기 추정
네트워크패킷 재전송 횟수, CSMA/CD의 백오프 시도 횟수
보안무차별 대입(Brute-force) 공격의 평균 시도 횟수 산정
품질 관리첫 불량품이 나올 때까지 검사한 제품 수
마케팅·영업첫 계약 성사까지의 평균 접촉 횟수
알고리즘 분석라스베가스 알고리즘의 기대 반복 횟수

Ⅳ. 베르누이 분포 vs 기하 분포 비교​

비교 기준베르누이 분포기하 분포
확률변수의 의미1회 시행의 결과(성공=1/실패=0)첫 성공까지의 시행 횟수
시행 횟수고정 1회가변(성공할 때까지 반복)
확률변수 범위{0, 1}(유한){1, 2, 3, …}(무한)
PMFp^x(1−p)^(1−x)(1−p)^(k−1) · p
기댓값p1/p
분산p(1−p)(1−p)/p²
분포 형태두 개의 막대(이봉)단조 감소(우측 꼬리)
무기억성해당 없음(1회 시행)보유(핵심 특성)
관계기하 분포는 베르누이 시행의 반복으로 정의됨 ⇒ 베르누이가 기본 단위(Building Block)
대표 질문"이번 시도는 성공할까?""몇 번 만에 성공할까?"
관련 분포관계
이항 분포(Binomial)베르누이 시행 n회 중 성공 횟수 → 베르누이의 n회 합. B(1,p) = Bernoulli(p)
음이항 분포(Negative Binomial)r번째 성공까지의 시행 횟수 → 기하 분포의 일반화(r=1이면 기하 분포)
지수 분포(Exponential)기하 분포의 연속형 대응 — 첫 사건 발생까지의 시간, 무기억성 공유
푸아송 분포(Poisson)이항 분포에서 n→∞, p→0 (np=λ 고정) — 단위 시간당 사건 발생 횟수

Ⅴ. 결론​

베르누이 분포와 기하 분포는 동일한 베르누이 시행을 서로 다른 관점에서 바라본 분포이다. 베르누이는 "한 번의 시도가 성공인가" 라는 결과(Outcome) 에 주목하는 반면, 기하 분포는 "성공까지 몇 번이 필요한가" 라는 대기(Waiting) 에 주목한다. 따라서 베르누이는 모든 이산 확률 모형의 원자적 기본 단위이며, 이항·기하·음이항 분포는 모두 이로부터 파생된다.

실무 적용 관점에서 두 분포의 핵심 통찰은 다음과 같다. 첫째, 베르누이 분포의 분산 p(1−p)가 p=0.5에서 최대라는 성질은, 성공률이 50%에 가까운 이진 예측일수록 불확실성이 크다는 것을 의미하며, 이는 분류 모델의 신뢰도 해석과 A/B 테스트의 표본 크기 산정에 직접 활용된다.

둘째, 기하 분포의 무기억성은 실무에서 자주 오해되는 부분이다. "여러 번 실패했으니 이번엔 성공할 확률이 높다"는 도박사의 오류(Gambler's Fallacy) 는 수학적으로 성립하지 않으며, 반대로 평균 1/p회의 시도가 필요하다는 사실은 재전송 정책, 브루트포스 공격 대응(계정 잠금 임계값 설정), 영업 파이프라인 설계 등에서 정량적 기준을 제공한다. 다만 실제 시스템에서는 시행 간 독립성이나 확률 p의 불변 가정이 깨지는 경우가 많으므로(예: 재전송 시 혼잡 심화), 모형 적용 전 가정의 성립 여부를 반드시 검증해야 한다.
