IEEE 802.11bn (Wi-Fi 8)

Ⅰ. 개요​

IEEE 802.11bn은 Wi-Fi 7(802.11be)의 후속 표준으로 개발 중인 차세대 무선랜 규격이며, Wi-Fi 8로 명명될 예정이다. 최대 전송속도 경쟁에서 벗어나 UHR(Ultra High Reliability, 초고신뢰성) 을 핵심 목표로 삼는다는 점에서 이전 세대와 방향성이 근본적으로 다르다.

Ⅱ. 세대별 진화와 설계 목표​

   [Wi-Fi 세대 진화 — 목표의 전환]
   Wi-Fi 5(11ac)  : **속도** 향상(MU-MIMO, 80/160MHz)
   Wi-Fi 6(11ax)  : **효율** 향상(OFDMA, 밀집 환경 수용)
   Wi-Fi 6E       : 6GHz 대역 확장
   Wi-Fi 7(11be)  : **극한 처리량**(320MHz, 4K-QAM, **MLO**)
        ↓
   **Wi-Fi 8(11bn) : 「속도」가 아닌 「신뢰성·일관성」**
   → 최고 속도보다 **실제 환경에서 끊기지 않는 품질**을 지향
설계 목표(UHR)내용
지연 시간 안정화평균이 아닌 최악 지연(Tail Latency) 감소 — 실시간 응용 대응
처리량 일관성이동·간섭 상황에서도 성능 저하 최소화
패킷 손실 감소재전송 축소, 신뢰성 있는 전달
전력 효율IoT·웨어러블의 배터리 수명 개선

Ⅲ. 주요 기술 요소 및 활용​

기술 요소내용
MLO 고도화(Multi-Link Operation)2.4/5/6GHz 다중 대역 동시 사용을 강화하여 간섭 회피·끊김 없는 전환
협력 통신(Coordinated AP)인접 AP 간 협력 스케줄링·빔포밍·전송 조율(Co-SR, Co-BF, Joint Tx) → 밀집 환경 간섭 완화
끊김 없는 로밍AP 간 이동 시 세션 유지(Seamless Roaming)
향상된 링크 적응채널 상태에 따른 동적 변조·전력 제어, 이동성 대응
저전력향상된 절전 모드(TWT 확장)
호환성기존 Wi-Fi 6/7과 하위 호환, 6GHz 대역 활용
활용 분야내용
XR·메타버스저지연·일관된 대역폭 필요(VR 멀미 방지)
산업용 무선(Industrial IoT)유선 대체 수준의 신뢰성 요구, 스마트 팩토리 제어
고밀도 환경경기장·공항·오피스의 다수 동시 접속
실시간 서비스클라우드 게이밍, 원격 협업, 자율이동로봇(AMR)

Ⅳ. 결론​

IEEE 802.11bn(Wi-Fi 8)은 "얼마나 빠른가"에서 "얼마나 안정적인가"로 무선랜의 경쟁 축을 이동시킨 표준으로, 특히 산업용 무선과 XR처럼 지연 편차를 허용하지 않는 응용에서 의미가 크다. 다만 표준화가 진행 중(2028년경 완료 예상)이므로, 현 시점에서는 Wi-Fi 7의 MLO 활용과 AP 밀도·채널 설계 최적화로 신뢰성을 확보하고, 향후 도입 시 협력 AP 기능을 지원하는 인프라 구성을 고려하는 것이 실무적 접근이다.
