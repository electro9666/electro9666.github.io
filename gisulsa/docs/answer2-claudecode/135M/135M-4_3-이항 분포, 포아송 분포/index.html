이항 분포(Binomial Distribution)와 포아송 분포(Poisson Distribution)

Ⅰ. 개요​

이항 분포와 포아송 분포는 대표적인 이산확률분포로, 특정 사건의 발생 횟수를 모형화한다. 이항 분포는 정해진 횟수의 시행에서 성공 횟수를, 포아송 분포는 일정한 단위(시간·공간)에서 발생하는 사건 횟수를 다룬다는 점에서 구별된다.

   [분포 선택의 출발점]
   "**시행 횟수 n이 정해져 있는가?**"
        ├─ 예 → **이항 분포** (예: 100개 검사 중 불량품 수)
        └─ 아니오 → **포아송 분포** (예: 1시간 동안 발생한 장애 건수)

Ⅱ. 이항 분포(Binomial Distribution)​

1. 개념​

동일한 조건에서 독립적으로 n번 시행할 때, 성공이 나타나는 횟수 X의 분포이다. 각 시행은 성공/실패 두 가지 결과만 갖는 베르누이 시행(Bernoulli Trial) 이다.

   **X ~ B(n, p)**

   [성립 조건 — BINS]
   ① **Binary**      : 각 시행의 결과가 **성공/실패 두 가지**
   ② **Independent** : 각 시행이 **서로 독립**
   ③ **Number fixed**: **시행 횟수 n이 고정**
   ④ **Same p**      : 매 시행의 **성공 확률 p가 일정**

   [확률질량함수(PMF)]
       **P(X = k) = ₙCₖ · pᵏ · (1−p)^(n−k)**,   k = 0, 1, 2, …, n

   [기댓값·분산]
       **E(X) = np**,   **Var(X) = np(1−p)**

2. 예시​

문제: 불량률 5%인 공정에서 제품 20개를 검사할 때, 불량품이 정확히 2개일 확률은?

X ~ B(20, 0.05) P(X = 2) = ₂₀C₂ × 0.05² × 0.95¹⁸ = 190 × 0.0025 × 0.3972 ≈ 0.1887 (약 18.9%) E(X) = 20 × 0.05 = 1개, Var(X) = 20 × 0.05 × 0.95 = 0.95

Ⅲ. 포아송 분포(Poisson Distribution)​

1. 개념​

단위 시간·단위 공간에서 어떤 사건이 발생하는 횟수의 분포로, 발생 확률은 매우 낮으나 시행 기회가 매우 많은 희귀 사건(Rare Event) 을 모형화한다.

   **X ~ Poisson(λ)**   (λ = 단위당 평균 발생 횟수)

   [성립 조건]
   ① 사건은 **독립적으로 발생**
   ② 단위 구간당 **평균 발생률 λ가 일정**
   ③ 극히 짧은 구간에서 **두 사건이 동시에 발생하지 않음**
   ④ **시행 횟수 n의 개념이 없음**(발생 횟수만 관찰)

   [확률질량함수(PMF)]
       **P(X = k) = (e^(−λ) · λᵏ) / k!**,   k = 0, 1, 2, …

   [기댓값·분산]
       **E(X) = Var(X) = λ**   ← **평균과 분산이 같다는 것이 핵심 특징**

2. 예시​

문제: 어떤 서버에 시간당 평균 3건의 장애가 발생할 때, 1시간에 장애가 5건 발생할 확률은?

X ~ Poisson(3) P(X = 5) = (e⁻³ × 3⁵) / 5! = (0.0498 × 243) / 120 ≈ 0.1008 (약 10.1%) E(X) = Var(X) = 3건

Ⅳ. 두 분포의 비교​

1. 종합 비교표​

비교 기준이항 분포 B(n, p)포아송 분포 Poisson(λ)
관심 대상n번 시행 중 성공 횟수단위 구간당 사건 발생 횟수
모수(Parameter)n(시행 횟수), p(성공 확률) — 2개λ(평균 발생률) — 1개
시행 횟수고정(유한, n)정해지지 않음(무한 시행 개념)
확률변수 범위0 ≤ X ≤ n (유한)X = 0, 1, 2, … (무한)
확률질량함수ₙCₖ pᵏ(1−p)^(n−k)e^(−λ)λᵏ / k!
기댓값E(X) = npE(X) = λ
분산Var(X) = np(1−p)Var(X) = λ
평균과 분산 관계Var < E (항상 np(1−p) < np)Var = E (동일)
실패 개념존재(성공/실패 명확)없음(발생 횟수만 관찰)
적용 예시20개 검사 중 불량품 수, 10회 시도 중 성공 횟수, 설문 응답률시간당 접속 요청 수, 하루 장애 건수, 페이지당 오탈자 수

2. 두 분포의 관계 — 포아송 근사(Poisson Approximation)​

   [이항 분포 → 포아송 분포 근사]
   **n이 매우 크고(n ≥ 100), p가 매우 작으며(p ≤ 0.01), np = λ가 적당할 때**
        **B(n, p) ≈ Poisson(λ = np)**

   [근사의 의미]
   n이 커지면 ₙCₖ 계산이 매우 복잡해짐
   → 포아송 분포로 **계산을 대폭 단순화**
   → **"희귀 사건의 법칙(Law of Rare Events)"**

   [예시] 불량률 0.1%인 제품 1,000개 중 불량품 수
        정확 : B(1000, 0.001) → 계산 복잡
        근사 : Poisson(λ = 1000 × 0.001 = 1) → 간편하고 오차 매우 작음
   [분포 간 관계도]
   **베르누이 분포** ──(n회 반복)──► **이항 분포**
                                          │ n→∞, p→0, np=λ 고정
                                          ▼
                                    **포아송 분포**
                                          │ λ가 클 때(λ ≥ 20)
                                          ▼
                                     **정규 분포**(연속)
   ※ 이항 분포도 n이 크고 p가 0.5에 가까우면 **정규 근사** 가능 (중심극한정리)
   ※ 포아송 사건의 **발생 간격**은 **지수 분포**를 따름

3. 분포 선택 판단 흐름​

   시작
     │
   "시행 횟수가 명확히 정해져 있는가?"
     ├─ **예** → 각 시행이 독립이고 성공확률이 일정한가?
     │            ├─ 예 → **이항 분포**
     │            └─ 아니오(비복원 추출) → 초기하 분포
     │
     └─ **아니오** → "단위 시간·공간당 발생 횟수인가?"
                      ├─ 예, 평균 발생률 λ 일정 → **포아송 분포**
                      └─ 첫 성공까지의 시행 횟수 → 기하 분포

Ⅴ. IT 분야 활용​

분포IT 활용 사례
이항 분포· A/B 테스트의 전환율 검정(n명 중 전환 k명)
· 소프트웨어 테스트 — n개 케이스 중 실패 건수
· 패킷 전송 성공률, 신뢰성 평가(n개 부품 중 정상 작동 수)
· 설문·클릭률(CTR) 분석
포아송 분포· 서버 요청 도착률 모델링 → 대기행렬이론(M/M/1)의 기본 가정
· 단위 시간당 장애·오류 발생 건수 예측 → 용량 산정·SLA 설계
· 네트워크 패킷 도착·손실 건수
· 소프트웨어 결함 밀도(KLOC당 결함 수), 이상 탐지의 기준선 설정

Ⅵ. 결론​

이항 분포와 포아송 분포는 모두 이산 사건의 발생을 다루지만, "시행 횟수 n이 고정되어 있는가" 라는 기준으로 명확히 구분된다. 이항 분포는 유한한 시행에서의 성공 횟수를, 포아송 분포는 단위 구간에서의 발생 횟수를 모형화하며, 특히 포아송 분포의 평균과 분산이 같다(E = Var = λ) 는 성질은 실무에서 분포 적합성을 판단하는 유용한 기준이 된다.

두 분포는 독립적이지 않고 n이 크고 p가 작을 때 이항 분포가 포아송 분포로 수렴하는 관계에 있어, 계산이 복잡한 상황에서 포아송 근사를 통해 실용적으로 처리할 수 있다.

IT 실무에서는 A/B 테스트·품질 검사에는 이항 분포를, 트래픽 도착률·장애 발생률 분석에는 포아송 분포를 적용하며, 특히 포아송 분포는 대기행렬이론과 용량 산정의 기본 가정이 되므로 시스템 성능 설계에서 중요한 의미를 갖는다. 다만 실제 데이터는 과대산포(Overdispersion, Var > E) 를 보이는 경우가 많으므로, 적합성 검정을 거쳐 음이항 분포 등 대안 검토가 필요하다.
