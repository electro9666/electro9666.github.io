VAE(Variational AutoEncoder, 변분 오토인코더)

Ⅰ. 개요​

VAE는 오토인코더 구조에 확률적 잠재변수(Latent Variable)와 변분추론(Variational Inference) 을 결합한 생성 모델(Generative Model) 이다. 입력을 잠재공간의 하나의 점이 아닌 확률분포(평균 μ, 분산 σ²)로 인코딩함으로써, 잠재공간에서 샘플링하여 새로운 데이터를 생성할 수 있다.

Ⅱ. 구조 및 동작 원리​

   입력 x                                                  복원 x̂
     │                                                        ▲
   ┌─▼──────────┐    **μ**, **σ**    ┌──────────┐      ┌──────┴─────┐
   │ **인코더**  │ ─────────────────► │ 잠재공간 │ ───► │ **디코더**  │
   │ q(z|x)     │                    │  **z**    │      │ p(x|z)     │
   └────────────┘                    └────▲─────┘      └────────────┘
                                          │
                     **재파라미터화 트릭(Reparameterization Trick)**
                          **z = μ + σ ⊙ ε**,  ε ~ N(0, I)
                     → 샘플링을 결정적 연산으로 분리하여 **역전파 가능**

   [손실 함수]
   **L = 재구성 오차(Reconstruction Loss) + KL 발산(KL Divergence)**
        ▲ 원본과 유사하게 복원        ▲ q(z|x)를 표준정규분포 N(0,I)에 근접시켜
                                        **잠재공간을 연속적·규칙적으로 정렬**
   ※ ELBO(Evidence Lower Bound)를 최대화하는 것과 동일

Ⅳ. 결론​

VAE는 확률적 잠재공간을 통해 생성 능력과 해석 가능성을 동시에 확보한 모델로, 생성 품질은 GAN·확산모델에 미치지 못하지만 학습 안정성과 구조화된 잠재공간이라는 고유 강점을 갖는다. 이에 따라 순수 이미지 생성보다는 이상 탐지, 표현 학습, 그리고 확산모델의 잠재공간 인코더로서 실무적 가치가 크며, 재파라미터화 트릭은 확률적 모델을 역전파로 학습 가능하게 만든 핵심 기법으로 이후 생성 모델 전반에 영향을 미쳤다.
