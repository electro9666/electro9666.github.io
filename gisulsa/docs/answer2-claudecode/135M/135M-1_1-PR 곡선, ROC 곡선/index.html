PR(Precision-Recall) 곡선과 ROC 곡선 비교

Ⅰ. 개요​

ROC 곡선과 PR 곡선은 분류 모델의 임계값(Threshold)을 연속적으로 변화시키며 성능을 시각화하는 평가 도구이다. 단일 임계값에서의 정확도·F1과 달리, 모든 임계값에 걸친 모델의 판별력을 종합 평가할 수 있다.

Ⅱ. 두 곡선의 구조​

   [ROC 곡선]                          [PR 곡선]
   TPR │        ╱‾‾‾‾‾‾ 우수      Precision │‾‾‾╲       우수
 (재현율)│    ╱                            │      ╲
       │  ╱  ╱ ← 무작위(대각선)            │       ╲___
       │╱ ╱                                │           ╲___
       └──────────────► FPR                └──────────────► Recall
   x축 : **FPR = FP/(FP+TN)**          x축 : **재현율 = TP/(TP+FN)**
   y축 : **TPR = TP/(TP+FN)**          y축 : **정밀도 = TP/(TP+FP)**
   → 좌상단(0,1)에 가까울수록 우수     → 우상단(1,1)에 가까울수록 우수
   면적 = **AUC-ROC** (무작위 = 0.5)   면적 = **AUC-PR** (기준선 = 양성 비율)

Ⅲ. 비교​

비교 기준ROC 곡선PR 곡선
축 구성FPR vs TPR재현율 vs 정밀도
TN 반영반영함(FPR 계산에 사용)반영하지 않음
관심 클래스양성·음성 모두양성 클래스에 집중
클래스 불균형영향에 둔감 → 음성이 많으면 성능을 과대평가민감하게 반영 → 실질 성능 파악에 유리
기준선(Baseline)0.5(대각선, 고정)양성 비율(데이터에 따라 변동)
적합 상황클래스가 균형을 이룰 때, 양·음성이 동등하게 중요할 때불균형이 심할 때(사기 탐지·질병 진단·이상 탐지)
해석임의의 양성이 임의의 음성보다 높은 점수를 받을 확률양성 예측의 신뢰도와 탐지율의 균형

핵심: 양성 1%·음성 99%인 데이터에서 FP가 크게 늘어도 FPR의 분모(TN)가 매우 커서 변화가 미미하므로 ROC는 여전히 높게 나온다. 반면 PR 곡선은 정밀도가 즉시 하락하여 실제 문제를 드러낸다.

Ⅳ. 결론​

두 곡선은 대체 관계가 아니라 관점이 다른 상호 보완 도구이다. 클래스가 균형적이면 ROC-AUC로 전반적 판별력을 평가하고, 불균형이 심하거나 양성 탐지가 목적이면 반드시 PR 곡선(AUC-PR) 을 함께 확인해야 한다. 아울러 곡선은 임계값 선택의 근거이기도 하므로, FP와 FN의 비용 구조에 따라 운영 임계값을 결정하는 데 활용하는 것이 실무적으로 중요하다.
