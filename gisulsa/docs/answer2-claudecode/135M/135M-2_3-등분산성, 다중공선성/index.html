회귀모형의 등분산성(Homoscedasticity)과 다중공선성(Multicollinearity)

Ⅰ. 개요​

1. 회귀모형의 기본 가정​

선형회귀분석의 추정량이 BLUE(Best Linear Unbiased Estimator, 최적선형불편추정량) 가 되기 위해서는 가우스-마르코프 가정이 충족되어야 한다.

   [선형회귀 4대 가정]
   ① **선형성(Linearity)**        : 독립변수와 종속변수가 선형 관계
   ② **독립성(Independence)**     : 오차항 간 자기상관 없음
   ③ **등분산성(Homoscedasticity)**: 오차의 분산이 일정  ← **본 문제**
   ④ **정규성(Normality)**        : 오차가 정규분포를 따름
   + 다중회귀의 추가 요건 : **독립변수 간 다중공선성이 없을 것**  ← **본 문제**

두 개념 모두 가정 위반 시 회귀계수의 신뢰성과 통계적 검정 결과를 훼손한다는 공통점이 있으나, 등분산성은 오차항(잔차)의 문제, 다중공선성은 독립변수 간 관계의 문제라는 점에서 성격이 다르다.

Ⅱ. 등분산성(Homoscedasticity)​

1. 개념​

등분산성은 독립변수의 모든 값에 대하여 오차항(잔차)의 분산이 일정하게 유지되는 성질이다. 즉 Var(εᵢ) = σ² (상수)를 만족해야 한다. 이 가정이 깨진 상태를 이분산성(Heteroscedasticity) 이라 한다.

2. 등분산과 이분산의 형태​

   [등분산 — 정상]                    [이분산 — 위반]
   잔차 │                             잔차 │              ·
        │  ·  ·   ·  ·  ·                  │          ·      ·
      0 ├──·──·──·──·──·──              0 ├─·─·──·───·────·──
        │ ·   ·  ·   ·  ·                  │ ·  ·      ·
        │                                  │              ·      ·
        └──────────────► 예측값             └──────────────► 예측값
   잔차가 **띠(Band) 형태**로 균일       예측값 증가에 따라 **퍼짐(부채꼴)**
                                         → 대표적 이분산 패턴

3. 이분산성의 원인과 영향​

구분내용
발생 원인① 종속변수의 크기에 비례하여 변동이 커지는 데이터(소득-소비, 매출-비용)
② 이상치(Outlier) 존재
③ 중요한 변수 누락(모형 설정 오류)
④ 척도·단위 문제, 횡단면 데이터의 이질적 집단 혼재
영향① 회귀계수 추정치 자체는 여전히 불편(Unbiased) 하지만
② 표준오차가 왜곡 → t검정·F검정·신뢰구간이 부정확
③ 유의하지 않은 변수를 유의하다고 오판(1종 오류 증가)
④ 추정량이 더 이상 최소분산이 아님(BLUE 상실 — 비효율적)

4. 진단 방법​

방법내용
시각적 진단잔차 산점도(예측값 vs 잔차) — 부채꼴·나팔 모양 확인, Scale-Location Plot
Breusch-Pagan 검정잔차 제곱을 독립변수에 회귀 → H₀: 등분산 기각 시 이분산
White 검정함수 형태를 특정하지 않는 일반적 검정(제곱항·교차항 포함)
Goldfeld-Quandt 검정데이터를 두 그룹으로 나눠 분산 비율 검정

5. 해결 방안​

방안내용
변수 변환종속변수에 로그(log)·제곱근 변환 적용 → 분산 안정화(가장 일반적)
가중최소제곱법(WLS)분산이 큰 관측치에 작은 가중치 부여하여 추정
강건 표준오차(Robust SE)White의 이분산 일치 표준오차(HC) 사용 — 계수는 그대로 두고 표준오차만 보정(실무에서 가장 널리 사용)
모형 재설정누락 변수 추가, 이상치 처리, 비선형 항 추가

Ⅲ. 다중공선성(Multicollinearity)​

1. 개념​

다중공선성은 다중회귀모형에서 독립변수들 간에 강한 선형 상관관계가 존재하는 현상이다. 독립변수가 서로 독립적이어야 각 변수의 고유한 영향력을 분리할 수 있는데, 이들이 함께 움직이면 개별 기여도를 구분할 수 없게 된다.

   [정상]                            [다중공선성]
   Y ← X₁ (독립)                     Y ← X₁ ⇄ X₂ (X₁과 X₂가 강한 상관)
   Y ← X₂ (독립)                          │
   → 각 변수의 영향 분리 가능              └─► "매출 증가가 X₁ 때문인지
                                                X₂ 때문인지 구분 불가"

   예) 독립변수에 **키(cm)와 키(inch)**, 또는 **총소득과 가처분소득**을 함께 투입

2. 원인과 영향​

구분내용
발생 원인① 본질적으로 유사한 변수 동시 투입(총자산·순자산)
② 파생변수와 원변수를 함께 사용(가격, 수량, 매출액)
③ 더미변수 함정(Dummy Variable Trap — 모든 범주를 더미로 투입)
④ 표본 수 대비 변수 수 과다, 데이터 수집 범위 협소
영향① 회귀계수의 분산이 급격히 증가 → 추정치 불안정
② 표준오차 증가 → t값 감소 → 개별 변수가 유의하지 않게 나옴
③ F검정은 유의한데 개별 t검정은 모두 유의하지 않은 모순 발생
④ 계수의 부호가 이론과 반대로 나타남(해석 불가)
⑤ 데이터가 조금만 바뀌어도 계수가 크게 변동
⑥ 단, 예측(Prediction) 목적에는 큰 영향이 없음 — 해석의 문제

3. 진단 방법​

방법판단 기준
상관계수 행렬독립변수 간 상관계수 **
VIF(분산팽창인자)
VIF = 1 / (1 − Rᵢ²)		VIF ≥ 5: 다중공선성 존재 의심
VIF ≥ 10: 심각한 다중공선성(일반적 기준)
※ Rᵢ² = 해당 변수를 나머지 독립변수로 회귀했을 때의 결정계수
공차 한계(Tolerance)1/VIF, 0.1 미만이면 문제
상태지수(Condition Index)30 이상이면 심각
증상 관찰모형 R²는 높은데 개별 계수가 모두 비유의, 부호 이상

4. 해결 방안​

방안내용
변수 제거상관이 높은 변수 중 이론적 중요도가 낮거나 VIF가 큰 변수 제거(가장 단순)
변수 결합·파생유사 변수를 합산·평균하여 하나의 지표로 통합(예: 총소득 = 근로+사업소득)
주성분분석(PCA)상관된 변수들을 서로 직교하는 주성분으로 변환 후 회귀 → 다중공선성 원천 제거(단, 해석력 저하)
정규화 회귀
(Regularization)		릿지 회귀(Ridge) — L2 penalty로 계수를 축소하여 분산 감소(약간의 편의를 감수하고 안정성 확보)
라쏘(Lasso) — L1 penalty로 불필요 변수 계수를 0으로 만들어 자동 선택
표본 확대데이터 추가 수집으로 변수 간 변동 확보
중심화(Centering)교호작용항·다항항 사용 시 평균 차감으로 구조적 공선성 완화
더미변수 조정k개 범주는 k−1개 더미만 투입(더미 함정 회피)

Ⅳ. 등분산성과 다중공선성 비교​

비교 기준등분산성(위반 = 이분산성)다중공선성
대상오차항(잔차) 의 분산독립변수 간 상관관계
가정 위치가우스-마르코프 기본 가정다중회귀의 추가 요건
위반 시 계수 추정치불편성 유지(치우침 없음)불편성 유지(단, 분산 급증)
주된 문제표준오차 왜곡 → 검정 부정확계수 불안정·해석 불가
증상잔차 산점도의 부채꼴 패턴R² 높으나 개별 t값 비유의, 부호 이상
진단 지표잔차 플롯, Breusch-Pagan·White 검정VIF(≥10), 공차한계, 상관행렬
대표 해결책로그 변환, WLS, 강건 표준오차변수 제거·결합, PCA, 릿지 회귀
예측에 미치는 영향영향 있음(신뢰구간 부정확)예측은 양호, 해석이 문제

Ⅴ. 결론​

등분산성과 다중공선성은 모두 회귀계수 자체는 불편하게 유지되지만 그 신뢰성과 해석 가능성을 훼손한다는 공통점이 있다. 다만 이분산성은 검정 결과(표준오차)를 왜곡하고, 다중공선성은 계수의 안정성과 해석을 파괴한다는 점에서 문제의 성격이 다르다.

실무적으로는 ① 회귀분석 수행 후 반드시 잔차 진단(플롯 + Breusch-Pagan)과 VIF 확인을 정형 절차로 포함하고, ② 이분산 발견 시 로그 변환 또는 강건 표준오차를 적용하며, ③ 다중공선성 발견 시 분석 목적에 따라 대응을 달리해야 한다.

특히 중요한 판단 기준은 분석 목적이다. 해석(설명)이 목적이면 다중공선성을 반드시 해소해야 하지만, 예측이 목적이라면 다중공선성 자체는 큰 문제가 아니며 릿지 회귀 등으로 안정성만 확보하면 충분하다. 이처럼 가정 위반에 대한 대응은 기계적 적용이 아니라 분석 목적과 데이터 특성에 근거한 판단이 되어야 한다.
