데이터 거래를 위한 데이터 가치평가

Ⅰ. 개요​

1. 배경​

데이터 산업진흥 및 이용촉진에 관한 기본법(데이터산업법) 시행과 데이터 거래소 확산으로 데이터의 자산화·거래가 본격화되었다. 그러나 데이터의 가격을 산정할 객관적 기준이 부재하여 거래 활성화의 장애가 되고 있으며, 이에 데이터 가치평가의 중요성이 부각되었다.

2. 제도적 근거​

  • 데이터산업법 제15조: 데이터 가치의 객관적 평가를 위한 가치평가 기법 개발·보급 및 평가기관 지정
  • 「데이터 가치평가 안내서」(과기정통부·한국데이터산업진흥원) — 실무 기준 제시

Ⅱ. 가. 데이터 재화와 데이터 가치의 특징​

1. 데이터 재화(Data as a Good)의 특징​

   [일반 재화 vs 데이터 재화]
   ┌──────────────┬──────────────────┬──────────────────────┐
   │   구분       │   일반 재화       │   **데이터 재화**      │
   ├──────────────┼──────────────────┼──────────────────────┤
   │ 소비 특성    │ 소비하면 소멸     │ **비소멸·무한 재사용** │
   │ 경합성       │ 있음(내가 쓰면    │ **비경합성**(동시에    │
   │              │ 남이 못 씀)       │ 다수가 사용 가능)      │
   │ 복제 비용    │ 높음              │ **거의 0(Zero)**       │
   │ 가치 변화    │ 사용할수록 감소   │ **결합·축적할수록 증가**│
   │ 가격 결정    │ 수요·공급         │ **활용 목적에 따라 상이**│
   └──────────────┴──────────────────┴──────────────────────┘
특징상세 내용
비경합성(Non-rivalry)여러 주체가 동시에 사용해도 감소하지 않음 → 한계비용 거의 0
비소멸성사용해도 소진되지 않고 반복 활용 가능
복제·전송 용이무한 복제 가능 → 거래 후 통제 곤란(재판매·유출 위험)
결합 가치 증대(Network Effect)다른 데이터와 결합·융합할 때 가치가 비선형적으로 증가
경험재(Experience Good)사용해 보기 전에는 가치를 알 수 없음 → 거래 전 가치 판단 곤란
정보 비대칭판매자만 데이터 품질·내용을 앎 → 레몬 시장(Lemon Market) 우려
배제 가능성 약함일단 공개되면 배타적 이용 제한 어려움

2. 데이터 가치의 특징​

특징상세 내용
맥락 의존성(상대성)동일한 데이터도 활용 주체·목적에 따라 가치가 전혀 다름
예) 위치 데이터 — 물류사에게는 고가치, 제조사에게는 저가치
시간 의존성신선도(Freshness) 가 가치를 좌우 — 실시간 데이터는 시간 경과 시 급격히 가치 하락
품질 의존성정확성·완전성·일관성 등 품질이 곧 가치(오류 데이터는 마이너스 가치)
규모·희소성규모가 클수록 가치 증가하나, 대체 불가능한 희소 데이터의 가치가 더 큼
파생 가치원본보다 분석·가공된 결과물의 가치가 더 클 수 있음
법적 제약개인정보·저작권 제약이 활용 범위를 제한 → 가치 하락
측정의 어려움무형자산으로 회계상 인식·평가 기준 미흡, 시장 거래 사례 부족

Ⅲ. 나. 데이터 가치평가의 모델 및 절차​

1. 3대 평가 접근법​

   ┌──────────── 데이터 가치평가 접근법 ────────────┐
   │ **① 원가 접근법(Cost Approach)**                │
   │    "이 데이터를 다시 만들려면 얼마가 드는가"     │
   │ **② 시장 접근법(Market Approach)**              │
   │    "유사 데이터가 시장에서 얼마에 거래되는가"    │
   │ **③ 수익 접근법(Income Approach)**              │
   │    "이 데이터가 미래에 얼마의 수익을 창출하는가" │
   └────────────────────────────────────────────────┘
접근법산정 방식장점단점적합 상황
원가 접근법데이터 수집·정제·가공·저장에 투입된 비용 합산(재생산 원가·대체 원가)객관적·산출 용이, 근거 명확미래 활용 가치 미반영 → 실제 가치와 괴리, 데이터는 복제비 0이라 과소평가거래 사례·수익 예측이 없을 때, 최저 가격(하한선) 산정
시장 접근법유사 데이터의 실제 거래 가격을 기준으로 비교·보정시장 현실 반영, 신뢰도 높음데이터 거래 사례 부족, 데이터의 고유성으로 비교 곤란데이터 거래소 등 유사 거래가 존재할 때
수익 접근법데이터 활용으로 발생할 미래 현금흐름을 추정 후 현재가치 할인(DCF)
· 로열티 공제법, 초과이익법		실질 가치 반영, 이론적으로 가장 타당미래 수익 추정의 주관성·불확실성, 데이터 기여도 분리 곤란활용 계획·수익 모델이 구체적일 때

실무: 단일 접근법이 아니라 복수 접근법을 병행 적용하고 결과를 비교·조정하는 것이 원칙이다. 통상 원가로 하한선, 수익으로 상한선을 설정하고 협상 범위를 도출한다.

2. 가치평가 요소(평가 지표)​

평가 영역세부 지표
데이터 품질정확성, 완전성, 일관성, 적시성(신선도), 유효성
데이터 규모·범위데이터량, 기간, 항목 수, 커버리지
희소성·대체가능성유일성, 대체 데이터 존재 여부, 취득 난이도
활용성활용 목적 적합성, 표준화·정형화 수준, 연계·결합 용이성, 접근성(API 제공 여부)
법적 안정성개인정보 포함 여부, 저작권·이용권한 명확성, 제3자 제공 가능성
경제적 효과수익 창출 기여도, 비용 절감 효과, 시장 수요
기술적 요소데이터 구조·형식, 갱신 주기, 보안 수준

3. 가치평가 절차​

 ① **평가 대상·목적 정의** ─► ② **데이터 현황 조사·분석** ─► ③ **평가 방법 선정**
   (거래·투자·담보·회계 등)     (품질·규모·권리관계 실사)      (원가/시장/수익)
        │                                                          │
        ▼                                                          ▼
 ⑥ **평가 결과 활용** ◄─── ⑤ **가치 산정 및 검증** ◄─── ④ **평가 지표별 측정·분석**
   (거래 가격·협상 근거)      (복수 방법 비교·조정)        (품질·활용성·법적 검토)
단계주요 활동산출물
① 평가 대상·목적 정의평가 대상 데이터셋 범위 확정, 평가 목적 명확화(거래·투자유치·담보·자산 계상), 이용 조건(기간·범위·독점 여부) 정의평가 요청서, 평가 범위 정의서
② 현황 조사·분석데이터 명세·메타데이터 확보, 품질 진단(정확성·완전성), 권리관계 실사(개인정보·저작권·제3자 권리), 시장 수요 조사데이터 실사 보고서
③ 평가 방법 선정데이터 특성·목적에 맞는 접근법 선택, 복수 방법 조합 결정, 평가 전제·가정 설정평가 계획서
④ 평가 지표 측정품질·희소성·활용성·법적 안정성 등 지표별 정량·정성 평가, 가중치 적용지표별 평가 결과
⑤ 가치 산정·검증방법별 가치 산출 → 결과 비교·조정, 민감도 분석, 전문가 검토가치평가 결과서(금액 및 범위)
⑥ 결과 활용거래 가격 협상 근거, 투자·담보 활용, 무형자산 계상 검토계약서, 회계 반영

Ⅳ. 다. 데이터 가치평가의 활용방안​

활용 영역활용 방안기대효과
① 데이터 거래데이터 거래소·중개 플랫폼에서 합리적 가격 산정 근거 제공, 판매자–구매자 간 협상 기준 마련정보 비대칭 완화, 거래 활성화
② 데이터 자산화보유 데이터를 무형자산으로 재무제표에 계상, 기업 가치 재평가기업 가치 상승, 투자 유치
③ 자금 조달데이터 담보 대출(데이터 보증·유동화), 데이터 기반 스타트업 투자 평가데이터 기업의 자금 조달 경로 확대
④ 투자 의사결정데이터 구매·구축 투자 타당성 검토(ROI 분석), 데이터 수집 우선순위 결정합리적 투자 배분
⑤ 내부 데이터 관리보유 데이터의 가치 등급 분류 → 고가치 데이터에 품질관리·보안 자원 집중 배분데이터 거버넌스 효율화
⑥ 손해배상 산정데이터 유출·침해 사고 시 피해액 산정 근거, 보험 가입·보상 기준분쟁 해결 객관성 확보
⑦ 공공데이터 정책공공데이터 개방 우선순위 결정, 개방 효과 측정, 데이터 바우처 지원 규모 산정정책 효과성 제고
⑧ M&A·기업 평가데이터 중심 기업 인수 시 데이터 자산 실사(Due Diligence)인수 가격 적정성 확보
⑨ 데이터 배당마이데이터 환경에서 정보주체에 대한 보상 기준데이터 제공 유인 확대

Ⅴ. 한계 및 고려사항​

고려사항내용
평가의 주관성미래 수익 추정·가중치 설정에 주관 개입 → 평가 전제와 가정을 명시적으로 문서화
맥락 의존성동일 데이터도 구매자별 가치 상이 → 단일 가격보다 가격 범위(Range) 제시가 현실적
거래 사례 부족시장 접근법 적용 제약 → 거래 사례 데이터베이스 축적 필요
법적 리스크개인정보·저작권 문제 발견 시 가치가 급락하거나 거래 불가 → 권리관계 실사 필수
복제 가능성거래 후 재판매·무단 확산 통제 곤란 → 이용 조건 계약 명시, 워터마킹·DRM 활용
회계 기준 미비무형자산 인식 요건 충족이 어려워 재무제표 반영 제한 → 제도 정비 필요
평가기관 신뢰성공인 평가기관 지정·평가사 자격 체계 확립 필요

Ⅵ. 결론​

데이터 가치평가는 데이터를 "관리 대상"에서 "거래 가능한 자산"으로 전환시키는 핵심 인프라이다. 그러나 데이터는 비경합·비소멸·복제 용이·맥락 의존적이라는 특성 때문에 전통적 자산 평가 방법론을 그대로 적용하기 어렵다는 근본적 난제를 안고 있다.

따라서 실무적으로는 ① 원가 접근법으로 하한선, 수익 접근법으로 상한선을 설정하고, ② 품질·희소성·법적 안정성 등 지표별 평가를 병행하여 단일 금액이 아닌 합리적 가격 범위를 제시하는 접근이 타당하다. 특히 ③ 평가 전 권리관계 실사는 필수적이며, 개인정보·저작권 문제가 확인되면 가치 자체가 성립하지 않는다.

궁극적으로 데이터 거래 시장이 활성화되려면 거래 사례 축적을 통한 시장 접근법의 신뢰성 확보, 공인 평가기관·평가사 체계 확립, 무형자산 회계 기준 정비가 함께 진행되어야 한다. 데이터가 진정한 경제적 자산이 되기 위한 조건은 기술이 아니라 신뢰할 수 있는 평가와 거래 제도에 있다.
