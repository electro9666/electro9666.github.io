독립표본 t-검정, 대응표본 t-검정

문제​

9.독립표본 t-검정(Independent t-test)과 대응표본 t-검정(Paired t-test) 비교

Ⅰ. 개요​

t-검정(t-test) 은 모집단의 분산을 모르고 표본 크기가 작을 때(n < 30) t-분포를 이용하여 두 집단(또는 두 시점) 평균 차이의 통계적 유의성을 검정하는 방법이다. 이 중 독립표본 t-검정은 서로 다른 두 집단의 평균을 비교하고, 대응표본 t-검정은 동일 대상의 두 측정값(사전–사후) 을 비교한다.

   [**독립표본**]  A집단 (n₁명)   vs   B집단 (n₂명)
                   ○○○○○              ●●●●●●
                   **서로 다른 대상** — 표본 크기 달라도 됨
                   예) 남성 vs 여성, 신약군 vs 위약군

   [**대응표본**]  동일 대상의 **두 측정값**
                   ○ → ○'   ○ → ○'   ○ → ○'
                  사전    사후    (**짝(Pair)을 이룸**)
                   예) 교육 전·후 점수, 좌·우 눈 시력
                   ⇒ **차이값(d) 하나의 표본**으로 변환하여 검정

Ⅱ. 각 검정의 개념과 검정 통계량​

1. 독립표본 t-검정 (Independent Two-Sample t-test)​

항목내용
가설H₀: μ₁ = μ₂ (두 집단 평균이 같다) / H₁: μ₁ ≠ μ₂
검정통계량t = (x̄₁ − x̄₂) / SE, SE = 합동표준편차 기반 표준오차
자유도df = n₁ + n₂ − 2(등분산 가정 시)
핵심 전제등분산성 검정 필수 — Levene 검정 또는 F-검정
등분산 미충족 시Welch의 t-검정(자유도 보정, Satterthwaite 근사) 사용

2. 대응표본 t-검정 (Paired t-test)​

항목내용
가설H₀: μ_d = 0 (차이의 평균이 0이다) / H₁: μ_d ≠ 0
검정통계량t = d̄ / (s_d / √n), d = 사후 − 사전
자유도df = n − 1(쌍의 개수 − 1)
핵심 전제차이값 d의 정규성(개별 측정값의 정규성이 아님)
본질두 표본 문제를 차이값 하나의 단일표본 t-검정으로 환원
   [**대응표본이 강력한 이유** — 개인차 제거]

   독립표본 : 개인 간 편차(σ_between) **+** 처치 효과 → **노이즈 큼**
   대응표본 : **동일인의 차이만 관찰** → **개인차 제거** → 오차 감소
        ▼
   **동일한 효과 크기라면 대응표본이 검정력(Power)이 더 높다**
   → **더 적은 표본으로도 유의한 결과 도출 가능**

Ⅲ. 독립표본 t-검정과 대응표본 t-검정 비교​

비교 기준독립표본 t-검정대응표본 t-검정
표본 관계서로 독립(다른 대상)짝을 이룸(동일 대상 또는 매칭)
표본 크기n₁ ≠ n₂ 허용n₁ = n₂ 필수(쌍 구성)
비교 대상두 집단의 평균차이값의 평균(μ_d)
귀무가설H₀: μ₁ = μ₂H₀: μ_d = 0
자유도n₁ + n₂ − 2n − 1
정규성 가정각 집단의 값이 정규분포차이값 d가 정규분포
등분산 가정필요(Levene 검정)불필요
독립성 가정관측치 간 독립쌍 간 독립(쌍 내부는 종속)
개인차 통제불가(오차에 포함)가능(제거됨)
검정력상대적 낮음높음(동일 n 기준)
비모수 대안Mann-Whitney U 검정Wilcoxon 부호순위 검정
3집단 이상 확장일원배치 분산분석(ANOVA)반복측정 ANOVA
적용 예남녀 급여 차이, A/B 테스트(다른 사용자군), 신약 vs 위약교육 전후 점수, 다이어트 전후 체중, 시스템 개선 전후 응답시간
   [**검정 선택 의사결정 흐름**]

   비교할 평균이 몇 개인가?
        ├ **1개**(모평균과 비교) → **단일표본 t-검정**
        ├ **2개** ─┬ 두 표본이 **짝을 이루는가?**
        │          │      ├ **예** → **대응표본 t-검정**
        │          │      │           (d 정규성 위배 → Wilcoxon)
        │          │      └ **아니오** → **등분산인가?**(Levene)
        │          │             ├ 등분산 ○ → **Student t-검정**
        │          │             ├ 등분산 ✕ → **Welch t-검정**
        │          │             └ 정규성 ✕ → **Mann-Whitney U**
        └ **3개 이상** → **ANOVA**(반복측정 여부에 따라 구분)

Ⅳ. 해석 및 실무 고려사항​

항목내용
유의확률(p-value)p < α(통상 0.05) → 귀무가설 기각, "평균 차이가 통계적으로 유의함"
신뢰구간평균 차이의 95% 신뢰구간이 0을 포함하지 않으면 유의
효과크기(Cohen's d)통계적 유의성 ≠ 실질적 중요성
d ≈ 0.2(작음) / 0.5(중간) / 0.8(큼) — 반드시 병기
검정력(1−β)통상 0.8 이상 확보 — 사전 표본 크기 산정 필요
오류 유형1종 오류(α) : 차이 없는데 있다고 판단
2종 오류(β) : 차이 있는데 없다고 판단
실무 유의사항내용
① 검정 선택 오류대응 데이터에 독립표본 t-검정을 적용하면 개인차가 오차로 남아 검정력 손실 → 실제 효과를 놓침(2종 오류 증가)
② 등분산 검정 누락등분산 위배 시 Student t를 쓰면 1종 오류율 왜곡 → 실무에서는 기본적으로 Welch t-검정 사용 권장
③ 정규성 확인Shapiro-Wilk 검정·Q-Q Plot. 다만 중심극한정리에 의해 n ≥ 30이면 정규성 위배에 강건
④ 다중비교 문제여러 쌍을 반복 검정하면 1종 오류 누적 → Bonferroni 보정 또는 ANOVA 사용
⑤ p-hacking 경계유의할 때까지 표본 추가·변수 변경 금지, 사전 가설·표본수 확정
⑥ 이상치 영향소표본에서 이상치가 평균·분산을 크게 왜곡 → 사전 탐색 필수
활용 분야A/B 테스트(UI 개선 효과), 시스템 성능 개선 전후 응답시간 비교, 교육·훈련 효과 측정, 품질개선 활동 효과 검증, 임상시험

Ⅴ. 결론​

두 검정의 본질적 차이는 "두 표본이 짝을 이루는가" 이며, 이는 단순한 형식의 문제가 아니라 개인차라는 변동 요인을 통제할 수 있는가의 문제이다. 대응표본 t-검정은 동일 대상 내의 차이만을 관찰함으로써 개인 간 편차를 제거하고, 그 결과 같은 표본 수로 더 높은 검정력을 확보한다.

따라서 실무에서 가장 중요한 판단은 데이터 수집 설계 단계에서 이루어진다. 가능하다면 동일 대상을 사전·사후로 측정하는 대응 설계를 채택하는 것이 표본 확보 비용과 검정력 측면에서 유리하다. 반대로 이미 대응 구조로 수집된 데이터를 독립표본 t-검정으로 분석하면, 개인차가 오차항에 그대로 남아 실제로 존재하는 효과를 놓치는 2종 오류를 범하게 된다.

끝으로, p-value만으로 결론을 내리지 않는 것이 통계 활용의 기본이다. 표본이 충분히 크면 사소한 차이도 유의하게 나타나므로, 효과크기(Cohen's d)와 신뢰구간을 함께 제시하여 "통계적으로 유의한가"와 "실무적으로 의미 있는가"를 구분해 판단해야 한다.
