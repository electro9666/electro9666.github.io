데이터 차원 축소

문제​

5.데이터 차원 축소(Data Dimensionality Reduction)

Ⅰ. 개요​

차원 축소(Dimensionality Reduction) 는 고차원 데이터의 변수(Feature) 수를 줄이면서 원 데이터가 보유한 정보와 구조를 최대한 보존하는 기법으로, 차원의 저주(Curse of Dimensionality) 를 완화하여 모델 성능·학습 속도·해석력을 향상시키는 데이터 전처리 활동이다.

   [**차원의 저주**(Curse of Dimensionality)]

   차원 ↑  →  데이터 공간의 부피가 **지수적으로 증가**
        │  · 동일 밀도 유지에 필요한 **표본 수 지수적 증가**
        │  · 모든 점 간 거리가 **균일화** → **거리 기반 알고리즘 무력화**
        │    (KNN·K-means·군집 성능 급락)
        │  · **과적합(Overfitting)** 위험 증가
        │  · 계산량·저장공간 급증, **시각화 불가**
        ▼
   [**차원 축소**] 정보 손실을 최소화하며 **저차원으로 사상**

Ⅱ. 차원 축소의 유형​

 ┌──────────── **차원 축소 분류** ────────────┐
 │                                            │
 │  **① 변수 선택**(Feature Selection)         │
 │     원 변수 중 **유용한 변수만 선별**       │
 │     → **해석 가능성 유지** ○                │
 │     ├ **필터**(Filter)   : 통계 기준 사전 선별│
 │     ├ **래퍼**(Wrapper)  : 모델 성능 기반 탐색│
 │     └ **임베디드**(Embedded) : 학습 중 선택  │
 │                                            │
 │  **② 변수 추출**(Feature Extraction)        │
 │     원 변수를 **조합·변환하여 새 변수 생성** │
 │     → **정보 보존 우수**, 해석 어려움 ✕     │
 │     ├ **선형** : PCA · LDA · SVD · FA       │
 │     └ **비선형** : t-SNE · UMAP ·           │
 │                    커널 PCA · **오토인코더** │
 └────────────────────────────────────────────┘
구분변수 선택(Selection)변수 추출(Extraction)
방식기존 변수의 부분집합 선택기존 변수를 변환·결합
결과 변수원 변수 그대로새로운 잠재 변수(성분)
해석 가능성높음(변수 의미 유지)낮음(성분의 의미 모호)
정보 보존상대적 낮음(버린 변수 정보 소실)높음(모든 변수 반영)
대표 기법분산 임계·상관분석, RFE, LASSO, 트리 중요도PCA, LDA, SVD, t-SNE, 오토인코더
적용 상황설명이 중요한 분야(금융 신용평가·의료)예측 성능·시각화가 중요한 경우

Ⅲ. 주요 기법​

1. 변수 선택 기법​

기법내용
필터(Filter)모델과 무관하게 통계량으로 사전 선별 — 분산 임계, 상관계수, 카이제곱, 정보이득, ANOVA. 빠르나 변수 간 상호작용 미반영
래퍼(Wrapper)변수 조합별로 실제 모델을 학습해 성능 비교 — 전진선택·후진제거·RFE. 성능 우수하나 계산 비용 매우 큼
임베디드(Embedded)학습 과정에 선택이 내장 — LASSO(L1 규제, 계수를 0으로), 릿지, 트리 기반 변수 중요도, ElasticNet. 성능·효율의 균형

2. 변수 추출 기법​

기법원리 및 특징
PCA(주성분분석)분산이 최대인 축(주성분) 을 순차 도출하는 비지도 선형 기법. 공분산행렬의 고유값·고유벡터를 이용하며, 설명 분산 비율(누적 기여율) 로 차원 수 결정. 스케일링 필수
LDA(선형판별분석)클래스 레이블을 활용하는 지도 학습 기법. 집단 간 분산 / 집단 내 분산을 최대화. 최대 차원은 클래스 수 − 1
SVD(특이값분해)임의의 행렬을 U·Σ·Vᵀ 로 분해. Truncated SVD는 희소행렬에 적용 가능 → LSA(잠재의미분석), 추천시스템
t-SNE국소 이웃 구조 보존에 특화된 비선형 시각화 기법(주로 2~3차원). 군집 시각화 우수하나 전역 거리 왜곡·재현성 낮음, 신규 데이터 변환 불가
UMAPt-SNE 대비 속도가 빠르고 전역 구조 보존이 우수, 신규 데이터 변환 가능
오토인코더신경망 인코더–병목(잠재벡터)–디코더 구조로 비선형 압축. 대용량·이미지·이상탐지에 강점, 학습 비용 큼
요인분석(FA)관측 변수 뒤의 잠재 요인 추정 — 설문·심리 측정
   [**PCA 수행 절차**]

   ① **표준화**(평균 0, 분산 1)   ← 단위 차이 제거, **필수 단계**
        ▼
   ② **공분산행렬** 계산
        ▼
   ③ **고유값·고유벡터** 산출  (고유값 = 해당 축의 분산 크기)
        ▼
   ④ 고유값 **내림차순 정렬** → 상위 k개 주성분 선택
        │  기준 : **누적 설명분산 80~95%**, **스크리 도표의 elbow**,
        │         **Kaiser 규칙(고유값 > 1)**
        ▼
   ⑤ 원 데이터를 선택된 주성분 축으로 **사영(Projection)**

Ⅳ. 효과 및 고려사항​

구분내용
기대효과· 차원의 저주 완화 → 거리 기반 알고리즘 성능 회복
· 과적합 감소, 일반화 성능 향상
· 학습·추론 속도 향상, 저장공간 절감
· 다중공선성 제거(PCA의 주성분은 상호 직교)
· 2·3차원 시각화를 통한 데이터 이해
· 노이즈 제거 효과
한계·주의점· 정보 손실 불가피 → 성능 저하 가능성
· 해석 가능성 저하(설명책임 요구 영역에서 문제)
· PCA는 스케일에 민감 → 표준화 누락 시 왜곡
· PCA는 선형 가정 → 비선형 구조 포착 실패
· 분산이 큰 것이 항상 중요한 정보는 아님(지도학습 시 LDA 고려)
· 데이터 누수 방지 — 학습 데이터로만 fit, 검증·시험 데이터는 transform만
적용 분야이미지·영상(픽셀 압축, Eigenface), 텍스트(LSA·임베딩), 유전체 분석(수만 개 유전자), 추천시스템(행렬분해), 이상탐지(재구성 오차), 신용평가 변수 축약

Ⅴ. 결론​

차원 축소의 본질은 "정보 손실과 차원 감소 사이의 트레이드오프를 최적화하는 것" 이다. 무조건 차원을 줄이는 것이 아니라, 차원의 저주로 인한 성능 저하와 축소로 인한 정보 손실 중 어느 쪽이 큰지를 검증(교차검증)하여 결정해야 한다.

기법 선택의 실무 기준은 명확하다. 모델의 설명책임이 요구되는 금융·의료 영역에서는 원 변수의 의미가 보존되는 변수 선택(LASSO·RFE) 을, 예측 성능과 연산 효율이 중요한 영역에서는 변수 추출(PCA·오토인코더) 을 택한다. 또한 레이블이 있으면 LDA, 시각화 목적이면 UMAP/t-SNE, 비선형 대용량이면 오토인코더가 적합하다.

무엇보다 실무에서 빈번히 발생하는 오류는 표준화 누락과 전체 데이터로 PCA를 학습한 뒤 분할하여 발생하는 데이터 누수이므로, 전처리 파이프라인 내에서 학습 데이터 기준으로만 적합(fit) 시키는 원칙을 반드시 지켜야 한다.
