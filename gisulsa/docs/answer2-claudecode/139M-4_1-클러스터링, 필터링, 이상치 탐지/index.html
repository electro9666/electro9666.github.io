빅데이터 분석기법 — 클러스터링, 필터링, 이상치 탐지

Ⅰ. 개요​

1. 세 기법의 위치​

빅데이터 분석에서 클러스터링은 데이터를 유사 집단으로 묶고(그룹화), 필터링은 필요한 데이터만 골라내며(선별), 이상치 탐지는 정상 범위를 벗어난 데이터를 찾아낸다(식별). 세 기법은 목적이 다르나 모두 "유사성(Similarity)과 거리(Distance)" 라는 공통 개념에 기반한다.

2. 상호 관계​

   [원시 대용량 데이터]
            │
      ① 필터링(Filtering)  ── 노이즈·불필요 데이터 제거, 관심 데이터 선별
            │
      ② 클러스터링(Clustering) ── 유사 집단 구조 발견(비지도 학습)
            │                        │
            │                  군집에 속하지 못한 점
            ▼                        ▼
      분석·모델링         ③ 이상치 탐지(Outlier Detection)
                                     │
                          → 사기·장애·침해 탐지 / 데이터 정제 환류
  • 연계 관계: 필터링으로 데이터를 정제하면 클러스터링 품질이 향상되고, 클러스터링 결과의 군집 미소속 점(Noise) 은 곧 이상치 후보가 된다. 반대로 협업 필터링은 유사 사용자 군집 정보를 활용한다.

Ⅱ. 클러스터링(Clustering)​

1. 개념​

클러스터링은 정답 레이블 없이 데이터 간 유사도를 기준으로 군집 내 유사성은 최대, 군집 간 차이는 최대가 되도록 데이터를 분할하는 비지도 학습 기법이다. 분류(Classification)와 달리 사전 정의된 클래스가 없다.

2. 주요 알고리즘​

유형알고리즘원리특징
분할 기반K-Means중심(Centroid)까지 거리 제곱합(SSE) 최소화, 반복 갱신빠르고 확장성 우수, K 사전 지정·구형 군집 가정·이상치 민감
K-Medoids(PAM)실제 데이터 점을 대표로 사용이상치에 강건, 계산량 큼
계층 기반병합형(Agglomerative), 분할형(Divisive)유사한 것끼리 병합/분할, 덴드로그램 생성K 지정 불필요, O(n²)로 대용량 부적합
밀도 기반DBSCANε 반경 내 MinPts 이상이면 핵심점, 밀도 연결로 군집 확장임의 형태 군집 탐지, 이상치를 Noise로 자동 분리
OPTICS, HDBSCAN밀도 변화에 적응밀도 편차 큰 데이터에 적합
모델 기반GMM(가우시안 혼합)EM 알고리즘으로 확률분포 추정소프트 클러스터링(소속 확률 제공)
그래프 기반스펙트럴 클러스터링유사도 그래프의 라플라시안 고유벡터 활용비선형 구조에 강함
대용량BIRCH, Mini-Batch K-Means, Canopy요약(CF Tree)·미니배치 처리스트리밍·초대용량 처리

3. 유사도 척도 및 평가​

구분내용
거리 척도유클리드, 맨해튼, 코사인 유사도(텍스트), 마할라노비스, 자카드(집합)
최적 K 결정엘보우 기법(SSE), 실루엣 계수, Gap Statistic
내부 평가실루엣 계수, Dunn Index, Davies-Bouldin Index
외부 평가정답 존재 시 ARI, NMI

4. 활용 사례​

고객 세분화(RFM 기반 마케팅), 이미지 색상 양자화, 문서 주제 그룹화, 유전자 발현 패턴 분석, 네트워크 트래픽 프로파일링

Ⅲ. 필터링(Filtering)​

1. 개념​

필터링은 대량 데이터에서 조건에 부합하는 데이터만 선별하거나 불필요한 요소를 제거하는 기법이다. 데이터 전처리 관점의 데이터 필터링과 개인화 추천 관점의 정보 필터링으로 구분된다.

2. 유형별 분류​

관점유형내용
데이터 전처리조건 필터링조건식·범위·정규식 기반 행·열 선별(SQL WHERE, Spark filter)
잡음 필터링(신호)이동평균, 저역통과(Low-pass), 칼만 필터(Kalman), 사비츠키-골레이
중복 필터링해시·유사도 기반 중복 제거(Dedup), MinHash·LSH
확률적 필터링블룸 필터(Bloom Filter) — 메모리 효율적 존재 여부 판별(오탐 허용)
스트림 필터링윈도우 기반 실시간 선별(Kafka Streams, Flink), 샘플링
정보·추천협업 필터링(CF)사용자 기반 / 아이템 기반 / 잠재요인(MF·SVD) — 유사 이용자·항목 평점 활용
콘텐츠 기반 필터링항목 속성·프로파일 유사도(TF-IDF, 임베딩) 활용
하이브리드 필터링CF + 콘텐츠 결합으로 콜드 스타트·희소성 완화
보안·품질유해 콘텐츠 필터링규칙·분류 모델 기반 차단(스팸, 욕설, 악성코드)
접근 필터링권한·행 수준 보안(RLS), 마스킹

3. 협업 필터링의 한계와 대응​

한계내용대응
콜드 스타트신규 사용자·항목의 이력 부재콘텐츠 기반 병용, 인기도 초기화
데이터 희소성평점 행렬의 대부분이 결측행렬분해(MF), 임베딩, 암묵적 피드백 활용
확장성사용자·항목 급증 시 계산량 폭증ANN 검색(HNSW), 근사 계산, 사전 계산
필터 버블유사 콘텐츠만 반복 노출다양성·세렌디피티 지표 반영

4. 활용 사례​

전자상거래 상품 추천, OTT 콘텐츠 추천, 스팸메일 차단, IoT 센서 노이즈 제거, 로그 전처리, 대용량 조회 전 블룸 필터 선행 판별

Ⅳ. 이상치 탐지(Outlier / Anomaly Detection)​

1. 개념​

이상치 탐지는 데이터의 정상 패턴에서 현저히 벗어난 관측값·패턴을 식별하는 기법이다. 목적에 따라 데이터 정제(제거 대상) 와 이상 사건 탐지(발견 대상) 로 상반된 활용을 가진다.

2. 이상치 유형​

유형내용예시
점 이상치(Point)개별 값이 전체 분포에서 이탈비정상 고액 결제
상황적 이상치(Contextual)특정 문맥에서만 이상새벽 시간대의 대량 접속
집단 이상치(Collective)개별은 정상이나 패턴 집합이 이상분산 서비스 거부(DDoS) 시퀀스

3. 탐지 기법​

접근기법원리·특징
통계 기반Z-Score(|z|>3), IQR, Grubbs·Dixon 검정, 마할라노비스 거리단순·해석 용이, 분포 가정 필요
거리 기반k-NN 거리, LOF(국소 이상 요인)국소 밀도 차이 반영, 고차원에서 성능 저하
밀도·군집 기반DBSCAN Noise, 클러스터 중심 거리군집화와 동시 수행 가능
모델 기반Isolation Forest(고립 깊이), One-Class SVM, Elliptic Envelope고차원·대용량에 효과적, 비지도
딥러닝 기반AutoEncoder 재구성오차, VAE, LSTM 예측오차, GAN(AnoGAN)비정형·시계열 복잡 패턴에 강함
시계열ARIMA·Prophet 예측 잔차, 계절성 분해(STL), CUSUM·변화점 탐지추세·계절성 반영 필수
지도 학습분류 모델(불균형 처리: SMOTE, 가중치)레이블 존재 시 정확도 높음, 신종 이상 탐지 취약

4. 평가 및 실무 고려사항​

항목내용
평가 지표정확도(Accuracy)는 부적절 → Precision·Recall·F1, PR-AUC 사용
임계값 결정오탐(False Positive)과 미탐(False Negative)의 업무 비용 비교로 결정
클래스 불균형이상 사례가 극소수 → 재표본추출, 이상탐지 전용 기법 우선
개념 변화정상 패턴 변화(Concept Drift) → 주기적 재학습, 기준선 갱신
설명가능성탐지 근거 제시 필요(SHAP, 기여 변수) → 운영자 수용성 확보

5. 활용 사례​

카드 부정사용 탐지(FDS), 네트워크 침입탐지(IDS), 제조 설비 예측정비(PdM), 서버 성능 이상 알람(AIOps), 의료 영상 병변 탐지, 회계 부정 감사

Ⅴ. 세 기법의 비교​

비교 기준클러스터링필터링이상치 탐지
목적숨겨진 집단 구조 발견필요 데이터 선별·제거비정상 패턴 식별
학습 유형비지도 학습규칙 기반 / 비지도·지도비지도 중심(지도 병행)
출력군집 레이블축소된 데이터셋 / 추천 목록이상 점수(Anomaly Score)
대표 기법K-Means, DBSCAN, GMM협업 필터링, 칼만 필터, 블룸 필터Isolation Forest, LOF, AutoEncoder
평가 척도실루엣 계수, ARI정밀도·재현율, nDCG, 처리량PR-AUC, F1
데이터 전제유사도 정의 가능선별 기준 정의 가능정상 패턴 정의 가능
주요 위험K·거리척도 선택 오류과도 필터링으로 정보 손실, 필터 버블오탐 과다로 알람 피로
활용 단계탐색적 분석·세분화전처리·서비스 제공모니터링·품질관리

Ⅵ. 결론​

클러스터링·필터링·이상치 탐지는 그룹화·선별·식별이라는 상이한 목적을 갖지만, 유사도와 밀도라는 공통 기반 위에서 상호 보완적으로 결합될 때 효과가 극대화된다. 실무에서는 필터링으로 데이터 품질을 확보한 뒤 클러스터링으로 구조를 파악하고, 군집에서 이탈한 데이터를 이상치로 탐지하는 파이프라인이 일반적이다.

성공의 관건은 알고리즘 선택보다 거리 척도와 임계값의 적정성, 그리고 오탐·미탐의 업무 비용에 대한 판단에 있다. 따라서 도메인 전문가와 함께 정상의 기준을 정의하고, 개념 변화(Drift)에 대응하는 주기적 재학습 체계를 갖추어야 한다.
