서포트 벡터 머신, 마진

문제​

2.머신러닝의 분류 모델인 서포트 벡터 머신(Support Vector Machine)중 선형 서포트벡터 머신의 마진(Margin) 분류 방법 2 가지를 설명하시오.

Ⅰ. 개요​

1. SVM의 개념​

서포트 벡터 머신(SVM) 은 서로 다른 클래스의 데이터를 구분하는 초평면(Hyperplane) 을 찾되, 두 클래스 사이의 여백(마진, Margin)을 최대화하는 초평면을 선택하는 지도학습 분류 모델이다.

   [문제의식 — 어떤 결정 경계가 좋은가?]

   ○ ○ ○  ╲  ╱  │ ╲       ● ● ●
   ○ ○   ╲ ╱   │   ╲    ● ●
        (A)(B) (C)  (D)

   → 훈련 데이터를 완벽히 나누는 경계는 **무수히 많음**
   → 그중 **어떤 것이 새로운 데이터에 가장 잘 일반화되는가?**
        ▼
   [**SVM의 답**] **양쪽 클래스에서 가장 멀리 떨어진 경계**
   = **마진(Margin)을 최대화하는 초평면**
   ⇒ 경계가 데이터에서 멀수록 **작은 변동에도 강건**(일반화 성능 ↑)

2. 핵심 용어​

   [SVM의 기하학적 구조]

        ● ●                    ▲ 마진 경계 (+1)
      ●     **●**  ← **서포트 벡터**  ╱
    ●    ╱────────────────────────╱
        ╱      ↕ **마진**(Margin)  ╱
   ────╱──────**결정 초평면**──────╱────  w·x + b = 0
      ╱        ↕                  ╱
     ╱────────────────────────────╱  ← 마진 경계 (−1)
    **○**  ← **서포트 벡터**
   ○    ○
      ○   ○

   · **결정 초평면**(Hyperplane) : **w·x + b = 0** — 클래스를 나누는 경계
   · **서포트 벡터**(Support Vector) : **마진 경계 위에 놓인 데이터점**
        → **오직 이 점들만이 초평면을 결정**(나머지 데이터는 영향 없음)
   · **마진**(Margin) : 두 마진 경계 사이의 거리 = **2 / ‖w‖**
        → 마진 최대화 = **‖w‖ 최소화**
용어내용
초평면n차원 공간에서 데이터를 나누는 (n−1)차원 경계면(2차원 → 직선, 3차원 → 평면)
서포트 벡터마진 경계에 위치한 결정적 데이터점 — SVM의 이름이 유래
마진초평면과 가장 가까운 데이터 사이 거리의 2배 = 2/‖w‖
최적화 목표min (1/2)‖w‖² subject to yᵢ(w·xᵢ + b) ≥ 1 (볼록 최적화 → 전역 최적해 보장)

Ⅱ. 선형 SVM의 마진 분류 방법 2가지​

 ┌──────── **선형 SVM의 두 가지 마진 분류** ────────┐
 │                                                  │
 │  **① 하드 마진**(Hard Margin)                     │
 │      "**어떤 오분류도 허용하지 않는다**"           │
 │      → 선형 분리 가능(Linearly Separable) 전제    │
 │                                                  │
 │  **② 소프트 마진**(Soft Margin)                   │
 │      "**일부 오분류를 허용하되 벌점을 부과한다**"  │
 │      → 노이즈·중첩이 있는 현실 데이터 대응        │
 └──────────────────────────────────────────────────┘

1. 하드 마진 (Hard Margin)​

   [기하학적 형태]
        ● ●   ●
      ●   **●**  ← 서포트 벡터
    ────────────────────  마진 경계 (+1)
         ↕ 마진 (완전히 비어 있음)
    ══════════════════════  **결정 초평면**
         ↕
    ────────────────────  마진 경계 (−1)
      **○**  ← 서포트 벡터
    ○   ○  ○

   ⇒ **마진 안에 어떤 데이터도 존재하지 않음**
   ⇒ 모든 데이터가 **완벽하게 분리**됨
항목내용
개념모든 훈련 데이터를 오차 없이 정확히 분류하면서 마진을 최대화
전제 조건데이터가 선형 분리 가능(Linearly Separable) 해야 함
제약 조건yᵢ(w·xᵢ + b) ≥ 1 — 모든 i에 대해 예외 없이 만족
목적 함수min (1/2)‖w‖² (마진 최대화)
장점· 개념이 명확·단순
· 분리 가능한 데이터에서 최적의 경계 도출
· 훈련 데이터에 대한 오분류 0
단점· 선형 분리 불가능하면 해가 존재하지 않음(최적화 실패)
· 이상치(Outlier) 하나에 결정 경계가 크게 왜곡
· 과적합(Overfitting) 위험 높음
· 노이즈에 매우 취약 → 현실 데이터에 부적합
   [**하드 마진의 치명적 약점** — 이상치 1개의 영향]

   [정상적인 경우]              [**이상치가 있는 경우**]
     ● ● ●                        ● ● ●
   ────────  넓은 마진          ●     ○ ← **이상치**
   ════════  안정적 경계      ──────      ← 마진이 극도로 좁아짐
   ────────                   ═══         ← 경계가 **크게 왜곡**
     ○ ○ ○                    ──────
                                ○ ○ ○
   ⇒ 단 하나의 이상치가 **전체 모델을 망가뜨림**

2. 소프트 마진 (Soft Margin)​

   [기하학적 형태]
        ● ●   ●
      ●   **●**
    ────────────────────  마진 경계 (+1)
        ↕      **○** ← ξ만큼 **침범 허용**(오분류)
    ══════════════════════  **결정 초평면**
        ↕  **●** ← 마진 안에 위치(**여유변수 ξ**)
    ────────────────────  마진 경계 (−1)
      **○**
    ○   ○  ○

   ⇒ **여유변수(Slack Variable, ξ)** 도입으로 **일부 위반 허용**
   ⇒ 대신 **위반량에 비례한 벌점**을 목적함수에 추가
항목내용
개념여유변수(ξ, Slack Variable) 를 도입해 일부 데이터의 마진 침범·오분류를 허용하되, 그 정도에 벌점(Penalty) 을 부과
제약 조건yᵢ(w·xᵢ + b) ≥ 1 − ξᵢ, ξᵢ ≥ 0
목적 함수min (1/2)‖w‖² + C·Σξᵢ
└ 마진 최대화 ── └ 오분류 벌점의 합
여유변수 ξ의 의미ξ = 0 : 올바르게 분류되고 마진 밖
0 < ξ < 1 : 마진 안이지만 올바른 쪽
ξ ≥ 1 : 오분류(경계를 넘어감)
장점· 선형 분리 불가능한 현실 데이터에도 적용 가능
· 이상치·노이즈에 강건
· C로 과적합-과소적합 조절 가능
· 일반화 성능 우수
단점· 하이퍼파라미터 C의 튜닝 필요
· 훈련 데이터에 오분류 존재
· C 설정에 따라 성능 편차 큼

■ 규제 파라미터 C의 역할 (핵심)​

   **목적함수 : min (1/2)‖w‖²  +  C · Σξᵢ**
                    ↑ 마진 최대화      ↑ 오분류 최소화
                    (일반화)          (훈련 정확도)
                    └──── **C가 둘 사이의 균형을 조절** ────┘

   ┌──────────────┬────────────────────────────────────────┐
   │ **C가 큰 경우**│ 오분류 벌점 **큼** → 오분류를 강하게 억제│
   │  (C → ∞)     │ → **마진 좁아짐**, **하드 마진에 수렴**  │
   │              │ → 훈련 정확도 ↑, **과적합(Overfitting)** │
   │              │ → 낮은 편향(Bias), **높은 분산(Variance)**│
   ├──────────────┼────────────────────────────────────────┤
   │ **C가 작은 경우**│ 오분류 벌점 **작음** → 위반에 관대     │
   │  (C → 0)     │ → **마진 넓어짐**, 많은 위반 허용        │
   │              │ → **과소적합(Underfitting)** 위험         │
   │              │ → **높은 편향**, 낮은 분산               │
   └──────────────┴────────────────────────────────────────┘

   [시각적 비교]
   **C 큼(과적합)**              **C 적정**              **C 작음(과소적합)**
    ●●│○ ●                      ● ●  ○                  ● ●  ○ ●
    ●●│ ○○   ← 좁은 마진        ──────  ← 적정 마진      ─────────
    ● │○ ○      경계 복잡       ══════     안정적        ═════════ ← 넓은 마진
              ○ 하나에 반응     ──────                   ─────────    단순
                                  ○ ○                      ○ ● ○

   ⇒ **C는 교차검증(Cross Validation)으로 최적값 탐색**
   ⇒ **편향-분산 상충(Bias-Variance Trade-off)** 을 조절하는 핵심 파라미터

Ⅲ. 하드 마진과 소프트 마진의 비교​

비교 기준하드 마진(Hard Margin)소프트 마진(Soft Margin)
오분류 허용전혀 허용하지 않음일부 허용(여유변수 ξ)
전제 조건선형 분리 가능해야 함분리 불가능해도 적용 가능
제약 조건yᵢ(w·xᵢ+b) ≥ 1yᵢ(w·xᵢ+b) ≥ 1 − ξᵢ, ξᵢ ≥ 0
목적 함수min (1/2)‖w‖²min (1/2)‖w‖² + C·Σξᵢ
하이퍼파라미터없음C(규제 파라미터)
마진 폭좁음(엄격)C에 따라 조절 가능
이상치 영향매우 민감(1개로 왜곡)강건(Robust)
과적합 위험높음조절 가능
해의 존재분리 불가 시 해 없음항상 해 존재
일반화 성능낮음(노이즈 데이터)우수
실무 활용거의 사용 안 함(이론적 기준)표준(scikit-learn 기본값 C=1.0)
관계—C → ∞ 이면 하드 마진과 동일
   [**두 방법의 관계**]
   소프트 마진은 하드 마진의 **일반화(Generalization)**

        **C → ∞**  ─────▶  **하드 마진**(위반 절대 불허)
        **C 유한**  ─────▶  **소프트 마진**(위반 허용)
        **C → 0**   ─────▶  마진만 최대화(분류 성능 무시)

   ⇒ 실무에서는 **소프트 마진 하나로 통일**하고 **C를 조절**하는 방식 사용

Ⅳ. SVM의 확장 및 특징​

1. 비선형 문제로의 확장 — 커널 트릭​

   [선형으로 분리 불가능한 경우]

   1차원 공간              **고차원 사상 후**
   ○ ○ ● ● ● ○ ○     →      φ(x) = x²        ●   ●
   ← 직선으로 분리 불가            ▲          ─────── ← **분리 가능**
                                   │        ○       ○
   ⇒ **커널 함수(Kernel)** 로 고차원 사상 효과를 **실제 변환 없이** 계산
      = **커널 트릭(Kernel Trick)** — 계산량 폭증 회피
커널수식용도
선형(Linear)K(x,y) = x·y고차원·희소 데이터(텍스트 분류)
다항(Polynomial)K(x,y) = (γx·y + r)^d특징 간 상호작용
RBF/가우시안K(x,y) = exp(−γ‖x−y‖²)범용 기본값 — 복잡한 비선형 경계
시그모이드tanh(γx·y + r)신경망 유사

RBF 커널의 γ(gamma) : 작으면 결정 경계가 부드럽고(과소적합), 크면 각 데이터에 민감(과적합) → C와 함께 그리드 서치·베이지안 최적화로 튜닝

2. SVM의 장단점​

구분내용
장점· 마진 최대화 → 일반화 성능 우수
· 고차원 데이터에 강함(차원 > 표본 수에서도 동작)
· 볼록 최적화 → 전역 최적해 보장(신경망의 국소 최적 문제 없음)
· 서포트 벡터만 저장하면 되어 모델이 간결
· 커널로 비선형 문제 대응
단점· 대용량 데이터에 느림(학습 복잡도 O(n²)~O(n³))
· 하이퍼파라미터(C·γ·커널) 튜닝 필요
· 확률값을 직접 출력하지 않음(Platt Scaling 필요)
· 다중 클래스 미지원(OvO·OvR로 확장)
· 스케일링 필수(거리 기반이므로 정규화 안 하면 성능 급락)
· 결과 해석이 어려움(비선형 커널 시)

3. 실무 적용 시 고려사항​

고려사항내용
① 특성 스케일링 필수거리 기반 알고리즘 → StandardScaler·MinMaxScaler 반드시 적용
② C·γ 동시 튜닝그리드 서치 + 교차검증, 또는 베이지안 최적화로 효율 탐색
③ 커널 선택특성 수 > 샘플 수 → 선형 커널
샘플 수 많고 비선형 → RBF 커널
④ 클래스 불균형class_weight='balanced' 옵션으로 가중치 조정
⑤ 대용량 데이터SVM 대신 LinearSVC·SGDClassifier, 또는 트리 기반 모델(XGBoost) 고려
⑥ 적용 분야텍스트 분류(스팸 필터), 이미지 인식, 얼굴 인식, 이상 탐지(One-Class SVM), 생물정보학(유전자 분류)

Ⅴ. 결론​

선형 SVM의 마진 분류 방법은 하드 마진과 소프트 마진 두 가지로, 그 차이는 "오분류를 허용할 것인가" 라는 단 하나의 기준에서 비롯된다.

하드 마진은 모든 데이터를 완벽히 분리한다는 이상적 조건을 요구하므로 개념적으로는 명확하지만, 선형 분리가 불가능하면 해 자체가 존재하지 않고, 단 하나의 이상치에도 결정 경계가 크게 왜곡된다. 노이즈가 없는 데이터는 현실에 거의 존재하지 않으므로, 하드 마진은 이론적 출발점으로서의 의미가 크다.

소프트 마진은 여유변수(ξ)를 도입하여 일부 위반을 허용하되 벌점을 부과함으로써 이 문제를 해결한다. 그 결과 선형 분리가 불가능한 데이터에도 항상 해가 존재하고, 이상치에 강건하며, 일반화 성능이 향상된다. 따라서 실무에서 사용되는 SVM은 사실상 모두 소프트 마진 방식이다.

두 방법의 관계에서 핵심은 규제 파라미터 C이다. C는 "마진을 넓게 가져갈 것인가(일반화), 훈련 데이터를 정확히 맞출 것인가(정확도)" 라는 편향-분산 상충을 조절하는 손잡이이며, C → ∞ 이면 소프트 마진은 하드 마진으로 수렴한다. 즉 소프트 마진은 하드 마진을 포함하는 일반화된 형태이므로, 실무에서는 소프트 마진 하나로 통일하고 교차검증을 통해 C의 최적값을 탐색하는 것이 표준적 접근이다.

끝으로 SVM 적용 시 가장 흔한 실수는 특성 스케일링을 생략하는 것이다. SVM은 거리 기반 알고리즘이므로 변수 간 단위가 다르면 성능이 급격히 저하되며, 이는 커널이나 C 튜닝으로 보완할 수 없는 전처리상의 문제임을 유의해야 한다.
