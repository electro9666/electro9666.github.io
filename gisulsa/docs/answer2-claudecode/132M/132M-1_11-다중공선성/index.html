다중공선성(Multicollinearity)

문제​

11.다중공선성 (Multicollinearity)

Ⅰ. 개요​

다중공선성이란 다중 회귀분석에서 독립변수들 간에 강한 선형 상관관계가 존재하는 현상이다. 회귀모형의 예측력 자체는 유지되지만, 개별 회귀계수의 추정이 불안정해져 해석이 왜곡된다.

   [문제의 본질]
   회귀분석의 전제 : 독립변수는 **서로 독립적**이어야 함
        │  Y = β₀ + β₁X₁ + β₂X₂ + ε
        │  β₁의 의미 = "**X₂를 고정한 채** X₁이 1 증가할 때 Y의 변화량"
        ▼
   그런데 **X₁과 X₂가 함께 움직인다면?**
        │  → "X₂를 고정한 채 X₁만 변화"시키는 상황이 **데이터에 없음**
        ▼
   ⇒ **각 변수의 고유한 기여도를 분리할 수 없음**
      = 회귀계수 추정이 **불안정·부정확**해짐

Ⅱ. 발생 원인 및 영향​

1. 발생 원인​

원인예시
본질적으로 유사한 변수키·몸무게, 소득·소비, CPU 사용률·응답시간
파생·중복 변수 포함총점과 각 과목 점수, 매출액과 단가×수량
더미변수 함정(Dummy Variable Trap)범주 k개를 더미 k개 모두 포함 → 완전 공선성 발생
(반드시 k−1개만 사용)
표본 수 부족변수 수에 비해 관측치가 적음(n < p)
동일 척도의 반복 측정설문의 유사 문항 다수 포함
시계열 추세 변수시간에 따라 함께 증가하는 변수들

2. 영향​

영향내용
① 회귀계수 분산 증가표준오차 급증 → 추정이 불안정
② 통계적 유의성 저하t값 감소 → p-value 상승 → 실제로 중요한 변수가 유의하지 않게 판정
③ 계수의 부호·크기 왜곡이론과 반대 부호가 나오거나 비상식적 크기 → 해석 불가
④ 모형 불안정성데이터 일부만 바뀌어도 계수가 크게 변동
⑤ 역설적 현상모형 전체 F검정은 유의한데 개별 변수는 모두 유의하지 않음 ← 대표적 징후
⑥ 예측력은 유지Y 예측 자체는 문제없음 — 해석·추론이 목적일 때만 문제
   [**핵심 구분** — 목적에 따라 문제 여부가 달라진다]

   **예측(Prediction)이 목적**  → 다중공선성 **큰 문제 아님**
        (예측값 Ŷ은 여전히 정확)

   **해석·추론(Inference)이 목적** → **심각한 문제**
        (어떤 변수가 얼마나 영향을 주는지 알 수 없음)

Ⅲ. 진단 방법​

진단 방법판단 기준특징
① 상관계수 행렬독립변수 간 상관계수 │r│ > 0.8~0.9간단하나 두 변수 간 관계만 확인 가능
② VIF(분산팽창인자)VIF > 10(엄격히는 5) → 다중공선성 의심가장 널리 사용, 다변수 관계 반영
③ 공차한계(Tolerance)Tolerance < 0.1VIF의 역수
④ 상태지수(Condition Index)CI > 30 → 심각고유값 기반, 다중 공선 관계 탐지
⑤ 결정계수·유의성 불일치R² 높고 F 유의 + 개별 t 모두 비유의실무적 징후 판단
⑥ 계수 부호 이상이론과 반대 부호정성적 신호
   [**VIF 계산 원리**]
       **VIF(Xᵢ) = 1 / (1 − Rᵢ²)**

   Rᵢ² : Xᵢ를 **나머지 모든 독립변수로 회귀**했을 때의 결정계수
        │
        ├ Rᵢ² = 0    → 완전 독립      → **VIF = 1**  (문제 없음)
        ├ Rᵢ² = 0.8  → 80% 설명됨     → **VIF = 5**  (주의)
        ├ Rᵢ² = 0.9  → 90% 설명됨     → **VIF = 10** (심각)
        └ Rᵢ² → 1    → 완전 공선성    → **VIF → ∞**

   ※ **VIF = 1 / (1 − Rᵢ²)**, **Tolerance = 1 − Rᵢ² = 1/VIF**

Ⅳ. 해결 방안​

해결 방안내용장단점
① 변수 제거VIF가 높은 변수 중 이론적 중요도가 낮은 것 제거가장 단순 / 정보 손실, 누락변수 편의 위험
② 변수 결합·파생유사 변수를 합산·평균·비율로 통합(예: BMI = 체중/키²)정보 보존 / 해석 변화
③ 주성분분석(PCA)상관된 변수를 직교하는 주성분으로 변환공선성 완전 제거 / 해석력 상실(주성분의 의미 불명확)
④ 표본 크기 증가관측치 확대로 추정 안정화근본적 / 비용·현실적 제약
⑤ 정규화 회귀(Regularization)Ridge(L2) — 계수를 축소하여 분산 감소, 다중공선성 대응에 효과적
Lasso(L1) — 계수를 0으로 만들어 변수 선택
ElasticNet — 두 방식 결합		예측 성능 유지 / 약간의 편향 발생(편향-분산 상충)
⑥ 중심화(Centering)변수에서 평균을 뺌 — 교호작용항·다항항의 공선성 완화특정 상황에 한정
⑦ 더미변수 조정범주 k개 → 더미 k−1개만 사용완전 공선성 원천 차단
⑧ 그대로 사용예측이 목적이거나 공선 변수가 통제변수인 경우해석 포기
   [**해결 방안 선택 판단 흐름**]
   다중공선성 발견(VIF > 10)
        │
        ├─ **분석 목적이 예측** ────────────▶ **그대로 사용** 또는 **Ridge**
        │
        └─ **분석 목적이 해석**
             ├─ 변수가 이론적으로 중복 ────▶ **변수 제거·결합**
             ├─ 모든 변수가 중요 ──────────▶ **PCA** 또는 **Ridge**
             └─ 다항·교호항 때문 ──────────▶ **중심화**

Ⅴ. 결론​

다중공선성은 독립변수들이 서로 독립적이어야 한다는 회귀분석의 전제가 깨진 상황으로, 그 본질적 문제는 "각 변수의 고유한 기여도를 데이터로부터 분리할 수 없다" 는 데 있다. 그 결과 회귀계수의 표준오차가 커지고, 실제로 중요한 변수가 통계적으로 유의하지 않게 나타나거나 부호가 뒤바뀌는 현상이 발생한다.

진단은 VIF > 10(엄격하게는 5)을 기준으로 하는 것이 표준이며, "모형 전체 F검정은 유의한데 개별 변수는 모두 유의하지 않은" 역설적 결과는 다중공선성의 전형적 징후이다.

가장 중요한 실무적 판단 기준은 분석의 목적이다. 예측이 목적이라면 다중공선성은 심각한 문제가 아니다 — 예측값 자체는 여전히 정확하기 때문이다. 반면 "어떤 요인이 결과에 얼마나 영향을 미치는가"를 해석하는 것이 목적이라면 반드시 해결해야 한다. 이 구분 없이 무조건 변수를 제거하면 오히려 누락변수 편의(Omitted Variable Bias) 라는 더 큰 문제를 초래할 수 있다.

해결 방안 중에서는 이론적 근거에 따른 변수 제거·결합이 해석력을 유지하므로 우선 검토 대상이며, 모든 변수를 유지해야 하는 경우에는 Ridge 회귀가 예측 성능과 안정성을 함께 확보하는 실용적 대안이 된다. PCA는 공선성을 완전히 제거하지만 주성분의 해석이 불가능해지므로, 해석이 목적인 분석에서는 신중히 적용해야 한다.
