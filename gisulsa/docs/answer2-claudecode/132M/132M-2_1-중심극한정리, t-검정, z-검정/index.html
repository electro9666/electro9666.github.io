중심극한정리, t-검정, z-검정

문제​

1.중심극한정리, t-검정, z-검정을 설명하시오

Ⅰ. 개요​

1. 통계적 추론의 구조​

모집단 전체를 조사할 수 없으므로 표본으로 모집단을 추론해야 한다. 이때 "표본평균이 어떤 분포를 따르는가" 를 알아야 확률적 판단이 가능해지는데, 그 이론적 근거가 중심극한정리(CLT) 이며, 이를 실제 판단에 적용하는 도구가 z-검정과 t-검정이다.

   [세 개념의 관계]

   **중심극한정리(CLT)**  ── "표본평균은 **정규분포를 따른다**"
        │                    ※ 모든 통계적 검정의 **이론적 토대**
        ▼
   **표본분포**(Sampling Distribution) 확보
        │
        ├─ **모분산 σ²를 아는 경우** 또는 **대표본(n ≥ 30)** ─▶ **z-검정**(정규분포)
        │
        └─ **모분산 σ²를 모르고 소표본(n < 30)** ────────────▶ **t-검정**(t분포)

   ⇒ CLT는 **이론**, z·t 검정은 그 이론을 쓰는 **도구**

2. 통계적 가설검정의 절차​

   ① **가설 설정**
        **귀무가설 H₀** : "차이가 없다"(기각을 목표로 하는 가설)
        **대립가설 H₁** : "차이가 있다"(입증하고자 하는 주장)
        ▼
   ② **유의수준(α) 결정** — 통상 0.05(5%) 또는 0.01
        ▼
   ③ **검정통계량 계산** — z값 또는 t값
        ▼
   ④ **판단**
        · **p-value < α** → **H₀ 기각**(통계적으로 유의)
        · 검정통계량 > 임계값 → H₀ 기각
        ▼
   ⑤ **결론 해석**(실무적 의미 부여)

   [오류의 종류]
   **제1종 오류(α)** : H₀가 참인데 **기각**(없는 차이를 있다고 판단)
   **제2종 오류(β)** : H₀가 거짓인데 **채택**(있는 차이를 놓침)
   **검정력(1−β)**  : 실제 차이를 올바로 검출할 확률

Ⅱ. 중심극한정리 (Central Limit Theorem, CLT)​

1. 개념​

중심극한정리란 모집단의 분포 형태와 관계없이, 표본 크기 n이 충분히 크면 표본평균 X̄의 분포가 정규분포에 근사한다는 정리이다.

   [정리의 내용]

   모집단 : 평균 μ, 분산 σ²  (**분포 형태는 무엇이든 상관없음**)
        │  크기 n인 표본을 반복 추출
        ▼
   **표본평균 X̄ ~ N( μ , σ²/n )**   (n이 충분히 클 때, 통상 **n ≥ 30**)

   · **표본평균의 기댓값** : E(X̄) = **μ**            ← 모평균과 동일(불편성)
   · **표본평균의 분산**   : Var(X̄) = **σ²/n**
   · **표준오차(SE)**      : **σ/√n**                ← n이 커질수록 작아짐

2. 시각적 이해​

   [모집단 분포]                    [표본평균의 분포]

   ① **균등분포**
      ┌─────────┐                        ╱╲
      │         │      ── n=30 ──▶      ╱  ╲      **정규분포**
      └─────────┘                     ╱      ╲

   ② **치우친 분포(지수)**
      ▏                                     ╱╲
      ▏╲                ── n=30 ──▶       ╱  ╲    **정규분포**
      ▏  ╲___                           ╱      ╲

   ③ **이봉분포**
       ╱╲  ╱╲            ── n=30 ──▶      ╱╲
      ╱  ╲╱  ╲                          ╱    ╲    **정규분포**

   ⇒ **원래 분포가 무엇이든 표본평균은 정규분포로 수렴**  ← CLT의 위력
   ⇒ n이 커질수록 **분포의 폭(표준오차 σ/√n)이 좁아짐** = 추정 정밀도 향상

3. 의의 및 조건​

항목내용
핵심 의의모집단 분포를 몰라도 표본평균을 이용한 확률적 추론이 가능해짐
→ 모수적 통계 기법(z·t 검정, 신뢰구간, 회귀분석)의 이론적 토대
적용 조건· 무작위 추출(독립·동일분포, i.i.d.)
· 표본 크기 n ≥ 30(경험적 기준)
· 모집단 분산 σ²가 유한해야 함
예외·주의· 모집단이 극단적으로 치우친 경우 더 큰 n 필요
· 모집단이 이미 정규분포면 n이 작아도 X̄는 정규분포
· 표본이 편향되면 CLT를 적용해도 무의미(비표본오차)
큰 수의 법칙과 구분큰 수의 법칙 : n → ∞일 때 X̄ → μ(값의 수렴)
중심극한정리 : X̄의 분포 형태가 정규분포로 수렴(분포의 수렴)

4. 활용​

활용내용
신뢰구간 추정x̄ ± Z(α/2)·(σ/√n) — 표본평균의 정규성 가정
가설검정z-검정·t-검정의 전제
품질관리관리도(X̄ 관리도)의 관리한계선 설정
여론조사표본오차 산정(±1.96·√(p(1−p)/n))
성능 측정평균 응답시간의 통계적 판단

Ⅲ. z-검정 (Z-test)​

1. 개념 및 조건​

z-검정은 표준정규분포(Z분포) 를 이용하여 모평균·모비율에 대한 가설을 검정하는 방법이다.

항목내용
사용 조건① 모분산(σ²)을 알고 있음, 또는
② 대표본(n ≥ 30) — CLT에 의해 정규 근사, 표본표준편차 s로 σ 대체 가능
③ 모집단이 정규분포이거나 CLT 적용 가능
기준 분포표준정규분포 N(0, 1) — 고정된 형태
주요 임계값양측 α=0.05 → ±1.96 / α=0.01 → ±2.58
단측 α=0.05 → 1.645

2. 검정통계량​

   [**① 단일 모평균 검정**]
        **z = ( x̄ − μ₀ ) / ( σ / √n )**

        x̄  : 표본평균      μ₀ : 귀무가설의 모평균
        σ  : 모표준편차    n  : 표본 크기
        (σ 미지·대표본 시 **s**로 대체)

   [**② 두 모평균 차이 검정**]
        **z = ( x̄₁ − x̄₂ ) / √( σ₁²/n₁ + σ₂²/n₂ )**

   [**③ 모비율 검정**]
        **z = ( p̂ − p₀ ) / √( p₀(1−p₀) / n )**

3. 적용 예시​

   [문제] 어느 시스템의 평균 응답시간이 **2.0초**라고 알려져 있다
          (모표준편차 σ = 0.5초).
          개선 후 **100건**을 측정하니 평균 **1.9초**였다.
          유의수준 5%에서 응답시간이 개선되었다고 할 수 있는가?

   ① H₀ : μ = 2.0   /   H₁ : μ < 2.0  (**단측검정**)
   ② α = 0.05 → 임계값 **−1.645**
   ③ z = (1.9 − 2.0) / (0.5 / √100) = **−0.1 / 0.05 = −2.0**
   ④ **−2.0 < −1.645** → **H₀ 기각**
   ⑤ 결론 : 유의수준 5%에서 **응답시간이 유의하게 개선되었다**

Ⅳ. t-검정 (T-test)​

1. 개념 및 조건​

t-검정은 모분산을 모르고 표본 크기가 작을 때(n < 30), t분포(Student's t-distribution) 를 이용하여 모평균에 관한 가설을 검정하는 방법이다.

항목내용
사용 조건① 모분산(σ²) 미지 → 표본표준편차 s 사용
② 소표본(n < 30)
③ 모집단의 정규성 가정 필요(소표본에서는 CLT 적용 불가)
기준 분포t분포 — 자유도(df = n−1) 에 따라 형태 변화
t분포의 특성· 정규분포보다 꼬리가 두껍고 중심이 낮음(불확실성 반영)
· 자유도가 커질수록 정규분포에 수렴(n ≥ 30이면 거의 동일)
· 좌우 대칭, 평균 0
   [정규분포와 t분포의 비교]

        ▲
        │      ╱╲  ← **정규분포(Z)** — 뾰족
        │     ╱  ╲
        │    ╱╌╌╲ ← **t분포(df 작음)** — 완만·**두꺼운 꼬리**
        │   ╱      ╲
        │ ╱╌          ╌╲   ← 꼬리가 두꺼움 = 극단값 확률 높게 봄
        └──────────────────▶
           −t   0   +t

   ⇒ 같은 유의수준이라도 **t의 임계값이 더 큼**
      (예: df=9, α=0.05 양측 → t = **2.262** vs z = 1.96)
   ⇒ **소표본의 불확실성을 보수적으로 반영**

2. t-검정의 3가지 유형​

유형용도검정통계량자유도
① 일표본 t-검정
(One-sample)		표본평균과 알려진 기준값 비교t = (x̄ − μ₀) / (s / √n)n − 1
② 독립표본 t-검정
(Independent two-sample)		서로 다른 두 집단의 평균 비교
(예: A그룹 vs B그룹)		t = (x̄₁ − x̄₂) / (Sp·√(1/n₁ + 1/n₂))
Sp = 합동표준편차		n₁ + n₂ − 2
③ 대응표본 t-검정
(Paired)		동일 대상의 전·후 비교
(예: 교육 전후 점수)		t = d̄ / (s_d / √n)
d = 각 쌍의 차이		n − 1
유형전제 조건
독립표본두 집단 독립, 각 집단 정규성, 등분산성(Levene 검정)
※ 등분산 위배 시 Welch's t-검정 사용
대응표본차이값(d)의 정규성 — 개별 값의 정규성은 불필요

3. 적용 예시​

   [문제] 신규 알고리즘 적용 전후 처리시간을 **동일한 10개 작업**에
          대해 측정하였다. 차이(전−후)의 평균 d̄ = **0.8초**,
          차이의 표준편차 s_d = **1.0초**.
          유의수준 5%에서 개선 효과가 있는가?

   ① **대응표본 t-검정** (동일 대상 전후 비교)
   ② H₀ : μ_d = 0  /  H₁ : μ_d > 0  (단측)
   ③ 자유도 df = 10 − 1 = **9**, 임계값 t(0.05, 9) = **1.833**
   ④ t = 0.8 / (1.0 / √10) = 0.8 / 0.3162 = **2.53**
   ⑤ **2.53 > 1.833** → **H₀ 기각**
   ⑥ 결론 : 유의수준 5%에서 **처리시간이 유의하게 단축되었다**

Ⅴ. z-검정과 t-검정의 비교​

비교 기준z-검정t-검정
기준 분포표준정규분포 N(0,1)t분포(자유도에 따라 변화)
모분산(σ²)알고 있음(또는 대표본에서 s로 대체)모름 → 표본표준편차 s 사용
표본 크기대표본(n ≥ 30)소표본(n < 30) 에 적합
자유도없음(고정 분포)있음(df = n−1 등)
정규성 가정CLT로 완화 가능모집단 정규성 필요(소표본)
임계값(α=0.05, 양측)±1.96(고정)자유도에 따라 변동(df=9 → 2.262)
보수성상대적으로 관대더 보수적(꼬리가 두꺼워 기각 어려움)
주요 용도모비율 검정, 대규모 조사, 품질관리실험 연구, 소규모 A/B 테스트, 전후 비교
실무 사용 빈도낮음(모분산을 아는 경우가 드묾)높음(모분산 미지가 일반적)
   [**검정 방법 선택 흐름도**]

   두 집단(또는 한 집단)의 **평균** 비교
        │
        ├─ **모분산 σ²를 아는가?**
        │     ├─ Yes ──────────────────────▶ **z-검정**
        │     └─ No
        │          ├─ **n ≥ 30**(대표본) ──▶ **z-검정**(근사) 또는 t-검정
        │          │     ※ 실무에서는 **t-검정을 써도 무방**(결과 거의 동일)
        │          └─ **n < 30**(소표본)
        │                ├─ **정규성 만족** ──▶ **t-검정**
        │                └─ 정규성 위배 ─────▶ **비모수 검정**
        │                                     (Mann-Whitney U,
        │                                      Wilcoxon 부호순위)
        │
        └─ **3개 이상 집단** ────────────────▶ **ANOVA**(분산분석)
                                              ※ t-검정 반복 시
                                                **제1종 오류 누적**

Ⅵ. 활용 및 고려사항​

활용 분야내용
A/B 테스트두 버전의 전환율·체류시간 비교(독립표본 t-검정, 비율은 z-검정)
시스템 성능 개선 검증튜닝 전후 응답시간 비교(대응표본 t-검정)
품질관리공정 평균의 규격 준수 여부(일표본 검정), 관리도

① 가정의 확인정규성(Shapiro-Wilk), 등분산성(Levene), 독립성 검토 → 위배 시 Welch's t / 비모수 검정
② 통계적 유의성 ≠ 실무적 중요성n이 크면 사소한 차이도 유의하게 나옴 → 효과크기(Cohen's d) 와 신뢰구간을 함께 보고
③ 다중비교 문제t-검정을 여러 번 반복하면 제1종 오류가 누적 → ANOVA 또는 Bonferroni 보정
④ 표본 크기 사전 산정검정력(1−β) 0.8 이상 확보를 위한 표본 수 계산(Power Analysis)
⑤ p-hacking 경계유의한 결과가 나올 때까지 반복 분석 금지 → 사전 가설·분석계획 수립
⑥ 표본의 대표성무작위 추출이 전제 — 편향된 표본은 CLT로도 보정 불가
⑦ 단측 vs 양측방향성이 명확한 경우에만 단측검정 — 사후에 바꾸면 안 됨

Ⅶ. 결론​

중심극한정리는 통계적 추론 전체를 떠받치는 이론적 토대이다. 모집단의 분포를 알 수 없는 현실에서도 표본평균만큼은 정규분포를 따른다는 사실 덕분에 확률적 판단이 가능해지며, z-검정·t-검정·신뢰구간 추정·회귀분석이 모두 이 정리 위에 성립한다. 다만 CLT는 무작위 추출과 충분한 표본 크기를 전제로 하며, 편향된 표본에는 어떤 통계 기법도 무의미하다는 점을 항상 유념해야 한다.

z-검정과 t-검정의 차이는 결국 "모분산을 아는가" 로 귀결된다. 모분산을 알거나 대표본이면 정규분포를 그대로 쓸 수 있지만, 모분산을 모르고 표본이 작으면 표본표준편차로 추정하는 데서 오는 추가 불확실성을 t분포의 두꺼운 꼬리로 반영해야 한다. 이것이 t분포의 임계값이 더 큰 — 즉 더 보수적인 — 이유이다.

실무적으로는 모분산을 아는 경우가 거의 없으므로 t-검정이 훨씬 널리 사용되며, 표본이 크면 t분포가 정규분포에 수렴하므로 대표본에서도 t-검정을 쓰면 무방하다. 따라서 실무 판단의 핵심은 z와 t의 선택보다는 ① 정규성·등분산성 등 가정의 확인, ② 3개 이상 집단 비교 시 ANOVA로의 전환, ③ 통계적 유의성과 실무적 중요성의 구분에 있다.

특히 마지막 항목이 중요하다. 표본이 충분히 크면 실무적으로 무의미한 0.01초의 차이도 통계적으로 유의하게 나타난다. 따라서 p-value만 보고 의사결정을 내리지 말고, 효과크기와 신뢰구간을 함께 제시하여 "그 차이가 실제로 의미 있는 크기인가" 를 판단하는 것이 올바른 통계 활용 자세이다.
