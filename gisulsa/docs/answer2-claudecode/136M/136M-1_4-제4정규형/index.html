제4정규형(4NF: Fourth Normal Form)

Ⅰ. 개요​

제4정규형은 릴레이션이 BCNF를 만족하면서, 자명하지 않은 다치 종속(MVD: Multi-Valued Dependency)이 존재하지 않는 상태이다. 함수 종속으로는 제거되지 않는 서로 독립적인 다중 값 속성의 조합에 의한 중복을 해소한다.

Ⅱ. 다치 종속과 이상 현상​

   [정규화 단계]
   1NF(원자값) → 2NF(부분 함수종속 제거) → 3NF(이행 함수종속 제거)
   → BCNF(결정자=후보키) → **4NF(다치 종속 제거)** → 5NF(조인 종속 제거)

   [다치 종속 A ↠ B]
   : 하나의 A 값에 **여러 B 값의 집합이 대응**하고, 그 집합이 **C와 독립적**일 때

예) 교수 릴레이션 — 한 교수가 여러 과목을 담당하고 여러 자격증을 보유(상호 무관)

교수과목자격증
홍길동DB정보처리기술사
홍길동DB정보보안기사
홍길동네트워크정보처리기술사
홍길동네트워크정보보안기사
  • 문제: 과목과 자격증은 서로 무관한데도 모든 조합(2×2=4건)이 강제 저장 → 삽입·삭제·갱신 이상 발생
  • 다치 종속: 교수 ↠ 과목, 교수 ↠ 자격증 (자명하지 않음)

Ⅲ. 4NF 분해 및 판단 기준​

   [분해 — 무손실 분해(Lossless Join) 보장]
   ┌── **교수-과목** ──┐        ┌── **교수-자격증** ──┐
   │ 홍길동 | DB       │        │ 홍길동 | 기술사      │
   │ 홍길동 | 네트워크 │        │ 홍길동 | 보안기사    │
   └──────────────────┘        └─────────────────────┘
   ⇒ 4건 → 2+2건으로 축소, 과목 추가 시 자격증 수만큼 삽입할 필요 없음
판단 기준내용
4NF 조건BCNF 만족 + 모든 다치 종속 A ↠ B에서 A가 슈퍼키여야 함
자명한 MVDB ⊆ A 이거나 A ∪ B = 전체 속성인 경우 → 문제 없음
함수 종속과의 관계함수 종속은 다치 종속의 특수한 경우(값이 1개인 MVD)
발생 조건3개 이상의 속성이 존재하고, 두 다중값 속성이 상호 독립일 때

Ⅳ. 결론​

제4정규형은 함수 종속만으로는 제거되지 않는, 독립적 다중값 속성 간의 조합 중복을 해소한다는 점에서 의미가 있다. 실무에서는 대부분 3NF·BCNF 수준에서 설계를 마무리하지만, N:M 관계가 여러 개 얽힌 테이블에서는 4NF 위반이 실제로 발생하므로 점검이 필요하다. 다만 분해는 조인 비용을 수반하므로, 정규화 후 성능 요건에 따라 선택적 반정규화를 검토하는 것이 현실적이다.
