혼동행렬(Confusion Matrix)을 이용한 모델 성능 평가

Ⅰ. 개요​

혼동행렬은 분류 모델의 예측 결과와 실제 값의 대응 관계를 행렬 형태로 정리한 표로, 단일 지표로는 알 수 없는 오류의 유형과 방향까지 파악할 수 있게 해주는 분류 모델 평가의 기본 도구이다.

문제에 주어진 결과: TP = 100, FP = 5, FN = 7, TN = 9 (전체 121건)

Ⅱ. 가. 혼동행렬을 사용한 모델의 성능 평가 원리​

1. 혼동행렬의 구조​

                        **예측값(Predicted)**
                    ┌──────────────┬──────────────┐
                    │  Positive(P) │  Negative(N) │
   ┌────────────────┼──────────────┼──────────────┤
   │ **실제** Positive│  **TP = 100** │  **FN = 7**   │  ← 실제 양성 107건
   │ (Actual)        │  (True Positive)│(False Negative)│
   │                 │  정확히 맞춤   │ **놓침(2종 오류)**│
   ├────────────────┼──────────────┼──────────────┤
   │        Negative │  **FP = 5**   │  **TN = 9**   │  ← 실제 음성 14건
   │                 │(False Positive)│(True Negative)│
   │                 │**오탐(1종 오류)**│  정확히 맞춤  │
   └────────────────┴──────────────┴──────────────┘
                      예측 양성 105건   예측 음성 16건    **총 121건**

2. 4가지 결과의 의미​

구분명칭의미통계적 오류
TPTrue Positive양성을 양성으로 정확히 예측—
TNTrue Negative음성을 음성으로 정확히 예측—
FPFalse Positive음성을 양성으로 잘못 예측(오탐)1종 오류(α)
FNFalse Negative양성을 음성으로 잘못 예측(놓침)2종 오류(β)

3. 평가 원리​

원리내용
① 오류의 유형 구분단순 정확도는 "몇 개 틀렸는가"만 알려주지만, 혼동행렬은 "어떻게 틀렸는가"(FP형 오류인가 FN형 오류인가) 를 구분한다
② 오류 비용의 비대칭성 반영실무에서 FP와 FN의 손실 크기는 전혀 다르다
· 암 진단: FN(암을 놓침) ≫ FP(재검사) → 재현율 중시
· 스팸 필터: FP(정상 메일 차단) ≫ FN(스팸 통과) → 정밀도 중시
③ 클래스 불균형 탐지정확도만 보면 착시가 발생하는 상황을 행렬 구조로 즉시 확인 가능
④ 다양한 지표의 기반정확도·정밀도·재현율·특이도·F1·MCC 등 모든 분류 지표가 혼동행렬에서 도출
⑤ 임계값 조정의 근거분류 임계값(Threshold)을 조정하면 TP·FP가 변화 → ROC·PR 곡선 분석의 기초

Ⅲ. 나. 정확도·정밀도·재현율 계산 결과와 해석​

1. 정확도(Accuracy)​

   **정확도 = (TP + TN) / (TP + TN + FP + FN)**
            = (100 + 9) / (100 + 9 + 5 + 7)
            = 109 / 121
            = 0.90082...
   ⇒ **90 %** (소수점 버림)
항목내용
의미전체 예측 중 정답을 맞힌 비율
해석전체 121건 중 109건을 맞혀 표면적으로는 우수해 보인다.
⚠ 주의실제 양성이 107건(88.4%), 실제 음성이 14건(11.6%)로 클래스가 심하게 불균형하다.
이 경우 모든 데이터를 무조건 "양성"으로 예측하기만 해도 정확도는 107/121 ≈ 88% 가 나온다.
⇒ 즉 90%라는 정확도는 무의미한 분류기(88%)보다 겨우 2%p 높은 수준이며, 모델의 실질적 성능을 과대평가하게 만든다(Accuracy Paradox).

2. 정밀도(Precision)​

   **정밀도 = TP / (TP + FP)**
            = 100 / (100 + 5)
            = 100 / 105
            = 0.95238...
   ⇒ **95 %** (소수점 버림)
항목내용
의미모델이 양성이라고 예측한 것 중 실제로 양성인 비율 (예측의 신뢰도)
관점예측 결과 기준(세로 방향 — 예측 Positive 열)
해석양성으로 예측한 105건 중 100건이 실제 양성으로, 모델이 양성이라고 하면 95% 신뢰할 수 있다. 오탐(FP)이 5건으로 적어 불필요한 후속 조치 비용이 낮다.
중요한 상황스팸 필터, 광고 타겟팅, 추천 시스템 등 FP의 비용이 큰 경우

3. 재현율(Recall / 민감도 Sensitivity)​

   **재현율 = TP / (TP + FN)**
            = 100 / (100 + 7)
            = 100 / 107
            = 0.93457...
   ⇒ **93 %** (소수점 버림)
항목내용
의미실제 양성 중에서 모델이 찾아낸 비율 (탐지 능력)
관점실제 값 기준(가로 방향 — 실제 Positive 행)
해석실제 양성 107건 중 100건을 찾아내 탐지율이 93%로 양호하다. 다만 7건(약 6.5%)을 놓쳤으며(FN), 이것이 질병·사기·침입 탐지라면 놓친 7건의 피해가 매우 클 수 있다.
중요한 상황암 진단, 사기 탐지, 침입 탐지, 불량품 검출 등 FN의 비용이 큰 경우

4. 정밀도와 재현율의 관계 및 종합 해석​

   [Trade-off 관계]
   임계값 ↑ (엄격하게 양성 판정) → **정밀도 ↑, 재현율 ↓** (놓치는 것 증가)
   임계값 ↓ (느슨하게 양성 판정) → **재현율 ↑, 정밀도 ↓** (오탐 증가)

   [본 모델의 위치]
   정밀도 95% > 재현율 93% ⇒ 다소 **보수적(엄격한) 판정 경향**
   ⇒ 재현율이 더 중요한 도메인이라면 **임계값을 낮춰 FN(7건)을 줄이는 조정** 필요

5. 참고 — 음성 클래스에 대한 성능(문제점 확인)​

   **특이도(Specificity) = TN / (TN + FP) = 9 / (9 + 5) = 9/14 = 0.6428... ⇒ 64 %**
   **음성예측도(NPV)   = TN / (TN + FN) = 9 / (9 + 7) = 9/16 = 0.5625  ⇒ 56 %**

핵심 진단: 양성 클래스 성능(정밀도 95%·재현율 93%)은 우수하지만, 음성 클래스 성능은 특이도 64%·음성예측도 56%로 매우 저조하다. 이는 학습 데이터의 음성 표본이 14건에 불과한 심각한 불균형 때문이며, 정확도 90%라는 수치가 양성 클래스의 성능에 의해 만들어진 착시임을 명확히 보여준다.

Ⅳ. 다. F1-score 계산 결과와 해석​

1. 계산​

   **F1-score = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)**   ← 조화평균(Harmonic Mean)

   [방법 1 — 지표 대입]
   정밀도 = 100/105 ≈ 0.95238,  재현율 = 100/107 ≈ 0.93457

   F1 = 2 × (0.95238 × 0.93457) / (0.95238 + 0.93457)
      = 2 × 0.89006 / 1.88695
      = 1.78012 / 1.88695
      = 0.94339...

   [방법 2 — 혼동행렬 원소로 직접 계산(검산)]
   **F1 = 2TP / (2TP + FP + FN)** = (2×100) / (2×100 + 5 + 7)
        = 200 / 212 = 0.94339...

   ⇒ **F1-score = 94 %** (소수점 버림)

2. 해석​

항목내용
의미정밀도와 재현율의 조화평균 — 두 지표를 하나로 통합한 균형 지표
조화평균을 쓰는 이유산술평균은 한쪽이 극단적으로 낮아도 값이 높게 나오는 반면, 조화평균은 낮은 쪽에 크게 영향받는다.
예) 정밀도 100%, 재현율 0% → 산술평균 50%(오해 유발), 조화평균 0%(정확한 평가)
결과 해석F1 = 94% 로, 정밀도(95%)와 재현율(93%)이 모두 높고 균형 잡혀 있음을 의미한다. 두 값의 차이가 2%p로 작아 F1이 두 값 사이에 위치하며, 어느 한쪽으로 치우치지 않은 안정적 모델임을 나타낸다.
정확도(90%)와의 비교F1(94%) > 정확도(90%) — 이는 모델이 양성 클래스를 잘 분류하는 반면, 음성 클래스(14건)에서 오류가 집중되고 있음을 시사한다.
한계F1은 TN을 전혀 반영하지 않는다. 따라서 본 사례처럼 음성 클래스 성능이 저조해도 F1은 높게 나타나므로, F1만으로 모델을 판단해서는 안 된다.

3. 확장 지표 — F-beta 및 대안​

지표계산·의미적용
F1정밀도·재현율 동등 가중균형이 필요할 때
F2재현율에 2배 가중놓치면 안 되는 경우(암 진단·사기 탐지)
F0.5정밀도에 2배 가중오탐이 치명적인 경우(스팸 필터)
MCC(매튜 상관계수)TP·TN·FP·FN 4개 모두 반영, −1~+1불균형 데이터에서 F1보다 신뢰성 높음
PR-AUC정밀도-재현율 곡선 아래 면적불균형 데이터의 종합 평가
ROC-AUC임계값 전체에 걸친 판별력균형 데이터에 적합

본 사례처럼 음성 표본이 극히 적은 불균형 데이터에서는 MCC나 PR-AUC를 함께 확인하는 것이 타당하다.

Ⅴ. 종합 결과 및 개선 방안​

1. 계산 결과 요약​

지표계산식계산결과
정확도(Accuracy)(TP+TN)/전체109/121 = 0.900890 %
정밀도(Precision)TP/(TP+FP)100/105 = 0.952395 %
재현율(Recall)TP/(TP+FN)100/107 = 0.934593 %
F1-score2PR/(P+R) = 2TP/(2TP+FP+FN)200/212 = 0.943394 %
(참고) 특이도TN/(TN+FP)9/14 = 0.642864 %

2. 모델 진단 및 개선 방안​

진단개선 방안
심각한 클래스 불균형(양성 107 : 음성 14 ≈ 88:12)① 음성 데이터 추가 수집(가장 근본적)
② 오버샘플링(SMOTE)·언더샘플링, 클래스 가중치(Class Weight) 부여
③ 평가 시 층화 교차검증(Stratified K-Fold) 적용
정확도의 착시(무의미 분류기 88%와 근접)④ 정확도 대신 F1·MCC·PR-AUC를 주 지표로 사용
음성 클래스 성능 저조(특이도 64%)⑤ 음성 클래스에 대한 특징 공학 보강, 임계값 재조정
FN 7건 존재⑥ 도메인 특성상 놓침의 비용이 크다면 임계값을 낮추고 F2-score로 평가
평가 신뢰성⑦ 표본 121건은 소규모 → 교차검증과 별도 검증셋으로 재확인

Ⅵ. 결론​

혼동행렬은 단순히 지표를 계산하는 도구가 아니라, 오류의 유형(FP·FN)을 구분하여 비즈니스 손실 구조에 맞는 지표를 선택하게 해주는 진단 도구이다.

본 사례의 모델은 정확도 90%, 정밀도 95%, 재현율 93%, F1-score 94% 로 표면적으로는 우수하나, 실제 음성 표본이 14건에 불과한 심각한 불균형 데이터라는 점에서 해석에 주의가 필요하다. 특히 모든 것을 양성으로 예측하는 무의미한 분류기도 88%의 정확도를 얻는 상황이므로, 정확도 90%는 실질적 성능을 보증하지 못한다.

따라서 실무적으로는 ① 정확도가 아닌 F1·MCC·PR-AUC를 주 평가 지표로 사용하고, ② 음성 데이터를 추가 확보하거나 클래스 가중치·리샘플링으로 불균형을 완화하며, ③ 무엇보다 해당 도메인에서 FP와 FN 중 어느 오류가 더 치명적인지 판단하여 임계값과 평가 지표(F2 또는 F0.5)를 선택해야 한다. 결국 모델 평가의 핵심은 지표의 수치가 아니라 오류가 초래할 실제 비용에 대한 판단이다.
