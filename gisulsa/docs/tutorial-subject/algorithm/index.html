알고리즘/자료구조

정보관리기술사 기출문제 중 알고리즘/자료구조 관련 문제를 정리한 페이지입니다.

110회​

1교시​

  • 4.유한 오토마타에 대해 설명하시오.

유한 오토마타(Finite Automata)는 유한한 수의 상태를 가지며, 입력 기호에 따라 상태를 전이하는 수학적 모델입니다. 결정적(DFA)과 비결정적(NFA) 두 종류가 있으며, 정규 언어를 인식하는 데 사용됩니다. 컴파일러의 어휘 분석(Lexical Analysis) 단계에서 토큰을 인식하는 데 핵심적으로 활용됩니다.

113회​

1교시​

  • 1.다중연결리스트(Multi-linked List)

다중연결리스트는 각 노드가 두 개 이상의 포인터를 가져 여러 방향으로 연결될 수 있는 자료구조입니다. 행렬의 희소 표현이나 다차원 데이터 구조를 효율적으로 표현할 때 활용됩니다. 일반 단일 연결리스트보다 탐색 유연성이 높지만 포인터 관리가 복잡해집니다.

  • 7.우선순위 큐(Priority Queue)

우선순위 큐는 각 원소에 우선순위를 부여하여 우선순위가 높은 원소가 먼저 처리되는 자료구조입니다. 힙(Heap) 자료구조를 기반으로 구현하는 것이 일반적이며, 삽입과 삭제 연산이 O(log n)의 시간복잡도를 가집니다. 운영체제의 프로세스 스케줄링, 다익스트라 알고리즘 등에 광범위하게 사용됩니다.

4교시​

  • 4.인공지능으로 해결 할 수 있는 문제의 특징을 기술하고, 문제해결 방법 중 균일비용탐색(Uniform Cost Search)과 A* 알고리즘에 대하여 비교 설명하시오.

균일비용탐색(UCS)은 출발 노드에서 현재까지의 실제 비용 g(n)을 기준으로 최소 비용 경로를 탐색하는 알고리즘입니다. A* 알고리즘은 g(n)에 목표까지의 휴리스틱 추정 비용 h(n)을 더한 f(n) = g(n) + h(n)으로 탐색하여 더 효율적입니다. h(n)이 실제 비용을 과대평가하지 않는 허용 가능한(admissible) 휴리스틱을 사용하면 A*는 최적해를 보장합니다.

117회​

3교시​

  • 3.MST(Minimum Spanning Tree)를 구하는 알고리즘인 크루스칼(Kruskal) 알고리즘, 프림(Prim) 알고리즘을 설명하시오.

크루스칼 알고리즘은 모든 간선을 가중치 오름차순으로 정렬한 후 사이클을 형성하지 않는 간선을 순서대로 선택하여 MST를 구성합니다. 프림 알고리즘은 임의의 시작 정점에서 출발해 현재 트리에 연결된 최소 가중치 간선을 반복적으로 추가합니다. 크루스칼은 간선이 적은 희소 그래프에, 프림은 간선이 많은 밀집 그래프에 유리합니다.

4교시​

  • 4.운영체제에서 페이지 교체 알고리즘을 사용한다.
    • 가.페이지 교체 알고리즘을 사용하는 이유에 대하여 설명하시오.

물리적 메모리의 크기는 한정되어 있으므로, 프로세스가 필요로 하는 모든 페이지를 메모리에 올려둘 수 없습니다. 페이지 부재(Page Fault)가 발생했을 때 새로운 페이지를 적재하기 위해 기존 페이지 중 하나를 내보내야 합니다. 페이지 교체 알고리즘은 어떤 페이지를 내보낼지 결정하여 페이지 부재율을 최소화하는 역할을 합니다.

  • 나.페이지 교체 알고리즘의 종류를 나열하고, 각 종류별 동작 과정에 대하여 설명하시오.

FIFO는 메모리에 가장 먼저 올라온 페이지를 교체하며 구현이 단순하지만 성능이 낮을 수 있습니다. LRU(Least Recently Used)는 가장 오랫동안 사용되지 않은 페이지를 교체하여 실제 사용 패턴을 잘 반영합니다. OPT(최적 알고리즘)는 앞으로 가장 오래 사용되지 않을 페이지를 교체하는 이론적 최적 기법이지만 실제 구현은 불가능합니다.

113회​

3교시​

  • 5.유전 알고리즘(Genetic algorithm)을 정의하고, 그 알고리즘의 흐름을 설명한 후, 이 알고리즘에서 사용되는 기법인 룰렛 휠 선택(roulett wheel selection)의 역할에 대하여 설명하시오.

유전 알고리즘은 자연의 진화 과정(선택, 교차, 돌연변이)을 모방하여 최적해를 탐색하는 메타휴리스틱 알고리즘입니다. 초기 집단(Population)을 생성하고 적합도(Fitness)를 평가한 후 선택, 교차, 돌연변이를 반복하여 해를 개선합니다. 룰렛 휠 선택은 개체의 적합도에 비례하는 확률로 부모를 선택하여 우수한 개체가 더 많이 선택되도록 하는 방법입니다.

119회​

1교시​

  • 11.정규식(Regular Expression), 유한오토마타

정규식은 문자열의 패턴을 표현하는 형식 언어로, 문자열 검색·치환·유효성 검사에 널리 사용됩니다. 유한 오토마타는 정규식을 기계적으로 처리하기 위한 상태 기계 모델로, 정규식과 1:1 대응 관계를 가집니다. NFA(비결정 유한 오토마타)를 거쳐 DFA(결정 유한 오토마타)로 변환하면 효율적인 패턴 매칭이 가능합니다.

122회​

2교시​

  • 6.스택(Stack)의 개념을 설명하고, 아래의 조건을 만족하는 스택의 작동 알고리즘을 작성하시오.(K : 스택의 크기, Top : 스택 포인터, S : 스택의 이름)
    • 가.스택(S)의 스택 포인터(Top)를 1 증가시킨다. 스택 포인터가 스택의 크기(K)보다 크면 Overflow 처리한다. 그렇지 않으면 Item이 가지고 있는 값을 스택의 Top 위치에 삽입한다.

스택의 Push 연산은 데이터를 스택의 상단에 추가하는 작업입니다. Top 포인터를 먼저 1 증가시킨 후, 그 값이 최대 크기 K를 초과하면 오버플로(Overflow) 오류를 발생시킵니다. 오버플로가 아닌 경우 S[Top] 위치에 Item 값을 저장합니다.

  • 나.스택 포인터가 0이면 스택의 바닥이며 더 이상 삭제할 자료가 없으므로 Underflow 처리한다. 그렇지 않으면 Top 위치에 있는 값을 Item으로 옮기고 스택 포인터를 1 감소시킨다.

스택의 Pop 연산은 스택의 최상단 데이터를 꺼내는 작업입니다. Top이 0이면 스택이 비어 있으므로 언더플로(Underflow) 오류를 발생시킵니다. 정상인 경우 S[Top] 값을 Item에 저장하고 Top을 1 감소시켜 스택의 크기를 줄입니다.

123회​

4교시​

  • 6.다음에 대하여 설명하시오.
    • 가.최단경로 알고리즘의 유형 4가지

최단경로 알고리즘의 대표적인 유형으로는 다익스트라, 벨만-포드, 플로이드-워샬, A* 알고리즘이 있습니다. 다익스트라는 음수 가중치가 없는 그래프에서 단일 출발지 최단 경로를 효율적으로 구합니다. 벨만-포드는 음수 가중치를 허용하며, 플로이드-워샬은 모든 쌍 최단 경로를 한 번에 계산합니다.

  • 나.다음 그래프에서 4가지 알고리즘 계산 방법 (A, B, C, D, E 5개 노드로 구성된 그래프, A가 출발지, E가 목적지임)

다익스트라는 A에서 출발하여 인접 노드를 탐색하며 최소 비용 누적 경로를 갱신합니다. 벨만-포드는 모든 간선을 (노드 수-1)번 반복 완화하여 최단 거리를 구합니다. 플로이드-워샬은 2차원 비용 행렬을 초기화하고 각 중간 노드를 경유하는 경우를 비교하여 최소값으로 갱신합니다.

  • 다."나"의 4가지 알고리즘 계산결과 비교

동일한 그래프에 대해 4가지 알고리즘을 적용하면 최적 경로는 동일하지만 탐색 과정과 시간복잡도가 다릅니다. 다익스트라는 O((V+E)log V), 벨만-포드는 O(VE), 플로이드-워샬은 O(V³)의 복잡도를 가집니다. 문제 조건(음수 가중치 유무, 단일/다중 출발지)에 따라 적합한 알고리즘을 선택해야 합니다.

124회​

3교시​

  • 2.자료구조 Heap의 2가지 유형인 Max-heap과 Min-heap을 설명하시오.

힙(Heap)은 완전 이진 트리 기반의 자료구조로, 부모 노드와 자식 노드 간의 대소 관계가 일정하게 유지됩니다. Max-heap은 부모 노드가 자식 노드보다 항상 크거나 같으며, 루트가 최댓값입니다. Min-heap은 그 반대로 루트가 항상 최솟값이 되며, 우선순위 큐나 힙 정렬에 활용됩니다.

3교시​

  • 4.교착 상태(Dead Lock)의 개념과 교착상태를 회피하기 위한 은행가 알고리즘(Banker's Algorithm)의 개념 및 자료구조를 설명하시오.

교착 상태(Deadlock)는 둘 이상의 프로세스가 서로 상대방이 점유한 자원을 기다리며 무한히 대기하는 상태입니다. 은행가 알고리즘은 자원 요청 시 안전 상태(Safe State)를 유지할 수 있는지 시뮬레이션하여 교착 상태를 예방합니다. 최대 요구량, 할당량, 가용량 행렬을 활용하여 안전 순서열 존재 여부를 판단합니다.

125회​

1교시​

  • 4.선형 자료구조와 비선형 자료구조

선형 자료구조는 데이터 요소들이 순차적으로 배열된 구조로 배열, 스택, 큐, 연결리스트가 해당됩니다. 비선형 자료구조는 하나의 데이터가 여러 데이터와 관계를 맺는 구조로 트리와 그래프가 대표적입니다. 선형 구조는 순차 탐색이 주를 이루고, 비선형 구조는 계층적 또는 망 형태의 관계를 표현하는 데 적합합니다.

3교시​

  • 1.배열을 이용하여 큐(Queue)를 구성할 때의 단점과 해결 방법을 설명하시오.

배열로 구현한 선형 큐는 Front와 Rear 포인터가 한 방향으로만 이동하므로 앞쪽 공간이 비어도 재사용이 불가능한 공간 낭비 문제가 발생합니다. 이를 해결하기 위해 원형 큐(Circular Queue)를 사용하면 배열의 끝과 처음을 연결하여 공간을 효율적으로 재활용할 수 있습니다. 원형 큐에서는 (Rear + 1) % 배열크기로 다음 인덱스를 계산하여 포화/공백 상태를 판단합니다.

126회​

1교시​

  • 10.스래싱

스래싱(Thrashing)은 프로세스들이 실제 작업보다 페이지 교체를 위한 입출력에 더 많은 시간을 소비하는 현상입니다. 다중 프로그래밍 정도가 지나치게 높아지면 각 프로세스에 할당되는 페이지 프레임이 줄어들어 페이지 부재율이 급격히 증가합니다. 작업 집합(Working Set) 모델이나 페이지 부재 빈도(PFF) 기법으로 스래싱을 예방할 수 있습니다.

4교시​

  • 4.방향성 비순환 그래프(Directed Acyclic Graph)에 대하여 다음 물음에 답하시오.
    • 가.방향성 비순환 그래프의 개념과 특징

DAG(Directed Acyclic Graph)는 방향이 있는 간선으로 연결되며 사이클이 존재하지 않는 그래프입니다. 순환이 없으므로 위상 정렬이 가능하며, 작업 스케줄링이나 데이터 의존성 표현에 적합합니다. Git의 커밋 이력, 빌드 시스템의 의존성 관리, 데이터 파이프라인 등에서 널리 활용됩니다.

  • 나.아래 방향성 비순환 그래프에 대하여 위상정렬(Topology Sort)을 실시하고 결과값 제시

위상 정렬은 DAG에서 각 정점을 간선의 방향에 어긋나지 않도록 선형으로 나열하는 알고리즘입니다. 진입 차수(In-degree)가 0인 노드를 먼저 선택하고 해당 노드와 연결된 간선을 제거하는 과정을 반복합니다. 결과적으로 선행 관계를 모두 만족하는 순서로 정렬된 노드 리스트가 출력됩니다.

131회​

1교시​

  • 13.트리정렬(Tree Sort)

트리 정렬은 데이터를 이진 탐색 트리(BST)에 차례로 삽입한 후, 중위 순회(In-order Traversal)로 노드를 방문하여 정렬된 결과를 얻는 알고리즘입니다. 평균 시간복잡도는 O(n log n)이지만 이미 정렬된 데이터가 입력되면 최악 O(n²)이 됩니다. AVL 트리나 레드-블랙 트리를 사용하면 항상 O(n log n)을 보장할 수 있습니다.

3교시​

  • 2.데이터 구조(Data Structure)에 대하여 다음을 설명하시오.
    • 가.선형 구조(Linear Structure)의 개념 및 유형

선형 구조는 데이터 요소들이 일렬로 순서 있게 나열된 자료구조입니다. 각 요소가 최대 하나의 선행 요소와 하나의 후행 요소를 가지는 1:1 관계가 특징입니다. 대표적인 유형으로 배열(Array), 연결리스트(Linked List), 스택(Stack), 큐(Queue), 덱(Deque)이 있습니다.

  • 나.비선형 구조(Non-Linear Structure)의 개념 및 유형

비선형 구조는 하나의 데이터 요소가 여러 요소와 관계를 맺을 수 있는 자료구조입니다. 1:N 또는 N:M의 관계를 가지므로 계층적이거나 그물망 형태의 데이터 표현에 적합합니다. 트리(Tree)와 그래프(Graph)가 대표적인 비선형 구조입니다.

  • 다.선형 구조(Linear Structure)와 비선형 구조(Non-Linear Structure) 비교

선형 구조는 데이터 접근이 순차적이어서 탐색이 단순하지만 표현력이 제한적입니다. 비선형 구조는 복잡한 관계를 표현할 수 있으나 탐색 알고리즘이 더 복잡합니다. 활용 목적에 따라 선형 구조는 순차 처리 작업에, 비선형 구조는 계층·네트워크 데이터 표현에 사용됩니다.

  • 6.선형 자료 구조인 스택, 큐, 리스트의 자료 입출력 원리를 설명하시오.

스택(Stack)은 LIFO(Last In First Out) 방식으로 마지막에 삽입된 데이터가 먼저 삭제되며 Push/Pop 연산을 사용합니다. 큐(Queue)는 FIFO(First In First Out) 방식으로 먼저 삽입된 데이터가 먼저 삭제되며 Enqueue/Dequeue 연산을 사용합니다. 리스트(List)는 임의 위치에서 삽입·삭제가 가능하며 포인터를 통해 노드를 연결합니다.

3교시​

  • 4.알고리즘의 복잡도를 설명하고 성능을 표기하기 위한 O-Notation의 개념과 유형 및 유형별 연산시간의 차이를 설명하시오.

알고리즘 복잡도는 입력 크기 n에 따른 자원(시간, 공간) 사용량을 분석하는 척도입니다. O-Notation(Big-O 표기법)은 최악의 경우 시간복잡도를 표현하며 알고리즘의 성능 상한을 나타냅니다. O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) 순으로 효율이 떨어지며, 알고리즘 선택의 핵심 기준이 됩니다.

4교시​

  • 1.확장성 해싱(Extendible Hashing)기법에 대하여 다음을 설명하시오.
    • 가.개념 및 구성요소

확장성 해싱은 데이터가 증가함에 따라 동적으로 디렉토리와 버킷을 확장할 수 있는 해싱 기법입니다. 전체 해시 테이블을 재구성하지 않고 분할이 필요한 버킷만 분리하여 효율적으로 확장합니다. 주요 구성요소로는 글로벌 깊이(Global Depth), 로컬 깊이(Local Depth), 디렉토리(Directory), 버킷(Bucket)이 있습니다.

  • 나.충돌회피 기법

해시 충돌 발생 시 확장성 해싱은 해당 버킷을 분할하고 로컬 깊이를 증가시켜 충돌을 해결합니다. 로컬 깊이가 글로벌 깊이와 같아지면 디렉토리 크기를 두 배로 늘려 글로벌 깊이를 1 증가시킵니다. 이 방식은 점진적 확장이 가능하여 대규모 동적 데이터셋 처리에 효과적입니다.

  • 12.이진 탐색 트리를 설명하시오.

이진 탐색 트리(BST)는 각 노드의 왼쪽 서브트리에는 노드보다 작은 값, 오른쪽 서브트리에는 큰 값이 위치하는 이진 트리입니다. 탐색, 삽입, 삭제 연산의 평균 시간복잡도는 O(log n)이며, 중위 순회 시 정렬된 결과를 얻을 수 있습니다. 트리가 편향되면 최악 O(n)이 되므로 AVL 트리나 레드-블랙 트리 같은 균형 BST를 활용합니다.

4교시​

  • 5.유전 알고리즘(Genetic Algorithm)에 대하여 설명하시오.
    • 가.유전 알고리즘의 개념 및 절차

유전 알고리즘은 생물학적 진화를 모방하여 최적해를 탐색하는 확률론적 탐색 기법입니다. 초기 집단 생성 → 적합도 평가 → 선택 → 교차 → 돌연변이 → 새 세대 생성의 절차를 반복합니다. 넓은 탐색 공간에서 복잡한 최적화 문제를 해결하는 데 효과적이며, 지역 최적해(Local Optima) 회피 능력이 뛰어납니다.

  • 나.유전 알고리즘의 최적화 방법

유전 알고리즘의 최적화는 적합도 함수 설계, 선택 압력 조절, 교차·돌연변이 확률 튜닝을 통해 이루어집니다. 엘리트주의(Elitism)를 적용하면 최우수 개체를 다음 세대에 그대로 유지하여 해의 퇴보를 방지합니다. 탐색(Exploration)과 활용(Exploitation) 간의 균형을 유지하는 것이 최적화 성능의 핵심입니다.

1교시​

  • 11.은행가 알고리즘(Banker's Algorithm)

은행가 알고리즘은 다익스트라가 제안한 교착 상태 회피 알고리즘으로, 자원 요청 시 시스템이 안전 상태를 유지할 수 있는지 미리 검사합니다. 각 프로세스의 최대 요구량, 현재 할당량, 잔여 필요량을 관리하는 행렬을 기반으로 안전 순서열의 존재 여부를 판단합니다. 안전 순서열이 존재하면 자원을 할당하고, 존재하지 않으면 프로세스를 대기시켜 교착 상태를 예방합니다.
